# Original-question certification scope

The repository contains 3,406 detailed reviewed explanations and essential question contexts. That does not certify verbatim original wording, every option glyph, or all original artwork for the entire collection.

The 279 records with source_transcription_verified set to true use that field for essential source-faithful text or paraphrases; they are not a count of fully certified verbatim originals. Their question_text_status fields preserve that narrower scope. A separate item-by-item original-text, option and figure audit is required before reporting such a count.

The strict release validator currently combines generic verification labels, transcription flags, inventory and final-key requirements. Its failure is not a count of unsolved questions. No gate has been relaxed to conceal these limits.

The 2019 Q10 diagram's stale pending-accessibility label was reconciled with its already independently reviewed complete topology/choice reconstruction. Physical dimensions remain unspecified in the original and are not inferred. The 2025 CS1 Q9 source-page artwork is another dedicated access artifact; raster access alone is not screen-reader certification.

Next steps: inventory original text/options/figures separately; verify direct original-paper links; check applicable copying permissions; compare source glyphs and artwork; retain unknown historical completeness and unresolved source variants explicitly. Public availability alone is not evidence of permission to reproduce entire papers.
