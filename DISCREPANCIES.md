## Corrections and qualifications found during detailed expansion

- CS-2007-Q32: the initial independent answer B dropped a complement mark on z. The source expression Q=w′y′z′+wx′y′+xz is equivalent to the target, as are P and R. Only S differs, so the corrected independent answer is D. No official key was located. See the independent expansion review audit.
- CS-2008-Q60-source-code: the source prints z=*ppz, where ppz is int**. Assigning the resulting pointer to an int violates standard C assignment constraints. The earlier numeric answer B=19 applies only after an explicit repair to z=**ppz; no portable numeric answer follows as printed. Both the literal code and conditional trace are retained.
- CS-2006-Q39-overbar-scope: the reproduced second term has a continuous complement bar over ab. Standard signed overflow is ab¬c+¬a¬bc; a grouped reading ab¬c+¬(ab)c is different. B is therefore conditional on separate-literal complements, not an unconditional literal-source answer. Both reproductions were checked; no official key is available.
- CS-2015-S3-Q36: detailed arithmetic review corrected the calculated Simpson result from 308.67 to 309.33 km. Odd/even sample sums are 80 and 72, giving (2/3)(4×80+2×72)=309.3333. The published accepted interval 308–310 is unchanged.

- CS-2003-Q38: corrected the earlier independent answer B to C. Both reproduced multiplication tables have b×b=c. The simultaneous equations therefore have two solutions, (b,c) and (c,b), not one. No official key was located.
