**Official answer:** Not available; no official key located.

**Independently derived answer:** B: 2

**Essential problem context (paraphrased):** A counting semaphore starts at7. Twenty P and fifteen V operations complete. What is its final value?

## Solution

Each completed P consumes one permit, decreasing the value by one; each V adds one. The net change is −20+15=−5, so the final value is7−5=2. The word completed matters: blocked, uncompleted waits cannot simply be counted as successful acquisitions in a nonnegative semaphore convention. The stated totals permit an interleaving with enough signals before later waits, so no contradiction is implied by having twenty waits after an initial value of only seven.

**Independently derived answer:** A: n=2

**Essential problem context (paraphrased):** Six identical tape drives are shared by n processes, each possibly needing three. What maximum n guarantees no resource deadlock without restrictive allocation?

## Solution

A worst-case deadlock can have every process hold two drives and wait for its third. To rule that out for n processes, at least2n+1 drives suffice under the standard completion model. With six drives, this requires n≤2. For three processes, each can hold two, exhausting all six and waiting forever. For two processes, their combined maximum demand is six, so both can be fully satisfied. The guarantee assumes eventual completion after required resources are granted and no additional resource types or faulty nontermination.

**Independently derived answer:** C: line printer

**Essential problem context (paraphrased):** Which is a spooled-device example: interactive input terminal, virtual-memory backing store, line printer serving jobs, or none?

## Solution

Spooling places jobs in a queue, usually on disk, and lets a dedicated service feed an exclusive sequential device at its own speed. A printer serving several jobs is the standard example: applications finish depositing their output without waiting for physical printing, and each job can be kept separate. A terminal’s interactive input and demand paging have different purposes, even though they may involve buffers or secondary storage. The presence of a buffer alone does not make an operation spooling.

**Official answer:** Not available; no official key located.

**Independently derived answer:** FIFO: Belady’s anomaly

**Essential problem context (paraphrased):** Which page-replacement policy can have more faults when memory size increases?

## Solution

FIFO evicts the page loaded earliest, not necessarily the least useful page. With different frame counts, the order of subsequent evictions can change so that the larger memory performs worse. For example the reference string1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5 has nine FIFO faults with three frames but ten with four. LRU and optimal replacement have the stack-inclusion property and avoid this anomaly. The question asks for a policy that sometimes exhibits it, not a claim that adding frames always hurts FIFO.

**Independently derived answer:** Edges: 1→2,3,7; 2→4; 3→5,6; 6→8; 4,5,8,7→9.

**Essential problem context (paraphrased):** Draw the precedence graph for this concurrent program. Within begin/end statements are sequential; parbegin/parend runs its components concurrently and joins them:
S1;
parbegin
  begin S2; S4 end;
  begin S3; parbegin S5; begin S6; S8 end parend end;
  S7
parend;
S9

## Solution

S1 executes before the outer fork. Its three branches start with S2, S3, and S7. In the first branch S2 precedes S4. In the second branch S3 precedes a nested fork: S5 runs in parallel with the sequential pair S6 then S8. The outer join waits for S4, both S5 and S8, and S7 before permitting S9.

The precedence graph (arrows are immediate dependencies) is:

          ┌→ S2 → S4 ─────────┐
          │                  │
S1 ───────┼→ S3 ─┬→ S5 ─────┼→ S9
          │      └→ S6 → S8 ─┤
          └→ S7 ─────────────┘

Its exact edge set is {(S1,S2),(S1,S3),(S1,S7),(S2,S4),(S3,S5),(S3,S6),(S6,S8),(S4,S9),(S5,S9),(S8,S9),(S7,S9)}. This is a transitive reduction: edges such as S1→S9 are implied and need not be drawn. It uses only statement vertices; explicit fork/join vertices would be an equivalent representation.

Do not add S4→S3, S5→S6, or S8→S7: textual order among separate parallel branches does not force execution order. Conversely, S9 must not start after just one branch finishes. The structure imposes control dependencies only; no extra read/write data dependencies are supplied. Both source images visibly include S9 after the outer parend, even though OCR can omit it.

# GATE 1992: Q58 (printed B Q12(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 5 page faults; average |W(t)| for t=1…10 is 3.2 frames.

**Essential problem context (paraphrased):** With working-set window Δ=4, process the page references c c d b c e c e a d. Initially W(0)={a,d,e}; the latest initial references are a at t=0, d at t=−1, and e at t=−2. Find each working set, the total faults, and average frames used.

## Solution

Use the standard discrete-reference window W(t) containing pages referenced at times t−3 through t, i.e. the last four references including the current one. Immediately before reference t, resident pages are W(t−1); a fault occurs exactly when the requested page is absent there. After serving the request, remove pages no longer in the new window. The specified W(0) fixes initial residency; any unspecified t=−3 reference expires at t=1 and does not affect the trace.

t  page   W(t)       size  fault?
0  a      {a,d,e}     3    initial state
1  c      {a,c,d,e}   4    yes
2  c      {a,c,d}     3    no
3  d      {a,c,d}     3    no
4  b      {b,c,d}     3    yes
5  c      {b,c,d}     3    no
6  e      {b,c,d,e}   4    yes
7  c      {b,c,e}     3    no
8  e      {c,e}       2    no
9  a      {a,c,e}     3    yes
10 d      {a,c,d,e}   4    yes

For example at t=6 the four references are d,b,c,e, whereas at t=8 they are c,e,c,e, using only two distinct frames. The last d reference at t=3 has expired by t=7, so d faults again at t=10. Fault times are 1,4,6,9,10: five faults.

The frame sum over the ten requested-reference instants is 4+3+3+3+3+4+3+2+3+4=32, so the conventional post-reference average is 32/10=3.2 frames. If one instead includes the supplied initial snapshot as an eleventh sample, the average is 35/11; if averaging pre-reference residency W(0)…W(9), it is 31/10. These are different sampling conventions, not different working-set traces. The reported 3.2 explicitly averages W(1)…W(10).
