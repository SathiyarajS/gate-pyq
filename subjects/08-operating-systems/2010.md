

# GATE 2010: Q33 (printed CS Q23)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 5. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

P1 passes its guard only when S1≠S2; P2 passes only when S1=S2. Neither changes the shared state until leaving its critical section, so while one is inside the other’s guard stays blocking: mutual exclusion holds. Progress fails: if S1=S2 and only P1 wants to enter, P1 spins forever unless P2 participates and changes S2. The symmetric case also occurs. This is strict alternation, so A, assuming atomic sequentially consistent accesses as the pseudocode model does.

# GATE 2010: Q34 (printed CS Q24)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 5. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

The first 100 distinct references all fault. The four resident pages are then the last four in forward order, and the reverse scan hits these four first. Every one of the other 96 reverse references is to a page not yet resident; those faults evict only pages already visited in the reverse scan. Therefore faults total 100+96=196, option A. Hits do not refresh FIFO order.

# GATE 2010: Q35 (printed CS Q25)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 6. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

SRTF may indefinitely postpone a long job when shorter jobs keep arriving, so I is true. SRTF is itself preemptive, establishing that preemptive scheduling may cause starvation, so II is true. Round robin’s time slices let waiting jobs receive CPU service without waiting for a long earlier job to finish, which is the conventional interactive response-time advantage asserted by III. The intended answer is all three, D. III is a qualitative textbook comparison, not a strict improvement for every workload and quantum; for a quantum exceeding all bursts, RR reduces to FCFS.

# GATE 2010: Q55 (printed CS Q45)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 11. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

P0 consumes the initial S0 permit and prints once, then enables P1 and P2. Each of those processes releases S0 exactly once. If both releases occur before P0 next waits on S0, binary saturation coalesces them into one permit, allowing only one further print: total 2. If P0 consumes the first released permit before the other process releases S0, it receives two separate permits and prints three times total. Thus 2 or 3 prints are possible, so the only correct choice is A, at least twice. This assumes ordinary progress/eventual scheduling; an adversarial scheduler that permanently starves runnable processes defeats any eventual-print guarantee. A counting semaphore would instead give exactly three.

# GATE 2010: Q56 (printed CS Q46)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 11. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Read the code as even i requesting Ri followed by R(i+2), and odd i requesting R(n−i) followed by R(n−i−2), subject to the printed guards. For n=21,k=12, P10 requests R10 then R12, while P9 requests R12 then R10. If each obtains its first resource, they wait on each other: deadlock is possible, B. For even n (A and C), even processes use only even-indexed resources in increasing order, while odd processes use only odd-indexed resources in decreasing order. Each parity class has a consistent order, so neither can cycle. For D, n=41,k=19: even processes use resources 0 through 20, whereas odd processes use even resources 22 through 40, so these opposite-order sets do not overlap and cannot form a cycle. This uses single-instance, non-preemptive resources held until completion, the standard deadlock model. The low-quality scan has faint minus signs/subscripts in the odd branch; the relevant R(n−i),R(n−i−2) reading is recorded explicitly.
