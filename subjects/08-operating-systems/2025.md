

# GATE 2025 CS1: Q14

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

A page contains 2048=2¹¹ bytes, so the logical address splits into 21 virtual-page bits and 11 offset bits. A conventional page table with one entry per virtual page can therefore have 2²¹ entries, A. The 20-bit physical address determines frame-number width, not the number of possible virtual-page entries.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 21 to 21

**Derived answer:** 21

## Solution

There is one scanf call and twenty printf calls, hence 21 stipulated I/O operations. An I/O request moves this process from running to blocked/I/O, not to ready. Each corresponding completion makes it ready once. Excluding initial admission gives 21 ready-queue entries. This counts the transitions forced by the question’s model and assumes no additional time-slice or priority preemptions; such preemptions, if allowed, would add ready entries not determined by the code. The stipulated model also treats every listed library I/O operation as blocking, irrespective of real buffering.

# GATE 2025 CS1: Q38

**Question:** [Official archived paper page 38](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=38); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

At time 0, M1 takes its highest-priority process P1 and M2 takes P2; both have zero waiting time. At t=16, M2 finishes P2 and selects the highest-priority waiting process P3, which then runs until t=41. At t=20, M1 finishes P1 and selects the remaining P4, running until t=30. Waiting times are therefore 0, 0, 16, 20 milliseconds; their average is (36/4)=9. 00 ms, option A.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 65468 to 65468

**Derived answer:** 65468

## Solution

Each 65536-byte block leaves 65532 bytes for file data after its4-byte pointer. A1 MiB file therefore needs ceil(1048576/65532)=17 blocks. Unused data capacity is 17×65532−1048576=65468 bytes. The68 pointer bytes are allocation overhead, not internal fragmentation; counting them would instead give65536 total bytes beyond file payload.
