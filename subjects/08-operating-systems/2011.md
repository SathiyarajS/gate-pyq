**Question:** [Official archived paper page 2](https://web.archive.org/web/20220204093545id_/https://gate.iitkgp.ac.in/documents/gatepapers/2011/cs_2011.pdf#page=2); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C in the conventional OS model

**Source access:** Archived official IIT Kharagpur paper and IIT Madras key, booklet A. Physical PDF page numbers are used; code A is the matching key column. Final-revision designation is unverified.

## Solution

A user/kernel mode switch changes privilege and performs the associated entry/exit bookkeeping without necessarily changing the current process. A process context switch additionally saves/restores execution context and changes scheduling/address-space state. In the conventional comparison this costs more, giving t1<t2, C. It is an architectural cost-model comparison, not a hardware-independent numerical law for arbitrary implementations.

## Solution

The fault probability is 10^−6 and 10ms=10^7 ns. Average fault overhead contributes10 ns per access, in addition to the 20 ns memory time, giving approximately30 ns, B. If fault service is taken as a replacement rather than added time, the weighted result29.99998 ns has the same rounded answer.

**Question:** [Official archived paper page 11](https://web.archive.org/web/20220204093545id_/https://gate.iitkgp.ac.in/documents/gatepapers/2011/cs_2011.pdf#page=11); consult original wording, diagrams and choices.

**Official answer:** B

**Derived answer:** B

**Source access:** Archived official IIT Kharagpur paper and IIT Madras key, booklet A. Physical PDF page numbers are used; code A is the matching key column. Final-revision designation is unverified.

## Solution

At 6000 rpm the disk makes 100 revolutions per second, so one revolution lasts 10 ms. Random angular position gives an average rotational latency of 5 ms. Each library requires one access with 10 ms seek time plus 5 ms average rotational latency; transfer time is neglected. The total expected loading time is 100×15 ms=1500 ms=1.50 s, option B. The random-location wording calls for average rotational latency, not a full revolution per access.
