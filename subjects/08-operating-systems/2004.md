## Solution

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D under synchronous single-request I/O

## Solution

If the single sequential process blocks for each disk request, there is never a choice among queued requests. FCFS and SSTF therefore execute the same sequence, giving0% improvement, D; a benchmark with concurrency does not transfer to this case. The premise of one sequential process alone does not prohibit asynchronous I/O, readahead or background requests. Without the one-outstanding-request assumption, the improvement is not determined by the stated facts.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A under a fixed paging configuration

## Solution

The instruction set determines which instruction bytes and operands may have to be resident together to complete/restart one instruction without endless page faults. Thus A is the standard determinant of the minimum required frame count, rather than a count based simply on concurrent processes or total RAM. Exact numerical requirements also depend on the fixed page size, operand placement, and restart implementation; the answer identifies the architectural constraint, not independence from all those details.

**Official answer:** Not available; no official key located.

**Independently derived answer:** 1260 ns under literal two-level page-table model; no listed option

## Solution

Assuming negligible TLB lookup time and a true two-level page table, a TLB hit costs150ns and a miss costs three memory accesses: two page-table reads plus the requested data access,450ns. Two accesses per instruction therefore cost2(0.9×150+0.1×450)=360ns. Add100ns CPU time and8,000,000/10,000=800ns amortized fault service:1260ns. None of645,1050,1215,1230 matches. Option D=1230ns results from counting only TWO total memory accesses per TLB miss:100+2(0.9×150+0.1×300)+800. That requires a single-level translation model or an unstated cached first-level entry. Treat the result as model-dependent rather than silently forcing D. Minor whether-fault-service-includes-retry conventions do not account for the30ns discrepancy.

# GATE 2004: Q48 (printed CS Q48)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203330/GATE2004.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Both processes must acquire both Sx and Sy, exactly once, in the same global order. Option D supplies P(Sx),P(Sy) to both processes. A process that has acquired Sx prevents its competitor from holding Sy while it waits for Sx, so the circular-wait condition is impossible. Options A/B use opposite acquisition orders and admit deadlock; C acquires the same binary semaphore twice and can block itself. Different release orders do not invalidate the common acquisition order.

## Solution

A1KiB indirect block holds1024/4=256 addresses. The inode can reference10+256+256²+256³=16,843,018 data blocks, totaling17,247,250,432 bytes. The32-bit block-address space and48-bit integer bound are both larger and do not constrain this total. The dominant triple-indirect contribution alone is256³×1024=2^34 bytes, option C, but the exact maximum includes direct, single-indirect and double-indirect blocks and exceeds2^34 by67,381,248 bytes. Thus no offered power-of-two option is exactly the stated maximum; C is the usual scale approximation, not an exact equality.
