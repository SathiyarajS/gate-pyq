

# GATE 2024 CS1: Q24

**Question:** [Official archived paper page 16](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=16); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

## Solution

Threads may be implemented in user space or kernel space. Threads within a process normally share its file descriptors and address space, but each has its own execution stack and registers. Sharing the address space means one thread can access another’s memory without default process-style protection. Thus only D.

# GATE 2024 CS1: Q25

**Question:** [Official archived paper page 17](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=17); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

## Solution

In the standard process-state graph, preemption moves Running→Ready and exit moves Running→Terminated. A waiting process first becomes Ready when its event completes; dispatch then makes it Running. A Ready process must execute before issuing a blocking operation, so it cannot directly become Waiting. Thus the impossible direct transitions are B and C.

Across the three x values there are2, 4, 8 executions, totaling14. wait changes scheduling but does not delete any remaining loop iterations, and the question asks executions rather than displayed buffered output. **Derived answer:** B;C;D

## Solution

The OS allocates a new process’s page-table structures, so A is not an MMU duty. The MMU uses the mappings to translate addresses, detects absent/invalid mappings and raises page-fault exceptions, and checks permissions such as write protection. Thus B, C, D. A TLB miss alone is not the same as a page being absent from the page table.

# GATE 2024 CS2: Q25

**Question:** [Official archived paper page 18](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=18); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;B

**Derived answer:** A;B

## Solution

A genuinely blocking disk read puts P into a waiting state while I/O completes. A fault on a page currently in swap also requires storage I/O, so P is blocked pending page-in. An interrupt for another process need not deschedule P, and a timer interrupt may return to P if no switch is needed. Thus A, B. A mere user-to-kernel mode switch is not necessarily a switch to a different process; blocking in A is taken as actual blocking, as stipulated.

# GATE 2024 CS2: Q46

**Question:** [Official archived paper page 32](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=32); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

## Solution

The first successful wait(s1) excludes the other thread. If T1 acquires it first, T1 increments and prints 1, then blocks on initially zero s2 while still holding s1; T2 cannot reach its signal(s2), so this deadlocks, giving C. If T2 acquires first, it prints 1 and signals s2 and s1. T1 can then acquire s1, print2, consume s2, and finish, giving B. Thus B, C.

# GATE 2024 CS2: Q64

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 1028 to 1028

**Derived answer:** 1028

## Solution

A4KB table page holds4096/4=1024 entries. The32-bit address divides into 10 outer-index bits, 10 inner-index bits and 12 offset bits, allowing1024 inner table pages. Minimum table storage for2000 mapped pages packs them into ceil(2000/1024)=2 inner pages plus the allocated outer page: X=3. Maximum spreads mappings across all1024 distinct outer entries, possible with 2000 pages, giving Y=1024+1=1025. Thus X+Y=1028. Data pages themselves are not counted.
