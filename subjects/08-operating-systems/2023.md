

# GATE 2023 CS: Q22

**Question:** [Official archived paper page 20](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=20); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** B, C, D

**Derived answer:** B;C;D

## Solution

Threads in one process share the same virtual address space, so the page-table base normally need not change. Their stacks, instruction positions, and working register values differ, requiring preservation of stack pointer, program counter, and general-purpose registers. Thus B, C, D in the usual same-process thread model.

# GATE 2023 CS: Q23

**Question:** [Official archived paper page 21](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=21); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** C, D

**Derived answer:** C;D

## Solution

A page fault is an exception handled in kernel mode, and a system call deliberately enters kernel mode. An ordinary function call need not do so. malloc may satisfy a request from already acquired user-space allocator memory and therefore does not always invoke the kernel. Hence C, D.

# GATE 2023 CS: Q27

**Question:** [Official archived paper page 25](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=25); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A, C, D or C, D

**Derived answer:** C;D under finite-burst FIFO; A;C;D also officially accepted

## Solution

Priority scheduling can indefinitely postpone a low-priority process when higher-priority work keeps arriving. SJF can similarly starve a long job under a continuing supply of shorter jobs. Round robin provides recurring turns under its usual finite-quantum assumptions. Ordinary FIFO with finite earlier jobs does not starve a waiting job, giving C, D. If an earlier nonpreemptive FIFO job never relinquishes the CPU, a later job can wait forever; the official key additionally accepts A, C, D. Preserve both accepted sets rather than silently selecting one.

# GATE 2023 CS: Q38

**Question:** [Official archived paper page 39](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=39); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

With binary semaphore1 the updates are mutually exclusive: V1=10+5−3=12. With counting semaphore2, two updates may overlap. For a witness to V2=7, let one decrement enter and read10, then pause before its write. Through the second permit run all five increments to completion. Resume the held decrement to overwrite X with 9, then run the other two decrements serially, giving8 then7. No value below7 can arise because a value’s chain of read/write dependencies starts at 10 and contains at most the three decrement operations; increments only increase it. Thus12, 7, option C, under the intended non-atomic read-modify-write interleaving model.

# GATE 2023 CS: Q57

**Question:** [Official archived paper page 60](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=60); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4096 to 4096

**Derived answer:** 4096

## Solution

Under the usual page-aligned, initially nonresident array model, one page holds four complete rows because 512/128=4. The inner loop scans down a column and touches 32 pages in order, with four consecutive accesses per page. Only the first access of each four-row group faults. A cyclic traversal of 32 distinct pages with only 30 LRU frames has a miss on each page at every column: the reuse distance is 31 other pages. Hence 128 columns times 32 faults per column gives 4096. The standard answer implicitly assumes the array starts at a page boundary and ignores unrelated memory references. A non-page-aligned placement or a different initial residency can change the count; these are not specified explicitly.

# GATE 2023 CS: Q58

**Question:** [Official archived paper page 61](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=61); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 5 to 5

**Derived answer:** 5

## Solution

A 4 KiB page has a 12-bit offset. Under the conventional one-page-per-page-table-node layout, each node holds 4096/8=512 entries and contributes 9 index bits. The virtual page number has 57-12=45 bits, requiring L=45/9=5 levels. The page-sized table-node convention is implicit in this standard multilevel-paging calculation.
