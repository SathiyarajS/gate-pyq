**Type / marks:** MSQ, 1 mark(s).

**Official answer:** B, C, D

**Derived answer:** B;C;D

**Paraphrased problem context:** During a switch between two threads of the same process, which state needs saving? A page-table base register; B stack pointer; C program counter; D general-purpose registers. Select all applicable options.

## Solution

Threads in one process share the same virtual address space, so the page-table base normally need not change. Their stacks, instruction positions, and working register values differ, requiring preservation of stack pointer, program counter, and general-purpose registers. Thus B, C, D in the usual same-process thread model.

Teaching detail. A thread must later resume at its own instruction and restore the register values on which that computation depends. It also needs its own stack pointer because function frames and local storage belong to that thread's call chain. Threads in one process ordinarily share the page tables, so changing only the thread does not require switching the address-space root. Real implementations may save additional architecture-specific state, but that does not alter which of the four listed items are logically thread-specific in the stated model.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** C, D

**Derived answer:** C;D

**Paraphrased problem context:** Which events necessarily enter kernel mode from user mode? A ordinary function call; B malloc call; C page fault; D system call. Select all.

## Solution

A page fault is an exception handled in kernel mode, and a system call deliberately enters kernel mode. An ordinary function call need not do so. malloc may satisfy a request from already acquired user-space allocator memory and therefore does not always invoke the kernel. Hence C, D.

Teaching detail. The word “guarantee” excludes events that merely sometimes need kernel assistance. A user-space function can manipulate registers and its stack entirely in user mode. A malloc implementation often serves a request from a previously acquired heap arena; only some calls need to request more memory from the operating system. A page fault is a processor exception and transfers control to the kernel fault handler. A system call is the designated controlled entry mechanism for requesting kernel services.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A, C, D or C, D

**Derived answer:** C;D under finite-burst FIFO; A;C;D also officially accepted

**Paraphrased problem context:** Which scheduling policies can cause starvation? A FIFO; B round robin; C priority scheduling; D shortest job first. Preserve all answer sets accepted in the official key.

## Solution

Priority scheduling can indefinitely postpone a low-priority process when higher-priority work keeps arriving. SJF can similarly starve a long job under a continuing supply of shorter jobs. Round robin provides recurring turns under its usual finite-quantum assumptions. Ordinary FIFO with finite earlier jobs does not starve a waiting job, giving C, D. If an earlier nonpreemptive FIFO job never relinquishes the CPU, a later job can wait forever; the official key additionally accepts A, C, D. Preserve both accepted sets rather than silently selecting one.

Teaching detail. Starvation means indefinite postponement despite continuing operation, rather than a long but finite waiting time. Under conventional finite service times, FIFO eventually reaches each queued job, whereas higher priorities or shorter new jobs can repeatedly overtake an eligible job under the other policies. Round robin with finite quanta and the ordinary finite active-set assumptions revisits each ready process. The official acceptance of a second set including FIFO must not be erased by applying only the conventional model. The nonterminating FIFO-job scenario explains one possible model distinction, not an official stated rationale.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Shared X starts at 10. Five threads each do wait(s); X=X+1; signal(s), and three do wait(s); X=X−1; signal(s). The updates are non-atomic read/modify/write operations. Find minimum final values V1,V2 for a binary semaphore initially 1 and a counting semaphore initially 2. A 15,7; B 7,7; C 12,7; D 12,8.

## Solution

With binary semaphore1 the updates are mutually exclusive: V1=10+5−3=12. With counting semaphore2, two updates may overlap. For a witness to V2=7, let one decrement enter and read 10, then pause before its write. Through the second permit run all five increments to completion. Resume the held decrement to overwrite X with 9, then run the other two decrements serially, giving 8 then 7. No value below 7 can arise because a value’s chain of read/write dependencies starts at 10 and contains at most the three decrement operations; increments only increase it. Thus12, 7, option C, under the intended non-atomic read-modify-write interleaving model.

Teaching detail. A semaphore with capacity two limits concurrency but does not make each arithmetic assignment atomic. Two threads can read the same old value and later overwrite each other's results. The witness yielding 7 uses only two simultaneous entrants at any moment: one delayed decrement occupies one permit while all other selected operations use the second. The lower-bound argument follows the ancestry of the final written value, not the total number of writes. Each decrement in that ancestry contributes −1 once at most, and there are only three decrements available.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4096 to 4096

**Derived answer:** 4096

**Paraphrased problem context:** Row-major C array int D[128][128] is accessed by for i=0..127, for j=0..127, D[j][i]*=10. A page holds 512 array elements and 30 frames are available under LRU demand paging. Count faults in the intended page-aligned, initially nonresident array model; disclose these implicit assumptions.

## Solution

Under the usual page-aligned, initially nonresident array model, one page holds four complete rows because 512/128=4. The inner loop scans down a column and touches 32 pages in order, with four consecutive accesses per page. Only the first access of each four-row group faults. A cyclic traversal of 32 distinct pages with only 30 LRU frames has a miss on each page at every column: the reuse distance is 31 other pages. Hence 128 columns times 32 faults per column gives 4096. The standard answer implicitly assumes the array starts at a page boundary and ignores unrelated memory references. A non-page-aligned placement or a different initial residency can change the count; these are not specified explicitly.

Teaching detail. For aligned storage, element D[j][i] has page number floor((128j+i)/512)=floor(j/4) for each fixed i∈[0,127]. The page stream per column is therefore 0 repeated four times, 1 repeated four times, through 31 repeated four times. Only the first access to each repeated group faults. Between two uses of any page in successive columns are 31 distinct other pages, exceeding the 30-frame capacity, so no page survives until its next reuse. Multiplying 32 by 128 gives the count; multiplying 128² would ignore within-page hits.

**Official answer:** 5 to 5

**Derived answer:** 5

**Paraphrased problem context:** A 57-bit virtual address uses an L-level tree of page tables. Pages are 4 KiB; each page-table entry is 8 bytes at every level. Find L under the conventional one-page-per-table-node layout.

## Solution

A 4 KiB page has a 12-bit offset. Under the conventional one-page-per-page-table-node layout, each node holds 4096/8=512 entries and contributes 9 index bits. The virtual page number has 57-12=45 bits, requiring L=45/9=5 levels. The page-sized table-node convention is implicit in this standard multilevel-paging calculation.

Teaching detail. The address must be partitioned into a page offset and a sequence of table indexes. Offset bits select one byte within 4096 bytes, so there are 12. Each page-sized table contains 512 entries, whose selection requires 9 bits. Five indexes account for 45 virtual-page bits and, together with the 12-bit offset, exactly cover 57 bits. In cases where this division is not exact, the top-level index can be shorter; here no partial level is needed. The result depends on page-sized table nodes, not merely on entry width alone.
