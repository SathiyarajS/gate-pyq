**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 4. Consult original wording and choices.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Match CPU scheduling algorithms P: Gang, Q: Rate Monotonic, R: Fair Share with applications 1: Guaranteed Scheduling, 2: Real-time Scheduling, 3: Thread Scheduling.
Options:
(A) P-3,Q-2,R-1
(B) P-1,Q-2,R-3
(C) P-2,Q-3,R-1
(D) P-1,Q-3,R-2

## Solution

1. Approach. Gang scheduling groups collaborating threads; rate monotonic assigns priorities from task periods; fair share divides capacity between users or groups rather than only individual runnable processes.

2. Derivation and interpretation. Gang scheduling coordinates related threads, P→3. Rate-monotonic priorities schedule periodic real-time tasks, Q→2. Fair-share scheduling aims to guarantee users/groups an allocated CPU share, R→1. Thus A.

# GATE 2007: Q17 (printed CS Q17)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 4. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Which statement about user-level and kernel-level threads is false?
Options:
(A) Context switches take longer for kernel-level than user-level threads
(B) User-level threads need no hardware support
(C) Related kernel threads may run on different processors
(D) Blocking one kernel thread blocks all related threads

## Solution

1. Approach. The kernel knows about each kernel thread and can choose another runnable thread when one blocks. Contrast this with a many-to-one user-thread implementation whose sole kernel thread blocks.

2. Derivation and interpretation. Kernel threads are independently schedulable, including on different processors. Blocking one does not inherently block every sibling thread, making D false. User-level thread switching can avoid kernel entry and dedicated threading hardware under the conventional comparison; kernel scheduling manages each kernel thread separately.

# GATE 2007: Q55 (printed CS Q55)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 13. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** Shortest Remaining Time first schedules four processes: P1 arrives at 0 and requires 20 units; P2 at 15 requires 25; P3 at 30 requires 10; P4 at 45 requires 15. What is P2’s total waiting time?
Options:
(A) 5
(B) 15
(C) 40
(D) 55

## Solution

1. Approach. At each arrival compare remaining service, not original burst lengths. Draw the execution intervals and count only the intervals after P2 arrives during which it is ready but not running.

2. Derivation and interpretation. P1 runs from 0 to 20: at P2's arrival at 15, P1 has only 5 units left versus P2's 25. P2 runs 20–30, leaving 15; P3 then arrives with 10 and runs 30–40. P2 resumes at 40. When P4 arrives at 45, P2 has 10 left versus P4's 15, so P2 continues until 55. Its waiting intervals are 15–20 and 30–40, totaling 5+10=15 (B). Equivalently completion−arrival−execution=55−15−25=15.

# GATE 2007: Q56 (printed CS Q56)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** A virtual-memory system uses FIFO replacement with a fixed allocation of frames. P: increasing a process’s frame allocation sometimes increases its page-fault rate. Q: some programs do not exhibit locality of reference. Which statement is true?
Options:
(A) Both true and Q explains P
(B) Both true but Q does not explain P
(C) P false,Q true
(D) Both false

## Solution

1. Approach. Separate truth from causation. Belady’s anomaly is possible because FIFO does not retain a nested set of resident pages as frame count grows; locality is not the defining cause.

2. Derivation and interpretation. P is true: FIFO can exhibit Belady's anomaly. For example, reference string 1,2,3,4,1,2,5,1,2,3,4,5 incurs 9 faults with three initially empty frames but 10 with four. Q is also true: programs can make accesses without useful locality, for example broadly scattered independent random accesses. Q does not explain the anomaly; the issue is FIFO's failure of the stack-inclusion property, not simply the presence or absence of locality. Stack algorithms such as LRU do not exhibit this anomaly even on reference strings without locality. Thus B.

# GATE 2007: Q57 (printed CS Q57)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Three processes share resource types X,Y,Z, with 5 units of each. Allocated and additionally requested vectors (X,Y,Z) are: P0 alloc=(1,2,1), request=(1,0,3); P1 alloc=(2,0,1), request=(0,1,2); P2 alloc=(2,2,1), request=(1,2,0). Each request is needed to finish, after which resources are released. Which process finishes last?
Options:
(A) P0
(B) P1
(C) P2
(D) None; the system is deadlocked

## Solution

1. Approach. Subtract all allocations from the total vector to obtain current availability. Repeatedly choose a process whose remaining request fits componentwise, then add its old allocation back to availability.

2. Derivation and interpretation. Allocated totals are (1,2,1)+(2,0,1)+(2,2,1)=(5,4,3), so the initial available vector is (0,1,2). Only P1's remaining request (0,1,2) can be met. After P1 completes and returns all its resources, availability becomes (0,1,2)+(2,0,1)=(2,1,3). P0's request (1,0,3) can now be met, while P2 still needs two Y units but only one is available. P0 finishes next, leaving availability (2,1,3)+(1,2,1)=(3,3,4), which permits P2's request (1,2,0). The forced safe order is P1,P0,P2, so P2 finishes last (C), assuming each request is the additional resource vector needed for completion as stated.

# GATE 2007: Q58 (printed CS Q58)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Shared flags wants1,wants2 are initially false. P1 executes:
while(true) { wants1=true; while(wants2==true); /* critical section */ wants1=false; }
P2 executes:
while(true) { wants2=true; while(wants1==true); /* critical section */ wants2=false; }
The source places each remainder-section comment after its loop. Under atomic sequentially consistent flag operations, which statement is intended?
Options:
(A) Mutual exclusion is not ensured
(B) Bounded waiting is not ensured
(C) Critical sections must alternate strictly
(D) Deadlock is not prevented, but mutual exclusion is ensured

## Solution

1. Approach. Test safety and progress separately. Two critical sections cannot overlap because each entrant advertises its intent. But if both advertise before either tests, neither can reach the instruction clearing its flag.

2. Derivation and interpretation. Under the standard sequentially consistent, atomic-read/write pseudocode model, each process sets its own wants flag before testing the other's flag and keeps it true throughout its critical section. Thus both cannot pass their tests and overlap in the critical section: whichever passes first prevents the other entering until it clears its flag. However, if both set their flags before either tests the other, each spins forever, giving deadlock. Thus D describes the decisive combination: mutual exclusion holds but deadlock prevention fails. Strict alternation is not required; one process can repeatedly enter while the other does not request entry. Option B needs care: under a broad interpretation that bounded waiting guarantees eventual entry, deadlock also violates it. In the usual bounded-overtaking formulation, distinguish this progress failure from another process overtaking a waiter indefinitely; the latter cannot occur here. D is the intended most specific answer, while the phrasing of B can be read more broadly.

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 20. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** A process has three initially empty page frames and reference string 1,2,1,3,7,4,5,6,3,1. How many page faults occur with optimal replacement?
Options:
(A) 7
(B) 8
(C) 9
(D) 10

## Solution

1. Approach. At a miss with full frames, evict the page whose next reference lies farthest in the future, treating never-used-again pages as farthest. Keeping pages 1 and 3 is valuable because both are referenced at the end.

2. Derivation and interpretation. For references 1,2,1,3,7,4,5,6,3,1 with three initially empty frames, first load 1,2,3 (the second reference to 1 hits). When 7 arrives, discard 2 because it is never needed again. Retain 1 and 3 while replacing the third frame successively by 7,4,5,6; each of these pages has no future use. The final 3 and 1 then hit. Faults are on 1,2,3,7,4,5,6, totaling 7, option A. Seven distinct pages also give a matching lower bound.

**Independently derived answer:** C

**Paraphrased problem context:** A process has three initially empty page frames and reference string 1,2,1,3,7,4,5,6,3,1. How many more faults does LRU incur than optimal replacement?
Options:
(A) 0
(B) 1
(C) 2
(D) 3

## Solution

1. Approach. LRU uses past recency rather than future references. Maintain a least-recent-to-most-recent list and move a page to the end even on a hit; then compare the full LRU count with the optimal count.

2. Derivation and interpretation. LRU faults on references 1,2,3,7,4,5,6,3,1; only the early repeated 1 hits. After loading 3, the least-recent order is 2,1,3; successive new pages evict 2, then 1, then 3, then 7. Therefore final references 3 and 1 also fault. LRU has 9 faults versus the optimal 7, an excess of 2, option C.
