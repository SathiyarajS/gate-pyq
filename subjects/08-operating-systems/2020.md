**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

Best fit chooses the smallest adequate hole. Subtracting the same process size from that hole and from the first-fit hole preserves the ≤ relation, so the best-fit remainder is never larger. Strict inequalities in the other options can fail when policies select the same hole. Thus C.

## Solution

Preemption gives running→ready; dispatch gives ready→running; completion of the awaited event gives blocked→ready. In the standard state-transition model a blocked process becomes ready before dispatch, not directly running. Thus I, II, IV, C.

# GATE 2020 CS: Q44 (printed CS Q34)

**Question:** [Official archived paper page 11](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

Semaphore a serializes count increments after each process finishes P. Semaphore b starts0 and is signaled for the first time only when count=n, so no process can pass wait(b) before all have finished P. Each passing process signals b to release the next waiter. The signal occurs before Q, so Q is not mutually excluded or limited to two entrants. Thus this is a barrier, A.

**Official answer:** 5.25 to 5.25

**Derived answer:** 5.25

## Solution

SJF executes P3, P4, P2, P1, completing them at 2, 6, 13, 21ms. Since arrivals are all zero, average turnaround is 42/4=10.5ms. RR with quantum4 executes P1[0, 4], P2[4, 8], P3[8, 10], P4[10, 14], P1[14, 18], P2[18, 21]. Completion times are18, 21, 10, 14ms, averaging63/4=15.75ms. The absolute difference is 15.75−10.5=5.25ms, with zero context-switch overhead as conventionally assumed.

# GATE 2020 CS: Q63 (printed CS Q53)

**Question:** [Official archived paper page 16](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=16); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 154.5 to 155.5

**Derived answer:** 155.0 under conditional page-fault convention

## Solution

A TLB hit costs20+100=120 ns; a nonfaulting miss costs20+100+100=220 ns. Average disk work per page fault is 5000+0.20*5000=6000 ns. Interpreting the stated10% page-fault rate as conditional on a TLB miss gives 0.95*120+0.05*(220+0.10*6000)=155.0 ns, within the official154.5–155.5 range. The question does not explicitly say conditional: an unconditional10% fault probability is inconsistent with a 95% valid resident TLB hit ratio in this standard model, since faults can occur only among the 5% misses. Official scoring therefore depends on the conditional interpretation and neglects extra fault-handler/restart overhead.
