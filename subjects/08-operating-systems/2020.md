

# GATE 2020 CS: Q21 (printed CS Q11)

**Question:** [Official archived paper page 6](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=6); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Allocate one process into a memory hole, with no exact fit. Which comparison of newly remaining holes is always true? A first-fit remainder > next-fit remainder; B worst-fit remainder > first-fit remainder; C best-fit remainder ≤ first-fit remainder; D next-fit remainder ≤ best-fit remainder.

## Solution

Worked explanation

Let p be the process size and let H be the set of adequate hole sizes. Best fit chooses hB=min H. If first fit chooses hF∈H, then hB≤hF, and subtracting p gives hB−p≤hF−p. This is exactly C and allows equality. For counterexamples to strict claims A and B, take a single adequate hole: all policies choose it, so no remainder is strictly larger. D fails with adequate holes of sizes 10 and 20 for a process of size 6 when next fit chooses 20: its remainder 14 exceeds best fit’s 4. The cursor position matters for next fit, not for the minimum defining best fit.

Derivation and answer

Best fit chooses the smallest adequate hole. Subtracting the same process size from that hole and from the first-fit hole preserves the ≤ relation, so the best-fit remainder is never larger. Strict inequalities in the other options can fail when policies select the same hole. Thus C.

# GATE 2020 CS: Q22 (printed CS Q12)

**Question:** [Official archived paper page 6](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=6); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** For preemptive scheduling, which direct state transitions are possible? I running→ready; II ready→running; III blocked→running; IV blocked→ready. Options: A I,II,III; B II,III; C I,II,IV; D all four.

## Solution

Worked explanation

Ready means eligible to run but not currently assigned a CPU; blocked means waiting for an event and therefore not eligible. A timer interrupt can preempt a running process into ready (I). Dispatch selects a ready process to run (II). I/O completion changes blocked to ready (IV); the scheduler may then dispatch it, but that is a second transition, not the direct blocked→running edge in III. The standard graph also has running→blocked when a process requests I/O. Distinguishing a possible two-edge path from one direct transition is the key to choosing C.

Derivation and answer

Preemption gives running→ready; dispatch gives ready→running; completion of the awaited event gives blocked→ready. In the standard state-transition model a blocked process becomes ready before dispatch, not directly running. Thus I, II, IV, C.

# GATE 2020 CS: Q44 (printed CS Q34)

**Question:** [Official archived paper page 11](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** Each of n processes runs this once, with shared count=0, semaphores a=1,b=0, and P not using count:
P;
wait(a); count=count+1;
if(count==n) signal(b);
signal(a); wait(b); signal(b);
Q;
What is guaranteed? A no Q before all P finish; B at most two in Q; C P mutually exclusive; D at most n−1 in P.

## Solution

Worked explanation

Before any process can signal b, some process must observe count=n while holding a. Since increments are protected and occur after P, count is exactly the number of completed P sections that have passed the increment. Thus the first b signal proves every P has completed. The subsequent wait(b);signal(b) passes a token along the waiting processes; it gates entry but does not keep b held during Q. A process may enter Q and another may immediately enter too, so no mutual-exclusion or two-process bound follows. P is outside both waits, so every process can be in P simultaneously. This is a one-use barrier, not a reusable barrier because count is never reset.

Derivation and answer

Semaphore a serializes count increments after each process finishes P. Semaphore b starts0 and is signaled for the first time only when count=n, so no process can pass wait(b) before all have finished P. Each passing process signals b to release the next waiter. The signal occurs before Q, so Q is not mutually excluded or limited to two entrants. Thus this is a barrier, A.

# GATE 2020 CS: Q45 (printed CS Q35)

**Question:** [Official archived paper page 12](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=12); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** SSTF disk scheduling begins at cylinder 100 with requests P:155,Q:85,R:110,S:30,T:115. Which is false? A T before P; B Q after S but before T; C direction reverses between service of Q and P; D R before P.

## Solution

Worked explanation

Recompute the nearest remaining request after every move. From 100, distances to P,Q,R,S,T are 55,15,10,70,15, so R wins. From 110, T is 5 away; from 115, Q is 30 away versus P at 40 and S at 85, so Q wins. From 85, S is 55 away versus P at 70, so S wins, leaving P. The path is 100→110→115→85→30→155. T and R both precede P, and movement changes from decreasing to increasing at S between Q and P. B reverses the actual relation of Q to both S and T.

Derivation and answer

From100, nearest requests are R110 thenT115 thenQ85 thenS30 thenP155. The head distances for these choices are10, 5, 30, 55, 125. Thus Q is before S and after T, making B false. The other assertions hold, including reversal at S between servicing Q andP.

# GATE 2020 CS: Q60 (printed CS Q50)

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 5.25 to 5.25

**Derived answer:** 5.25

**Paraphrased problem context:** All processes arrive at time 0. Burst times: P1=8,P2=7,P3=2,P4=4 ms. Compare SJF with RR, quantum 4 ms and initial order P1,P2,P3,P4. Find the absolute difference in average turnaround times, to two decimal places.

## Solution

Worked explanation

Turnaround time is completion minus arrival, not just waiting time. With all arrivals zero, completion times can be averaged directly. SJF Gantt timeline: 0—P3—2—P4—6—P2—13—P1—21. RR timeline: 0—P1—4—P2—8—P3—10—P4—14—P1—18—P2—21. After their first slices P1 has 4 ms remaining and P2 has 3; P3 and P4 finish in their first slices and leave the queue. In process order P1,P2,P3,P4, completions are (21,13,2,6) for SJF and (18,21,10,14) for RR. Sums 42 and 63 divided by 4 give the required difference 5.25 ms.

Derivation and answer

SJF executes P3, P4, P2, P1, completing them at 2, 6, 13, 21ms. Since arrivals are all zero, average turnaround is 42/4=10.5ms. RR with quantum4 executes P1[0, 4], P2[4, 8], P3[8, 10], P4[10, 14], P1[14, 18], P2[18, 21]. Completion times are18, 21, 10, 14ms, averaging63/4=15.75ms. The absolute difference is 15.75−10.5=5.25ms, with zero context-switch overhead as conventionally assumed.

# GATE 2020 CS: Q63 (printed CS Q53)

**Question:** [Official archived paper page 16](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=16); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 154.5 to 155.5

**Derived answer:** 155.0 under conditional page-fault convention

**Paraphrased problem context:** A one-level page table is in main memory. Main-memory access=100 ns, TLB lookup=20 ns, each disk page transfer=5000 ns. TLB hit ratio=95%, stated page-fault rate=10%, dirty victim on 20% of page faults, negligible TLB-update time. Find average access time to one decimal. The source does not explicitly state what conditions the fault rate.

## Solution

Worked explanation

Under the intended conditional model, split all references into disjoint cases: TLB hit probability .95 and time 120; nonfaulting TLB miss probability .05×.9=.045 and time 220; clean-victim fault probability .05×.1×.8=.004 and time 5220; dirty-victim fault probability .05×.1×.2=.001 and time 10220. These probabilities sum to 1. Weighted contributions are 114,9.9,20.88,10.22 ns, totaling 155.0 ns. The 220 ns baseline counts lookup, page-table read and final data access; the faults add one or two disk transfers. This arithmetic follows the official convention, not a uniquely specified real-system fault handler. An unconditional 10% page-fault rate cannot coexist with 95% valid resident TLB hits in this simple model.

Derivation and answer

A TLB hit costs20+100=120 ns; a nonfaulting miss costs20+100+100=220 ns. Average disk work per page fault is 5000+0.20*5000=6000 ns. Interpreting the stated10% page-fault rate as conditional on a TLB miss gives 0.95*120+0.05*(220+0.10*6000)=155.0 ns, within the official154.5–155.5 range. The question does not explicitly say conditional: an unconditional10% fault probability is inconsistent with a 95% valid resident TLB hit ratio in this standard model, since faults can occur only among the 5% misses. Official scoring therefore depends on the conditional interpretation and neglects extra fault-handler/restart overhead.
