

# GATE 2022 CS: Q19

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Three infinite threads run on one CPU with binary semaphores. T1 repeats wait(S3); print C; signal(S2). T2 repeats wait(S1); print B; signal(S3). T3 repeats wait(S2); print A; signal(S1). Which initialization forces BCABC… despite arbitrary context switches? A (S1,S2,S3)=(1,1,1); B (1,1,0); C (1,0,0); D (0,1,1).

## Solution

T2 waits on S1 and prints B, then signals S3. T1 waits on S3 and prints C, then signals S2. T3 waits on S2 and prints A, then signals S1. Initialize only S1 to 1, with S2=S3=0, to force B→C→A repeatedly. That is C. This assumes ordinary successful semaphore operations and eventual scheduling of enabled threads.

Teaching detail:
Track the unique token: (1,0,0) enables only T2. Its wait consumes S1 and its signal creates the S3 token; then T1 creates S2; then T3 restores S1. Context switching can delay progress, but cannot permit a different letter while its semaphore is zero.

# GATE 2022 CS: Q26

**Question:** [Official archived paper page 20](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=20); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A,D

**Derived answer:** A,D

**Paraphrased problem context:** Select true deadlock statements: A circular wait is necessary; B with multiple instances per resource a wait-for cycle guarantees deadlock; C an unsafe allocation necessarily leads to deadlock; D if all resource-allocation edges are assignment edges, there is no deadlock.

## Solution

Circular wait is a necessary Coffman condition, so A is true. With multiple instances per resource, a cycle alone need not imply deadlock: an external holder can release an instance and let a waiting process proceed. An unsafe state means some future demands may deadlock, not that deadlock must occur, so C is false. If every resource-allocation edge is an assignment, there are no request edges and therefore no waiting cycle, making D true. Thus A, D under the usual resource-allocation interpretation of the question’s wait-for terminology.

Teaching detail:
An unsafe state lacks a guaranteed completion sequence for all declared maximum demands; it need not be currently deadlocked. Processes may request less than their maxima or release resources. Without request edges no process is represented as waiting, so assignment-only graphs cannot contain the alternating request/assignment cycle needed for deadlock.

# GATE 2022 CS: Q38

**Question:** [Official archived paper page 25](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=25); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C in the intended textbook model; D is also overbroad literally

**Paraphrased problem context:** Identify the intended FALSE virtual-memory statement: A a TLB searches all valid entries associatively in parallel by virtual page number; B a TLB hit followed by a cache miss guarantees the word is in main memory; C a given inverted page table has identical access time for all virtual addresses; D distinct virtual addresses hashing to the same value necessarily have different memory access times. Retain literal-model qualifications.

## Solution

Inverted page-table lookup can scan or follow collision chains of different lengths, so access time is not always identical: C is false. The intended model treats A as a fully associative TLB search and B as a valid, coherent TLB translation implying resident data memory. D is intended to distinguish positions in a serial hash collision chain, but its literal universal claim is not valid: two distinct virtual byte addresses in the same virtual page share the same hashed page entry and may have identical access time. Other collision-resolution and caching implementations also defeat the asserted necessity. Preserve official C, while disclosing that the question needs distinct-page, serial-chain and textbook TLB assumptions to make it uniquely false.

Teaching detail:
An inverted table has one entry per physical frame and needs to locate a process/virtual-page pair; search or hash-chain length can vary by input. In a serial collision chain, different pages at different positions may take different time, explaining the intended D. But distinct byte addresses with the same page number use the same entry, providing a concrete counterexample to its unqualified wording.

# GATE 2022 CS: Q42

**Question:** [Official archived paper page 27](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=27); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** P,Q,R,S arrive at time zero in that order. Round-robin quantum is 4. Observed switches include exactly one S→Q, one R→Q, two Q→R and no S→P, counting switches after termination too. Which burst tuple (P,Q,R,S) is impossible? A (4,10,6,2); B (2,9,5,1); C (4,12,5,4); D (3,7,7,3).

## Solution

With quantum 4, A, B, C each give execution segments P, Q, R, S, Q, R, Q: P and S finish in their first turn, R in its second, and Q in its third. This yields two Q→R switches, one R→Q and one S→Q. For D, burst times (3, 7, 7, 3) instead give P, Q, R, S, Q, R: Q finishes on its second turn, leaving no final R→Q switch. Thus D cannot produce the stated trace.

Teaching detail:
For option D the slices have lengths 3,4,4,3,3,3 respectively. The running order P,Q,R,S,Q,R has Q→R twice and S→Q once, but no R→Q. For A the slice lengths are 4,4,4,2,4,2,2, so P,Q,R,S,Q,R,Q satisfies all stated counts. B,C have that same order because Q needs three turns and R two.

# GATE 2022 CS: Q63

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 153 to 153

**Derived answer:** 153

**Paraphrased problem context:** A 100-block file exists in contiguous-allocation system A and linked-allocation system B. Insert one memory-resident block between original blocks 50 and 51. There is enough free space after the contiguous file; file-control blocks are in memory. If the respective disk-access counts are nA,nB, find nA+nB.

## Solution

For contiguous allocation, shift original blocks 51 through 100 one position to the right, working backward. Each of the 50 blocks is read and written, costing 100 disk accesses; writing the new memory-resident block costs one more, so nA=101. For linked allocation, follow the chain by reading blocks 1 through 50, costing 50 reads. Retain block 50 and its old next pointer in memory, write the new block pointing to original block 51, and rewrite block 50 to point to the new block: two writes, so nB=52. The sum is 153. This is the usual uncached data-block I/O model, with file-control blocks already in memory and no extra metadata-flush charges.

Teaching detail:
The backward shift in A is essential: forward shifting would overwrite block 52 before reading its original contents. In B, the data of blocks 51…100 stay in place; only the predecessor’s link and new block are written. Traversing 50 blocks rather than reading all 100 is sufficient to locate the insertion point.

# GATE 2022 CS: Q64

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 0.6 to 0.6

**Derived answer:** 0.6

**Paraphrased problem context:** Four initially empty demand-paging frames use LRU. References: 7,2,7,3,2,5,3,4,6,7,7,1,5,6,1. Find page faults/accesses rounded to one decimal.

## Solution

Simulating four LRU frames gives faults at reference positions 1, 2, 4, 6, 8, 9, 10, 12, 13, for the values 7, 2, 3, 5, 4, 6, 7, 1, 5. The other six references hit. In particular, the second consecutive 7 hits, and the last 6 and 1 both remain resident. Hence the fault rate is 9/15=0.6.

Teaching detail:
Maintain recency oldest→newest after each access: [7]; [7,2]; [2,7]; [2,7,3]; [7,3,2]; [7,3,2,5]; [7,2,5,3]; [2,5,3,4]; [5,3,4,6]; [3,4,6,7]; [3,4,6,7]; [4,6,7,1]; [6,7,1,5]; [7,1,5,6]; [7,5,6,1]. On a full-frame miss remove the oldest before appending; on a hit move the referenced page to newest.
