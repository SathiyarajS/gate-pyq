

# GATE 2022 CS: Q19

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

T2 waits on S1 and prints B, then signals S3. T1 waits on S3 and prints C, then signals S2. T3 waits on S2 and prints A, then signals S1. Initialize only S1 to 1, with S2=S3=0, to force B→C→A repeatedly. That is C. This assumes ordinary successful semaphore operations and eventual scheduling of enabled threads.

# GATE 2022 CS: Q26

**Question:** [Official archived paper page 20](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=20); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A,D

**Derived answer:** A,D

## Solution

Circular wait is a necessary Coffman condition, so A is true. With multiple instances per resource, a cycle alone need not imply deadlock: an external holder can release an instance and let a waiting process proceed. An unsafe state means some future demands may deadlock, not that deadlock must occur, so C is false. If every resource-allocation edge is an assignment, there are no request edges and therefore no waiting cycle, making D true. Thus A, D under the usual resource-allocation interpretation of the question’s wait-for terminology.

# GATE 2022 CS: Q38

**Question:** [Official archived paper page 25](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=25); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C in the intended textbook model; D is also overbroad literally

## Solution

Inverted page-table lookup can scan or follow collision chains of different lengths, so access time is not always identical: C is false. The intended model treats A as a fully associative TLB search and B as a valid, coherent TLB translation implying resident data memory. D is intended to distinguish positions in a serial hash collision chain, but its literal universal claim is not valid: two distinct virtual byte addresses in the same virtual page share the same hashed page entry and may have identical access time. Other collision-resolution and caching implementations also defeat the asserted necessity. Preserve official C, while disclosing that the question needs distinct-page, serial-chain and textbook TLB assumptions to make it uniquely false.

# GATE 2022 CS: Q42

**Question:** [Official archived paper page 27](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=27); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

## Solution

With quantum 4, A, B, C each give execution segments P, Q, R, S, Q, R, Q: P and S finish in their first turn, R in its second, and Q in its third. This yields two Q→R switches, one R→Q and one S→Q. For D, burst times (3, 7, 7, 3) instead give P, Q, R, S, Q, R: Q finishes on its second turn, leaving no final R→Q switch. Thus D cannot produce the stated trace.

# GATE 2022 CS: Q63

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 153 to 153

**Derived answer:** 153

## Solution

For contiguous allocation, shift original blocks 51 through 100 one position to the right, working backward. Each of the 50 blocks is read and written, costing 100 disk accesses; writing the new memory-resident block costs one more, so nA=101. For linked allocation, follow the chain by reading blocks 1 through 50, costing 50 reads. Retain block 50 and its old next pointer in memory, write the new block pointing to original block 51, and rewrite block 50 to point to the new block: two writes, so nB=52. The sum is 153. This is the usual uncached data-block I/O model, with file-control blocks already in memory and no extra metadata-flush charges.

# GATE 2022 CS: Q64

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 0.6 to 0.6

**Derived answer:** 0.6

## Solution

Simulating four LRU frames gives faults at reference positions 1, 2, 4, 6, 8, 9, 10, 12, 13, for the values 7, 2, 3, 5, 4, 6, 7, 1, 5. The other six references hit. In particular, the second consecutive 7 hits, and the last 6 and 1 both remain resident. Hence the fault rate is 9/15=0.6.
