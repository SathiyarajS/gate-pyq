## Solution

Map device registers into protected address ranges/pages and have the processor’s memory-protection hardware trap unauthorized user-mode loads or stores. **Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

If no process can finish, every process can hold at most s_i−1 units while still needing another unit. Thus at most sum(s_i−1)=sum(s_i)−n units can be held in an all-unfinished configuration. If sum(s_i)<m+n, this total is less than m, so at least one resource is free; allocating available units eventually lets a process reach its maximum and finish. Release its resources and repeat. Equivalently m>sum(s_i−1) guarantees progress for the single resource type. This is option C.

# GATE 2005: Q72 (printed CS Q72)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C, under intended address-printing semantics

## Solution

Let a initially equal a0. The child executes the zero-return branch and obtains x=a0+5; the parent obtains u=a0−5. Therefore u+10=x. fork preserves the virtual address of a, so its address has the same numeric value in each process even though the memory is logically separate: v=y. Hence C under the intended OS model. Strictly, the reproduced printf uses %d for &a; that variadic type mismatch is undefined behavior in ISO C, so literal portable-C output is not guaranteed. Using %p with (void *)&a expresses the intended comparison.
