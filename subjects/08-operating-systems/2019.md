**Type / marks:** NAT, 1 mark(s).

**Official answer:** 31 to 31

**Derived answer:** 31

**Paraphrased problem context:** A Unix/Linux program runs for(i=0; i<10; i++), calling fork() whenever i%2==0, then returns. Assuming all forks succeed, find the total number of newly created child processes, excluding the original process.

## Solution

Method: count the branching rounds; every process alive at a fork round executes that fork and then continues the same loop.

1. The loop values are 0 through 9. The even values 0,2,4,6,8 cause five fork rounds; odd iterations create no processes.
2. A successful fork creates one new child from each currently executing process. Both parent and child continue from immediately after the fork with their own copy of i, so both participate in later rounds.
3. Starting from one process, the total after successive rounds is 2,4,8,16,32. The numbers of new children produced at those rounds are respectively 1,2,4,8,16.
4. Adding the created children gives 1+2+4+8+16 = 31. Equivalently, subtract the original from the final total: 2^5−1 = 31.

Result: 31 child processes in total, including descendants created by children. Counting only the five calls made by the original parent would omit later generations. The result assumes no fork failure or external process termination.

**Question:** [Official archived paper page 8](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=8); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 80 to 80

**Derived answer:** 80

**Paraphrased problem context:** Shared D starts at 100. Concurrent processes perform P1: D=D+20; P2: D=D−50; P3: D=D+10 on a time-shared uniprocessor. If X and Y are the minimum and maximum possible final values, find Y−X. Use the intended model in which each assignment's read and write can be interleaved with other processes.

## Solution

Method: split each assignment into a read, local arithmetic, and write; an interrupted process may later overwrite a newer shared value using its earlier read.

1. To attain the minimum, let P2 read 100 and compute 50 but delay its write. Let P1 and P3 complete their increments, then let P2 write its stored 50 last. The final result is 50, because the earlier increments are overwritten.
2. To attain the maximum, let P1 and P2 both read 100. P2 writes 50 first; P1 then writes its stored 120, overwriting the decrement. P3 reads 120 and writes 130. The final result is 130.
3. These are also bounds. Trace the final write back through the value read by its writer, and recursively through preceding writes. This dependency chain starts at 100 and can include each process's change at most once. Its smallest possible sum includes −50 but no positive changes, giving 50; its largest includes +20 and +10 but not −50, giving 130.
4. Both bounds are attainable by steps 1 and 2, so X=50 and Y=130. Their difference is 130−50=80.

Result: 80. If whole assignments were atomic, every order would instead end at 80; the intended model permits preemption within an assignment. Under that different atomic model X=Y=80 and Y−X would be zero. A uniprocessor prevents simultaneous instruction execution but does not by itself make a multi-instruction update atomic.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** A word-addressable machine has 64-bit virtual addresses, 48-bit physical addresses, 8 kB pages, 4-byte words, and 128 valid TLB entries. Find the maximum distinct virtual word addresses translatable without a TLB miss: A 16×2^10, B 256×2^10, C 4×2^20, D 8×2^20.

## Solution

1. One TLB entry caches the translation for an entire virtual page, not just one word. Every offset within a cached page can use that same entry.
2. Using the intended binary memory units, a page contains 8×1024=8192 bytes. Since an address identifies a four-byte word, the number of addressable words per page is 8192/4=2048=2^11.
3. To maximize coverage, let the 128=2^7 valid entries represent different virtual pages. The number of distinct covered word addresses is 2^7×2^11=2^18=262144.
4. Rewriting 262144 as 256×2^10 identifies option B. The cached byte span would be 1 MiB, but reporting that number of addresses would ignore word addressability.
5. The 64-bit and 48-bit widths bound the larger virtual and physical spaces; they do not change the number of offsets covered by these 128 page translations.

# GATE 2019 CS: Q49 (printed CS Q39)

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A under actual-remaining-demand interpretation

**Paraphrased problem context:** All instances of resource R are allocated. Process i holds Xi and may request at most Yi additional instances. Exactly p and q have Yp=Yq=0. Which condition guarantees no other process completes? A Xp+Xq<min other Yk; B Xp+Xq<max other Yk; C min(Xp,Xq)≥min other Yk; D min(Xp,Xq)≤max other Yk.

## Solution

1. First solve the intended resource-demand model, where Yi is the amount process i still needs in order to finish. Because no resource instances are currently free, only p and q have enough resources to finish immediately.
2. Once both finish and release what they hold, the total available pool is A=Xp+Xq. No other process has released anything yet.
3. If A<min{Yk:k≠p,q}, then A is smaller than every remaining demand. There is no possible next finishing process, so the system cannot enlarge its free pool by further completions. This yields option A under that model.
4. Comparing A with the maximum demand, as in B, blocks only at least one large-demand process; a smaller-demand process may finish and release resources. C and D similarly do not establish insufficiency for every remaining process.
5. The literal wording is weaker: each Yi is an upper bound on additional requests, not a necessary demand. A process with positive Yi could actually need zero more instances and finish. For example, with Xp=Xq=1 and another process's bound Yk=3, A holds, yet that process may finish without requesting anything.
6. Thus the keyed A needs the actual-remaining-demand interpretation. Under upper bounds alone, the claimed guarantee is not justified. Preserve this model caveat rather than presenting A as unconditional.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 2 to 2

**Derived answer:** 2

**Paraphrased problem context:** Four processes have (arrival, CPU burst) in ms: P1=(0,3), P2=(1,1), P3=(3,3), P4=(4,Z). Under preemptive shortest-remaining-time-first scheduling their average waiting time is 1 ms. Determine Z.

## Solution

1. SRTF always runs the available process with least unfinished CPU time. P1 runs from 0 to 1, leaving 2 ms. P2 arrives at 1 with burst 1, preempts P1, and finishes at 2.
2. P1 resumes at 2. When P3 arrives at 3, P1 has only 1 ms left versus P3's 3 ms, so P1 continues to completion at 4. P1 has waited 1 ms; P2 has waited 0; P3 has already waited 1.
3. At time 4, P4 arrives. If Z<3, P4 runs first for Z ms, then P3 runs for 3 ms. The total waiting time is W1+W2+W3+W4=1+0+(1+Z)+0=2+Z.
4. Average waiting 1 over four processes requires total waiting 4. Thus 2+Z=4, giving Z=2, which satisfies the branch assumption Z<3.
5. Check the other branch: if Z≥3, running P3 first adds a wait of 3 to P4, giving total 1+0+1+3=5. For Z=3 either tie order gives the same total, so this branch cannot give average 1.
6. With Z=2, completion times are P1=4, P2=2, P4=6, P3=9. Using waiting=completion−arrival−burst gives 1,0,0,3 respectively, totaling 4. Answer 2 ms.

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 3.7 to 3.8 OR 4.0 to 4.1

**Derived answer:** 4.0 under consistent binary units; alternate range retained

**Paraphrased problem context:** An inode has 12 direct pointers, one single-indirect pointer, and one double-indirect pointer. Blocks are 4 kB and each disk-block address is 32 bits. Find the maximum file-data size in GB, rounded to one decimal place; retain the official key's alternative unit ranges.

## Solution

1. A block pointer occupies 32/8=4 bytes. Under the usual binary convention, one block is B=4096 bytes, so an indirect block stores 4096/4=1024 addresses.
2. Direct pointers address 12 data blocks. The single-indirect pointer addresses one metadata block containing 1024 data-block pointers, so it contributes 1024 data blocks.
3. The double-indirect pointer reaches a first-level metadata block containing 1024 pointers to second-level indirect blocks. Each second-level block addresses another 1024 data blocks. Its contribution is 1024²=1,048,576 data blocks.
4. Total file-data capacity is (12+1024+1,048,576)×4096=4,299,210,752 bytes. Metadata blocks are not part of the file's data size and must not be added to this total.
5. In binary GiB, divide by 2^30 to obtain 4.003952... GiB, rounding to 4.0. This is the conventional intended calculation even though the question prints GB.
6. Units matter. Taking kB as 1000 gives (12+1000+1000²)×4000=4,004,048,000 bytes: 4.0 decimal GB, or 3.7 GiB after rounding. Taking binary blocks but decimal GB instead gives 4.3, not an accepted supplied range. Preserve the official disjoint intervals 3.7–3.8 OR 4.0–4.1 rather than concealing this unit ambiguity.
