# GATE 2019 CS: Q33 (printed CS Q23)

**Question:** [Official archived paper page 8](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=8); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 80 to 80

**Derived answer:** 80

## Solution

Under interleaved read-modify-write operations, the minimum final value is 50: P2 reads100, the others finish, and P2 writes50 last. The maximum is 130: P1 and P2 read100; P2 writes50; P1 writes120; then P3 reads120 and writes130. No chain can decrease by more than50 or increase by more than20+10. Hence Y−X=130−50=80. If whole assignments were atomic, every order would instead end at 80; the intended model permits preemption within an assignment.

# GATE 2019 CS: Q49 (printed CS Q39)

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A under actual-remaining-demand interpretation

## Solution

After p and q finish, at most Xp+Xq instances become free. If this is less than every other process’s actual remaining requirement, none can finish, yielding A. However the source only says at most Yi additional instances, making Yi upper bounds rather than necessary requests. Another process could need zero additional instances and finish even if A holds. Thus A uses the intended interpretation of Yi as the required remaining demand; the literal upper-bound premise alone does not guarantee the conclusion.

# GATE 2019 CS: Q51 (printed CS Q41)

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 2 to 2

**Derived answer:** 2

## Solution

P1 runs0–1, then P2 preempts it and finishes at 2. P1 resumes2–4, including past P3 arrival at 3 because its remaining 1 is shorter than P3 burst3. At4, P1 is done, P3 has waited1, and P4 arrives. If Z<3, P4 runs before P3; total waiting is 1+0+(1+Z)+0=2+Z. The given average1 requires total 4, hence Z=2, consistent with Z<3. If Z≥3, the minimum total waiting of the remaining pair gives total 5, so it cannot satisfy the condition. For Z=2 the completions are P1=4, P2=2, P4=6, P3=9.

# GATE 2019 CS: Q52 (printed CS Q42)

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 3.7 to 3.8 OR 4.0 to 4.1

**Derived answer:** 4.0 under consistent binary units; alternate range retained

## Solution

A block contains B/4 addresses if its size is B bytes. The data capacity is B[12+B/4+(B/4)^2]. With B=4096, this is 4299210752 bytes, or4.003952... GiB, rounding to 4.0. With decimal4kB=4000 bytes the capacity is 4004048000 bytes, or4.004048 decimal GB, again4.0; expressed instead in GiB that latter capacity is 3.729060..., rounding to 3.7. The official disjoint intervals3.7–3.8 OR4.0–4.1 are preserved. Unit convention is material: 4096-byte blocks expressed in decimal GB give4.3, which is not within the supplied key. Indirect blocks themselves are metadata and not counted as file data.
