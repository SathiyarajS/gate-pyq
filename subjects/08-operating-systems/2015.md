**Paraphrased problem context:** Byte-addressable memory has 32-bit logical addresses, 4-kilobyte pages, and 4-byte page-table entries. Find the single-level page-table size in megabytes.

## Solution

There are 2^32 addressable bytes and 2^12 bytes per page, so the virtual address space contains 2^20 pages. Each needs one entry even though physical memory size is not given. Multiply entries by bytes per entry: 2^20×4=2^22 bytes=4 MiB. The question labels binary MiB as MB; the answer is not the page size itself.

Baseline derivation and retained qualifications: A4 KiB page uses 12 offset bits, leaving 20 page-number bits in a 32-bit address. A single-level table needs 2^20 entries of 4 bytes, totaling 2^22 bytes=4 MiB. Thus4 under the question’s binary MB convention.

X: while(true) { varP=true; while(varQ==true) { /* critical section X */ varP=false; } }

Thus A. Literal unsynchronized C threads would instead require a memory-model analysis; the source is treated as synchronization pseudocode.
