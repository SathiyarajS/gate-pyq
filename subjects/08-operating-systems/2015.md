**Derived answer:** 36

**Source access:** Open archive member CS/CS2015.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

An8 KiB page uses13 offset bits. A physical frame number needs 32−13=19 bits, and the five status/permission bits make a 24-bit (3-byte) packed PTE. A24 MiB table then holds2^23 entries, giving23+13=36 virtual address bits. This assumes the entries are packed into 3 bytes rather than padded and the maximum table maps the full virtual page space.

# GATE 2015 CS3: Q31 (printed CS Q31)

**Question:** [Official archived paper page 63](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A under atomic shared-flag model

**Source access:** Open archive member CS/CS2015.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

If both flags become true before either loop test, both processes can enter their critical sections, so mutual exclusion fails. The inner loops are not waiting loops: their bodies execute the critical section when the other flag is true. Under fair execution and terminating critical sections, a false test returns to the outer loop and reasserts the flag; there is no state where both wait permanently for an action the other cannot perform. Thus A. Literal unsynchronized C threads would instead require a memory-model analysis; the source is treated as synchronization pseudocode.
