# GATE 2026 CS1: Q35

**Status:** Partial subject-year coverage. Independently derived and matched against the published official key; independent second derivation review passed; final-key revision check remains pending.

**Question summary (paraphrased):** Five processes share k identical resource units; each needs at most two, acquired singly. Find the least k that rules out deadlock.

Accepted numerical interval is preserved exactly.

**Type / marks:** NAT, 1 mark. Paper variant CS1 (forenoon); the official key labels the exam session 3.

**Official answer:** 6 to 6

**Derived answer:** 6

## Solution

With five units, each of the five processes can hold one and wait for a second, creating deadlock. With six units, if every unfinished process holds at most one unit, at most five units are held, leaving a unit available. Granting that unit lets a process attain its maximum claim of two, complete and release its units. The remaining processes can then finish in sequence. If some process already has two units, it needs no more units and can complete. Thus six units guarantee absence of resource deadlock under the stated model, and five do not. This is a deadlock guarantee, not a fairness or starvation guarantee.

# GATE 2026 CS1: Q29

**Topic:** False deadlock statements.

**Question:** Consult [the original master question, page 22](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=22) for the full wording and options. This entry supplies an original solution, not a complete transcription.

**Type / marks:** MSQ, 1 mark.

**Official and derived answer:** A;C

## Solution

The question asks for FALSE statements. Banker’s algorithm implements deadlock avoidance by testing whether allocations preserve a safe state; it is not a deadlock-prevention rule that forbids one of the necessary conditions. Thus A is false. Preventing hold-and-wait blocks a necessary deadlock condition, so B is true. In a resource-allocation graph an assignment edge points from a resource instance to the process holding it; a process-to-resource edge is a request, so C is false. A safe state has a sequence in which all processes can obtain their remaining claims and finish, which makes D true in the standard safe-allocation sense. Select A and C.

# GATE 2026 CS1: Q63

**Question:** [Official master paper page 46](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=46); consult original wording and options.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4 to 4

## Solution

Only the newly created child executes continue and advances to the next loop iteration. The parent of each successful fork reaches break, exits the loop, and prints once. The first parent prints, its child forks the next process and then prints, and that next child forks once more and prints. The last child leaves the loop when its index reaches 3 and also prints. Thus three forks form a single continuing lineage with four total processes and four executions of printf. This is not exponential doubling because each parent stops forking immediately.

# GATE 2026 CS1: Q64

**Question:** [Official master paper page 46](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=46); consult original wording and options.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 9.5 to 9.5

## Solution

Sort the ten arrivals chronologically and apply nonpreemptive FCFS. The arrival times are 10,11,20,22,30,33,40,44,50,55, with alternating service durations 6 and 8. Starting each process at max(arrival,previous completion) gives start times 10,16,24,30,38,44,52,58,66,72. The waiting times are therefore 0,5,4,8,8,11,12,14,16,17, summing to 95 seconds. Divide by ten processes to obtain 9.5 seconds. Arrival gaps do not create idle periods after the first process because the queue never empties before the next arrival.

## Q54 — Operating Systems / Computer Organization: translation and cache events

Paper page 42. MSQ, 2 marks. **Answer: B, C.**

1. Interpret a page-table miss here as a nonresident page (a page fault), not as a cache miss while fetching the page-table entry. The cache is physically addressed, so the ordinary sequence first resolves virtual-to-physical translation and then accesses the referenced cache block.
2. A TLB miss can occur even when the page is resident: the translation may simply not be cached in the TLB. After a successful page-table lookup the data block may still be present in the cache. Therefore A is possible.
3. In a correctly maintained translation system, a TLB hit supplies a valid resident-page translation, and a page-table walk is not needed for that reference. It cannot simultaneously be the page-table-fault sequence described in B. Thus B is impossible.
4. If the referenced page is absent from memory, the stated invalidation rule prevents its data blocks from remaining valid in the cache. Therefore the page-fault-plus-cache-hit sequence C is impossible. A TLB miss, page fault and absence of the data block from cache, as in D, is possible.

**Interpretation note:** These are hit/miss conditions for the original reference before fault recovery. Fault servicing can populate memory or cache and then retry the instruction; hits on that later retry are not the same event sequence. Correct TLB invalidation is implicit in a functioning virtual-memory system.
