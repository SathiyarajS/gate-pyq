**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Every NP language reduces to S, and S reduces to R, so transitivity makes R NP-hard. R need not belong to NP and therefore need not be NP-complete. Q reducing to S does place Q in NP, but does not make Q NP-hard. Thus B.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

L1={0^(n+m)1^n0^m} is context-free: S→0S0|T and T→0T1|ε generates it. Write L2={0^k1^k0^m:0≤m≤k}. It is not context-free: apply the CFL pumping lemma to0^p1^p0^p. A pump confined to one block breaks either equality of the first two block lengths or the last≤first inequality (choose pumping direction accordingly). A pump crossing one boundary cannot touch all three blocks; preserving the first two lengths while pumping down makes the third too long, while other changes break equality or block order. L3 is{0^k1^k0^k:k≥0}, also non-context-free by the usual three-block pumping argument. Hence L2 and L3, D.

# GATE 2006: Q31 (printed CS Q31)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203119/GATE2006.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

The vertex-count restriction does not remove NP-hardness. Reduce an undirected Hamiltonian-cycle instance by replacing each original vertex with a three-vertex path. For each original edge uv, connect each endpoint of u’s path to each endpoint of v’s path. The middle vertices have degree2, so any Hamiltonian cycle must traverse each replacement path; contracting the paths recovers a Hamiltonian cycle of the original graph. Conversely any original cycle expands through all paths. The new graph has3|V| vertices. Therefore decision DHAM3 is NP-hard; a polynomial search algorithm that returns a cycle or reports none would decide it, so SHAM3 is NP-hard as well, A.

## Solution

Regular∩deterministic-CFL is deterministic context-free; regular∪CFL is context-free. Intersecting the two decidable languages with a recursively enumerable language remains recursively enumerable. But L3∩L1 need not be recursive: take L1=Σ*, giving L3 itself. Thus B is the false universal closure assertion. It can nevertheless be recursive for some choices, such as L1=∅; it is not false for every instance.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D over the unary alphabet

## Solution

The possible lengths are3a+5b, a,b≥0:0,3,5,6 and all integers≥8. The missing nonnegative lengths are1,2,4,7. A unary DFA counts lengths0 through7, then enters an accepting sink at8, using9 states. For any0≤i<j≤8, append7−i symbols: the first length becomes7 and is rejected, while the second exceeds7 and is accepted. Thus all nine states are distinguishable and D is minimal. This treats the stated expression as a language over{1}; a larger alphabet would require a rejecting sink for other symbols.

## Solution

In D, C→aCb|ε generates balanced a^k b^k. A→aA|a adds a positive number of a symbols, so S→AC generates all i>j. B→bB|b adds a positive number of b symbols, so S→CB generates all j>i. Together these are precisely a^i b^j with i≠j. A permits cancellation of C’s ±1 imbalance by the other nonterminal: for example S⇒AC⇒aC⇒ab. B also generates ab. C allows A/B→ε and therefore generates equal counts, including ε. Only D excludes every equal-count string while covering every unequal-count string.

**Independently derived answer:** max(l,m)+2; A and D duplicate in primary reproduction

## Solution

For l>m use S→AC (1 step), expand C by C→aCb exactly m times and then C→ε (m+1 steps), and derive a^(l−m) from A using l−m productions (l−m−1 recursive steps and one terminal step). Total=1+(m+1)+(l−m)=l+2. For m>l the CB branch gives m+2. Thus the length is max(l,m)+2, regardless of the order in which independent nonterminals are expanded. In GFG, both A and D visibly print this same expression, so no unique option letter is supported. The alternate GATE Forum p28 prints D as max(l,m)+3, making A unique in that reproduction.
