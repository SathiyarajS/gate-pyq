**Paraphrased problem context:** S is NP-complete. Q and R are problems not initially known to belong to NP. Q is polynomial-time reducible to S and S is polynomial-time reducible to R. Which statement necessarily follows?
Options:
(A) R is NP-complete
(B) R is NP-hard
(C) Q is NP-complete
(D) Q is NP-hard

## Solution

1. Every NP language reduces to S, and S reduces to R, so transitivity makes R NP-hard. R need not belong to NP and therefore need not be NP-complete.

2. Q reducing to S does place Q in NP, but does not make Q NP-hard. Thus B.

3. Teaching check: Reduction direction matters: if A reduces to B, a solver for B can solve A. Thus hardness flows from S toward R. Membership in NP does not automatically flow in that direction, which is why NP-hard is justified but NP-complete is not.

**Paraphrased problem context:** For n,m≥0 define L₁={0^(n+m)1^n0^m}, L₂={0^(n+m)1^(n+m)0^m}, and L₃={0^(n+m)1^(n+m)0^(n+m)}. Which languages are not context-free?
Options:
(A) L₁ only
(B) L₃ only
(C) L₁ and L₂
(D) L₂ and L₃

## Solution

1. L1={0^(n+m)1^n0^m} is context-free: S→0S0|T and T→0T1|ε generates it. Write L2={0^k1^k0^m:0≤m≤k}.

2. It is not context-free: apply the CFL pumping lemma to0^p1^p0^p. A pump confined to one block breaks either equality of the first two block lengths or the last≤first inequality (choose pumping direction accordingly).

3. A pump crossing one boundary cannot touch all three blocks; preserving the first two lengths while pumping down makes the third too long, while other changes break equality or block order. L3 is{0^k1^k0^k:k≥0}, also non-context-free by the usual three-block pumping argument.

4. Hence L2 and L3, D.

5. Teaching check: For L₂ the two equal leading block lengths and the upper bound on the final block are linked. A pumping window of length p cannot span all three p-length blocks in 0^p1^p0^p. Even if it changes the first two blocks equally, pumping down leaves the untouched third block too long.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** For binary string s, let n₀(s),n₁(s) count zeros and ones. Which language is not regular?
Options:
(A) {s:n₀(s) is a three-digit prime}
(B) {s:for every prefix t of s, |n₀(t)−n₁(t)|≤2}
(C) {s:|n₀(s)−n₁(s)|≤4}
(D) {s:n₀(s) mod 7=0 and n₁(s) mod 5=0}

## Solution

1. A is regular because the permitted zero counts are finitely many three-digit primes; count zeros up to the maximum with an overflow state. B tracks prefix imbalance in{−2,−1,0,1,2}, rejecting immediately outside that range.

2. D tracks zero count modulo7 and one count modulo5. C only bounds the final imbalance and allows arbitrarily large intermediate imbalance.

3. Intersect C with0*1* and pump0^p1^p: pumping a nonempty block of initial zeros sufficiently many times makes the final difference exceed4. Hence C is not regular.

4. Teaching check: A bound on every prefix permits a finite-state machine to reject immediately when its imbalance leaves a fixed range. A bound only on the final string allows arbitrarily large positive imbalance followed by enough ones to cancel it. Tracking this unbounded debt cannot be done with finitely many states.

**Paraphrased problem context:** For a binary string s let d(s) be its numerical value, for example d(101)=5. Classify L={s:d(s) mod 5=2 and d(s) mod 7≠4}.
Options:
(A) Recursively enumerable but not recursive
(B) Recursive but not context-free
(C) Context-free but not regular
(D) Regular

## Solution

1. A finite automaton stores the current binary value modulo35. Reading bit b replaces residue r by(2r+b) mod35.

2. Accept precisely residues r with r mod5=2 and r mod7≠4. This recognizes the language, so it is regular, D; leading zeros do not affect the construction.

3. Teaching check: The joint modulus 35 suffices because both congruence tests depend only on the value modulo 35. Starting at residue zero, scan bits left to right and update r←(2r+b) mod 35. A 35-state DFA with appropriate accepting residues is a constructive regularity proof.

# GATE 2006: Q31 (printed CS Q31)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203119/GATE2006.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Restrict undirected graphs G=(V,E) to |V| divisible by 3. SHAM₃ is the problem of finding a Hamiltonian cycle; DHAM₃ asks whether one exists. Which statement is true?
Options:
(A) Both DHAM₃ and SHAM₃ are NP-hard
(B) SHAM₃ is NP-hard but DHAM₃ is not
(C) DHAM₃ is NP-hard but SHAM₃ is not
(D) Neither is NP-hard

## Solution

1. The vertex-count restriction does not remove NP-hardness. Reduce an undirected Hamiltonian-cycle instance by replacing each original vertex with a three-vertex path.

2. For each original edge uv, connect each endpoint of u’s path to each endpoint of v’s path. The middle vertices have degree2, so any Hamiltonian cycle must traverse each replacement path; contracting the paths recovers a Hamiltonian cycle of the original graph.

3. Conversely any original cycle expands through all paths. The new graph has3|V| vertices.

4. Therefore decision DHAM3 is NP-hard; a polynomial search algorithm that returns a cycle or reports none would decide it, so SHAM3 is NP-hard as well, A.

5. Teaching check: The middle vertex in each three-vertex replacement path has degree two, forcing both its incident edges into any Hamiltonian cycle. Hence the whole path acts as one original vertex when contracted. This gives an explicit polynomial reduction rather than assuming a divisibility restriction preserves hardness.

**Paraphrased problem context:** Grammar G has productions S→SS | ab | ba | ε. Consider I: G is ambiguous; II: G generates every string with equal counts of a and b; III: the language of G can be accepted by a deterministic PDA. Which statements are true?
Options:
(A) I only
(B) I and III only
(C) II and III only
(D) I, II and III

## Solution

1. The grammar generates exactly(ab+ba)*: SS concatenates its two-letter blocks and ε contributes nothing. It is ambiguous, for example ab has both S→ab and S→SS→abS→ab, with different parse trees.

2. It does not generate aabb, although that string has equal a/b counts. The generated language is regular and therefore accepted by a deterministic PDA (even a DFA).

3. Statements1 and3 hold, B; the PDA accepts the language, not the grammar object.

4. Teaching check: Equal counts are necessary for this grammar but not sufficient: concatenating ab and ba blocks cannot produce aabb. The ε production together with S→SS also allows redundant decompositions, so even a very short generated word has multiple parse trees.

**Paraphrased problem context:** L₁ is regular, L₂ is deterministic context-free, and L₃ is recursively enumerable but not recursive. Which universal closure assertion is false?
Options:
(A) L₁∩L₂ is deterministic context-free
(B) L₃∩L₁ is recursive
(C) L₁∪L₂ is context-free
(D) L₁∩L₂∩L₃ is recursively enumerable

## Solution

1. Regular∩deterministic-CFL is deterministic context-free; regular∪CFL is context-free. Intersecting the two decidable languages with a recursively enumerable language remains recursively enumerable.

2. But L3∩L1 need not be recursive: take L1=Σ*, giving L3 itself. Thus B is the false universal closure assertion.

3. It can nevertheless be recursive for some choices, such as L1=∅; it is not false for every instance.

4. Teaching check: To refute a universal closure claim, choose an extreme regular language. Taking L₁=Σ* preserves all of L₃ under intersection, so undecidability remains. Taking L₁=∅ illustrates why the false assertion is “always recursive,” not “never recursive.”

**Independently derived answer:** D over the unary alphabet

**Paraphrased problem context:** Over the unary alphabet {1}, what is the smallest number of states in a DFA for (111+11111)*, where + denotes union?
Options:
(A) 3
(B) 5
(C) 8
(D) 9

## Solution

1. The possible lengths are3a+5b, a,b≥0:0,3,5,6 and all integers≥8. The missing nonnegative lengths are1,2,4,7.

2. A unary DFA counts lengths0 through7, then enters an accepting sink at8, using9 states. For any0≤i<j≤8, append7−i symbols: the first length becomes7 and is rejected, while the second exceeds7 and is accepted.

3. Thus all nine states are distinguishable and D is minimal. This treats the stated expression as a language over{1}; a larger alphabet would require a rejecting sink for other symbols.

4. Teaching check: Lengths 0,3,5,6 and all lengths at least eight are accepted; 1,2,4,7 are rejected. Build states recording exact lengths below eight, followed by one accepting sink. Distinguishability proves this nine-state construction minimal, rather than merely establishing an upper bound.

**Paraphrased problem context:** Which grammar generates precisely {a^i b^j:i,j≥0 and i≠j}? ε denotes the empty string.
Options:
(A) S→AC|CB; C→aCb|a|b; A→aA|ε; B→Bb|ε
(B) S→aS|Sb|a|b
(C) S→AC|CB; C→aCb|ε; A→aA|ε; B→Bb|ε
(D) S→AC|CB; C→aCb|ε; A→aA|a; B→Bb|b

## Solution

1. In D, C→aCb|ε generates balanced a^k b^k. A→aA|a adds a positive number of a symbols, so S→AC generates all i>j.

2. B→Bb|b adds a positive number of b symbols, so S→CB generates all j>i. Together these are precisely a^i b^j with i≠j.

3. A permits cancellation of C’s ±1 imbalance by the other nonterminal: for example S⇒AC⇒aC⇒ab. B also generates ab.

4. C allows A/B→ε and therefore generates equal counts, including ε. Only D excludes every equal-count string while covering every unequal-count string.

5. Teaching check: C supplies equal counts, while A supplies at least one extra a or B at least one extra b. Because A and B cannot derive ε in D, every generated string has unequal counts. Conversely any unequal pair of nonnegative counts decomposes into a common balanced part and one positive excess.

**Independently derived answer:** max(l,m)+2; A and D duplicate in primary reproduction

**Paraphrased problem context:** Using grammar S→AC|CB, C→aCb|ε, A→aA|a, B→Bb|b, count the production applications in a derivation from S of a^l b^m, with l,m≥0 and l≠m. GFG prints the same expression in A and D; GateForum D instead has +3.
Options:
(A) max(l,m)+2
(B) l+m+2
(C) l+m+3
(D) max(l,m)+2 [GFG]; max(l,m)+3 [GateForum]

## Solution

1. For l>m use S→AC (1 step), expand C by C→aCb exactly m times and then C→ε (m+1 steps), and derive a^(l−m) from A using l−m productions (l−m−1 recursive steps and one terminal step). Total=1+(m+1)+(l−m)=l+2.

2. For m>l the CB branch gives m+2. Thus the length is max(l,m)+2, regardless of the order in which independent nonterminals are expanded.

3. In GFG, both A and D visibly print this same expression, so no unique option letter is supported. The alternate GATE Forum p28 prints D as max(l,m)+3, making A unique in that reproduction.

4. Teaching check: Count production applications, including C→ε and the initial S choice. For l=3,m=1, use S→AC, A→aA→aa, C→aCb→ab: five applications, equal to max(3,1)+2. Interleaving A and C expansions does not alter the number of productions used.
