**Paraphrased problem context:** An NFA has n states. Its equivalent minimal DFA has k states. Which is always true? A k≥2^n; B k≥n; C k≤n²; D k≤2^n.

## Solution

Method and intermediate reasoning:

A DFA must remember the entire set of NFA states that could currently be active. There are 2^n subsets of an n-element set. Some subsets may be unreachable and some reachable ones may be equivalent, so both reachability pruning and minimization can reduce this bound. There is no general lower bound k≥n: an NFA can contain many redundant states while accepting a language recognized by one DFA state. Some NFA families require exponentially many DFA states, ruling out a universal quadratic bound.

Derivation, answer and qualifications:

Subset construction represents each DFA state by a subset of the NFA’s n states, so at most 2^n states are needed, including a possible empty subset. Minimization cannot increase that count. Thus k≤2^n, D.

**Paraphrased problem context:** For recursively enumerable languages, choose the true statement: A closed under complement; B closed under intersection; C all are recursive; D there are uncountably many.

## Solution

Method and intermediate reasoning:

A recognizer may run forever when the input is not in its language. For intersection, sequential simulation is sufficient: run the first recognizer and, if it accepts, run the second and accept only if it also accepts. An input in both languages reaches both acceptances; if the first simulation loops, that input is outside the intersection, where looping is permitted. Dovetailing is another valid construction, not a requirement here. Unlike intersection, union requires avoiding a loop in one recognizer that hides acceptance by the other. Finite machine descriptions are countable, and recognizable but undecidable languages refute C.

Derivation, answer and qualifications:

To recognize the intersection of two recursively enumerable languages, dovetail their recognizers on the same input and accept when both accept. Hence intersection closure holds. Complement closure would make every recognizable language decidable, which is false; encodings of recognizers are countable. Thus B.

**Paraphrased problem context:** Over words a^m b^n c^p d^q, with all exponents nonnegative, define I m+p=n+q; II m=n and p=q; III m=n=p and p≠q; IV mn=p+q. Which are context-free? A I,IV; B I,II; C II,III; D II,IV.

## Solution

Method and intermediate reasoning:

One stack can track a single signed difference, so the crossed-looking equality in I is still manageable; a finite-state component checks block order. II has grammar S→AB, A→aAb|ε, B→cBd|ε. For III, restricting to positive a,b,c blocks and no d leaves the standard non-CFL equal-three-count language. For IV, the multiplication constraint cannot be reduced to one additive counter. The pumping argument below makes this precise, including decompositions that cross a block boundary rather than assuming where the pumped substrings lie.

Derivation, answer and qualifications:

I is context-free: a PDA tracks the signed running difference(#a+#c)−(#b+#d) with one stack symbol for positive excess and another for negative excess, canceling opposite contributions; finite control enforces a*b*c*d* order. II is the concatenation{a^n b^n}{c^p d^p}, a CFL. For III, intersect with a+b+c+ (no d); the result is{a^n b^n c^n: n≥1}, not context-free. For IV, suppose pumping length p and take a^p b^p c^(p²). Pumping up either disrupts block order or adds α a symbols, β b symbols and γ c symbols, with α+β+γ≤p and at least one added symbol. If α+β=0, the product stays p² but γ>0. Otherwise the required increase in c is p(α+β)+αβ≥p, while actual γ≤p−α−β<p. In every case the equality mn=p+q fails (here the fourth-block length remains 0). Thus only I and II are CFL, B.

**Paraphrased problem context:** Classify: I membership w∈L(G) for unrestricted G; II whether a TM language is regular; III equality of languages of two unrestricted/general grammars; IV whether an NFA language has an equivalent deterministic PDA. Options A only I,II undecidable; B only III; C only II,IV; D only I,II,III.

## Solution

Method and intermediate reasoning:

Rice’s theorem applies to nontrivial properties of the recognized language, not to arbitrary syntactic machine properties. Regularity is nontrivial because some recognizable languages are regular and some are not. Equivalence of general grammars includes comparing a grammar to one generating the empty language, already an undecidable emptiness problem. IV is different: every regular language has a DFA, and a deterministic PDA can simulate a DFA while leaving its stack unchanged. Therefore IV is a constant-yes decision problem.

Derivation, answer and qualifications:

I is the undecidable membership problem for unrestricted grammars/Turing-recognizable languages. II is a nontrivial semantic property of a TM language, hence undecidable by Rice’s theorem. III, equivalence of general grammars, is undecidable (even equivalence of CFGs is undecidable). IV always has answer yes: convert the NFA to a DFA and view that DFA as a DPDA that does not use its stack. Hence only I, II, III are undecidable, D. If III were restricted to regular grammars it would be decidable, but no such restriction is stated.

**Paraphrased problem context:** Define L^0={ε}, L^(i+1)=L^iL; order is least k with L^k=L^(k+1). The unary DFA has accepting start q0, accepting q1, rejecting q2, and transitions q0−0→q1, q1−0→q2, q2−0→q1. Find order of its language.

## Solution

Method and intermediate reasoning:

A path of length 0 accepts, and positive path lengths accept exactly when odd. Concatenation over a unary alphabet adds lengths. Every positive even length 2m can be decomposed as 1+(2m−1), both positive odd, so two language factors suffice for every even length as well. Zero and odd lengths use ε in one factor. To prove the least order, explicitly exclude k=0 and k=1: length 1 distinguishes L^0 from L, and length 2 distinguishes L from L².

Derivation, answer and qualifications:

The start state is accepting. After one 0 the automaton enters an accepting state alternating with a nonaccepting state, so L1 contains epsilon and precisely the positive odd-length unary words. L1 squared contains every unary word: odd lengths use one odd word and epsilon, while any positive even length is the sum of two positive odd lengths. Hence L1²=0* and L1³=0*. But L1^0 differs from L1, and L1 differs from L1² because length 2 is absent from L1. The smallest equality index is therefore 2.
