**Type / marks:** MSQ, 1 mark(s).

**Official answer:** C;D

**Derived answer:** C;D

**Paraphrased problem context:** L1 and L2 are regular languages and L3 is not regular, over a common alphabet. Which statements always hold? A L1=L2 iff L1∩complement(L2)=∅. B L1∪L3 is nonregular. C complement(L3) is nonregular. D complement(L1)∪complement(L2) is regular.

## Solution

Approach: Use closure under complement and union to prove universal claims, and a single legal counterexample to reject each false universal claim.
1. A is false. L1∩complement(L2)=∅ means only L1⊆L2. For instance L1=∅ and L2={a} satisfy this condition without being equal. Equality would require both inclusions.
2. B is false. Choose L1=Σ*, which is regular. Its union with any L3 is Σ*, so the union can be regular even though L3 is not.
3. C is true by contradiction. If complement(L3) were regular, complementing it again would make L3 regular, since regular languages are closed under complement. This contradicts the premise.
4. D is true because complement(L1) and complement(L2) are each regular, and their union is regular by union closure.
Answer: C and D. A nonregular input does not automatically make the result of every language operation nonregular.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

**Paraphrased problem context:** A DFA has start state 1 and only accepting state 1. For inputs (0,1), its transitions are: state 1→(2,4); state 2→(3,1); state 3→(1,2); state 4→(1,5); state 5→(4,1). Let n0(w),n1(w) count symbols. Which statements are false? A States 2 and 4 are distinguishable. B States 3 and 4 are distinguishable. C States 2 and 5 are distinguishable. D Every w with n0(w)=n1(w) is accepted.

## Solution

Approach: Group states with the same future acceptance behavior, then interpret the resulting quotient machine.
1. Consider classes C0={1}, C1={2,5}, C2={3,4}. Only C0 accepts. From either member of C1, input 0 leads to C2 and input 1 to C0. From either member of C2, 0 leads to C0 and 1 to C1. From C0, 0 leads to C1 and 1 to C2.
2. This is a stable partition: members of each class have the same accepting status and transition to the same classes for each symbol. Induction on suffix length therefore proves that states 2 and 5 are equivalent, as are states 3 and 4. Claims B and C are false.
3. States 2 and 4 are distinguishable: suffix 1 sends 2 to accepting state 1 but sends 4 to nonaccepting state 5. Thus A is true.
4. Label C0,C1,C2 by residues 0,1,2. A 0 adds 1 modulo 3 and a 1 subtracts 1. Starting at residue 0, the machine accepts exactly when n0−n1 is divisible by 3. Equal counts satisfy this condition, so D is true.
Answer: B and C, because the question asks for false statements.

**Paraphrased problem context:** A context-free grammar in Chomsky Normal Form has terminals {a,b,c} and 10 variables including start symbol S. It derives w=a³⁰b³⁰c³⁰. How many rule applications occur in a derivation S⇒*w?

## Solution

Approach: In Chomsky Normal Form, a nonempty derivation uses binary-variable rules A→BC and terminal rules A→a. Count each kind using the final word length.
1. The word contains 30+30+30=90 terminal symbols. Each requires exactly one terminal-producing rule application, so there are 90 such applications.
2. Initially there is one variable occurrence. Each binary rule replaces one variable with two and therefore increases the total number of current symbol occurrences by one. Terminal rules replace one symbol with one and do not change that total.
3. To grow from one symbol to a final string of 90 symbols requires exactly 89 binary-rule applications. Equivalently, the variable branching tree is full binary with 90 leaves and 89 internal branching nodes.
4. Total rule applications =90+89=179.
Answer: 179. The ten available variable names can be reused and do not bound the number of variable occurrences. Derivation order does not change these counts; the CNF epsilon exception is irrelevant to this nonempty word.

**Paraphrased problem context:** Over {0,1}, r=0*+1* and s=01*+10*, where + means union and * means Kleene star. Count strings of length at most 5 that belong to neither language, including the empty string in the universe.

## Solution

Approach: Count all short binary strings, subtract the union of the two languages, and account for their overlap.
1. There are Σ from length 0 to 5 of 2^length =1+2+4+8+16+32=63 strings. The empty string is the single length-zero string.
2. Language r contains ε and, at each positive length 1–5, the all-zero and all-one strings. Thus |r within the limit|=1+2×5=11. Count ε only once even though both starred expressions generate it.
3. Language s contains a leading 0 followed by only 1s, or a leading 1 followed by only 0s. It has two strings at each length 1–5 and none at length zero, so its count is 10.
4. The overlap is exactly {0,1}. Longer strings in s contain both symbols, so cannot be in r. Inclusion-exclusion gives union size 11+10−2=19.
5. The complement count is 63−19=44.
Answer: 44. A lengthwise check gives 0,0,0,4,12,28 excluded strings at lengths 0 through 5, again totaling 44.

## Solution

Approach: Assign a parity invariant to each state, then check the loop structure in the regex.

1. Derivation. In the visually checked DFA, 0 loops on each state and 1 toggles between the nonaccepting start and the accepting state. It accepts exactly strings with an odd number of 1s. B accepts epsilon, C cannot generate111, and D requires an initial 0, so each differs.

2. Explanation and checks. After any prefix, E means an even number of ones and O means an odd number. In A, the leading 0*1 contributes the first one; each subsequent block contributes either zero ones or exactly two, preserving odd parity. Conversely, after the first one, any remaining ones can be paired, with intervening zeros accommodated by the blocks. The short strings ε, 111 and 1 distinguish B, C and D respectively from the required language.

## Solution

Approach: Enumerate paths ending in each accepting state and track the parity before and after the epsilon jump.

1. Derivation. The initial epsilon choice reaches state2 or4. State2 accepts an even number of 0s; after an odd number of 0s the machine is in 3 and can take epsilon to accepting5, after which an even number of 1s returns to 5. The direct state4 branch accepts an odd number of 1s. Thus the language is(00)* + 0(00)*(11)* + 1(11)*. The pure even/odd zero cases together equal0*, so it can be written0*+(1+0(00)*)(11)*, option B. Diagram directions and accepting states 2, 5 were visually checked.

2. Explanation and checks. Staying in the upper component accepts an even zero count; reaching 3 requires an odd zero count and jumping to 5 then permits an even one count. Starting at 4 instead requires an odd one count. A misses the accepted word 0. C wrongly accepts 11 (take ε from (00)* and one pair of ones), whereas the NFA cannot accept pure even-positive ones. D misses ε, which is accepted via 1→2. These witnesses isolate B beyond merely manipulating algebraic expressions.

**Official answer:** B;C

**Paraphrased problem context:** Grammar S→aS | aSbS | c generates w. Let na,nb,nc count the respective terminals in w. Which always hold? A na>nb; B na>nc−2; C nc=nb+1; D nc=2nb.

## Solution

Approach: Count how each production changes both the terminal totals and the outstanding nonterminals.

1. Derivation. Let u count applications of S→aS and v count applications of S→aSbS. Then n_a=u+v and n_b=v. A derivation starts with one S; unary rules leave the number of outstanding S unchanged, binary rules increase it by one, and S→c decreases it by one. Thus n_c=v+1, proving C. Also n_a≥v=n_c−1>n_c−2, proving B. A fails for w=c, where both a and b counts are0; D also fails for c, whose c count is 1 and b count 0.

2. Explanation and checks. Each binary rule contributes one b and creates one additional S requiring eventual termination by a c-rule. Starting with one S therefore requires exactly one more terminating c-rule than binary rules. Unary aS rules can add any extra a’s without changing b or c counts. Consequently na−nb equals their nonnegative number; it may be zero, so A’s strict inequality is too strong. In B the weaker strict bound still holds because na≥nc−1 is an integer stronger than na>nc−2.

**Paraphrased problem context:** L1 is described by b*ab*(ab*ab*)*. L2 contains all strings over {a,b} of length at most four. How many strings belong to both?

## Solution

Approach: Interpret the regex structurally before doing a length-by-length count.

1. Derivation. The regular expression has one initial a followed by any number of pairs of a’s, with arbitrary b runs between and around them. It therefore accepts exactly the strings with an odd positive number of a’s. For any positive length ℓ exactly half of the 2^ℓ binary strings have odd a-parity, by flipping one fixed position. Lengths1 through4 contribute1+2+4+8=15; ε has even parity and is excluded.

2. Explanation and checks. The one initial a plus any number of pairs makes the a-count odd; the b* runs admit arbitrary b’s before, between and after those a’s. For length 3 the allowable counts are one a or three a’s, giving C(3,1)+C(3,3)=4. For length 4 they give C(4,1)+C(4,3)=8. Lengths 1 and 2 contribute one and two. The empty string has no a and cannot match the mandatory initial a.
