**Paraphrased problem context:** A grammar has start symbol S and productions S→aaB | Abb, A→a | aA, B→b | bB. Choose its language: A {a²b^n:n≥1}∪{a^nb²:n≥1}; B {a^nb^(2n):n≥1}∪{a^(2n)b^n:n≥1}; C {a^nb^n:n≥1}; D {a^(2n)b^(2n):n≥1}.

## Solution

Approach: First identify what each helper nonterminal can generate, then substitute into each start production.
A→a is the base case. Each application of A→aA adds one a before eventually taking the base case, so A generates exactly a^n for n≥1. Similarly B generates exactly b^n for n≥1. Neither can generate the empty string.
Taking S→aaB fixes the number of a’s at two and allows any positive number of b’s. Taking S→Abb allows any positive number of a’s and fixes the number of b’s at two. The language is the union of these alternatives, which is A.
For example aabbb is generated by the first branch, and ab b (the word abb) by the second. The grammar does not synchronize the two counts, so the equality and ratio conditions in B–D are unjustified. The common word aabb belongs to both branches but is counted just once in the language.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** A regular language L is accepted by an n-state NFA. Which statements are false? A L may also have an NFA with fewer than n states; B L may have a DFA with fewer than n states; C some DFA for L has at most 2^n states; D every DFA for L has more than 2^n states.

## Solution

Approach: Apply subset construction and distinguish “may” from a guaranteed reduction.
When determinizing an NFA, a DFA state records the set of NFA states that can currently be active. An n-element set has 2^n subsets, so the construction uses at most 2^n states, including the empty subset if needed. Unreachable subsets can be removed. This proves C and directly contradicts D, making D the false statement.
The NFA in the premise is not required to be minimal. For example, an automaton for all strings can be padded with redundant states although a one-state accepting automaton already recognizes that language. Therefore A and B describe genuine possibilities for a nonminimal supplied NFA.
They do not assert that every n-state NFA can be reduced, nor a strict reduction at n=1 in the conventional nonempty-state model. The exponential bound is an upper bound that can be necessary for some languages, not a claim that every language needs exponentially many DFA states.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Over {a,b}, define L1={αβα | α∈{a,b}+ and β∈{a,b}+}, and L2={αβα | α∈{a}+ and β∈{a,b}+}. Both α and β must be nonempty. Which is correct? A both regular; B only L1 regular; C only L2 regular; D neither regular.

## Solution

Approach: Simplify L2 directly, then prove L1 nonregular using intersection with a carefully chosen regular language.
Every L2 word begins and ends in a and has length at least three. Conversely any such word can use α=a and the nonempty intervening substring as β. Hence L2=a(a|b)+a, which is regular.
For L1 intersect with R={ab^r aab^s:r,s≥1}. R is regular. A word in R has exactly three a’s. If it equals αβα, the two disjoint copies of α cannot each contain two a’s; because α starts at the initial a, it contains exactly one a. It also ends in b, and its suffix copy must start at the third a: starting at the second a would include two a’s. Thus α=ab^s. This is a prefix exactly when r≥s. The remaining β=b^(r−s)a is nonempty. Therefore L1∩R={ab^r aab^s:r≥s≥1}.
If this intersection were regular with pumping length p, choose w=ab^p aab^p. Any pumpable nonempty substring within the first p positions either includes the initial a or consists only of b’s from the first block. Pumping it down in the first case destroys the required initial a; in the second case it reduces r below s. Every permitted decomposition fails, contradicting the pumping lemma.
Regular languages are closed under intersection, so L1 cannot be regular. L2 is regular and L1 is not: C. A repeated substring does not automatically prove nonregularity; the explicit restriction and pumping argument supply the proof.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** For m,n≥1, L1={a^m b^m c^(m+n)} and L2={a^m b^n c^(m+n)}. Which is true? A both context-free; B only L1 context-free; C only L2 context-free; D neither context-free.

## Solution

Approach: Give a constructive grammar for L2 and a pumping-lemma contradiction for L1.
L2 is generated by S→aSc | aTc and T→bTc | bc. Each use of S adds one a and one trailing c, with at least one a forced before moving to T. Each T production similarly pairs a b with a c and forces at least one b. The derived words are exactly a^m b^n c^(m+n), so L2 is context-free.
Suppose L1 were context-free with pumping length p. Choose w=a^p b^p c^(p+1), which is in L1 with m=p,n=1. In a pumping decomposition w=uvxyz, |vxy|≤p and |vy|>0. The window cannot touch both the a and c blocks, because it would have to span all p b’s between them.
Let Δa,Δb,Δc count those symbols in the pumped parts v and y. If pumping disrupts block order, it already leaves L1. Otherwise, if Δa≠Δb, pumping down or up breaks equality of a and b counts. If Δa=Δb>0, then Δc=0; pumping up makes the common count at least p+1 while c remains p+1, violating the strict requirement c>m. Finally if Δa=Δb=0, then Δc>0; pumping down leaves at most p c’s while a=b=p, again violating c>m.
All possibilities fail. Thus L1 is not context-free, giving C. The unrestricted extra c’s in L1 do not eliminate the need to enforce both equality and a strict count comparison.

**Paraphrased problem context:** A DFA over {a,b} has states q0,q1,q2,q3, start q0 and sole accepting state q3. Transitions on (a,b) are q0→(q0,q1), q1→(q2,q1), q2→(q0,q3), q3→(q2,q1). Which language does it recognize? A words with an even number of b’s; B words containing bab; C words ending in bab; D words avoiding aba.

## Solution

Approach: Assign each state the longest suffix of the input read so far that is also a prefix of the pattern bab.
The prefixes are ε,b,ba,bab, corresponding respectively to q0,q1,q2,q3. At q0 an a leaves no nonempty matching suffix, while b starts the match. At q1 another b still leaves suffix b, while a extends it to ba. At q2, b completes bab, but a leaves no matching suffix and returns to q0.
After reaching q3, an a leaves suffix ba and returns to q2; a b leaves suffix b and returns to q1. Therefore acceptance records that the current complete word ends in bab, not merely that bab appeared at some earlier position. This proves C.
B fails because baba contains bab but ends at nonaccepting q2. A fails because the empty word has an even b-count but is rejected. D fails because a avoids aba yet is rejected. The figure’s transition directions and labels were visually checked before encoding this complete transition list.

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** Which family is guaranteed to be accepted by deterministic pushdown automata, meaning that every language in the listed family has some DPDA?
Options: A. every regular language; B. every context-free language; C. every language accepted by an NPDA; D. every decidable language.

## Solution

A DPDA can simulate a DFA: copy the DFA's finite control and transitions, and leave the stack unused except for its bottom marker. Therefore every regular language has a deterministic pushdown recognizer, establishing A.

Nondeterministic PDAs recognize exactly the context-free languages, while deterministic PDAs recognize only the deterministic context-free languages, a proper subclass. Thus B and C make the same overly broad guarantee. For example, the unrestricted palindrome language over {a,b} requires guessing the midpoint in the usual PDA construction and is not deterministic context-free; a visible midpoint marker would change the problem.

D is even broader. A decidable language such as {a^n b^n c^n:n≥0} can be decided by a Turing machine but is not context-free, so no PDA, deterministic or nondeterministic, accepts it. These statements concern existence of a suitable machine for each language, not one fixed machine that accepts every language at once. Answer: A.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** Given arbitrary context-free grammars G1,G2 and a regular expression R, which decision problem has an algorithm that always terminates with the correct yes/no answer?
Options: A. L(G1)=L(G2)? B. L(G1)∩L(G2)=∅? C. L(G1)=L(R)? D. L(G1)=∅?

## Solution

CFG emptiness is decidable by identifying productive nonterminals, those that can derive a string containing only terminals. Start by marking a nonterminal with a production containing no nonterminals, including an epsilon production. Repeatedly mark the left side of a production whenever all nonterminals on its right side are already marked. Since there are finitely many nonterminals and marks are only added, this process terminates. The generated language is nonempty exactly when the start symbol is marked. Hence D is decidable.

General equivalence of two CFGs (A) and emptiness of the intersection of two CFLs (B) are undecidable. Do not infer B from single-CFG emptiness: CFLs are not closed under intersection, so there need not be an effectively constructed CFG for the intersection.

C is also undecidable in general despite one language being regular. If it were decidable, choose R to denote Σ*. It would then decide whether an arbitrary CFG generates every string over Σ, the undecidable CFG universality problem. The asymmetry matters: containment of a CFL in a regular language can be decided using intersection with a regular complement, but equality also requires the reverse containment. Answer: D.

**Official answer:** B;C

**Paraphrased problem context:** Match language families (i) context-free, (ii) recursive/decidable, (iii) regular with properties (a) closed under union, (b) not closed under complementation, (c) closed under intersection. Select every option whose three matches are all valid.
A. i→a, ii→b, iii→c.
B. i→b, ii→a, iii→c.
C. i→b, ii→c, iii→a.
D. i→a, ii→c, iii→b.

## Solution

Context-free languages are closed under union: introduce a new start symbol that chooses either grammar. They are not closed under complementation. One way to understand the latter fact is that closure under both union and complement would, by De Morgan's law, imply closure under intersection, which CFLs do not have.

Decidable languages are closed under union and intersection because both deciders halt: run them and combine their Boolean answers with OR or AND. They are closed under complement by swapping acceptance and rejection. Regular languages have all three closures: product automata handle union/intersection, and swapping accepting states in a complete DFA handles complement.

Now inspect each full option. A incorrectly assigns nonclosure under complement to decidable languages. B correctly assigns CFL nonclosure, decidable union closure, and regular intersection closure. C correctly assigns CFL nonclosure, decidable intersection closure, and regular union closure. D incorrectly denies complement closure to regular languages. Therefore B and C are correct. This is not a one-to-one matching puzzle: a family can possess more than one listed closure property.

**Paraphrased problem context:** Let #a(w),#b(w) count symbol occurrences. Which languages are regular?
A. {a^m b^n:m,n≥0}.
B. {a,b}* ∩ {a^m b^n c^(m−n):m≥n≥0}.
C. {w∈{a,b}*: #a(w)≡2 (mod 7), #b(w)≡3 (mod 9)}.
D. {w∈{a,b}*: #a(w)≡2 (mod 7), #a(w)=#b(w)}.

## Solution

A is described by the regular expression a*b*, so it is regular. The two block lengths are independent; there is no equality constraint to remember.

For B, membership in {a,b}* excludes every c. Hence m−n=0 and the intersection is exactly {a^n b^n:n≥0}. This is nonregular: for a pumping length p, any allowed pumping segment in the initial a-block of a^p b^p changes the a-count without changing the b-count.

C needs only finite modular information. A DFA state (r,s) stores #a modulo 7 and #b modulo 9. On a update r to r+1 modulo 7; on b update s to s+1 modulo 9. Start at (0,0), accept (2,3). The 7·9=63-state construction proves regularity, without claiming a state-minimality result.

For D, intersect with the regular language a*b*. If D were regular, this intersection K={a^k b^k:k≡2 mod 7} would also be regular. Choose an allowed k greater than a proposed pumping length. Any pumping segment within the first p positions consists only of a's; pumping it changes one count and breaks equality. Thus K, and therefore D, is nonregular. A modular restriction alone is finite-state, but it does not eliminate an unbounded equality requirement. Select A,C.

**Official answer:** 6 to 6

**Paraphrased problem context:** Let Σ={1,2,3,4}. For a string x, prod(x) is the product of its symbols modulo 7, with prod(ε)=1. Define L={x:prod(x)=2}. How many states does a minimum DFA for L have?

## Solution

No input symbol is divisible by 7, so a product can never have residue 0. A DFA can keep one of the six nonzero residues 1,…,6 as its state. Start in state 1, use transition δ(r,a)=ra mod 7 for a∈{1,2,3,4}, and accept only state 2. This proves that six states suffice.

To prove minimality, first show all six residues are reachable. Repeated input 3 gives the cycle 1→3→2→6→4→5→1, so every state is reached by some power of the string symbol 3.

Next distinguish two different residues r and s. Nonzero residues modulo the prime 7 have multiplicative inverses. Choose a suffix whose product is t=2r^(−1) mod 7. Such a suffix exists because powers of 3 realize every nonzero residue. Appending it to a prefix with product r yields rt=2 and is accepted. Appending it to a prefix with product s cannot yield 2: st=rt would imply s=r after cancellation. Thus every pair of reachable states has different residual languages.

By the DFA distinguishability criterion, none of these states can be merged. Exactly six are necessary and sufficient; no seventh zero-residue state is reachable or needed for this alphabet. Answer: 6.
