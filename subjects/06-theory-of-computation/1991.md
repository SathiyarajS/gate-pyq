

# GATE 1991: Q32 (printed A Q3(xiii))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Essential problem context (paraphrased):** Let r=1(1+0)*, s=11*0, t=1*0. Choose A L(s)⊆L(r) and L(s)⊆L(t); B reverse first inclusion; C L(s)=L(t); D L(t)⊆L(s); E none.

## Solution

Every s-word is one or more 1s followed by a single 0. It starts with 1 and has an arbitrary binary suffix, so it belongs to r. It also consists of zero or more 1s followed by 0, so it belongs to t. The inclusions are strict: 1 belongs to r but not s, and 0 belongs to t but not s. These witnesses refute the reverse inclusion and equality choices. Kleene star in 11*0 applies only to the second 1; the mandatory initial 1 is what excludes 0 from s.

# GATE 1991: Q33 (printed A Q3(xiv))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D: regular

**Essential problem context (paraphrased):** For a finite language over a finite alphabet, choose strongest claim: possibly undecidable, TM-recognizable, context-sensitive, regular, none.

## Solution

Write the finite language as{w1, …, wk}. Each fixed word has a regular expression obtained by concatenating its symbols, and their finite union is a regular expression for the whole language. The empty language and words containing ε also fit the regular class. Hence it is regular, which already implies decidability and TM recognizability. Those weaker true classifications are not the strongest requested answer. The proof is existential: it does not claim that an arbitrary description of an unknown finite language makes its entire list immediately computable.

# GATE 1991: Q70 (printed B Q17(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Exactly the regular languages: finite workspace folds into finite control, giving a two-way finite automaton, and two-way finite automata recognize regular languages.

**Essential problem context (paraphrased):** Prove that Turing machines with a read-only input tape and constant-size work tape recognize exactly the regular languages. Use the standard single input-head model with endmarkers.

## Solution

For the easy direction, let L be regular and choose a DFA for L. A Turing machine stores the DFA state in its finite control, scans the read-only input from left to right, and accepts exactly when the simulated DFA ends in an accepting state. It needs no growing work tape, hence satisfies the constant-space requirement.

For the other direction, let the machine use at most c work cells, where c is independent of input length. If the work alphabet is Γ and the finite control has q states, the work contents and work-head location together have at most |Γ|^c·O(c) possibilities. Fold these possibilities into the control state. This gives a finite-state device whose only unbounded feature is the position of its single head on the read-only input. It is a two-way finite automaton, not immediately an ordinary one-way DFA: treating input-head position as a fixed finite state would be an error.

Here is why two-way motion does not add language power. For any finite input block, summarize its behavior by a finite relation recording which control state and side can enter the block and which control state and side can next exit it, together with whether acceptance can be reached before exit. There are finitely many such boundary-state combinations, so only finitely many possible block summaries, regardless of block length. Infinite internal loops yield no exit or acceptance in the summary.

The summary of a concatenation uv is determined solely by the summaries of u and v: connect their touching boundaries and compute reachability through the finite interface graph, allowing repeated crossings. Each symbol has its own summary. A one-way DFA can therefore read symbols from left to right, retaining the accumulated block summary as its state and updating it by this finite composition. With the endmarkers included, its accepting states are exactly the summaries allowing the original initial state to reach acceptance. This constructs a finite recognizer for the same language. For nondeterministic machines use existential reachability in the same summaries; a finite relation still suffices.

Thus the constant-workspace machine cannot recognize any nonregular language, and both containments establish equality. The standard assumptions exclude multiple independent input heads or writable unbounded input cells, which would invalidate this reduction.

# GATE 1991: Q71 (printed B Q17(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A four-state NFA suffices; the minimum DFA has exactly 8 states.

**Essential problem context (paraphrased):** Let L be the set of binary strings whose third symbol from the right is 1. Construct an NFA for L and justify the number of states in its minimized equivalent DFA.

## Solution

The language is {0,1}*1{0,1}{0,1}. An NFA can guess which 1 will be third from last, then require exactly two more symbols before acceptance. Use states q0,q1,q2,q3; q0 is initial and q3 is the only accepting state. Missing transitions go to the empty set.

Transition table:
State | on 0 | on 1
q0    | {q0} | {q0,q1}
q1    | {q2} | {q2}
q2    | {q3} | {q3}
q3    | {}   | {}

Equivalently, q0 has a loop labeled 0,1 and an additional edge labeled 1 to q1; q1→q2 and q2→q3 are labeled 0,1. A successful path stays at q0 through an arbitrary prefix, takes the guessing edge on a 1, and reads exactly two additional symbols. It ends in q3 precisely for the required strings.

For a DFA upper bound, store the most recent three bits, padding on the left with zeros before three bits have arrived. Use the eight states abc∈{0,1}^3, initial state 000, transition δ(abc,d)=bcd, and accepting states 100,101,110,111. After at least three inputs the first stored bit is exactly third from last; shorter strings remain nonaccepting because their padded first bit is zero. Every state is reachable by reading its three-bit label.

For minimality, take two different length-three strings x and y, differing at position r counted from the left, with 1≤r≤3. Append 0^{r−1} to both. In each resulting string, the third symbol from the right is precisely the old position r, so exactly one extension is accepted. Thus all eight three-bit strings have pairwise distinct right languages. By Myhill–Nerode, every DFA needs at least eight states. The construction meets this bound, proving that its minimized size is exactly 8.
