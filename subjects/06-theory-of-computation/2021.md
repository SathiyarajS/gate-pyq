

# GATE 2021 CS1: Q11 (printed CS Q1)

**Question:** [Official archived paper page 12](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=12); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

CFLs are closed under intersection with regular languages, concatenation with regular languages, and union with regular languages. They are not closed under complement, so choosing regular L1=Σ* makes L1−L2 the complement of a CFL, which need not be context-free. For a concrete witness, the complement of the non-context-free copy language {ww} is context-free; using that complement as L2 yields the non-CFL {ww}. Thus C.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

## Solution

DFA emptiness is decidable by reachability of an accepting state. DFA universality is decidable by complementing the complete DFA and checking emptiness. PDA emptiness is decidable, for example by converting to a CFG and marking productive nonterminals. Universality of a general nondeterministic PDA/CFG is undecidable, so only D is not recursive.

**Official answer:** A

**Derived answer:** A

## Solution

A computation limited to 2021 steps can inspect only finitely many input positions. Enumerate all finite relevant prefixes, including end-of-input cases, and simulate M for that fixed bound on each representative. Check whether all representatives run longer than2021 for L1, or at least one does for L2. Both procedures terminate, despite a very large finite enumeration. Therefore both languages are decidable, A.

# GATE 2021 CS1: Q61 (printed CS Q51)

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 50 to 50

**Derived answer:** 50

## Solution

The PDA first pushes its bottom marker, then pushes one A for each initial a. In the second phase it pops one A for each b. Reaching the final state requires an A still on top, so the language is a^m b^n with m>n>=0. For total length 100, n can be any integer from 0 through 49, with m=100-n. Each choice determines one string, giving 50. The accepting-state transition preserves that remaining A; acceptance is by final state rather than empty stack.

Complement a complete minimal DFA by exchanging accepting and nonaccepting states. Thus the complement language, C.

**Derived answer:** B; C; D

## Solution

Visually reading the overbars, B is the complement of (complement L1 union complement L2), hence L1 intersection L2, which is context-free. C contains L2 union complement L2 and equals the whole alphabet-star. D is (L1 intersection L2) union (complement L1 intersection L2), hence L2. A is L1 intersection complement L2; taking L1=Σ* shows that it need not be context-free, since CFLs are not closed under complement. Thus B, C, D.

# GATE 2021 CS2: Q46 (printed CS Q36)

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

Every infinite language over a finite alphabet is countably infinite and has uncountably many subsets, whereas only countably many algorithms, hence decidable languages, exist. At least one subset is therefore undecidable, proving S1. Every finite language has a regular expression formed by union of its finitely many words, proving S2. Thus C.

# GATE 2021 CS2: Q51 (printed CS Q41)

**Question:** [Official archived paper page 78](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=78); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B; C; D

**Derived answer:** B; C; D

## Solution

B concatenates two even-palindrome languages and is context-free. C is all binary strings, since w may be empty. D is exactly the even palindromes: wx x^R w^R=(wx)(wx)^R, and x may be empty. A is not context-free. Here is a pumping argument that accounts for empty w and x rather than merely calling the dependencies crossed. Its intersection with 0+1+0+1+ consists of 0^a 1^b0^c1^d satisfying either a=c and b-d is a nonnegative even integer, or b=d and c-a is a nonnegative even integer. This follows by examining where w and x split the first half: either w=0^a 1^k and x=1^d, or w=0^a and x=1^b0^k. The word 0^p1^p0^p1^p belongs. A pumping window of length at most p meets at most two adjacent blocks. Pumping a piece crossing a boundary creates extra runs when repeated. Otherwise pumping changes only those adjacent block lengths. If both change, use upward pumping for blocks1/2 or3/4 and downward pumping for blocks2/3 to violate both conditions. If only one changes, increase block1 or4, or decrease block2 or3. Every possible pumping decomposition thus has a failing exponent. Closure under regular intersection proves A is not context-free. Answer B, C, D.

# GATE 2021 CS2: Q57 (printed CS Q47)

**Question:** [Official archived paper page 84](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=84); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A; B; C

**Derived answer:** A; B; C

## Solution

Use the remainder automaton r→(2r+b) mod3, start/accept0. A describes concatenated excursions from 0: a 0 stays at 0, while1 enters remainder1, any number of blocks01*0 returns to 1 via remainder2, and final 1 returns to 0. B describes the same excursions by separating11 from 10(1+00)*01: at remainder2, either1 or00 loops back to 2, then01 exits to 0. C is equivalent to A because arbitrary concatenations of zeros and nonzero excursions can be grouped into runs of zeros followed by runs of excursions. D is wrong: it cannot generate1001 (binary9); every nonempty D word beginning1 begins11. Thus A, B, C. Leading zeros and the empty string are allowed as stated.
