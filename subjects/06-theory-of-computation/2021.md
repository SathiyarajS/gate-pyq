**Paraphrased problem context:** L1 is regular and L2 is context-free. Which language need NOT be context-free? A L1∩L2; B L1·L2 (concatenation); C L1−L2; D L1∪L2.

## Solution

CFLs are closed under intersection with regular languages, concatenation with regular languages, and union with regular languages. They are not closed under complement, so choosing regular L1=Σ* makes L1−L2 the complement of a CFL, which need not be context-free. For a concrete witness, the complement of the non-context-free copy language {ww} is context-free; using that complement as L2 yields the non-CFL {ww}. Thus C.

A simpler explicit counterexample to closure under difference uses Σ={a,b,c}. Define L2=Σ*\{a^n b^n c^n:n≥0}. This is context-free: strings outside a*b*c* form a regular language; inside that regular pattern, unequal a/b counts or unequal b/c counts form a union of CFLs, each checkable by a PDA. With regular L1=Σ*, L1−L2 is the standard non-CFL {a^n b^n c^n}. For A, run the DFA alongside the PDA; for B,D, use standard CFL concatenation/union constructions because regular languages are also CFLs.

**Paraphrased problem context:** For Σ={0,1} and automaton encoding ⟨M⟩, select the languages that are NOT recursive. A {⟨M⟩: M is a DFA and L(M)=∅}; B {⟨M⟩: M is a DFA and L(M)=Σ*}; C {⟨M⟩: M is a PDA and L(M)=∅}; D {⟨M⟩: M is a PDA and L(M)=Σ*}.

## Solution

DFA emptiness is decidable by reachability of an accepting state. DFA universality is decidable by complementing the complete DFA and checking emptiness. PDA emptiness is decidable, for example by converting to a CFG and marking productive nonterminals. Universality of a general nondeterministic PDA/CFG is undecidable, so only D is not recursive.

A recursive language has an algorithm that halts on both yes and no instances. For DFA universality, first ensure the transition function is total by adding a sink if necessary, then invert final/nonfinal states and run a finite reachability test. PDA emptiness asks whether some derivation produces a terminal string, which productive-variable marking decides. PDA universality is a known undecidable CFG universality problem; enumerating accepted strings cannot certify that no unaccepted string exists.

Label the four states by the longest suffix matching a prefix of 011: ε, 0, 01, 011. Their transitions on(0, 1) are respectively(0,ε),(0, 01),(0, 011),(0,ε). Only the 011 state accepts. The return arrows and loops were visually checked.

The invariant is that the state remembers the longest suffix of the input that is also a prefix of the target 011. After reading 0111 there is no nonempty suffix that is such a prefix, so the accepting state's 1-transition must return to q0. After reading 0110, the suffix 0 remains useful, so its 0-transition must go to q1. These two checks distinguish D from the three other diagrams while the invariant proves correctness for arbitrary input lengths.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** For Turing-machine encodings ⟨M⟩, L1={⟨M⟩: M takes more than 2021 steps on all inputs}, L2={⟨M⟩: M takes more than 2021 steps on some input}. Which is correct? A both decidable; B L1 decidable/L2 undecidable; C L1 undecidable/L2 decidable; D both undecidable.

## Solution

A computation limited to 2021 steps can inspect only finitely many input positions. Enumerate all finite relevant prefixes, including end-of-input cases, and simulate M for that fixed bound on each representative. Check whether all representatives run longer than2021 for L1, or at least one does for L2. Both procedures terminate, despite a very large finite enumeration. Therefore both languages are decidable, A.

This is bounded-time behavior, unlike the unbounded halting problem. In 2021 steps a standard single-tape input head can visit only a bounded initial portion of the input; choose a conservative prefix bound 2022 and include all shorter words and all words of that prefix length as representatives for longer inputs. Simulate each for exactly the fixed bound, detecting whether it halts within it. The enumeration is enormous but finite, which is sufficient for decidability; no practical polynomial-time claim is made.

**Paraphrased problem context:** A PDA has states q0,q1,q2,q3, start q0 and only final state q3, input {a,b} and stack alphabet {#,A}. Transition label input,pop→push is used, with ε meaning no input/pop/push. Transitions: q0→q1: ε,ε→#; q1 loop: a,ε→A; q1→q2: ε,ε→ε; q2 loop: b,A→ε; q2→q3: ε,A→A. There are no other transitions. How many length-100 strings are accepted by final state?

## Solution

The PDA first pushes its bottom marker, then pushes one A for each initial a. In the second phase it pops one A for each b. Reaching the final state requires an A still on top, so the language is a^m b^n with m>n>=0. For total length 100, n can be any integer from 0 through 49, with m=100-n. Each choice determines one string, giving 50. The accepting-state transition preserves that remaining A; acceptance is by final state rather than empty stack.

While reading a's, the stack contains one A per a above #. After switching to q2, each b removes one A and no a-transition exists, enforcing the order a* b*. The final ε-transition tests and preserves an A, requiring strictly more a's than b's. For length 100, m+n=100 and m>n give 100−n>n, so n<50. Each n=0,...,49 gives one word a^(100−n)b^n, including a^100; equality at n=50 is not accepted.

## Solution

Complement a complete minimal DFA by exchanging accepting and nonaccepting states. Reachability is unchanged, and every distinguishing suffix still distinguishes the same pair with acceptance reversed. Consequently no states merge and the minimal state count remains k. Thus the complement language, C.

For any states p,q distinguished in L by suffix w, exactly one of their w-runs ends accepting. Flipping all final-state flags preserves that exclusive difference, proving minimality rather than merely giving an upper bound of k states. Completeness matters: a missing transition must first be represented by a dead state before taking a DFA complement.

The relevant closure theorem is intersection of a CFL with a regular language, not intersection of two arbitrary CFLs. A product construction combines the CFL's PDA control with the regular DFA state without adding another stack. **Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** S1 every infinite regular language contains an undecidable subset. S2 every finite language is regular. A only S1; B only S2; C both; D neither.

## Solution

Every infinite language over a finite alphabet is countably infinite and has uncountably many subsets, whereas only countably many algorithms, hence decidable languages, exist. At least one subset is therefore undecidable, proving S1. Every finite language has a regular expression formed by union of its finitely many words, proving S2. Thus C.

The counting argument is nonconstructive: it proves an undecidable subset exists without requiring the regular language itself to encode a difficult membership test. For a finite language {w1,…,wm}, regex w1+…+wm recognizes it; the empty language is regular too. Being a subset of a decidable language does not imply decidability.

## Solution

B concatenates two even-palindrome languages and is context-free. C is all binary strings, since w may be empty. D is exactly the even palindromes: wx x^R w^R=(wx)(wx)^R, and x may be empty. A is not context-free. Here is a pumping argument that accounts for empty w and x rather than merely calling the dependencies crossed. Its intersection with 0+1+0+1+ consists of 0^a 1^b0^c1^d satisfying either a=c and b-d is a nonnegative even integer, or b=d and c-a is a nonnegative even integer. This follows by examining where w and x split the first half: either w=0^a 1^k and x=1^d, or w=0^a and x=1^b0^k. The word 0^p1^p0^p1^p belongs. A pumping window of length at most p meets at most two adjacent blocks. Pumping a piece crossing a boundary creates extra runs when repeated. Otherwise pumping changes only those adjacent block lengths. If both change, use upward pumping for blocks1/2 or3/4 and downward pumping for blocks2/3 to violate both conditions. If only one changes, increase block1 or4, or decrease block2 or3. Every possible pumping decomposition thus has a failing exponent. Closure under regular intersection proves A is not context-free. Answer B, C, D.

Constructive positive proofs: let E→0E0|1E1|ε generate even palindromes. For B use start H→EE, concatenating two such words. For C use H→0H|1H|ε, since taking w=ε yields arbitrary x. For D use E again, because the concatenated first half wx is arbitrary. These grammars establish membership instead of relying only on a visual impression of symmetry; A requires the non-CFL argument above.
