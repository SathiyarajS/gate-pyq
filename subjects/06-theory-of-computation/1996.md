

# GATE 1996: Q8 (printed A Q1.8)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C: (i) and (iii)

**Essential problem context (paraphrased):** Compare (i)(00)*(ε+0), (ii)(00)*, (iii)0*, and (iv)0(00)*. Which expressions are equivalent?

## Solution

Expression (00)* produces every even number of zeros, including zero. Appending either ε or one zero therefore produces every nonnegative length, exactly 0*. Expression (ii) alone excludes odd lengths; expression (iv) produces only odd lengths and excludes ε. Thus only (i) and (iii) describe the same language. Checking both ε and a one-symbol word already distinguishes the parity-restricted alternatives from the full unary language.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Essential problem context (paraphrased):** Select the false undecidability claim among TM halting, CFG ambiguity, CFG equivalence and regular-grammar equivalence.

## Solution

Regular grammars can be converted to finite automata. Determinize and complete the automata, form their product accepting the symmetric difference, and test whether any accepting product state is reachable. No reachable accepting state means the languages are equal. This is a terminating decision procedure, so saying regular-grammar equivalence is undecidable is false. TM halting, general CFG ambiguity and general CFG equivalence are undecidable problems. The finite-state restriction is what makes the fourth case different.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Essential problem context (paraphrased):** Which language over {a,b} is regular: (A) all words with equally many a and b symbols; (B) {a^n b^n:n≥1}; (C) all words with more a symbols than b symbols; (D) {a^m b^n:m≥1,n≥1}?

## Solution

The displayed language has no equality or inequality coupling the two block lengths. It is described by the regular expression aa*bb*: read at least one a, then at least one b. A finite automaton only needs to remember which block it is reading and reject a later a. In contrast, requiring equal block lengths or comparing their unbounded counts generally needs more than finite memory. Thus the unrestricted positive two-block choice D is regular; the independent quantifiers m,n are crucial.

**Independently derived answer:** B in GateForum; B and C in literal GFG

**Essential problem context (paraphrased):** For CFLs L1,L2 and regular R, which need not be context-free: concatenation, L1∩L2, L1∩R, or union?

## Solution

Context-free languages are closed under union and concatenation by introducing an appropriate new grammar start rule. They are also closed under intersection with a regular language, using a product of a PDA and a finite automaton. But take L1={a^n b^n c^m} and L2={a^m b^n c^n}, with nonnegative exponents. Each is context-free, while their intersection is {a^n b^n c^n}, which is not. Hence intersection of two arbitrary CFLs is the exceptional operation. GateForum choice C is L1∩R, so B is unique there. GFG instead repeats L1∩L2 in choice C, making both B and C valid answers to its literal options; this source discrepancy is retained.

# GATE 1996: Q34 (printed A Q2.9)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B: {0,1}*

**Essential problem context (paraphrased):** Let init(L)={u:uv∈L for some v}. If L is the set of nonempty binary words with equally many 0s and 1s, determine init(L).

## Solution

Take any binary word u. If it has more zeros than ones, append exactly enough ones to balance the counts; if it has more ones, append zeros instead. If its counts are already equal and u is nonempty, append ε; if u=ε, append 01 so the resulting balanced word is nonempty. In every case there exists a suffix v with uv∈L, so every binary word is in init(L). Conversely, every prefix of a binary word is binary. The two inclusions prove init(L)={0,1}*, without requiring the prefix itself to have balanced counts.

# GATE 1996: Q67 (printed B Q11)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** S→ABAC|BAC|AAC|ABC|AC|BC|d; A→aA|a; B→bB|b; C→d.

**Essential problem context (paraphrased):** Transform S→ABAC, A→aA|ε, B→bB|ε, C→d into an equivalent CFG with no ε-productions and no unit productions.

## Solution

The nullable nonterminals are A and B. C is not nullable because it must produce d; S is consequently not nullable. In S→ABAC, independently retain or omit each of the two occurrences of A and the one occurrence of B. The distinct right sides are ABAC, BAC, AAC, ABC, AC, BC and C. The side AC arises twice because either A can be the sole retained A, but duplicate productions need only be written once.

Removing A→ε and B→ε requires adding the terminating alternatives A→a and B→b: their old recursive rules could previously terminate by using the nullable final nonterminal. Keep A→aA|a and B→bB|b, so these variables now generate positive rather than arbitrary nonnegative repetitions. Keep C→d.

The only unit production introduced is S→C. Substitute C's nonunit right side to obtain S→d, then delete S→C. The resulting grammar is S→ABAC|BAC|AAC|ABC|AC|BC|d, A→aA|a, B→bB|b, C→d.

Every rule now has a nonempty right side; none has a sole nonterminal. The original language is {a^i b^j a^k d:i,j,k≥0}. The seven start alternatives cover exactly which of the three repetition blocks are empty, with the all-empty case producing d. Thus the transformation preserves the language, including the shortest word d.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Use start A, final states C,D; add A→C on ε, retaining every original transition.

**Essential problem context (paraphrased):** M1 has states A(start,final),B(nonfinal), with A→B and B→A on either 0 or 1. M2 has C(start,final),D(final),E(nonfinal): C loops on a, C→D on b, D loops on b, D→E on a, and E loops on a,b. Construct an ε-NFA recognizing L1L2 using no new states and only added ε-transitions.

## Solution

M1 accepts binary strings of even length: each 0 or 1 toggles A and B, and A is accepting. M2 accepts a*b*: it stays at C through a's, moves to D at the first b, and a later a leads to rejecting sink E. Both languages contain ε.

For concatenation, retain all original symbol-labelled edges and add A→C on ε, because A is the only accepting state of M1 and C is the initial state of M2. The combined machine has just one initial state, A. Its accepting states are C and D, the former accepting states of M2. A is no longer designated accepting, although ε is still accepted via the new ε-edge to C. B and E remain nonaccepting.

Any accepting run first follows a run of M1 ending at A, then uses the ε-edge and follows an accepting run in M2. The consumed string therefore factors as uv with u∈L1 and v∈L2. Conversely every such factorization gives an accepting run. This proves equivalence rather than just providing a diagram recipe.

Text diagram addition: A --ε--> C. Initial/final annotations must be updated as stated; “only add ε-transitions” refers to edges and state count, not to keeping two independent initial-state markings. No new states or symbol transitions are required.

# GATE 1996: Q69 (printed B Q12(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Add C→A and D→A on ε; keep start A and final states C,D.

**Essential problem context (paraphrased):** M1 has states A(start,final),B(nonfinal), with A→B and B→A on either 0 or 1. M2 has C(start,final),D(final),E(nonfinal): C loops on a, C→D on b, D loops on b, D→E on a, and E loops on a,b. Starting with the concatenation machine (start A, finals C,D, added ε-edge A→C), recognize (L1L2)* without new states.

## Solution

In the concatenation machine, reaching either C or D after consuming input means one complete L1L2 factor has been recognized. To permit another factor, add ε-edges from both accepting states back to the start A. Retain A→C and all original symbol edges. The complete added-edge set relative to the original two diagrams is A→C, C→A and D→A, all labelled ε.

An accepting run can now consist of any finite number of concatenation runs separated by the new return edges. Each segment consumes a word of L1L2; conversely a concatenation of such words is realized by joining their accepting runs through these ε-edges. Since L1 and L2 already contain ε, the start A can reach accepting C without consuming input, so the zero-factor case is accepted without adding a new accepting start state.

Keep C,D as final states. Making A final as well would also be harmless here because A already has an ε-path to a final state, but it is unnecessary. Adding only D→A would be insufficient as a general concatenation construction because C is also a valid final state, for example after a factor ending with only a's. ε-cycles cause no language-theoretic problem; an implementation computes finite ε-closures rather than following such cycles forever.

# GATE 1996: Q70 (printed B Q13)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** δ(q1,a,a)={(q1,aa),(q2,ε)}; δ(q1,b,b)={(q1,bb),(q2,ε)}. Also require δ(q1,a,b)={(q1,ba)} and δ(q1,b,a)={(q1,ab)}.

**Essential problem context (paraphrased):** A PDA with states q1,q2, alphabet {a,b}, stack alphabet {a,b,Z}, initial state q1 and stack Z accepts nonempty even palindromes by empty stack. Stack top is at the right. Given δ(q1,a,Z)={(q1,Za)}, δ(q1,b,Z)={(q1,Zb)}, δ(q2,a,a)={(q2,ε)}, δ(q2,b,b)={(q2,ε)}, δ(q2,ε,Z)={(q2,ε)}, fill the two alternatives in each of δ(q1,a,a) and δ(q1,b,b). Discuss whether the displayed list is sufficient.

## Solution

In state q1, the machine is guessing and storing the first half. On a matching input/top pair, it has two nondeterministic choices: push that input as another first-half symbol, or treat it as the first symbol of the reversed second half and pop the matching top while entering q2. Thus the displayed blanks are (q1,aa) and (q2,ε) for input a/top a, and (q1,bb) and (q2,ε) for input b/top b.

Those fillings alone do not recognize all even palindromes. Both reproductions omit the mixed push transitions δ(q1,a,b)={(q1,ba)} and δ(q1,b,a)={(q1,ab)}. With rightmost stack top, ba means retain b and push a. For example abba requires pushing b over a; it is rejected if the missing transitions are absent. This is a defect in the printed specification, not an additional blank that can be silently filled.

With these two additional rules, q1 pushes an arbitrary nonempty first half. It switches to q2 only while reading and popping a matching character, then q2 can only pop further matching characters. Finally it removes Z by ε. Acceptance requires both empty stack and exhausted input. The first symbol must be pushed, so the empty word cannot be accepted; each push corresponds to exactly one later matched input, enforcing even length. The accepted strings are exactly ww^R with nonempty w. No literal filling of just the four displayed blanks repairs the missing mixed cases.
