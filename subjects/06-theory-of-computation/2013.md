**Paraphrased problem context:** Let L1=∅ and L2={a}. Evaluate L1 L2* ∪ L1*. A{ε}; B∅; C a*; D{ε, a}.

## Solution

The concatenation of the empty language with any language is empty. Meanwhile ∅*={ε}. Therefore the displayed union is{ε}, A.

Teaching detail:
Language concatenation requires one word from each operand. Since L1 contains no word at all, L1 L2* contains none, irrespective of L2*. A Kleene star always includes the concatenation of zero words, namely ε. With an empty base language there are no positive-length concatenations, so L1* contains exactly ε. Taking the union of ∅ with{ε} yields{ε}; do not confuse ∅ with the singleton language containing the empty word.

**Paraphrased problem context:** Which statements are false?1 Every nondeterministic TM has an equivalent deterministic TM.2 Recognizable languages are closed under union and complement.3 Decidable languages are closed under intersection and complement.4 Recognizable languages are closed under union and intersection. A1, 4; B1, 3; C2 only; D3 only.

## Solution

Nondeterministic Turing machines can be simulated deterministically by dovetailing. Recognizable languages are closed under union and intersection by dovetailing recognizers, but not generally under complement. Decidable languages are closed under intersection and complement. Therefore only statement2 is false, C.

Teaching detail:
A deterministic simulator explores a nondeterministic computation tree fairly, preventing an infinite branch from starving an accepting finite branch; this establishes1. To recognize a union, interleave two recognizers and accept if either accepts. For intersection, interleave and accept after both have accepted, establishing4. A recognizer may run forever on a rejected input, so simply swapping accept/reject does not recognize its complement; statement2 is false. A decider always halts, so complementing its result and combining two runs both work, establishing3.

**Paraphrased problem context:** Let L1={0^p1^q0^r:p, q, r≥0} and L2={0^p1^q0^r:p, q, r≥0, p≠r}. Which is false? A L2 is context-free. B L1∩L2 is context-free. C complement(L2) is recursive. D complement(L1) is context-free but not regular.

## Solution

L1=0*1*0* is regular. L2, whose outer zero-block counts differ, is context-free: split into more leading zeros or more trailing zeros and use a pushdown comparison. Since L2⊆L1, their intersection is L2 and context-free. L2 is decidable by finite examination of the block counts (including the possible zero middle block), so its complement is recursive. The complement of regular L1 is regular and consequently context-free. Thus option D, which says this last complement is context-free but not regular, has a false not-regular clause. It is regular and therefore context-free; D is the requested false statement.

Teaching detail:
For the decisive option D, L1 is represented directly by 0*1*0*, hence is regular. Complement a complete DFA by swapping accepting and nonaccepting states; this proves its complement is regular as well. Being regular implies context-free, but it contradicts the extra words “not regular.” For L2, a pushdown machine can compare the first and final zero blocks when a nonempty middle1block separates them; the all-zero case can be treated separately. A finite input can also be tested by enumerating its finitely many possible block splits, giving decidability without needing a closed form.

**Paraphrased problem context:** A DFA starts in nonaccepting s; s--1→t and s--0→f. Nonaccepting t loops on1 and goes to f on0. Accepting f loops on0, 1. Which claims are false?1 complement of its language is context-free.2 its language has regex(11*0+0)(0+1)*0*1*.3 this three-state DFA is minimal.4 it accepts every binary string of length≥2. A1, 3; B2, 4; C2, 3; D3, 4.

## Solution

The accepting state is reached once a 0 occurs and then loops on both symbols. The language is all binary strings containing at least one0. Its complement is 1*, hence context-free. The given regular expression describes that same language: its leading component reaches a first 0 and the remaining factors allow arbitrary continuation. The two nonaccepting states have identical future acceptance behavior, so the three-state DFA is not minimal. It does not accept11. Thus statements1 and 2 are true and statements3 and 4 are false. The question asks for the false statements, so the pair3 and 4 gives option D.

Teaching detail:
Before the first0, the machine is in s or t; after the first0 it stays in accepting f forever. Thus its language is 1*0(0+1)*. The regex’s first factor(11*0+0) is precisely1*0, and its trailing0*1* can always be empty, so the expression describes the same language. States s and t accept exactly the same suffixes (those containing a0), hence can be merged. Finally11 is a length 2counterexample to claim4. Therefore claims3and4, and only those, are false.

**Paraphrased problem context:** Which problems are undecidable?1 CFG emptiness L(G)=∅;2 CFG universality L(G)=Σ*;3 regularity of the language of a TM;4 equality of a DFA language with an NFA language. A3 only; B3, 4; C1, 2, 3; D2, 3.

## Solution

Statement 1 is decidable: repeatedly mark CFG variables that can derive terminal strings; L(G) is nonempty exactly when the start variable becomes marked. Statement 2, universality of a general CFG (whether L(G)=Σ*), is undecidable. Statement 3 is undecidable by Rice’s theorem: regularity is a nontrivial property of the language recognized by a Turing machine, since some recognizable languages are regular and some are not. Statement 4 is decidable: determinize the NFA, form the product automaton for the symmetric difference with the DFA, and test whether any accepting product state is reachable. Thus only 2 and 3 are undecidable, option D.

Teaching detail:
Separate finite-state and general-machine questions. DFA/NFA equivalence remains decidable even if determinization is exponentially expensive: decidability requires termination, not efficiency. CFG emptiness is a finite fixed-point computation over its nonterminals. In contrast, general CFG universality is a standard undecidable property. TM language regularity is semantic and nontrivial, so Rice’s theorem applies; regular and nonregular recognizable languages both exist. These distinctions leave exactly 2and3.
