## Solution

Nondeterministic Turing machines can be simulated deterministically by dovetailing. Recognizable languages are closed under union and intersection by dovetailing recognizers, but not generally under complement. Decidable languages are closed under intersection and complement. Therefore only statement2 is false, C.

**Official answer:** D

**Derived answer:** D

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

## Solution

L1=0*1*0* is regular. L2, whose outer zero-block counts differ, is context-free: split into more leading zeros or more trailing zeros and use a pushdown comparison. Since L2⊆L1, their intersection is L2 and context-free. L2 is decidable by finite examination of the block counts (including the possible zero middle block), so its complement is recursive. The complement of regular L1 is regular and consequently context-free. Thus option D, which says this last complement is context-free but not regular, has a false not-regular clause. It is regular and therefore context-free; D is the requested false statement.

## Solution

The accepting state is reached once a 0 occurs and then loops on both symbols. The language is all binary strings containing at least one0. Its complement is 1*, hence context-free. The given regular expression describes that same language: its leading component reaches a first 0 and the remaining factors allow arbitrary continuation. The two nonaccepting states have identical future acceptance behavior, so the three-state DFA is not minimal. It does not accept11. Thus statements1 and 2 are true and statements3 and 4 are false. The question asks for the false statements, so the pair3 and 4 gives option D.

**Question:** [Official archived paper page 9](https://web.archive.org/web/20130418030400id_/http://www.gate.iitb.ac.in:80/gate2013/wp-content/uploads/2013/03/CS-A.pdf#page=9); consult original wording, diagrams and choices.

**Official answer:** D

**Derived answer:** D

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

## Solution

Statement 1 is decidable: repeatedly mark CFG variables that can derive terminal strings; L(G) is nonempty exactly when the start variable becomes marked. Statement 2, universality of a general CFG (whether L(G)=Σ*), is undecidable. Statement 3 is undecidable by Rice’s theorem: regularity is a nontrivial property of the language recognized by a Turing machine, since some recognizable languages are regular and some are not. Statement 4 is decidable: determinize the NFA, form the product automaton for the symmetric difference with the DFA, and test whether any accepting product state is reachable. Thus only 2 and 3 are undecidable, option D.
