**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203551/GATE2001.pdf#page=1), physical page 1. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Essential problem context (paraphrased):** Assess regularity of L1={0^(2n):n≥1} and L2={0^m1^n0^(m+n):m,n≥1}. Choices A/B/C/D assert only L1, only L2, both, or neither is regular.

## Solution

Step 1: S1 contains positive even-length strings of zeros, described by regular expression 00(00)*, so it is regular.

Step 2: Suppose S2 were regular with pumping length p. Choose 0^p1^p0^(2p). Any pumping segment in the first p symbols consists of k≥1 initial zeros. Pumping it out changes the first zero-block length to p−k while leaving the final zero block length 2p. That final block no longer equals the sum(p−k)+p. This contradicts the pumping lemma.

Therefore S2 is not regular and only S1 is correct, A.

**Essential problem context (paraphrased):** Which statement about context-free languages is true: every CFL has a deterministic PDA; CFLs are closed under union; CFLs are closed under intersection; or CFLs are closed under complement?

## Solution

Step 1: Given grammars with disjoint renamed nonterminals and start symbols S1,S2, introduce a fresh start S→S1|S2. This grammar generates their union, proving B.

Step 2: The CFLs {a^n b^n c^m} and {a^m b^n c^n} have intersection{a^n b^n c^n}, which is not context-free. Thus C is false. If CFLs were closed under complement, their union closure and De Morgan would imply intersection closure, so D also fails.

Finally deterministic PDA languages form a strict subclass of CFLs; an arbitrary CFL need not have a deterministic PDA. Hence A is false.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203551/GATE2001.pdf#page=1), physical page 1. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B for the tight worst-case bound

**Essential problem context (paraphrased):** For an N-state NFA, determine the maximum possible size of an equivalent minimized DFA. Listed expressions are N², 2^N, 2N, and N!. The reproduced wording uses “maximum … at least”; distinguish worst-case size from the size for every individual NFA.

## Solution

Step 1: Subset construction represents a DFA state by a subset of the N NFA states. There are at most 2^N such subsets, and minimization cannot increase that number.

Step 2: This bound can be attained when the alphabet is unrestricted. Start at q0, make q0 accepting, and include symbols that map q0 to each chosen subset S. Include test symbols b_i that map only q_i to q0 and all other states to the empty set. Every subset is reachable, and b_i distinguishes two subsets that differ in whether they contain q_i. Thus all 2^N subsets are inequivalent.

Conclusion: The maximum over N-state NFAs is 2^N, B. This is not a claim that every particular NFA requires 2^N states. The source phrase “maximum … at least” is imprecise; the tight worst-case reading is used.

**Essential problem context (paraphrased):** Find the minimum DFA size over {a,b} accepting exactly strings whose a-count is divisible by 6 and b-count by 8. Options: 8,14,15,48.

## Solution

Step 1: Store a pair(i,j), where i is the number of a symbols modulo 6 and j the number of b symbols modulo 8. Reading a increments only i; reading b increments only j. Accept(0,0). This constructs 6·8=48 states.

Step 2: Every pair is reached by a^i b^j. For two distinct pairs, append a number of a and b symbols that brings the first pair to(0,0). The second pair retains a nonzero difference in at least one residue and rejects. Thus all pairs are distinguishable.

The construction is minimal, giving 48, D, not the sum 6+8.

**Essential problem context (paraphrased):** Which languages are regular? L1={ww:w∈{a,b}*}; L2={ww^R:w∈{a,b}*}; L3={0^(2i)}; L4={0^(i²)}, interpreting valid nonnegative lengths. Choices: L1/L2; L2/L3/L4; L3/L4; only L3.

## Solution

Step 1: L3 contains even-length unary strings, recognized by a two-state parity machine. Interpreting only nonnegative string lengths, negative integer parameters do not add new words.

Step 2: L1={ww} is nonregular: prefixes a^n b are pairwise distinguishable, since suffix a^n b makes a square with that prefix but not with a^m b for m≠n. L2={ww^R} is nonregular: prefixes a^n b are distinguished by suffix b a^n; the resulting word a^m bb a^n is an even palindrome exactly when m=n.

Step 3: L4 has square unary lengths. For pumping length p, pump a nonempty segment of length k≤p in 0^(p²). Pumping once more gives length p²+k strictly between consecutive squares p² and(p+1)², contradiction.

Therefore only L3 is regular, D. The alternate reproduction accidentally labels its fourth formula L3 again; its position and options identify it as L4.

**Essential problem context (paraphrased):** Given a Turing machine M, input w, and state q, ask whether M’s computation on w ever visits q. Is this decidable, undecidable but partially decidable, not even partially decidable, or not a decision problem?

## Solution

Step 1: Simulate M on w and accept as soon as q is visited. Every yes instance is eventually accepted; a no instance may run forever. This proves partial decidability.

Step 2: Reduce the halting problem: construct a simulator that enters a fresh designated state q exactly when the simulated machine halts. A decider for state visitation would decide halting, impossible.

Hence X is undecidable but partially decidable, B. It is a decision problem because the required answer is yes/no, regardless of whether an algorithm always produces that answer.

**Essential problem context (paraphrased):** Alphabet {a,b}; accept precisely strings containing baab as a contiguous substring.

Task: Construct a DFA for this language.

## Solution

1. Use states to remember the longest suffix of the input read so far that is also a prefix of baab: q0 remembers ε, q1 remembers b, q2 remembers ba, and q3 remembers baa. q4 means the complete substring has already occurred.

2. From q0, a contributes no matching prefix and b starts one: δ(q0,a)=q0, δ(q0,b)=q1. From q1, a extends b to ba, while another b starts a fresh b: δ(q1,a)=q2, δ(q1,b)=q1.

3. From q2, a extends ba to baa; b leaves the suffix b. Thus δ(q2,a)=q3, δ(q2,b)=q1. From q3, b completes baab and a destroys every nonempty matching suffix: δ(q3,b)=q4, δ(q3,a)=q0.

4. Both transitions from q4 loop to q4, since later symbols cannot remove an occurrence already seen. Set start q0 and accepting set {q4}. The trace baab is q0→q1→q2→q3→q4; baa alone ends in nonaccepting q3.

**Essential problem context (paraphrased):** Alphabet {a,b}; accept strings with an odd number of a symbols and an odd number of b symbols.

Task: Construct a DFA for this language.

## Solution

1. Only the two parities matter, so use states (parity of a count, parity of b count). The empty string has counts zero and zero, making EE the start state.

2. Reading a increments only the a count and toggles its parity. Reading b toggles only the b parity. Complete transition table on (a,b): EE→(OE,EO); OE→(EE,OO); EO→(OO,EE); OO→(EO,OE).

3. Mark only OO accepting. By induction on the processed prefix, the stored pair equals its two actual count parities: the base is EE and every transition applies the correct single parity toggle.

4. Therefore a string is accepted exactly when both counts are odd. For instance ab ends in OO, whereas aab ends in EO and is rejected.

Task: Construct a deterministic PDA and specify its accepting state.

## Solution

1. Use stack alphabet {Z,X} with bottom marker Z, and states q0 (start), qA (a phase), qB (b phase), qF (sole accepting state). Stack top is written at the left. A transition (q,s,T)→(p,γ) consumes s and replaces top T by γ.

3. The first a is required to leave q0, enforcing n≥1. Each subsequent a replaces one X with three, a net push of two; after n a symbols there are exactly 2n markers. The unique c switches irreversibly to qB.

5. Determinism holds because qB has a b transition only with top X and an ε-transition only with top Z; no fixed state/top pair offers both an ε-transition and an input transition.

**Official answer:** Not available; no official key located.

**Independently derived answer:** X is undecidable.

**Essential problem context (paraphrased):** X asks whether a Turing machine M loops forever on input w. The halting problem H is assumed undecidable but partially decidable.

Task: Prove that X is undecidable.

## Solution

1. For a fixed valid encoding ⟨M,w⟩, exactly one possibility holds: M halts on w, or it runs forever. Thus X is the complement of H on valid encodings.

2. Assume a decider D for X exists. A decider always terminates and correctly answers both yes and no instances.

3. Construct a halting decider by running D on ⟨M,w⟩ and reversing its answer. If D says loops forever, answer does not halt; if D says does not loop forever, answer halts.

4. This new algorithm terminates on every input because D does, contradicting the assumed undecidability of H. Therefore no such D exists. Mere simulation does not refute this result: observing a halt is possible, but waiting forever is not a terminating negative test.

# GATE 2001: Q59 (printed B Q7(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203551/GATE2001.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** X is not partially decidable (not recursively enumerable).

**Essential problem context (paraphrased):** X asks whether a Turing machine M loops forever on input w. The halting problem H is assumed undecidable but partially decidable.

Task: Prove that X is not even partially decidable.

## Solution

1. Partial decidability means a recognizer must halt and accept every yes instance, but may run forever on no instances. Let R_H be the given recognizer for halting, and suppose a recognizer R_X for nonhalting also exists.

2. On the same encoding ⟨M,w⟩, dovetail the two recognizers: execute one step of R_H, then one step of R_X, repeatedly. Do not run either one to completion before starting the other.

3. If R_H accepts, answer halts; if R_X accepts, answer does not halt. Since H and X partition valid machine-input pairs, precisely the appropriate recognizer is guaranteed eventually to accept.

4. The combined computation therefore always terminates with a correct answer, deciding H. This contradicts undecidability. Hence X is not even partially decidable, although its complement H is.
