

# GATE 1999: Q4 (printed A Q1.4)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=1), physical page 1. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C for a complete DFA

**Essential problem context (paraphrased):** For the regular expression consisting of n concatenated factors (0+1), find the minimum finite-automaton states; choice C is n+2 and B is n+1.

## Solution

The language contains exactly the binary strings of length n. Use states 0 through n to record how many symbols have been read and a dead state for lengths above n. State n alone accepts; both symbols advance the count, and the dead state loops. This constructs n+2 states. For i<j≤n, a suffix of length n−j accepts from j but not i, so all progress states are distinguishable. The dead state is distinguishable from each by an appropriate accepting suffix. A partial automaton or NFA could omit that state and use n+1, giving B. The source says finite automaton without explicitly saying complete deterministic; C uses that conventional interpretation, rather than a universal minimum across all automaton models.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Essential problem context (paraphrased):** Which pair of operations preserves context-free languages: intersection/complement, union/Kleene star, or the other listed pairs?

## Solution

For union, introduce a fresh start symbol with alternatives leading to the two original start symbols. For Kleene star, introduce S→S_old S|ε, producing any finite concatenation of words from the original language. Thus union and star preserve context-freeness. Intersection does not: {a^i b^i c^j} intersected with {a^i b^j c^j} gives {a^n b^n c^n}. Closure under complement together with union would imply intersection closure by De Morgan, so complement closure also fails. Hence B.

**Independently derived answer:** A for nondeterministic PDAs

**Essential problem context (paraphrased):** Compare languages accepted by final state and by empty stack: equal classes, one proper inclusion, or incomparable?

## Solution

An empty-stack PDA can be turned into a final-state PDA by adding a protected bottom marker and moving to an accepting state when the original stack empties. Conversely, a final-state PDA can nondeterministically enter a stack-draining phase after reaching an accepting state; acceptance still requires consuming the whole input. These constructions preserve the recognized language and show equal classes, A. The statement is for unrestricted nondeterministic PDAs. Deterministic acceptance conventions have additional restrictions and cannot be substituted without qualification.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A,C

**Essential problem context (paraphrased):** L1 is context-free and L2 regular. Which claims are false in general: A L1−L2 is not context-free; B L1∩L2 is context-free; C complement L1 is context-free; D complement L2 is regular?

## Solution

Regular languages are closed under complement, and intersecting a CFL with a regular language preserves context-freeness using a PDA–DFA product. Thus L1−L2=L1∩complement(L2) is context-free, so A is false; B and D are true. CFLs are not closed under complement: otherwise their union closure plus De Morgan would imply intersection closure, contradicted by the standard a^n b^n c^n construction. Hence C is also false as a universal assertion. Some particular L1 do have context-free complements, so the conclusion is about closure, not every instance.

**Essential problem context (paraphrased):** Which constructs should be excluded to make the language’s halting function programmable: choices include arbitrary goto(v),recursive calls(vii),and repeat loops(viii), together in B? Remaining constructs are assignment,bounded for,if,forward goto,and nonrecursive calls.

## Solution

Exclude arbitrary backward jumps, unrestricted recursion and unbounded repeat loops. The remaining for loops have fixed finite bounds whose control variable cannot be changed in the body; forward jumps cannot create cycles; and a finite acyclic nonrecursive call structure terminates. Structural induction on these constructs therefore proves every valid program halts. Its halting predicate is simply the constant true function, expressible in the language. This establishes the intended sufficient restriction B. The argument assumes finite evaluated bounds and ordinary bounded-for semantics, not changing loop limits or hidden nonterminating primitives.

# GATE 1999: Q60 (printed B Q6(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** No: take A={0,1}* and B={0ⁿ1ⁿ:n≥0}.

**Essential problem context (paraphrased):** Given that language A is regular and A∪B is regular, must B be regular? Justify.

## Solution

Let the alphabet be {0,1}. Choose A={0,1}*, a regular language, and B={0ⁿ1ⁿ:n≥0}, which is not regular. Because B⊆A, the union A∪B equals A and is regular.

For completeness, B is nonregular by the pumping lemma: for pumping length p, any allowed pumped substring in 0ᵖ1ᵖ lies among the initial p zeros, and pumping it down changes the number of zeros without changing the p ones. The resulting word is not in B.

Closure under difference only proves (A∪B)\A=B\A is regular. It gives no control over the possibly nonregular part B∩A. This is precisely why reversing union closure fails.

# GATE 1999: Q61 (printed B Q6(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 3 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Require L(M₁)\L(M₂)=∅ and L(M₂)\L(M₁)≠∅.

**Essential problem context (paraphrased):** Given finite automata M₁ and M₂, outline an algorithm to decide L(M₁)⊊L(M₂). The prose explicitly says strict subset even though a reproduced symbol permits equality.

## Solution

1. Put the automata over the same alphabet Σ, taking the union of their alphabets if needed. Determinize any NFAs and complete both resulting DFAs with sink states for missing transitions. This makes complementing acceptance correct.

2. Explore the product states (q₁,q₂) from the initial pair, with δ((q₁,q₂),a)=(δ₁(q₁,a),δ₂(q₂,a)). A reachable pair with q₁ accepting and q₂ rejecting witnesses a word in L(M₁)\L(M₂). If such a pair exists, answer NO.

3. Also look for a reachable pair with q₂ accepting and q₁ rejecting. If none exists, the languages are equal, so strict inclusion is false. If one exists while the first kind does not, answer YES.

4. Breadth-first or depth-first search suffices because a finite automaton language is nonempty exactly when an accepting state is reachable. On complete DFAs the search takes O(|Σ||Q₁||Q₂|) time; determinization can add exponential cost for NFA input. Both tests are necessary: ordinary inclusion alone incorrectly accepts equal languages.

# GATE 1999: Q62 (printed B Q7)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A context-free pumping-lemma argument on 0ᵖ1ᵖc0ᵖ1ᵖ yields a contradiction.

**Essential problem context (paraphrased):** Prove L={xcx:x∈{0,1}*} is not context-free, where c is a terminal different from 0 and 1.

## Solution

Suppose L were context-free and let p be its pumping length. Choose w=0ᵖ1ᵖc0ᵖ1ᵖ∈L. For any pumping decomposition w=uvxyz, the lemma requires |vxy|≤p, |vy|>0, and uvⁱxyⁱz∈L for every i≥0. We show pumping down (i=0) always fails.

If v or y contains c, removing v and y removes the unique separator. The result cannot be in L.

Otherwise c is not pumped. If vxy lies entirely on one side of c, pumping down shortens only that copy. The two sides have unequal lengths, so cannot be equal.

The remaining case is that vxy spans c, with c inside the unpumped substring x. Because |vxy|≤p, everything it can reach to the left of c is in the first block of ones, and everything to the right is in the second block of zeros: it cannot reach the first zeros or the final ones, each separated by a whole length-p block. Thus v=1ᵃ and y=0ᵇ, allowing a or b to be zero, but a+b>0. Pumping down leaves 0ᵖ1^(p−a)c0^(p−b)1ᵖ. Equality of the two copies would force both a=0 (compare ones) and b=0 (compare zeros), contrary to |vy|>0.

Every allowable decomposition fails the lemma, so L is not context-free. The argument relies on a genuine copy xc x, not the context-free reversed-copy language xc xᴿ.

# GATE 1999: Q65 (printed B Q10(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Under the hypothetical HALTS assumption, both selected branches terminate.

**Essential problem context (paraphrased):** Assume a total, correct procedure HALTS(f,x) reports whether f(x) terminates. Define FUNNY(f)=IF HALTS(f,f) THEN NOT(f(f)) ELSE TRUE. Show FUNNY terminates for every f.

## Solution

Interpret f as a program that can be supplied its own description as input; for the NOT expression restrict attention to programs returning Boolean values when they halt. This restricted class already suffices for the impossibility proof.

HALTS(f,f) terminates by the assumed totality of the decision procedure. If it returns FALSE, FUNNY immediately returns TRUE without running the nonterminating f(f). If it returns TRUE, its correctness guarantees that f(f) terminates. Evaluating that result and applying Boolean NOT therefore also terminates.

Thus for every such input program f, FUNNY(f) terminates and returns a Boolean. This is a conclusion conditional on the assumed existence of HALTS, not an independently implementable algorithm. Short-circuit branch selection is essential: the unselected branch must not evaluate f(f).

# GATE 1999: Q66 (printed B Q10(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 3 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** FUNNY(FUNNY) would return the negation of its own Boolean result.

**Essential problem context (paraphrased):** Assume a total, correct procedure HALTS(f,x) reports whether f(x) terminates. Define FUNNY(f)=IF HALTS(f,f) THEN NOT(f(f)) ELSE TRUE. Use termination of FUNNY to prove by contradiction that no such total correct HALTS exists.

## Solution

Assume HALTS exists as a computable, always-terminating correct decision procedure. Then the definition constructs a computable FUNNY, and part (a) shows that FUNNY terminates on every program description, including its own. Consequently HALTS(FUNNY,FUNNY) must return TRUE.

Let b be the Boolean returned by FUNNY(FUNNY). Following its definition and the TRUE answer, the same call must return NOT(FUNNY(FUNNY)), namely NOT b. This implies b=NOT b. Neither Boolean value satisfies this equation: TRUE would have to be FALSE and FALSE would have to be TRUE.

There is also an operational view: the TRUE branch invokes the identical FUNNY(FUNNY) call again before it can negate the result, producing unending recursion, contradicting the termination guaranteed by part (a). Either explanation refutes the initial assumption. Therefore no algorithm decides halting for arbitrary programs and inputs. Assuming a function can accept its own encoded description is standard for general-purpose programs; restricting output to Booleans does not avoid the contradiction.
