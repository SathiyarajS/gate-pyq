**Paraphrased problem context:** Which pair of computational models has DIFFERENT expressive power?

(A) DFA and NFA
(B) Deterministic PDA and nondeterministic PDA
(C) Deterministic single-tape Turing machine and nondeterministic single-tape Turing machine
(D) Single-tape and multitape Turing machines

## Solution

DFA and NFA recognize exactly the regular languages. Deterministic/nondeterministic and single/multitape Turing machines recognize the same class, though their efficiencies can differ. DPDAs recognize only deterministic CFLs, a proper subclass of the CFLs recognized by NPDAs. Hence B.

Expressive power asks which languages can be recognized, not how many states are needed or how fast a simulation runs. Subset construction turns an NFA into a DFA, possibly increasing its size. Turing machines can simulate nondeterministic branches by systematic exploration and can simulate extra tapes. A single stack plus deterministic choices is more restrictive: some context-free languages require the nondeterministic choice of how to parse or where to change phases.

**Paraphrased problem context:** P is regular and Q is context-free with Q a subset of P. For example, P=p*q* and Q={p^n q^n : n is natural}. Which language is ALWAYS regular, over alphabet Σ?

(A) P intersect Q
(B) P minus Q
(C) Σ* minus P
(D) Σ* minus Q

## Solution

Regular languages are closed under complement, so Σ*−P is always regular. P∩Q=Q may be nonregular. If P−Q were always regular, Q=P−(P−Q) would always be regular, a contradiction; likewise regularity of Σ*−Q would imply regularity of Q. Therefore only C is guaranteed.

A counterexample is permitted because the question asks what is guaranteed for all P,Q. Choose P=0*1* and Q={0^n1^n}. Then P∩Q=Q is nonregular. If P−Q were regular, subtracting it from regular P would recover nonregular Q, contradicting closure of regular languages under difference. If the complement of Q were regular, complementing again would make Q regular. In contrast, a complete DFA for P can always have its accepting and rejecting states swapped to recognize its complement.

**Paraphrased problem context:** Let L1={0^p1^q : p,q in N}, L2={0^p1^q : p=q in N}, and L3={0^p1^q0^r : p=q=r in N}. Which statement is NOT TRUE?

(A) A PDA can recognize L1 and L2
(B) L1 is regular
(C) All three languages are context-free
(D) Turing machines can recognize all three languages

## Solution

L1=0*1* is regular and hence recognizable by a PDA; L2 matches two block lengths and is context-free. L3={0^n1^n0^n} is not context-free: for pumping length p, choose0^p1^p0^p. A pumping window of length≤p cannot reach both outer zero blocks. Pumping a nonempty part therefore changes at most two blocks while leaving another unchanged, or destroys the block order, so equality of all three counts fails. All three are decidable by a Turing machine. Thus the claim that all three are context-free is false, C.

A PDA for L2 pushes one marker per initial 0 and pops one per following 1, rejecting if lengths differ or block order is wrong. L1 does not even need the stack. L3 requires coordinating three unbounded block lengths, and the pumping argument establishes the failure of context-freeness rather than merely asserting that a particular PDA design fails. A Turing machine can repeatedly mark one symbol in each block, so the failure is specific to context-free recognition, not computability.

**Paraphrased problem context:** Over alphabet {a}, let L={a^(nk): k>0}, where n is a fixed positive integer. What is the minimum number of states in a DFA recognizing L?

(A) k+1
(B) n+1
(C) 2^(n+1)
(D) 2^(k+1)

## Solution

The language is {a^(nk): k>0}, where n is a fixed positive integer; epsilon is excluded. Use a separate nonaccepting start state, then an n-state cycle that records the positive input length modulo n, accepting the residue-zero state. This uses n+1 states. For minimality, the n positive residue classes are pairwise distinguishable by an extension that makes exactly one length divisible by n. The empty prefix is distinguished from a positive multiple of n by the empty suffix, and from each other positive residue by a suffix that completes that residue to a multiple of n. Thus all n+1 classes are necessary, option B.

An explicit construction uses start z and cycle states r0,...,r(n-1). The first a moves z to r(1 mod n); each subsequent a advances the residue by one modulo n; only r0 is accepting. z must reject epsilon whereas r0 accepts it, so the usual n-state modulo counter cannot merge these two states. For n=1 the result is two states, recognizing a+ rather than a*, which also checks the boundary case.

**Paraphrased problem context:** DFA D has alphabet {a,b}, start p, accepting states s,t, and transitions p:a→s,b→q; q:a→t,b→r; r:a,b→r; s:a,b→s; t:a,b→t. Which supplied machine is an equivalent minimal DFA? Unlisted states in the alternatives are nonaccepting.

(A) Start p; final s; p:a→s,b→q; q:a→s,b→r; r:a,b→r; s:a,b→s
(B) Start p; finals q,r; p:a,b→q; q:a→r,b→s; r:a,b→r; s:a,b→s
(C) Start p; final q; p:a,b→q; q:a,b→q and also q:b→r; r:a,b→r
(D) Start p; final s; p:a→s,b→q; q:a→s,b→q; s:a,b→s

## Solution

The accepting states s and t both loop on a and b, so their right languages are identical and they merge. The other states p, q and r remain distinct: p versus q is distinguished by suffix ba, since p accepts ba while q reaches the dead state; q versus r is distinguished by a; p versus r is also distinguished by a. Any accepting state differs from these nonaccepting states on epsilon. All four resulting classes are reachable. The minimal DFA has classes {p}, {q}, {r}, {s, t}, with p --b--> q --b--> r, r a/b-loops, and a-transitions from p and q to the accepting sink. This is option A.

All five original states are reachable: epsilon reaches p, b reaches q, bb reaches r, a reaches s, and ba reaches t. Initially separate accepting {s,t} from rejecting {p,q,r}; r differs because its a-transition stays rejecting, and then p differs from q because their b-transitions lead to different classes. Alternative B wrongly accepts b, C has two b-transitions from q and is not deterministic, and D accepts bba although the original reaches r on bb and must reject every continuation.
