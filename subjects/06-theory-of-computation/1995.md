

# GATE 1995: Q9 (printed A Q1.9)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=1), physical page 1. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B: L(L∪D)*

**Essential problem context (paraphrased):** An identifier is one letter followed by zero or more letters or digits. With letter set L and digit set D, choose its expression.

## Solution

The initial L enforces exactly one initial letter. Every subsequent character may independently be a letter or digit, represented by L∪D, and the star allows zero or more such characters. Thus a one-letter identifier is allowed, but an empty identifier or one beginning with a digit is not. Expressions that star an alternating letter-digit pair impose an unjustified pattern, while starring or plussing L∪D alone permits a digit first. The concatenation L(L∪D)* captures precisely the requirement.

# GATE 1995: Q45 (printed A Q2.20)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A: I only

**Essential problem context (paraphrased):** For L={x^n y^n:n≥1}, compare I E→xEy|xy; II xy | x⁺xyy⁺; III x⁺y⁺. Which define L?

## Solution

Grammar I starts with xy and each recursive wrapping adds one x to the front and one y to the end. It therefore generates exactly equal positive block counts. Expression III permits unequal counts, for example xyy. Expression II permits independently sized positive runs before its extra x and after its first y; for example xxyyy is accepted but has unequal counts. Hence neither regular expression enforces equality. Only I defines L, in agreement with the fact that the equal-count language is not regular.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C: regular,nonregular

**Essential problem context (paraphrased):** Let Σ={0,1}, L=Σ*, R={0^n1^n:n>0}. Classify L∪R and R as regular or nonregular.

## Solution

Every member of R is a binary word, so R⊆Σ*=L. Hence L∪R=L, which is regular. R itself is nonregular: if its pumping length were p, the word 0^p1^p would have a pumpable nonempty segment entirely among its first p zeros. Pumping that segment changes the number of zeros but not ones, leaving R and contradicting the lemma. Thus adjoining R to a universal regular language does not make the union nonregular.

# GATE 1995: Q61 (printed B Q9(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A useful/productive cycle is incompatible with LL(1); the unrestricted claim needs a reduced-grammar assumption.

**Essential problem context (paraphrased):** A grammar has a cycle if A⇒⁺A for some nonterminal A. Show that a grammar with cycles cannot be LL(1), stating any necessary qualification.

## Solution

Assume the cyclic nonterminal A is reachable in a successful derivation and can derive a terminal string w (possibly ε). Starting at A, one may derive w directly, or first traverse the nonempty cycle A⇒⁺A and then derive the same w. Inserting the cycle into a successful start-symbol derivation gives two distinct parse trees for the same terminal string. Every LL(1) grammar is unambiguous, so this useful cyclic grammar cannot be LL(1).

Operationally, a predictive parser cannot decide from the same next input symbol whether to begin another traversal of a nullable cycle or leave it to produce the terminal string. The proof concerns a cycle deriving A itself, not ordinary right recursion such as A→aA, which consumes input and can be LL(1).

The statement as printed omits the usual reduced-grammar qualification. As a literal counterexample, S→a with an unreachable rule A→A generates only a and has a conflict-free predictive table for all successful parses from S; the unreachable cycle contributes no competing table entry. A nonproductive cycle likewise cannot be inserted in a successful parse. Thus the intended theorem is valid for reduced grammars, or for cycles on useful nonterminals, rather than arbitrary added useless rules.

# GATE 1995: Q64 (printed B Q11)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** For x, certify a different same-length y∈L using its NP witness.

**Essential problem context (paraphrased):** L⊆Σ* is in NP and contains exactly one string of each length n. Prove its complement is in NP.

## Solution

Since L is in NP, there is a polynomial-time verifier V(y,c) and a polynomial bound on certificates c such that y∈L exactly when some c makes V accept. To verify that x is in the complement, guess a pair (y,c), require |y|=|x| and y≠x, and run V(y,c). Accept precisely when all checks pass.

Completeness: if x∉L, the hypothesis guarantees a string y∈L of length |x|. It cannot equal x, and it has an accepting NP certificate, so the new verifier has an accepting guess. Soundness: if x∈L, uniqueness says no different same-length y lies in L. Therefore no proposed pair can pass all checks.

The guessed y has length n, its certificate has polynomial length in n, and both comparison and verification take polynomial time. This proves the complement is in NP without assuming NP=coNP. Both parts of “exactly one” matter: existence supplies a witness on complement instances, while uniqueness prevents false acceptance on member instances. At length zero the only word is ε, which is in L, and no different same-length word exists, so rejection is correct.
