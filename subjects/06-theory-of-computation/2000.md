**Independently derived answer:** C

**Essential problem context (paraphrased):** Let S=(a+b*)* and T=(a+b)* over {a,b}. Are S and T in a proper-subset relation, equal, or disjoint?

## Solution

Step 1: Every block allowed inside S is either a or a finite run of b symbols. Concatenating such blocks can produce every word over {a,b}, since individual a and b symbols are both available.

Step 2: No other symbol can appear, so S⊆{a,b}*. The expression T also generates exactly {a,b}*, including ε.

Hence S=T, option C. The inner star on b does not restrict the outer star’s ability to concatenate individual symbols.

**Independently derived answer:** B

**Essential problem context (paraphrased):** For grammar S→0S0|00, decide whether L is 0+, regular but not 0+, context-free but not regular, or not context-free.

## Solution

Step 1: The base production yields two zeros. Each use of 0S0 adds exactly two more, so every generated word has positive even length. Conversely, applying the recursive rule k times generates 0^(2k+2).

Step 2: Therefore L={0^(2m):m≥1}=00(00)*, a regular language. It excludes the one-symbol string 0, which belongs to 0+.

Thus B. A recursive-looking grammar does not imply a nonregular language.

**Essential problem context (paraphrased):** A unary regular language has a minimal two-state automaton. Must it be the odd-length language,the even-length language,a*,or one of the two parity languages?

## Solution

Step 1: Consider L=a+, the nonempty unary strings. A minimal complete DFA has a nonaccepting start state that transitions on a to an accepting state with an a self-loop. The two states are distinguishable by ε.

Step 2: This L contains both odd and positive even lengths but excludes ε, so it is neither parity language nor a*. It satisfies the two-state premise and refutes all four mandatory claims.

If the two reachable states were additionally required to form a cycle, exactly one would accept in a minimal two-state DFA, yielding parity and option D. The source does not state that restriction. Strong connectivity cannot be assumed from minimality.

# GATE 2000: Q32 (printed A Q2.9)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203732/GATE2000_compressed-1.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Essential problem context (paraphrased):** Decide whether P1,finite-state-machine acceptance of a given string,and P2,infiniteness of a CFG language,are decidable. Options: both,neither,only P1,only P2.

## Solution

Step 1: For P1, simulate the finite automaton on the finite input, tracking a set of states if it is nondeterministic, then inspect acceptance. This always terminates.

Step 2: For P2, convert the productive nonempty-word portion of the grammar to Chomsky normal form with m variables. Any parse tree without a repeated variable along a root-to-leaf path has bounded height and hence bounded word length. A sufficiently long word forces a repeat and pumping to infinitely many lengths.

One can effectively test whether the CFG generates a word exceeding that finite bound by intersection with the regular language of longer words and then CFG emptiness. Hence infiniteness is decidable too, giving A.

# GATE 2000: Q57 (printed B Q7(a))

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Complete minimal DFA has four states: start, last-0, last-1, dead.

**Essential problem context (paraphrased):** Alphabet {0,1}; accept exactly the strings containing neither 00 nor 11 as a substring.

Task: Construct a minimal finite-state machine.

## Solution

1. Use states s (no symbol yet), z (valid prefix ending 0), o (valid prefix ending 1), and d (a forbidden equal adjacent pair has occurred). Start at s; accepting states are s,z,o, so ε is accepted.

2. Complete transition table, entries in input order 0,1: s→(z,o); z→(d,o); o→(z,d); d→(d,d). This is also a complete text specification of the requested machine.

3. Induction on the processed prefix proves the state invariant. Alternating bits move between z and o; a repeated bit enters d permanently. Thus precisely the required language is recognized.

4. All four states are reachable using ε,0,1,00. Dead d is distinguished from every accepting state by suffix ε. States s and z are distinguished by suffix 0, s and o by suffix 1, and z and o by suffix 0. Therefore no pair can merge and four states are minimal for a complete DFA. A partial drawing may omit the explicit dead state, but that is not a three-state complete DFA.

**Independently derived answer:** (i,j)=(0,0), or i≥1 and j≥i.

**Essential problem context (paraphrased):** Grammar S→aSAb | ε and A→bA | ε, with start S, generates strings aⁱbʲ, i,j≥0.

Task: Determine the exact condition on i,j.

## Solution

1. Every application of S→aSAb adds one a at the front and one mandatory b at the end, with an A that can generate any additional number of b symbols.

2. After i recursive applications and S→ε, the form is aⁱ(Ab)ⁱ. Thus j=i+k₁+⋯+kᵢ for arbitrary nonnegative integers k₁,…,kᵢ.

3. If i≥1, this gives j≥i. Every such j is attainable by assigning j−i extra b symbols to one A and zero to all the others.

4. If i=0, S goes directly to ε and there are no A symbols, so j must also be zero. The looser answer j≥i incorrectly includes nonempty strings consisting only of b.

**Official answer:** Not available; no official key located.

**Independently derived answer:** Add q₀→q₀: 0,s/0s and q₁→q₁: 0,0s/s. Exact formal acceptance requires the caveat below.

**Essential problem context (paraphrased):** Two states q₀ (initial) and q₁. Existing edges: q₀→q₀ labeled 1,s/1s; q₀→q₁ labeled 2,s/s; q₁→q₁ labeled 1,1s/s. A label d,u/v consumes d and replaces entire stack u by v; s denotes the arbitrary remainder, top at left. Target L={x2xᴿ:x∈{0,1}*}.

Task: Add two appropriately labeled edges to accept L by empty stack.

## Solution

1. The missing push edge is a q₀ self-loop labeled 0,s/0s. The missing matching-pop edge is a q₁ self-loop labeled 0,0s/s. Together with the existing 1 loops these handle both symbols.

2. Before the delimiter, q₀ pushes every input symbol. The sole 2 edge enters q₁ without changing the stack. After it, each input bit must match the top bit and pops it; mismatches have no move.

3. For x=01, the successive configurations are (q₀,01210,ε)→(q₀,1210,0)→(q₀,210,10)→(q₁,10,10)→(q₁,0,0)→(q₁,ε,ε). Thus the intended accepting condition is exhausted input, empty stack, and completed delimiter transition into q₁.

4. Formal defect: under ordinary acceptance by empty stack in ANY state, an initially empty stack accepts ε immediately, although ε∉L. The two requested edges cannot undo this existing accepting run. An initial bottom marker does not alone solve it: none of the displayed or added transitions removes that marker.

5. To formalize the intended construction, require q₁ together with empty stack at input end; alternatively start with bottom marker Z and additionally permit q₁→q₁ labeled ε,Z/ε. The latter is a third added edge and therefore exceeds the literal two-edge request. We report the intended pair without claiming it repairs the original formal specification.

# GATE 2000: Q60 (printed B Q8(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203732/GATE2000_compressed-1.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Push one X per 0; nondeterministically consume either one or two 1s per X using three states.

**Essential problem context (paraphrased):** Target L={0ⁿ1ᵐ:n≤m≤2n}, with n,m nonnegative. Use labels d,u/v to consume d and replace entire stack u by v; stack top is at left.

Task: Describe a nondeterministic three-state PDA accepting by empty stack.

## Solution

1. Use states p (initial zero-reading phase), q (one-reading phase), r (one more 1 required for the current X). Start with empty stack. Edges: p→p: 0,s/Xs; p→q: ε,s/s; q→q: 1,Xs/s; q→r: 1,Xs/Xs; r→q: 1,Xs/s. There are no other edges. Accept only when all input is consumed and the stack is empty, in any state.

2. The zero phase pushes n copies of X. After the ε transition to q, no transition reads a zero, so every accepted word has form 0ⁿ1ᵐ.

3. For each X, q may consume one 1 and pop immediately, or consume one 1 without popping, enter r, and require a second 1 to pop and return to q. State r cannot have an empty stack because its entry edge requires and retains an X.

4. If k of the n markers use the two-symbol option, total ones are m=n+k with 0≤k≤n. Conversely any m in [n,2n] is realized by selecting k=m−n markers for that option.

5. The empty word is correctly accepted for n=m=0. A nonempty all-zero word leaves markers, a leading 1 has no applicable pop, and extra 1s cannot be read after the last marker disappears. This verifies the boundary cases without a bottom-marker convention.
