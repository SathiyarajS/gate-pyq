**Paraphrased problem context:** Which decision problem is undecidable?
Options:
(A) Membership for context-free grammars
(B) Ambiguity for context-free grammars
(C) Finiteness for finite-state automata
(D) Equivalence for finite-state automata

## Solution

1. Approach. Distinguish a property of a particular input string from a property of all derivations of a grammar. Parsing decides membership; finite automata allow finite graph algorithms.

2. Derivation and interpretation. CFG membership is decidable by parsing. Finite-automaton finiteness is decided by useful-cycle detection, and equivalence by symmetric-difference reachability. Ambiguity of an arbitrary CFG is undecidable, so B.

# GATE 2007: Q7 (printed CS Q7)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 3. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** Which statement about regular languages is true?
Options:
(A) Every subset of a regular set is regular
(B) Every finite subset of a nonregular set is regular
(C) The union of two nonregular sets is nonregular
(D) An infinite union of finite sets is regular

## Solution

1. Approach. A finite language is described by a finite union of its individual words. Closure under finite union does not imply closure under an arbitrary infinite union.

2. Derivation and interpretation. Every finite language is regular, regardless of the parent set, so B. A fails because nonregular languages are subsets ofΣ*. C fails by taking a nonregular language and its nonregular complement, whose union is Σ*. D fails because any nonregular language is an infinite union of singleton finite languages.

**Independently derived answer:** A

**Paraphrased problem context:** What is the number of states in a minimum DFA for L={w∈{0,1}*: the number of 0s is divisible by 3 and the number of 1s is divisible by 5}?
Options:
(A) 15
(B) 11
(C) 10
(D) 9

## Solution

1. Approach. Use a product state (i,j) recording the two remainders. On 0 update i modulo 3; on 1 update j modulo 5. Minimality requires distinguishability, not merely constructing a 15-state DFA.

2. Derivation and interpretation. Track the number of zeros modulo 3 and ones modulo 5, giving 3×5=15 states; accept residue (0,0). Every residue pair is reachable. Any two different pairs are distinguished by appending zeros and ones that bring one pair to (0,0), leaving the other nonzero in at least one coordinate. Thus 15 states are necessary and sufficient, A.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** Classify L={0^i 2 1^i:i≥0} over alphabet {0,1,2}.
Options:
(A) Not recursive
(B) Recursive and deterministic context-free
(C) Regular
(D) Context-free but not deterministic context-free

## Solution

1. Approach. The marker 2 identifies exactly when to switch from pushing zeros to matching ones. Unlike an unmarked palindrome, there is no need to guess the midpoint.

2. Derivation and interpretation. A deterministic PDA pushes for each initial 0, switches phase at the unique marker 2, and pops once per 1, accepting exactly when the counts match and input ends. Membership is also decidable. The language is not regular because matching unbounded block lengths requires memory. Hence it is recursive and deterministic context-free, B, including the string 2 for i=0.

# GATE 2007: Q31 (printed CS Q31)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 7. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Which language is regular? In all options w and x are nonempty binary strings, w^R is the reversal of w, and Σ={0,1}.
Options:
(A) {ww^R:w∈Σ+}
(B) {ww^R x:w,x∈Σ+}
(C) {wxw^R:w,x∈Σ+}
(D) {xww^R:w,x∈Σ+}

## Solution

1. Approach. The existential decomposition matters: for option C, w can always be chosen to have length one. This removes the apparent need to remember an arbitrarily long prefix. A direct regular expression is 0(0|1)+0 | 1(0|1)+1.

2. Derivation and interpretation. In C, every string wxw^R has the same first and last symbol and length at least 3. Conversely any binary string of length≥3 with equal endpoints has such a representation by choosing w to be its first single symbol and x its nonempty middle. Thus C equals 0(0+1)+0 ∪1(0+1)+1 and is regular. A is the nonempty even-palindrome language and nonregular. For B, intersect with the regular language 0(11)*1 00 (11)*1 01. The result is{0 1^k 00 1^k 01:k positive odd}: the only possible even-palindrome prefix must match the two odd-length 1 blocks. This equality language is nonregular by pumping the first block. Hence B is nonregular. D is the reversal of B and is likewise nonregular.

# GATE 2007: Q74 (printed CS Q74)

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** A DFA over {a,b} has start state q0, accepting states q1,q2 and nonaccepting states q0,q3. Its complete transition table is: q0: a→q1,b→q0; q1: a→q2,b→q1; q2: a→q1,b→q2; q3: a→q1,b→q2.
Which regular expression denotes its language? Here + denotes union.
Options:
(A) b*ab*ab*ab*
(B) (a+b)*
(C) b*a(a+b)*
(D) b*ab*ab*

## Solution

1. Approach. Before the first a the machine stays in nonaccepting q0. Once an a occurs, every later transition stays within the accepting pair q1,q2. q3 cannot affect strings read from the start state.

2. Derivation and interpretation. The start state q0 loops on b and is not accepting. Its first a enters accepting q1. Thereafter a alternates between q1 and q2 and b loops in either accepting state, so every suffix over {a,b} is accepted. q3 is unreachable from q0. Thus exactly the strings containing at least one a are accepted: b*a(a+b)*, option C.

**Paraphrased problem context:** A DFA over {a,b} has start state q0, accepting states q1,q2 and nonaccepting states q0,q3. Its complete transition table is: q0: a→q1,b→q0; q1: a→q2,b→q1; q2: a→q1,b→q2; q3: a→q1,b→q2.
How many states does a minimum equivalent DFA have?
Options:
(A) 1
(B) 2
(C) 3
(D) 4

## Solution

1. Approach. First remove unreachable states, then partition the remaining states by whether any suffix distinguishes their acceptance. q1 and q2 have identical future acceptance behavior even though their names differ.

2. Derivation and interpretation. Delete unreachable q3. States q1 and q2 are equivalent: both accept, b leaves each in the accepting class, and a switches within that class. Merge them. The remaining nonaccepting q0 and accepting merged state are distinguishable by the empty suffix, so two states are necessary and sufficient. Answer B.

**Paraphrased problem context:** A context-free grammar has nonterminals {S,A,B}, terminals {a,b}, start S, and productions S→aB | bA; B→b | bS | aBB; A→a | aS | bAA. Which string is generated?
Options:
(A) aaaabb
(B) aabbbb
(C) aabbab
(D) abbbba

## Solution

1. Approach. Track the invariant #a−#b for strings derived from each nonterminal: it is 0 from S, +1 from A and −1 from B. Reject options violating the invariant, then construct a derivation for the survivor.

2. Derivation and interpretation. Every S-derived string has equal numbers of a and b; A-derived strings have one more a, and B-derived strings one more b. These invariants follow directly from all eight productions. Only aabbab among the four options has equal counts. It is generated by S => aB => aaBB => aabB => aabbS => aabbaB => aabbab. Thus C.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** A context-free grammar has nonterminals {S,A,B}, terminals {a,b}, start S, and productions S→aB | bA; B→b | bS | aBB; A→a | aS | bAA. For aabbab, the answer string to linked Q78, how many distinct derivation trees exist?
Options:
(A) 1
(B) 2
(C) 3
(D) 4

## Solution

1. Approach. The first two a symbols force S→aB→aaBB. Enumerate how the remaining bbab splits between the two B subtrees. Count trees, not different orders of expanding the same tree.

2. Derivation and interpretation. The first two terminals aa force S -> aB and B -> aBB. The remaining bbab must split between the two B children. Each child has one more b than a. Exactly two splits work: b | bab and bba | b. For the first, the right child uniquely derives bab via B -> bS -> baB -> bab. For the second, the left child uniquely derives bba via B -> bS -> bbA -> bba. The single b children use B -> b. Thus there are 2 parse trees, option B; different orders of expanding a fixed tree do not count as additional trees.
