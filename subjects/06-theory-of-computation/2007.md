**Independently derived answer:** A

## Solution

Track the number of zeros modulo3 and ones modulo5, giving3×5=15 states; accept residue(0,0). Every residue pair is reachable. Any two different pairs are distinguished by appending zeros and ones that bring one pair to(0,0), leaving the other nonzero in at least one coordinate. Thus15 states are necessary and sufficient, A.

## Solution

In C, every string wxw^R has the same first and last symbol and length at least3. Conversely any binary string of length≥3 with equal endpoints has such a representation by choosing w to be its first single symbol and x its nonempty middle. Thus C equals0(0+1)+0 ∪1(0+1)+1 and is regular. A is the nonempty even-palindrome language and nonregular. For B, intersect with the regular language0(11)*1 00 (11)*1 01. The result is{0 1^k 00 1^k 01:k positive odd}: the only possible even-palindrome prefix must match the two odd-length1 blocks. This equality language is nonregular by pumping the first block. Hence B is nonregular. D is the reversal of B and is likewise nonregular.

Thus exactly the strings containing at least one a are accepted: b*a(a+b)*, option C.

Every S-derived string has equal numbers of a and b; A-derived strings have one more a, and B-derived strings one more b. These invariants follow directly from all eight productions. Only aabbab among the four options has equal counts. It is generated by S => aB => aaBB => aabB => aabbS => aabbaB => aabbab. Thus C.

# GATE 2007: Q79 (printed CS Q79)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 20. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

The first two terminals aa force S -> aB and B -> aBB. The remaining bbab must split between the two B children. Each child has one more b than a. Exactly two splits work: b | bab and bba | b. For the first, the right child uniquely derives bab via B -> bS -> baB -> bab. For the second, the left child uniquely derives bba via B -> bS -> bbA -> bba. The single b children use B -> b. Thus there are 2 parse trees, option B; different orders of expanding a fixed tree do not count as additional trees.
