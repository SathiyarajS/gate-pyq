

# GATE 2005: Q45 (printed CS Q45)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** P1 is decidable, P2 undecidable. Which is true? A P3 decidable if P1 reduces to P3; B P3 undecidable if P3 reduces to P2; C P3 undecidable if P2 reduces to P3; D P3 decidable if P3 reduces to its complement.

## Solution

If undecidable P2 reduces effectively to P3, a decider for P3 would decide P2 by applying the reduction first. Therefore P3 is undecidable (C). Reducing a decidable problem to P3 says nothing about P3; reducing P3 to an undecidable target also gives no such conclusion.

Teaching detail:
A reduction converts an instance of its source problem into a target instance while preserving the yes/no answer. If undecidable P2 reduces to P3 and P3 had a decider, their composition would decide P2, a contradiction. Thus C. Reduction direction matters: mapping an easy problem into a hard one does not make the easy problem hard, nor does it make the target easy.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** No exact option; B if at least one a is required

**Paraphrased problem context:** A deterministic machine over {a, b} starts at nonfinal q0. It has q0−b→q0, q0−a→q1, q1−b→q2, q2−b→q3, with final q3, q3−b→q3 and q3−a→q1; omitted transitions reject. Identify its language. Offered B describes every a being followed by at least two b symbols. Determine whether that wording is exact, including empty and b-only strings. Other choices: A every a followed by exactly two b symbols; C strings containing abb; D strings not containing aa.

## Solution

The start state has a b-loop but is not accepting. An a starts a required pair of b transitions, after which the accepting state permits more b symbols or another a followed by at least two b symbols. Hence the exact language is b*(abb b*)+ = b*(ab{2,})+. All words have at least one a, and every a is followed by at least two consecutive b symbols. Option B omits the at-least-one-a condition and therefore includes ε and every b-only word by vacuous truth, all rejected by the depicted machine. Both reproductions show the nonaccepting start state. B describes the intended restriction only if the domain excludes b*; there is no literally exact offered answer. Diagram and options continue on page 7.

Teaching detail:
Trace complete trips from the start to the final state. Initial b symbols can be arbitrary, but they never reach a final state. The first a must be followed by two b transitions to enter q3; additional b symbols may follow, and each later a begins another mandatory two-b segment. Thus at least one ab{2,} block is required. Checking ε or b provides immediate counterexamples to the broad offered description: its universal condition is vacuously true while the machine rejects. Do not silently mark the intended option as an exact language equality.

# GATE 2005: Q54 (printed CS Q54)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Let Df, Nf, Dp, Np denote languages accepted by deterministic finite, nondeterministic finite, deterministic pushdown and nondeterministic pushdown automata. Determine the equality/proper-inclusion relationships. The intended option D is Df=Nf and Dp properly contained in Np. Other options: A both inclusions proper; B Df proper subset Nf and Dp=Np; C both pairs equal.

## Solution

Subset construction converts any NFA into a DFA, so Df=Nf. A DPDA is a restricted NPDA, and the inclusion Dp⊊Np is strict, for example unmarked even palindromes require nondeterministic midpoint choice. Thus D. The printed subset symbol is interpreted as proper inclusion.

Teaching detail:
For finite automata, a DFA state can represent the full subset of possible NFA states after each prefix, so nondeterminism does not increase language expressive power. For pushdown automata, deterministic computation cannot generally guess an unmarked midpoint while preserving the necessary stack comparison. Every deterministic machine is a special nondeterministic one, but some CFLs such as unmarked even palindromes are not deterministic CFLs. Hence the first pair is equal and the second inclusion is strict.

# GATE 2005: Q55 (printed CS Q55)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** L1={a^n b^n c^m:n, m>0}, L2={a^n b^m c^m:n, m>0}. Identify the false claim among: A their intersection is context-free; B their union is context-free; C both individual languages are context-free; D their intersection is context-sensitive.

## Solution

L1={a^n b^n c^m:n, m>0} and L2={a^n b^m c^m:n, m>0} each need only one stack comparison, hence are CFLs. CFLs are closed under union. Their intersection is {a^k b^k c^k:k>0}, which is not context-free (standard CFL pumping argument) but is context-sensitive by linear-space counting. The false assertion is A.

Teaching detail:
Each individual language compares only two adjacent block counts and allows the remaining block freely, which a PDA can handle. Closure under union proves the union claim. In the intersection, the first language forces #a=#b and the second forces #b=#c, hence all three counts coincide. The standard pumping argument prevents a single stack from enforcing these three blocks: a short pumped region cannot cover all three, so pumping changes only one or two counts or disrupts the block order. Linear-space checking still recognizes the intersection, establishing context sensitivity.

# GATE 2005: Q56 (printed CS Q56)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** L1 is recursive; L2 is recursively enumerable but not recursive. Which is true of their complements? A complement L1 recursive and complement L2 RE; B complement L1 recursive and complement L2 not RE; C both complements RE; D complement L1 RE and complement L2 recursive.

## Solution

A recursive language has a halting decider, whose accept/reject outputs can be swapped to decide its complement. If both L2 and its complement were recursively enumerable, dovetailing their recognizers would decide L2, contradicting its nonrecursive premise. Thus complement(L1) is recursive and complement(L2) is not recursively enumerable, B.

Teaching detail:
A decider always halts, so swapping its accept/reject outcomes gives a complement decider. A recognizer need not halt on nonmembers, so that swap does not work for an arbitrary RE language. If both L2 and its complement had recognizers, run them in alternating steps on any input. Exactly one must eventually accept, deciding which side the input belongs to. That would contradict the given nonrecursive status. Thus B, with the nonhalting possibility explaining the distinction.

# GATE 2005: Q57 (printed CS Q57)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** For binary w, L1={wwᴿ}, L2={w#wᴿ} with special delimiter#, L3={ww}. Which is true? A L1 deterministic CFL; B L2 deterministic CFL; C L3 CFL but not deterministic; D L3 deterministic CFL.

## Solution

For L2={w#w^R}, a DPDA pushes before # and then deterministically pops and compares after #; it accepts exactly upon a complete match. L1={ww^R} has no delimiter and is context-free but not deterministic context-free. L3={ww} is not context-free. Therefore B.

Teaching detail:
For the delimited language, # tells the PDA exactly when to switch from pushing to comparing/popping. Every decision is determined by current input and stack top, so the recognizer is deterministic. Without the delimiter, a palindrome PDA must in general choose the midpoint nondeterministically. The duplicated-word language requires preserving the same order twice, not the reverse stack order, and is not CFL. These distinctions are about whole language classes, not whether some individual examples can be recognized.
