**Paraphrased problem context:** L₁ is recursive. L₂ and L₃ are recursively enumerable but not recursive. Which statement is not necessarily true?
Options: (A) L₂−L₁ is recursively enumerable; (B) L₁−L₃ is recursively enumerable; (C) L₂∩L₃ is recursively enumerable; (D) L₂∪L₃ is recursively enumerable.

## Solution

L₂−L₁=L₂∩complement(L₁) is recursively enumerable because L₁ is decidable and its complement is decidable. Recursively enumerable languages are also closed under union and intersection, proving C and D. But take L₁=Σ* and L₃ an undecidable recursively enumerable language: L₁−L₃ is its complement and cannot be recursively enumerable, or L₃ would be decidable by dovetailing both recognizers. Therefore B is not necessarily true.

Teaching detail: To recognize an intersection of two recursively enumerable languages, simulate both recognizers in parallel and accept only after both accept; for a union accept after either does. For L₂−L₁, first decide nonmembership in L₁, then run the L₂ recognizer. This construction fails for L₁−L₃ because nonmembership in undecidable L₃ cannot generally be recognized.

**Paraphrased problem context:** Let L be all binary strings with an even number of 1s, including zero 1s. Which regular expression represents L? Concatenation is implicit and * denotes Kleene star.
Options: (A) (0*10*1)*; (B) 0*(10*10*)*; (C) 0*(10*1)*0*; (D) 0*1(10*1)*10*.

## Solution

A binary string with an even number of 1s can be decomposed into initial zeros followed by zero or more pairs of 1s, with any number of zeros after each 1. This is exactly 0*(10*10*)*, option B. Each repeated block contributes two 1s, while any string with 2k ones can be split into k such blocks. The outer star includes the zero-ones case, including epsilon.

Teaching detail: Why the alternatives fail: A cannot generate a nonempty all-zero string; C cannot generate 11011, whose zero separates two adjacent pairs of ones; D always has at least its two explicit outer ones and therefore misses epsilon and all-zero strings. B allows arbitrary zeros before, between and after every pair, and its repetition count can be zero.

**Independently derived answer:** D

**Paraphrased problem context:** For nonnegative integers i,j, let L₁={0^i1^j:i≠j}, L₂={0^i1^j:i=j}, L₃={0^i1^j:i=2j+1}, L₄={0^i1^j:i≠2j}. Which statement is true?
Options: (A) Only L₂ is context-free; (B) Only L₂ and L₃ are context-free; (C) Only L₁ and L₂ are context-free; (D) All are context-free.

## Solution

All four languages are context free, D. L₂ has grammar S→0S1|ε. L₃ has S→00S1|0. For L₁, split into i>j and i<j: matched pairs 0^j1^j can have a nonempty zero prefix or nonempty one suffix, respectively, and CFLs are closed under concatenation with regular languages and finite union. For L₄, let E={0^(2j)1^j}, generated by S→00S1|ε. The part i>2j is 0⁺E. For i<2j, even i gives E1⁺, while odd i gives 0E1⁺. These are all CFLs by the same closure properties, proving the claim without incorrectly invoking closure of CFLs under complement.

Teaching detail: For the strict-inequality cases, the closure argument is constructive. L₁=0⁺{0^j1^j} ∪ {0^i1^i}1⁺. For L₄, write E={0^(2j)1^j}; the cases i>2j, i<2j with i even, and i<2j with i odd are respectively 0⁺E, E1⁺ and 0E1⁺. This separates the arithmetic conditions without relying on the generally false statement that context-free languages are closed under complement.

**Independently derived answer:** C

**Paraphrased problem context:** Let w be any binary string of length n, and L the set of all substrings of w. What is the minimum number of states in a nondeterministic finite automaton accepting L?
Options: (A) n−1; (B) n; (C) n+1; (D) 2^(n−1).

## Solution

The answer is n+1. For a lower bound, take an accepting computation for w, which has n consuming transitions. If a state repeats at two different consumed-input positions, the nonempty intervening loop can be pumped, accepting a string longer than n. That contradicts the definition of L. Hence at least n+1 states occur. For an upper bound, use states q0,…,qn, all accepting, with q0 initial. For every j=1,…,n add q0 --w[j]--> qj, and for i=1,…,n−1 add qi --w[i+1]--> q(i+1). Every nonempty accepted string follows a contiguous segment of w, and every substring has such a run. Making q0 accepting includes the empty substring. This construction uses one initial state and no epsilon moves; C.

Teaching detail: The lower bound applies even when w contains repeated symbols, because the finite language contains w itself but no string longer than n. Pumping a repeated state on that accepting computation would violate this maximum length. In the upper-bound construction, choosing q0→qj chooses the starting position of a substring; continuing along successive positions preserves contiguity, and accepting at any state permits any ending position.
