**Question:** [Official archived paper page 11](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

The initial 1 enters accepting p; an initial 0 reaches the dead state. At p, 0 loops, while11 follows p→q→p. A0 at q is rejected, so all accepted suffixes are concatenations of 0 and 11. This gives 1(0+11)*, option C. For example10 is accepted but not generated by A or D. Diagram arrows and the dead state were visually verified.

# GATE 2023 CS: Q24

**Question:** [Official archived paper page 22](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=22); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A, C, D

**Derived answer:** A;C;D

## Solution

Regular intersection uses a product automaton. Decidable-language intersection runs both halting deciders and accepts iff both accept. For recursively enumerable languages, dovetail the recognizers and accept once both have accepted, giving a recognizer. CFL intersection is not closed: {aⁿbⁿcᵐ}∩{aᵐbⁿcⁿ}={aⁿbⁿcⁿ}, which is not context-free. Thus A, C, D.

# GATE 2023 CS: Q39

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

## Solution

X generates every nonempty string of the form aⁱbʲ: its alternatives prepend a or append b and terminate at a or b. These operations never introduce a b before an a. Wrapping with S→aSb preserves that form and adds no strings beyond those already generated by X. Thus L(G)=a*b* minus epsilon, equivalently a*(a+b)b*, option B. The grammar may be context-free while its generated language is regular.

# GATE 2023 CS: Q40

**Question:** [Official archived paper page 41](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=41); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

In s each a pushes A. The first b moves to p and pops A, and further b’s pop more A. Entry to the cleanup state q requires an A at the stack top and pops it, so at least one A must remain after all input has been read. Then q removes the remaining stack symbols, including the bottom marker. Consequently input is aᵐbⁿ with m≥1 and 0≤n<m, option A. Equal counts leave only the bottom symbol in s/p and cannot enter q; epsilon is not accepted. All epsilon labels and stack symbols were visually inspected.

# GATE 2023 CS: Q63

**Question:** [Official archived paper page 67](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=67); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4 to 4

**Derived answer:** 4

## Solution

Use three accepting states tracking the trailing run of ones of lengths 0, 1, 2, and a rejecting trap after the third consecutive one. A zero resets each nontrap state to run length 0; a one advances the run or reaches the trap. All four states are reachable. The trap differs from the others on the empty suffix. For two run lengths i<j among 0, 1, 2, append 3-j ones: the state j rejects but state i still accepts. Thus all four are pairwise distinguishable and the DFA is minimal.
