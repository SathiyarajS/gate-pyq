

# GATE 2023 CS: Q14

**Question:** [Official archived paper page 11](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** A DFA over {0,1} starts in s, accepts only in p, and has transitions s:0→r,1→p; p:0→p,1→q; q:0→r,1→p; r:0→r,1→r. Which expression describes its language? A 1(0*11)*; B 0(0+1)*; C 1(0+11)*; D 1(110*)*.

## Solution

The initial 1 enters accepting p; an initial 0 reaches the dead state. At p, 0 loops, while11 follows p→q→p. A0 at q is rejected, so all accepted suffixes are concatenations of 0 and 11. This gives 1(0+11)*, option C. For example10 is accepted but not generated by A or D. Diagram arrows and the dead state were visually verified.

Teaching detail. Every accepting run must first consume 1 to reach p. From p there are two ways to return to p without entering the trap: consume a single 0, or consume the pair 11 through q. Any number of these complete return segments is allowed, including none, so the one-letter string 1 is accepted. A suffix ending after the first 1 of a pair stops at nonaccepting q. This run decomposition proves both that every accepted word has the expression's form and that every generated word is accepted.

# GATE 2023 CS: Q24

**Question:** [Official archived paper page 22](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=22); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A, C, D

**Derived answer:** A;C;D

**Paraphrased problem context:** Which language classes are closed under intersection with another language in the same class? A regular; B context-free; C recursive (decidable); D recursively enumerable (recognizable). Select all.

## Solution

Regular intersection uses a product automaton. Decidable-language intersection runs both halting deciders and accepts iff both accept. For recursively enumerable languages, dovetail the recognizers and accept once both have accepted, giving a recognizer. CFL intersection is not closed: {aⁿbⁿcᵐ}∩{aᵐbⁿcⁿ}={aⁿbⁿcⁿ}, which is not context-free. Thus A, C, D.

Teaching detail. For regular languages, a product DFA tracks both component states and accepts only when both components accept. For decidable languages, running the two deciders sequentially terminates, whether the answer is yes or no. For recognizers, a rejecting computation might never terminate, so dovetailing makes explicit that an accepting computation in each recognizer will eventually be observed. The CFL counterexample uses one language checking equality of a's and b's and another checking equality of b's and c's; requiring both produces the standard non-CFL of three equal counts.

# GATE 2023 CS: Q39

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** For grammar S→aSb|X and X→aX|Xb|a|b with start S, identify the language: A (a+b)*; B a*(a+b)b*; C a*b*(a+b); D a nonregular language.

## Solution

X generates every nonempty string of the form aⁱbʲ: its alternatives prepend a or append b and terminate at a or b. These operations never introduce a b before an a. Wrapping with S→aSb preserves that form and adds no strings beyond those already generated by X. Thus L(G)=a*b* minus epsilon, equivalently a*(a+b)b*, option B. The grammar may be context-free while its generated language is regular.

Teaching detail. For completeness, any aⁱbʲ with i+j≥1 can be derived from X. If i≥1, terminate with a and use i−1 prepending steps plus j appending steps. If i=0 and j≥1, terminate with b and append j−1 further b's. Conversely every X-production preserves the a-before-b ordering and cannot create ε. The S wrapping rule also preserves this ordering and nonemptiness. Hence it neither removes any X-generated word nor introduces a word outside the claimed regular language.

# GATE 2023 CS: Q40

**Question:** [Official archived paper page 41](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=41); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** An empty-stack-accepting PDA starts in s with stack ⊥. In s, a/⊥/A⊥ and a/A/AA push one A. Transition s→p and the loop at p are b/A/ε. Transitions s→q and p→q are ε/A/ε. At q, ε/A/ε and ε/⊥/ε empty the stack. Describe its accepted language over {a,b}, consuming all input.

## Solution

In s each a pushes A. The first b moves to p and pops A, and further b’s pop more A. Entry to the cleanup state q requires an A at the stack top and pops it, so at least one A must remain after all input has been read. Then q removes the remaining stack symbols, including the bottom marker. Consequently input is aᵐbⁿ with m≥1 and 0≤n<m, option A. Equal counts leave only the bottom symbol in s/p and cannot enter q; epsilon is not accepted. All epsilon labels and stack symbols were visually inspected.

Teaching detail. After reading m a's, the stack is A^m⊥. Reading n b's pops n A's, leaving A^(m−n)⊥. The only gateway to the cleanup state consumes one further A without consuming input, which is possible precisely when m−n≥1. Cleanup cannot read more input, so all a's and b's must already have been consumed. Pure a strings with m≥1 are accepted via s→q; the empty string is not, because no transition from s pops ⊥ directly. The strict inequality n<m, not n≤m, is therefore essential.

# GATE 2023 CS: Q63

**Question:** [Official archived paper page 67](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=67); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4 to 4

**Derived answer:** 4

**Paraphrased problem context:** Find the minimum number of states of a complete DFA over {0,1} accepting strings that never contain three consecutive 1s.

## Solution

Use three accepting states tracking the trailing run of ones of lengths 0, 1, 2, and a rejecting trap after the third consecutive one. A zero resets each nontrap state to run length 0; a one advances the run or reaches the trap. All four states are reachable. The trap differs from the others on the empty suffix. For two run lengths i<j among 0, 1, 2, append 3-j ones: the state j rejects but state i still accepts. Thus all four are pairwise distinguishable and the DFA is minimal.

Teaching detail. Name states q0,q1,q2,dead by the count of trailing 1s until a forbidden run has occurred. On 0, q0,q1,q2 go to q0; on 1 they go to q1,q2,dead respectively. dead loops on both symbols because an earlier occurrence of 111 can never be undone by later zeros. q0,q1,q2 accept, including q0 for ε. Reachability witnesses are ε,1,11,111. A construction alone proves an upper bound of four; the distinguishability argument is required to exclude every possible smaller DFA.
