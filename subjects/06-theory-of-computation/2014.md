**Paraphrased problem context:** Which language is regular? A: {aⁿbⁿ:n≥0}. B: {aⁿ:n is prime}. C: {w over {a,b}: w contains 3k+1 occurrences of b for some k∈ℕ}. D: {ww:w∈{0,1}*}.

## Solution

1. Method and setup. Finite-state memory can retain a count modulo a fixed constant, but cannot in general remember arbitrary equal block lengths, primality of unbounded lengths, or an arbitrary string for exact copying. For C, use states representing residues 0,1,2 of the b-count; a leaves the state unchanged and b advances it cyclically.

2. Work through the result and its assumptions. A DFA can count b symbols modulo 3 while ignoring a, accepting the residue 1 class; if natural k excludes 0, a finite initial-count adjustment still makes it regular. The equal-count language is nonregular by pumping; unary prime lengths are not ultimately periodic. The copy language is nonregular: intersection with 0*1*0*1* yields 0^i1^j0^i1^j, whose equal nonadjacent blocks defeat pumping on 0^p1^p0^p1^p. Thus only C.

**Paraphrased problem context:** Which problem is undecidable for arbitrary context-free grammars? A whether a grammar is ambiguous; B whether it generates a given string; C whether its language is empty; D whether its language is finite.

## Solution

Step 1: Membership is decidable by a general CFG parsing algorithm, so B is not the answer. Step 2: Emptiness is decidable by marking nonterminals that can derive terminal strings and checking the start symbol. Finiteness is decidable by analyzing useful recursive growth, so C and D are also decidable. Step 3: There is no algorithm deciding ambiguity for every CFG: whether some string has multiple parse trees is an undecidable property of arbitrary grammars. Thus A. This does not say that ambiguity cannot be demonstrated for a particular grammar by an explicit witness.

**Paraphrased problem context:** Over Σ={0,1,c}, define L1={0ⁿ1ⁿ:n≥0}, L2={wcwʳ:w∈{0,1}*}, L3={wwʳ:w∈{0,1}*}, with wʳ the reversal of w. Which languages are deterministic context-free? A none; B only L1; C only L1,L2; D all three.

## Solution

Step 1: For L1, a deterministic pushdown automaton pushes one marker per 0 and switches to popping when the first 1 appears. The input symbol change identifies the phase boundary; accept when the counts match. Step 2: For L2, push the first binary word, then the marker c deterministically signals the switch to matching and popping its reverse. Step 3: In L3 there is no midpoint marker. An arbitrary binary even palindrome requires a nondeterministic choice of when to switch, and this unmarked palindrome language is a standard CFL that is not deterministic context-free. Therefore C. The final claim is the known non-DCFL result, not a claim that every language with an unmarked midpoint is automatically nondeterministic.

**Paraphrased problem context:** 2CNFSAT asks whether a CNF propositional formula with at most two literals per clause is satisfiable; for example (x1∨x2)∧(x1∨¬x3)∧(x2∨x4). Classify it. A NP-complete; B polynomial-time solvable via directed graph reachability; C constant-time solvable because every instance is satisfiable; D NP-hard but not NP-complete.

## Solution

Step 1: Translate every clause (a∨b) into implications ¬a→b and ¬b→a. Treat a unit clause as (a∨a). This gives a directed implication graph with one vertex per literal. Step 2: If x reaches ¬x and ¬x reaches x, they lie in one strongly connected component, so either truth assignment forces a contradiction. Conversely, if no variable shares an SCC with its negation, the SCC ordering yields a satisfying assignment. Step 3: SCCs and reachability are computable in polynomial time (linear time suffices for SCCs), establishing B. C is false, as clauses x and ¬x form an unsatisfiable instance.
