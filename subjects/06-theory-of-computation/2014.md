## Solution

A DFA can count b symbols modulo3 while ignoring a, accepting the residue1 class; if natural k excludes0, a finite initial-count adjustment still makes it regular. The equal-count language is nonregular by pumping; unary prime lengths are not ultimately periodic. The copy language is nonregular: intersection with 0*1*0*1* yields0^i1^j0^i1^j, whose equal nonadjacent blocks defeat pumping on0^p1^p0^p1^p. Thus only C.

# GATE 2014 CS1: Q48 (printed CS Q38)

**Question:** [Official archived paper page 17](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** C under standard many-one completeness; official D simplifies away trivial languages

**Source access:** Open archive member CS/CS2014.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

A polynomial maximum-clique algorithm decides CLIQUE in polynomial time, so NP-completeness implies P=NP. Every nontrivial language in P is then NP-complete: decide an NP source and map yes/no instances to fixed yes/no target strings. But ∅ and Σ* are in P and cannot be NP-hard under many-one reductions because a nontrivial language cannot reduce to either. Thus NPC is a proper subset of P=NP, diagram C. Official D is valid only after excluding these trivial languages or changing the reduction convention; keep this discrepancy explicit.

## Solution

For each maximal run of at least two1s, an entering0 contributes one011 and a leaving0 contributes one110. Internal runs cancel; hence #110−#011 equals the indicator that the string starts11 minus the indicator that it ends11. A finite automaton can track these boundary facts, so L1 is regular. Intersect L2 with 0³0*1³1*: the resulting language is{0^m1^n: m≥n≥3}, because occurrences number m−2 and n−2. This is not regular: pumping down a zero in 0^p1^p violates m≥n. Thus L2 is not regular, A.
