**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Which statement holds for {a^p | p is prime}?

(A) Not accepted by a Turing machine
(B) Regular but not context-free
(C) Context-free but not regular
(D) Neither regular nor context-free, but accepted by a Turing machine

## Solution

1. Primality of the input length is decidable, so a Turing machine accepts the language. It is not regular: if a pumping length is p, choose prime q>p; a pumpable nonempty segment has length d≤p, and pumping it q+1 times changes length to q+qd=q(1+d), composite.
2. Every unary context-free language is regular (its length set is ultimately periodic/semilinear), so this language is not context-free either. Therefore D.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** Which are decidable? I: whether the intersection of two regular languages is infinite. II: whether a given context-free language is regular. III: whether two pushdown automata accept the same language. IV: whether a given grammar is context-free.

(A) I and II
(B) I and IV
(C) II and III
(D) II and IV

## Solution

1. For I, construct a product DFA for the intersection and test whether a reachable cycle can reach an accepting state; this decides infinitude. IV is a syntactic check of the grammar’s productions: every left side must be a single nonterminal.
2. Regularity of an arbitrary CFL and equivalence of arbitrary nondeterministic PDAs are undecidable. Thus I and IV, B.
3. IV asks whether the presented grammar is context-free in form, not whether an arbitrary grammar’s language happens to be a CFL.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** If both L and its complement are recursively enumerable, L is necessarily:

(A) Regular
(B) Context-free
(C) Context-sensitive
(D) Recursive

## Solution

1. Run recognizers for L and its complement in dovetailing fashion, alternating simulation steps so neither can prevent the other from progressing.
2. Every input lies in exactly one of the two languages, so exactly one recognizer eventually accepts. Accept if it is the L recognizer and reject otherwise.
3. This constructed decider halts on every input, making L recursive, D. Nothing here guarantees regularity, context-freeness or a linear-space bound.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Which statement is false?

(A) Every NFA has an equivalent DFA
(B) Every nondeterministic TM has an equivalent deterministic TM
(C) Every regular language is context-free
(D) Every subset of a recursively enumerable set is recursive

## Solution

1. D is false. The set Σ* is recursive and hence recursively enumerable, but it contains nonrecursive subsets, including an encoding of the halting language.
2. Even a recursively enumerable set itself need not be recursive. A holds by the subset construction for NFAs.
3. B holds because a deterministic Turing machine can dovetail the finitely branching computation tree of a nondeterministic machine, accepting exactly when an accepting branch is found. C holds because a finite automaton can be converted to a right-linear context-free grammar.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** None

**Paraphrased problem context:** DFA Y has start 1, final 2, and transitions on (a,b): 1→(1,2), 2→(2,1). DFA Z has start 1, final 2: 1→(2,2), 2→(1,1). Which printed table is their intersection product Z×Y? In every offered table P is initial, R is the only final state, and each row below lists its (a,b) destinations.

(A) P:(S,R), Q:(R,S), R:(Q,P), S:(Q,P)
(B) P:(S,Q), Q:(R,S), R:(Q,P), S:(P,Q)
(C) P:(Q,S), Q:(R,S), R:(Q,P), S:(Q,P)
(D) P:(S,Q), Q:(S,R), R:(Q,P), S:(Q,P)

## Solution

1. There is no correct option as printed. Let product states be P=(1,1), Q=(1,2), R=(2,2), S=(2,1), in (Z,Y) order. P is initial and R is the sole accepting state.
2. Applying both component transitions gives the rows (a,b): P=(S,R), Q=(R,S), R=(Q,P), S=(P,Q). Option A agrees in its first three rows but prints S=(Q,P), not (P,Q). Options B, C and D send the initial state on b to a nonfinal state, whereas b is accepted by both Y and Z and must be accepted by their intersection product.
3. Thus none represents the product, even after renaming. A would be correct if its final row were repaired. No official key is available to determine how the examination treated the printing defect.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Which statements are true? I: every left-recursive grammar can be converted to a right-recursive grammar and vice versa. II: all ε-productions can be removed from any CFG by suitable transformations. III: a CFG with only X→w or X→wY, where w is a terminal string and Y a nonterminal, always generates a regular language. IV: derivation trees for a CFG in Chomsky normal form are always binary trees.

(A) I,II,III,IV
(B) II,III,IV only
(C) I,III,IV only
(D) I,II,IV only

## Solution

1. Under the conventional grammar-transformation interpretation, I, III and IV are true, giving C. I refers to eliminating left recursion using right-recursive auxiliaries and the symmetric transformation for right recursion; it does not mean every context-free grammar becomes a right-linear regular grammar.
2. II is false as stated: if ε belongs to the language, removing every ε-production cannot preserve that language, since no nonempty sentential form can derive the empty string without one. III is a right-linear grammar, possibly with multi-terminal labels; expanding labels into paths yields a finite automaton, so its language is regular.
3. IV is true in the at-most-two-children sense of binary tree: CNF uses A→BC or A→a (and possibly the special start ε-rule), so no derivation-tree node has more than two children.

**Paraphrased problem context:** Match E: checking identifiers are declared before use; F: agreement of numbers of formal and actual function parameters; G: arithmetic expressions with matched parentheses; H: palindromes. Models: P={a^n b^m c^n d^m | n,m≥1}; Q: X→XbX|XcX|dXf|g; R={wcw | w∈{a,b}*}; S: X→bXb|cXc|ε.

3. H is modeled by X→bXb | cXc | ε, which generates even-length palindromes. These are structural analogies, not claims that the small grammars capture every feature of a programming language or all odd-length palindromes.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Match four NFAs to regular expressions. Each NFA has lower state L (initial and accepting), upper-left A and upper-right B. Unlisted transitions are absent. P: L−0→A, A−0→L and B, B−1→A and B; B is also accepting. Q: L−0→A, A−0→L, A−1→B, B−1→A, B−0→B; only L accepts. R: L−0→A, A−1→L and B, B−1→A, B−0→B; only L accepts. S has R’s transitions with both L and B accepting. Expressions: 1: ε+0(01*1+00)*01*; 2: ε+0(10*1+00)*0; 3: ε+0(10*1+10)*1; 4: ε+0(10*1+10)*10*.

(A) P–2,Q–1,R–3,S–4
(B) P–1,Q–3,R–2,S–4
(C) P–1,Q–2,R–3,S–4
(D) P–3,Q–2,R–1,S–4

## Solution

1. Name the lower start state L, upper-left state A and upper-right state B. Every automaton accepts ε at L; every nonempty accepted path begins with 0 from L to A. In P, cycles from A back to A are 00 via L or 01*1 via B, and a finishing path to either accepting state is represented by 01*.
2. Hence P matches expression 1: ε+0(01*1+00)*01*. In Q, the A-cycles are 00 or 10*1, with final 0 to L, giving expression 2. In R, the A-cycles are 10 or 10*1, with final 1 to L, giving expression 3.
3. In S, the same cycles apply but B is also accepting, so a final 10* covers both possible accepting destinations, giving expression 4. Thus P–1,Q–2,R–3,S–4, option C.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Which sets are regular? I: {a^n b^(2m) | n,m≥0}. II: {a^n b^m | n=2m}. III: {a^n b^m | n≠m}. IV: {xcy | x,y∈{a,b}*}.

(A) I and IV only
(B) I and III only
(C) I only
(D) IV only

## Solution

1. I and IV are regular, giving A. I has expression a*(bb)*: n and m are independent and only the parity of the b-count is restricted.
2. IV has expression (a|b)*c(a|b)* because x and y need not be equal. II is {a^(2m)b^m}; applying the pumping lemma to a^(2p)b^p pumps only a symbols and destroys the required 2:1 relation.
3. III is not regular: if it were, subtracting it from the regular language a*b* would make {a^n b^n} regular by closure under difference, a contradiction.
