

# GATE 2008: Q9 (printed CS Q9)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 3. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Primality of the input length is decidable, so a Turing machine accepts the language. It is not regular: if a pumping length is p, choose prime q>p; a pumpable nonempty segment has length d≤p, and pumping it q+1 times changes length to q+qd=q(1+d), composite. Every unary context-free language is regular (its length set is ultimately periodic/semilinear), so this language is not context-free either. Therefore D.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

For I, construct a product DFA for the intersection and test whether a reachable cycle can reach an accepting state; this decides infinitude. IV is a syntactic check of the grammar’s productions: every left side must be a single nonterminal. Regularity of an arbitrary CFL and equivalence of arbitrary nondeterministic PDAs are undecidable. Thus I and IV, B. IV asks whether the presented grammar is context-free in form, not whether an arbitrary grammar’s language happens to be a CFL.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Dovetail a recognizer for L with a recognizer for its complement. On every input exactly one eventually accepts; accept or reject according to which finishes. The resulting machine always halts, so L is recursive, D. This does not force a fixed linear-space bound, regularity or context-freeness.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

D is false. The set Σ* is recursive and hence recursively enumerable, but it contains nonrecursive subsets, including an encoding of the halting language. Even a recursively enumerable set itself need not be recursive. A holds by the subset construction for NFAs. B holds because a deterministic Turing machine can dovetail the finitely branching computation tree of a nondeterministic machine, accepting exactly when an accepting branch is found. C holds because a finite automaton can be converted to a right-linear context-free grammar.

# GATE 2008: Q49 (printed CS Q49)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 9. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** None

## Solution

There is no correct option as printed. Let product states be P=(1,1), Q=(1,2), R=(2,2), S=(2,1), in (Z,Y) order. P is initial and R is the sole accepting state. Applying both component transitions gives the rows (a,b): P=(S,R), Q=(R,S), R=(Q,P), S=(P,Q). Option A agrees in its first three rows but prints S=(Q,P), not (P,Q). Options B, C and D send the initial state on b to a nonfinal state, whereas b is accepted by both Y and Z and must be accepted by their intersection product. Thus none represents the product, even after renaming. A would be correct if its final row were repaired. No official key is available to determine how the examination treated the printing defect.

# GATE 2008: Q50 (printed CS Q50)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 9. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Under the conventional grammar-transformation interpretation, I, III and IV are true, giving C. I refers to eliminating left recursion using right-recursive auxiliaries and the symmetric transformation for right recursion; it does not mean every context-free grammar becomes a right-linear regular grammar. II is false as stated: if ε belongs to the language, removing every ε-production cannot preserve that language, since no nonempty sentential form can derive the empty string without one. III is a right-linear grammar, possibly with multi-terminal labels; expanding labels into paths yields a finite automaton, so its language is regular. IV is true in the at-most-two-children sense of binary tree: CNF uses A→BC or A→a (and possibly the special start ε-rule), so no derivation-tree node has more than two children.

# GATE 2008: Q51 (printed CS Q51)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 9. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

The matching is E–R, F–P, G–Q, H–S, option C. E requires the same identifier string in declaration and use, modeled by the copy language wcw. F matches counts of formal and actual parameters; a^n b^m c^n d^m models the two cross-referenced counts. G is modeled by X→XbX | XcX | dXf | g: b and c act as binary operators, d/f as matched opening/closing parentheses, and g as an operand. H is modeled by X→bXb | cXc | ε, which generates even-length palindromes. These are structural analogies, not claims that the small grammars capture every feature of a programming language or all odd-length palindromes.

# GATE 2008: Q52 (printed CS Q52)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 10. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Name the lower start state L, upper-left state A and upper-right state B. Every automaton accepts ε at L; every nonempty accepted path begins with 0 from L to A. In P, cycles from A back to A are 00 via L or 01*1 via B, and a finishing path to either accepting state is represented by 01*. Hence P matches expression 1: ε+0(01*1+00)*01*. In Q, the A-cycles are 00 or 10*1, with final 0 to L, giving expression 2. In R, the A-cycles are 10 or 10*1, with final 1 to L, giving expression 3. In S, the same cycles apply but B is also accepting, so a final 10* covers both possible accepting destinations, giving expression 4. Thus P–1,Q–2,R–3,S–4, option C.

# GATE 2008: Q53 (printed CS Q53)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 10. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

I and IV are regular, giving A. I has expression a*(bb)*: n and m are independent and only the parity of the b-count is restricted. IV has expression (a|b)*c(a|b)* because x and y need not be equal. II is {a^(2m)b^m}; applying the pumping lemma to a^(2p)b^p pumps only a symbols and destroys the required 2:1 relation. III is not regular: if it were, subtracting it from the regular language a*b* would make {a^n b^n} regular by closure under difference, a contradiction.
