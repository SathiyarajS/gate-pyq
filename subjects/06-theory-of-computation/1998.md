**Independently derived answer:** D: equality

**Essential problem context (paraphrased):** Compare A=(01+1)* and B=((01)*1*)*: proper inclusion, equality, or incomparable?

## Solution

Every block in B is a sequence of 01 blocks followed by a sequence of 1 symbols, all of which are permitted individual blocks of A. Thus B⊆A. Conversely B can produce an individual 01 by selecting one occurrence in (01)* and none in 1*, and can produce an individual 1 by the reverse choice. Its outer star concatenates any sequence of these, so A⊆B. Both include the empty string. Therefore A=B, D.

# GATE 1998: Q57 (printed A Q3(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203837/GATE1998.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Official answer:** Not available; no official key located.

**Independently derived answer:** 1* ∪ 1^k 1* 0 1^k (0 1^k)*.

**Essential problem context (paraphrased):** Give a regular expression for binary strings in which every 0 is immediately followed by exactly k consecutive 1s and preceded by at least k consecutive 1s, for fixed nonnegative integer k.

## Solution

Interpret “exactly k” as the length of the entire run of consecutive 1s immediately after a 0. Write 1^k for k copies of the symbol 1, not a variable exponent inside the regex. One expression is

1* ∪ 1^k 1* 0 1^k (0 1^k)*.

The first branch handles strings with no zeros, including ε. Their condition is vacuously true; they must not be discarded merely because they contain fewer than k ones. In the second branch, the initial run 1^k1* has at least k ones, so the first zero has the required predecessor run. Every zero then contributes the block 01^k. Repeating that block gives exactly k ones between consecutive zeros, simultaneously satisfying the preceding and following requirements. The last zero is also followed by exactly k ones, with no extra trailing ones.

Conversely, any valid string containing a zero has an initial run of at least k ones. After its first zero, each run of ones has length exactly k, until the string ends or the next zero begins. It therefore has the displayed form. For k=2, 11011 and 111011011 are accepted, whereas 1011 lacks enough leading ones and 110111 has too many final ones. For k=0 the formula reduces to 1*0*: no one may occur after the first zero. If “followed by k ones” meant at least k rather than exactly k, a different language would result.

**Independently derived answer:** Five remainder states if ε represents 0; six if an empty representation is excluded.

**Essential problem context (paraphrased):** Design a minimum-state DFA for binary strings whose numeric value, ignoring leading zeros, is divisible by five.

## Solution

Maintain the remainder r of the binary prefix modulo 5. Appending bit b changes a value v into 2v+b, so the transition is δ(q_r,b)=q_((2r+b) mod 5). The start and sole accepting state is q0, using the conventional value 0 for ε.

State     input 0   input 1
q0        q0        q1
q1        q2        q3
q2        q4        q0
q3        q1        q2
q4        q3        q4

This transition table fully specifies the DFA. Leading zeros loop at q0, and zero is divisible by five. Induction on prefix length proves the invariant that state q_r means the prefix value is congruent to r. Consequently the final state is accepting exactly for multiples of five.

For minimality, all five states are reachable: ε, 1, 10, 11 and 100 reach q0 through q4. Given distinct remainders r and s, choose v in {0,1,2,3,4} with 8r+v≡0 mod 5 and append its three-bit binary representation, including leading zeros. From q_r the result is accepting. From q_s its remainder differs by 8(s−r), which is nonzero modulo 5 because 8 is invertible modulo 5. Thus every pair is distinguishable, establishing a five-state lower bound.

The source says strings in {0,1}* but does not define the value of ε. If a binary numeral must contain at least one symbol, add a new nonaccepting start state s with 0→q0 and 1→q1. It is distinct from q0 by ε and from every other remainder state by the suffix argument, so this alternative language needs six states. The five-state answer uses the explicitly stated conventional interpretation.

**Essential problem context (paraphrased):** For the displayed PDA on states q0,q1, alphabet {0,1}, stack {Z0,X}, start (q0,Z0), and empty-store acceptance, determine its language. Common transitions: (q0,1,Z0)→(q0,XZ0), (q0,ε,Z0)→(q0,ε), (q0,1,X)→(q0,XX), (q1,1,X)→(q1,ε). GFG has (q0,0,Z0)→(q1,X) and (q1,0,Z0)→(q0,Z0); GateForum instead has (q0,0,X)→(q1,X) and (q0,0,Z0)→(q0,Z0).

## Solution

Empty-store acceptance requires both the entire input to be consumed and the stack to be empty. Merely reaching Z0, or emptying the stack while unread input remains, is not sufficient. The two reproduced transition sets differ materially, so there is no source-independent single language.

GFG literal version: at (q0,Z0), ε can pop Z0 and accept ε. Reading 0 uses its printed transition (q0,0,Z0)→(q1,X), replacing Z0 rather than preserving it. One subsequent 1 pops X and accepts 01 with an empty stack. No further input can then be consumed. Reading any 1 first puts X above Z0 in q0; that state can only push more X on further 1s, because GFG's zero transition tests Z0, not X. It can never enter its popping phase from such a stack. Thus L_GFG={ε,01}. The printed q1,0,Z0 return transition is unreachable from the start in this literal machine.

GateForum literal version: (q0,0,Z0)→(q0,Z0) permits any number of leading zeros, followed by the ε-pop, so every string in 0* is accepted. If any 1 is read, q0 pushes Xs; a subsequent 0 can enter q1 using its X-preserving transition. q1 may pop them on 1s, but after the last X it remains at (q1,Z0), for which GateForum prints no outgoing transition. It cannot empty Z0. Hence no string containing a 1 is accepted and L_GF=0*.

A plausible intended reconstruction combines GateForum's switch (q0,0,X)→(q1,X) with GFG's return (q1,0,Z0)→(q0,Z0), keeping the four common transitions. It pushes n≥1 Xs on 1s, reads 0 to switch phase, pops n Xs on 1s, then reads another 0 to return to q0. It can repeat such blocks and finally pop Z0 by ε. Conditional on exactly those repairs, the language is (⋃_(n≥1){1^n01^n0})*. The choice n≥1 is necessary because no q0,0,Z0 transition remains in this repair. This reconstructed answer is useful but not verified as the original question; silently substituting it would conceal different literal answers.

**Independently derived answer:** Explain literal source behavior separately from the conditional push/switch/pop/return reconstruction.

**Essential problem context (paraphrased):** For the displayed PDA on states q0,q1, alphabet {0,1}, stack {Z0,X}, start (q0,Z0), and empty-store acceptance, describe its operation informally. Common transitions: (q0,1,Z0)→(q0,XZ0), (q0,ε,Z0)→(q0,ε), (q0,1,X)→(q0,XX), (q1,1,X)→(q1,ε). ## Solution

A transition (q,a,T)→(p,γ) consumes a when a≠ε, changes state to p, and replaces the top stack symbol T by γ. Take the leftmost stack symbol as the top. Thus replacing X by XX pushes one extra counter symbol, while replacing X by ε pops one.

In the plausible reconstruction specified in part (a), q0 is a counting-up phase and q1 a counting-down phase. Start with Z0. Each leading 1 pushes one X. A 0 with X on top switches q0→q1 without changing the stack. Each following 1 in q1 pops one X. Once only Z0 remains, another 0 returns to q0 without removing Z0. The machine may process another block in the same way. Only at q0 with top Z0 may ε remove the bottom marker, accepting if input is exhausted.

For reconstructed input 110110, the configurations (state, unread input, stack) are
(q0,110110,Z0)
→(q0,10110,XZ0)
→(q0,0110,XXZ0)
→(q1,110,XXZ0)
→(q1,10,XZ0)
→(q1,0,Z0)
→(q0,ε,Z0)
→(q0,ε,ε).

An extra 1 in the popping phase has no transition once Z0 is reached; too few 1s leave X on top when the closing 0 is encountered, also blocking the run. These restrictions enforce equal positive counts within every block. The four-phase explanation applies only to the explicitly repaired transition set, not literally to both printed versions.

For the GFG literal machine the special input 01 instead replaces Z0 by X on its first step, then pops X, so that machine accepts only ε and 01. For the GateForum literal machine, only leading zeros can be accepted; a run involving pushed Xs becomes stuck at q1,Z0 even after their counts match. These observations explain why the attractive counting-machine interpretation cannot be presented without disclosing the source repairs. All unspecified transitions are treated as absent, not guessed.

# GATE 1998: Q78 (printed B Q14(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203837/GATE1998.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** {a^i b^j : i,j≥1 and i≠j}.

**Essential problem context (paraphrased):** Find L(G1) for S1→aS1b|aAb|aBb, A→aA|a, B→Bb|b.

## Solution

A generates exactly a^r with r≥1: each recursive step adds one a and the final A→a supplies the last. Similarly B generates exactly b^s with s≥1. The left recursion in B changes derivation direction, not its generated language or uniqueness for a fixed length.

After t≥0 uses of S1→aS1b, choosing S1→aAb and A⇒a^r produces a^(t+r+1)b^(t+1). Both exponents are positive and the number of a's exceeds the number of b's by r≥1. Choosing S1→aBb instead gives a^(t+1)b^(t+s+1), whose b-count exceeds its a-count by s≥1. These are the only terminating choices, so equality of the counts is impossible.

Conversely, for any i>j≥1, choose t=j−1 and r=i−j, yielding a^i b^j through the A branch. For j>i≥1, choose t=i−1 and s=j−i through the B branch. Therefore every positive unequal pair occurs, proving L(G1)={a^i b^j:i,j≥1,i≠j}.

This grammar is also unambiguous. The comparison between i and j forces the A or B branch; the smaller exponent forces t; the difference forces r or s. The unary A or B derivation of that length is unique. This fact will be useful when answering the inherent-ambiguity question, but does not need to be assumed to establish the language.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203837/GATE1998.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Official answer:** Not available; no official key located.

**Independently derived answer:** No. The four-rule extension gives an unambiguous CFG.

**Essential problem context (paraphrased):** For L2={a^i b^j a^k b^l : i,j,k,l≥1 and (i=j or k=l)}, decide whether it is inherently ambiguous. Use the grammar extension from part (b) if helpful.

## Solution

A context-free language is inherently ambiguous only if every CFG generating it is ambiguous. It is therefore enough to exhibit and prove one unambiguous grammar. Use the extension from part (b): S2→TAB|S1T, T→aTb|ab, retaining the unambiguous unequal-count grammar G1.

Every word of L2 has four nonempty runs a^i,b^j,a^k,b^l. The boundaries between the runs are determined by changes of symbol, particularly the middle b-to-a change, so a derivation cannot shift the split between its two a*b* components.

If i=j, only S2→TAB can apply, since S1 generates unequal first counts. The exponent i fixes the unique derivation in T. The remaining exponents k and l fix the unique unary derivations in A and B. If i≠j, only S2→S1T can apply. Then membership requires k=l. Part (a)'s proof gives a unique derivation of a^i b^j in S1, and the common value k=l gives a unique derivation in T. Hence each word has exactly one parse tree.

Words satisfying both equalities still use only the first branch, so they do not create an intersection ambiguity. A different grammar with productions for “first pair equal” and “second pair equal” may generate those words twice, but ambiguity of one grammar does not establish inherent ambiguity of its language. This four-run language also should not be confused with classical three-run examples whose equality conditions share the middle count. The explicit disjoint grammar here proves that L2 is not inherently ambiguous.

Conversely any permitted identifier can be decomposed into its initial letter and its remaining zero to five alphanumeric symbols, so it is accepted. The actual letter alphabet, such as upper/lowercase distinctions, is a language-design input; underscores are not included because the question permits only letters and digits.
