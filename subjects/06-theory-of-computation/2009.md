**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** For grammar S→aSa|bSb|a|b over {a, b}, identify the language: A all palindromes; B odd-length palindromes; C all strings beginning and ending with the same symbol; D even-length palindromes.

## Solution

The base productions produce a single a or b. Every recursive production adds the same symbol at both ends, preserving the palindrome property and odd length. Conversely strip matching outer pairs from any odd palindrome until one central symbol remains, yielding a derivation. Thus exactly all odd-length palindromes, B.

Teaching detail:
Every derivation starts from a one-symbol base a or b and adds matching symbols around the outside. Length therefore remains odd and the string remains a palindrome. Conversely, removing the equal end symbols from any odd palindrome repeatedly reaches its one-symbol centre, giving a reverse derivation. Even palindromes are excluded because no ε base exists; a string such as aabba begins/ends alike but is not generated.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Describe (0+1)*0(0+1)*0(0+1)*: A strings containing 00; B at most two zeros; C at least two zeros; D strings beginning and ending with either 0 or 1.

## Solution

Each starred(0+1) factor permits any binary string, but the two explicit 0 symbols must occur in order. Hence the expression accepts exactly strings with at least two zeros, not necessarily adjacent, C.

Teaching detail:
Each explicit 0 in the expression must consume a separate symbol, so every generated string contains at least two zeros. The three starred factors can contain arbitrary binary strings, including more zeros, and may be empty. Conversely, choose any two zeros in a string and assign the prefix, intervening segment and suffix to the three starred factors. The zeros need not be adjacent, so 010 is accepted despite lacking substring 00. Hence C.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Which is false? A each regular language has a unique minimal DFA (up to renaming); B each NFA has an equivalent PDA; C the complement of every CFL is recursive; D every NPDA has an equivalent DPDA.

## Solution

Minimal DFAs are unique up to state renaming; an NFA can be simulated by a PDA that ignores its stack. Every CFL is decidable, so its complement is recursive. But deterministic PDAs recognize a proper subclass of the CFLs recognized by NPDAs. Thus the universal conversion in D is false.

Teaching detail:
A PDA can simulate an NFA without using its stack. Context-free membership is decidable, so complementing that decision gives a decider for the complement. Minimal DFAs are unique up to state renaming. Deterministic PDAs, however, recognize a proper subset of context-free languages; nondeterminism cannot always be eliminated. For instance, unmarked palindromes need a nondeterministic guess of the midpoint. Thus D is the false universal claim.

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2009.pdf, physical page 9. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** L1={a^m b^m c a^n b^n:m, n≥0}; L2={a^i b^j c^k:i, j, k≥0}; L=L1∩L2. Classify: A not recursive; B regular; C context-free but nonregular; D RE but not context-free.

## Solution

L1 contains exactly one c between a^m b^m and a^n b^n. For membership in L2=a*b*c*, no a or b may follow that c, so n=0. Thus the intersection is{a^m b^m c:m≥0}. A grammar for it is S→Tc, T→aTb|ε. The language is context-free and nonregular: removing its fixed final c by regular right quotient would otherwise make{a^m b^m} regular. Therefore C.

Teaching detail:
L2 permits only a block of a’s, then b’s, then c’s. A word of L1 has one central c, so its trailing a^n b^n must be empty to fit L2. Thus L={a^m b^m c:m≥0}. The grammar S→Tc and T→aTb|ε proves context-freeness. For nonregularity, removing the final fixed c from a hypothetical finite automaton would recognize the classic nonregular language a^m b^m. Hence C, not the much stronger undecidability alternatives.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** A DFA starts q0, accepts only q2. On 0, q0→q1→q2→q2; on 1, all states go q0. What does it accept? A strings beginning 0 or 1; B ending 0; C ending 00; D containing 00.

## Solution

The states record zero, one, or at least two consecutive zeros at the end. Every 1 returns to the start state; 0 advances to the accepting state after the second consecutive zero, where further zeros loop. Hence exactly strings ending 00 are accepted, C, rather than all strings that merely contain 00 somewhere.

Teaching detail:
The state records the length of the current suffix of consecutive zeros, capped at 2. Reading 1 resets that suffix to length 0. Reading a second consecutive 0 reaches q2; additional zeros stay accepting. A string such as 001 contains 00 but ends in 1 and is rejected, separating C from D. A single 0 reaches q1 and is rejected, separating C from B.
