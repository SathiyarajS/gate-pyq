

# GATE 2009: Q12 (printed CS Q12)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2009.pdf, physical page 3. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

The base productions produce a single a or b. Every recursive production adds the same symbol at both ends, preserving the palindrome property and odd length. Conversely strip matching outer pairs from any odd palindrome until one central symbol remains, yielding a derivation. Thus exactly all odd-length palindromes, B.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Minimal DFAs are unique up to state renaming; an NFA can be simulated by a PDA that ignores its stack. Every CFL is decidable, so its complement is recursive. But deterministic PDAs recognize a proper subclass of the CFLs recognized by NPDAs. Thus the universal conversion in D is false.

# GATE 2009: Q40 (printed CS Q40)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2009.pdf, physical page 9. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

L1 contains exactly one c between a^m b^m and a^n b^n. For membership in L2=a*b*c*, no a or b may follow that c, so n=0. Thus the intersection is{a^m b^m c:m≥0}. A grammar for it is S→Tc,T→aTb|ε. The language is context-free and nonregular: removing its fixed final c by regular right quotient would otherwise make{a^m b^m} regular. Therefore C.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

The states record zero, one, or at least two consecutive zeros at the end. Every1 returns to the start state;0 advances to the accepting state after the second consecutive zero, where further zeros loop. Hence exactly strings ending00 are accepted, C, rather than all strings that merely contain00 somewhere.
