## Solution

3-SAT is NP-complete.2-SAT is decidable in polynomial time, for example by strongly connected components of its implication graph, so C. These classifications are established without assuming P≠NP; saying3-SAT is NP-complete is not a proof that it lies outside P.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

Label each of the three columns by the count of ones modulo 3, from left to right 0,1,2; label upper and lower rows by the count of zeros modulo 2, 0 and1. Each 1 edge advances one column cyclically without changing row, and each 0 edge toggles the row without changing column. The initial upper-left state is the only accepting state. Hence acceptance requires #1≡0 mod3 and #0≡0 mod2, option A, including the empty string.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

For L={a^m b^n c^(m+n):m,n≥1}, a context-free grammar is S→aSc | aTc and T→bTc | bc. The outer recursion supplies matching a/c pairs and the inner recursion matching b/c pairs, so it generates exactly L. It is not regular: for a putative pumping length p, use a^p b c^(p+1). Any pumpable segment within the first p symbols consists only of a characters; pumping changes the a count without changing the c count, violating the defining equality. Therefore context-free but not regular, B.

# GATE 2004: Q88 (printed CS Q88)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203330/GATE2004.pdf#page=12), physical page 12. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Interpret S,A,B as states tracking the number of a symbols modulo3: a advances S→A→B→S, while b leaves the state unchanged. Terminating production S→b ends with residue0, and B→a also ends with residue0. Consequently every generated word has #a divisible by3. Conversely any nonempty word with that property can be scanned along these transitions; if its last symbol is b it terminates via S→b, and if its last symbol is a it terminates via B→a. Thus L={w in {a,b}^+ : #a(w)≡0 mod3}, option C in the stated positive-word universe.

# GATE 2004: Q89 (printed CS Q89)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203330/GATE2004.pdf#page=12), physical page 12. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** None

## Solution

Under repetition-free enumeration, both S1 and S2 hold (A). For S1, first decide membership of both components in recursive L1; if either is absent reject, otherwise run A until both appear and compare their unique indices. For S2, if L1 is empty it is recursive. Otherwise fix its first enumerated word w1. Decide whether x is in L1 by accepting x=w1 and otherwise asking the L2 decider whether w1#x belongs. Every other word appears later, so this is correct. The S2 argument also survives repetitions. However, if arbitrary repetitions are permitted, S1 can fail: let recursive L1 consist of all distinct tags a_e and b_e. Enumerate each b_e before its a_e, and repeat b_e after a_e exactly if machine e halts, using dovetailing. Then a_e#b_e belongs to L2 exactly for halting machines, making L2 nonrecursive despite recursive L1. Thus with repetitions allowed only S2 is necessarily true (C). No unconditional option is assigned without fixing the enumeration convention.
