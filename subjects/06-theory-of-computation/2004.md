**Paraphrased problem context:** Which complexity classification applies to 3-SAT and 2-SAT respectively?
Options:
(A) Both in P
(B) Both NP-complete
(C) NP-complete and in P
(D) Undecidable and NP-complete

## Solution

Step 1: 3-SAT is NP-complete.2-SAT is decidable in polynomial time, for example by strongly connected components of its implication graph, so C. These classifications are established without assuming P≠NP; saying 3-SAT is NP-complete is not a proof that it lies outside P.

Step 2: Teaching check: For 2-SAT, clause (u∨v) adds implications ¬u→v and ¬v→u. The formula is unsatisfiable exactly when some variable and its negation occupy one strongly connected component. This polynomial algorithm is why one cannot extend the 3-SAT hardness conclusion to two literals.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** A DFA has six states arranged as top row t0,t1,t2 and bottom row b0,b1,b2. Initial and sole accepting state is t0. On 1, each row cycles left-to-right: t0→t1→t2→t0 and b0→b1→b2→b0. On 0, each column toggles tj↔bj. Which condition on (#1,#0) describes the accepted strings?
Options:
(A) Divisible by 3 and 2 respectively
(B) Odd and even respectively
(C) Even and odd respectively
(D) Divisible by 2 and 3 respectively

## Solution

1. Label each of the three columns by the count of ones modulo 3, from left to right 0,1,2; label upper and lower rows by the count of zeros modulo 2, 0 and 1. Each 1 edge advances one column cyclically without changing row, and each 0 edge toggles the row without changing column.

2. The initial upper-left state is the only accepting state. Hence acceptance requires #1≡0 mod3 and #0≡0 mod2, option A, including the empty string.

3. Teaching check: The two counters are independent: reading 1 changes the column but not the row, and reading 0 changes the row but not the column. Returning to t0 requires both modular counts to return to zero. The empty word is accepted because the start state is accepting.

**Independently derived answer:** B

**Paraphrased problem context:** Classify L={a^m b^n c^(m+n):m,n≥1}.
Options:
(A) Regular
(B) Context-free but not regular
(C) Context-sensitive but not context-free
(D) Type-0 but not context-sensitive

## Solution

1. For L={a^m b^n c^(m+n):m,n≥1}, a context-free grammar is S→aSc | aTc and T→bTc | bc. The outer recursion supplies matching a/c pairs and the inner recursion matching b/c pairs, so it generates exactly L.

2. It is not regular: for a putative pumping length p, use a^p b c^(p+1). Any pumpable segment within the first p symbols consists only of a characters; pumping changes the a count without changing the c count, violating the defining equality.

3. Therefore context-free but not regular, B.

4. Teaching check: A pushdown automaton can push one marker for each a and b, then pop one for each c, while tracking the required block order and nonempty a,b blocks. A finite automaton cannot maintain the unbounded count equality; the pumping argument makes this limitation rigorous.

**Independently derived answer:** C

**Paraphrased problem context:** Grammar G has S→bS | aA | b; A→bA | aB; B→bB | aS | a. Na(w),Nb(w) count a,b symbols. Which describes L(G) within {a,b}^+ (nonempty words)?
Options:
(A) {w:Na(w)>3Nb(w)}
(B) {w:Nb(w)>3Na(w)}
(C) {w:Na(w)=3k, k∈{0,1,2,…}}
(D) {w:Nb(w)=3k, k∈{0,1,2,…}}

## Solution

1. Interpret S,A,B as states tracking the number of a symbols modulo 3: a advances S→A→B→S, while b leaves the state unchanged. Terminating production S→b ends with residue 0, and B→a also ends with residue 0.

2. Consequently every generated word has #a divisible by 3. Conversely any nonempty word with that property can be scanned along these transitions; if its last symbol is b it terminates via S→b, and if its last symbol is a it terminates via B→a.

3. Thus L={w in {a,b}^+ : #a(w)≡0 mod3}, option C in the stated positive-word universe.

4. Teaching check: There is no ε production, so the empty word is excluded despite having zero a symbols. The problem explicitly uses {a,b}^+, which resolves that apparent exception. Each a advances one of three residue states while any b preserves it.

# GATE 2004: Q89 (printed CS Q89)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203330/GATE2004.pdf#page=12), physical page 12. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** None

**Paraphrased problem context:** L1 is recursively enumerable over Σ. Algorithm A enumerates its words as w1,w2,w3,… . Let #∉Σ and L2={wi#wj:wi,wj∈L1 and i<j}. Consider S1: if L1 is recursive then L2 is recursive; S2: if L2 is recursive then L1 is recursive. Which is true? The reproduction does not state whether enumeration can repeat words; keep that distinction explicit.
Options:
(A) Both S1 and S2
(B) S1, but S2 need not be true
(C) S2, but S1 need not be true
(D) Neither need be true

## Solution

1. Under repetition-free enumeration, both S1 and S2 hold (A). For S1, first decide membership of both components in recursive L1; if either is absent reject, otherwise run A until both appear and compare their unique indices.

2. For S2, if L1 is empty it is recursive. Otherwise fix its first enumerated word w1.

3. Decide whether x is in L1 by accepting x=w1 and otherwise asking the L2 decider whether w1#x belongs. Every other word appears later, so this is correct.

4. The S2 argument also survives repetitions. However, if arbitrary repetitions are permitted, S1 can fail: let recursive L1 consist of all distinct tags a_e and b_e.

5. Enumerate each b_e before its a_e, and repeat b_e after a_e exactly if machine e halts, using dovetailing. Then a_e#b_e belongs to L2 exactly for halting machines, making L2 nonrecursive despite recursive L1.

6. Thus with repetitions allowed only S2 is necessarily true (C). No unconditional option is assigned without fixing the enumeration convention.

7. Teaching check: The relation depends on enumeration positions, not a lexicographic order on words. If words repeat, one pair may have witnesses in both directions. That is why a proof using unique indices needs an explicit repetition-free convention instead of being applied automatically.
