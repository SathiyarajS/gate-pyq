**Essential problem context (paraphrased):** The copies print A r(*)=r* and B (r*s*)=(r+s)*, plus C (r+s)*=r*+s* and D r*s*=r*+s*. Which identities are justified?

## Solution

Thus the often-intended answers A, B are conditional repairs, not identities established by the literal reproduced notation. The missing-star issue is retained as a source discrepancy.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C: 2ℓ−1

**Essential problem context (paraphrased):** For a nonempty word w of length ℓ in a Chomsky-normal-form grammar, how many production applications derive it?

## Solution

A CNF parse tree uses binary nonterminal productions A→BC and terminal productions A→a. There are ℓ terminal-producing leaves. A full binary tree with ℓ leaves has ℓ−1 binary internal nodes, so the total applications are ℓ+(ℓ−1)=2ℓ−1. The order of expanding variables does not change that count. The special ε-production sometimes allowed for the start symbol is outside this nonempty-word case; substituting ℓ=0 into the formula would not count its derivation correctly.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A, D

**Essential problem context (paraphrased):** Which closures hold for CFLs: union, complement, intersection, Kleene star?

## Solution

For union, introduce a new start symbol choosing either original grammar. For star, use a new start that produces ε or concatenates one original-language word with another repetition. Hence both operations preserve context-freeness. Intersection does not: {a^n b^n c^m} intersected with {a^m b^n c^n} gives the non-CFL equal-three-block language. If CFLs were also closed under complement, De Morgan together with union closure would imply intersection closure, contradicting that example. Thus complement and arbitrary intersection fail.

**Independently derived answer:** A, C

**Essential problem context (paraphrased):** For which machine models does every nondeterministic machine have an equivalent deterministic machine: finite automata, PDAs, TMs, or none?

## Solution

The subset construction converts an NFA to a DFA recognizing the same language. A deterministic TM can explore the finitely branching computation tree breadth-first or by dovetailing, accepting whenever some nondeterministic branch accepts. Thus nondeterministic TMs recognize no additional languages, though complexity can change. NPDAs recognize all CFLs, while DPDAs recognize only deterministic CFLs, a strict subclass. Consequently the universal equivalence holds for finite automata and Turing machines, but not pushdown automata.

# GATE 1992: Q67 (printed B Q16(i))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** True; run the two total deciders and accept iff either accepts.

**Essential problem context (paraphrased):** True or false? The union of two recursive languages is recursive. Prove your answer.

## Solution

True. A recursive language has a decider: a machine that halts on every input and answers membership correctly. Let M1 decide L1 and M2 decide L2, taking a common ambient alphabet (the union of their alphabets if necessary). A machine for L1∪L2 operates as follows:

On input w:
  run M1(w) to completion;
  if M1 accepts, accept;
  run M2(w) to completion;
  if M2 accepts, accept;
  otherwise reject.

If w belongs to the union, at least one decider accepts. Acceptance by M1 immediately suffices; otherwise M2 accepts. If w is outside the union, both deciders reject, and the constructed machine rejects. It always halts because M1 always halts and, when run, M2 always halts. Correctness together with total termination proves recursiveness.

Sequential simulation is adequate here. For merely recursively enumerable languages the first recognizer might loop forever on a nonmember, so a union recognizer generally needs dovetailing instead. The stronger halting promise for recursive languages is the precise reason the simpler proof works. This establishes closure under finite union by induction; it does not establish closure under arbitrary infinite union.

# GATE 1992: Q68 (printed B Q16(ii))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** True. Pump a prime-length q word with i=q+1 to obtain composite length q(1+|y|).

**Essential problem context (paraphrased):** True or false? L={0ⁿ : n is prime} is not regular. Prove your answer.

## Solution

True. Suppose for contradiction that L is regular, and let p≥1 be its pumping length. There is a prime q≥p, because primes are unbounded. Choose w=0^q∈L. For any pumping-lemma decomposition w=xyz with |xy|≤p and |y|≥1, let d=|y|, so 1≤d≤p.

The pumping lemma requires xy^i z∈L for every integer i≥0. Choose i=q+1. This word has length
|xz|+(q+1)|y| = (q−d)+(q+1)d = q+qd = q(1+d).
Both factors exceed one: q is prime and therefore q≥2, while d≥1 gives 1+d≥2. The length is composite. Consequently xy^(q+1)z∉L, contradicting the pumping lemma.

The contradiction holds for every valid decomposition, because the same choice i=q+1 works for every positive d. We therefore refute the existence of a pumping length, and L is nonregular. Choosing an arbitrary fixed pump such as i=2 would not suffice: q+d might itself be prime for some decompositions. The deliberately selected exponent makes the resulting length a multiple of q larger than q.

# GATE 1992: Q69 (printed B Q16(iii))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** False; ⋃_{n≥0}{0ⁿ1ⁿ} is nonregular although each singleton is regular.

**Essential problem context (paraphrased):** True or false? Regular languages are closed under infinite union. Prove your answer.

## Solution

False. For every n≥0 define L_n={0^n1^n}. Each L_n contains one fixed finite word and is regular: a finite chain of states accepts exactly that word, or the word itself is a regular expression. However, the infinite union ⋃_{n≥0}L_n={0^n1^n:n≥0} is not regular.

For completeness, suppose this union has pumping length p. The word w=0^p1^p belongs to it. Every legal decomposition w=xyz with |xy|≤p and |y|≥1 puts y entirely in the first block of zeros, say y=0^d with d≥1. Pump down to i=0. The resulting xz=0^(p−d)1^p has unequal numbers of zeros and ones and is not in the union, contradicting the pumping lemma.

This is a countably infinite family of regular languages with a nonregular union, enough to disprove arbitrary infinite-union closure. Closure under two-way union, and hence any finite union, is not in conflict: the usual product/NFA constructions use finitely many component automata, whereas this family requires unboundedly many distinct word lengths. Some infinite unions do happen to be regular, for example ⋃_{n≥0}{0^n}=0*. The statement fails because not every infinite union is regular.
