A word must contain both a 00 occurrence and a 11 occurrence, in either order, with an arbitrary middle substring and arbitrary prefix/suffix. They cannot overlap because their symbols differ. Hence Σ*(00Σ*11+11Σ*00)Σ*, B. A forces adjacent blocks, C requires only one, and D disallows arbitrary outside context.

**Official answer:** D

**Derived answer:** D

**Source access:** Open archive member CS/CS2016.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

The initial state is accepting, so epsilon and every a-only word are accepted while pushing one X per a. On the first b the machine moves to the middle state and pops one X per b; it reaches the final accepting state only when the stack returns to Z. Therefore the additional accepted words are a^n b^n. The displayed machine is deterministic: at each state/stack combination the input transitions do not compete with epsilon transitions. The language is a* union {a^n b^n: n≥0}, a deterministic CFL, D.

## Solution

The source has complement bars: complement(Y) reduces to W, and Z reduces to complement(X). Since Y is RE but not recursive, complement(Y) cannot be RE, otherwise dovetailing the two recognizers would decide Y. RE languages are closed under computable many-one preimages, so W cannot be RE. X recursive implies complement(X) recursive, and its computable preimage Z is recursive. Hence C. The complement bars were visually checked; text extraction omits them.

**Source access:** Open archive member CS/CS2016.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

L1 is generated by S→aSc|aBc and B→bBc|bc: each a or b adds one trailing c, with positive counts of both. Thus L1 is context-free. If L2 were context-free, its inverse image under h(a)=a, h(b)=b, h(c)=cc would be {a^n b^n c^n: n≥1}, which is not context-free by the pumping lemma. CFL closure under inverse homomorphism therefore proves L2 non-context-free. Answer B.

# GATE 2016 CS2: Q54 (printed CS Q44)

**Question:** [Official archived paper page 38](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Source access:** Open archive member CS/CS2016.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

Whether a machine takes at least2016 steps depends only on its first 2016-step computation prefix. In that time its input head can inspect only a bounded initial segment, so finitely many representative inputs suffice: all short inputs and one representative extension for each sufficiently long prefix. Simulate each for the fixed bound and test whether any (L1) or every (L2) representative survives that many steps. Both tests halt. Acceptance of epsilon (L3) is undecidable by the standard reduction that builds a machine ignoring its input and simulating an arbitrary machine/input pair. Hence C.
