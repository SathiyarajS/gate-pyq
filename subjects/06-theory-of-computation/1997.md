**Independently derived answer:** B

**Essential problem context (paraphrased):** Over{a, b}, which is uncountable: all finite strings, all languages, regular languages, or Turing-recognizable languages?

## Solution

Finite strings can be enumerated by length and lexicographic order, so Σ* is countably infinite. All languages form its power set P(Σ*), which is uncountable by Cantor’s theorem. In contrast, finite automata and Turing machines each have finite descriptions over a finite alphabet, so there are only countably many of either and hence only countably many languages they describe. Thus B. The distinction is between elements that are strings and arbitrary sets of those strings.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Essential problem context (paraphrased):** Which regex describes binary strings with no substring 100? Choice D is 0*(10+1)*.

## Solution

Any leading run of zeros is harmless and is covered by 0*. After the first 1, there cannot be two consecutive zeros, or the preceding 1 followed by those zeros would form 100. Thus the remaining word can be partitioned into blocks 1 and 10, covered by (1+10)*. Conversely, a word built this way has no pair of zeros after a 1, so it cannot contain 100. Hence 0*(10+1)* is exactly the desired language, D. It includes ε and all-zero strings, which also avoid the forbidden substring.

**Essential problem context (paraphrased):** Choose the undecidable task: bounded-step TM acceptance, TM language equivalence, DFA nonemptiness, CFG nonemptiness.

## Solution

Given a step bound k, simulate the TM for at most k steps and answer, so A is decidable. DFA nonemptiness is reachability of an accepting state. CFG nonemptiness is found by marking variables that derive terminal strings until a fixed point. TM language equivalence is undecidable: if decidable, it could compare any TM with one recognizing the empty language and thereby decide TM language emptiness, an undecidable semantic property. Thus B. Bounded simulation differs crucially from unbounded acceptance.

## Solution

For A, the symbol c uniquely marks the midpoint because w uses only a, b. A DPDA pushes symbols before c, then deterministically switches to popping and comparing symbols after c, accepting when they match exactly and input ends. Unmarked palindrome languages require finding an unspecified midpoint and are not deterministic context-free over a multi-symbol alphabet. The equal-three-block language is not even context-free. Hence A. The delimiter’s exclusion from w is essential; without it, the same deterministic switch is unavailable.

# GATE 1997: Q59 (printed A Q11(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 3 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** For GFG: i,j,k,m≥0 and i+k=j+m. GateForum literal S→bSc also generates words outside b*c*d*e*; its block-form subset additionally requires j≥i.

**Essential problem context (paraphrased):** Use the GFG grammar with start symbol S:
S → bSe | PQR
P → bPc | ε
Q → cQd | ε
R → dRe | ε.
Terminals are b,c,d,e. Generated words are b^i c^j d^k e^m with nonnegative integer exponents. GateForum instead prints S→bSc and mistakenly gives nonpositive exponents; those literal variants must be distinguished.
What condition on i,j,k,m characterizes the generated language?

## Solution

Let t be the number of uses of S→bSe before S→PQR. Let p,q,r be the numbers of recursive productions used by P,Q,R. Their contributions are P⇒b^p c^p, Q⇒c^q d^q and R⇒d^r e^r. Combining them with the outer b/e pairs gives

i=t+p,  j=p+q,  k=q+r,  m=r+t,
where t,p,q,r are nonnegative integers. Adding opposite equations yields the necessary relation i+k=j+m.

To prove sufficiency, assume all four exponents are nonnegative and i+k=j+m. Choose any integer t satisfying max(0,i−j)≤t≤min(i,m), and put p=i−t, q=j−i+t, r=m−t. These parameters are nonnegative and reproduce every exponent, including k=j−i+m. Such a t always exists: i−j≤m follows from k≥0, while i−j≤i follows from j≥0. Thus the equality, together with nonnegativity, is also sufficient.

GateForum's visibly different rule S→bSc cannot silently be substituted. Its full generated form is b^(t+p)c^(p+q)d^(q+r)e^r c^t, with a trailing block of c symbols after the d/e blocks. For example S⇒bSc⇒bPQRc⇒bcdc is possible, contradicting that reproduction's claim that every generated word is in b*c*d*e*. Restricting to words of the claimed block form forces either t=0, or q=r=0 so no d/e lies before the final c. The t=0 case gives i=p,j=p+q,k=q+r,m=r, hence i+k=j+m and j≥i. The other case gives only b^i c^i, already included in that subset. Thus the block-form subset has that extra inequality, but it is not the whole literal GateForum language. The word be belongs to GFG but not GateForum.

Finally, GateForum's printed i,j,k,m≤0 is inconsistent with arbitrary nonempty strings of repeated terminals. Taken literally as string exponents, only zero exponents are meaningful, leaving ε; the language intended by the grammar is not that singleton. This solution uses nonnegative counts, as explicitly printed in GFG, and discloses both source differences.

# GATE 1997: Q60 (printed A Q11(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** GFG grammar: bcde, length 4. GateForum literal S→bSc grammar: bc, length 2.

**Essential problem context (paraphrased):** Use the GFG grammar with start symbol S:
S → bSe | PQR
P → bPc | ε
Q → cQd | ε
R → dRe | ε.
Terminals are b,c,d,e. Generated words are b^i c^j d^k e^m with nonnegative integer exponents. GateForum instead prints S→bSc and mistakenly gives nonpositive exponents; those literal variants must be distinguished.
Find a shortest word having two distinct parse trees.

## Solution

For the GFG grammar, bcde has two different parses. The difference is whether the initial b and final e are supplied by the outer S rule or by P and R:

Parse 1: S⇒PQR, with P⇒bPc⇒bc, Q⇒ε, R⇒dRe⇒de. Concatenation gives bcde.
Parse 2: S⇒bSe⇒bPQRe, with P⇒ε, Q⇒cQd⇒cd, R⇒ε. This also gives bcde.

These are distinct parse trees because the first root uses S→PQR and the second root uses S→bSe. Merely changing the order of independent rewrites would not demonstrate ambiguity; here the production at the root really differs.

To prove shortestness, fix a word's exponents. Every parse is uniquely determined by t, the number of outer S→bSe applications, since p=i−t, q=j−i+t and r=m−t determine the unique chains in P,Q,R. Two parses require two possible t values. If consecutive valid choices are t and t+1, the lower choice has p≥1 and r≥1. Those two recursive chains alone contribute at least two b/c symbols and two d/e symbols, so the total length is at least four. The displayed word attains that bound.

Under GateForum's different rule S→bSc, bc is already ambiguous: S⇒bSc⇒bPQRc⇒bc using empty P,Q,R, or S⇒PQR⇒bPcQR⇒bc with P producing bc. ε has a unique parse, and every nonempty generated word has even length, so length two is minimal. The answer therefore must be tied to the chosen reproduction; bcde is not the shortest answer to the literal GateForum grammar.

# GATE 1997: Q81 (printed B Q20)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Six-state DFA tracking (#a mod 2, #b mod 3); start and only accepting state q00.

**Essential problem context (paraphrased):** Construct a finite-state machine with the minimum number of states accepting exactly the strings over {a,b} whose number of a symbols is divisible by 2 and number of b symbols is divisible by 3.

## Solution

The future acceptance of a prefix depends on two remainders, not on the order of its symbols. Let qij mean that the prefix contains i a's modulo 2 and j b's modulo 3. Use Q={q00,q01,q02,q10,q11,q12}; start at q00 and make only q00 accepting. An a toggles i, while a b advances j modulo 3.

State    on a    on b    Accepting?
q00      q10     q01     yes
q01      q11     q02     no
q02      q12     q00     no
q10      q00     q11     no
q11      q01     q12     no
q12      q02     q10     no

This table completely specifies the machine and can be drawn as two three-state b-cycles with paired a-transitions between them. By induction on input length, its state is always the pair of remainders claimed above. Therefore it accepts exactly the required strings, including the empty string because zero is divisible by both divisors.

To prove minimum size, first note that every qij is reachable by a^i b^j. Next take any distinct qij and qkl. Append the suffix a^((-i) mod 2)b^((-j) mod 3). From qij this reaches q00 and accepts. From qkl it reaches the nonzero remainder pair ((k−i) mod 2,(l−j) mod 3), so it rejects. Every pair of states is thus distinguishable by a common suffix. The six distinct residual languages require at least six DFA states; our six-state construction meets this lower bound. Merely multiplying 2 by 3 would suggest the answer but would not, without distinguishability, prove minimality.

# GATE 1997: Q82 (printed B Q21)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** For prefixes, accept all states that can reach an old final state. For reversal, reverse edges and exchange starts/finals using an ε-NFA.

**Essential problem context (paraphrased):** A language L is accepted by a finite-state machine. Prove that finite-state machines also accept L′={s: ss′∈L for some string s′} and Lᴿ={s: s is the reversal of some string in L}.

## Solution

Begin with a DFA M=(Q,Σ,δ,q0,F) for L. This loses no generality because any finite-state recognizer can be determinized. The two constructions solve different problems: L′ consists of prefixes that can still be completed to an accepted word; Lᴿ reverses complete accepted words.

Prefix construction: compute C={q∈Q: δ*(q,t)∈F for some t∈Σ*}. These are exactly the states from which some accepting state is reachable, found by a reverse graph search starting at F. Keep Q,Σ,δ,q0 unchanged and replace the accepting set F by C. The new machine accepts s precisely when δ*(q0,s) belongs to C, which is equivalent to the existence of t with δ*(q0,st)∈F. That is exactly s∈L′. No new states are needed. If L is nonempty, q0∈C and ε is a prefix; if L is empty, C is empty and no word is accepted.

Reversal construction: retain all old states and reverse every labeled transition. For each δ(p,a)=q, add an a-transition q→p. Introduce a fresh start state r with ε-transitions to every f∈F, and make q0 the sole final state. The result is generally nondeterministic because reversing edges can create several transitions with the same label. A path q0 --a1...an--> f in the old machine becomes f --an...a1--> q0 in the new one, and the converse follows by reversing the path again. Thus exactly the reversed words are accepted. If a DFA is required, apply ε-closure and subset construction. Simply exchanging start/final states without reversing edges, or reversing edges while insisting on a single old final as start, would not establish closure for arbitrary L.
