**Paraphrased problem context:** L1 is context-free; L2 is recursively enumerable but not recursive. Which must hold? I complement(L1) is recursive; II complement(L2) is recursive; III complement(L1) is context-free; IV complement(L1)∪L2 is recursively enumerable. A I only; B III only; C III and IV; D I and IV.

## Solution

A CFL has a terminating membership algorithm, so it and its complement are recursive. If complement(L2) had a decider, exchanging accept/reject would decide L2, a contradiction. CFL closure under complement fails in general, so III is not necessary. For IV, first decide whether the input is outside L1; accept if so, otherwise run the recognizer for L2. That algorithm recognizes the union and may loop only for nonmembers.

Baseline derivation and retained qualifications: Every CFL is decidable, so complement(L1) is recursive. The complement of nonrecursive L2 cannot be recursive, because recursive languages are closed under complement. CFLs are not closed under complement. Since complement(L1) is recursive and L2 is RE, their union is RE by dovetailing recognizers. Hence I and IV, D.

**Paraphrased problem context:** Two complete DFAs over {a,b} each have start nonfinal state 0 and final state 1. M: on a, either state goes to 1; on b, either goes to 0. N: on a, either goes to 0; on b, either goes to 1. Find states in a minimal DFA for L(M)∩L(N).

## Solution

M records whether the most recent symbol is a; N records whether it is b. Empty input is rejected by both initial states. A nonempty string cannot end in both symbols, so no string belongs to the intersection. Although a mechanical product construction offers up to four states, minimization merges all reachable states into one rejecting sink because every continuation is rejected. A DFA still requires its start state, so the answer is not zero.

Baseline derivation and retained qualifications: The first DFA accepts exactly strings ending in a, and the second exactly strings ending in b. Their intersection is empty. The minimal complete DFA for the empty language is one nonaccepting state with loops on both symbols, so 1.

**Paraphrased problem context:** NPDA states q0(start),q1,q2(final), stack bottom ⊥. At q0 read b∈{0,1} and push b; transition to q1 may consume 0,1,or ε without changing stack. At q1 read 0 and pop 1, or read 1 and pop 0. With only ⊥ left, ε-pop it and enter q2. Which suffix appended to 101100 is accepted? A 10110; B 10010; C 01010; D 01001.

## Solution

The push phase remembers a prefix in reverse order; the pop phase checks its complemented reverse. Thus accepted strings have form w z complement(reverse(w)), where z is empty or one symbol. Every listed concatenation has eleven symbols, forcing |w|=5 and one middle symbol. Here w=10110, middle=0, and reverse(w)=01101. Complementing gives 10010. The nondeterministic phase switch is constrained by total length, so one cannot push all six supplied prefix bits.

Baseline derivation and retained qualifications: The NPDA pushes a prefix, optionally consumes a middle symbol while changing phase, then pops only on the complementary symbol. The full listed strings have length 11, so the first five symbols10110 are pushed and the sixth0 is the middle. The remaining five must be the complement of the reversed prefix: reverse10110=01101, complement10010. Thus B.

**Paraphrased problem context:** Assess I complement of every decidable language is decidable; II some language is in NP but undecidable; III every NP language is decidable. A II only; B III only; C I and II; D I and III.

## Solution

A decider halts on every input, so exchanging accept and reject decides the complement. An NP computation has a finite polynomially bounded certificate/search tree, which a deterministic machine can exhaust, so every NP language is decidable. I and III hold, II fails: D.

Teaching detail:
A language in NP has a polynomially bounded certificate verifier. A deterministic decider can enumerate every certificate up to that finite bound and run the verifier, halting with yes if one works and no otherwise. This may be exponential but still terminates, so III is true and II is false. A decider for a complement simply reverses the yes/no outcomes of a halting decider, so I is also true. Distinguish decidability from efficient decidability.

**Derived answer:** A is guaranteed; all choices can be consistent

**Paraphrased problem context:** Q1≤p3-SAT≤pQ2. Which is “consistent” with this? A Q1 in NP, Q2 NP-hard; B Q2 in NP, Q1 NP-hard; C both in NP; D both NP-hard. Official choice interprets the question as what is necessarily implied.

## Solution

A polynomial reduction Q1≤p3-SAT implies Q1∈NP, by composing the reduction with a 3-SAT verifier. The reduction 3-SAT≤pQ2 makes Q2 NP-hard. Thus A is necessarily implied. The literal word consistent is weaker: taking Q1=Q2=3-SAT satisfies all four options simultaneously. The key A requires reading the question as asking what is guaranteed, not merely possible.

Teaching detail:
A reduction from Q1 to 3-SAT converts a Q1 instance in polynomial time and lets an NP verifier check the resulting formula certificate, so Q1 belongs to NP. A reduction in the other direction from an NP-complete problem to Q2 shows Q2 is at least as hard as every NP problem, so it is NP-hard; it need not belong to NP. These are directional implications, not equivalence. Literal consistency is weaker than logical entailment: choosing both problems equal to 3-SAT makes every listed classification possible, which is why the source wording is explicitly qualified.

**Paraphrased problem context:** How many states does the minimal DFA for(0+1)*(10)have?

## Solution

The language consists of binary strings ending 10. Track no matching suffix, suffix 1, and suffix 10 (accepting). On0 the transitions are q0, q2, q0; on 1 all go to q1. These three states are distinguishable: q2 accepts empty suffix, and suffix 0 distinguishes q1 from q0. Thus 3.

Teaching detail:
Track the longest suffix that is also a prefix of target 10: empty, 1, and 10. Reading 1 always leaves suffix 1. Reading 0 moves from suffix 1 to accepting 10, and otherwise to empty. These three states suffice. They are also necessary: accepting 10 differs from both nonaccepting states on ε, and suffix 1 differs from empty on continuation 0. This distinguishability proof prevents merely guessing the count from the pattern length.

## Solution

L1 consists exactly of length≥3 strings with equal first/last symbols: choose the one-symbol w and nonempty interior x. Its regex is a(a+b)(a+b)*a + b(a+b)(a+b)*b, so regular. If L2 were regular, subtracting it from a*b* would make{a^n b^n} regular, contradiction. L3=a*b*c* is regular. Thus L1, L3, A.

Teaching detail:

L2 is the unequal-count complement within a*b*. If it were regular, subtracting it from regular a*b* would make the equal-count language regular, contradicting its pumping argument. L3 has the direct regular expression a*b*c*. Thus A contains exactly the regular choices.

**Paraphrased problem context:** Which languages are context-free? L1={a^m b^n a^n b^m | m,n≥1}; L2={a^m b^n a^m b^n | m,n≥1}; L3={a^m b^n | m=2n+1}. Exponents denote nonnegative integer counts unless constrained otherwise. Options: (A) L1 and L2 only; (B) L1 and L3 only; (C) L2 and L3 only; (D) L3 only.

## Solution

1. L1=a^m b^n a^n b^m has nested dependencies: S→aSb|aTb and T→bTa|ba generates m, n≥1, so it is CFL.

2. L3 is generated by U→aaUb|a for n≥0. L2=a^m b^n a^m b^n is not CFL: for pumping length p, choose a^p b^p a^p b^p. The pumping window of length≤p touches at most two adjacent blocks, so pumping changes at least one block but cannot change its corresponding nonadjacent equal block; if a pumped piece crosses a boundary, pumping can also destroy the four-block form. Thus pumping fails. L1, L3 only, B.
