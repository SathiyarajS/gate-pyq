

# GATE 2022 CS: Q12

**Question:** [Official archived paper page 11](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

## Solution

Each return to the nonaccepting start state consumes either ab*b through the upper accepting state or ba*a through the lower one. Any number of such excursions may occur. Finally the path must stop in an accepting state, consuming ab* or ba*. Thus the language is (ba*a+ab*b)*(ab*+ba*), D. The nondeterministic return arrows and self-loops were visually checked.

**Official answer:** B,C,D

**Derived answer:** B,C,D

## Solution

A is false: a recursively enumerable language such as Σ* can have a subset that is not recursive. B is true because dovetailing recognizers for a language and its complement always finds one acceptance, giving a decider. C is true because CFL membership is decidable and decidable languages are closed under complement. D is true because a DPDA can track a regular-language DFA in its finite control without losing determinism. Thus B, C, D.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A,B,C

**Derived answer:** A,B,C

## Solution

Turing-machine language equivalence, regularity, and universality are undecidable semantic properties: fix one machine to recognize Σ* for an equivalence-to-universality reduction, and apply Rice’s theorem to the other two nontrivial language properties. D asks about a fixed finite time bound, printed as 1073. Simulate on the finitely many distinguishable input prefixes/end-marker cases visible within that many steps. This decides whether every input runs longer than the bound; complexity is enormous but finiteness suffices. Thus A, B, C.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A,B,C

**Derived answer:** A,B,C

## Solution

In L1 the arbitrary middle word absorbs all content: if n=0 is allowed, L1=Σ*; if n is required positive, taking n=1 gives aΣ*a. Either reading is regular. L2 consists exactly of strings of length at least 3 whose first and last symbols agree: take w to be the first symbol and x the nonempty middle. Hence L2=aΣ+a ∪ bΣ+b is regular. Both are therefore context-free as well, so A, B, C are true and D is false.

# GATE 2022 CS: Q48

**Question:** [Official archived paper page 32](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=32); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B,C,D

**Derived answer:** B,C,D

## Solution

The copy language L1={ww} is not context-free: intersecting with a+b+a+b+ gives {aⁱbʲaⁱbʲ: i, j>0}. For pumping length p, aᵖbᵖaᵖbᵖ has any pumping window of length at most p within at most two adjacent blocks. Pumping changes at least one block without changing its matching nonadjacent block, or creates extra alternations, contradicting this language’s form. L2 and L3 are deterministic context-free by pushing one block and matching the adjacent equal-count block; their intersection is {aⁿbⁿcⁿ}, not context-free. Thus A is true and B, C are false. D is also false because the complement of L1 is context-free: include all odd-length words, and for even length choose two different symbols in corresponding half-positions. Let E_a={uav:|u|=|v|} and E_b={ubv:|u|=|v|}; each is context-free via S_a→cS_a d | a for c, d∈Σ, and similarly S_b. E_aE_b ∪ E_bE_a describes exactly the even noncopies, since the two centers differ and are separated by half the total length. Closure under concatenation and union proves the complement claim. Select false statements B, C, D.
