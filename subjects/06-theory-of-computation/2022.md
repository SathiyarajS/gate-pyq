**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** An NFA has nonfinal start s and final states u,v. Transitions: s—a→u, s—b→v, u—b→u and s, v—a→v and s; no other transitions. Choose its regular expression (plus means union): A ab*bab*+ba*aba*; B (ab*b)*ab*+(ba*a)*ba*; C (ab*b+ba*a)*(a*+b*); D (ba*a+ab*b)*(ab*+ba*).

## Solution

Each return to the nonaccepting start state consumes either ab*b through the upper accepting state or ba*a through the lower one. Any number of such excursions may occur. Finally the path must stop in an accepting state, consuming ab* or ba*. Thus the language is (ba*a+ab*b)*(ab*+ba*), D. The nondeterministic return arrows and self-loops were visually checked.

Teaching detail:
A useful state-elimination decomposition is a sequence of complete excursions back to s, then one final unfinished excursion into u or v. Since s is nonaccepting, the final factor must consume at least one symbol; option C incorrectly admits ε. Option B disallows mixing the two types of returning excursion before the last segment.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** B,C,D

**Derived answer:** B,C,D

**Paraphrased problem context:** Select true statements: A every subset of a recursively enumerable language is recursive; B if L and its complement are recursively enumerable, L is recursive; C the complement of a context-free language is recursive; D the intersection of two regular languages is deterministic context-free.

## Solution

A is false: a recursively enumerable language such as Σ* can have a subset that is not recursive. B is true because dovetailing recognizers for a language and its complement always finds one acceptance, giving a decider. C is true because CFL membership is decidable and decidable languages are closed under complement. D is true because a DPDA can track a regular-language DFA in its finite control without losing determinism. Thus B, C, D.

Teaching detail:
For B, alternate one step of each recognizer on the same input. Exactly one must eventually accept, so the procedure always halts with the correct yes/no result. For D, regular languages are closed under intersection using a product DFA; a deterministic PDA can simulate that DFA while ignoring its stack.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A,B,C

**Derived answer:** A,B,C

**Paraphrased problem context:** Select undecidable problems: A equality of languages of two given Turing machines; B whether a given TM language is regular; C whether a TM accepts all strings; D whether a given TM takes more than the fixed printed bound 1073 steps on every string.

## Solution

Turing-machine language equivalence, regularity, and universality are undecidable semantic properties: fix one machine to recognize Σ* for an equivalence-to-universality reduction, and apply Rice’s theorem to the other two nontrivial language properties. D asks about a fixed finite time bound, printed as 1073. Simulate on the finitely many distinguishable input prefixes/end-marker cases visible within that many steps. This decides whether every input runs longer than the bound; complexity is enormous but finiteness suffices. Thus A, B, C.

Teaching detail:
A language property is nontrivial when some recognizable languages possess it and others do not. Regularity and universality satisfy this requirement, so Rice applies. Runtime within a fixed number of steps is instead a bounded execution property: only finitely many tape cells can be inspected. An astronomical fixed bound remains finite and does not become the unbounded halting problem.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A,B,C

**Derived answer:** A,B,C

**Paraphrased problem context:** Over Σ={a,b}, L1={a^n w a^n : w∈Σ*}, L2={w x w^R : w,x∈Σ*, |w|,|x|>0}. Select true statements: A both regular; B both context-free; C L1 regular and L2 context-free; D both context-free but neither regular. The source does not explicitly state the allowed n in L1.

## Solution

In L1 the arbitrary middle word absorbs all content: if n=0 is allowed, L1=Σ*; if n is required positive, taking n=1 gives aΣ*a. Either reading is regular. L2 consists exactly of strings of length at least 3 whose first and last symbols agree: take w to be the first symbol and x the nonempty middle. Hence L2=aΣ+a ∪ bΣ+b is regular. Both are therefore context-free as well, so A, B, C are true and D is false.

Teaching detail:
For L2, any allowed decomposition has equal first and last symbols and at least one middle symbol. Conversely if those conditions hold, choose |w|=1 and put everything else in x. Longer equal/reversed boundary strings are optional witnesses, not extra restrictions. This existential choice is why the language is much simpler than a general palindrome language.

**Question:** [Official archived paper page 32](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=32); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B,C,D

**Derived answer:** B,C,D

**Paraphrased problem context:** L1={ww:w∈{a,b}*}, L2={a^n b^n c^m:m,n≥0}, L3={a^m b^n c^n:m,n≥0}. Select FALSE claims: A L1 not context-free, L2/L3 deterministic context-free; B neither L1 nor L2 context-free; C L2,L3 and their intersection all context-free; D neither L1 nor its complement context-free.

## Solution

The copy language L1={ww} is not context-free: intersecting with a+b+a+b+ gives {aⁱbʲaⁱbʲ: i, j>0}. For pumping length p, aᵖbᵖaᵖbᵖ has any pumping window of length at most p within at most two adjacent blocks. Pumping changes at least one block without changing its matching nonadjacent block, or creates extra alternations, contradicting this language’s form. L2 and L3 are deterministic context-free by pushing one block and matching the adjacent equal-count block; their intersection is {aⁿbⁿcⁿ}, not context-free. Thus A is true and B, C are false. D is also false because the complement of L1 is context-free: include all odd-length words, and for even length choose two different symbols in corresponding half-positions. Let E_a={uav:|u|=|v|} and E_b={ubv:|u|=|v|}; each is context-free via S_a→cS_a d | a for c, d∈Σ, and similarly S_b. E_aE_b ∪ E_bE_a describes exactly the even noncopies, since the two centers differ and are separated by half the total length. Closure under concatenation and union proves the complement claim. Select false statements B, C, D.

Teaching detail:
For the complement construction, E_a contains odd strings whose center is a and E_b those whose center is b. Concatenating lengths 2r+1 and 2s+1 puts their centers r+s+1 positions apart, exactly half the total length. Thus choosing unequal centers witnesses unequal half-positions. Conversely any mismatching pair in two equal halves determines such a split. Odd-length strings are automatically noncopies and form a regular language.
