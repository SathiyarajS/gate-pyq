

# GATE 1994: Q15 (printed A Q1.15)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D: n(n+1)/2

**Essential problem context (paraphrased):** For a character string of length n, how many nonempty contiguous substrings are there when counted by position?

## Solution

A substring of length k can start in n−k+1 positions. Summing for k=1 through n gives n+(n−1)+…+1=n(n+1)/2. Equivalently choose its two boundaries among n+1 boundary positions. This counts occurrences, not necessarily distinct string values: repeated characters can make different positions yield the same word. It also excludes ε. If “substrings of all lengths” includes the empty word or means distinct values, the answer needs that additional convention.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Essential problem context (paraphrased):** Which equivalent-machine conversion is impossible in general: regular grammar→CFG, NFA→DFA, NPDA→DPDA, or nondeterministic TM→deterministic TM?

## Solution

Every regular grammar is already a restricted CFG, and the subset construction converts NFAs to equivalent DFAs. A deterministic TM can simulate all branches of a nondeterministic TM by dovetailing, preserving recognition power. But deterministic context-free languages are strictly fewer than context-free languages. For example unmarked palindromes over a two-letter alphabet are context-free but not deterministic context-free. Hence some NPDAs have no equivalent DPDA at all, so a general conversion cannot exist.

**Official answer:** Not available; no official key located.

**Independently derived answer:** 0*1*

**Essential problem context (paraphrased):** Start/accept state A loops on 0 and goes to accept B on 1. B loops on 1 and goes to nonaccepting trap C on 0; C loops on both. Give a regex.

## Solution

While in A the machine reads any number of zeros, possibly none. The first one moves it to B, where further ones are allowed. A zero after that moves to the trap and cannot be recovered. Thus accepted words are exactly a block of zeros followed by a block of ones, with either block allowed empty: 0*1*. The empty word is accepted because the start state A is accepting. The accepting mark on B permits words ending after one or more ones.

# GATE 1994: Q71 (printed B Q19(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** The justified choice is (ii): recursively enumerable. No claim of nonrecursiveness follows.

**Essential problem context (paraphrased):** Let S be the set of positive integers x for which the decimal expansion of π contains a maximal consecutive run of exactly x digits equal to 5. Which classification is warranted: (i) regular, (ii) recursively enumerable, (iii) not recursively enumerable, (iv) recursive?

## Solution

π is a computable real, and any finite initial segment of its decimal digits can be calculated effectively. Scan these digits from left to right, keeping the length of the current run of 5s. When a non-5 follows a nonempty run, output its length and reset the counter. Because a completed run has a non-5 immediately on each side (or begins at the start of the fractional digit stream), it is maximal rather than merely a substring of a longer run. Repeated lengths may be printed repeatedly; enumeration does not require uniqueness.

Equivalently, on input x, keep scanning until a completed run of length exactly x appears, then accept. Every positive instance eventually has a finite witness and is accepted. For an absent length the scan may never halt. This establishes recursive enumerability, the warranted answer (ii).

It does not establish that S is nonrecursive. In particular, a hypothetical proof that all finite digit blocks occur in π would make S all positive integers, which is recursive (and regular under customary encodings). Normality of π is not a given and must not be assumed. Nor does failure of this particular search to halt on negative instances prove that no different decision procedure exists. Options (i) and (iv) therefore cannot be inferred merely from the stated computability facts; describing (ii) as the only possible mathematical property would overstate the argument. A regular-language claim additionally needs an encoding of integers.

# GATE 1994: Q72 (printed B Q19(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** No. Take L1={a,b}* and L2={a^n b^n:n≥0}.

**Essential problem context (paraphrased):** If L1 and L1∪L2 are regular, must L2 be regular? Prove the answer.

## Solution

Choose the common alphabet Σ={a,b}, let L1=Σ*, and let L2={a^n b^n:n≥0}. L1 is recognized by a single accepting state with a loop on each alphabet symbol. Since L2⊆L1, their union is Σ*, also regular. Nevertheless L2 is not regular.

To verify the last assertion, suppose a pumping length p exists. The word a^p b^p must have a decomposition xyz with |xy|≤p and |y|>0. Consequently y consists of k≥1 copies of a. Pumping y zero times gives a^(p−k)b^p, which is not in L2 because the numbers of a and b differ. This contradicts the pumping lemma.

The tempting subtraction argument is invalid: (L1∪L2) minus L1 equals L2 minus L1, not necessarily L2. Regularity of the union controls the portion of L2 outside L1, but places no constraint on its arbitrary portion inside L1. Our counterexample puts all of L2 inside L1, making that gap explicit.

# GATE 1994: Q73 (printed B Q20)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 2ℓ−1 production applications for ℓ≥1.

**Essential problem context (paraphrased):** A CFG has only productions A→BC and A→a. For a generated terminal word of length ℓ, how many production applications occur in its derivation? GateForum omits the symbol after “length”; GFG supplies ℓ.

## Solution

Each terminal of the final word is introduced by exactly one A→a production: no other production introduces terminals, and no production subsequently removes them. Hence there are exactly ℓ terminal-producing steps. Start with one nonterminal. Each A→BC application increases the number of nonterminals by one, whereas each A→a decreases it by one. If b is the number of binary applications, the final nonterminal count is 1+b−ℓ=0, so b=ℓ−1. The total number of applications is b+ℓ=2ℓ−1.

The same result follows by viewing the nonterminal portion of the parse tree as a full binary tree: ℓ terminal-producing leaves require ℓ−1 binary internal nodes. The count is independent of which nonterminal is expanded first, of leftmost versus rightmost derivation, and of ambiguity of the grammar. For ℓ=1 there is just the single terminal production, agreeing with the formula.

This is a count of steps, not a count of sentential forms: including both the initial symbol and final word gives 2ℓ sentential forms. Under the strict production forms stated here ε cannot be generated. If a different CNF convention permits S→ε, its ε derivation is a separate one-step exception, not an application of the formula at ℓ=0.
