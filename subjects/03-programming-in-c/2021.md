**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

## Solution

For j=−3,−2,−1 the left operand of && is false, so i++ is not evaluated. At j=0 the old i=0 makes the condition false, but increments i to 1. At j=1, 2, 3 the old i is nonzero, adding1+2+3=6 while i reaches4. The final addition gives count=6+4=10. Thus B. Short-circuiting and postincrement order are defined by C.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 1023 to 1023

**Derived answer:** 1023

## Solution

The loop performs Horner evaluation. Starting at total=1, each of the nine iterations replaces total by 2*total+1. After k iterations total=2^(k+1)-1, so after nine iterations the result is 2^10-1=1023. All intermediate results are within even the minimum standard signed-int range.

# GATE 2021 CS2: Q20 (printed CS Q10)

**Question:** [Official archived paper page 60](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=60); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C under intended flattening; undefined in strict C

## Solution

The intended contiguous-address calculation begins at row1, column0, linear index5; advancing9 integers reaches index14=row2, column4, whose initialized value is 24, C. However arr[1] decays to a pointer into the five-element row subarray. Adding9 goes beyond that array and its one-past position, so the expression has undefined behavior under C pointer-arithmetic rules. Contiguous storage of the outer array does not legalize this cross-row pointer arithmetic. The official C is retained as the intended exam answer, not a portable guarantee.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

## Solution

The initial allocation plus three loop allocations create four nodes with values 0, 1, 2, 3. The final node’s next field is never initialized. The second loop advances head and dereferences it again each iteration; on the fourth iteration it reads that uninitialized next pointer and uses it for head->value. This is undefined behavior and may cause a runtime error, D. The loops themselves have bounded iteration counts.

# GATE 2021 CS2: Q59 (printed CS Q49)

**Question:** [Official archived paper page 85](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=85); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 60 to 60

**Derived answer:** 60

## Solution

With q=10, each initial coordinate15 requires two decrements to become nonpositive. When both remain positive the recursion branches on which coordinate decreases; once one is nonpositive only the other can decrease. Thus leaves correspond to the six interleavings of two x decrements and two y decrements, binomial(4, 2)=6. Each leaf returns 10, so the output is 60. There are no side effects across recursive calls, so unspecified operand evaluation order does not affect this sum.
