**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Initially p=1 and n=1. On iteration i, p is multiplied by x/i, so it becomes x^i/i!, which is added to n. The returned value is the truncated series sum from i=0 to y−1 of x^i/i!, approaching e^x for fixed x as y increases. Thus B in the mathematical arithmetic model; finite floating-point range/roundoff can limit the actual approximation.

# GATE 2003: Q88 (printed CS Q88)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=13), physical page 13. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

A[j] becomes true as soon as one tested k does not divide j; this is not a sieve that marks multiples. Let L be the outer-loop limit. If 3≤j≤L+1, the tested k=j−1 leaves remainder one, so j is not printed. For j>L+1, printing requires j to be divisible by every integer from 2 through L, hence by lcm(1,…,L). In the GFG floor version let r=floor(log2 n), L=2r. For n≥4, the standard bound lcm(1,…,L)≥2^(L−1)=2^(2r−1)≥2^(r+1)>n rules this out. The n=3 case is directly marked by k=2. Thus nothing is printed, D. The GateForum ceiling version tests at least as many divisors and reaches the same empty output. The LCM bound can also be established from the fact that every binomial coefficient in row L−1 divides lcm(1,…,L)/L, whose row sum is 2^(L−1).

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

main sets global x=5 and passes its address to P. P's local x becomes *y+2=7 and shadows the global only inside P. Q receives z=7; its unqualified x is the global 5, so z becomes 12 and Q prints 12. Returning to P, *y=x−1 writes 6 to the global, but P's local remains 7 and is printed. Finally main prints the global 6. The output is 12 7 6, A.
