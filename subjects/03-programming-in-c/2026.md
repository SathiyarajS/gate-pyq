

## Q34 — Programming in C: block scope and shadowing

Paper page 24; key page 1. NAT, 1 mark. **Answer: 9. Official interval: 9 to 9.**

1. The function receives its own parameter i with value 9 and parameter j with value 10. The initial comparison succeeds.
2. Inside the conditional block, a new local i is declared. It shadows the parameter i only within that block. The loop increments this inner variable from 0 to 10; it does not alter the parameter i.
3. The loop also increases the function-local j, which has no effect on the printed expression. When execution leaves the block, the inner i goes out of scope.
4. The print statement is outside the block. Its identifier i therefore refers to the parameter, still equal to 9. The output is 9, with no newline implied by the shown format string.

**Common error:** Shadowing creates a different object; it is not assignment to the outer object.

## Q39 — Programming in C / Data Structures: recursive list length

Paper page 28; key page 2. MCQ, 2 marks. **Answer: B.**

1. The input list is nonempty, so the current head points to a node. A one-node list is recognized by a null next pointer, and its length is 1.
2. If a next node exists, the tail beginning there is also nonempty. The total length is one for the current node plus the recursively computed tail length. This supplies the base condition and recursive expression in B.
3. Induction proves correctness: length 1 returns 1; assuming the routine counts a tail of length n−1, the recursive case returns 1+(n−1)=n.
4. Passing the unchanged head recursively never decreases the problem size and does not terminate on longer lists. Using head==NULL as the base test while returning 1 gives an extra count for the empty suffix. These defects eliminate the other choices.

**Assumption:** As usual for a finite singly linked list, the chain is acyclic. The question's recursion would not terminate on a cyclic structure.

# GATE 2026 CS1: Q61

**Question:** [Official master paper page 45](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=45); consult original wording and options.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 65536 to 65536

## Solution

For positive integer n, repeated integer division by two reaches 1 after floor(log2 n) divisions, so bar(n)=floor(log2 n). Thus foo(n)=1+foo(floor(log2 n)) for n>1, with foo(1)=1. Let a_j be the smallest positive n returning j. Then a_1=1, and reaching the smallest input a_j after one floor-log step requires n=2^(a_j), so a_(j+1)=2^(a_j). The thresholds are 1,2,4,16,65536. Consequently the smallest input returning 5 is 65536; its chain is 65536→16→4→2→1.
