**Essential problem context (paraphrased):** Select the correct statement about C.
(A) At most one activation record lies between the current record and main’s record.
(B) The number of activation records between the current record and main’s record depends on the actual sequence of function calls.
(C) Visibility of global variables depends on the actual sequence of function calls.
(D) Before a recursive call, the recursive function’s activation record must be saved on another stack.

## Solution

Step 1: Trace a concrete call chain.

Step 2: If main calls f and f calls g, the active stack contains main,f,g. If g recursively calls itself, another g activation is needed while the earlier one remains active. Thus the number of intervening records changes with actual calls. Lexical visibility is determined by declarations and scopes, not by this stack depth.

Conclusion and qualifications: The runtime activation chain follows the actual sequence of function calls. Its depth between the current function and main therefore depends on that sequence, B. C uses lexical rather than dynamic scope for global names, and recursive calls can use successive records on the same runtime stack.

**Essential problem context (paraphrased):** C declares char a[100][100]. Memory is byte-addressable, and the array starts at address 0. What is the address of a[40][50]?
(A) 4040; (B) 4050; (C) 5040; (D) 5050.

## Solution

Step 1: Compute the linear index before the byte address.

Step 2: There are 40 complete rows before row40, each contributing 100 characters, and 50 earlier characters within that row. Therefore the zero-based linear index is 4000+50=4050. Since sizeof(char)=1, no further scale factor is needed. The5040 alternative reverses the row and column roles.

Conclusion and qualifications: C lays out rows contiguously in row-major order. Each char occupies one byte, and each row has 100 elements. The offset of a[40][50] is 40×100+50=4050 bytes, giving address 4050 from the stipulated zero base, B.

# GATE 2002: Q69 (printed B Q11)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203519/GATE2002.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Official answer:** Not available; no official key located.

**Independently derived answer:** Blanks: n > 0; n−1, A, C, B; n−1, B, A, C

**Essential problem context (paraphrased):** Fill the three blanks in this recursive C template for Towers of Hanoi:
void move(int n, char A, char B, char C) {
    if (____) {
        move(____);
        printf("Move disk %d from pole %c to pole %c\n", n, A, C);
        move(____);
    }
}
The task is to supply the condition and the arguments of both recursive calls.

## Solution

1. Infer the parameter roles from the printed central action. move(n,A,B,C) prints a move of disk n from A to C, so A is the source, C the destination, and B the spare pole. A recursive call must preserve this source/spare/destination order even when the pole names are permuted.

2. Fill the stopping condition. For zero disks there is nothing to move. Therefore execute the body only when n > 0. Using n > 1 would incorrectly skip the required single-disk move.

3. Clear the largest disk. Before disk n can move from A to C, the n−1 disks above it must move from A to B with C available as spare. In the function’s argument order this is move(n−1,A,C,B).

4. Move the largest disk, then restore the smaller tower above it. The printed action moves disk n from A to C. Next transfer the n−1 disks from B to C using A as spare, which is move(n−1,B,A,C).

5. The completed valid C function is:

```c
void move(int n, char A, char B, char C)
{
    if (n > 0) {
        move(n - 1, A, C, B);
        printf("Move disk %d from pole %c to pole %c\n", n, A, C);
        move(n - 1, B, A, C);
    }
}
```

Use the standard stdio declaration for printf in a complete program. The three blanks, in order, are n > 0; n−1,A,C,B; and n−1,B,A,C.

6. Check n=2 explicitly. The execution moves disk 1 A→B, disk 2 A→C, and disk 1 B→C. Each move is legal and the final tower is on C. For general n, assuming both smaller recursive transfers are legal establishes correctness by induction. The move count satisfies T(0)=0 and T(n)=2T(n−1)+1, hence T(n)=2^n−1. Simulation verifies legality and final placement for n=1,…,8.
