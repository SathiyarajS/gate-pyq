**Official answer:** 19 to 19

**Derived answer:** 19

## Solution

Here **a=a[0][0]=1. Thus a+**a+2=a+3 points to the fourth row. Dereferencing that row and adding3 selects a[3][3]=19. All pointer arithmetic stays within the relevant row/outer array, so the printed expression has the defined result19.

# GATE 2020 CS: Q56 (printed CS Q46)

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 55 to 55

**Derived answer:** 55

## Solution

The two static variables named i belong to different functions and persist across calls. Starting from their initial zeros, fun1(5) increments its i five times and returns 5; subsequent fun1(4), fun1(3), fun1(2), fun1(1) return 9, 12, 14, 15 respectively. fun2 adds those five results into its own static i, so it returns 5+9+12+14+15=55. The recursive return values ignored inside fun1/fun2 do not undo updates to static storage. This assumes the displayed call is the first invocation, as intended.

# GATE 2020 CS: Q58 (printed CS Q48)

**Official answer:** 81 to 81

**Derived answer:** 81

## Solution

tob(4, arr) stores the low-to-high binary digits0, 0, 1 and returns len=3. In pp, ex is successively3, 9, 81. Only the third digit is 1, so tot changes from 1 to 81 then. The final squaring makes ex=6561 but does not change tot. Thus pp(3, 4) returns 81. All values here fit even a 16-bit signed int, so overflow does not alter this evaluation.
