**Paraphrased problem context:** For integer n, unknown initializes k=0; for i=n/2 through n inclusive, for j=2 while j≤n doubling each time, it adds n/2 to k; finally returns k. Choose growth of returned value: AΘ(n²), BΘ(n²log n), CΘ(n³), DΘ(n³log n). Integer divisions truncate; asymptotics use no-overflow mathematical arithmetic.

## Solution

The outer loop runs Θ(n) times and the doubling inner index takes Θ(log n) iterations for each. Each iteration adds a value Θ(n) to the accumulator. Thus the returned value is Θ(n² log n), B. The number of loop-body executions, and hence the usual unit-cost running time, is only Θ(n log n); the question asks for the value returned. This asymptotic calculation uses mathematical integers or assumes no integer overflow, rather than literal fixed-width C behavior for arbitrarily large n.

Teaching detail:
There are n−floor(n/2)+1 outer iterations. For n≥2 the inner values are2, 4,…, 2^floor(log2 n), so there are floor(log2 n) inner iterations each time. Each contributes floor(n/2), giving the exact mathematical-integer value [n−floor(n/2)+1]floor(log2 n)floor(n/2). Multiplying these three orders gives Θ(n²log n). A running-time answer would omit the magnitude added per iteration and would be a different question.

# GATE 2013 CS: Q60 (printed CS Q50)

**Question:** [Official archived paper page 11](https://web.archive.org/web/20130418030400id_/http://www.gate.iitb.ac.in:80/gate2013/wp-content/uploads/2013/03/CS-A.pdf#page=11); consult original wording, diagrams and choices.

**Official answer:** B

**Derived answer:** B

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

**Paraphrased problem context:** Code loops i=0…4 then j=0…2, and if A[i]==oldc[j] immediately sets A[i]=newc[j], without breaking. Maps are1 abc→dab;2 cde→bcd;3 bca→cda;4 abc→bac. Testing every5-character input from{a, b, c, d, e}, how many maps expose its replacement flaw? A1, B2, C3, D4.

## Solution

The defect is that the inner loop continues after a match, so a replacement character can match a later oldc entry and be replaced again. In case 1 (abc→dab), a becomes d, b becomes a after the a-entry has already been passed, and c becomes b after the b-entry has been passed. No input character cascades. In case 2 (cde→bcd), each replacement is absent from the remaining suffix of oldc, so again no character cascades. In case 3 (bca→cda), an original b first becomes c and then becomes d; the intended one-step result is c. In case 4 (abc→bac), an original a first becomes b and then becomes a; the intended result is b. Exhaustive length-five input testing includes strings containing b and a, respectively, so exactly cases 3 and 4 can reveal the flaw. That is two cases, option B. The five-character array need not be NUL-terminated because the code accesses exactly its five given elements.

Teaching detail:
The intended specification performs one replacement based on the original character, whereas the code repeatedly tests the updated character. For each map, inspect whether a replacement equals an oldc entry at a later j. Only later entries matter: a match with an earlier entry is never revisited. Map3 has b→c with c later, and map 4 has a→b with b later. Maps 1and2 only map backward or outside the remaining entries, so no repeated substitution can occur. Exhaustive input testing guarantees witnesses containing the affected characters.

# GATE 2013 CS: Q61 (printed CS Q51)

**Question:** [Official archived paper page 11](https://web.archive.org/web/20130418030400id_/http://www.gate.iitb.ac.in:80/gate2013/wp-content/uploads/2013/03/CS-A.pdf#page=11); consult original wording, diagrams and choices.

**Official answer:** C

**Derived answer:** C

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

**Paraphrased problem context:** Use the same nested replacement loops and four maps1 abc→dab;2 cde→bcd;3 bca→cda;4 abc→bac. For input abcde specifically, which expose the flaw? A none; B2 only; C3and4; D4 only.

## Solution

Apply each map once to each original character to obtain the intended result, then compare with the procedure’s sequential replacements. For input abcde, case 1 has intended and actual output dabde. Case 2 has intended and actual output abbcd. Case 3 should produce acdde, but its b is changed twice, b→c→d, producing addde. Case 4 should produce bacde, but its initial a is changed twice, a→b→a, producing aacde. Therefore cases 3 and 4 expose the defect, option C.

Teaching detail:
The fixed input contains every candidate letter once, including both b and a that trigger the two flaws. In map 3 the intended b→c is followed by an unintended c→d, changing the second character from expected c to d. In map 4 the intended a→b is followed by unintended b→a, undoing that substitution. Comparing complete strings confirms the discrepancy rather than relying merely on the presence of an intermediate match. Cases 1and2remain unaffected.
