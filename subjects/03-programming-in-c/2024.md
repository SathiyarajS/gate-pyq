**Official answer:** 6 to 6

**Derived answer:** 6

## Solution

Use the specified precedence, not C’s usual precedence. The high-precedence additions give(3+1+5)=9 and(7+2)=9. Right-associative subtraction gives 9−(4−(7−6))=6. Multiplication next produces9×2=18. The two divisions associate right, so the final expression is 18/(6/2)=18/3=6. All divisions here are exact.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;D

**Derived answer:** B;D

## Solution

After k iterations, x_k=2^k(x_0+y)−y, obtained by adding y to both sides of x_(k+1)=2x_k+y. The loop executes y times for the positive inputs. f(20, 10)=30×1024−10=30710, between2¹⁰ and 2²⁰, so A, C are false. f(20, 20)=40×1048576−20=41943020 and f(10, 20)=30×1048576−20=31457260 both exceed2²⁰, proving B, D. This uses an int type wide enough to hold the results, as with 32-bit signed int. On a smaller implementation signed overflow could invalidate the mathematical trace; the question does not specify int width.

**Derived answer:** A;B;D

## Solution

The pointer b advances until it reaches the terminating null byte and returns the element difference b−a, the string length. Each stated argument is a valid null-terminated four-character string, so each call returns 4. The function only reads characters; it does not modify string literals. Therefore A, B, D are true and the code is valid C. Pointer subtraction here is within the same array and the small result fits int.
