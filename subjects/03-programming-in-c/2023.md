**Question:** [Official archived paper page 33](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=33); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 7 to 7

**Derived answer:** 7

## Solution

The static local x in funcp persists across calls. Its first call increments1 to 2 and returns 2, assigned to main’s x. The second increments the same static value2 to 3; main’s y becomes3+2=5. Therefore main prints x+y=2+5=7. The local static and main’s x are distinct objects.

**Derived answer:** A

## Solution

main has three ordered children f1, f2(2), f3. The f2(2) activation first calls f3 and then recursively calls f2(1). That activation calls f3 and, because X=1, calls f1. Thus f2(2) has children f3, f2(1), and f2(1) has children f3, f1. This is activation tree A, visually verified.

# GATE 2023 CS: Q47

**Question:** [Official archived paper page 50](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=50); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C under left-before-right recursive evaluation; order not fixed by C

## Solution

Each call returns its subtree sum and prints that sum after both child calls. The leaf sums are3, 8, 13; the subtree rooted at 5 sums16; that at 11 sums24; the root sums50. If the left recursive operand is evaluated before the right, the output is 3 8 16 13 24 50, official C. However C does not specify operand evaluation order for +. Evaluating the right subtree first can instead print13 24 3 8 16 50, and the two left leaves may also appear in either order. The printed order is therefore not portable as written; the final return value50 is stable. Preserve the official answer with this missing evaluation-order assumption disclosed.
