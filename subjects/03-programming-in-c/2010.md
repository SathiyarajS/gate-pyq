**Independently derived answer:** D

**Paraphrased problem context:** What does this C program print?
#include <stdio.h>
void f(int *p, int *q) { p=q; *p=2; }
int i=0, j=1;
int main(void) { f(&i,&j); printf("%d %d\n",i,j); return 0; }
Options: (A) 2 2; (B) 2 1; (C) 0 1; (D) 0 2.

## Solution

Initially i=0 and j=1. The local parameter assignment p=q redirects p to j, without altering i or the caller’s pointer arguments. Then *p=2 writes j=2. The printed values are 0 2, option D.

Teaching detail: C passes the pointer values by value. At entry p contains &i and q contains &j; p=q copies &j into the local pointer p. It does not copy j into i. The later dereference acts on the new pointee j. Distinguish p=q, which redirects a pointer, from *p=*q, which would copy an integer.

**Independently derived answer:** C

**Paraphrased problem context:** What value does this C program print?
#include <stdio.h>
int f(int *a,int n) {
 if(n<=0) return 0;
 else if(*a%2==0) return *a+f(a+1,n-1);
 else return *a-f(a+1,n-1);
}
int main(void) { int a[]={12,7,13,4,11,6}; printf("%d",f(a,6)); return 0; }
Options: (A) −9; (B) 5; (C) 15; (D) 19.

## Solution

Evaluate from the last array element backward. The empty suffix returns 0; f([6])=6; f([11,6])=11−6=5; f([4,11,6])=4+5=9; f([13,4,11,6])=13−9=4; f([7,13,4,11,6])=7−4=3; finally 12+3=15. The function tests each current element’s parity, not its index. Printed value 15, C.

Teaching detail: The recurrence is not a flat alternating sum of the original elements: subtraction applies to the entire recursively computed suffix. Parentheses make the evaluation explicit: 12+(7−(13−(4+(11−6))))=15. Pointer arithmetic a+1 advances to the next integer and n−1 shrinks the remaining array; the parity test examines the value *a at each call.

**Independently derived answer:** D

**Paraphrased problem context:** Complete this C function so it moves the last node of a singly linked list to the front and returns the new head.
typedef struct node { int value; struct node *next; } Node;
Node *move_to_front(Node *head) {
 Node *p,*q;
 if(head==NULL || head->next==NULL) return head;
 q=NULL; p=head;
 while(p->next!=NULL) { q=p; p=p->next; }
 /* BLANK */
 return head;
}
Options: (A) q=NULL; p->next=head; head=p;; (B) q->next=NULL; head=p; p->next=head;; (C) head=p; p->next=q; q->next=NULL;; (D) q->next=NULL; p->next=head; head=p;.

## Solution

At loop exit p points to the last node and q to its predecessor. First set q->next=NULL to detach p, then p->next=head to link p before the old first node, and finally head=p. This is option D. Updating head before p->next would lose the old head and can create a self-loop; the early return already handles lists shorter than two nodes.

Teaching detail: For A→B→C, the loop ends with p=C and q=B. Detach B→C, point C→A and set head=C, obtaining C→A→B→NULL. Choice A only clears the local variable q and leaves B linked to C, producing a cycle. Choice B makes C point to itself. Choice C loses the old head connection by linking the last node to its predecessor instead.
