**Essential problem context (paraphrased):** A random variable has E[X]=5. Must some outcome have X=5, X>5, X≥5, or none of these?

## Solution

Suppose every outcome had X<5. Then Y=5−X is positive everywhere. Since a positive random variable has positive expectation, E[Y]>0, contradicting E[Y]=5−E[X]=0. Hence some outcome has X≥5. Equality need not occur: equal probabilities on 4 and 6 have mean 5 but never value 5. Nor must a value exceed 5: the constant variable X=5 is a counterexample. Thus only C is forced, assuming the stated finite expectation.

**Essential problem context (paraphrased):** How many binary relations exist on a set of n elements? Options: n,2^n,2^(n²),none.

## Solution

A binary relation is any subset of the Cartesian product S×S. There are n choices for each coordinate, hence n² ordered pairs. Each pair independently either belongs to the relation or does not. Multiplying the two choices over n² pairs gives 2^(n²), C. No reflexivity, symmetry or function restriction is imposed; imposing one would change the count.

**Essential problem context (paraphrased):** Count strings containing n zeros and k ones with no adjacent ones. The listed binomial choice A is C(n+1,k).

## Solution

First place the n zeros in their fixed order. They create n+1 gaps: before the first zero, between consecutive zeros, and after the last zero. A valid string uses at most one 1 in each gap, otherwise two ones would be adjacent. Choose exactly k of those gaps, giving C(n+1,k). Conversely every such choice creates one valid string, so this is a bijection rather than merely an upper bound. When k>n+1 the count is zero.

# GATE 1999: Q51 (printed B Q3(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 3 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** The proof assumes every x has some related y; symmetry and transitivity do not guarantee this.

**Essential problem context (paraphrased):** For a relation R on a set X, Mr. X claims symmetry and transitivity imply reflexivity. His proof starts with xRy, obtains yRx by symmetry, and then xRx by transitivity. Briefly identify the flaw. (This final instruction appears in GFG but is omitted from GateForum.)

## Solution

1. Reflexivity requires xRx for every x in the specified underlying set X. The proof must therefore start with an arbitrary x, not with an arbitrarily available related pair.

2. Its deductions from xRy are valid: symmetry gives yRx, and transitivity then gives xRx. What is unjustified is the premise that, for each x, there exists any y with xRy.

3. Thus the argument proves only: if x occurs as the first coordinate of some pair in R, then xRx. Elements outside that domain may have no related pairs at all.

4. For example, on X={0,1}, R={(0,0)} satisfies symmetry and transitivity but does not contain (1,1). Replacing the missing premise with an assumption that every x relates to some y would make the proposed proof valid.

## Solution

Choose X={0,1} and R={(0,0)}. Symmetry holds because the reverse of its only pair is the same pair. For transitivity, if xRy and yRz hold, both pairs must be (0,0), so x=z=0 and the required pair xRz=(0,0) is in R. However, reflexivity on X would require both (0,0) and (1,1); the latter is absent.

The universe matters: this same relation would be reflexive on {0}. Alternatively, the empty relation on any nonempty set works, since symmetry and transitivity are vacuously true while at least one required diagonal pair is missing.

**Independently derived answer:** Left multiplication h↦ah is a bijection H→aH.

**Essential problem context (paraphrased):** Let G be a finite group, H a subgroup, and aH={ah:h∈H} for a∈G. Prove |aH|=|H|.

## Solution

Define φ:H→aH by φ(h)=ah. It is surjective by the definition of aH: every element there is ah for some h in H. It is injective because ah₁=ah₂ implies h₁=h₂ after multiplying on the left by a⁻¹. Thus φ is a bijection, proving equal cardinalities. Its inverse is x↦a⁻¹x, which sends each x=ah back to h∈H. Commutativity is unnecessary; the side on which cancellation occurs must remain consistent.

**Essential problem context (paraphrased):** Let G be a finite group, H a subgroup, and aH={ah:h∈H} for a∈G. Prove aH=bH or aH∩bH=∅ for all a,b∈G.

## Solution

If the intersection is empty there is nothing to prove. Otherwise choose x=ah₁=bh₂ with h₁,h₂∈H. Rearrangement gives b⁻¹a=h₂h₁⁻¹∈H, using subgroup closure and inverses.

For any ah∈aH, write ah=b(h₂h₁⁻¹h). The parenthesized product belongs to H, so ah∈bH; hence aH⊆bH. Likewise a⁻¹b=h₁h₂⁻¹∈H gives bH⊆aH. Therefore aH=bH.

This proof does not assume the cosets themselves are subgroups, which need not be true. The subgroup properties are used only for products of the h-elements.

**Independently derived answer:** |G|=[G:H]|H|, so |H| divides |G|.

**Essential problem context (paraphrased):** Let G be a finite group, H a subgroup, and aH={ah:h∈H} for a∈G. Use equal coset sizes and the equal-or-disjoint property to show |H| divides |G|.

## Solution

Every g∈G belongs to gH because the identity e lies in H and g=ge. Thus all left cosets cover G. By the previous part, distinct left cosets do not overlap; they form a partition. Finiteness of G means there are a finite number r of distinct cosets. Each has |H| elements by the multiplication bijection. Counting the disjoint union yields |G|=r|H|. Since r is an integer, |H| divides |G|. The number r is called the index [G:H]; no normality assumption is needed.

## Solution

An upper bound is immediate: C has degree two, so deleting BC and CF isolates C. Hence the minimum cut has size at most two.

To exclude a one-edge cut, show that no edge is a bridge. The cycle A–B–C–F–A contains AB, BC, CF, AF. The triangle A–B–D–A contains BD and AD. The triangle A–D–E–A contains DE and AE. Finally the triangle D–E–F–D contains EF and DF. Together these cycles cover every edge of G.

An edge on a cycle cannot be a bridge because the rest of that cycle provides an alternate path between its endpoints after deletion. The graph is connected initially, so a zero-edge cut is impossible. Therefore its minimum cut cardinality is exactly two.

**Essential problem context (paraphrased):** Let G be a connected undirected graph with n≥2 vertices and min-cut cardinality k. Prove G has at least nk/2 edges.

## Solution

For each vertex v, delete all edges incident to v. This isolates v from the other n−1 vertices, so those deg(v) edges form a cut. Since k is the minimum possible cut size, deg(v)≥k for every v.

Sum these n inequalities to obtain Σᵥdeg(v)≥nk. By the handshake lemma, every undirected edge contributes one to each endpoint degree, and therefore Σᵥdeg(v)=2|E|. Dividing by two gives |E|≥nk/2. If nk is odd, the integer edge count is in fact at least ⌈nk/2⌉. The proof explains why the minimum cut bounds every degree rather than merely the average degree.

**Independently derived answer:** Counterexample p=false, q=true.

**Essential problem context (paraphrased):** Show that (¬p ∨ q) ⇒ (q ⇒ p) is not a tautology.

## Solution

An implication is false precisely when its antecedent is true and consequent false. Set p=false and q=true. Then ¬p ∨ q=true ∨ true=true, but q ⇒ p=true ⇒ false=false. The whole formula is therefore false. One counterexample suffices to refute a tautology; it need not be false on every valuation. Indeed the formula simplifies to p ∨ ¬q: ¬(¬p ∨ q) ∨ (¬q ∨ p)=(p ∧ ¬q) ∨ ¬q ∨ p=p ∨ ¬q. Its values for (p,q)=(F,F),(F,T),(T,F),(T,T) are T,F,T,T.

Take an arbitrary valuation v of every propositional variable occurring in A or B. Because A is a tautology, v(A)=true regardless of that valuation. No assumption about satisfiability of B is needed: B may be a tautology, contradiction, or contingent formula.
