**Independently derived answer:** B

## Solution

The universal relation S×S is an equivalence relation with n² pairs. Reflexivity requires every diagonal pair(s,s), and those n pairs alone form the identity equivalence relation. Hence the largest and smallest counts are n² and n, B.

# GATE 2007: Q4 (printed CS Q4)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 2. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B for the minimal nonplanar core

## Solution

By Kuratowski’s theorem a nonplanar graph contains a subdivision of K5 or K3,3. Such a subgraph needs at least10 or9 edges respectively. K3,3 attains the9-edge minimum with6 vertices, giving B. The vertex count is not forced by edge minimality alone: isolated vertices can be added without changing the9 edges or nonplanarity. Thus6 is the minimum/core vertex count, not a universal claim for every graph minimizing only edges.

# GATE 2007: Q48 (printed CS Q48)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 11. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

For the conventional setting in which each clause contains at least one literal, consider any assignment and its bitwise complement. Every clause is satisfied by at least one of the two: choose any literal in it, which is true in one assignment. Hence the two assignments together satisfy at least m clause occurrences, and one satisfies at least m/2. This proves A. B fails for (x)∧(¬x), and the same half-clause guarantee rules out C. If empty clauses are permitted, the unstated nonempty-clause assumption matters: a formula consisting only of empty clauses is never satisfied at all, so A would fail and C could hold. The intended CNF convention excludes this degenerate case.

**Independently derived answer:** D

## Solution

Subtract paths using the forbidden edge (4,4)->(5,4) from all C(20,10) paths. A path using that edge has C(8,4) choices to reach (4,4), then the fixed forbidden step, then C(11,5) choices for five right and six up moves from (5,4) to (10,10). Thus the permitted count is C(20,10)-C(8,4)*C(11,5)=184756-70*462=152416, option D.
