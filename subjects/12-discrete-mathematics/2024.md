**Type / marks:** NAT, 1 mark(s).

**Official answer:** 2 to 2

**Derived answer:** 2

## Solution

Write |A|=|B|=n≥1 from the first bijection, and t=|A∩B|. The second requires n²=|A∪B|=2n−t, with 0≤t≤n. Hence n²≤2n, so n is 1 or2. Both work: n=1 with A=B gives t=1; n=2 with A, B disjoint gives t=0. There are therefore2 possible values.

# GATE 2024 CS1: Q51

**Question:** [Official archived paper page 32](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=32); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

## Solution

A proper k-colouring divides n vertices into k independent colour classes, so some class has size at least n/k, proving B. In a minimum colouring every pair of colour classes has at least one joining edge; otherwise the pair could be merged to use k−1 colours. Distinct pairs require distinct edges, so at least k(k−1)/2 edges exist, proving C. A fails for the five-cycle, whose chromatic number is 3 but has no triangle. D fails for K_k, whose vertices all have degree k−1. Thus B, C.

# GATE 2024 CS1: Q52

**Question:** [Official archived paper page 32](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=32); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;D

**Derived answer:** B;D

## Solution

For diamond, (a◇b)◇c=a+2b+2c while a◇(b◇c)=a+2b+4c, so it is not associative. Square is ordinary multiplication and is associative. Multiplication distributes over diamond on both sides: a(b+2c)=ab+2ac and (a+2b)c=ac+2bc. Diamond does not distribute over multiplication: with a=b=c=1, a◇(b□c)=3 but (a◇b)□(a◇c)=9. Therefore B, D.

# GATE 2024 CS2: Q51

**Question:** [Official archived paper page 36](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=36); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

## Solution

Fix a cycle C and an edge e on it. The path C minus e is acyclic and can be extended to a spanning tree T. For any other cycle edge f, T−f+e is another spanning tree. Both tree weights are even, so w(e)−w(f) is even. Thus every pair of cycle edges has the same parity, proving D. A and B fail for a graph that is itself a tree with edge weights1, 1, 2: its only spanning tree has even total 4 but mixed parity. C fails for a triangle with all three weights1, whose spanning trees all weigh2 although its cycle edges are odd.

**Official answer:** 4 to 4

**Derived answer:** 4

## Solution

An element is its own inverse exactly when twice it is 0 in each coordinate. Z2 contributes0, 1 (two choices); Z3 contributes only 0; Z4 contributes0, 2 (two choices). The product group therefore has 2×1×2=4 such elements.
