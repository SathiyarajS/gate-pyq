

# GATE 2024 CS1: Q32

**Question:** [Official archived paper page 20](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=20); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 2 to 2

**Derived answer:** 2

**Paraphrased problem context:** Nonempty finite sets A and B admit bijections A→B and A×A→A∪B. How many different values of |A| are possible?

## Solution

Approach: Turn the bijections into cardinality equations, use the range of the intersection size, and then prove that every remaining candidate is achievable.
1. The first bijection gives |A|=|B|=n for an integer n≥1. Put t=|A∩B|, so 0≤t≤n.
2. The second bijection gives |A×A|=|A∪B|. Therefore n²=2n−t.
3. Since t≥0, n²≤2n. Dividing by positive n yields n≤2. Thus only n=1 and n=2 can work.
4. For n=1, choose A=B={a}. Then n²=1=|A∪B| and both bijections exist. For n=2, choose disjoint sets A={a,b} and B={c,d}; both A×A and A∪B have four elements, so a bijection exists between them.
Answer: 2 possible values. The question asks for the number of possible cardinalities, not the number of choices of the sets themselves.

# GATE 2024 CS1: Q34

**Question:** [Official archived paper page 21](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=21); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 16 to 16

**Derived answer:** 16

**Paraphrased problem context:** How many spanning trees does the complete graph on four labelled vertices A, B, C and D have?

## Solution

Approach: A spanning tree uses all vertices, is connected and has no cycle. Since the graph is complete, every labelled tree on these vertices is available.
1. Cayley's formula states that the complete graph K_n has n^(n−2) labelled spanning trees. Substituting n=4 gives 4²=16.
2. We can verify this without the formula by classifying four-vertex tree shapes. A tree has three edges. It is either a star with one vertex of degree 3 or a path with degrees 1,2,2,1.
3. There are four stars, one for each choice of centre. For a path, arrange all four labels in an order. Reversing the order describes the same undirected path, so there are 4!/2=12 paths.
4. These shapes are disjoint and exhaustive, giving 4+12=16.
Answer: 16. Counting arbitrary three-edge subsets would also include disconnected or cyclic selections, so not every such subset is a spanning tree.

# GATE 2024 CS1: Q51

**Question:** [Official archived paper page 32](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=32); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

**Paraphrased problem context:** A graph G has n vertices and chromatic number k, the minimum number of colors in a proper coloring. Which always hold? A G contains K_k as a subgraph. B G has an independent set of size at least n/k. C G has at least k(k−1)/2 edges. D G has a vertex of degree at least k.

## Solution

Approach: A proper coloring partitions vertices into independent color classes. Use a coloring with exactly k colors to prove B and C, and small graphs to test A and D.
1. The k color classes together contain n vertices. By the pigeonhole principle, some class has at least n/k vertices (in fact at least ceil(n/k)). No two in that class are adjacent, proving B.
2. Every pair of color classes must have at least one edge between them. Otherwise those two classes could use the same color, producing a (k−1)-coloring and contradicting minimality.
3. There are choose(k,2)=k(k−1)/2 pairs of classes. An edge belongs to only one such pair, so at least that many edges are necessary. C is true.
4. A fails for the five-cycle: its chromatic number is 3, but it contains no triangle K3. D fails for K_k itself, where every vertex has degree k−1 rather than at least k.
Answer: B and C. A clique of size k forces at least k colors, but needing k colors does not force a k-clique.

# GATE 2024 CS1: Q52

**Question:** [Official archived paper page 32](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=32); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;D

**Derived answer:** B;D

**Paraphrased problem context:** For positive integers, define a◇b=a+2b and a□b=ab. Which claims are true? A ◇ is associative. B □ is associative. C ◇ distributes over □. D □ distributes over ◇.

## Solution

Approach: Write both sides of each proposed identity using the definitions. An operation's symbol does not give it familiar arithmetic properties automatically.
1. For associativity of ◇, (a◇b)◇c=a+2b+2c, whereas a◇(b◇c)=a+2b+4c. Because c>0, they differ, so A is false.
2. □ is ordinary multiplication: (a□b)□c=(ab)c=a(bc)=a□(b□c). B is true.
3. For ◇ distributing over □, a◇(b□c)=a+2bc, but (a◇b)□(a◇c)=(a+2b)(a+2c). Taking a=b=c=1 yields 3 versus 9, disproving C.
4. Multiplication distributes over ◇ on both sides: a□(b◇c)=a(b+2c)=ab+2ac=(a□b)◇(a□c), and (a◇b)□c=(a+2b)c=ac+2bc=(a□c)◇(b□c).
Answer: B and D. Checking both sides is useful because ◇ is not commutative, so left and right distributive identities should not be silently identified.

## Solution

Approach: Identify the condition and then negate the correct proposition.

1. Derivation. The phrase when q makes q the sufficient condition. Its consequence is that fail grade cannot be given, namely NOT p. Therefore the statement is q→NOT p, option A; the converse is not asserted.

2. Explanation and checks. The only prohibited case is q true together with p true: a student exceeds the threshold yet a fail grade can be given. The implication q→¬p excludes exactly that case. When q is false, the sentence says nothing about whether a fail grade can be given. Option D incorrectly turns sufficient marks into a necessary condition for not giving a fail grade; it asserts the converse.

# GATE 2024 CS2: Q17

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** A is the adjacency matrix of a simple undirected graph and A=A^−1. What must the graph be? A a cycle; B a perfect matching; C a complete graph; D no such graph exists.

## Solution

Approach: Convert the inverse equation to A²=I and count length-two walks.

1. Derivation. A=A⁻¹ implies A²=I. For a simple undirected graph, diagonal entry(A²)ᵥᵥ counts the neighbors of v, so every vertex has degree1. Thus the graph is a disjoint union of edges covering all vertices, a perfect matching. Conversely each two-vertex edge adjacency block squares to identity. Answer B.

2. Explanation and checks. Because A is symmetric with entries 0 or 1, (A²)vv=sum_u A_vu A_uv=sum_u A_vu=degree(v). The identity matrix has diagonal 1, forcing every degree to be exactly one. Following the sole edge from any vertex reaches a partner whose sole edge comes back, so components are isolated two-vertex edges. Such graphs exist whenever the number of vertices is even; they need not form one cycle or a complete graph.

# GATE 2024 CS2: Q34

**Question:** [Official archived paper page 23](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=23); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 5 to 5

**Derived answer:** 5

**Paraphrased problem context:** On {1,2,3,4}, a partial order contains every reflexive pair and (1,2),(3,2),(3,4). How many total orders extend it?

## Solution

Approach: Choose only minimal elements first and branch on those choices.

1. Derivation. The restrictions are1 before 2, 3 before 2, and 3 before 4. If1 is first, 3 must be second and 2, 4 may be ordered either way, giving1324 and 1342. If3 is first, the remaining order only requires1 before 2, giving3124, 3142, 3412. These exhaust the choices, so there are5 linear extensions.

2. Explanation and checks. Initially 1 and 3 are eligible: 2 requires both to precede it, while 4 requires 3. In the branch starting with 1, only 3 is eligible next, leaving two orders of 2 and 4. In the branch starting with 3, the remaining three elements need only respect 1 before 2, which holds in half of their 3!=6 permutations. The reflexive pairs impose no extra restriction on the sequence of distinct elements.

# GATE 2024 CS2: Q51

**Question:** [Official archived paper page 36](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=36); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** A connected undirected graph has positive integer edge weights and every spanning tree has even total weight. What must hold? A all edges even; B all edges share one parity; C every cycle has only even edges; D within each cycle all its edges share one parity.

## Solution

Approach: Exchange one cycle edge in a spanning tree and compare the two total weights modulo two.

1. Derivation. Fix a cycle C and an edge e on it. The path C minus e is acyclic and can be extended to a spanning tree T. For any other cycle edge f, T−f+e is another spanning tree. Both tree weights are even, so w(e)−w(f) is even. Thus every pair of cycle edges has the same parity, proving D. A and B fail for a graph that is itself a tree with edge weights1, 1, 2: its only spanning tree has even total 4 but mixed parity. C fails for a triangle with all three weights1, whose spanning trees all weigh2 although its cycle edges are odd.

2. Explanation and checks. The extension step is justified because any acyclic edge set in a connected graph can be extended to a spanning tree by repeatedly joining components. Adding e to the tree containing C−e creates exactly the cycle C, so removing any f in that cycle returns a tree. Equal parity of tree sums forces equal parity of e and f. Bridges do not belong to cycles, explaining why D places no restriction on their individual parity and why global uniform parity need not follow.

**Paraphrased problem context:** The diagram has eight marked vertices numbered clockwise from the upper-left corner of its top horizontal edge: 1 top-left,2 top-right,3 upper-right,4 lower-right,5 bottom-right,6 bottom-left,7 lower-left,8 upper-left. Edges are the boundary cycle 12,23,34,45,56,67,78,81 plus 14,16,25,27,36,38,47,58. Unmarked crossings are not vertices. Find the chromatic number.

## Solution

Approach: Produce a valid coloring and separately show that fewer colors cannot suffice.

1. Derivation. Number the eight marked boundary vertices cyclically. Every drawn edge joins an odd-numbered vertex to an even-numbered one, so alternating two colours is a valid colouring. There is at least one edge, ruling out one colour. Thus the chromatic number is 2. Unmarked line crossings are not additional graph vertices; the source diagram was visually inspected.

2. Explanation and checks. The two classes are {1,3,5,7} and {2,4,6,8}. Inspection of the full edge list shows every edge crosses between classes, so no two adjacent vertices share a color under this assignment. In fact the listed graph is K4,4, with all sixteen cross-class edges present. It has edges such as 12, so assigning just one color is impossible. Geometric crossings in a drawing do not imply graph adjacency without marked vertices.

# GATE 2024 CS2: Q63

**Question:** [Official archived paper page 39](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=39); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4 to 4

**Derived answer:** 4

**Paraphrased problem context:** Zn is the additive group modulo n. How many elements of Z2×Z3×Z4 are their own inverse?

## Solution

Approach: Solve 2x=0 modulo the corresponding modulus independently in each coordinate.

1. Derivation. An element is its own inverse exactly when twice it is 0 in each coordinate. Z2 contributes0, 1 (two choices); Z3 contributes only 0; Z4 contributes0, 2 (two choices). The product group therefore has 2×1×2=4 such elements.

2. Explanation and checks. The identity element counts: it is always its own inverse. In Z2 both residues satisfy 2x≡0; in Z3 only zero does, because two is invertible modulo three; in Z4 the solutions are zero and two. Explicitly the four product elements are (0,0,0), (0,0,2), (1,0,0), (1,0,2). The coordinate choices multiply because the group operation is coordinatewise, so there is no additional compatibility condition between them.
