**Paraphrased problem context:** On ordered pairs of integers define (x,y)R(u,v) iff x<u and y>v. Classify R, with partial order understood in the usual reflexive sense.
Options:
(A) Neither a partial order nor an equivalence relation
(B) A partial order but not a total order
(C) A total order
(D) An equivalence relation

## Solution

1. For every pair(x,y), x<x is false, so the relation is not reflexive. It is therefore neither an equivalence relation nor a reflexive partial order, A.

2. It is transitive and irreflexive, hence a strict partial order in terminology that explicitly distinguishes strict orders; it is not total because pairs with equal first coordinate are incomparable.

3. Teaching check: To test reflexivity, substitute the very same pair on both sides. The required inequalities become x<x and y>y, both false. Although transitivity holds by chaining strict inequalities, transitivity alone does not meet the definition of a reflexive partial order.

**Paraphrased problem context:** Let X={2¹,2²,…,2ⁿ}. Form S⊆X by independently selecting each element with probability 1/2. What is the expected smallest element of S? The reproduced question does not specify what to do when S is empty.
Options:
(A) 1/n
(B) 2
(C) √n
(D) n

## Solution

1. The event that2^i is the minimum requires excluding the i−1 smaller values and including2^i, with probability2^-i. Summing2^i×2^-i over i=1,...,n gives n.

2. But the empty sample occurs with probability2^-n and has no smallest element. Thus the expectation as literally stated is undefined.

3. Setting the empty-sample value to0 gives n, D; conditioning on a nonempty sample instead gives n/(1−2^-n). No official answer is inferred.

4. Teaching check: There are n disjoint events “2^i is the minimum,” each contributing exactly one to the unconditioned sum when the empty case is assigned zero. Their probabilities sum to 1−2^(−n), not one. Dividing by that nonempty probability produces the conditional expectation.

**Paraphrased problem context:** Let N={1,…,n} and A,B⊆N. How many permutations π of N satisfy min(π(A))=min(π(B)), where π(S)={π(s):s∈S}? The minimum requires nonempty A and B, although the reproduction says arbitrary subsets.
Options:
(A) (n−|A∪B|)|A||B|
(B) (|A|²+|B|²)n²
(C) n!·|A∩B|/|A∪B|
(D) |A∩B|²/C(n,|A∪B|)

## Solution

1. The minima of π(A) and π(B) agree exactly when the smallest image among A∪B belongs to A∩B. By symmetry every member of A∪B is equally likely to have that image, so the fraction is |A∩B|/|A∪B|.

2. Multiply by n! to get C. The statement allows arbitrary subsets, but min of an empty set is undefined; nonempty A,B are required for this calculation.

3. If they are disjoint and nonempty the answer is0.

4. Teaching check: Only the relative order of images of A∪B matters. If its earliest image comes from an element outside the intersection, one subset has a strictly earlier minimum than the other. Uniform permutations make each union element equally likely to be earliest, giving the intersection-to-union ratio.

Options:
(A) C(n/2,2)·2^(n/2)
(B) 2^(n−2)
(C) 3·2^(n−3)
(D) 2^(n−1)

## Solution

1. For a vertex S with |S|=k, choose the two intersection elements from S and any subset outside S, giving C(k,2)·2^(n−k) candidate neighbors. When k=2 subtract one to exclude S itself; for k=0,1 degree is zero.

2. For k≥3, the ratio of successive degrees is (k+1)/(2(k−1)), equal to 1 at k=3 and less than 1 for k>3. The maximum is therefore attained at k=3 and k=4, with degree 3·2^(n−3).

3. This exceeds the k=2 degree 2^(n−2)−1. Thus C.

4. Teaching check: For a size-k set, choose which two of its k elements are in the neighbor; no other element of the set may be in that neighbor. Every outside element is freely included or excluded. Exclude a self-neighbor only when k=2, then compare successive k values rather than assuming k=n/2 maximizes the degree.
