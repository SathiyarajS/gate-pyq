**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=1), physical page 1. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** fill-in, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 3n−6 for simple planar graphs with n≥3

**Essential problem context (paraphrased):** What is the maximum number of edges of a planar graph with n vertices?

## Solution

For a connected simple planar embedding, Euler gives n−m+f=2. Every face boundary has length at least three, while each edge contributes two boundary incidences, so 3f≤2m. Combining gives m≤3n−6, attained by triangulations. Disconnected simple graphs cannot exceed that maximum. Simplicity and n≥3 are necessary qualifications: parallel edges can make edge count unbounded for fixed n, and the small cases n=1, 2 have maxima 0, 1. The familiar formula is therefore a conditional standard answer, not valid for every use of the word graph.

**Essential problem context (paraphrased):** Which listed vertex/edge counts describe a nonplanar simple graph with the fewest vertices:9 edges 6 vertices, 6 edges 4 vertices, 10 edges 5 vertices, 9 edges 5 vertices?

## Solution

Every simple graph on at most four vertices is a subgraph of planar K4, so nonplanarity requires at least five vertices. On five vertices, K5 is nonplanar and has 10 edges. Removing any edge from K5 gives a planar graph, so a five-vertex graph with only nine edges does not supply the required example. K3, 3 has nine edges but six vertices, so it minimizes a different quantity. The question asks for fewest vertices, not fewest edges.

**Official answer:** Not available; no official key located.

**Independently derived answer:** n−p

**Essential problem context (paraphrased):** A forest has n vertices and p connected components. How many edges?

## Solution

Every component of a forest is a tree. If component i has ni vertices, it has ni−1 edges. Summing over the p components gives Σ(ni−1)=Σni−p=n−p. Isolated vertices count as one-vertex components with zero edges, so the formula handles them automatically. The acyclicity assumption is essential: a graph with cycles can have more edges with the same n and p. The empty forest gives zero with n=p=0.

# GATE 1992: Q63 (printed B Q14(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** True: inverse pairing leaves a nonidentity self-inverse element.

**Essential problem context (paraphrased):** Let G be a group of even order with identity e. Show that some a≠e satisfies a²=e.

## Solution

Here “even order” means finite order |G|=2m. Consider inversion g↦g⁻¹. Every element whose inverse is different forms a two-element pair {g,g⁻¹}; these pairs are disjoint because taking the inverse twice returns g. The remaining elements are fixed points of inversion, satisfying g=g⁻¹, equivalently g²=e.

The paired elements account for an even number of elements. Subtracting this number from the even total |G| shows that the number of fixed points is even. Identity e is one fixed point, so there cannot be exactly one: another fixed point a≠e exists. Multiplying a=a⁻¹ by a gives a²=e, as required. Since a≠e, its order is exactly two.

Equivalently, G\{e} has odd size and cannot be completely partitioned into distinct inverse pairs; one nonidentity self-inverse element must remain. This proof uses neither commutativity nor any assumption that G is cyclic. It proves existence, not uniqueness: some groups have several nonidentity involutions. The finite-even-order qualification matters; an infinite group is not classified as even merely by an informal pairing argument.

# GATE 1992: Q64 (printed B Q14(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MSQ, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Only (iv), lattice.

**Essential problem context (paraphrased):** On D={1,2,3,4,6,8,12,24}, use the binary operations LCM and GCD. Which structures apply: (i) group, (ii) ring, (iii) field, (iv) lattice?

## Solution

D is exactly the positive divisors of 24=2³·3. Order D by divisibility, not by the ordinary numerical ≤ relation. Every d is uniquely 2^i3^j with 0≤i≤3 and 0≤j≤1. GCD takes the coordinatewise minimum of exponent pairs, and LCM takes their coordinatewise maximum. Both outputs are again divisors of 24, proving closure.

For x,y∈D, gcd(x,y) divides both and every common divisor divides it, so it is their greatest lower bound (meet). Likewise lcm(x,y) is their least upper bound (join). Thus every pair has a meet and join: (D,gcd,lcm) is a lattice, option (iv). In fact it is a bounded distributive lattice, with bottom 1 and top 24. For example gcd(8,12)=4 and lcm(8,12)=24.

Neither operation makes this nontrivial set a group. Both are idempotent: x⋆x=x. In a group, cancellation would force every idempotent x to equal the identity, impossible for eight distinct elements. More concretely, LCM has identity 1 but 2 has no inverse giving LCM(2,y)=1; GCD has identity 24 but 2 has no inverse giving GCD(2,y)=24. Consequently these operations cannot provide the additive group required for a ring, in either assignment of addition and multiplication, and cannot form a field. Do not classify it as a group merely because the operations are closed and associative.

(1) ∀x [Q(x) → (P(x) ∨ ¬R(a))]
(2) R(a) [missing connective] ¬Q(a)

## Solution

Convert (1) to the universally quantified clause ¬Q(x)∨P(x)∨¬R(a). Instantiate x=a and resolve with (3), Q(a), to obtain P(a)∨¬R(a). Instantiate (4) at y=a, obtaining ¬P(a); resolve to get ¬R(a). The repaired (2), R(a)∨¬Q(a), resolves with Q(a) to give R(a). Resolving R(a) and ¬R(a) yields the empty clause □. Hence the disjunction repair is inconsistent.

The same reasoning can be written with modus ponens: Q(a) and (1) imply P(a)∨¬R(a); ¬P(a) forces ¬R(a). Under the disjunction repair, (2) is Q(a)→R(a), so Q(a) forces R(a), a contradiction.

If the missing connective were ∧, (2) would directly include ¬Q(a), contradicting (3), so that repair is also inconsistent. But if it were →, the set would be consistent: take a singleton domain {a}, Q(a)=true, P(a)=false, and R(a)=false. Then (1) is true because ¬R(a) is true, (2) R(a)→¬Q(a) is vacuously true, (3) is true, and (4) is true. This countermodel shows why the missing connective cannot be dismissed as harmless typography or filled in without disclosure. The requested unconditional proof is blocked by the defective premise, while the explicitly labeled repaired proof is complete.

# GATE 1992: Q66 (printed B Q15(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Independently derived answer:** R is congruence modulo n; for n=5 the classes are 5ℤ,5ℤ+1,5ℤ+2,5ℤ+3,5ℤ+4.

**Essential problem context (paraphrased):** On S=ℤ fix n>1 and define aRb iff a−b is a multiple of n. Prove that R is an equivalence relation and find its classes when n=5.

## Solution

Prove all three defining properties using divisibility.

Reflexivity: for each a, a−a=0=n·0, so aRa.
Symmetry: if aRb, then a−b=nk for an integer k. Hence b−a=n(−k), so bRa.
Transitivity: if aRb and bRc, write a−b=nk and b−c=nℓ. Adding gives a−c=n(k+ℓ), so aRc.
Thus R is an equivalence relation.

For n=5, the division algorithm gives every integer z a unique remainder r∈{0,1,2,3,4}, including negative integers. Two integers are related exactly when these remainders agree. The five distinct classes are:
[0]={5k:k∈ℤ}={…,−10,−5,0,5,10,…}
[1]={5k+1:k∈ℤ}={…,−9,−4,1,6,11,…}
[2]={5k+2:k∈ℤ}={…,−8,−3,2,7,12,…}
[3]={5k+3:k∈ℤ}={…,−7,−2,3,8,13,…}
[4]={5k+4:k∈ℤ}={…,−6,−1,4,9,14,…}.

They cover ℤ by existence of remainders. They are disjoint because equality 5k+r=5ℓ+s implies 5 divides r−s, and for r,s in 0…4 this forces r=s. Representatives are not unique: for example [−1]=[4], but these are the same class, not a sixth class.
