**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2009.pdf, physical page 2. Consult original wording and choices.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Which property is not required of a group? A commutativity; B associativity; C an inverse for each element; D an identity element.

## Solution

Associativity, an identity and inverses are group axioms. Commutativity is an additional property of abelian groups, not all groups; for example permutations of three objects need not commute. Thus A.

Teaching detail:
A group requires closure, associativity, an identity and an inverse for every element. Commutativity is an extra condition defining an abelian group. For a counterexample to its necessity, permutations of three objects form a group under composition, but swapping 1/2 then 2/3 differs from doing those swaps in reverse order. Thus A is not a required axiom; B, C, D are.

# GATE 2009: Q2 (printed CS Q2)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2009.pdf, physical page 2. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** A simple connected graph on n≥2 vertices has no odd cycle. Find its chromatic number: A 2; B 3; C n−1; D n.

## Solution

An undirected graph with no odd cycle is bipartite, so two colors suffice. Connectedness and n≥2 ensure at least one edge, so one color cannot suffice. The chromatic number is exactly 2, A.

Teaching detail:
A graph has a two-colouring exactly when it has no odd cycle. One construction assigns colours by even or odd distance from a chosen root. If an edge joined equal-parity vertices, the corresponding paths would create an odd closed walk and hence an odd cycle. The given connected graph with at least two vertices has an edge, so one colour is insufficient. Therefore its chromatic number is exactly 2, not merely at most 2.

# GATE 2009: Q3 (printed CS Q3)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2009.pdf, physical page 2. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** Which statement holds for every simple connected undirected graph with more than two vertices? A all degrees distinct; B at least two equal degrees; C at least three equal degrees; D all degrees equal.

## Solution

For n vertices in a simple connected graph with n>2, each degree lies in{1, ..., n−1}. There are n vertices but only n−1 possible degrees. By the pigeonhole principle at least two share a degree, B. Three equal degrees are not necessary, as a path on four vertices shows.

Teaching detail:
Connectivity excludes degree 0, and simplicity excludes degree above n−1. Thus n vertices must be assigned one of only n−1 possible degree values. The pigeonhole principle forces a repeated degree, proving B. A three-vertex path has degrees 1, 2, 1, so neither three equal degrees nor all equal degrees is necessary. This example also makes clear why the claim is about at least two, not a particular pair.

**Independently derived answer:** D

**Paraphrased problem context:** On {x, y, z}, R={(x, y), (x, z), (z, x), (z, y)}. Classify R: A symmetric but not antisymmetric; B antisymmetric but not symmetric; C both; D neither.

## Solution

The pair(x, y) is present but(y, x) is absent, so the relation is not symmetric. Both(x, z) and(z, x) are present with x≠z, so it is not antisymmetric either. Therefore D.

Teaching detail:
Symmetry would require (y, x) whenever (x, y) belongs, but (y, x) is missing. Antisymmetry would forbid distinct elements relating both ways; here (x, z) and (z, x) are both present with x≠z. Hence each property fails by a concrete witness, giving D. Antisymmetry does not mean the logical negation of symmetry; it is a separate condition.

**Independently derived answer:** B

**Paraphrased problem context:** For a biased six-faced die, P(odd)=0.9P(even), the three even faces are equally likely, and P(even | value>3)=0.75. Which is closest to P(value>3)? A 0.453; B 0.468; C 0.485; D 0.492.

## Solution

Let E=P(even). Since P(odd)=.9E and probabilities sum to 1, E=10/19. Each even face has probability 10/57. Therefore P(even and >3)=P(4)+P(6)=20/57. Dividing by the given conditional probability 3/4 gives P(>3)=80/171≈.46784, closest to.468, B.

Teaching detail:
Let total even probability be e. Then 1=e+0.9e=1.9e, so e=10/19. Equal even faces each have probability e/3=10/57. Event even and greater than 3 consists precisely of 4 and 6, giving 20/57. Conditional probability equals intersection divided by P(value>3); hence 0.75=(20/57)/p and p=80/171≈0.46784. Choose the nearest offered value 0.468. No equality assumption for the three odd faces was needed.

**Paraphrased problem context:** A cyclic group has rows/columns a, b, c, d and multiplication rows [a, b, c, d], [b, a, d, c], [c, d, b, a], [d, c, a, b]. Which pair generates the group? A a, b; B b, c; C c, d; D d, a.

## Solution

The identity is a. The powers of c are c, b, d, a, and those of d are d, b, c, a, so each generates all four elements. The element b has order 2 and a order 1. Thus the generators are c, d, option C.

Teaching detail:
The first row/column shows a acts as identity. The element b squares to a, so it generates only{a, b}. From the table c²=b, c³=d, c⁴=a, which visits all elements. Similarly d²=b, d³=c, d⁴=a. Therefore exactly c and d have order 4 and generate the cyclic group, option C. Being nonidentity alone does not guarantee being a generator.

**Paraphrased problem context:** G(x), S(x), P(x) mean x is a gold ornament, silver ornament, precious. Formalize “Gold and silver ornaments are precious.” A ∀x(P→(G∧S)); B ∀x((G∧S)→P); C ∃x((G∧S)→P); D ∀x((G∨S)→P).

## Solution

The sentence applies to both categories separately: every object that is a gold ornament or a silver ornament is precious. Its formula is∀x((G(x)∨S(x))→P(x)), D. Using conjunction would restrict the statement to ornaments simultaneously in both categories.

Teaching detail:
The intended universal statement covers either kind of ornament: if an object is gold OR silver, it is precious. Thus the antecedent must use disjunction and the quantifier must be universal, giving D. B says only objects simultaneously gold and silver are precious, which misses gold-only objects. A reverses the implication and requires both materials for every precious object. C makes only an existential assertion and can hold vacuously for an unrelated object.

**Paraphrased problem context:** Operation P□Q outputs T, T, F, T on inputs TT, TF, FT, FF respectively. Which equals P∨Q? A ¬Q□¬P; B P□¬Q; C ¬P□Q; D ¬P□¬Q.

## Solution

The given operation is false only when its first argument is false and its second true, so P□Q=P∨¬Q. Substituting¬Q for the second argument yields P□¬Q=P∨Q, option B.

Teaching detail:
Inspect the sole false row: P is false while Q is true. This is exactly the false case of Q→P, equivalently P∨¬Q. To remove the negation on the second variable, supply ¬Q as that argument: P□¬Q=P∨¬¬Q=P∨Q. This is option B. A quick countercheck with P=Q=false rejects substitutions that incorrectly produce true in that case.

**Paraphrased problem context:** Which pair is equivalent? I ¬∀xP(x); II ¬∃xP(x); III ¬∃x¬P(x); IV ∃x¬P(x). A I, III; B I, IV; C II, III; D II, IV.

## Solution

By quantifier negation, ¬∀xP(x) is equivalent to∃x¬P(x). These are I and IV, option B. II means every object fails P, while III means every object satisfies P; neither is generally equivalent to I.

Teaching detail:
Negating “every object satisfies P” means “some object does not satisfy P.” Thus I and IV express precisely the same proposition. In contrast, II says no object satisfies P, while III says no object fails P. On a domain with one P-object and one non-P-object, I/IV are true but II/III are false; this separates the alternatives directly. Answer B.
