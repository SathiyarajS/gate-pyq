## Solution

2. If every x satisfies α(x)→β(x), and every x satisfies α(x), then every x satisfies β(x). This is the valid formula in D. For A take a two-element domain with α true only at one point and β false everywhere: its premise is vacuously true but its conclusion fails. For B take α always true and β always false. For C take a two-element domain with α true at exactly one point. Then ∃xα is true, so the inner implication is true regardless of β, while ∀xα is false; the full implication fails. Thus the alternatives are not valid.

Baseline derivation and caveats (retained): The rule says that for every x,y, B(x,y) and C(y) together imply A(x). The headless clause forbids every instance of B(x,x), hence contributes not-exists x B(x,x). A program containing both clauses requires their conjunction. This is option A. Moving a universal quantifier inside the antecedent would weaken the rule; joining the clauses with OR would not enforce both.

## Solution

1. For A, if P and Q were both false, satisfying the first premise would require R=true and satisfying the second would require R=false. This contradiction proves soundness.
2. For C, soundness supplies one direction. Conversely, if P∨Q has a model, extend it with R=false when P is true, or R=true when Q is true. Both premises then hold. This extension uses the pivot-free assumption.
3. D follows because a disjunction has a model exactly when at least one disjunct has a model.
4. GFG B has R∨¬R on its right and is therefore always true. Thus none of its options is false. GateForum B instead has a conjunction: P=true,Q=false,R=true makes its antecedent true and consequent false, so that version has answer B.
5. If arbitrary residual formulas could contain R, C need not hold: P=R,Q=¬R makes the resolvent a tautology and the premises inconsistent. That is a different convention, not a silent repair of GFG.

Baseline derivation and caveats (retained): Under the ordinary resolution convention, R is the pivot atom and neither residual clause P nor Q contains it. The conjunction of the premises entails P∨Q, so A is sound. Conversely, any satisfying assignment of P∨Q can be extended by an appropriate value of R to satisfy both premises, which establishes the satisfiability equivalence in C without claiming logical equivalence. D expresses that P∨Q is unsatisfiable exactly when both disjuncts are unsatisfiable. GateForum B uses a conjunction on its right: choosing P=true,Q=false,R=true falsifies that implication, so B is its answer. GFG B instead uses a disjunction on its right, which contains R∨not-R and is a tautology; under the ordinary convention no GFG option is false. If P and Q may be arbitrary formulas involving R, C also fails: set P=R and Q=not-R. Then the resolvent is a tautology but the premises reduce to R∧not-R. That broader interpretation must not be silently substituted for the conventional pivot-free reading.
