**Official answer:** Not available; no official key located.

**Independently derived answer:** A: A∪B

**Essential problem context (paraphrased):** Simplify (A−B)∪(B−A)∪(A∩B).

## Solution

An element of A∪B belongs to exactly one of three regions: A only, B only, or both sets. These are precisely A−B, B−A and A∩B. Their union therefore recovers A∪B. Conversely, every element in any of those three regions belongs to A or B, proving the reverse inclusion. The intersection alone omits the two exclusive regions, while the symmetric difference omits the common region. No assumption that A and B are disjoint is needed.

**Independently derived answer:** B: 4

**Essential problem context (paraphrased):** Count Hasse-diagram edges for {2,3,6,12,24} ordered by divisibility.

## Solution

A Hasse edge joins comparable elements only when no listed element lies strictly between them. The covers are 2<6, 3<6, 6<12 and 12<24. For example, 2<12 is not an edge because 6 is between them; similarly 6<24 is omitted because of 12. The elements 2 and 3 are incomparable. Thus there are four edges. Counting every divisibility relation would count transitive relations that the Hasse diagram deliberately suppresses.

**Independently derived answer:** A: |X|=1, |Y|=97

**Essential problem context (paraphrased):** Exactly 97 functions exist from X to Y. Determine the finite cardinalities of X and Y.

## Solution

If |X|=m and |Y|=n, each of the m arguments independently chooses one of n images, yielding n^m functions. Here n^m=97. Since 97 is prime, it cannot be an integer power with exponent at least two and base greater than one. Hence m=1 and n=97. An empty domain gives exactly one function, and an empty codomain cannot give 97 functions. This also explains why reversing the two cardinalities would give only one function.

**Independently derived answer:** C

**Essential problem context (paraphrased):** Which claim is false: rationals under addition, integers under addition, rationals under multiplication, or nonzero reals under multiplication form an abelian group?

## Solution

A group requires an identity and an inverse for every element. Under rational multiplication, zero has no inverse because 0·q=0 for every rational q, never the multiplicative identity 1. Thus the set of all rationals is not a multiplication group. The additive inverses of rationals and integers remain in their respective sets. Every nonzero real has a nonzero reciprocal. All the indicated operations commute, so the other three groups are abelian.

**Essential problem context (paraphrased):** Two fair independent dice are thrown. Find the probability that at least one shows 6.

## Solution

Use the complement event that neither die shows 6. Each die avoids 6 with probability 5/6, so independence gives probability 25/36 for neither. Subtracting from one gives 11/36. Equivalently, there are six outcomes with the first die equal to 6 and six with the second equal to 6, but (6,6) was counted twice: 6+6−1=11 of 36 equally likely outcomes. Simply adding 1/6+1/6 would fail to remove this overlap.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B as the usual “symmetric, not necessarily transitive” reading; literal universality needs qualification

**Essential problem context (paraphrased):** On a collection of sets, let A R B iff A∩B=∅, and assume the relation is nonempty. Assess symmetry and transitivity.

## Solution

Disjointness is symmetric because A∩B=B∩A. It is not generally transitive: take A=C={1}, B={2}. Then A R B and B R C hold, but A R C fails. This gives the intended B. Nevertheless the statement that every such nonempty relation is nontransitive is too strong for an arbitrary collection. On the collection {∅}, the relation contains only (∅,∅) and is transitive and reflexive. The assumption that R is nonempty does not exclude that example. Thus B describes the general failure of a transitivity law, not a property forced for every possible underlying collection.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Essential problem context (paraphrased):** Which formula is not a tautology: (A) ((x→y)∧x)→y; (B) ((¬x→y)∧(¬x→¬y))→x; (C) x→(x∨y); (D) (x∨y)↔(¬x→¬y)? GFG supplies these formulas; the alternate changes the second implication inside B to a conjunction, which also makes B a tautology.

## Solution

Replace implication p→q by ¬p∨q. Then ¬x→¬y is x∨¬y, which is not equivalent to x∨y: at x=false,y=true the left side is true and the right side false. Thus D is not a tautology. Choice A is modus ponens written as an implication, and C is the rule that x implies x∨y. In the alternate’s B, the antecedent combines ¬x∧¬y with ¬x→y, making it contradictory; consequently the whole implication is true. These checks establish the distinction by truth values, not symbol resemblance.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C for a nonempty alphabet

**Essential problem context (paraphrased):** Which group claim fails: permutations under composition, nonzero residues modulo prime p, strings under concatenation, or the nonempty-subset subgroup test ab⁻¹∈S?

## Solution

Finite strings have identity ε under concatenation, but a nonempty string w has no inverse. For any string v, length(wv)=length(w)+length(v)>0, so wv cannot equal ε. Thus strings form a monoid, not a group. Permutations have inverse bijections; every nonzero residue modulo prime p has a multiplicative inverse. The subgroup criterion ab⁻¹∈S is valid when S is nonempty, as explicitly printed in the clearer alternate. If an empty alphabet were allowed, its sole string ε would form the trivial group; the conventional alphabet here is nonempty.

**Independently derived answer:** C: (4/52)(3/51)=1/221

**Essential problem context (paraphrased):** A uniformly shuffled standard 52-card deck is considered. What is the probability its top and bottom cards are both aces?

## Solution

The top position contains an ace with probability 4/52. Conditional on that event, three aces remain among the other 51 cards, and every remaining card is equally likely to occupy the bottom position. Multiplying conditional probabilities gives (4/52)(3/51)=1/221. The two positions are distinct, so the second denominator is 51 rather than 52. Using four aces again for the second event would incorrectly replace the already-used top card.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 3.

**Essential problem context (paraphrased):** F consists of all functions {1,2,3}→{1,2,3}. Define f~g iff f(3)=g(3). How many equivalence classes are there?

## Solution

A class is determined completely by the value at input 3. This value can be 1,2 or 3. Define C_r={f∈F:f(3)=r}, for r∈{1,2,3}. Each C_r is nonempty, for example because the constant function with value r lies in it. Every function belongs to exactly one C_r, since f(3) is a single well-defined value.

Within C_r, any two functions have the same value at 3 and are related. Functions from different C_r sets are not related. Thus these three sets are precisely the equivalence classes, not merely three arbitrary subsets. The assignments at 1 and 2 can vary freely without changing class membership.

The relation is reflexive because f(3)=f(3), symmetric because equality is symmetric, and transitive because equal values at 3 remain equal through an intermediate function. There are 3³=27 total functions, but the number of functions is not the number of classes. The quotient groups them by only one of their three output coordinates. GFG explicitly prints f(3)=g(3); GateForum's corresponding line is truncated/malformed.

# GATE 1996: Q64 (printed B Q8(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 9 functions per class.

**Essential problem context (paraphrased):** For functions {1,2,3}→{1,2,3} with f~g iff f(3)=g(3), find the size of each equivalence class.

## Solution

Fix one class C_r, so f(3)=r is fixed. There are three independent choices for f(1) and three for f(2). By the multiplication principle the class contains 3×3=9 functions. No injectivity or surjectivity restriction is stated, so the two values may coincide with each other or with r.

One can enumerate the free pair (f(1),f(2)) as (1,1),(1,2),(1,3),(2,1),(2,2),(2,3),(3,1),(3,2),(3,3). Appending the fixed third coordinate r gives nine distinct functions, and every function in C_r is represented once. The same argument works for r=1,2,3, so all three classes have the same size.

As a consistency check, 3 classes times 9 members gives 27=3³, the number of all functions from a three-element set to a three-element set. A common mistake is to count only permutations, which would wrongly impose a one-to-one condition absent from the question. The complete equality f(3)=g(3) comes from the GFG reproduction.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Official answer:** Not available; no official key located.

**Independently derived answer:** For every k≥1, f_(3k) is even.

**Essential problem context (paraphrased):** Let f1=f2=1 and f_(n+2)=f_(n+1)+f_n for n≥1. Prove by induction that every third term is even.

## Solution

Use induction on k, not on the original index one step at a time. The base case is f3=f2+f1=2, which is even. For the induction step, derive a recurrence connecting terms three positions apart:
f_(m+3)=f_(m+2)+f_(m+1)=(f_(m+1)+f_m)+f_(m+1)=2f_(m+1)+f_m.

Assume f_(3k) is even. Set m=3k in this identity. Then f_(3k+3)=2f_(3k+1)+f_(3k) is the sum of two even integers, hence even. This proves the claim for k+1 and completes the induction.

The proof deliberately does not assume anything about f_(3k+1): multiplying any integer by 2 makes it even. An alternative stronger invariant is that each consecutive block has parity odd,odd,even. Starting from 1,1,2, the recurrence gives the next block odd,odd,even again. This additionally proves that exactly the multiples of three have even terms, but the weaker requested conclusion already follows from the simpler induction above.
