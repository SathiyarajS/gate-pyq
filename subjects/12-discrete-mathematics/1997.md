**Independently derived answer:** ((n−1)/n)^K, for independent uniform hashing.

**Essential problem context (paraphrased):** A hash table has n≥1 buckets, uses external chaining, and is initially empty. K distinct keys are inserted. Each key hashes uniformly to one of the n buckets. Under the standard additional assumption that different keys hash independently, find the probability that bucket 1 is empty after K insertions.

## Solution

A single inserted key avoids bucket 1 with probability (n−1)/n=1−1/n. Bucket 1 is empty after K insertions exactly when every one of those K keys avoids it. Under independent hashing, multiply the K probabilities to obtain

P(bucket 1 empty) = (1−1/n)^K.

The table may have collisions in other buckets; they do not affect this event. External chaining allows arbitrarily many keys in a bucket, so K need not be at most n. For K=0 the probability is 1, including the n=1 case, by the empty-product convention. For n=1 and K≥1 it is 0, because the only bucket must receive every key. For n=2,K=3 it is (1/2)^3=1/8.

The independence qualification is substantive. The source supplies the uniform probability for any individual key, but marginal uniformity alone is not enough to multiply events. For example, choose one uniformly random bucket U and send all keys to U. Every key is marginally uniform, yet bucket 1 remains empty with probability 1−1/n for every K≥1, rather than (1−1/n)^K. The displayed answer uses the usual independent-uniform hashing model and is not claimed under that correlated alternative.

**Independently derived answer:** n! / ((n−K)! n^K) for 0≤K≤n; 0 for K>n.

**Essential problem context (paraphrased):** A hash table has n≥1 buckets, uses external chaining, and is initially empty. K distinct keys are inserted. Each key hashes uniformly to one of the n buckets. Under the standard additional assumption that different keys hash independently, find the probability that none of the K insertions causes a collision.

## Solution

After j collision-free insertions, exactly j buckets are occupied. Conditional on that event, the next independently hashed key must choose one of the n−j empty buckets, which has probability (n−j)/n. Multiplying from j=0 through K−1 gives

P(no collision in K insertions)
= 1·(n−1)/n·(n−2)/n·…·(n−K+1)/n
= n! / ((n−K)! n^K), for 0≤K≤n.

For K>n the probability is zero by the pigeonhole principle. Do not extend the factorial formula to a negative factorial. At K=0, the empty product is 1; at K=1, no collision is possible and the result is also 1. For n=3,K=2 it is 2/3, because only the second key can cause the first collision.

An equivalent counting argument considers n^K equally likely ordered bucket-choice sequences. Collision-free choices are injective assignments of the K ordered keys to the n buckets, numbering n(n−1)…(n−K+1). The keys are distinct, but that does not make their bucket values distinct automatically.

This derivation needs independent uniform hashing, not just equal marginal bucket probabilities. Under the correlated scheme that sends every key to one common randomly chosen bucket, the probability is already zero at K=2 despite uniform marginals. That source-model limitation is stated explicitly rather than hidden in the multiplication.

**Essential problem context (paraphrased):** A hash table has n≥1 buckets, uses external chaining, and is initially empty. K distinct keys are inserted. Under the standard additional assumption that different keys hash independently, find the probability that the first collision occurs on insertion K.

## Solution

The event consists of two parts: the first K−1 insertions are collision-free, and the Kth key hits one of their occupied buckets. Given the first part, there are exactly K−1 occupied buckets, so the conditional probability of the second part is (K−1)/n.

For 2≤K≤n+1, the requested probability is therefore

[n(n−1)…(n−K+2)/n^(K−1)]·(K−1)/n
= n!(K−1) / ((n−K+1)! n^K).

The upper endpoint n+1 is legitimate: the first n keys could fill all n buckets without a collision, after which the next key certainly collides. Its probability is n!/n^n. For K=1 the event is impossible because an empty table has no occupied bucket. For K>n+1, a first collision must already have happened, so the probability is also zero.

As a check, write p_j for the probability of no collision after j insertions. Then P(first at K)=p_(K−1)−p_K. Summing from K=2 to n+1 telescopes to p_1−p_(n+1)=1, as required. For n=2 the probabilities are 1/2 at K=2 and 1/2 at K=3. These arguments all use independent uniform bucket choices; the source's uniform marginals alone do not determine the distribution of the first collision.

**Independently derived answer:** E is reflexive, symmetric and transitive.

**Essential problem context (paraphrased):** Let R be a reflexive and transitive relation on a set A. Define E={(a,b):aRb and bRa}. Prove that E is an equivalence relation.

## Solution

We must check the three equivalence-relation axioms on the same set A.

Reflexivity: for every a∈A, reflexivity of R gives aRa. Both required directions in the definition of E are then the same true statement, so aEa.

Symmetry: if aEb, the definition supplies both aRb and bRa. Reversing their order immediately gives bEa. No symmetry assumption about R is needed; taking its mutual part creates symmetry.

Transitivity: suppose aEb and bEc. Then aRb and bRc, so transitivity of R yields aRc. We also have cRb and bRa, so another use of transitivity gives cRa. Both directions hold, establishing aEc.

Thus E is reflexive, symmetric and transitive, hence an equivalence relation. Its classes group elements that are mutually related by R. In a directed-reachability interpretation, R says one vertex can reach another, and E groups vertices that can reach each other in both directions.

The proof does not claim that R itself is symmetric or antisymmetric. A reflexive, transitive relation is a preorder and may relate distinct elements in both directions. Passing to E-classes is precisely how the companion part removes that possible failure of antisymmetry.

**Essential problem context (paraphrased):** For positive integers n,m, consider the directly recursive, nonmemoized function
function F(n,m:integer):integer;
begin
  if (n<=0) or (m<=0) then F:=1
  else F:=F(n-1,m)+F(n,m-1)
end.
Use C(s,t)=C(s−1,t)+C(s−1,t−1).
Find F(n,m).

## Solution

The boundary values are F(0,m)=F(n,0)=1. Compare them with G(n,m)=C(n+m,n): G(0,m)=C(m,0)=1 and G(n,0)=C(n,n)=1, so the axes agree.

For n,m≥1, Pascal's identity gives

G(n−1,m)+G(n,m−1)
=C(n+m−1,n−1)+C(n+m−1,n)
=C(n+m,n)=G(n,m).

Thus G obeys exactly the same recurrence and boundaries as F. Induction on n+m proves equality: each interior value depends only on two smaller sums, so once their equality is established the new value also agrees. Therefore F(n,m)=C(n+m,n)=C(n+m,m).

A useful combinatorial interpretation is the number of lattice paths from (0,0) to (n,m) using n horizontal and m vertical moves. Select which n of the n+m positions are horizontal. On either axis there is only one path, and every interior path arrives from one of its two preceding grid points, explaining both the boundary and recurrence.
