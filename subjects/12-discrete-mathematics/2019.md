**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Let U = {1,…,n} and A contain pairs (x,X) with X a subset of U and x a member of X. Statement I claims |A| = n·2^(n−1). Statement II claims |A| = sum from k=1 to n of k·C(n,k). Decide whether only I, only II, both, or neither is true; these are choices A, B, C, D respectively.

## Solution

Method: count the same objects in two different orders.

1. First choose the marked member x. There are n choices. Its membership in X is then compulsory, but each of the other n − 1 elements may independently be included or excluded.
2. Consequently there are 2^(n−1) subsets X for each chosen x, and n·2^(n−1) pairs overall. Statement I is true.
3. Alternatively, fix the subset size k. There are C(n,k) ways to choose X, and then k choices for its marked member x. This contributes k·C(n,k) pairs.
4. Sum over k = 1,…,n. The empty subset contributes no pair because it has no member to mark. This gives the expression in II, so II is also true.

Result: C, both statements. This is a double-counting proof of the identity sum k·C(n,k) = n·2^(n−1); it also explains why merely counting all 2^n subsets would miss the possible choices of x.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** In an arbitrary group G, relation R1 is a R1 b iff a = g^−1bg for some g∈G. Relation R2 is a R2 b iff a = b^−1. Which are necessarily equivalence relations? Choices: A both; B R1 only; C R2 only; D neither.

## Solution

Method: verify reflexivity, symmetry, and transitivity for conjugacy, then seek a counterexample for the inverse relation.

1. R1 is reflexive: taking g to be the identity e gives a = e^−1ae.
2. R1 is symmetric: if a = g^−1bg, rearrange to b = gag^−1. This has the required form h^−1ah with h = g^−1.
3. R1 is transitive: if a = g^−1bg and b = h^−1ch, substitute to obtain a = g^−1h^−1chg = (hg)^−1c(hg). Thus a R1 c.
4. R2 need not even be reflexive. In the cyclic group of order three, let u be a nonidentity generator. Then u^−1 = u² ≠ u, so u is not related to itself by R2. One failure of reflexivity is enough to disprove that R2 is necessarily an equivalence relation.

Result: B, R1 only. R2 can be an equivalence relation in special groups where every element equals its inverse, but “arbitrary group” requires the claim to hold for every group.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C OR D

**Derived answer:** D generally; official accepts C OR D

**Paraphrased problem context:** For an undirected complete graph on n vertices with n>2, count distinct Hamiltonian cycles. Choices: A n!; B (n−1)!; C 1; D (n−1)!/2. Rotations and reversal describe the same undirected cycle.

## Solution

Method: count vertex orders while removing the two sources of duplicate descriptions.

1. A Hamiltonian cycle visits every vertex once and returns to its start. Because the graph is complete, any ordering of the vertices produces the required edges.
2. Fix one named vertex as the start. The other n − 1 vertices can be arranged in (n−1)! orders. Fixing the start removes the n equivalent rotations that would appear in an unrestricted n! count.
3. Every undirected cycle is still counted twice: once for each traversal direction. For example, v1,v2,…,vn,v1 and v1,vn,…,v2,v1 use exactly the same undirected edges. Since n>2, these are two distinct orders, so divide by 2.
4. Hence the general count is (n−1)!/2. For n=3 this gives 1; for n=4 it gives 3, showing why the constant answer 1 does not hold for every allowed n.

Result: D is the general formula. The official key also accepts C, the value 1; that is true only for n=3, not for general n>2. Preserve both official scoring alternatives without presenting C as the general formula.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 2 to 2

**Derived answer:** 2

**Paraphrased problem context:** Compute 3^51 modulo 5. The exponent in the original is 51.

## Solution

Method: find the repeating cycle of powers modulo 5, rather than form the large integer.

1. Compute successive residues: 3¹≡3, 3²=9≡4, 3³≡4×3=12≡2, and 3⁴≡2×3=6≡1 (mod 5).
2. Once the residue is 1, the next powers repeat this four-step pattern. Write 51=4×12+3.
3. Therefore 3^51=(3⁴)^12·3³≡1^12·2≡2 (mod 5).
4. The residue 2 already lies in the standard range 0 through 4, so no further reduction is needed.

Result: 2. The exponent itself was visually verified as 51; treating the superscript as a different number would select a different position in the cycle.

# GATE 2019 CS: Q45 (printed CS Q35)

**Question:** [Official archived paper page 11](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** Only S2 under literal integer divisibility; official C

**Paraphrased problem context:** Let P(x) mean that every domain element z dividing x satisfies z=x or z=1. The formula says ∀x[P(x)⇒∃w(w>x and P(w))]. Which domains satisfy it: S1={1,...,100}, S2=positive integers, S3=all integers? Choices A S1/S2, B S1/S3, C S2/S3, D all three. Divisibility and quantifiers must be interpreted in the stated domain.

## Solution

1. Read the formula as: each number whose divisors are restricted to itself and 1 has a larger number with the same property. Do not replace P(x) by an informal definition of prime before checking its domain.
2. In the positive integers, P(x) holds for 1 and all primes. For every such x there is a larger prime, since primes are unbounded. Thus S2 satisfies the formula.
3. In S1, x=97 has P(x), since its only positive divisors are 1 and 97. The larger available values 98, 99, and 100 are composite and have divisors in S1 other than themselves and 1. No valid w exists, so S1 fails.
4. In S3, the integer −1 divides every integer. If P(x) holds, taking z=−1 forces −1=x or −1=1, hence x=−1. Conversely, −1 has exactly divisors −1 and 1, so P(−1) really is true.
5. There is no larger integer w with P(w), because step 4 shows −1 is the only qualifying integer. The implication consequently fails at x=−1, and S3 fails under literal integer divisibility.
6. The literal result is only S2, which none of the choices lists. The official key selects C, S2 and S3. Keep this discrepancy open: importing a positive-divisor convention into all-integer quantifiers silently changes the formula rather than resolving it.
