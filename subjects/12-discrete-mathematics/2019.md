

# GATE 2019 CS: Q15 (printed CS Q5)

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

Count pairs(x, X) with x∈X⊆U. Choose x in n ways and independently include any of the other n−1 elements, giving n·2^(n−1). Alternatively choose |X|=k and then its marked member, giving sum k·C(n, k). Both expressions count the same pairs, C.

**Official answer:** B

**Derived answer:** B

## Solution

Conjugacy is reflexive using the identity, symmetric by inverting the conjugator, and transitive by composing conjugators. The relation a=b^−1 is not generally reflexive: a generator of a cyclic group of order3 differs from its inverse. Thus only R1 is necessarily an equivalence relation, B.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C OR D

**Derived answer:** D generally; official accepts C OR D

## Solution

Fix one vertex first. The other n−1 vertices can occur in any order, giving(n−1)! oriented cycles. Reversal identifies pairs in the undirected graph, so there are(n−1)!/2 cycles, D. The official key also accepts C, the value1; that is true only for n=3, not for general n>2. Preserve both official scoring alternatives without presenting C as the general formula.

# GATE 2019 CS: Q45 (printed CS Q35)

**Question:** [Official archived paper page 11](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** Only S2 under literal integer divisibility; official C

## Solution

Over positive integers the antecedent identifies1 and the primes, and infinitely many primes supply a larger qualifying w. In S1={1,..., 100}, prime97 has no larger qualifying member. Over all integers S3, −1 divides every integer. Consequently a number satisfying the displayed divisor property must be x=−1; this value does satisfy it, but no larger w does. The implication fails at x=−1. Thus only S2 satisfies the literal formula, whereas official C lists S2 and S3. The usual positive-divisor interpretation cannot silently be extended to all integer quantifiers.
