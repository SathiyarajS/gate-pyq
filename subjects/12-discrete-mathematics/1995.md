**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D: 18/25

**Essential problem context (paraphrased):** A number is selected uniformly from 100 through 999. Find the probability it contains no digit 7.

## Solution

There are 900 equally likely three-digit numbers. The hundreds position has eight allowed choices: 1 through 9 except 7. Each remaining position has nine choices: 0 through 9 except 7. Thus 8·9·9=648 numbers avoid 7, and 648/900=18/25. Using (9/10)³ would wrongly allow zero in the hundreds position and assume all three positions have the same distribution.

**Independently derived answer:** D: none of the asserted necessities

**Essential problem context (paraphrased):** Given a symmetric and transitive relation R on A, must it be an equivalence, a partial order, nonreflexive, or none? The alternate changes the negation in C.

## Solution

Reflexivity is independent of the two stated properties on the entire underlying set. On a nonempty A, the empty relation is symmetric and transitive but not reflexive. Conversely the identity relation is reflexive, symmetric and transitive, so nonreflexivity is not forced either. Symmetry also does not imply the antisymmetry required for a partial order. Thus none of A,B,C is a necessary conclusion, giving D. GateForum’s C says reflexive “and hence not an equivalence,” unlike GFG’s nonreflexive wording; that altered inference is not a valid necessity either.

**Essential problem context (paraphrased):** What is the minimum number of edges in a connected graph on n vertices containing a cycle?

## Solution

Every connected graph contains a spanning tree with n−1 edges. A tree has no cycle, so at least one further edge is necessary. Adding one non-tree edge to a spanning tree creates a cycle while retaining connectivity, attaining n edges. Thus n is both a lower bound and achievable for a simple graph with n≥3. If “cycle graph” means precisely the graph C_n, it likewise has exactly n edges.

**Independently derived answer:** D for a fixed square dimension n≥2

**Essential problem context (paraphrased):** For nonsingular real matrices under multiplication, are they merely closed, a semigroup, a monoid, or a nonabelian group?

## Solution

For fixed n, the product of invertible matrices is invertible because (AB)⁻¹=B⁻¹A⁻¹. Matrix multiplication is associative, the identity matrix is present, and every member has an inverse, so this is a group. For n≥2 it is noncommutative: diagonal scaling diag(2,1) and the coordinate-swap matrix have different products in the two orders. Thus D holds under that convention. The question omits dimension: all sizes together do not form a multiplication group, while n=1 gives an abelian group of nonzero reals.

**Essential problem context (paraphrased):** Determine the number of divisors of 600.

## Solution

Prime-factorize 600=6×100=2³×3¹×5². Every positive divisor has a unique form 2ᵃ3ᵇ5ᶜ where a∈{0,1,2,3}, b∈{0,1} and c∈{0,1,2}. There are four choices for a, two for b and three for c. The choices are independent, so the multiplication principle gives 4×2×3=24.

The factorization also explains why adding these counts would be wrong: one divisor is determined by choosing all three exponents together. Both 1 (all exponents zero) and 600 (all exponents maximal) are included. In standard elementary-number-theory exam usage “number of divisors” counts positive divisors. If the question instead meant all nonzero integer divisors, every positive divisor has a distinct negative partner, giving 48.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** (p∨q∨r)∧(p∨¬q∨r)∧(p∨¬q∨¬r)∧(¬p∨q∨r).

**Essential problem context (paraphrased):** Find the principal/canonical CNF of (p∧q)∨(¬q∧r).

## Solution

A canonical CNF contains one maxterm for each falsifying truth assignment, with all three variables appearing once in every clause. If q=0 the formula reduces to r, so it is false at (p,q,r)=(0,0,0) and (1,0,0). If q=1 it reduces to p, so it is false at (0,1,0) and (0,1,1). The four other rows are true.

To construct a clause false at a given row, write a variable positively when that row assigns it 0 and negatively when it assigns it 1. The false rows 000,010,011,100 therefore give respectively (p∨q∨r), (p∨¬q∨r), (p∨¬q∨¬r), and (¬p∨q∨r). Their conjunction is the answer, conventionally ΠM(0,2,3,4) with p as the most significant bit.

Each maxterm rules out exactly its own false row. Thus the conjunction excludes precisely the original formula’s four false rows and accepts all others, proving equivalence. A shorter equivalent CNF might be valid Boolean algebra, but would not satisfy the requested canonical form if its clauses omitted variables.

# GATE 1995: Q80 (printed B Q21(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** G1∩G2 is nonempty and closed under xy⁻¹, hence a subgroup.

**Essential problem context (paraphrased):** Let G1 and G2 be subgroups of a group G. Prove that G1∩G2 is a subgroup of G.

## Solution

Write H=G1∩G2. Both subgroups contain the identity e of G, so e belongs to H and H is nonempty. This step matters because an empty set cannot be a subgroup.

Take arbitrary x,y in H. By definition of intersection, both x and y belong to G1 and also to G2. Since each Gi is a subgroup, y⁻¹ lies in each Gi, and closure gives xy⁻¹ in each Gi. Consequently xy⁻¹ belongs to their intersection H. The nonempty-subset subgroup test now proves that H is a subgroup of G.

Alternatively, check the axioms separately: the common identity lies in H; for x,y in H, xy is in both groups and hence H; and for x in H, x⁻¹ is in both groups and hence H. Associativity is inherited from G because H uses the same operation. No commutativity, finiteness, or containment of one subgroup inside the other is needed. The essential distinction from a union is that every chosen element of the intersection is available in both subgroups, so a single subgroup's closure can always be applied.

# GATE 1995: Q81 (printed B Q21(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** No. In (Z,+), 2Z∪3Z contains 2 and 3 but not 5. The union is a subgroup exactly when one subgroup contains the other.

**Essential problem context (paraphrased):** Let G1,G2 be subgroups of G. Is G1∪G2 necessarily a subgroup? Justify the answer.

## Solution

Take the additive group of integers. Let G1=2Z, the even integers, and G2=3Z, the multiples of 3. Each is a subgroup: it contains 0 and is closed under subtraction. Their union contains 2 and 3. But 2+3=5 is neither even nor a multiple of 3, so it is outside the union. Closure fails, proving that the answer is no.

There is a useful exact characterization. If G1⊆G2, the union is simply G2 and is a subgroup; the reverse containment works too. Conversely suppose neither contains the other, and choose a∈G1 minus G2 and b∈G2 minus G1. If the union were closed, ab would lie in G1 or G2. If ab∈G1, then a⁻¹(ab)=b∈G1, a contradiction. If ab∈G2, then (ab)b⁻¹=a∈G2, again a contradiction. Therefore the union cannot be a subgroup.

This argument uses the inherited group operation and does not assume an abelian group. The reason the intersection proof does not extend to a union is that two union elements can come from different subgroups, whose individual closure properties say nothing about their mixed product.

# GATE 1995: Q83 (printed B Q23)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Base32>25; induction follows from 2n²>(n+1)² for n≥5.

**Essential problem context (paraphrased):** Prove by mathematical induction that 2^n>n² for every integer n≥5.

## Solution

Start at n=5: 2^5=32>25=5², so the claimed strict inequality holds. Now suppose it holds for some integer k≥5, namely 2^k>k². Multiplying this strict inequality by 2 gives 2^(k+1)>2k². To reach the desired conclusion, it remains to compare 2k² with (k+1)².

The difference is 2k²−(k+1)²=k²−2k−1=(k−1)²−2. Since k≥5, this is at least 16−2=14>0. Therefore 2k²>(k+1)², and chaining the two inequalities gives 2^(k+1)>(k+1)². This proves the induction step. By mathematical induction the assertion holds for all integers n≥5.

The comparison in the middle is necessary: merely doubling both sides of the induction hypothesis does not automatically produce the next quadratic term. The starting value is also meaningful: at n=4 both sides equal 16, so the strict claim cannot start there. This proof covers the stated integer domain only; induction alone is not a proof for arbitrary real n.

# GATE 1995: Q84 (printed B Q24)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** The degree sum equals 2|E|, so the number of its odd summands is even.

**Essential problem context (paraphrased):** Prove that a finite undirected graph has an even number of vertices of odd degree.

## Solution

Each undirected edge contributes one incident end at each endpoint. Counting all incident ends first by edges and then by vertices yields the handshaking identity ∑v deg(v)=2|E|, an even integer. If loops are allowed, a loop contributes 2 to the degree of its vertex, so the same identity remains true under that standard convention.

Partition the vertices into those with even degree and those with odd degree. The sum over the even-degree vertices is even. Subtracting it from the even total shows that the sum over the odd-degree vertices is also even. A sum of m odd integers has parity m: write each degree as 2ki+1, so their sum is 2∑ki+m. It can be even only if m is even. Hence the number of odd-degree vertices is even.

The graph need not be connected, and isolated vertices have degree 0 and do not affect the argument. Finiteness ensures that these are ordinary finite sums. The assertion is about undirected degree; for a directed graph, odd outdegrees alone need not occur an even number of times. One must specify the appropriate total-degree convention rather than reuse this proof unaltered.

# GATE 1995: Q86 (printed B Q25(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 192.

**Essential problem context (paraphrased):** How many positive integers at most 720 are divisible by none of 2,3,5?

## Solution

Let A,B,C be the subsets of {1,…,720} divisible by 2,3,5 respectively. Their sizes are 360,240,144. Because the divisors are pairwise coprime, the pair intersections count multiples of 6,10,15, giving 120,72,48; the triple intersection counts multiples of 30, giving 24.

Inclusion–exclusion gives |A∪B∪C|=360+240+144−120−72−48+24=528. These are exactly the integers disqualified by at least one divisibility condition. Subtract from all 720 positive integers to obtain 720−528=192. The subtraction of pair intersections corrects double counting, while adding the triple intersection restores numbers removed too many times.

An independent way to see the count is to use blocks of 30. In each block the allowed residue classes are 1,7,11,13,17,19,23,29 modulo 30, eight in total. There are 720/30=24 complete blocks, hence 24×8=192. The residue 0 is not allowed, and the positive-integer domain excludes 0 anyway. Both inspected rasters show ≤720; even if one mistakenly read a strict <720, the count would not change here, because 720 is divisible by all three numbers and is excluded.
