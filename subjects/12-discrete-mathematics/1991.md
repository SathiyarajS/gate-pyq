**Independently derived answer:** 9, 000, 000

**Essential problem context (paraphrased):** Count ordered integer triples (i, j, k) with 1≤i, j, k≤300 and i+j+k divisible by 3.

## Solution

The interval 1, …, 300 contains exactly 100 representatives of each residue modulo 3. For each ordered pair (i, j), the required residue of k is uniquely −i−j modulo 3, and precisely 100 values of k realize it. There are 300² ordered pairs, so the total is 300²×100=9, 000, 000. Repetitions and different orderings are permitted because these are triples, not three-element subsets. Equivalently, exactly one third of the 300³ triples have residue sum zero. Both bounds are inclusive in the inspected source.

**Official answer:** Not available; no official key located.

**Independently derived answer:** n antichains

**Essential problem context (paraphrased):** If a finite partial order has longest chain of n elements, into how many antichains can it be partitioned?

## Solution

Assign each element the maximum number of elements in a chain ending there. Each rank lies between 1 and n. If x<y, appending y to a longest chain ending at x shows rank(y)>rank(x). Therefore elements with equal rank are incomparable and form an antichain; the n rank classes give the desired partition. Conversely, a chain of n elements meets any antichain in at most one element, so fewer than n classes cannot suffice. Here chain length counts elements; if it counted edges the numerical parameter would shift by one.

**Essential problem context (paraphrased):** Find the maximum number of edges in an undirected graph with n vertices and k components.

## Solution

For component sizes n1, …, nk, simplicity permits at most Σ C(ni, 2) edges, attained by making each component complete. If two component sizes a≥b≥2 occur, transferring a vertex from the smaller to the larger changes the sum by a−b+1>0. Repeating leaves one component of size n−k+1 and k−1 isolated vertices, giving C(n−k+1, 2). This assumes 1≤k≤n and a simple loopless graph. If parallel edges are unrestricted, no finite maximum follows merely from n and k.

**Essential problem context (paraphrased):** GFG states (F1∧F2)→F3 and (F1∧F2)→¬F3 are tautologies. Choices: both F1, F2 tautologies; their conjunction unsatisfiable; neither tautological; neither satisfiable; none. Forum alters the second formula.

## Solution

Suppose a valuation made F1 and F2 both true. The first tautology would then force F3 true, and the second would force F3 false, an impossibility. Thus no such valuation exists and their conjunction is unsatisfiable. This does not require either individual formula to be unsatisfiable: F1=p, F2=¬p is a counterexample to that stronger claim. Nor must both fail to be tautologies; F1=true, F2=false satisfies the premises. # GATE 1991: Q37 (printed A Q4(iv))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** short-answer, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Consistency is inherited; completeness need not be

**Essential problem context (paraphrased):** If a finite axiom system A is complete and consistent for a theory, is every subsystem also complete and consistent? Explain.

## Solution

Let B⊆A. Any proof from B is also a proof from A, since all its premises remain available. If B derived a contradiction, so would A; therefore every subsystem is consistent. Completeness does not follow because removing an essential axiom can remove the ability to decide a sentence. For example, in propositional logic over a single atom p, the axiom set{p} is consistent and complete for truth-functional formulas over p, whereas the empty subsystem proves neither p nor ¬p. Redundant-axiom removal may preserve completeness, but arbitrary removal need not. The claim does not require an impossible complete arithmetic theory.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** gcd(a,b)·lcm(a,b)=ab.

**Essential problem context (paraphrased):** For positive integers a and b, prove gcd(a,b)·lcm(a,b)=ab.

## Solution

By unique prime factorization, write a=∏p p^{αp} and b=∏p p^{βp}, using exponent zero for a prime absent from either factorization. Only finitely many exponents are nonzero.

A common divisor cannot contain more copies of p than either number, so the largest possible exponent of p in the gcd is min(αp,βp). Conversely these minimum exponents do divide both numbers, proving gcd(a,b)=∏p p^{min(αp,βp)}.

A common multiple must contain at least as many copies of p as each number, so the smallest possible exponent in the lcm is max(αp,βp). These maximum exponents form a multiple of both, proving lcm(a,b)=∏p p^{max(αp,βp)}.

Multiplying adds exponents. Since min(u,v)+max(u,v)=u+v for any u,v, the product is ∏p p^{αp+βp}=ab. This also covers a=1 or b=1 by the empty-product convention. Positivity avoids sign conventions and zero-related lcm special cases.

# GATE 1991: Q67 (printed B Q15(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** No nonempty finite models. It is satisfiable in the countably infinite structure (ℕ,<).

**Essential problem context (paraphrased):** Over a nonempty domain, consider (∀x∃y R(x,y)) ∧ (∀x∀y(R(x,y)→¬R(y,x))) ∧ (∀x∀y∀z((R(x,y)∧R(y,z))→R(x,z))) ∧ (∀x ¬R(x,x)). Does this formula have finite models? Is it satisfiable? Give a countable model if so.

## Solution

The conjuncts say respectively that every element has a strict successor in R, the relation is asymmetric, it is transitive, and it is irreflexive. In particular the first clause prevents a maximal element. The negation in the asymmetry clause is essential and is visibly present in the sources.

Suppose a finite model had m≥1 elements. Choose any x0. By the first clause choose x1 with R(x0,x1), then x2 with R(x1,x2), continuing to xm. Among these m+1 elements some xi=xj with i<j. Repeated application of transitivity to the nonempty chain from xi to xj yields R(xi,xj), hence R(xi,xi). This contradicts irreflexivity. Thus there is no finite nonempty model. One can equivalently say that a finite strict partial order has a maximal element, contrary to the successor clause.

For satisfiability, take the domain ℕ={0,1,2,…} and interpret R(x,y) as x<y. Every x has witness y=x+1. If x<y then not y<x, so asymmetry holds. From x<y and y<z follows x<z, so transitivity holds; x<x is always false. All four conjuncts therefore hold. The domain is countably infinite, giving the requested countable model. Ordinary first-order semantics requires a nonempty domain; if empty domains were unusually permitted, the universally quantified formula would also hold vacuously there.

**Independently derived answer:** C_n = binom(2n,n) − binom(2n,n−1) = binom(2n,n)/(n+1).

**Essential problem context (paraphrased):** How many length-2n binary strings have n zeros and n ones and every prefix contains at least as many zeros as ones?

## Solution

Interpret a zero as a +1 step and a one as a −1 step. A balanced string gives a walk from height 0 to height 0 in 2n steps. The prefix restriction asks that the height never become negative. There are binom(2n,n) balanced strings before imposing the restriction.

Count the bad strings by reflection. A bad walk has a first step reaching height −1. Swap zeros and ones in the segment from the beginning through that first visit. Originally that segment has one more one than zero; after the swap it has one more zero than one. Consequently the transformed entire string has n+1 zeros and n−1 ones and ends at height +2.

Conversely, any string with n+1 zeros and n−1 ones must first reach height +1. Reflect its prefix through that first visit. The resulting balanced walk first reaches −1 there, so it is bad. These two operations invert each other, establishing a bijection. The number of bad strings is therefore binom(2n,n−1), choosing the positions of its n−1 ones after reflection.

Subtracting gives binom(2n,n)−binom(2n,n−1). Since binom(2n,n−1)=n·binom(2n,n)/(n+1), the result is C_n=binom(2n,n)/(n+1), the nth Catalan number. For n=0, the empty string contributes one; for n=2, the valid strings are 0011 and 0101, agreeing with C_2=2.

# GATE 1991: Q69 (printed B Q16(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Two vertices must share a degree, since degrees 0 and n−1 cannot both occur.

**Essential problem context (paraphrased):** Prove that a finite undirected simple graph with at least two vertices has two vertices of equal degree.

## Solution

Let the graph have n≥2 vertices. In a simple undirected graph each degree is an integer in {0,1,…,n−1}. Merely counting n possible degrees and n vertices does not yet prove a repetition; the key is that the extreme values cannot coexist.

If a vertex has degree n−1, it is adjacent to every other vertex, so every other vertex has degree at least 1. Thus no degree-0 vertex exists. Conversely, if an isolated vertex exists, no vertex can be adjacent to all n−1 others, so degree n−1 is absent.

There are therefore at most n−1 possible degrees in the graph: if there is an isolated vertex, use {0,…,n−2}; if not, use {1,…,n−1}. Assigning n vertices to at most n−1 degree values forces two into the same value by the pigeonhole principle.

The simple-graph convention matters. If parallel edges or loops were allowed, the bound n−1 would fail and so can the conclusion. For example, on three vertices put one edge between a and b, two parallel edges between a and c, and none between b and c. The degrees are 3,1,2, all distinct. The source's unqualified graph is interpreted in the standard simple-graph setting.
