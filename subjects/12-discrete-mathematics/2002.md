## Solution

1. Identify the formula: (A ∨ B) → B. An implication is false only when its antecedent is true and its consequent is false.

2. Eliminate the implication and simplify:
(A ∨ B) → B = ¬(A ∨ B) ∨ B = (¬A ∧ ¬B) ∨ B = (¬A ∨ B) ∧ (¬B ∨ B) = ¬A ∨ B.

3. Evaluate all four assignments, or equivalently use the implication’s false-case rule:

```text
A  B  A∨B  (A∨B)→B
F  F   F       T
F  T   T       T
T  F   T       F
T  T   T       T
```

4. The row A = T, B = F rules out a tautology. Any true row, such as A = F, B = F, rules out a contradiction. Therefore the formula is neither; it is contingent. In particular, a false antecedent in the first row makes the implication true, not false.

5. Hence the formula is a contradiction, not merely a contingent formula that happens to fail on one input.
