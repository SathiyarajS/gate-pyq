# GATE 2026 CS1: Q12

**Status:** Partial subject-year coverage. Independently derived and matched against the published official key; independent second derivation review passed; final-key revision check remains pending.

**Question summary (paraphrased):** How many binary 4-by-4 matrices have even parity in every row and every column?

Options: A=512, B=1025, C=1023, D=255.

**Type / marks:** MCQ, 1 mark. Paper variant CS1 (forenoon); the official key labels the exam session 3.

**Official answer:** A

**Derived answer:** 512; option A

## Solution

Choose the upper-left 3-by-3 block freely: there are 2^9 choices. In each of the first three rows, the fourth entry is forced by even row parity. In each of the first three columns, the fourth entry is forced by even column parity. The bottom-right entry is then fixed by the fourth row. It also satisfies the fourth column because the parity of all entries counted by rows equals that counted by columns. Thus every free block yields exactly one valid matrix, giving 2^9 = 512.

# GATE 2026 CS1: Q47

**Question:** [Official paper page 35](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=35); refer to the original wording and options.

**Type / marks:** MSQ, 2 marks.

**Official answer:** A

## Solution

If a vertex v is omitted from a vertex cover, all its distinct neighbors must be included to cover its incident edges. Degree at least k+1 would then require more than k vertices, contradicting minimal cover size k. Thus A forces v into every minimum cover. B does not: take a four-vertex path a-b-c-d, whose minimum cover size is 2. Endpoint a lies on the path of length 3=k+1, but the minimum cover {b,c} excludes it. C does not: a triangle has k=2, and any vertex lies on its cycle of length 3 but can be excluded by choosing the other two. The same triangle refutes D: each vertex belongs to a clique of size k=2 (an incident edge), yet some minimum cover excludes it. Only A always forces inclusion.

## Q55 — Discrete Mathematics / Algorithms: bipartiteness

Paper page 43. MSQ, 2 marks. **Answer: B, C.**

1. Along a cycle, a proper two-colouring alternates colours on each successive edge. An odd number of alternations would require the starting vertex to have both colours. Odd cycles are therefore forbidden, making A false.
2. An even cycle can alternate colours consistently. A four-cycle is a direct example, so B is true.
3. Use BFS or DFS from every not-yet-coloured vertex, assign opposite colours across each explored edge, and reject if an edge has equally coloured endpoints. If no conflict occurs, the assignment is a valid two-colouring. Processing all components is essential for disconnected graphs.
4. With adjacency lists, each vertex is visited once and each undirected edge is examined at most twice. This is the standard worst-case Θ(|V|+|E|) traversal bound used by the question, yielding C. No sorting or priority queue is required; the claimed optimal logarithmic-factor bound in D is not the standard bound.

**Complexity scope:** The stated bound is the conventional full-graph adjacency-list algorithm bound. Particular inputs may be rejected earlier, for example when a conflict is found before traversal finishes.

## Q57 — Discrete Mathematics: matchings in a path

Paper page 44. NAT, 2 marks. **Answer: 34. Official interval: 34 to 34.**

1. Let M_n count matchings of an n-vertex path, including the empty matching. If the first vertex is unmatched, the remaining choices are any matching of the last n−1 vertices, giving M_(n−1).
2. If the first vertex is matched, it must use the edge to the second vertex. No other chosen edge may touch either of those vertices, leaving a path on n−2 vertices and M_(n−2) choices.
3. These cases are disjoint and exhaustive, so M_n=M_(n−1)+M_(n−2), with M_0=M_1=1. The values through n=8 are 1,1,2,3,5,8,13,21,34.
4. A separate count by matching size agrees: choosing k nonadjacent edges among the seven edges gives binomial(8−k,k). Summing for k=0,1,2,3,4 yields 1+7+15+10+1=34.

**Common error:** The empty set is a matching and contributes one. Omitting it gives an off-by-one result.

# GATE 2026 CS2: Q11

**Question:** [Official master paper page 10](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS2.pdf#page=10); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

Choose the exceptional person y existentially, then quantify universally over every other person x. The condition x≠y implies that x knows y and y does not know x: ∃y∀x[(x≠y)→(M(x,y)∧¬M(y,x))]. The implication excludes any requirement about knowing oneself. Thus A has the required quantifier order and both directions of the relationship. B and C can use x=y to make the implication vacuous; D incorrectly requires every person to have the exceptional property.

# GATE 2026 CS2: Q26

**Question:** [Official master paper page 20](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS2.pdf#page=20); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;B;C

**Derived answer:** A;B;C

## Solution

Every x relates to itself because x² is a square, giving reflexivity. Symmetry follows from xy=yx. Write each positive integer as its prime-exponent parity vector. The product xy is a square exactly when the parity vectors of x and y agree. Equality of these vectors is transitive, so the relation is transitive. It is not antisymmetric: 1 and 4 are distinct but both (1,4) and (4,1) belong to R. Hence A, B, C.

# GATE 2026 CS2: Q36

**Question:** [Official master paper page 24](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS2.pdf#page=24); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

A Jaccard coefficient is nonnegative, so 0 is a lower bound. It is attainable by two edge-disjoint spanning trees. Label vertices 1,…,n. Let T1 be the path with edges (i,i+1), 1≤i<n. Let T2 contain (1,j) for 3≤j≤n, plus (2,4). T2 connects every vertex and has exactly n−1 edges, so it is a tree. None of its edges is a consecutive-vertex edge of T1. Consequently |T1∩T2|=0 and |T1∪T2|=2n−2, giving coefficient 0, option C.
