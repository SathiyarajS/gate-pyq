**Paraphrased problem context:** Let S={1,2,3,4,5,6}, U be its power set, |T| denote cardinality, T′ denote complement relative to S, and T\R denote set difference. Which statement is true? (A) For every X∈U, |X|=|X′|. (B) There exist X,Y∈U with |X|=|Y|=5 and X∩Y=∅. (C) For every X,Y∈U, |X|=2, |Y|=3 and X\Y=∅. (D) For every X,Y∈U, X\Y=Y′\X′.

## Solution

1. For A, take X=∅: its size is 0 while its complement has size 6. For B, inclusion-exclusion gives |X∩Y|≥5+5−6=4, so disjointness is impossible. For C, its universal cardinality claims already fail at X=∅; even restricting to sizes 2 and 3 does not force containment, e.g. X={1,2}, Y={3,4,5}.

2. For any element t, t∈X\Y iff t∈X and t∉Y iff t∈Y′ and t∉X′, hence X\Y=Y′\X′. Thus D. Equal complement sizes need not hold, two5-subsets of a 6-set cannot be disjoint, and arbitrary2/3-subsets need not satisfy the proposed containment.

**Paraphrased problem context:** How many four-digit numbers can be made using only digits {1,2,3}, with digits in nondecreasing order from left to right? Repetition is permitted.

## Solution

1. For example, counts (2,1,1) give exactly 1123, not its other permutations, because sorting is required. Distributing four identical positions among three digit counts is the weak-composition count (4+3−1 choose 3−1).

2. A nondecreasing four-digit sequence is determined by counts c1, c2, c3≥0 summing to 4. Stars and bars gives C(6, 2)=15, with one sorted sequence for every count triple.

**Paraphrased problem context:** A room contains only Type 1 people, who always tell the truth, and Type 2 people, who always lie. You give a fair coin to someone of unknown type, ask them to toss it and hide the result, then ask the result. They reply: “The result of the toss is head if and only if I am telling the truth.” Which option is correct? (A) The result is head. (B) The result is tail. (C) If the person is Type 2, the result is tail. (D) If the person is Type 1, the result is tail.

## Solution

1. Let T indicate that the speaker tells the truth and H that the coin is heads.

2. The assertion is H↔T, whose truth value must equal T. If T is true, H must be true; if T is false, H↔false must be false, again requiring H true. Thus the coin is heads, A.

**Paraphrased problem context:** R is a relation on ordered pairs of positive integers, with ((p,q),(r,s))∈R iff p−s=q−r. Which description is correct? (A) reflexive and symmetric; (B) reflexive but not symmetric; (C) not reflexive but symmetric; (D) neither reflexive nor symmetric.

## Solution

1. The condition p−s=q−r is equivalent to p+r=q+s, unchanged by swapping the two ordered pairs; the relation is symmetric.

2. Reflexivity at(p, q) would require2p=2q, which fails for example at(1, 2). Thus it is not reflexive but is symmetric, C.

**Paraphrased problem context:** X1,X2,X3 are independent, identically distributed bits with P(Xi=0)=P(Xi=1)=1/2. Let Y=(X1X2) XOR X3, where juxtaposition denotes ordinary multiplication of bits. Find P(Y=0 | X3=0).

## Solution

1. The four conditional equally likely (X1,X2) pairs are 00,01,10,11. With X3=0, XOR changes nothing, so the first three give Y=0 and only 11 gives Y=1.

2. Conditioning on X3=0 makes Y=X1X2. Independence leaves X1 and X2 independent fair bits. Their product is 1 only when both are1, with probability1/4. Therefore Pr(Y=0|X3=0)=3/4=0.75.
