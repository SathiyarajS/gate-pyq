**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

## Solution

The antecedent ¬p∧(p∨q) simplifies to ¬p∧q. Therefore S1 is (¬p∧q)→q, a tautology. S2 is q→(¬p∧q), which is false when p=q=true. Hence only S1 is a tautology, B.

# GATE 2021 CS1: Q46 (printed CS Q36)

**Question:** [Official archived paper page 30](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=30); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

G2 connects vertices whose original distance is at most2. A shortest G path of lengthd can be compressed into ceil(d/2) G2 edges. Conversely each G2 edge expands into at most2 G edges, so no shorter G2 path than ceil(d/2) is possible. Thus d_G2(u, v)=ceil(d_G(u, v)/2), and diam(G2)=ceil(diam(G)/2), which in particular satisfies A’s ≤ bound. Self-loops from M² do not shorten distances.

# GATE 2021 CS1: Q53 (printed CS Q43)

**Question:** [Official archived paper page 35](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=35); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

If S is reflexive and circular, aSb together with bSb implies bSa, establishing symmetry. If aSb and bSc, circularity gives cSa, and symmetry then gives aSc; hence S is transitive as well, proving C. Reflexive and symmetric need not imply transitive: take all loops on {1, 2, 3}, pairs (1, 2),(2, 1),(2, 3),(3, 2), but omit (1, 3). This refutes A. The empty relation on a nonempty set is circular, symmetric and transitive but not reflexive, refuting B and D.

**Derived answer:** B; C

## Solution

There are3^(n²) matrices because each of n² entries has 3 choices. There are also3^(n²) functions from an n²-element domain to a 3-element codomain. A direct bijection reads matrix entries in a fixed order and maps a, b, c to 0, 1, 2. A bijection is also a surjection and an injection, so B, C.

For each of the 10 elements choose exactly one of three states: outside B, in B but not A, or in A (and therefore in B). Choices are independent, giving3^10=59049 ordered pairs. The source symbol is subset-or-equal, so A=B is included.
