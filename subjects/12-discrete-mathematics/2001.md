**Essential problem context (paraphrased):** Which relations are equivalence relations? R1 on integers: a+b is even; R2 on integers: a+b is odd; R3 on nonzero rationals: ab>0; R4 on natural numbers: |a−b|≤2. Options select R1/R2, R1/R3, R1/R4, or all four.

## Solution

Step 1: R1 means the integers have the same parity. Equality of parity is reflexive, symmetric and transitive, giving two equivalence classes. R3 means two nonzero rationals have the same sign, another equivalence relation.

Step 2: R2 is not reflexive because a+a is always even, never odd. R4 is not transitive: |1−3|≤2 and |3−5|≤2, but |1−5|>2.

Conclusion: Exactly R1 and R3 qualify, so B. Testing only symmetry would miss the failures in R2 and R4.

**Essential problem context (paraphrased):** Classify F1=(P→¬P) and F2=(P→¬P)∨(¬P→P). Choices: A F1 satisfiable and F2 valid; B F1 unsatisfiable and F2 satisfiable; C F1 unsatisfiable and F2 valid; D both satisfiable.

## Solution

Step 1: P→¬P simplifies to ¬P, so F1 is true when P is false and false when P is true. It is satisfiable but not valid.

Step 2: ¬P→P simplifies to P. Therefore F2=(¬P)∨P is a tautology, true for both valuations, so A states the precise classifications.

Option issue: Every valid formula is also satisfiable on this nonempty valuation space. Consequently D, saying both formulas are satisfiable, is also true. B and C incorrectly call F1 unsatisfiable. A is more informative, but the literal single-correct-option premise fails.

**Essential problem context (paraphrased):** Count four-digit even decimal numbers whose four digits are distinct. Options are 2240,2296,2620,4536.

## Solution

Step 1: Separate the final digit 0 from the other even digits. If the last digit is 0, the first digit has 9 choices and the middle positions have 8 and 7, giving 9·8·7=504.

Step 2: If the last digit is one of 2,4,6,8, there are 4 choices. The first digit can be any nonzero digit except that last digit:8 choices. The middle positions then have 8 and 7 choices, including zero if unused. This gives 4·8·8·7=1792.

Total 504+1792=2296, B. Counting all even last digits uniformly would mishandle leading zero.

Thus S2 need not hold and only S1 is universally correct, A. Injectivity would make the intersection equality valid.

## Solution

Step 1: Treat the seven distinct accidents as independent choices among seven equally likely days. There are 7^7 equally likely day assignments.

## Solution

Step 1: The fixed labeled vertex set has binomial(n,2)=n(n−1)/2 possible unordered pairs of distinct vertices. Each pair can independently be an edge or not.

Step 2: Multiplying these two choices for every pair gives 2^[n(n−1)/2], D. Connectedness is not imposed, so no edge subsets are excluded.

This is the conventional simple loop-free graph model. Permitting loops adds n binary choices, and permitting unrestricted parallel edges would remove this finite count. The fixed labels mean we are not quotienting by graph isomorphism.

**Independently derived answer:** P(A∩B)=P(A)∩P(B).

**Essential problem context (paraphrased):** Prove P(A∩B)=P(A)∩P(B).

Task: Prove the stated power-set identity.

## Solution

1. Prove equality by membership of an arbitrary set S, rather than by membership of an arbitrary element of A. Power sets contain sets.

2. If S∈P(A∩B), then S⊆A∩B. Every element of S consequently belongs to both A and B, so S⊆A and S⊆B. Therefore S∈P(A) and S∈P(B), hence S∈P(A)∩P(B).

3. Conversely, if S∈P(A)∩P(B), then S⊆A and S⊆B. Every element of S lies in both sets, so S⊆A∩B and S∈P(A∩B).

4. The two inclusions prove the identity, including when A or B is empty. In that case the empty subset remains an element of the relevant power sets.

**Independently derived answer:** S(m+n)=S(m)+S(n)+mn for all m,n≥0.

**Essential problem context (paraphrased):** S(n)=0+1+⋯+n for natural numbers including 0. Prove S(m+n)=S(m)+S(n)+mn.

Task: Give an induction proof of the stated sum identity.

## Solution

1. Fix an arbitrary natural number m and induct on n. This proves the statement for all n for each m, and hence for all pairs.

2. Base n=0: S(m+0)=S(m), while S(m)+S(0)+m·0=S(m).

3. Inductive hypothesis: assume S(m+n)=S(m)+S(n)+mn. By the defining sum, S(m+n+1)=S(m+n)+(m+n+1).

4. Substitute the hypothesis and regroup: S(m+n+1)=S(m)+S(n)+mn+m+n+1 = S(m)+[S(n)+(n+1)]+m(n+1) = S(m)+S(n+1)+m(n+1).

5. This proves the induction step without assuming the closed form n(n+1)/2. Since m was arbitrary, the required two-variable identity follows.

**Essential problem context (paraphrased):** N={0,1,2,…}; h:N×N→N is h(a,b)=(2a+1)2^b−1.

Task: Prove that h is injective.

## Solution

1. Assume h(a,b)=h(c,d). Adding 1 gives (2a+1)2^b=(2c+1)2^d, where both parenthesized factors are odd positive integers.

2. If b<d, divide by 2^b. The left side is odd and the right side, (2c+1)2^(d−b), is even, a contradiction. The symmetric argument rules out d<b.

3. Thus b=d. Cancelling 2^b gives 2a+1=2c+1, so a=c.

4. Equality of images has forced equality of both coordinates, exactly the definition of injectivity. The argument also covers zero coordinates, since 2^0=1 and 2·0+1 is odd.

**Essential problem context (paraphrased):** N={0,1,2,…}; h:N×N→N is h(a,b)=(2a+1)2^b−1.

Task: Prove that h is surjective.

## Solution

1. Take an arbitrary target n∈N. The positive integer n+1 can be repeatedly divided by 2 until an odd number u remains. This terminates because positive integers strictly decrease at each division.

2. If b divisions were made, then n+1=u2^b, with b≥0 and u≥1 odd. Define a=(u−1)/2, which is a nonnegative integer.

3. Then h(a,b)=(2a+1)2^b−1=u2^b−1=n. Thus every target has a preimage in N×N, establishing surjectivity.

4. For example n=11 gives n+1=12=3·2², so (a,b)=(1,2). For n=0 the preimage is (0,0). Combined with injectivity, h is a bijection.
