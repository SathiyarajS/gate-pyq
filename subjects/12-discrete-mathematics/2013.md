**Official answer:** C

**Derived answer:** C under independent-edge model

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

## Solution

For each of C(8, 3)=56 vertex triples, its triangle indicator has mean(1/2)^3=1/8 under the standard independent-edge random-graph model. By linearity of expectation the expected count is 56/8=7, C. Equal individual edge probabilities alone would not establish independence: choosing either the complete or empty graph with probability1/2 would instead give mean28. The usual random-graph model is therefore a necessary convention.

# GATE 2013 CS: Q57 (printed CS Q47)

**Question:** [Official archived paper page 10](https://web.archive.org/web/20130418030400id_/http://www.gate.iitb.ac.in:80/gate2013/wp-content/uploads/2013/03/CS-A.pdf#page=10); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Marks to All

**Derived answer:** Both A and D are not equivalent.

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

## Solution

For each x, write P(x)=∀y α and Q(x)=∀z β. Quantifier negation and De Morgan’s law turn the target ¬∃x(P∧Q) into ∀x(¬P∨¬Q). Option B is ∀x(Q→¬P), and option C is ∀x(P→¬Q); both simplify to that target. Option A is ∀x(¬Q→P)=∀x(Q∨P), while option D is ∀x(¬P→¬Q)=∀x(P∨¬Q). Neither is equivalent to the target. For an explicit countermodel, use a nonempty singleton domain and let α and β both be true: the target is false, but A and D are both true. Hence the single-choice request has two qualifying options, A and D. The official Code A key resolves scoring as Marks to All; it does not select one letter.
