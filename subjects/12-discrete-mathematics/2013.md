**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

**Paraphrased problem context:** On the integers define x⊕y=x²+y². Which holds? A commutative but not associative; B both; C associative but not commutative; D neither.

## Solution

x⊕y=x²+y² is symmetric, so it is commutative. It is not associative: (1⊕1)⊕2=2²+2²=8, whereas1⊕(1⊕2)=1²+5²=26. Therefore A.

Teaching detail:
Commutativity asks whether swapping the two inputs changes the output; x²+y²=y²+x² for all integers. Associativity asks whether changing parentheses changes a three-input computation. For inputs1, 1, 2, first forming1⊕1 gives2 and then2⊕2 gives8. First forming1⊕2 gives5 and then1⊕5 gives26. One counterexample is enough to disprove associativity, whereas commutativity was established for arbitrary inputs.

**Paraphrased problem context:** Cars arriving per minute follow a Poisson distribution of mean3. Find P(X<3): A8/(2e³), B9/(2e³), C17/(2e³), D26/(2e³).

## Solution

For Poisson mean3, P(X<3)=P(0)+P(1)+P(2)=e^(−3)(1+3+9/2)=17/(2e³), C.

Teaching detail:
For Poisson mean λ, P(X=k)=e^(−λ)λ^k/k!. The event fewer than 3 consists of the disjoint outcomes0, 1, 2. Substituting λ=3 gives probabilities e^(−3), 3e^(−3), and(9/2)e^(−3). Their sum is(1+3+4.5)e^(−3)=8.5e^(−3)=17/(2e³). Do not include X=3: “fewer than” is strict.

**Official answer:** C

**Derived answer:** C under independent-edge model

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

**Paraphrased problem context:** An undirected random graph has 8 vertices, with edge probability1/2 for each vertex pair. Find the expected number of unordered triangles. A1/8, B1, C7, D8. The standard independent-edge model is intended.

## Solution

For each of C(8, 3)=56 vertex triples, its triangle indicator has mean(1/2)^3=1/8 under the standard independent-edge random-graph model. By linearity of expectation the expected count is 56/8=7, C. Equal individual edge probabilities alone would not establish independence: choosing either the complete or empty graph with probability1/2 would instead give mean28. The usual random-graph model is therefore a necessary convention.

Teaching detail:
Use one indicator variable for each unordered three-vertex subset, not for each ordered traversal of a triangle. There are8·7·6/6=56 such subsets. Its three edges must all occur, with probability(1/2)³ under independence. The expected sum is the sum of expectations, so56/8=7. Distinct triangle indicators can share edges and need not be independent; linearity of expectation does not require their independence. The independence needed is within the three edges of one triangle.

**Derived answer:** C

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

**Paraphrased problem context:** For undirected graphs, assess P:the number of odd-degree vertices is even; Q:the sum of all degrees is even. A Ponly; B Qonly; C both; D neither.

## Solution

The source asks about undirected graphs. Each edge contributes2 to the sum of vertex degrees, so that sum is 2|E| and even. Reducing the sum modulo2 shows that the number of odd-degree vertices must also be even. Thus both P and Q hold, C.

Teaching detail:
Count edge endpoints in two ways. Summing degrees counts each undirected edge once at each end, so Σdeg(v)=2|E| and Q holds. Separate even- and odd-degree vertices. Even degrees contribute0 modulo2; each odd degree contributes1. Since the total is even, the count of odd contributions must be even, proving P. The result also accommodates loops if each loop contributes2 to degree, though the ordinary simple-graph convention suffices.

**Paraphrased problem context:** The line graph has one vertex per original edge, adjacent when the corresponding edges share an endpoint. Which claims hold universally? P line graph of a cycle is a cycle; Q of a clique is a clique; R of a planar graph is planar; S of a tree is a tree. A Ponly; B P, R; C Ronly; D P, Q, S.

## Solution

A cycle’s edges form another cycle in the line graph, so P holds. Q fails for K4: two disjoint original edges become nonadjacent vertices. R fails for the planar star K1, 5, whose line graph is nonplanar K5. S fails for the tree K1, 3, whose line graph is the triangle K3. Therefore only P is universally true, A.

Teaching detail:
A universal assertion can be refuted with one permitted example. On a cycle each edge meets exactly its predecessor and successor, forming another cycle. In K4, edges12 and 34 are disjoint, so their line-graph vertices are not adjacent: Q fails. A planar star with five leaves has all five edges meeting the center, so its line graph is K5 and nonplanar: R fails. A three-leaf star is a tree but has line graph K3, a cycle: S fails. Only P survives.

**Paraphrased problem context:** Translate “None of my friends are perfect,” with F(x)=friend and P(x)=perfect. A ∃x(F(x)∧¬P(x)); B ∃x(¬F(x)∧P(x)); C ∃x(¬F(x)∧¬P(x)); D ¬∃x(F(x)∧P(x)).

## Solution

The statement says there is no object that is both a friend and perfect: ¬∃x(F(x)∧P(x)), option D. Equivalently ∀x(F(x)→¬P(x)). A merely says at least one friend is imperfect and does not rule out another perfect friend. MuPDF rendering was used to verify the existential quantifiers and conjunctions omitted by the Poppler render.

Teaching detail:
“None” rules out the existence of a perfect friend, which is the negation of an existential conjunction. It does not assert that any friend exists at all. Therefore the statement remains true when the speaker has no friends, whereas A would be false in that case because it requires an imperfect friend to exist. B and C speak about nonfriends and do not constrain perfect friends. D is exactly the desired prohibition, equivalently ∀x(F(x)→¬P(x)).

# GATE 2013 CS: Q57 (printed CS Q47)

**Question:** [Official archived paper page 10](https://web.archive.org/web/20130418030400id_/http://www.gate.iitb.ac.in:80/gate2013/wp-content/uploads/2013/03/CS-A.pdf#page=10); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Marks to All

**Derived answer:** Both A and D are not equivalent.

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

**Paraphrased problem context:** Which option is NOT equivalent to ¬∃x[(∀y α)∧(∀z β)]? A∀x[(∃z¬β)→∀yα]; B∀x[(∀zβ)→∃y¬α]; C∀x[(∀yα)→∃z¬β]; D∀x[(∃y¬α)→∃z¬β]. The single-choice source has official Marks to All.

## Solution

For each x, write P(x)=∀y α and Q(x)=∀z β. Quantifier negation and De Morgan’s law turn the target ¬∃x(P∧Q) into ∀x(¬P∨¬Q). Option B is ∀x(Q→¬P), and option C is ∀x(P→¬Q); both simplify to that target. Option A is ∀x(¬Q→P)=∀x(Q∨P), while option D is ∀x(¬P→¬Q)=∀x(P∨¬Q). Neither is equivalent to the target. For an explicit countermodel, use a nonempty singleton domain and let α and β both be true: the target is false, but A and D are both true. Hence the single-choice request has two qualifying options, A and D. The official Code A key resolves scoring as Marks to All; it does not select one letter.

Teaching detail:
Using P=∀yα and Q=∀zβ, the target is universally ¬P∨¬Q. Implication U→V means ¬U∨V. Therefore B becomes¬Q∨¬P and C becomes¬P∨¬Q, both correct equivalents. A instead becomes Q∨P, and D becomes P∨¬Q. At P=Q=true, both AandDare true while the target is false. This is a direct two-option counterexample to a single-choice “NOT equivalent” question, explaining why MTA rather than a repaired single letter is retained.
