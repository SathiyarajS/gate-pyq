**Paraphrased problem context:** For directed G=(V,E), which construction preserves its strongly connected components? A: Keep V and use every ordered pair not in E. B: Keep V and reverse all edges: E₂={(u,v):(v,u)∈E}. C: Keep V and add an edge (u,v) whenever G has a path from u to v of length at most 2. D: Keep E but remove isolated vertices from V. The paper asks for one option.

## Solution

1. Method and setup. An SCC is an equivalence class under mutual reachability, so compare reachability rather than individual edges. Reversing paths preserves mutual reachability. Also, shortening existing paths into edges cannot introduce reachability that was absent, while retaining all length-one edges preserves old paths.

2. Work through the result and its assumptions. Reversing every edge reverses paths and preserves mutual reachability, so B preserves every SCC. C also preserves them: it includes every original length 1 edge, and every added edge abbreviates an original path of length≤2. Thus reachability in either graph is equivalent. The official single answer B omits the equally valid C. Deleting isolated vertices loses singleton SCCs; complementing edges need not preserve SCCs.

**Paraphrased problem context:** Which Boolean formula is NOT a tautology? A ((a→b)∧(b→c))→(a→c); B (a↔c)→(¬b→(a∧c)); C (a∧b∧c)→(c∨a); D a→(b→a).

## Solution

1. Set up the reasoning. An implication fails only when its premise is true and conclusion false. To refute a proposed tautology, one such assignment is enough; proving the others can be done by their logical forms.

2. Derive the result. Set a=b=c=false. Then a↔c is true, NOT b is true, and a AND c is false, so B evaluates true→(true→false)=false.
