**Official answer:** A,B,C

**Derived answer:** A,B,C

**Paraphrased problem context:** For group G with identity 1, select true statements: A (xy)²=x²y² for all x,y implies commutativity; B x²=1 for all x implies commutativity; C order 2 implies commutativity; D a subgroup of a commutative group need not be commutative.

## Solution

A gives xyxy=xxyy; multiplying on the left by x^−1 and on the right by y^−1 gives yx=xy. In B each element is its own inverse, so xy=(xy)^−1=y^−1x^−1=yx. Every group of order 2 is cyclic and hence abelian, proving C. Every subgroup of an abelian group inherits commutativity, so D is false. Thus A, B, C.

Teaching detail:
For A, x^−1(xyxy)y^−1=x^−1(xxyy)y^−1 simplifies to yx=xy; cancellation does not assume the very commutativity being proved. For C, writing G={1,g} forces g²=1 by closure and cancellation, and every product is among these commuting elements.

**Paraphrased problem context:** What is the maximum possible edge count of a disconnected simple undirected graph on 10 vertices?

## Solution

For a disconnected simple graph with 10 vertices, maximize edges by making each component complete. Moving vertices into the largest component increases the sum of binomial(component size, 2), so the maximum uses sizes 9 and 1. This gives binomial(9, 2)=36 edges.

Teaching detail:
If two nonempty components have a and b vertices, merging them would add ab edges. To keep at least two components while maximizing edges, use one largest possible component and one isolated vertex. Equivalently for a split k and 10−k the complete-component bound is C(10,2)−k(10−k), largest at k=1 or 9.

**Paraphrased problem context:** How many distributions of six identical balls into three identical bins exist, allowing empty bins?

## Solution

Because both balls and bins are identical, count unordered partitions of 6 into at most three parts. In nonincreasing order they are (6, 0, 0),(5, 1, 0),(4, 2, 0),(4, 1, 1),(3, 3, 0),(3, 2, 1),(2, 2, 2). Therefore 7 distributions, allowing empty bins as stated by the ordinary distribution model.

Teaching detail:
Sort occupancies a≥b≥c≥0 so each distribution is counted once. For c=0, b ranges 0…3 giving four cases; for c=1, b=1 or 2 gives two; for c=2, only a=b=c=2 gives one. Hence 4+2+1=7. Stars-and-bars would count labeled bins and overcount here.

**Paraphrased problem context:** For n≥0, a_n=n+1 if n is odd, and 1 otherwise. Find the ordinary generating function. Options all include +1/(1−x): A x(1+x²)/(1−x²)²; B x(3−x²)/(1−x²)²; C 2x/(1−x²)²; D x/(1−x²)².

## Solution

Write a_n=1+n for odd n and 1 for even n. The baseline generating function is 1/(1−x). Also Σ_(odd n≥1) n x^n=x d/dx[x/(1−x²)]=x(1+x²)/(1−x²)². Adding gives 1/(1−x)+x(1+x²)/(1−x²)², option A.

Teaching detail:
The first coefficients are 1,2,1,4,1,6,… . Begin with the all-ones series, then add x+3x³+5x⁵+… . Differentiating x+x³+x⁵+…=x/(1−x²) and multiplying by x produces exactly that odd-index correction. This also checks that the constant coefficient remains 1.

**Official answer:** D

**Paraphrased problem context:** For a simple undirected unweighted graph on at least three vertices with adjacency matrix A, the triangle count is the trace of which matrix? A A³; B A³/2; C A³/3; D A³/6.

## Solution

The ith diagonal entry of A³ counts length-three closed walks starting at vertex i. In a simple undirected graph each such walk traverses a triangle. Each triangle contributes three starting vertices and two directions, hence six walks. Therefore the number of triangles is trace(A³)/6, D.

Teaching detail:
A length-three closed walk i→j→k→i cannot repeat an adjacent vertex because there are no loops, so i,j,k are distinct. Every triangle is counted starting at i,j,k and in each of two orientations: 3×2=6. Dividing by 3 alone would still count both orientations.

**Paraphrased problem context:** For the Petersen graph define vertices v0…v4,u0…u4, with edges vi–v(i+1), vi–ui, ui–u(i+2), subscripts modulo 5. Select true claims: A chromatic number 3; B Hamiltonian path exists; C isomorphic to the alternate source drawing; D maximum independent-set size 3. Reconstruct the alternate drawing by a 9-cycle h0…h8 plus center h9, with extra edges h0–h9,h3–h9,h6–h9,h1–h5,h2–h7,h4–h8.

## Solution

Label the outer pentagon v0,…, v4 clockwise from the top, and corresponding inner vertices u0,…, u4. Edges are vi-v(i+1), vi-ui, ui-u(i+2), indices modulo 5. A proper three-coloring is v=(0, 1, 0, 1, 2), u=(1, 0, 2, 2, 1); the outer odd cycle rules out two colors. A Hamiltonian path is v0, v1, v2, v3, v4, u4, u1, u3, u0, u2. For the second drawing label its nine perimeter vertices h0,…, h8 clockwise from the top and its central vertex h9. Its extra edges are h0-h9, h3-h9, h6-h9, h1-h5, h2-h7, h4-h8. An edge-preserving bijection maps (v0, v1, v2, v3, v4, u0, u1, u2, u3, u4) to (h0, h1, h2, h3, h9, h8, h5, h7, h4, h6), proving isomorphism. Finally {v0, v2, u3, u4} is independent, disproving the claimed maximum 3. In fact an independent set of 5 in this cubic 10-vertex 15-edge graph would force every edge across that partition, contradicting its odd cycle, so the maximum is 4. Thus A, B, C. Both drawings and all listed extra edges were visually inspected.

Teaching detail:
The explicit coloring is a verifiable upper bound, and the outer 5-cycle supplies the matching lower bound of three. A Hamiltonian path need not close back to its start, so the Petersen graph’s lack of a Hamiltonian cycle is irrelevant. The bijection in the solution preserves all fifteen edges, providing a stronger isomorphism witness than matching degrees alone.

**Paraphrased problem context:** Given f(1)=1, f(2n)=2f(n)−1, f(2n+1)=2f(n)+1 for n≥1, select identities for positive n: A f(2^n−1)=2^n−1; B f(2^n)=1; C f(5·2^n)=2^(n+1)+1; D f(2^n+1)=2^n+1.

## Solution

For positive integer n, prove A by induction: f(1)=1, and applying the odd recurrence to 2^(n+1)-1=2(2^n-1)+1 preserves f(2^n-1)=2^n-1. For B, repeated use of f(2m)=2f(m)-1 starting with f(1)=1 yields f(2^n)=1. Also f(5)=2f(2)+1=3. Repeated doubling gives f(5*2^n)-1=2^n(f(5)-1)=2^(n+1), proving C. D is false: at n=2, f(5)=3 whereas 2^2+1=5. The exponents in all four options were visually checked.

Teaching detail:
A useful closed form is f(m)=2(m−2^⌊log2(m)⌋)+1. It follows by induction on the binary length: the leading 1 determines the power of two, and the even/odd recurrence appends a bit while updating the residual. Substituting m=2^n−1,2^n,5·2^n confirms the three identities and also shows f(2^n+1)=3, not 2^n+1 for n≥2.

**Paraphrased problem context:** For the adjacency matrix A of an n-vertex simple undirected unweighted graph, select true statements: A diagonal of A² equals degrees; B connectivity implies A^(n−1)+I has no zero entry; C sum of A's entries ≤2(n−1) implies acyclic; D a 1 in every row/column implies connectivity.

## Solution

The ith diagonal of A squared is sum_j A_ij A_ji=sum_j A_ij, since the matrix is symmetric with binary entries. It therefore equals degree(i), proving A. B fails for the three-vertex path: no length-two walk connects adjacent vertices, so that off-diagonal entry of A^2+I is zero. C fails for a triangle plus an isolated vertex: n=4 and the entry sum is 6=2(n-1), yet there is a cycle. D fails for two disjoint edges, which give no zero row or column but are disconnected.

Teaching detail:
The distinction in B is walks of exactly n−1 edges versus paths of at most n−1 edges. Connectivity guarantees the latter, not the former. Adding I supplies only length-zero diagonal walks; it does not add all smaller powers needed to test reachability. In D, absence of isolated vertices still permits several nontrivial components.

**Paraphrased problem context:** Directed graph on {1,2,3,4,5} has edge i→j exactly when 1≤j≤i≤5. Count directed spanning trees rooted at 5 with directed paths from 5 to every vertex and an undirected underlying tree.

## Solution

An edge goes only from a larger label to a smaller label, apart from irrelevant self-loops. Every nonroot vertex j in an outward tree must choose exactly one incoming edge from a parent in {j+1,..., 5}. There are respectively 4, 3, 2, 1 choices for j=1, 2, 3, 4. Any such choices form a tree rooted at 5: following parents strictly increases the label and must end at 5, so there are no cycles and every vertex is reached. The total is 4*3*2*1=24.

Teaching detail:
Self-loops cannot be in a spanning tree. Each nonroot has indegree exactly one in an outward arborescence, so choosing its parent is necessary, not merely sufficient. Exactly four nonloop edges are selected; increasing parent labels ensure all parent chains terminate at the sole root 5 rather than another component.
