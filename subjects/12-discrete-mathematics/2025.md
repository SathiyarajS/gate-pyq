

# GATE 2025 CS1: Q17

**Question:** [Official archived paper page 17](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=17); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** Let g:A→B and f:B→C. Both f and f∘g are surjective. Which property must g have? A surjective; B injective; C bijective; D neither injectivity nor surjectivity is required.

## Solution

Approach: Determine whether hitting every point of C requires hitting every point of B. Different points of B can share the same image under f, so it need not.
Construct a counterexample: A={1,2}, B={u,v}, C={w}. Define g(1)=g(2)=u and f(u)=f(v)=w. The function f is onto C because w has a preimage. The composition sends both elements of A to w, so it is also onto C.
However g is not injective, because its two inputs share the output u, and is not onto B, because v is missed. This single example refutes the necessary-property claims in A, B and C and establishes D.
Conceptually, g only needs to hit enough points of B to cover all f-fibres over C. The conclusion would differ if extra assumptions, such as injectivity of f, were supplied; none is supplied here.

# GATE 2025 CS1: Q30

**Question:** [Official archived paper page 30](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=30); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 195 to 195

**Derived answer:** 195

**Paraphrased problem context:** Over alphabet {a,b,c}, count the length-five strings containing at least one adjacent equal pair aa, bb or cc.

## Solution

Approach: Count the complement, because counting each repeated-pair position directly would count some strings multiple times.
There are three choices independently at each of five positions, so there are 3^5=243 strings in total. A string with no equal adjacent symbols has 3 choices for its first symbol. At each of its remaining four positions, the immediately previous symbol is forbidden and the other two are allowed. This gives 3×2^4=48 strings without adjacent repeats.
Every string either has an adjacent equal pair or has none, and these categories are disjoint. Subtracting the latter from the total gives 243−48=195.
For example aaaaa has four repeated-adjacency positions, but it must count as just one string. Complement counting handles such overlaps automatically. The condition is “at least one”, so strings with two, three or four equal adjacent pairs all remain included in 195.

# GATE 2025 CS1: Q48

**Question:** [Official archived paper page 48](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=48); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;D

**Derived answer:** B;D

**Paraphrased problem context:** mother(y,x) means y is x’s mother; noteq(x,y) means x≠y. Which formulae express that everyone has exactly one mother? A ∀x∃y∃z(mother(y,x) ∧ ¬mother(z,x)); B ∀x∃y[mother(y,x) ∧ ∀z(noteq(z,y)→¬mother(z,x))]; C ∀x∀y[mother(y,x)→∃z(mother(z,x)∧¬noteq(z,y))]; D ∀x∃y[mother(y,x) ∧ ¬∃z(noteq(z,y)∧mother(z,x))].

## Solution

Approach: “Exactly one” requires both existence and uniqueness for each x.
B first supplies a witness y with mother(y,x). Its universal clause says every z different from y is not a mother of x, which excludes all second mothers. Hence B expresses both requirements.
D has the same existence clause and says there is no different z that is also a mother. By negating an existential conjunction, that uniqueness clause is equivalent to B’s universal implication. Thus D is also correct.
A only supplies one mother and one nonmother. It allows two or more mothers as long as somebody is not a mother, so it does not enforce uniqueness. C says that if y is a mother, an equal mother z exists; choosing z=y always satisfies it. It imposes no uniqueness and, when no mothers exist, is vacuously true, so it does not even enforce existence.
Therefore choose B,D. The location of the quantifiers and the difference between a universal exclusion and one existential nonexample are decisive.

# GATE 2025 CS1: Q49

**Question:** [Official archived paper page 49](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=49); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Let A={0,1,2,…} and F be all functions A→A. Define (f1⊙f2)(n)=f1(n)+f2(n) for every n. Classify (F,⊙): A Abelian group; B Abelian monoid; C non-Abelian group; D non-Abelian monoid.

## Solution

Approach: Check closure, associativity, identity, commutativity and inverses separately. The operation is pointwise addition, not function composition.
For any n, the sum of two non-negative integers is non-negative, so f1⊙f2 is again a function A→A: closure holds. Ordinary addition is associative, so evaluating either (f1⊙f2)⊙f3 or f1⊙(f2⊙f3) at n gives the same sum of three values. The identically zero function e(n)=0 acts as a two-sided identity.
Addition is commutative at every n, so the function operation is commutative. These facts make an Abelian monoid.
To be a group every function would need an inverse in F. The constant function f(n)=1 would require an inverse g(n)=−1 for all n to obtain zero. Such a g does not map A to A. Therefore inverses do not exist for all elements and the structure is not a group. Select B; A and C fail the inverse requirement, and D fails commutativity.

# GATE 2025 CS2: Q15

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** P(x) is any predicate on the natural numbers, with 0 included. Which implication is valid for every P?
A. [P(0) and ∀x(P(x)⇒P(x+1))] ⇒ ∀x P(x).
B. [P(0) and ∀x(P(x)⇒P(x−1))] ⇒ ∀x P(x).
C. [P(1000) and ∀x(P(x)⇒P(x−1))] ⇒ ∀x P(x).
D. [P(1000) and ∀x(P(x)⇒P(x+1))] ⇒ ∀x P(x).
For downward steps, interpret the implication only where x−1 is in the domain.

## Solution

A is the induction principle. P(0) supplies the first case. The upward step gives P(1) from P(0), then P(2) from P(1), and so on. Every nonnegative integer is reached after finitely many upward steps, proving ∀x P(x).

The direction of the step must match the base and the target domain. B starts at the smallest element and moves downward, so it cannot establish any positive case. For example, P(x) meaning “x=0” satisfies the meaningful downward condition and P(0), but not all natural numbers satisfy P. C can cover 0 through 1000, not larger numbers; P(x) meaning “x≤1000” is a counterexample. D can cover 1000 upward, but not smaller numbers; use P(x) meaning “x≥1000.” Thus A alone is valid. Literally writing P(−1) for a predicate only defined on natural numbers is a domain issue in B/C; it does not supply the missing coverage.

# GATE 2025 CS2: Q42

**Question:** [Official archived paper page 31](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=31); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

**Paraphrased problem context:** Let F be all functions {1,…,n}→{0,1}, for positive n. Define f≼g exactly when f(x)≤g(x) for every x, using 0≤1. Select true statements.
Options: A. ≼ is symmetric; B. (F,≼) is a partial order; C. (F,≼) is a lattice; D. ≼ is an equivalence relation.

## Solution

Verify the partial-order axioms coordinate by coordinate. Reflexivity holds because f(x)≤f(x). If f≼g and g≼f, then both inequalities force f(x)=g(x) at each x, so f=g; this is antisymmetry. If f≼g and g≼h, transitivity of ≤ gives f≼h. Thus B is true.

For any two functions define m(x)=min(f(x),g(x)) and j(x)=max(f(x),g(x)). Both are still {0,1}-valued functions. The function m is below both f and g; any other common lower bound is below m at every coordinate. Hence m is their greatest lower bound. Similarly, j is their least upper bound. Every pair therefore has a meet and join, establishing the lattice claim C. This is the same ordering as subset inclusion under the identification f↔{x:f(x)=1}.

A is false: the all-zero function is below the all-one function, but the reverse comparison fails for positive n. An equivalence relation must be symmetric, so D is false too. Select B,C. The positive-domain convention matters: if n=0, only the empty function exists and the relation also becomes symmetric.
