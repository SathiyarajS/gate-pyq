**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

Each pass places one selected minimum using at most one swap, and there are n−1 passes. Inputs exist requiring a linear number of those swaps, so the worst-case swap count is Θ(n), A, despite Θ(n²) comparisons.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Single-source Bellman-Ford detects a negative cycle reachable from that source by checking for a further relaxable edge after n−1 passes. A negative cycle in an unreachable component remains at infinite distance and need not be found. Therefore Q is true but P is not, giving B.

## Solution

A problem already in NP is NP-complete exactly when it is also NP-hard, so C. Membership in NP does not exclude membership in P, and solving an arbitrary NP problem efficiently would not by itself prove P=NP. Every NP decision problem is decidable.

## Solution

Kruskal considers accepted edges in nondecreasing weight. The relevant weights are be2,ef3,ac3,bc4,fg4,cd5. Equal-weight3 or4 edges may be interchanged in the valid choices. ## Solution

Selecting the one-quarter order statistic in linear time gives recurrence T(n)=T(n/4)+T(3n/4−1)+Θ(n). Each recursion level has linear total work, and the longest/shortest nontrivial paths are logarithmic up to constants. Equivalently the Akra–Bazzi exponent is1 because1/4+3/4=1. Thus Θ(n log n), B, assuming rank partitioning is implemented appropriately for distinct keys or duplicates.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Let l(i,j) be the LCS length of the first i elements of X and first j elements of Y. If either prefix is empty, l(i,j)=0. When X[i−1]=Y[j−1], the matching final elements extend an optimal LCS of both shortened prefixes, so expr1=l(i−1,j−1)+1. If they differ, an LCS omits at least one of the two final elements, yielding expr2=max(l(i−1,j),l(i,j−1)). Only option C gives a correct proposed expression. A omits shortening Y in the matching case, B omits both the match increment and shortening X, and D is circular.

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2009.pdf, physical page 12. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Initialize only the empty-prefix boundary L[0,j]=L[i,0]=0. Every other L[i,j] depends on L[i−1,j−1] in the matching case, or on L[i−1,j] and L[i,j−1] in the nonmatching case. Increasing-index row-major order computes all predecessors first; increasing-index column-major order also does so. Therefore B. Initializing every cell to zero is not necessary (A), and C contradicts these valid orders. D overstates the dependency: p<r alone does not require an arbitrarily far-right cell L[p,q] before L[r,s]; its OR condition can even demand opposite orders for incomparable cells such as (1,2) and (2,1).
