**Essential problem context (paraphrased):** Classify Σ(k=1…n)O(n) among O(n),O(n²),O(n³),O(3n²),O(1.5n²).

## Solution

If each summand has magnitude at most Cn with the same constant C, the sum has magnitude at most Cn². Thus it belongs to O(n²),and constant factors3 or1.5 do not change that class. O(n³) is also a valid looser upper bound,so C must be selected in a literal multiple-select reading. O(n) is not guaranteed because n terms each equal to n sum to n². The notation needs a uniform bound over k: if hidden constants depend unboundedly on k, such as terms kn, the sum can instead be Θ(n³). Big-O is an upper-bound class,not an assertion of tightness.

# GATE 1993: Q48 (printed II-B Q12)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204139/GATE1993.pdf#page=11), physical page 11. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A=A[0,0]; B=i<n; C=j<n−1; D=i+1 (n>=1).

**Essential problem context (paraphrased):** For integer A[0..n-1,0..n-1], complete four boxes in: max:=[A]; i:=0; j:=0; while [B] do begin if A[i,j]>max then max:=A[i,j]; if [C] then j:=j+1 else begin j:=0; i:=[D] end end. Use a single loop to find the largest entry. The source's comma/semicolon punctuation is defective; boxes A–D are one coordinated question.

## Solution

For n>=1 choose box A=A[0,0], B=(i<n), C=(j<n-1), D=i+1. Initializing to the first entry rather than 0 is important: all entries may be negative. The fully punctuated Pascal-style segment is:

begin
  max := A[0,0];
  i := 0; j := 0;
  while i < n do
  begin
    if A[i,j] > max then max := A[i,j];
    if j < n-1 then
      j := j+1
    else
    begin
      j := 0;
      i := i+1
    end
  end
end.

The pair (i,j) moves in row-major order: (0,0),(0,1),...,(0,n-1),(1,0),..., (n-1,n-1). At a row's last column, j is reset before proceeding to the next row. After the final element the state becomes (n,0); the guard stops before any invalid A[n,0] access.

Correctness invariant: immediately before processing each cell, max is the maximum of A[0,0] and every previously visited cell. The comparison incorporates the current cell and preserves this property. The rank n*i+j increases by exactly 1 per iteration and begins at 0, so exactly n^2 cells are visited. On exit the invariant gives the maximum over the entire array. For n=1 the first entry is compared with itself once and the program exits correctly. Time is Theta(n^2), extra space Theta(1). The n=0 case has no maximum and must be rejected or handled outside this segment; the printed task implicitly needs a nonempty array.

# GATE 1993: Q51 (printed II-B Q15)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204139/GATE1993.pdf#page=11), physical page 11. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** With a base case: a1=0, an=a(n−1)+n−1, giving n(n−1)/2 comparisons. Literal source lacks termination.

**Essential problem context (paraphrased):** The printed procedure loops i=1 to n−1, tests A[i]>A[i+1], swaps adjacent entries if true, and then unconditionally calls bubblesort(n−1). It has no base-case guard and prints temp : A[i] instead of a valid assignment. Let an count executions of the if test. Give a recurrence and solve it.

## Solution

First distinguish the literal source from its conventional intended algorithm. As printed, the procedure has no terminating case and contains a malformed temp assignment. It is not a valid terminating Pascal sort. After correcting assignment punctuation and adding a guard such as "if n<=1 then return", the standard comparison-count question is well-defined.

For the repaired algorithm, one call on n>=2 performs exactly n−1 tests A[i]>A[i+1], irrespective of the data or whether the consequent swap executes. It then calls the procedure once on n−1. Therefore a1=0 and an=a(n−1)+(n−1), n>=2. Equivalently a0=0 may be used with the guard. Repeated substitution gives
an=(n−1)+(n−2)+...+1+a1=n(n−1)/2.
An induction verifies the closed form: it is 0 at n=1; if a(n−1)=(n−1)(n−2)/2, adding n−1 yields n(n−1)/2. Thus the comparison count and running time are Theta(n^2), even for sorted input, because there is no early-exit flag. The swaps, unlike tests, depend on data: zero for sorted input, up to n(n−1)/2 for reverse order with distinct entries.

A complete repaired algorithm is:
procedure bubblesort(A,n):
    if n<=1: return
    for i=1,...,n-1:
        if A[i]>A[i+1]:
            temp:=A[i]
            A[i]:=A[i+1]
            A[i+1]:=temp
    bubblesort(A,n-1)

Each pass moves the largest of the first n entries to position n; recursion sorts the preceding prefix. Without the added guard the recursive calls proceed through n=1,0,−1,... (or fail because of the index type/stack), so the printed code does not successfully finish. The finite formula is explicitly for the repaired intended algorithm, not a claim that the literal program terminates.
