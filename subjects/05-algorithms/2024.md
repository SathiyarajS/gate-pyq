**Paraphrased problem context:** An algorithm checks whether an N-element integer array is sorted in either ascending or descending order by one pass comparing adjacent elements. Its worst-case running time is: A both O(N) and Ω(N); B O(N) but not Ω(N); C Ω(N) but not O(N); D neither.

## Solution

Approach: Big-O and big-Omega describe upper and lower bounds on the same worst-case running-time function; they are not synonyms for worst case and best case.
1. Maintain whether any adjacent pair increases and whether any adjacent pair decreases. Each of the N−1 adjacent pairs requires only constant work. The single pass therefore takes at most cN+d operations, giving O(N).
2. On an already sorted array, no early contradiction occurs. The algorithm must examine through the final adjacent pair to certify the property. Such an input requires a number of comparisons proportional to N, giving a worst-case Ω(N) lower bound.
3. Together these bounds give Θ(N).
Answer: A. Some unsorted inputs may allow early termination, but that does not remove the linear worst-case lower bound.

**Paraphrased problem context:** The printed recurrence gives T(n)=√n·T(√n)+n for n≥1 and T(1)=1. Which asymptotic answer is intended? A Θ(n log log n); B Θ(n log n); C Θ(n² log n); D Θ(n² log log n). The recursive branch overlaps the base case, so the literal definition needs qualification.

## Solution

Approach: First disclose the definition's defect, then solve the intended version with a constant-size stopping threshold.
1. Literally, the n≥1 branch applies at n=1 and says T(1)=T(1)+1, contradicting T(1)=1. Merely changing ≥ to > is still insufficient over exact real arguments: repeated square roots of n>1 approach 1 but never reach it in finitely many steps. A constant threshold greater than 1, or a specified integer-rounding convention with a valid base, is needed.
2. For the intended recurrence, divide by n and set F(n)=T(n)/n. Then √n·T(√n)/n=T(√n)/√n=F(√n), so F(n)=F(√n)+1.
3. After k expansions, F(n)=F(n^(1/2^k))+k. Reaching a fixed threshold c>1 requires log n/2^k≤log c, so k=Θ(log log n).
4. A bounded base value gives F(n)=Θ(log log n), hence T(n)=Θ(n log log n).
Official intended answer: A. This derivation is conditional on the corrected stopping model; it does not solve the inconsistent recurrence exactly as printed. Existing discrepancy CS-2024-S1-Q42-BASE-CASE is preserved.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** T is a DFS spanning tree of a directed graph G, rooted at v, and is also a BFS tree of G rooted at v. Which claims must hold? A G has no back edges relative to T. B G has no cross edges. C G has no forward edges. D Every edge of G belongs to T.

## Solution

Approach: A BFS tree preserves shortest-path distances from its root. Compare this constraint with the endpoint depths of each DFS edge type, using the usual simple directed-graph classification.
1. A non-tree forward edge u→w goes from a vertex to a proper descendant that is not its child. Thus depth_T(w)≥depth_T(u)+2.
2. But the edge supplies a root-to-w path of length depth_T(u)+1, shorter than its tree depth. This contradicts T being a BFS tree, so forward edges cannot exist. C is true.
3. Back edges are possible. In the directed cycle v→a→b→v, both DFS and BFS from v have the path v→a→b as their tree, and b→v is a back edge. Thus A and D are false.
4. Cross edges are also possible. Use edges v→a, v→b, b→a, with a explored before b in DFS. Both trees have a and b as root children, while b→a is a cross edge to the already completed branch.
Answer: C only.

**Official answer:** 60 to 60

**Derived answer:** 60

**Paraphrased problem context:** An undirected graph has 100 vertices. A complete DFS traversal produces a spanning forest containing 40 edges. How many connected components does the graph have?

## Solution

Approach: DFS starts a new tree exactly when it moves to a previously unvisited connected component. Each resulting tree spans that component.
1. Suppose there are c components and their vertex counts are v1,…,vc. The counts sum to 100.
2. A tree with vi vertices has exactly vi−1 edges. This includes an isolated vertex: vi=1 gives zero edges.
3. Summing over the DFS forest gives 40=Σ(vi−1)=Σvi−c=100−c.
4. Solving yields c=100−40=60.
Answer: 60 connected components. The original graph may have additional nontree edges and cycles; the given 40 counts only forest edges. One can also view each of those 40 tree edges as discovering one nonroot vertex, leaving 60 roots, one for each component.

**Paraphrased problem context:** T(0)=1, T(1)=2, and T(n)=5T(n−1)−6T(n−2) for n≥2. Choose its tight asymptotic class. A Θ(2^n); B Θ(n2^n); C Θ(3^n); D Θ(n3^n).

## Solution

Approach: Solve the characteristic equation and then enforce both initial conditions.

1. Derivation. The characteristic polynomial r²−5r+6=(r−2)(r−3) gives T(n)=a 2ⁿ+b3ⁿ. T(0)=1 gives a+b=1, while T(1)=2 gives 2a+3b=2. Subtracting twice the first equation yields b=0, so a=1 and T(n)=2ⁿ exactly. Therefore A; the larger characteristic root does not contribute for these initial values.

2. Explanation and checks. A direct induction independently verifies the result: assuming T(n−1)=2^(n−1) and T(n−2)=2^(n−2), the recurrence becomes (10−6)2^(n−2)=2^n. Both base cases agree. The characteristic roots are distinct, so no factor n is introduced by repeated roots. More importantly, choosing the largest root without solving for its coefficient would give the wrong growth class here because that coefficient is zero.

**Paraphrased problem context:** The distance of an integer array is the least number of entries replaced by arbitrary integers to make it nondecreasing. Find the distance of [2,5,3,1,4,2,6].

## Solution

Approach: Any entries kept in place must already form a nondecreasing subsequence; combine that lower bound with an explicit repair.

1. Derivation. Any unchanged elements must form a nondecreasing subsequence. Longest nondecreasing subsequence lengths ending at the seven positions are 1, 2, 2, 1, 3, 2, 4, so at most 4 elements can remain unchanged and at least 7−4=3 replacements are needed. Keep the subsequence 2, 3, 4, 6 at positions 1, 3, 5, 7; replace positions 2, 4, 6 by 2, 3, 4 respectively to obtain[2, 2, 3, 3, 4, 4, 6]. Thus3 is achievable and minimal.

2. Explanation and checks. For each position i define L[i]=1+max L[j] over j<i with A[j]≤A[i], or 1 if there is no such j. This yields [1,2,2,1,3,2,4], with maximum 4. Therefore keeping five entries is impossible. The displayed repair keeps four original entries and changes exactly three, establishing the matching upper bound. It is a replacement problem, not a sorting-by-swaps problem, and equality is allowed in the final array.

**Paraphrased problem context:** For positive X[0..n−1], initialize first=second=len1=len2=maxlen=0. For each v=X[i]: if v==first increment both len1,len2; else if v==second increment len2, set len1=P, second=first; else set len2=Q, len1=1, second=first. Update maxlen=max(maxlen,len2), then first=v. len1 is the equal-value suffix length; len2 is the suffix length with at most two distinct values. Choose P,Q: A len1+1,len2+1; B 1,len1+1; C 1,len2+1; D len2+1,len1+1.

## Solution

Approach: Interpret the saved values before the current iteration updates them.

1. Derivation. first is the previous element and len1 is its final equal-value run length. If the next item equals second but differs from first, the final equal run starts anew, so P=1, while the valid two-value suffix extends by one. If a third distinct value arrives, only the previous final run can accompany it; therefore the new two-value suffix has length len1+1, giving Q=len1+1. The assignments update second to the old first. Thus B; positive input values ensure initial zero sentinels are not actual array values.

2. Explanation and checks. For the prefix [1,2,2], len1=2 and len2=3. If the next value is 1, it is the other known value: the two-value suffix grows to 4, but the same-value suffix has length 1. If instead the next value is 3, keeping all three old elements would create three distinct values; only [2,2,3] is legal, of length old len1+1=3. Updating first last preserves the old run value while second is assigned.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 9 to 9

**Derived answer:** 9

**Paraphrased problem context:** Undirected graph vertices a,b,c,d,e,f,g have weight-1 edges ab,af,cd,de; weight-2 edges ag,bg,fg,cg,dg,eg; weight-3 edges bc,fe; and no others. How many distinct minimum-weight spanning trees exist?

## Solution

Approach: Force uniquely lightest cut edges, contract them, then count independent minimum connections.

1. Derivation. Each weight 1 edge (ab, af, cd, de) is uniquely lightest across the cut isolating its noncentral endpoint b, f, c, e, respectively, so all four occur in every MST. Contracting them gives components L={a, b, f}, R={c, d, e}, and{g}. There are three weight 2 choices linking L to g and three linking R to g. A minimum tree uses one of each, giving 3×3=9 distinct MSTs, each weight 4+2+2=8. Weight3 links L–R cannot improve that value. All edge labels were visually checked.

2. Explanation and checks. After contraction only three supervertices remain, requiring exactly two additional edges. Connecting g to the left component has three distinct original choices; connecting g to the right has another three. Each pair is acyclic and connects all seven original vertices once the four forced edges are restored. Choosing a weight-3 left–right link instead would require at least one further weight-2 edge and yield total at least nine rather than eight. Therefore it cannot contribute an alternative minimum tree.
