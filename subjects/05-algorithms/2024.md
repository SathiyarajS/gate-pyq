**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

A single pass performs at most a constant number of comparisons per adjacent pair, giving O(N). A sorted input requires examining all N−1 adjacent pairs in this algorithm, giving a worst-case Ω(N) bound. Therefore the worst case is Θ(N), satisfying both bounds in A.

# GATE 2024 CS1: Q42

**Question:** [Official archived paper page 27](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=27); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

For the intended recurrence above a constant-size base, divide by n and set F(n)=T(n)/n. Then F(n)=F(√n)+1. After k levels the argument is n^(1/2^k), so reaching a fixed constant threshold takes Θ(log log n) levels. Thus T(n)=Θ(n log log n), official A. The printed definition is literally inconsistent: its n≥1 recursive branch applies at 1 and gives T(1)=T(1)+1, contradicting T(1)=1. Moreover exact square-root iteration from a real n>1 never reaches1 in finitely many steps. A constant-size stopping threshold or discrete rounding convention is needed in addition to correcting the overlapping branch. The official asymptotic answer is preserved, not presented as a solution to the literal inconsistent definition.

# GATE 2024 CS1: Q45

**Question:** [Official archived paper page 28](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=28); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

A forward edge connects a vertex to a proper nonchild descendant in its DFS tree. It would give that descendant a path from the root shorter than its depth in T, contradicting the BFS-tree property. Thus no forward edges exist. Back edges may exist, as in a directed cycle whose DFS/BFS tree is a path. Cross edges may exist too: root r has children a, b; process a first, and include b→a. Both searches retain the two child edges, while b→a is cross. Hence only C is universally true, under the usual simple-graph edge classification.

## Solution

The characteristic polynomial r²−5r+6=(r−2)(r−3) gives T(n)=a 2ⁿ+b3ⁿ. T(0)=1 gives a+b=1, while T(1)=2 gives 2a+3b=2. Subtracting twice the first equation yields b=0, so a=1 and T(n)=2ⁿ exactly. Therefore A; the larger characteristic root does not contribute for these initial values.

## Solution

Any unchanged elements must form a nondecreasing subsequence. Longest nondecreasing subsequence lengths ending at the seven positions are1, 2, 2, 1, 3, 2, 4, so at most4 elements can remain unchanged and at least7−4=3 replacements are needed. Keep the subsequence2, 3, 4, 6 at positions1, 3, 5, 7; replace positions2, 4, 6 by 2, 3, 4 respectively to obtain[2, 2, 3, 3, 4, 4, 6]. Thus3 is achievable and minimal.

**Official answer:** B

**Derived answer:** B

## Solution

first is the previous element and len1 is its final equal-value run length. If the next item equals second but differs from first, the final equal run starts anew, so P=1, while the valid two-value suffix extends by one. If a third distinct value arrives, only the previous final run can accompany it; therefore the new two-value suffix has length len1+1, giving Q=len1+1. The assignments update second to the old first. Thus B; positive input values ensure initial zero sentinels are not actual array values.

# GATE 2024 CS2: Q59

**Question:** [Official archived paper page 38](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=38); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 9 to 9

**Derived answer:** 9

## Solution

Each weight1 edge (ab, af, cd, de) is uniquely lightest across the cut isolating its noncentral endpoint b, f, c, e, respectively, so all four occur in every MST. Contracting them gives components L={a, b, f}, R={c, d, e}, and{g}. There are three weight2 choices linking L to g and three linking R to g. A minimum tree uses one of each, giving3×3=9 distinct MSTs, each weight4+2+2=8. Weight3 links L–R cannot improve that value. All edge labels were visually checked.
