

# GATE 2010: Q22 (printed CS Q12)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 3. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** A database contains 10^k records. To process n records, package A takes 0.0001n² time units and B takes 10n log₁₀n time units. What is the smallest offered value of k for which B is preferred to A?
Options: (A) 12; (B) 10; (C) 6; (D) 5.

## Solution

Put n=10^k. Package B is faster when 10·10^k·k < 0.0001·10^(2k), equivalently 10^(k−5)>k. At k=5 this is 1>5, false; at k=6 it is 10>6, true. For positive integer k≤5, 10^(k−5)≤1≤k, so 6 is the smallest positive integer exponent, C. The meaningful growing-database interpretation excludes the degenerate n=1 case k=0.

Teaching detail: The inequality compares actual running-time formulas, not only asymptotic orders. At k=5, A=10^6 and B=5×10^6 time units, so A wins. At k=6, A=10^8 and B=6×10^7, so B wins. This illustrates why the smaller-growth algorithm need not be faster at small inputs when its constant factor is much larger.

# GATE 2010: Q44 (printed CS Q34)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 8. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** The weight of a real sequence a₀,…,aₙ₋₁ is a₀+a₁/2+⋯+aₙ₋₁/2^(n−1). A subsequence deletes elements without changing the order. X is the maximum subsequence weight of a₀,…,aₙ₋₁ and Y is that of a₁,…,aₙ₋₁. What is X?
Options: (A) max(Y,a₀+Y); (B) max(Y,a₀+Y/2); (C) max(Y,a₀+2Y); (D) a₀+Y/2.

## Solution

Split subsequences according to whether they include a₀. If not, their optimum weight is Y, the optimum on the suffix. If they do, a₀ contributes with weight 1 and each selected suffix element shifts one position, halving its contribution; the best such weight is a₀+Y/2. Thus X=max(Y,a₀+Y/2), B. The usual subsequence convention permits the empty subsequence, ensuring this also works with negative inputs.

Teaching detail: The split is exhaustive and disjoint: every candidate either omits a₀ or contains it. Including a₀ shifts every chosen suffix element one weight position to the right, multiplying the entire suffix weight by 1/2; its internal order and relative weights are unchanged. Since 1/2 is positive, the suffix maximizing its own weight also maximizes the scaled weight. The outer maximum is necessary because including a negative a₀ can be harmful.

# GATE 2010: Q60 (printed CS Q50)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 12. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** A complete undirected graph has vertices 0,1,2,3,4 and symmetric weight matrix W, with rows/columns in that order: [[0,1,8,1,4],[1,0,12,4,9],[8,12,0,7,3],[1,4,7,0,2],[4,9,3,2,0]]. What is the minimum weight of a spanning tree in which vertex 0 is a leaf?
Options: (A) 7; (B) 8; (C) 9; (D) 10.

## Solution

If vertex 0 is a leaf, removing it leaves a spanning tree on {1,2,3,4}; conversely any such tree plus one edge incident on 0 is feasible. Kruskal on the induced four-vertex graph chooses (3,4) of weight 2, (2,4) of weight 3, and (1,3) of weight 4, totaling 9. The cheapest edge from 0 has weight 1, either (0,1) or (0,3), hence the constrained minimum is 9+1=10, D. The unconstrained MST need not satisfy the leaf requirement.

Teaching detail: The leaf constraint permits exactly one edge incident to 0. Therefore 0 cannot serve as a cheap connector joining vertices 1 and 3 through two weight-one edges. On vertices 1,2,3,4, the sorted edges begin 3–4:2, 2–4:3, 1–3:4; these three create no cycle and already connect all four vertices, proving the induced-tree minimum of 9.

# GATE 2010: Q61 (printed CS Q51)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 12. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** A complete undirected graph has vertices 0,1,2,3,4 and symmetric weight matrix W, with rows/columns in that order: [[0,1,8,1,4],[1,0,12,4,9],[8,12,0,7,3],[1,4,7,0,2],[4,9,3,2,0]]. What is the minimum weight of a path from vertex 1 to vertex 2 containing at most three edges?
Options: (A) 7; (B) 8; (C) 9; (D) 10.

## Solution

The direct 1→2 path costs 12. With one intermediate vertex, costs via 0,3,4 are 9,11,12. With two distinct intermediate vertices, the six paths have costs: 1→0→3→2=9; 1→0→4→2=8; 1→3→0→2=13; 1→3→4→2=9; 1→4→0→2=21; 1→4→3→2=18. Thus minimum 8 is attained by 1→0→4→2, option B. All edge weights are positive, so adding a repeated-vertex cycle cannot improve a path within the edge limit.

Teaching detail: An unconstrained shortest-path calculation is insufficient because it may return a path with four edges. Indeed 1→0→3→4→2 has weight 1+1+2+3=7 but violates the three-edge limit. Enumerating zero, one and two intermediate vertices is exhaustive for simple paths with at most three edges; the weight-eight candidate obeys the constraint.
