**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Essential problem context (paraphrased):** An unsorted array A[1..n] contains n distinct values and contains x. A search repeatedly chooses i uniformly from 1..n, compares A[i] with x, stops on equality, and otherwise repeats the random choice. What is its expected comparison count before stopping?
(A) n; (B) n−1; (C) 2n; (D) n/2.

## Solution

Step 1: Recognize independent repeated trials.

Step 2: After any failed draw, the algorithm restarts with the same success probability 1/n; it has not removed that position from future draws. Thus the comparison count is geometric, P(N=k)=(1−1/n)^(k−1)/n. Its mean is 1/(1/n)=n, agreeing with the recurrence E=1+(1−1/n)E.

Conclusion and qualifications: Each independently sampled index hits the unique target with probability 1/n. If E is the expected number of comparisons including the successful comparison, E=1+(1−1/n)E, giving E=n, A. Resampling already examined positions is allowed; this is not a random permutation scan.

**Essential problem context (paraphrased):** For procedure A(n), if n≤2 return 1; otherwise return A(⌈√n⌉). Which listed bound best describes its running time?
(A) O(n); (B) O(log n); (C) O(log log n); (D) O(1).

## Solution

Step 1: Take logarithms of the argument shrinkage.

Step 2: Let m=log₂n. Taking a square root approximately halves m, so the recursion needs about log₂m halvings to make m constant. Therefore the number of constant-work calls is Θ(log log n). This count concerns runtime, not the returned value, which is always 1. Arbitrary-precision root computation would require a different per-call cost model.

Conclusion and qualifications: Ignoring integer rounding initially, after k calls the argument is n^(1/2^k). It becomes bounded once 2^k is of order log n, so the recursion depth is Θ(log log n). Ceiling rounding changes only constants, and the small integer arguments reach the base case. With constant-time root/rounding operations per call, C is the tight listed growth bound, even though looser O(n) and O(log n) bounds are also true.

**Independently derived answer:** For i≠j: ∞ if A[i,j]=0, otherwise 1; for i=j: 0

**Essential problem context (paraphrased):** Complete a template computing all-pairs shortest-path lengths in a directed graph G. Its n×n adjacency matrix A has A[i,j]=1 for an edge i→j and 0 otherwise. Initialization loops over i=1..n and j=1..n and executes:
if A[i,j]=0 then P[i,j]=____ else P[i,j]=____;
The algorithm then has nested loops, in this exact order: for i=1..n, for j=1..n, for k=1..n, executing:
P[____,____] = min{____,____};
Copy and complete the initialization line so that the algorithm is correct.

## Solution

1. Fix the graph interpretation. The adjacency entries are binary: A[i,j]=1 means a directed edge i→j of length 1, and A[i,j]=0 means that edge is absent. GateForum omits the numeral 1 in this sentence; GFG explicitly retains it, resolving that reproduction omission.

2. Handle distinct vertices before any intermediate vertices are allowed. If i≠j and A[i,j]=1, the one-edge path has length 1, so initialize P[i,j]=1. If i≠j and A[i,j]=0, no direct path is available yet, so initialize P[i,j]=∞. Zero would incorrectly claim a free path between disconnected vertices.

3. Handle the diagonal separately. Standard shortest-path distance permits the empty path, so P[i,i]=0 whether or not A[i,i] contains a self-loop. A length-1 self-loop cannot beat that empty path.

4. Fill the original two blanks with expressions that incorporate these cases, without changing the printed outer condition:

```text
if A[i,j] = 0 then P[i,j] = (0 if i = j else ∞)
              else P[i,j] = (0 if i = j else 1);
```

Equivalently, initialize off-diagonal entries to ∞/1 and then explicitly set each P[i,i] to 0.

5. Check a small graph. If the only edge is 1→2, initialization gives rows [0,1] and [∞,0]. This correctly represents the direct path, lack of a reverse path, and both empty paths.

6. State the convention caveat. The abbreviated fills “∞,1” alone make a diagonal entry the length of a shortest nonempty closed walk, or ∞ if none exists, rather than the standard distance 0. That abbreviation suffices only if diagonal results are excluded or that other convention is intended. The conditional fill above is correct for every vertex pair under the standard convention and respects the template’s two blanks.

# GATE 2002: Q71 (printed B Q12(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203519/GATE2002.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** P[j,k] = min(P[j,k], P[j,i] + P[i,k])

**Essential problem context (paraphrased):** Complete a template computing all-pairs shortest-path lengths in a directed graph G. Its n×n adjacency matrix A has A[i,j]=1 for an edge i→j and 0 otherwise. Initialization loops over i=1..n and j=1..n and executes:
if A[i,j]=0 then P[i,j]=____ else P[i,j]=____;
The algorithm then has nested loops, in this exact order: for i=1..n, for j=1..n, for k=1..n, executing:
P[____,____] = min{____,____};
Copy and complete the line in the algorithm’s triple loop so that the algorithm is correct.

## Solution

1. Respect the printed loop order: i is outermost, j is next, and k is innermost. In Floyd–Warshall the outer loop must identify the newly allowed intermediate vertex. Therefore i is that intermediate, j is the source, and k the destination.

2. State the invariant. Before outer iteration i, P[j,k] is the shortest distance from j to k using only vertices 1,…,i−1 as internal vertices. Initialization supplies paths with no internal vertices: 0 on the diagonal, 1 for a direct edge, and ∞ otherwise.

3. Split paths into two exhaustive cases. A shortest path allowed after iteration i either avoids i internally, in which case its best length is the old P[j,k], or passes through i, in which case it can be split into a j→i portion and an i→k portion. Their best combined length is P[j,i]+P[i,k]. Nonnegative unit weights let us choose a shortest path without repeated positive-length cycles.

4. Take the better candidate and fill the line as:

```text
P[j,k] = min(P[j,k], P[j,i] + P[i,k]);
```

For example, if the current j→k value is ∞ while P[j,i]=2 and P[i,k]=3, the update discovers a path of length 5. If P[j,k] were already 4, the minimum would retain 4.

5. Verify in-place and final correctness. During iteration i, the zero diagonal means an update through i does not lower the distances into or out of i; the in-place recurrence therefore preserves the invariant. After i=n, all vertices are allowed internally, so the table gives every shortest-path distance. Interpret ∞+x as ∞, or guard finite arithmetic against overflow.

6. Avoid a loop-order substitution error. The familiar form P[i,j]=min(P[i,j],P[i,k]+P[k,j]) assumes k is outermost. Under the source’s i,j,k loop order, using that form would generally be incorrect. Exhaustive comparison with BFS on every directed three-vertex graph, including self-loops, verifies the completed initialization and the stated j,k update.

# GATE 2002: Q72 (printed B Q12(c))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203519/GATE2002.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Official answer:** Not available; no official key located.

**Independently derived answer:** O(n³), more precisely Θ(n³)

**Essential problem context (paraphrased):** Complete a template computing all-pairs shortest-path lengths in a directed graph G. Its n×n adjacency matrix A has A[i,j]=1 for an edge i→j and 0 otherwise. Initialization loops over i=1..n and j=1..n and executes:
if A[i,j]=0 then P[i,j]=____ else P[i,j]=____;
The algorithm then has nested loops, in this exact order: for i=1..n, for j=1..n, for k=1..n, executing:
P[____,____] = min{____,____};
Complete the running-time expression O(____).

## Solution

1. Count initialization work. There are n choices for the first index and n for the second, so initializing P visits n² entries. Each requires only a constant-time case selection and assignment, giving Θ(n²).

2. Count the algorithm’s updates. The source has three nested loops, over i, j, and k, each running from 1 to n. There is no data-dependent early termination. Thus the innermost statement executes n×n×n = n³ times.

3. Count work per update. Reading two candidate distances, adding, comparing with the old entry, and writing the minimum take constant time under the usual RAM model with constant-time distance arithmetic. Therefore the update phase costs Θ(n³).

4. Combine the phases. Θ(n²)+Θ(n³)=Θ(n³), since the cubic term dominates as n grows. The requested big-O blank is n³, so the answer is O(n³); the tighter bound is Θ(n³).

5. Keep time and space distinct. The distance table contains n² entries and uses Θ(n²) space. Its space requirement does not reduce the cubic number of updates, and an adjacency-matrix input does not make this particular triple-loop implementation linear in the number of edges.
