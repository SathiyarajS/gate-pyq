**Paraphrased problem context:** An array algorithm initializes L[n-1]=1 and for 0≤i≤n-2 defines L[i]=1+L[i+1] when A[i]<A[i+1], otherwise L[i]=1. It returns max(L[0],...,L[n-1]). The source calls this the longest monotonically increasing sequence. Which statement is TRUE?

(A) It uses dynamic programming
(B) It has linear complexity and uses branch and bound
(C) It has nonlinear polynomial complexity and uses branch and bound
(D) It uses divide and conquer

## Solution

Compute the displayed L_i from right to left, reusing the already-computed L_(i+1). This is a dynamic program with linear time and the maximum L_i as output, so A. Its recurrence computes strictly increasing contiguous runs; it is not the general longest increasing subsequence algorithm when skipped elements are permitted. A suitable evaluation order is needed even though the source writes the index range without an order.

For the recurrence to run, process i=n-2,n-3,...,0. If adjacent entries increase, the run beginning at i is the current element followed by the already-solved run at i+1; otherwise it ends immediately. Each table entry takes constant work, and the final maximum takes linear work. For A=[1,3,2,4], every increasing contiguous run has length 2, although the noncontiguous subsequence [1,2,4] has length 3. This illustrates the important limitation of the displayed recurrence.

**Paraphrased problem context:** Order these functions by increasing asymptotic growth: f1(n)=2^n; f2(n)=n^(3/2); f3(n)=n log2 n; f4(n)=n^(log2 n).

(A) f3,f2,f4,f1
(B) f3,f2,f1,f4
(C) f2,f3,f1,f4
(D) f2,f3,f4,f1

## Solution

n log n grows slower than n^(3/2). The function n^(log2 n)=2^((log2 n)²) eventually exceeds every fixed power of n, but is smaller than 2^n since(log2 n)²=o(n). Hence f3<f2<f4<f1 asymptotically, A.

Pairwise ratios justify the ordering beyond a few sample values. f3/f2=(log2 n)/√n tends to zero. Taking logarithms, log2(f4/f2)=(log2 n)²-(3/2)log2 n tends to infinity. Finally log2(f4/f1)=(log2 n)²-n tends to minus infinity. Thus the quasipolynomial sits above every fixed-degree polynomial but below the exponential. Finite small-n ties or reversals do not affect an asymptotic comparison.

**Paraphrased problem context:** Four matrices M1,M2,M3,M4 have dimensions 10×100,100×20,20×5,5×80. Multiplication of an a×b matrix by a b×c matrix costs abc scalar multiplications. What is the minimum total for their ordered product over all parenthesizations?

(A) 248000
(B) 44000
(C) 19000
(D) 25000

## Solution

For dimensions 10, 100, 20, 5, 80, the five full parenthesizations have costs 25000 for(((AB)C)D), 19000 for((A(BC))D), 44000 for((AB)(CD)), 130000 for(A((BC)D)) and 248000 for(A(B(CD))). The minimum is 19000, attained by BC costing 100×20×5=10000, then A(BC) costing 10×100×5=5000, then the final product costing 10×5×80=4000. Thus C.

Label the matrices A,B,C,D. Dimensions of intermediate results matter: BC is 100×5, A(BC) is 10×5, and the final product is 10×80. Multiplying the dimensions of each operation yields the stated 10000+5000+4000 optimum. Checking all five full binary parenthesizations proves that this is a global minimum, not merely a good greedy choice. For example, doing AB first already costs 20000 before the remaining work, exceeding the optimum by itself.

**Paraphrased problem context:** An undirected graph has vertices v1,...,vn for n>2. Vertices vi and vj are adjacent exactly when 0<abs(i-j)≤2, and that edge has weight i+j. (For n=4 the edges are 12:3,13:4,23:5,24:6,34:7.) What is its minimum spanning-tree weight?

(A) (11n²-5n)/12
(B) n²-n+1
(C) 6n-11
(D) 2n+1

## Solution

For each vertex v_i with i≥3, its lightest incident edge is (v_(i−2), v_i), with weight 2i−2. The edge (v_1, v_2), of weight 3, is likewise the unique lightest edge incident to v_1 and to v_2. By the cut property all these edges must belong to an MST. They form two parity chains joined by (v_1, v_2), so they are connected and contain exactly n−1 edges, hence already form a spanning tree. Its weight is 3+sum from i=3 to n of (2i−2)=3+2[(n−1)n/2−1]=n²−n+1, option B.

For vertex vi with i≥3, possible smaller neighbors are v(i-2) and v(i-1), of weights 2i-2 and 2i-1; larger neighbors have still greater weights. Thus its distance-two backward edge uniquely minimizes the cut separating vi from all other vertices. The cut property forces every such edge, and also v1-v2. The odd-index chain and even-index chain are internally connected and joined by that last edge, showing the forced edges are sufficient, not merely a lower bound on the optimum.

**Paraphrased problem context:** An undirected graph has vertices v1,...,vn, edges precisely when 0<abs(i-j)≤2, and edge weight i+j. For n=10, what is the weighted length of the path from v5 to v6 in the minimum spanning tree of this graph?

(A) 11
(B) 25
(C) 31
(D) 41

## Solution

The MST consists of (v_1, v_2) and (v_(i−2), v_i) for i=3,..., 10. Its unique path from v_5 to v_6 is v_5→v_3→v_1→v_2→v_4→v_6. The edge weights are 8, 4, 3, 6 and 10, respectively, so its weighted length is 8+4+3+6+10=31, option C. The direct graph edge (v_5, v_6) has weight 11 but is not in the MST.

Write the two chains explicitly for n=10: odd vertices 1-3-5-7-9 and even vertices 2-4-6-8-10, joined by 1-2. Any route inside this tree from an odd to an even vertex must pass through that bridge. The requested route therefore goes downward in the odd chain to 1, crosses to 2, and climbs the even chain to 6. 'Length' here is total edge weight, not the number of edges; the path uses five edges but has weight 31.
