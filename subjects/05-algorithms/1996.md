

# GATE 1996: Q11 (printed A Q1.11)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Essential problem context (paraphrased):** Which asymptotic claim is false: (A) 100n log n=O(n log n/100); (B) sqrt(log n)=O(log log n); (C) for fixed 0<x<y, n^x=O(n^y); (D) 2^n is not O(n^k) for fixed k?

## Solution

Put t=log n. Then sqrt(log n)/(log log n)=sqrt(t)/log t tends to infinity, so no constant bounds the numerator by a multiple of the denominator eventually. Hence B is false. Multiplying n log n by fixed nonzero constants does not change its big-O class. For fixed x<y, n^x/n^y=n^(x−y) tends to zero. Finally 2^n eventually dominates every fixed-degree polynomial n^k: the logarithm of their ratio is n log 2−k log n, which tends to infinity. Thus D is true, not the false statement sought.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A: Θ(n)

**Essential problem context (paraphrased):** Solve T(1)=2, T(n)=3T(n/4)+n asymptotically for powers of four.

## Solution

At recursion depth j there are 3^j subproblems of size n/4^j, so the total nonrecursive work is n(3/4)^j. Summing these decreasing geometric terms gives O(n), while the root alone costs n and proves Ω(n). More exactly, with k=log₄ n, the leaves contribute 2·3^k and internal levels contribute 4n(1−(3/4)^k). The total is 4n−2n^(log₄3). Therefore the recurrence is linear, not n log n, because each successive level contributes less work than the preceding one.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D: (n+1)/2

**Essential problem context (paraphrased):** A sought item is equally likely to occupy any of n positions in a sequentially searched list. Find the expected comparisons for a successful search.

## Solution

If the item occupies position i, searching from the beginning requires i comparisons. Uniform success positions therefore give E[C]=(1+2+…+n)/n. The arithmetic-series sum is n(n+1)/2, so E[C]=(n+1)/2. This is not the unsuccessful-search cost n, because successful searches stop at their target. Nor is it a binary-search logarithm, since the stated algorithm scans sequentially rather than repeatedly halving a sorted range.

**Independently derived answer:** D in general; C for standard end-pivot worst-case counting

**Essential problem context (paraphrased):** Compare quicksort comparisons for a list already ascending versus descending when no pivot or partition implementation is specified.

## Solution

With the first or last element chosen as pivot on every subarray, either monotone input can split into sizes 0 and n−1. Counting n−1 comparisons per partition gives n(n−1)/2 for both orientations, the usual equality answer C under that model. But the question does not specify pivot selection or partition code. A rule depending on input orientation can select balanced pivots in one case and extreme pivots in the other; even comparison-count conventions vary. Therefore no implementation-independent ordering follows, corresponding to D. The common equal-count result is conditional, not a universal theorem about every quicksort variant.

**Official answer:** Not available; no official key located.

**Independently derived answer:** Path 0—1—2—…—(n−1), total weight n−1.

**Essential problem context (paraphrased):** A complete undirected graph on vertices 0,1,…,n−1 has weight w(u,v)=|u−v| for distinct vertices. Draw a minimum spanning tree.

## Solution

Every edge joins distinct integers, so its weight is at least 1. A spanning tree on n vertices contains exactly n−1 edges. Consequently every spanning tree has total weight at least n−1.

Connect consecutive vertices: (0,1),(1,2),…,(n−2,n−1). This is a connected path with no cycles, so it is a spanning tree. Each of its n−1 edges has weight 1, giving total n−1 and attaining the lower bound. Text diagram: 0 --1-- 1 --1-- 2 --1-- … --1-- (n−1), where the labels between dashes are edge weights.

For n≥2 it is also the unique MST. Achieving the lower bound requires every selected edge to have weight 1, and the only weight-1 edges in this graph are exactly the consecutive pairs. There are n−1 of them, so all must be selected. Alternatively, for the cut {0,…,k}|{k+1,…,n−1}, edge (k,k+1) is the unique minimum crossing edge and is mandatory by the cut property. When n=1 the empty tree has cost0; the same n−1 formula applies.

**Official answer:** Not available; no official key located.

**Independently derived answer:** Star centered at0, edges (0,v) for1≤v<n; total n(n−1)/2.

**Essential problem context (paraphrased):** A complete undirected graph on vertices 0,1,…,n−1 has weight w(u,v)=u+v for distinct vertices. Draw a minimum spanning tree.

## Solution

For each vertex v>0, consider the cut separating v from every other vertex. Its incident edges have weights v+u, with u≠v. The smallest possible u is0, so (v,0) is the unique minimum-weight edge across this cut. By the cut property every MST must contain it.

Doing this for every v=1,…,n−1 gives exactly the star centered at0. These n−1 edges connect all vertices and have no cycle, so the mandatory set itself is a spanning tree. Its weight is Σ_(v=1)^(n−1) v=n(n−1)/2. Text diagram: center0 with a spoke to each v; spoke (0,v) has label v.

A second lower-bound proof roots any spanning tree at0. Each nonroot vertex v has one parent p(v)≥0, so its parent edge costs v+p(v)≥v. Summing over all nonroot vertices gives total at least Σv. The star attains equality by taking every parent to be0. This argument also shows uniqueness for n≥2: equality requires all parents0. For n=1 there are no spokes and the minimum weight is0. The complete graph assumption guarantees that every required spoke exists.
