

# GATE 2026 CS1: Q17

**Status:** Partial coverage. Independently derived and published official-key matched; independent second derivation review passed; final-key revision check pending.

**Question summary (paraphrased):** Find the growth of T1 given T1(n)=4T1(n/2)+T2(n), T2(n)=5T2(n/4)+Theta(log_2 n), with both equal to 1 for n<=1.

**Type / marks:** MCQ, 1 mark.

**Official answer:** A

## Solution

Set alpha = log_4(5), approximately 1.161. In the recurrence for T2, the logarithmic additive term is polynomially smaller than n^alpha. Master theorem case 1 gives T2(n) = Theta(n^alpha).

For T1, the branching threshold is n^(log_2 4) = n^2. Since alpha < 2, its additive term T2(n) is polynomially smaller than n^2. Applying case 1 again gives T1(n) = Theta(n^2).

A recursion-tree check reaches the same answer: level j contributes Theta(n^alpha (4/2^alpha)^j). Since 4/2^alpha > 1, the sum is dominated by the deepest levels, whose scale is n^2.

**Common pitfall:** A logarithmic factor appears in Master theorem case 2, when the additive term matches the branching threshold. It does not match here.

# GATE 2026 CS1: Q41

**Question:** [Official paper page 30](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=30); refer to the original wording and options.

**Type / marks:** MCQ, 2 marks.

**Official answer:** A

## Solution

Increasing the permitted edge budget enlarges the set over which the minimum is taken. Therefore the minimum cannot increase, including the case where a former infinity becomes finite; S1 is true. S2 need not hold for a fixed smaller edge budget. As a counterexample, use undirected edges s-a, a-u, u-v of weight 1 each and s-v of weight 10. The unique shortest s-to-v path is s-a-u-v and includes (u,v). At budget k=1, u is unreachable from s, so d_1(u)=infinity, while d_1(v)=10. The claimed inequality fails. Thus only S1 holds, giving A. This positive-weight example avoids any complications about negative-weight cycles.

# GATE 2026 CS1: Q49

**Question:** [Official paper page 37](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=37); refer to the original wording and options.

**Type / marks:** MSQ, 2 marks.

**Official answer:** A;D

## Solution

A is the strict cycle property: if an MST included the uniquely heaviest edge of a cycle, deleting that edge separates the tree; another cycle edge crosses the resulting cut and is lighter, yielding a lower-weight spanning tree. D is the strict cut property for the cut containing one vertex: its unique lightest incident edge must occur in every MST. B is not a cycle property. For a concrete connected counterexample, take edges ad=1, bd=2, ab=3, bc=4, ac=5. The smallest edge of cycle a-b-c-a is ab=3, but it is excluded from the MST {ad,bd,bc}, because a-d-b already connects its endpoints more cheaply. C fails on any tree with distinct edge weights: every edge is in the only spanning tree, including the heaviest incident edge at each vertex. Thus select A and D. The statement tacitly needs a connected graph for an MST to exist; for disconnected inputs these arguments apply to a minimum spanning forest componentwise.

# GATE 2026 CS1: Q50

**Question:** [Official paper page 38](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=38); refer to the original wording and options.

**Type / marks:** MSQ, 2 marks.

**Official answer:** B;D

## Solution

DFS discovery-to-finish intervals for two distinct vertices are either nested or disjoint. They never partially overlap, so D is impossible for any DFS, not just on DAGs. In B, v is an ancestor of u when the edge u-to-v is examined. The DFS-tree path from v to u followed by this edge makes a directed cycle, contradicting that the input is a DAG. Thus B is also impossible. A occurs on a tree edge from u to a newly discovered v; v finishes before its recursive caller u. C occurs when v was fully explored before u is discovered, and a later edge goes from u to that already finished vertex. For example, process a DFS root v with no outgoing edges before root u in a graph with only edge u-to-v. Select B and D.
