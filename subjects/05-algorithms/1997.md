## Solution

Floyd–Warshall solves all-pairs paths through dynamic-programming subproblems. Quicksort partitions around a pivot and recursively sorts subarrays, a divide-and-conquer strategy. Prim or Kruskal builds an MST using safe greedy edge choices. Repeated DFS visits each connected component. Thus the four matches are 3, 4, 1, 2, option B. These refer to standard representative algorithms rather than asserting that each task has only one possible solution paradigm.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B: Θ(n)

**Essential problem context (paraphrased):** T(1)=1 and T(n)=2T(floor (n/2))+sqrt (n) for n≥2. Choose O(sqrt n), O(n), O(log n), none.

## Solution

At recursion depth j there are roughly 2^j subproblems of size n/2^j. Their combined nonrecursive work is sqrt (n)·2^(j/2), increasing geometrically toward the leaves. Summing through depth about log 2 n gives O(n), and there are Θ(n) leaves each contributing constant work, providing Ω(n). Hence T(n)=Θ(n), so B. Equivalently the Master theorem has n^(log 2 2)=n and toll n^(1/2), which is polynomially smaller; rounding does not change the asymptotic order.

# GATE 1997: Q54 (printed A Q9(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** n²−1.

**Essential problem context (paraphrased):** The vertices are the n² integer lattice points (x,y), 1≤x,y≤n, n≥2. Distinct vertices are adjacent when BOTH |x1−x2|≤1 and |y1−y2|≤1; an edge has Euclidean length sqrt((x1−x2)²+(y1−y2)²). This is the GateForum p11 adjacency, including the second-coordinate bound omitted in GFG. Find the minimum spanning-tree weight.

## Solution

There are n² vertices, so every spanning tree has exactly n²−1 edges. Distinct integer lattice points are at distance at least 1; hence every spanning tree has weight at least n²−1.

This bound is achievable without using any diagonals. In each row, connect its n vertices consecutively with n−1 horizontal unit edges. This uses n(n−1) edges and leaves n connected row paths. Connect consecutive rows by vertical unit edges along the first column, using n−1 more edges. The result is connected and has n(n−1)+(n−1)=n²−1 edges; equivalently, joining the disjoint row trees by a path cannot create a cycle. Its weight is exactly n²−1, matching the lower bound.

For n=2 this construction has three unit edges and weight 3. Using a diagonal would replace a unit edge by one of length √2 and cannot improve the minimum.

The source variant matters for the companion maximum-weight question: GFG prints only |x1−x2|≤1, permitting long changes in y. For this minimum, however, the same answer remains valid under that literal variant. All distinct vertices are still at least unit distance apart, and the unit-edge construction is still allowed. Thus this particular answer is robust even though the reproduced graph definitions differ.

# GATE 1997: Q55 (printed A Q9(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 3 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** GateForum: (n²−2)√2+1. Literal GFG: (2n−2)√(1+(n−1)²)+(n−1)+nΣ_(j=2)^(n−1)√(1+max(j−1,n−j)²).

**Essential problem context (paraphrased):** The vertices are the n² integer lattice points (x,y), 1≤x,y≤n, n≥2. Distinct vertices are adjacent when BOTH |x1−x2|≤1 and |y1−y2|≤1; an edge has Euclidean length sqrt((x1−x2)²+(y1−y2)²). This is the GateForum p11 adjacency, including the second-coordinate bound omitted in GFG. Find the maximum spanning-tree weight; also distinguish the literal GFG graph that constrains only |x1−x2|≤1.

## Solution

In the stated king-move grid, every edge is either horizontal/vertical with weight 1 or diagonal with weight √2. We therefore want as many diagonal edges as a spanning tree can contain.

Color vertex (x,y) by the parity of x+y. A diagonal changes both coordinates by one, so it preserves this parity; a horizontal or vertical edge changes it. Both parity classes are nonempty for n≥2. A connected spanning tree must consequently include at least one unit edge to join the two classes. Since it has n²−1 edges in total, its weight is at most (n²−2)√2+1.

To attain the bound, observe that the diagonal-only graph has exactly two connected components, one of each parity. Here is a constructive connectivity argument. Repeatedly use an upward diagonal to reduce y until reaching the first row; at a side boundary choose the inward direction, always possible because n≥2. On the first row, vertices of a fixed parity can move two columns at a time through a vertex of the second row. Thus all vertices of each parity are connected by diagonals. Take a spanning tree inside each diagonal component. Together they use n²−2 diagonal edges. Add any unit edge between the components. This produces a spanning tree attaining the upper bound.

For n=2 the two diagonals, joined by one side, have weight 2√2+1. That is the answer to GateForum's full adjacency rule. Under GFG's literal omission of the y-bound, longer edges are allowed when n≥3. Its maximum is instead

(2n−2)√(1+(n−1)²) + (n−1) + nΣ_(j=2)^(n−1)√(1+max(j−1,n−j)²).

Here is a separate optimality proof for that literal graph. Call vertices on y=1 or y=n boundary vertices. For each interior vertex at row j, select an edge to a farthest boundary row in an adjacent column. Such a column always exists for n≥2. Its length is √(1+max(j−1,n−j)²), a maximum edge across the cut isolating that vertex. Add these edges while each interior vertex is still isolated; all chosen parents are boundary vertices, so no cycle arises. By the maximum-spanning-tree cut property, each addition is safe.

Next add all 2n−2 boundary diagonals with |dx|=1 and |dy|=n−1. They are globally maximum edges, each of length √(1+(n−1)²), and form two disjoint alternating-row paths on the 2n boundary vertices. Interior attachments do not join those paths. Finally join them by a same-column edge from y=1 to y=n, of length n−1. Every competing cross-component edge with an interior endpoint is at most √(1+(n−2)²)<n−1 for n≥3. Remaining boundary cross-edges have length at most n−1, so this last edge is also cut-safe. At n=2 there are no interior vertices and the bridge length is 1.

The safe selections form a spanning tree and give the displayed sum: n equal-length interior attachments for each row j, 2n−2 boundary diagonals, and one bridge. Thus both materially different printed graphs have an explicit maximum and a proof, rather than silently restoring a bound in GFG.

# GATE 1997: Q71 (printed B Q15(c))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 2C(n+m,n)−1.

**Essential problem context (paraphrased):** For positive integers n,m, consider the directly recursive, nonmemoized function
function F(n,m:integer):integer;
begin
  if (n<=0) or (m<=0) then F:=1
  else F:=F(n-1,m)+F(n,m-1)
end.
Use C(s,t)=C(s−1,t)+C(s−1,t−1).
How many calls to F occur when evaluating F(n,m), including the original call?

## Solution

The execution forms a full binary recursion tree. Each nonbase call executes exactly two child calls, and each base call has no children. Every base call returns 1, while every internal call returns the sum of its two children's values. The root's return value is consequently the number L of leaf activations. From the recurrence solution, L=F(n,m)=C(n+m,n).

In a full binary tree with I internal nodes and L leaves, the number of edges is 2I because every internal node has two children. It is also I+L−1 because a tree has one fewer edge than nodes. Equating gives I=L−1, so the total number of call activations is I+L=2L−1. Therefore the requested count, including the root call, is

2C(n+m,n)−1.

For n=m=1, the root calls F(0,1) and F(1,0), giving three activations; the formula gives 2·2−1=3. For n=1,m=2 it gives five. If only calls initiated recursively were requested, one would subtract the original root and obtain 2C(n+m,n)−2, but that is not the wording here.

This counts the actual nonmemoized execution tree, including repeated argument pairs as separate calls. Counting only distinct states, or assuming a dynamic-programming implementation, would answer a different complexity question.

# GATE 1997: Q74 (printed B Q17)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B3=A[1]; B6=sum<M; B11=sum+A[j].

**Essential problem context (paraphrased):** An array A[1..n], n≥1, contains positive integers, and M>0. Complete the boxes in this program so it prints the shortest nonempty contiguous-subarray length having sum at least M, or n+1 if none exists. The program uses one-based array indexing:
1 begin
2   i:=1; j:=1;
3   sum:=[B3];
4   min:=n; finish:=false;
5   while not finish do
6     if [B6] then
7       if j=n then finish:=true
8       else
9         begin
10          j:=j+1;
11          sum:=[B11]
12        end
13    else
14      begin
15        if (j-i)<min then min:=j-i;
16        sum:=sum-A[i];
17        i:=i+1
18      end;
19  writeln(min+1)
20 end

## Solution

Fill line 3 with A[1], line 6 with sum<M, and line 11 with sum+A[j]. The invariant is that sum equals A[i]+…+A[j], with value zero if the current window is empty (i=j+1).

Initially i=j=1, so sum must be A[1]. If sum<M, the current window is too small. Removing positive elements cannot help it reach M, so extend the right endpoint. Line 10 has already incremented j, which is why line 11 adds A[j], not A[j+1]. If j=n, there is no further element to add and the loop can terminate.

If sum≥M, the current window is feasible. Its actual length is j−i+1, but min deliberately stores length minus one, so line 15 compares j−i. Remove A[i] and advance i to look for a shorter feasible window with the same right endpoint. Repeated shrinking examines the best ending-at-j choice before extending again. Positivity ensures that once a left endpoint is discarded, retaining it for later right endpoints cannot improve on a feasible length already considered.

For A=[2,3,1,2] and M=5, the first feasible window is [2,3], length 2. It stores min=1. After shrinking and extending, [3,1,2] is feasible but longer. The final print is 2. If no window reaches M, min stays n and the sentinel print is n+1. If one element alone reaches M, min becomes 0 and the answer is 1; removing that element creates a temporary empty window of sum zero, which safely forces extension or termination because M>0.

Both i and j only increase, giving O(n) time and O(1) auxiliary space. Negative array elements would invalidate the monotonic shrinking argument. The strict comparison at line 6 is essential: equality sum=M already satisfies the requested threshold.
