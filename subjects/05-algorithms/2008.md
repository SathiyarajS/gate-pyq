**Paraphrased problem context:** What is the most efficient time complexity to count connected components in an undirected graph with n vertices and m edges?

(A) Θ(n)
(B) Θ(m)
(C) Θ(m+n)
(D) Θ(mn)

## Solution

1. Maintain a visited flag for each vertex. Start a BFS/DFS at every vertex not yet visited and increment a component counter.
2. Each search visits precisely one previously unvisited component. Across all searches each vertex is processed once and each undirected edge twice.
3. With adjacency lists the total is Θ(n+m), C. The n term includes isolated vertices; an adjacency-matrix representation instead requires Θ(n²).

**Paraphrased problem context:** An undirected graph has vertices M,N,O,P,Q,R and edges MN,NO,OP,PQ,QM,QN,MR. Which is a possible queue-based breadth-first traversal?

(A) MNOPQR
(B) NQMPOR
(C) QMNPRO
(D) QMNPOR

## Solution

1. BFS uses a FIFO queue, so all newly discovered neighbors enter behind previously queued vertices. Start at Q and discover M,N,P in that order.
2. Processing M next discovers R. Processing N then discovers O. Processing P adds nothing because O is already discovered.
3. The dequeue/visit order is Q,M,N,P,R,O, C. D puts O before R despite the specified first-layer order; the other offered orders violate BFS layers.

**Paraphrased problem context:** Let f(n)=2^n, g(n)=n!, h(n)=n^(log n). Which asymptotic statement is true?

(A) f=O(g); g=O(h)
(B) f=Ω(g); g=O(h)
(C) g=O(f); h=O(f)
(D) h=O(f); g=Ω(f)

## Solution

1. Compare logarithms, which preserve growth order for positive functions. log h=(log n)² up to base constants; log f=Θ(n). Since (log n)²=o(n), h grows slower than f.
2. Stirling gives log(n!)=n log n−n+O(log n), which grows faster than n. Thus f grows slower than g.
3. Therefore h=O(f) and g=Ω(f), D.

**Paraphrased problem context:** What is the minimum worst-case number of comparisons needed to determine whether some integer appears more than n/2 times in a sorted array of n integers?

(A) Θ(n)
(B) Θ(log n)
(C) Θ(log* n)
(D) Θ(1)

## Solution

1. If a value occurs more than n/2 times, it must occupy the middle array position. Take that value as candidate and use binary searches for its first and last occurrences; accept exactly when the count exceeds n/2.
2. This needs Θ(log n) comparisons in the worst case. A logarithmic lower bound follows by locating a candidate-block boundary among linearly many possible positions while distinguishing length floor(n/2) from floor(n/2)+1.
3. Sortedness is essential; without it a linear majority scan is needed. Thus B.

**Paraphrased problem context:** A quicksort pivot procedure splits the list into two sublists each containing at least n/5 elements. If T(n) counts sorting comparisons, which offered upper recurrence follows?

(A) T(n)≤2T(n/5)+n
(B) T(n)≤T(n/5)+T(4n/5)+n
(C) T(n)≤2T(4n/5)+n
(D) T(n)≤2T(n/2)+n

## Solution

1. Each recursive subproblem has size at most 4n/5, because each side has at least n/5 elements. With the usual monotone worst-case upper-bound interpretation of T and linear partitioning cost, both recursive costs are bounded individually by T(4n/5), so T(n)≤2T(4n/5)+n, option C.
2. This loose recurrence follows immediately from the given size bounds. The tempting expression T(n/5)+T(4n/5)+n assumes that the most unequal permitted split maximizes the sum of recursive costs; monotonicity alone does not establish that.
3. More precisely the general recurrence is T(n)≤max_{n/5≤k≤4n/5}{T(k)+T(n−k)}+O(n), ignoring pivot/rounding constants. The standard comparison model includes linear partition/pivot overhead; the statement does not specify the cost of an arbitrary extra pivot-selection procedure.

**Paraphrased problem context:** Subset sum asks whether a subset of n positive integers sums to a positive integer W. Algorithm Q takes O(nW) time. Which statement is false?

(A) Q is polynomial-time for unary input encoding
(B) Q is polynomial-time for binary input encoding
(C) Subset sum belongs to NP
(D) Subset sum is NP-hard

## Solution

1. B is false. The dynamic program takes O(nW), polynomial in the numerical value W, not in its binary encoding length Θ(log W).
2. For binary input W can be exponential in the input length, so this is a pseudo-polynomial algorithm. With unary encoding the input has length at least W and at least n, hence nW is polynomial in that length.
3. A subset is a polynomial-size certificate whose sum can be checked in polynomial time, so subset sum is in NP; its standard decision form is NP-complete and therefore NP-hard. Thus A, C and D are true.

**Paraphrased problem context:** Run Dijkstra from a in this directed weighted graph: a→b:1, b→c:2, c→d:3, d→a:2, b→e:−3, c→h:−5, d→g:2, h→e:1, g→h:2, g→e:1, e→f:2, f→g:3. To which vertices does it compute correct shortest-path distances?

(A) Only a
(B) Only a,e,f,g,h
(C) Only a,b,c,d
(D) All vertices

3. They also satisfy every edge relaxation inequality, with each value attained by a path, proving optimality. Negative edges invalidate Dijkstra’s general guarantee, but do not force failure on every particular input.

**Paraphrased problem context:** Consider these C functions, assuming valid array bounds and the intended unit-cost arithmetic model:
int f1(int n) {
 if(n==0 || n==1) return n;
 else return 2*f1(n-1)+3*f1(n-2);
}
int f2(int n) {
 int i; int X[N],Y[N],Z[N];
 X[0]=Y[0]=Z[0]=0;
 X[1]=1; Y[1]=2; Z[1]=3;
 for(i=2;i<=n;i++) {
  X[i]=Y[i-1]+Z[i-2];
  Y[i]=2*X[i]; Z[i]=3*X[i];
 }
 return X[n];
}
What are the running times of f1(n) and f2(n), respectively?

(A) Θ(n),Θ(n)
(B) Θ(2^n),Θ(n)
(C) Θ(n),Θ(2^n)
(D) Θ(2^n),Θ(2^n)

## Solution

1. The recursive function makes one call on n−1 and one on n−2; coefficients 2 and 3 multiply the returned values and do not multiply the number of calls. Thus T(n)=T(n−1)+T(n−2)+Θ(1), giving Θ(φ^n), where φ=(1+√5)/2.
2. The iterative f2 executes n−1 constant-time iterations, Θ(n). None of the printed options gives Θ(φ^n),Θ(n).
3. Option B prints Θ(2^n),Θ(n), which supplies an exponential upper bound but falsely labels it tight Θ. This analysis assumes unit-cost bounded-size arithmetic and n within valid array bounds; unbounded n in actual C would also encounter overflow.

**Paraphrased problem context:** Given positive integers S={a₁,…,aₙ} and target W>0, a subset-sum dynamic program uses Boolean X with n rows and W+1 columns. X[i,j] is true iff some subset of {a₁,…,aᵢ} sums to j, for 1≤i≤n and 0≤j≤W. Which recurrence is valid for 2≤i≤n and aᵢ≤j≤W?

(A) X[i,j]=X[i−1,j]∨X[i,j−aᵢ]
(B) X[i,j]=X[i−1,j]∨X[i−1,j−aᵢ]
(C) X[i,j]=X[i−1,j]∧X[i,j−aᵢ]
(D) X[i,j]=X[i−1,j]∧X[i−1,j−aᵢ]

## Solution

1. Consider whether the chosen subset contains aᵢ. If not, the first i−1 elements alone must sum to j, represented by X[i−1,j].
2. If aᵢ is included, remove it once; the remaining subset of the first i−1 elements must sum to j−aᵢ, represented by X[i−1,j−aᵢ].
3. Either alternative suffices, so combine with OR, giving B. Using row i in the second term allows repeated copies of aᵢ; AND incorrectly requires both choices.

**Paraphrased problem context:** Given positive integers S={a₁,…,aₙ} and target W>0, a subset-sum dynamic program uses Boolean X with n rows and W+1 columns. X[i,j] is true iff some subset of {a₁,…,aᵢ} sums to j, for 1≤i≤n and 0≤j≤W. Which entry, if TRUE, implies there is a subset summing to W? (This preserves the printed one-way wording.)

(A) X[1,W]
(B) X[n,0]
(C) X[n,W]
(D) X[n−1,n]

## Solution

1. By the definition of X, X[n,W] is true if and only if a subset of all n inputs sums to W. Therefore C is the terminal decision cell intended by the algorithm.
2. However, the printed wording asks only which TRUE entry implies the existence of a subset summing to W. X[1,W] being true also implies that fact, since {a1} is contained in the full set.
3. B is always true via the empty subset and D concerns sum n rather than W. Thus A and C both satisfy the literal one-way implication; C alone is necessary and sufficient for the full problem.
