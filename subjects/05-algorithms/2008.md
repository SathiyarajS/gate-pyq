

# GATE 2008: Q7 (printed CS Q7)

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Run DFS or BFS from each still-unvisited vertex. With adjacency lists, each vertex and edge is examined only a constant number of times, giving Θ(n+m), C, in the standard graph-input model. Isolated vertices must also be counted; an adjacency matrix instead costs Θ(n²).

## Solution

Taking logarithms, log(n^(log n))=Θ((log n)²), log(2^n)=Θ(n), and log(n!)=Θ(n log n) by Stirling’s formula. Hence h grows slower than f, which grows slower than g. Therefore h=O(f) and g=Ω(f), D.

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 7. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

If a value occurs more than n/2 times, it must occupy the middle array position. Take that value as candidate and use binary searches for its first and last occurrences; accept exactly when the count exceeds n/2. This needs Θ(log n) comparisons in the worst case. A logarithmic lower bound follows by locating a candidate-block boundary among linearly many possible positions while distinguishing length floor(n/2) from floor(n/2)+1. Sortedness is essential; without it a linear majority scan is needed. Thus B.

# GATE 2008: Q43 (printed CS Q43)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 7. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Each recursive subproblem has size at most 4n/5, because each side has at least n/5 elements. With the usual monotone worst-case upper-bound interpretation of T and linear partitioning cost, both recursive costs are bounded individually by T(4n/5), so T(n)≤2T(4n/5)+n, option C. This loose recurrence follows immediately from the given size bounds. The tempting expression T(n/5)+T(4n/5)+n assumes that the most unequal permitted split maximizes the sum of recursive costs; monotonicity alone does not establish that. More precisely the general recurrence is T(n)≤max_{n/5≤k≤4n/5}{T(k)+T(n−k)}+O(n), ignoring pivot/rounding constants. The standard comparison model includes linear partition/pivot overhead; the statement does not specify the cost of an arbitrary extra pivot-selection procedure.

# GATE 2008: Q44 (printed CS Q44)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 8. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

B is false. The dynamic program takes O(nW), polynomial in the numerical value W, not in its binary encoding length Θ(log W). For binary input W can be exponential in the input length, so this is a pseudo-polynomial algorithm. With unary encoding the input has length at least W and at least n, hence nW is polynomial in that length. A subset is a polynomial-size certificate whose sum can be checked in polynomial time, so subset sum is in NP; its standard decision form is NP-complete and therefore NP-hard. Thus A, C and D are true.

# GATE 2008: Q45 (printed CS Q45)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 8. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

All vertices receive the correct distance despite the negative edges. From a, settle b at 1, which sets c=3 and e=−2. Settle e at −2, then f at 0, setting g=3. Vertices c and g tie at 3. Whichever is handled first, c sets h=3−5=−2 before h is settled (if g was handled first it only proposes h=5). Vertex h proposes e=−1, not an improvement over −2. Vertex d gets 6 from c and offers no improvement to a or g. Final distances (a,b,c,d,e,f,g,h)=(0,1,3,6,−2,0,3,−2). They also satisfy every edge relaxation inequality, with each value attained by a path, proving optimality. Negative edges invalidate Dijkstra’s general guarantee, but do not force failure on every particular input.

# GATE 2008: Q74 (printed CS Q74)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 16. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** No exact option; B is the apparent intended choice

## Solution

The recursive function makes one call on n−1 and one on n−2; coefficients 2 and 3 multiply the returned values and do not multiply the number of calls. Thus T(n)=T(n−1)+T(n−2)+Θ(1), giving Θ(φ^n), where φ=(1+√5)/2. The iterative f2 executes n−1 constant-time iterations, Θ(n). None of the printed options gives Θ(φ^n),Θ(n). Option B prints Θ(2^n),Θ(n), which supplies an exponential upper bound but falsely labels it tight Θ. This analysis assumes unit-cost bounded-size arithmetic and n within valid array bounds; unbounded n in actual C would also encounter overflow.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

A subset of the first i elements summing to j either excludes ai, giving X[i−1,j], or includes it once, leaving a subset of the first i−1 elements summing to j−ai. Hence X[i,j]=X[i−1,j] OR X[i−1,j−ai], option B. Using row i in the second term would permit repeated use of ai; AND would wrongly require both alternatives.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C intended; A also satisfies the literal implication

## Solution

By the definition of X, X[n,W] is true if and only if a subset of all n inputs sums to W. Therefore C is the terminal decision cell intended by the algorithm. However, the printed wording asks only which TRUE entry implies the existence of a subset summing to W. X[1,W] being true also implies that fact, since {a1} is contained in the full set. B is always true via the empty subset and D concerns sum n rather than W. Thus A and C both satisfy the literal one-way implication; C alone is necessary and sufficient for the full problem.
