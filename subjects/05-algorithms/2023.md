**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** An adversary chooses k keys for m hash slots, k>m, to maximize collisions. Which strategy best counters a malicious fixed key set: A division with a fixed modulus; B multiplication with a fixed constant; C universal hashing; D choose division or multiplication based on whether k is prime?

## Solution

Universal hashing chooses a hash function randomly from a family with a bounded collision probability for distinct fixed keys, preventing an adversary from exploiting one known deterministic mapping. Division and multiplication with fixed constants can be targeted. Thus C under the standard model in which the selected random function is hidden or chosen independently of the adversary’s key set; unrestricted adaptive knowledge would require additional assumptions.

Teaching detail. For a universal family H, each distinct fixed pair x,y has collision probability at most 1/m when h is selected randomly from H. With chaining, the expected number of other keys colliding with a particular key is consequently bounded by (k−1)/m by linearity of expectation. Since k>m, some collisions are unavoidable by the pigeonhole principle: the goal is controlling concentrated collisions, not eliminating them. Random selection must be independent of the malicious fixed keys for this standard guarantee to apply.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A, C

**Derived answer:** A;C

**Paraphrased problem context:** For f(n)=n and g(n)=n², select true claims: A f∈O(g); B f∈Ω(g); C f∈o(g); D f∈Θ(g).

## Solution

f(n)/g(n)=n/n²=1/n tends to 0. Hence f=o(g), which also implies f=O(g). A positive constant lower bound proportional to n² cannot hold for all large n, so f is neither Ω(g) nor Θ(g). Answer A, C.

Teaching detail. The asymptotic definitions distinguish an upper bound from a tight bound. For n≥1, n≤n², so O(g) holds with constant 1. Little-o requires that for every ε>0, n≤εn² for all sufficiently large n; choosing n≥1/ε establishes it. An Ω(n²) lower bound would require 1/n≥c for some fixed c>0 eventually, which is impossible. Since Θ requires both O and Ω, it fails as well. A vanishing ratio is stronger evidence than a few sample comparisons.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A, D

**Derived answer:** A, D

**Paraphrased problem context:** Function 1 repeats while n>1: increment x exactly n times, then set n=floor(n/2). Function 2 increments x exactly 100n times. Let their increment counts be f1(n),f2(n) for the original n. Select true claims: A f1∈Θ(f2); B f1∈o(f2); C f1∈ω(f2); D f1∈O(n).

## Solution

For integer n at least 2, the first function executes at least n increments and fewer than n+n/2+n/4+...=2n increments. Therefore f1(n)=Theta(n). The second executes exactly 100n increments, also Theta(n). Their ratio stays bounded above and below by positive constants, so A and D hold, while neither little-o nor little-omega holds. The floor in the halving assignment does not change these bounds.

Teaching detail. Do not multiply the outer-loop count Θ(log n) by the original inner-loop length n: the inner length shrinks each time. For n a power of two, the exact count is n+n/2+...+2=2n−2. For arbitrary n, flooring can only reduce the geometric upper bound and the first pass alone supplies the n lower bound for n≥2. Compared with f2=100n, the ratio lies between 1/100 and 2/100. Being a smaller constant fraction is not little-o; little-o needs the ratio to vanish.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 5040 to 5040

**Derived answer:** 5040

**Paraphrased problem context:** The vertices of a graph are all eight subsets of {1,2,3}. Distinct vertices are adjacent exactly when one set is a subset of the other. How many different BFS vertex-visit orders can start at ∅, allowing arbitrary neighbor ordering?

## Solution

The empty set is a proper subset of every nonempty subset, so it is adjacent to each of the other seven vertices. BFS discovers all seven while scanning the start vertex. Any permutation of those neighbors can be its adjacency order; all seven are already discovered before any is expanded. Thus precisely 7!=5040 visit orders are possible.

Teaching detail. BFS uses a queue and discovers every neighbor of the start before expanding any of those neighbors. Since ∅ is contained in every subset, all other vertices are at distance one. No deeper layer imposes additional order constraints. Choosing any desired permutation of the seven neighbors as the start's adjacency-list order produces exactly that traversal after the fixed initial ∅. Thus the number is 7!, not 8!; the start position is not free. Later edges cannot create new vertices because all seven are already discovered.
