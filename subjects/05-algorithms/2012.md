**Paraphrased problem context:** The recurrence relation capturing the optimal execution time of the Towers of Hanoi problem with
        n discs is
        (A) T(n) = 2T(n − 2) + 2                         (B) T(n) = 2T(n − 1) + n
        (C) T(n) = 2T(n/2) + 1                           (D) T(n) = 2T(n − 1) + 1

## Solution

To move n discs, first move the top n−1 discs to the spare peg, move the largest disc once, then move those n−1 discs onto it. These two subproblems cannot be avoided in an optimal solution. Thus T(n)=2T(n−1)+1 with T(0)=0, yielding 2^n−1 moves. Hence D.

Worked check / additional reasoning: The largest disc cannot move until all n−1 smaller discs are off it, and afterward those smaller discs must be transferred onto it. With T(1)=1, the recurrence yields T(2)=3 and T(3)=7, consistent with 2^n−1.

**Paraphrased problem context:** Let W(n) and A(n) denote respectively, the worst case and average case running time of an
        algorithm executed on an input of size n. Which of the following is ALWAYS TRUE?
        (A) A(n) = Ω(W(n))                              (B) A(n) = Θ (W(n))
        (C) A(n) = O (W(n))                              (D) A(n) = o (W(n))

## Solution

At a fixed input size, each running time is at most the maximum W(n). Taking an expectation over any input distribution preserves the inequality A(n)≤W(n). Hence A(n)=O(W(n)), C. Equality in order can occur, ruling out an always-strict little-o claim; no matching lower bound is guaranteed.

Worked check / additional reasoning: Average time depends on a distribution; worst-case time does not. If every input takes n steps then A=W=n, disproving an unconditional o bound. If a rare expensive input exists, the average can be much smaller, disproving an unconditional Θ bound.

**Paraphrased problem context:** Let G be a weighted graph with edge weights greater than one and G′ be the graph constructed by
        squaring the weights of edges in G. Let T and T′ be the minimum spanning trees of G and G′,
        respectively, with total weights t and t′. Which of the following statements is TRUE?
        (A) T′ = T with total weight t′ = t²
        (B) T′ = T with total weight t′ < t²
        (C) T′ ≠ T but total weight t′ = t²
        (D) None of the above

## Solution

Squaring positive weights preserves every pairwise edge order and equality. Consequently it preserves the set of minimum spanning trees: any chosen MST of G remains an MST of G′, although independently chosen T and T′ can differ if the MST is not unique. For a fixed spanning tree with edge weights w_i, its new weight is Σw_i², while t²=Σw_i²+2Σ_{i<j}w_iw_j. With at least two edges this gives t′<t²; with one edge there is equality. Thus B describes a consistent common choice of tree on at least three vertices, but the unqualified statement T′=T need not hold when multiple MSTs exist, and small graphs also matter. The official entry is Marks to All. These are independent qualifications, not a claimed official cancellation rationale.

Worked check / additional reasoning: For an explicit nonuniqueness example, give every edge of a triangle weight 2. Any two edges form an MST, before and after squaring. T and T′ can therefore be chosen differently even though the collection of optimal trees is unchanged.

**Paraphrased problem context:** A list of n strings, each of length n, is sorted lexicographically using mergesort. What is the worst-case running time?
(A) O(n log n) (B) O(n² log n) (C) O(n²+log n) (D) O(n²).

## Solution

Ordinary mergesort uses O(n log n) comparisons to sort n strings. A lexicographic comparison can inspect all n characters, so the standard upper bound is O(n² log n), option B. The bound is tight in the usual character-by-character implementation: strings can share a prefix of length n−O(log n) and have suitably ordered distinct suffixes, so a worst-case merge pattern performs Θ(n log n) comparisons each costing Θ(n). Treating entire strings as unit-cost keys, using LCP-aware comparison, or restricting how many distinct strings exist changes the analysis; those are extra models not specified. The official entry remains Marks to All. No official reason for awarding marks is asserted.

Worked check / additional reasoning: At each merge level O(n) string comparisons may be needed, and there are Θ(log n) levels. Multiplying by the worst-case Θ(n) character work per comparison gives Θ(n² log n) under the ordinary implementation, rather than counting comparisons as constant-time operations.

**Paraphrased problem context:** Run Dijkstra from S to T on the directed weighted graph below. Update a vertex’s path only when a strictly shorter path is found, never on an equal-distance tie. Which path is reported? The complete directed edge list (source,target,weight) is: (S,A,4), (S,B,3), (B,S,3), (S,D,7), (A,C,1), (B,D,4), (C,D,3), (C,E,1), (D,E,1), (D,F,5), (D,T,3), (E,G,2), (G,E,2), (E,T,4), (G,T,3), (T,F,5).
(A) SDT (B) SBDT (C) SACDT (D) SACET.

## Solution

After settling S, tentative distances are B=3, A=4 and D=7. Settling B offers D=3+4=7, an equal value that does not replace predecessor S. Settling A discovers C=5. Settling C discovers E=6; its edge to D offers 8 and is ignored. E is settled before D and gives T=6+4=10 with predecessor E (and G=8). D then offers T=7+3=10, which is equal and therefore cannot replace the predecessor. The path retained is S→A→C→E→T of length 10, option D. The graph’s G→E edge and T→F edge directions must not be reversed.

Worked check / additional reasoning: The decisive relaxation is E→T, performed at distance 6 before D is settled at distance 7. Both propose distance 10, but only the first establishes T’s predecessor. Thus equal shortest lengths do not imply that a later equal path replaces the already stored path.
