**Essential problem context (paraphrased):** Which technique underlies the standard all-pairs shortest-path algorithm: dynamic programming, backtracking, greedy, divide-and-conquer?

## Solution

Floyd–Warshall defines Dk (i, j) as the best path using only the first k vertices as intermediates. It either avoids k or passes through it, yielding Dk (i, j)=min (Dk−1(i, j), Dk−1(i, k)+Dk−1(k, j)). Reusing these overlapping subproblem values is dynamic programming, A. The answer refers to this standard all-pairs algorithm; other algorithms can solve restricted graph classes, so the task name alone is not a proof that every possible implementation uses the same paradigm.

**Independently derived answer:** B: 3, 1, 4, 2

**Essential problem context (paraphrased):** Match log n, n, n log n, n² to binary search, selection, merge sort, insertion sort.

## Solution

Binary search halves a sorted interval each step, giving logarithmic search time. Selection of a specified rank can be done in linear worst-case time using median-of-medians. Merge sort has logarithmically many levels with linear work per level, giving n log n. Insertion sort can shift a quadratic number of elements on reverse-sorted input. Therefore the intended mapping is 3, 1, 4, 2, B. “Selection” means order-statistic selection, not selection sort, whose worst-case comparisons are quadratic.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D for positional occurrences

**Essential problem context (paraphrased):** How many nonempty substrings of all lengths can be formed from a length-n string? Choices include n, n², 2^n, n (n+1)/2.

## Solution

A substring is determined by its starting and ending positions. For length k there are n−k+1 placements. Summing these counts from k=1 to n gives n+(n−1)+…+1=n (n+1)/2, D. This counts occurrences, even when their text is identical. If the phrase “different lengths” means counting length values alone, there are only n; if it means distinct substring contents, the answer depends on the string. The standard occurrence interpretation is explicitly used.
