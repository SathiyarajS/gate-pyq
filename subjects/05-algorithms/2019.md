# GATE 2019 CS: Q47 (printed CS Q37)

**Question:** [Official archived paper page 12](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=12); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

Linear-time selection obtains each array’s median in O(n), for n arrays totaling O(n²). Selecting the median of these n medians adds O(n). Exact medians of arbitrary unsorted inputs require linear inspection per array in the worst case, giving Θ(n²), C.

# GATE 2019 CS: Q48 (printed CS Q38)

**Question:** [Official archived paper page 12](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=12); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

Distinct edge weights guarantee a unique MST. More generally, if every cut has a unique minimum edge, take any MST T and remove an edge e: the resulting cut must have e as its unique cheapest crossing edge, or T could be improved. This forces every edge of T into every MST by the cut property, proving uniqueness. Both statements are true, C.
