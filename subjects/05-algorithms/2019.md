**Type / marks:** NAT, 1 mark(s).

**Official answer:** 0.08 to 0.08

**Derived answer:** 0.08

**Paraphrased problem context:** Quicksort is applied to 25 distinct elements, choosing the first pivot uniformly among them. Find the probability that the first partition puts the pivot in a worst possible position, rounded to two decimal places.

## Solution

Method: characterize the pivot ranks that make the two recursive subproblems maximally unequal.

1. If the pivot has sorted rank r among 25 distinct elements, partitioning leaves r−1 elements smaller and 25−r larger.
2. The worst split is 0 and 24, leaving almost the entire problem for one recursive branch. This occurs when r=1 (minimum pivot) or r=25 (maximum pivot).
3. Exactly two of the 25 possible pivots have those ranks. Uniform selection makes each pivot equally likely, so the probability is 2/25=0.08.

Result: 0.08 to two decimal places. This asks only about the first split. It is not the probability that every later recursive call also takes its worst split, nor does a bad first pivot alone prove that the whole execution has the maximum possible running time.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 29 to 29

**Derived answer:** 29

**Paraphrased problem context:** For A=[−5,−10,6,3,−1,−2,13,4,−9,−1,4,12,−3,0], find the maximum S(i,j)=sum of A[k] for k=i through j, with 0≤i≤j<14. The chosen elements must form a contiguous segment.

## Solution

Method: use Kadane's dynamic program. Let E[j] be the largest sum of any nonempty segment ending exactly at j. Such a segment either starts at j or extends the best segment ending at j−1.

1. The recurrence is E[0]=A[0]=−5 and E[j]=max(A[j],E[j−1]+A[j]). It is exhaustive because every segment ending at j has one of those two forms.
2. At indices 0 and 1, E is −5 then max(−10,−15)=−10. At index 2, starting afresh with 6 beats extending the negative prefix, so E[2]=6 and the candidate segment starts at index 2.
3. Continue through indices 3 to 7: E values are 9,8,6,19,23. Although −1 and −2 reduce the running sum, discarding the accumulated positive prefix would be worse.
4. For indices 8 to 13 the values are 14,13,17,29,26,26. The maximum across all E values is 29, achieved at j=11.
5. Recover the segment from i=2 through j=11: 6+3−1−2+13+4−9−1+4+12=29. The negative terms inside it must remain because the segment is contiguous.
6. Since every segment has some ending index j and E[j] is optimal for that ending index, taking the largest E[j] proves that no omitted segment has a greater sum.

Result: 29. The prompt permits divide and conquer but does not require it; this linear-time recurrence gives the same optimum and a direct correctness argument.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** There are n unsorted arrays, n odd, each containing n distinct elements; different arrays have no common elements. Find the worst-case complexity of computing the median of the n array medians. Choices A O(n), B O(n log n), C O(n²), D Ω(n² log n).

## Solution

1. The median of n distinct values for odd n is their order statistic of rank (n+1)/2. Finding that one rank does not require sorting every value.
2. Apply deterministic worst-case linear-time selection to each array. The median-of-medians selection algorithm, for example, finds an exact order statistic in O(n) time per array.
3. There are n arrays, so obtaining all their medians costs n×O(n)=O(n²). Store the n resulting medians in a separate array.
4. Apply linear-time selection once more to those n medians. This adds O(n), so the total remains O(n²), identifying C. The desired statistic is the median of array medians, which is not in general the median of all n² input values.
5. Sorting each original array would cost O(n² log n) and is unnecessary. Worst-case exact selection on arbitrary unsorted rows requires inspecting linearly many entries in potentially decisive rows; the general problem has quadratic worst-case scale, not O(n) or O(n log n) in the row count n. Randomized quickselect offers expected linear selection, but deterministic selection is what directly justifies the worst-case bound here.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** For a connected weighted undirected graph G, test: I distinct weights on all edges imply a unique MST; II every cut having a unique cheapest crossing edge implies a unique MST. Options A I only, B II only, C both, D neither.

## Solution

1. Use the cut property: if an edge is the unique lightest edge crossing some cut, every minimum spanning tree must contain it. Otherwise adding it to an MST forms a cycle containing another crossing edge, and replacing that heavier edge makes a cheaper spanning tree.
2. To prove II, choose any MST T and remove one of its edges e. The remaining components define a cut. Edge e must be a cheapest crossing edge: a strictly cheaper one could reconnect the components and improve T.
3. Under II the cheapest crossing edge is unique, so e is that unique edge. By step 1, every MST must contain e. This reasoning applies to each edge of T.
4. Any other MST must therefore contain all |V|−1 edges of T and hence equal T. This proves II.
5. If every edge weight in the graph is distinct, each nonempty cut automatically has a unique cheapest crossing edge. Thus I implies the condition of II and is also true. Answer C. These are sufficient conditions for uniqueness; the question does not require proving that all edge weights must be distinct in every graph with a unique MST.
