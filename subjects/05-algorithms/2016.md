**Paraphrased problem context:** Count the topological orders of the directed graph with vertices {a,b,c,d,e,f} and exactly the edges a→b, b→c, c→f, a→d, d→e, e→f. These two directed branches are the complete content of the source diagram.

## Solution

The graph consists of a→b→c→f and a→d→e→f. Vertex a must come first and f last. Interleave the two ordered middle chains(b, c) and(d, e), choosing their two positions among four: C(4, 2)=6.

After fixing a and f, the middle orders are bcde, bdce, bdec, dbce, dbec, debc. Each respects b before c and d before e. Choosing the two positions occupied by b,c determines the remaining positions for d,e, giving the binomial coefficient without listing all 4! permutations. A topological order need not follow a single path; it is any ordering in which every directed edge points forward.

**Paraphrased problem context:** Select the worst-case running times of insertion sort, merge sort, and quicksort, in that order. A: Θ(n log n), Θ(n log n), Θ(n^2). B: Θ(n^2), Θ(n^2), Θ(n log n). C: Θ(n^2), Θ(n log n), Θ(n log n). D: Θ(n^2), Θ(n log n), Θ(n^2).

## Solution

Insertion sort may shift Θ(n) elements on each of n insertions, giving Θ(n²). Merge sort uses Θ(n) work across each of Θ(log n) levels, giving Θ(n log n). Quicksort’s most unbalanced partitions give n+(n−1)+...+1=Θ(n²). Thus D.

For reverse-sorted input, insertion sort shifts 1+2+...+(n−1) elements. Merge sort's balanced divide-and-conquer recurrence T(n)=2T(n/2)+Θ(n) yields Θ(n log n) regardless of initial order. Quicksort can repeatedly choose an extreme pivot, leaving subproblems of sizes 0 and n−1, so its recurrence becomes T(n)=T(n−1)+Θ(n). Its average-case or expected randomized Θ(n log n) bound must not be substituted for this requested worst-case bound.

**Paraphrased problem context:** In a connected weighted undirected graph with distinct positive edge weights, add the same positive amount to every edge weight. Evaluate P: the minimum spanning tree is unchanged; Q: the shortest path between every pair is unchanged. A: P only. B: Q only. C: neither. D: both.

## Solution

Every spanning tree has |V|−1 edges, so adding a constant c to each edge adds the same c(|V|−1) to every tree’s weight, preserving the unique MST. Paths may have different edge counts: triangle weights 1, 2, 4 initially favor 1+2 over 4, but adding 2 makes the direct 6 shorter than 3+4. Thus only P, A.

The invariant for trees is equal edge count, not merely preserved ordering of individual edge weights. Compare two trees T1,T2: the added terms cancel in their weight difference. By contrast a k-edge path gains kc, and another path with fewer edges gains less. The triangle counterexample demonstrates an actual reversal while retaining positive, distinct edge weights, so Q fails as a universal statement even though some particular graphs keep their shortest paths.

**Paraphrased problem context:** A four-vertex weighted undirected graph has weight matrix W with rows (0,2,8,5), (2,0,5,8), (8,5,0,x), (5,8,x,0). Find the largest integer x for which some shortest path between some pair uses the edge of weight x.

## Solution

Without edge 3–4, the shortest route between its endpoints is 3→2→1→4 of length 5+2+5=12; the two-edge alternatives both cost 13. Any edge heavier than an alternative endpoint path cannot occur in a shortest path, since replacing it improves the route. At x=12 the edge itself ties the shortest endpoint route, so the largest integer is 12.

It suffices to compare x against the best route between its own endpoints that avoids that edge. Any shortest path using a heavier edge could be improved by substituting that alternative segment. The relevant routes from 3 to 4 have costs 13 via 1,13 via 2,12 via 2 then 1, and 18 via 1 then 2; thus 12 is the threshold. Equality is allowed because the question requires at least one shortest path, not a uniquely shortest path. At x=12, the direct edge is itself a shortest 3-to-4 path.

**Paraphrased problem context:** A complete undirected graph on 4 vertices has its 6 edges assigned the distinct weights 1,2,3,4,5,6. Over all assignments, find the largest possible weight of its minimum spanning tree.

## Solution

Kruskal always accepts edges 1 and 2. If edge 3 does not make a triangle, it completes the tree and total is 6. If edges 1, 2, 3 form a triangle, edge 3 is rejected and the next edge 4 must join the fourth vertex, giving total 7. Assigning 1, 2, 3 to one triangle and 4, 5, 6 to the remaining incident edges attains 7.

Kruskal processes weights in increasing order and cannot reject either of the first two edges of a simple graph: a cycle requires at least three. If the first three edges do not form a triangle, they connect all four vertices and total 6. Otherwise they occupy three vertices, and every remaining edge joins that triangle to the fourth vertex, so edge 4 is necessarily accepted. This proves the upper bound 7 and the triangle arrangement witnesses attainability over all 720 weight assignments.

**Paraphrased problem context:** In a simple undirected graph with distinct edge weights and an MST, consider edge e. I: If e is the lightest edge of some cycle, every MST includes e. II: If e is the heaviest edge of some cycle, every MST excludes e. Which statements are true? A:I only. B:II only. C:both. D:neither.

## Solution

The unique heaviest edge of a cycle is excluded by the cycle property, so II holds. I fails: take edges ab=3, bc=4, ca=5, ad=1, db=2. Edge ab is the lightest in triangle abc but the heaviest in triangle adb, hence excluded from the MST. Thus II only, B, assuming the connected graph/MST component context.

The valid cycle property concerns the heaviest edge: if a tree used it, deleting it creates a cut, and the rest of that cycle contains a lighter edge crossing the cut. Swapping would lower tree weight, contradicting minimality. The lightest edge of a cycle has no symmetric guarantee, because it might be a heavy choice relative to another route outside that cycle. Do not confuse it with the cut property, which guarantees inclusion of the unique lightest edge crossing a cut.

Standard merging processes n elements at each of log n levels. These derivations explain the official convention rather than falsely treating algorithm names as complete implementations.

**Paraphrased problem context:** Which paradigm underlies Floyd–Warshall all-pairs shortest paths? A greedy; B divide-and-conquer; C dynamic programming; D none of these.

## Solution

Floyd–Warshall maintains shortest distances whose allowed intermediate vertices come from the first k vertices, updating d_k(i, j)=min(d_(k−1)(i, j), d_(k−1)(i, k)+d_(k−1)(k, j)). Reusing these subproblems is dynamic programming, C.

Define Dk(i,j) as the best i-to-j path using only vertices 1,…,k internally. Such a path either avoids k or decomposes through k into two earlier subproblems. Initialize D0 with edge weights, zero diagonals and infinity for absent edges. Iterating k,i,j uses Θ(V³) time and can reuse one distance matrix.

**Paraphrased problem context:** Code for positive X,Y: int exp(int X,int Y){int res=1,a=X,b=Y; while(b!=0){if(b%2==0){a=a*a;b=b/2;}else{res=res*a;b=b-1;}}return res;}. Which invariant holds before every iteration? A X^Y=a^b; B (res*a)^Y=(res*X)^b; C X^Y=res*a^b; D X^Y=(res*a)^b.

## Solution

The invariant is X^Y=res·a^b, C. Initially res=1, a=X, b=Y. An even step replaces(a, b) by(a², b/2), preserving a^b. An odd step multiplies res by a and decreases b by 1, preserving the product. At termination b=0, res=X^Y. This mathematical proof assumes intermediates fit the C int type; arbitrary positive inputs can overflow signed int and then lack defined C behavior.

For example X=2,Y=3 gives states (res,a,b)=(1,2,3),(2,2,2),(2,4,1),(8,4,0). The invariant product is 8 at each state. Option A fails once a factor moves into res; option D incorrectly raises res to b. Initialization, preservation and termination are three distinct obligations in a loop-invariant proof.

Right: call A(n/2) twice, then branch to return or call A(n/2) and branch again to return or one final A(n/2) then return. ## Solution

The visually inspected longest branch executes five calls A(n/2): the initial call, two along the right branch, one downward, and one before the final left return. Only calls on a single executed control-flow path are added. The two alternative exits must not both be counted. At recursion level j, the worst-case tree has 5^j calls of size n/2^j; after log₂n levels it has 5^(log₂n)=n^(log₂5) leaves. This yields the exponent without mistaking five sequential calls for five levels of recursion.

**Paraphrased problem context:** An undirected simple graph with n vertices and m edges uses adjacency lists. Entries [v] in u’s list and [u] in v’s list are twins. With unrestricted auxiliary memory, find the best time to set all twin pointers. A Θ(n²); B Θ(n+m); C Θ(m²); D Θ(n⁴).

## Solution

Number vertices0..n−1. Scan the adjacency lists and record each entry’s pointer together with the ordered endpoint pair(min(u, v), max(u, v)). Two stable counting-sort passes on the endpoint labels sort all2m records in O(n+m) time. Consecutive equal pairs are twins, so link their pointers in O(m). Scanning the n list heads and writing the 2m pointers gives the matching linear input/output bound in the adjacency-list model. Thus Θ(n+m), B; the algorithm uses allowed auxiliary memory without initializing an n² matrix.

Give each adjacency entry a record (min endpoint,max endpoint,address). Integer vertex labels permit stable counting sorts instead of comparison sorting’s extra logarithm. Simplicity ensures exactly two records per undirected edge, so matching neighbors after sorting is unambiguous. A dense n-by-n matrix is unnecessary and initializing it would lose the linear bound for sparse graphs.
