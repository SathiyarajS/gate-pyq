**Question:** [Official archived paper page 4](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=4); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A under the intended recurrence-depth convention

**Paraphrased problem context:** For parameters a,b, both printed as ω(1), T(n)=T(n^(1/a))+1 and T(b)=1. Choose the printed asymptotic expression. Options: A Θ(log_a(log_b n)); B Θ(log_(ab) n); C Θ(log_b(log_a n)); D Θ(log_2(log_2 n)). No cutoff for inputs below b is specified; retain this qualification.

## Solution

Worked explanation

Unroll without changing the logarithm bases: T(n)=T(n^(1/a²))+2=…=T(n^(1/a^j))+j. Exact termination at b requires n^(1/a^j)=b, or (ln n)/a^j=ln b. Thus a^j=ln n/ln b=log_b n. Taking log base a yields the expression in A, with total value j+1. This derivation assumes a,b are held fixed during a recursion chain, even if their initial values depend on the original input size. It does not justify swapping a and b as in C. The rigorous cutoff-based estimate is Θ(1+max(0,log_a(log_b n))) in the regime n>1,a>1,b>1, with ceiling for integral depth. The printed ω(1) wording and lone base case are not silently replaced by a fixed-constant recurrence.

Derivation and answer

After j recursive calls the argument is n^(1/a^j). Equating it to b gives a^j=log_b n, hence j=log_a(log_b n) and T(n)=j+1 on exact-depth inputs. With a base cutoff at n≤b, the corresponding depth is max(0, ceil(log_a(log_b n))) for fixed call parameters a, b>1. This gives intended A when the depth is bounded below away from 0, in particular when it grows. Qualification: the source says a, b are ω(1), not fixed constants, and gives only T(b)=1. Arbitrary inputs need a cutoff/rounding convention, and the additive1 cannot always be dropped when parameters vary. For example a=n, b=log n gives depth1 under the cutoff, but log_a(log_b n) tends to 0. Thus the printed unconditional Theta claim requires a parameter regime/termination convention.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** A weighted undirected graph has MST T maintained in adjacency lists. A new weighted edge (u,v) is added. Without an additional preprocessed path-query index, what is the worst-case time to decide whether T remains an MST? A Θ(|E|+|V|); B Θ(|E||V|); C Θ(|E| log |V|); D Θ(|V|).

## Solution

Worked explanation

Let e be the new edge and P the unique u-v path in T. If w(e)<max weight on P, replace a maximum-weight path edge by e; the resulting spanning tree is strictly lighter, so T fails. Conversely, if w(e)≥that maximum, consider any competing tree using e. Removing e separates it into two parts; P crosses that cut at some tree edge f with w(f)≤w(e). Replacing e by f gives an old-graph spanning tree no heavier than the competitor. Since T was minimum among old trees, no new competitor is lighter. A DFS of T visits at most |V|−1 edges, carrying the path maximum. No need to rerun an MST algorithm on all of G.

Derivation and answer

Adding edge(u, v) creates one cycle with the unique u-v path in T. T remains minimum exactly when the new weight is at least the maximum weight on that tree path. A DFS of the adjacency-list tree finds the path and its maximum in O(|V|), and an unpreprocessed path-like tree can force inspection ofΘ(|V|) edges. ThusΘ(|V|), D.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** A directed weighted graph has reweighted edges w′(u,v)=w(u,v)+f(u)−f(v), with f:V→R. Shortest paths are preserved: A for every f; B iff f is everywhere positive; C iff f is everywhere negative; D iff f gives shortest distances from a new source joined to all vertices by zero-weight edges.

## Solution

Worked explanation

For a path v0=s,v1,…,vk=t, summing the added terms gives f(v0)−f(v1)+f(v1)−f(v2)+…+f(vk−1)−f(vk)=f(s)−f(t). Intermediate contributions cancel pairwise. Thus for two s-t paths P,Q, w′(P)−w′(Q)=w(P)−w(Q), preserving strict inequalities and ties. The signs of individual potentials do not matter. Choosing shortest-distance potentials is useful in Johnson’s algorithm to make edge weights nonnegative, but that is an additional goal; it is not necessary for path-order preservation. This argument compares common endpoints, not unrelated paths with different sources or destinations.

Derivation and answer

For any path from s to t, the added potentials telescope: sum[w(u, v)+f(u)−f(v)]=original path weight+f(s)−f(t). All paths with the same endpoints receive the same constant, so their relative order and shortest paths are unchanged for every real-valued f, A. Cycle weights are unchanged too; this does not create finite shortest paths where reachable negative cycles originally prevented them.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 99 to 99

**Derived answer:** 99

**Paraphrased problem context:** The complete undirected graph has vertices v1,…,v100 and edge (vi,vj) for every 1≤i<j≤100, with weight |i−j|. Find its MST weight.

## Solution

Worked explanation

A spanning tree is connected and acyclic on all 100 vertices, hence has exactly 99 edges. Here i≠j makes every weight |i−j| a positive integer, at least 1. Thus 99 is a universal lower bound. Choose precisely the edges (v1,v2),(v2,v3),…,(v99,v100). They form a path through every vertex, so are a valid spanning tree, and every edge has weight 1. Their sum is 99, attaining the bound. Taking all weight-one edges happens to work because they form this path; merely selecting individually cheap edges would not prove connectivity in a general graph.

Derivation and answer

Every edge has positive integer weight at least1, and every spanning tree on100 vertices has 99 edges, so its total weight is at least99. The path v1-v2-...-v100 uses99 consecutive-index edges of weight1 and attains that bound. Hence the MST weight is 99.
