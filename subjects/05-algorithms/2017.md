**Official answer:** C

**Derived answer:** C

**Source access:** Open archive member CS/CS2-2017.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** Match P:Towers of Hanoi with n disks; Q:binary search of n sorted numbers; R:worst-case heapsort of n numbers; S:addition of two n×n matrices. Complexities i:Θ(n²), ii:Θ(n log n), iii:Θ(2^n), iv:Θ(log n). Options (P,Q,R,S): A:(iii,iv,i,ii), B:(iv,iii,i,ii), C:(iii,iv,ii,i), D:(iv,iii,ii,i).

## Solution

1. Hanoi moves n-1 disks away, moves the largest disk once, then moves n-1 disks back: T(n)=2T(n-1)+1=2^n-1, so P→iii.

2. Binary search halves the candidate interval each time; after k comparisons about n/2^k candidates remain. Reaching one requires Θ(log n) comparisons, so Q→iv.

3. Heapsort builds a heap in O(n) and performs n extractions costing O(log n) each in the worst case, giving Θ(n log n): R→ii. Matrix addition performs one addition at each of n² positions, giving S→i. Select C.

**Question:** [Official archived paper page 6](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Official answer:** D

**Derived answer:** D

**Source access:** Open archive member CS/CS2-2017.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** An undirected graph has vertices M,N,O,P,Q,R and edges MN,NO,MR,MQ,NQ,OQ,OP,PQ. Which is a possible BFS visiting order, with the first vertex as the start? A:MNOPQR. B:NQMPOR. C:QMNROP. D:POQNMR.

## Solution

1. BFS removes vertices from a FIFO queue and discovers all vertices at a smaller distance before any at a larger distance. For D, start at P and enqueue its neighbors O then Q. The visited prefix is P,O,Q.

2. Processing O discovers N; its other neighbors P and Q are already discovered. Processing Q then discovers M, with N already queued. Processing N adds nothing, and processing M finally discovers R. The resulting order is P,O,Q,N,M,R.

3. A fails from M because O at distance 2 precedes its distance-1 neighbors Q and R. B fails from N because P at distance 2 precedes O at distance 1. C fails from Q because R at distance 2 precedes O and P at distance 1. Thus D is possible; BFS neighbor ordering need not be alphabetical.

**Paraphrased problem context:** T(n)=2T(√n)+1 for n>2, and T(n)=2 for 0<n≤2. What is its asymptotic order? A:Θ(log log n). B:Θ(log n). C:Θ(√n). D:Θ(n).

## Solution

1. The argument shrinks by square root, so transform to its logarithm. Put m=log₂n and S(m)=T(2^m). Since √(2^m)=2^(m/2), the recurrence becomes S(m)=2S(m/2)+1 with a constant base for m≤1.

2. This is a binary recursion tree with Θ(m) leaves and Θ(m) total nodes. Equivalently, the Master theorem has a=2,b=2 and f(m)=1, giving S(m)=Θ(m).

3. Substituting back gives T(n)=Θ(log n), option B. The recursion depth is only Θ(log log n), but each level branches into twice as many subproblems. Counting depth alone misses the total work.

**Paraphrased problem context:** For positive n, C code executes: for(i=1;i<=n;i++){ for(j=1;j<n;j+=i){ printf(" %d %d",i,j); } }. Find its Θ time complexity, treating each iteration/output as unit cost. A:Θ(n√n). B:Θ(n²). C:Θ(n log n). D:Θ(n² log n).

## Solution

1. Fix i. The inner-loop j values are 1,1+i,1+2i,… below n, so there are ceil((n-1)/i) iterations. The step size is i, not 1; different outer-loop iterations therefore have different costs.

2. Sum over i=1,…,n. Ignoring rounding gives (n-1)Σ1/i=(n-1)H_n. Rounding adds at most n operations, and H_n=Θ(log n), so the total is Θ(n log n).

3. The outer-loop overhead is only Θ(n) and does not change the result, giving C. This is the conventional unit-cost model used by the question. Counting the individual decimal digits written by printf, or fixed-width integer overflow at extreme n, would be a different analysis from the intended asymptotic loop count.

**Source access:** Open archive member CS/CS2-2017.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** A message uses symbols P,Q,R,S,T with probabilities 0.22,0.34,0.17,0.19,0.08 respectively. For a 100-character message encoded with binary Huffman coding, what is the expected encoded length in bits?

## Solution

1. Huffman coding repeatedly merges the two smallest current weights. Merge T and R:0.08+0.17=0.25. Next merge S and P:0.19+0.22=0.41. The remaining weights are 0.25,0.34,0.41; merge 0.25+0.34=0.59, then 0.41+0.59=1.

2. The resulting depths are 2 for P,Q,S and 3 for R,T. One valid code assignment is S=00,P=01,T=100,R=101,Q=11; swapping branch labels changes codewords but not lengths.

3. Expected bits per symbol are 2(0.22+0.34+0.19)+3(0.17+0.08)=1.5+0.75=2.25. Equivalently sum the merge weights 0.25+0.41+0.59+1=2.25. For 100 symbols the expectation is 225 bits, excluding codebook/container overhead. It is an expectation, not a guarantee for every possible 100-symbol sequence.

## Solution

1. Compare eventual growth rather than the values at a particular small n. The reciprocal 100/n tends to zero while 10 stays constant.

2. log₂n is unbounded, but log₂n/√n→0. Also √n/n=1/√n→0. These limiting ratios put logarithm below square root below linear growth.

3. Consequently 100/n < 10 < log₂n < √n < n in asymptotic growth, option B. Constants such as 100 do not reverse eventual ordering.

**Paraphrased problem context:** Match P Kruskal, Q Quicksort, R Floyd–Warshall to i divide and conquer, ii greedy, iii dynamic programming. A P-ii Q-iii R-i; B P-iii Q-i R-ii; C P-ii Q-i R-iii; D P-i Q-ii R-iii.

## Solution

1. Kruskal sorts edges by weight and repeatedly accepts a cheapest edge that does not form a cycle. This is the greedy paradigm ii.

2. Quicksort partitions around a pivot, recursively sorts the two resulting parts, and combines their order: divide and conquer i.

3. Floyd–Warshall updates distances by allowing intermediate vertices one at a time: Dk[i,j]=min(Dk−1[i,j],Dk−1[i,k]+Dk−1[k,j]). Reused subproblem values make it dynamic programming iii. Thus C.

**Paraphrased problem context:** In any connected undirected graph with positive distinct edge weights, are these necessarily true? I the minimum spanning tree is unique; II the shortest path between any two vertices is unique. A I only; B II only; C both; D neither.

## Solution

1. For uniqueness of the MST, suppose two different minimum trees exist. Select the lightest edge in their symmetric difference and add it to the tree not containing it.

2. The resulting cycle has an edge belonging to that tree but not the other. This edge is heavier because weights are distinct and the chosen edge was lightest in the difference. Exchanging them strictly reduces weight, contradicting minimality. Thus I is true.

3. Distinct edge weights do not make path sums distinct. In a triangle with weights 1,2,3 the direct weight-3 edge ties the 1+2 route. II fails, so A.

**Question:** [Official archived paper page 21](https://web.archive.org/web/20170712112248id_/http://www.gate.iitg.ac.in:80/2017questions/CS1.pdf#page=21); consult original wording, diagrams and choices.

**Paraphrased problem context:** An array of 31 entries consists of zeros followed by ones. Find the smallest index i with A[i]=1 using the minimum number of array probes. What is an optimal algorithm’s worst-case probe count?

## Solution

1. A probe returns one bit: if A[mid]=0 the first one lies to the right; if A[mid]=1 it lies at mid or to the left. This monotonicity permits binary search.

2. Balanced probing halves the candidate boundary positions each time. Five probes suffice for 31 first-one positions, or 32 possibilities if an all-zero sentinel is allowed.

3. For optimality, a binary decision tree of depth four has at most 2^4=16 leaves, fewer than 31 distinguishable answers. Thus no algorithm can guarantee four probes. The optimal worst case is 5, not a linear scan of 31.
