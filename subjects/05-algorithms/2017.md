## Solution

Hanoi obeys T(n)=2T(n−1)+1, Θ(2^n). Binary search halves the interval, Θ(log n). Worst-case heapsort isΘ(n log n), and adding all n² matrix entries isΘ(n²). The mapping is P-iii, Q-iv, R-ii, S-i, C.

**Official answer:** 225.0 to 225.0

**Derived answer:** 225

**Source access:** Open archive member CS/CS2-2017.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

Huffman merges probabilities0.08+0.17=0.25, 0.19+0.22=0.41, 0.25+0.34=0.59, then0.41+0.59=1. The sum of merge weights equals the expected code length: 0.25+0.41+0.59+1=2.25 bits per symbol. Equivalently P, Q, S have length 2 and R, T length 3. For100 symbols the expected length is 225 bits, excluding any codebook or container overhead.

## Solution

Kruskal repeatedly takes the cheapest safe edge, a greedy choice. Quicksort divides into partitions and recursively solves them, divide and conquer. Floyd–Warshall reuses shortest-path subproblems indexed by permitted intermediate vertices, dynamic programming. The mapping P-ii, Q-i, R-iii is C.

**Derived answer:** A

**Source access:** Archived July2017 original official paper and key. Page numbers refer to the paper PDF; key is a separate two-page PDF.

## Solution

Distinct edge weights imply a unique MST by the exchange/cut argument: the lightest differing edge between two supposed MSTs can improve one of them. Shortest paths can tie despite distinct individual weights: a triangle with edges 1, 2, 3 has a direct length 3 route tying the two-edge1+2 route. Thus I only, A.

# GATE 2017 CS1: Q58 (printed CS Q48)

**Question:** [Official archived paper page 21](https://web.archive.org/web/20170712112248id_/http://www.gate.iitg.ac.in:80/2017questions/CS1.pdf#page=21); consult original wording, diagrams and choices.

**Official answer:** 5.0 to 5.0

**Derived answer:** 5

**Source access:** Archived July2017 original official paper and key. Page numbers refer to the paper PDF; key is a separate two-page PDF.

## Solution

Binary search for the zero/one boundary halves the remaining possibilities and needs at most5 probes for31 locations. There are31 possible first-one indices (or32 possibilities if an all-zero sentinel is admitted), and a binary probe decision tree of depth4 has only 16 leaves, so fewer than5 probes cannot distinguish them all. Thus the optimal worst case is 5.
