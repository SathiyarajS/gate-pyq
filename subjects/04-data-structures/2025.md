

# GATE 2025 CS1: Q26

**Question:** [Official archived paper page 26](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=26); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;B

**Derived answer:** A;B under upper-bound interpretation; B under literal per-tree equality

## Solution

Inorder traversal of a BST with distinct keys is always sorted, so B is true. An n-node tree has root-to-node paths of at most n−1 edges; a skewed BST attains n−1. The official key A, B treats A as this maximum possible bound over all BSTs. However, the literal assertion that the maximum path length IS n−1 for any given BST is false: a balanced three-node BST has height 1, not 2. Under that literal reading, only B is true. C is false because a skewed BST may require Θ(n) search, and D is false because a left child can be smaller than its parent and a BST need not be complete. Preserve official A, B and disclose the wording ambiguity.

**Official answer:** 5 to 5

**Derived answer:** 5

## Solution

A standard binary heap has the shape of a complete binary tree. Levels 0 through 4 contain at most 1+2+4+8+16=31 nodes, so the 32nd key starts level 5. Consequently the maximum number of edges from the root to a leaf is floor(log₂32)=5. This uses the conventional binary-heap meaning of Min-Heap.

## Solution

Let i be the number of internal nodes. Every internal node has exactly two children, so counting parent-to-child edges gives 2i edges. Every n-node tree has n−1 edges. Thus2i=n−1 and i=(n−1)/2, option B. This also handles the single-node tree, where i=0.

P can concatenate the two doubly linked lists by changing a constant number of next/previous and head/tail pointers, Θ(1). # GATE 2025 CS2: Q45

**Question:** [Official archived paper page 34](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=34); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

With A, each newly pushed record stores a pointer to the minimum among records below it, computed from the previous top and its saved pointer in O(1). MIN compares the current top with its saved below-minimum; POP exposes a top whose saved pointer is still valid. Thus PUSH, POP, MIN are O(1). A single global pointer alone loses the next minimum when the current minimum is popped. Maintaining a sorted array requires O(n) shifts in the worst case; a heap requires O(log n) updates. Only A works with the stated complexities.
