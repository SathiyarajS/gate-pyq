

# GATE 2022 CS: Q15

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

Keep previous, current and next pointers. Save current.next, reverse that link, and advance; at termination previous becomes the head. This uses constant auxiliary space and one pass, O(n). Reversing the links of an arbitrary n-node list requires Ω(n) link changes, so the optimum is Θ(n), A.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

## Solution

For a fixed slot, each key maps there with probability 1/m under whichever uniform hash function applies to its parity. Summing n indicator expectations gives n/m. Independence between all indicators is unnecessary for this expectation. Thus B.

# GATE 2022 CS: Q28

**Question:** [Official archived paper page 22](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=22); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 509 to 509

**Derived answer:** 509

## Solution

The maximum key lies on the right spine, with zero-based array indices 0, 2, 6, 14, 30, 62, 126, 254, 510. Index 510 has no children because their indices exceed 999. The predecessor is its parent 254. The next predecessor is the maximum in 254’s left subtree, rooted at 509; 509 has no children either. Hence the third largest key is at index 509.

# GATE 2022 CS: Q62

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 0 to 0

**Derived answer:** 0

## Solution

No enqueue into Q1 is necessary. Move its front item to Q2, then rotate Q2 by moving each of its previously present items from front to back. Starting with Q2 empty, the successive states after these steps are [1], [2, 1], [3, 2, 1], [4, 3, 2, 1]. Each insertion is Enqueue(Q2, Dequeue(Q1)), and rotations are Enqueue(Q2, Dequeue(Q2)); Q1 is never enqueued. Since the count cannot be negative, the minimum is 0. As in the allowed operation model, a dequeued value can be passed directly to enqueue without an auxiliary storage data structure.
