

# GATE 2019 CS: Q50 (printed CS Q40)

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A under distinct-key comparison model

## Solution

With distinct keys, a minimum cannot have a child in a max-heap, and the second largest element must be a root child. Traverse the BST into an array and build a heap in linear time, proving III. Conversely constructing a comparison BST from arbitrary heap keys in linear time would permit linear-time sorting by inorder traversal; building the initial heap is itself linear, contradicting the comparison sorting lower bound. Hence I, II, III, A. Distinct-key interpretation matters: duplicate minima can occur internally, so the literal always wording of I is not valid for arbitrary duplicate-key heaps.

# GATE 2019 CS: Q56 (printed CS Q46)

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4.25 to 4.25

**Derived answer:** 4.25

## Solution

The parenthetical definition specifies a perfect tree of height3. Fix the first chosen leaf. Among8 equally likely second choices, one is the same leaf(distance0), one its sibling(distance2), two lie in the other sibling subtree under the same depth1 ancestor(distance4), and four lie in the other root subtree(distance6). Expectation=(0+2+2*4+4*6)/8=34/8=4.25. Independent sampling allows the same leaf twice; excluding that event would be a different distribution.
