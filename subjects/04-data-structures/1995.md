

# GATE 1995: Q17 (printed A Q1.17)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B: n−1

**Essential problem context (paraphrased):** A nonempty rooted binary tree has n leaves. How many nodes have two children?

## Solution

Let n0,n1,n2 count nodes with zero, one and two children. The tree has n0+n1+n2−1 edges because it is connected and acyclic. Counting edges by parents gives n1+2n2. Equating the two expressions yields n2=n0−1=n−1. Unary nodes cancel and therefore do not alter the relationship. Here degree two means two children, the rooted-tree convention; interpreting it as undirected graph degree would be a different question.

# GATE 1995: Q53 (printed A Q4(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Change the inner loop to J:=I+1 to N.

**Essential problem context (paraphrased):** An N×N integer array A (1<N≤20) is transposed by: for I:=1 to N−1 do for J:=1 to N do begin TMP:=A[I,J]; A[I,J]:=A[J,I]; A[J,I]:=TMP end. Find and correct the error.

## Solution

Transposition must exchange each off-diagonal pair A[i,j], A[j,i] exactly once. In the supplied code, when i and j are both below N, the pair is exchanged once on iteration (i,j) and again on (j,i). The second exchange undoes the first. Pairs involving N are treated differently because the outer loop never reaches N. This is therefore not a valid general transpose, even though special inputs or N=2 can hide the fault.

Keep I from 1 through N−1 and change the inner loop to J from I+1 through N. The three assignments in the swap body can remain unchanged. Every unordered off-diagonal pair has exactly one representative with i<j, so it is visited once; diagonal entries need no work. The algorithm performs N(N−1)/2 swaps, takes Θ(N²) time and uses one temporary integer. Afterward every old A[i,j] has moved to A[j,i].

# GATE 1995: Q56 (printed A Q6)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204046/GATE1995.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 5

**Essential problem context (paraphrased):** How many ordered binary trees on three nodes have postorder A,B,C? Draw all of them.

## Solution

Postorder visits the left subtree, then the right subtree, then the root, so C must be the root. Partition the first two labels between its subtrees. If both subtrees are nonempty, each has one node: left A and right B. If only one subtree is nonempty, that subtree has postorder A,B, so its root is B and A can be either B’s left or right child. The two-node subtree itself can be C’s left or right child, giving four more trees.

A compact complete drawing uses node(left,right), with ∅ denoting an absent child:
1. C(A,B)
2. C(B(A,∅),∅)
3. C(B(∅,A),∅)
4. C(∅,B(A,∅))
5. C(∅,B(∅,A)).
Here A or B written without parentheses is a leaf. Each drawing emits A then B then C under postorder. The cases exhaust left-subtree sizes 0,1,2, giving the Catalan count C₃=C₀C₂+C₁C₁+C₂C₀=2+1+2=5. Left and right child positions are distinguished; these are not restricted to full binary trees.
