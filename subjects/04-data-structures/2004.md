**Official answer:** Not available; no official key located.

**Independently derived answer:** D for direct list algorithms

## Solution

Membership scans a list in O(n), and cardinality is O(n) by traversal (or O(1) if stored). For union/intersection of two unsorted lists of comparable size, direct algorithms test each element against the other list, taking Θ(n²) worst case while avoiding duplicates in the union. Thus union and intersection, D. Auxiliary hashing or sorting can improve these operations; the comparison assumes direct operations on the stated unsorted-list representation without such an index.

A leaf returns zero. A node with a child takes one plus that child’s recursively computed value; with two children it takes the maximum. Induction gives the maximum number of edges from the node to a descendant leaf, i.e. height measured in edges. The null check returns zero but no missing child adds an edge. The code does not count nodes or leaves.
