**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Maintain a small candidate min-priority queue initially containing the root. Repeatedly remove its minimum and insert that node’s children; after seven removals the extracted value is seventh smallest. Only a constant number of nodes and candidate operations are used because rank7 is fixed, hence Θ(1) with respect to n, D, assuming n≥7. Repeatedly deleting from the original n-element heap is unnecessarily expensive.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

A balanced binary search tree supports membership search, insertion, and deletion of its minimum in O(log n) worst-case time. A plain heap supports minimum deletion and unrestricted insertion in O(log n), but checking whether an arbitrary proposed value is already present may require Θ(n) comparisons. Therefore the uniqueness requirement rules out the heap alone, leaving B. Augmenting a heap with a separate membership structure is outside the listed plain-structure comparison.

## Solution

For item m, there are n−m later pushes and n−m earlier pops between the end of push(m) and the start of its pop. Those 2(n−m) complete intervening operations cost 2(n−m)X and the 2(n−m)+1 gaps cost [2(n−m)+1]Y. Average n−m over m=1,…,n is (n−1)/2, so the mean is (n−1)X+nY=n(X+Y)−X, option C. For n=1 it correctly reduces to the single gap Y.

# GATE 2003: Q65 (printed CS Q65)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=9), physical page 9. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B under standard split-before-descent insertion

## Solution

The GFG reproduction omits the actual requested operation; GateForum explicitly asks to insert G. Under standard top-down B-tree insertion, first split the full root [L,P,U], promoting P and giving children [L] and [U]. Descending left, split its full child [B,H,I], promoting H into [L] to obtain [H,L] and leaves [B],[I],[N]. Insert G into [B], giving [B,G]. The result is option B, with root [P], left child [H,L] and right child [U]. A different valid insertion policy can produce another valid B-tree: A follows suitable bottom-up split choices, and C uses redistribution to a sibling. Consequently B is the conventional algorithmic answer, not a uniquely forced tree from the B-tree invariants alone.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

The empty list and a one-node list return true. For any longer list, short-circuit evaluation checks data at the current node≤data at the next node and then recursively verifies the suffix. By induction, the result is true exactly when every adjacent pair is in nondecreasing order, option B. The initial null checks protect the pointer dereferences. This assumes the ordinary finite, well-formed, acyclic linked-list input; on a cycle recursion need not terminate.
