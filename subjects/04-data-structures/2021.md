**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** A binary search tree T has n distinct elements. What is the time complexity of picking an element smaller than its maximum? A Θ(n log n); B Θ(n); C Θ(log n); D Θ(1). The task implicitly requires n≥2.

## Solution

If the root has a right child, the root itself is smaller than the maximum. If it has no right child, it is the maximum, so return its left child. For n≥2 that child exists in the latter case. Only a constant number of pointer tests is needed, Θ(1), D. The task implicitly needs at least two nodes; no such element exists for n=1.

An O(1) algorithm is: if root.right is non-null, return root.key; otherwise return root.left.key. In the first branch some right-subtree key is greater than the root, proving the root is not maximum. In the second branch the root is maximum; distinctness ensures its left child is strictly smaller. Searching for the second-largest element would be a different, potentially height-dependent task; the question asks for any smaller element.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 86 to 86

**Derived answer:** 86

**Paraphrased problem context:** An initially empty stack executes push(54); push(52); pop(); push(55); push(62); s=pop(). An initially empty queue executes enqueue(21); enqueue(24); dequeue(); enqueue(28); enqueue(32); q=dequeue(). Find s+q.

## Solution

The first pop removes 52. After pushing 55 and 62, the next pop gives s=62. In the queue the first dequeue removes 21, leaving 24 at the front even after 28 and 32 are enqueued. Thus q=24 and s+q=86.

Write stack contents bottom-to-top: [54], [54,52], [54], [54,55], [54,55,62], then pop returns 62. Write queue contents front-to-back: [21], [21,24], [24], [24,28], [24,28,32], then dequeue returns 24. The stack is last-in-first-out and the queue first-in-first-out. Recording contents after every operation prevents confusing the earlier discarded pop/dequeue results with s and q.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Dynamic hashing uses a four-entry table indexed by the lowest two bits of four-bit integer keys. Collisions split into a binary tree by the third-lowest bit (0 left,1 right), then the fourth-lowest bit; split only when required. Target diagram: bucket 00 empty; bucket 01 splits at bit 3, with a leaf on branch 0 and a bit-4 split with two leaves on branch 1; bucket 10 splits at bit 3 into two leaves; bucket 11 has one leaf. Which insertion sequence yields it? A 5,9,4,13,10,7; B 9,5,10,6,7,1; C 10,9,6,7,5,13; D 9,5,13,6,10,14.

## Solution

The displayed shape requires bucket 00 empty; bucket 01 with one key having third-lowest bit 0 and two keys having third-lowest bit 1, separated by the fourth bit; bucket 10 with one key on each third-bit branch; and bucket 11 with one key. C supplies bucket01={9(1001), 5(0101), 13(1101)}, bucket10={10(1010), 6(0110)}, and bucket11={7(0111)}, exactly that structure. A puts 4 in bucket00, B splits the zero third-bit branch of bucket01 because it contains 1 and 9, and D leaves bucket11 empty while putting three keys in bucket10. Only C matches.

Process C explicitly: 10=1010 enters bucket10; 9=1001 enters bucket01; 6=0110 collides in bucket10 but differs from 10 in bit3, making its two leaves. Key 7=0111 occupies bucket11. Key 5=0101 collides with 9 in bucket01 and goes to its bit3=1 branch, whereas 9 has bit3=0. Finally 13=1101 joins 5 on bit3=1 and differs in bit4, producing exactly the extra split. A premature split without collision would violate the stated rule.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** A binary min-heap of n elements is stored as an array. Find optimal worst-case time to find its maximum. A Θ(1); B Θ(log n); C Θ(n); D Θ(n log n).

## Solution

A maximum occurs among the heap leaves, of which there are ceil(n/2). Scan those leaves to find it in O(n). Their values have no heap-imposed relative order, so in the worst case each must be considered, yielding Ω(n). Hence Θ(n), C.

In a one-based heap array, indices floor(n/2)+1 through n are leaves. Initialize best to the first leaf and compare each remaining leaf once. Heap order says ancestors are no larger than descendants, so inspecting internal nodes is unnecessary. An adversary can assign distinct arbitrary values to leaves above all internal values; finding their maximum requires leaf-count−1 comparisons.

**Official answer:** 1 to 1

**Derived answer:** 1

**Paraphrased problem context:** A complete binary tree has 7 nodes. A is the first three BFS-discovered nodes from root; B is the first three DFS-discovered nodes from root. Find |A−B|.

## Solution

The complete seven-node tree has three levels. BFS first visits the root and both children. DFS discovery first visits the root, one child, and one grandchild. Therefore exactly one BFS member, the other child of the root, is absent from the first three DFS members, so |A−B|=1.

Name the root r, children l,u and grandchildren l1,l2,u1,u2. BFS gives {r,l,u}. A left-first DFS gives {r,l,l1}; right-first gives {r,u,u1}. In either case the intersection has two nodes and the BFS-only set has one. The result is independent of which child is explored first.
