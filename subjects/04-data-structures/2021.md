

# GATE 2021 CS1: Q20 (printed CS Q10)

**Question:** [Official archived paper page 16](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=16); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

## Solution

If the root has a right child, the root itself is smaller than the maximum. If it has no right child, it is the maximum, so return its left child. For n≥2 that child exists in the latter case. Only a constant number of pointer tests is needed, Θ(1), D. The task implicitly needs at least two nodes; no such element exists for n=1.

## Solution

The first pop removes52. After pushing55 and 62, the next pop gives s=62. In the queue the first dequeue removes21, leaving24 at the front even after 28 and 32 are enqueued. Thus q=24 and s+q=86.

# GATE 2021 CS1: Q57 (printed CS Q47)

**Question:** [Official archived paper page 38](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=38); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

The displayed shape requires bucket 00 empty; bucket 01 with one key having third-lowest bit 0 and two keys having third-lowest bit 1, separated by the fourth bit; bucket 10 with one key on each third-bit branch; and bucket 11 with one key. C supplies bucket01={9(1001), 5(0101), 13(1101)}, bucket10={10(1010), 6(0110)}, and bucket11={7(0111)}, exactly that structure. A puts 4 in bucket00, B splits the zero third-bit branch of bucket01 because it contains 1 and 9, and D leaves bucket11 empty while putting three keys in bucket10. Only C matches.

# GATE 2021 CS2: Q12 (printed CS Q2)

**Question:** [Official archived paper page 55](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=55); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

A maximum occurs among the heap leaves, of which there are ceil(n/2). Scan those leaves to find it in O(n). Their values have no heap-imposed relative order, so in the worst case each must be considered, yielding Ω(n). Hence Θ(n), C.

# GATE 2021 CS2: Q26 (printed CS Q16)

**Question:** [Official archived paper page 64](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=64); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 1 to 1

**Derived answer:** 1

## Solution

The complete seven-node tree has three levels. BFS first visits the root and both children. DFS discovery first visits the root, one child, and one grandchild. Therefore exactly one BFS member, the other child of the root, is absent from the first three DFS members, so |A−B|=1.
