

# GATE 2024 CS1: Q21

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

Nonroot B+ tree nodes must satisfy the minimum occupancy needed for balanced splitting/merging. The root is exceptional: an internal root can have only two children even when that is below half capacity, and a leaf root can hold a very small entire tree. Other leaves/internal nodes do not receive this general exemption. Answer A.

# GATE 2024 CS1: Q43

**Question:** [Official archived paper page 27](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=27); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

A maximum distinct key cannot have a child in a min-heap, since each child would have to be larger. Thus it must occupy a leaf. A105-node complete binary tree has floor(105/2)=52 internal nodes and 53 leaves, all possible locations for the maximum under some valid key assignment. The number of possible indices is 53, option A; zero-based versus one-based indexing changes the labels but not their count.

# GATE 2024 CS2: Q39

**Question:** [Official archived paper page 26](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=26); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

An inorder traversal of a BST with distinct keys and smaller keys to the left always visits exactly the sorted set V, regardless of insertion order. The first inserted key becomes the root, and different insertion orders can change the root, preorder, and postorder. Hence only inorder is determined in general, option A. Trivial sets can coincidentally determine more, but do not establish those claims for arbitrary V.

# GATE 2024 CS2: Q48

**Question:** [Official archived paper page 33](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=33); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C;D

**Derived answer:** B;C;D

## Solution

Write T for PushToS2, R for PushToS1, and O for GenerateOutput. Starting with S1 bottom-to-top100, 200, 300, 400 and empty S2: B is realized by T, T, O, R, O, R, O, O; C by O, T, O, O, R, O; D by T, O, O, R, O, O. These produce the stated sequences without exceeding S2 capacity2. A cannot start with 100: reaching it before any output requires all three higher elements outside S1, but S2 holds only two. Thus B, C, D.
