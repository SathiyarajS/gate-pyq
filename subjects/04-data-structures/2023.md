

# GATE 2023 CS: Q12

**Question:** [Official archived paper page 9](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=9); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Which 1-indexed array is a max-heap? A [23,17,10,6,13,14,1,5,7,12]; B [23,17,14,7,13,10,1,5,6,12]; C [23,17,14,6,13,10,1,5,7,15]; D [23,14,17,1,10,13,16,12,7,5].

## Solution

In a one-indexed max-heap, A[i] must be at least both A[2i] and A[2i+1] when those children exist. B satisfies all parent-child inequalities: 23≥17, 14; 17≥7, 13; 14≥10, 1; 7≥5, 6; 13≥12. A fails at 10<14, C at 6<7 and 13<15, and D at 1<12. Answer B.

Teaching detail. A heap is only partially ordered: parent keys dominate child keys, but siblings need not be sorted and the array need not be globally descending. There are only five possible parent positions in this ten-element array. For A, index 3 contains 10 and child index 6 contains 14. For C, parent index 4 contains 6 but child 9 contains 7. For D, parent 4 contains 1 but child 8 contains 12. One violation suffices to reject a candidate; every edge must pass to accept B.

# GATE 2023 CS: Q13

**Question:** [Official archived paper page 10](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=10); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** Given pointers to a list's head and an arbitrary node to delete, compare worst-case deletion time for singly and doubly linked lists of n nodes. A O(1),O(n); B O(log n),O(log n); C O(1),O(1); D O(n),O(1).

## Solution

Deleting an arbitrary node of a singly linked list requires locating its predecessor to reconnect the list. In the worst case the target is the tail and this takes a traversal, Θ(n); copying the next node’s value is not a universal solution for the tail. A doubly linked node directly exposes its predecessor and successor, so a constant number of links and possibly the head pointer suffice, Θ(1). Answer D.

Teaching detail. The important missing link in a singly linked node is its predecessor. Knowing the head and the target does not provide that predecessor directly, and freeing the target without redirecting its predecessor would leave a dangling link. For a doubly linked node u, set u.prev.next=u.next and u.next.prev=u.prev when those neighbors exist; handle a head or tail by changing the relevant end pointer. These are bounded operations independent of n. The worst-case claim concerns arbitrary nodes, including the tail.

# GATE 2023 CS: Q46

**Question:** [Official archived paper page 49](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=49); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** A priority queue of n elements is implemented as a max-heap. What are the worst-case times for Extract-Max (remove maximum and restore heap) and Insert (add key and restore heap)? A both O(1); B both O(log n); C O(1),O(n); D O(1),O(log n).

## Solution

A binary heap has heightΘ(log n). Extract-Max removes the root, moves the final element there, and can sift it down the full height. Insertion appends a leaf and can sift it up the full height. Both therefore take O(log n) worst-case time, option B, under the ordinary heap-storage model without charging an occasional external dynamic-array resize.

Teaching detail. Reading a heap's maximum is O(1) because it is at the root, but Extract-Max includes deletion and restoration, which is more work. A replacement root may be smaller than descendants all the way to a leaf, requiring one comparison/swap step per level. A newly inserted large key may similarly rise from its leaf to the root. A complete binary tree has logarithmic height, giving both upper bounds, and such examples attain that height. Neither operation scans all n items in the ordinary representation.

# GATE 2023 CS: Q59

**Question:** [Official archived paper page 62](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=62); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 8 to 8

**Derived answer:** 8

**Paraphrased problem context:** Start with empty stack S and queue Q. Push/enqueue 1,5,7,8,9,2 in that order into each. Then pop S, dequeue Q, pop S, dequeue Q. Four times, dequeue Q and push that element into S. Finally pop S twice. What is the remaining top?

## Solution

Write the stack from bottom to top. After the initial pushes it is [1, 5, 7, 8, 9, 2], and the queue front-to-back is [1, 5, 7, 8, 9, 2]. The two pops remove 2 and 9; the two dequeues remove 1 and 5. The stack is then [1, 5, 7, 8] and the queue [7, 8, 9, 2]. Operation VII and its three repetitions append 7, 8, 9, 2 to the stack. The final two pops remove 2 and 9, leaving top element 8.

Teaching detail. Use different ends for the two structures: a stack removes the most recently pushed item, while a queue removes the earliest enqueued one. After the four transfers, the stack bottom-to-top is [1,5,7,8,7,8,9,2] and the queue is empty. Removing its top two entries leaves [1,5,7,8,7,8], whose final entry is 8. Operation VIII says repeat VII three times after its first execution, making four transfers total. Mistaking this for only three transfers changes the trace.
