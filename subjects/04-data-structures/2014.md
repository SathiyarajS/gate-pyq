**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Source access:** Open archive member CS/CS2014.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

Keep the queue front at the stack top. ENQUEUE(x) performs REVERSE, PUSH(x), REVERSE, placing x at the bottom while preserving the previous order. DEQUEUE performs POP. Thus three and one instructions respectively, C. A single reversal followed by a pop would leave the remaining stack in the wrong orientation for an arbitrary future operation sequence.

The figure is not binary because R has three children. Using the conventional generalization visit first child, then node, then remaining children from left to right: Q gives SQ; R gives T, R, WU, V. # GATE 2014 CS3: Q51 (printed CS Q41)

**Question:** [Official archived paper page 62](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

**Source access:** Open archive member CS/CS2014.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

A null pointer contributes0. A node with no leftmost child contributes1 for itself; otherwise recursion counts leaves in its child list. Recursing on rightSibling adds all sibling subtrees. Induction on this forest representation shows each leaf counted exactly once and no internal node counted. At the root, which has no sibling, the result is the tree leaf count, D.
