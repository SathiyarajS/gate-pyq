## Solution

A fixed-capacity circular array stores front/rear indices and wraps them modulo capacity. Enqueue writes at rear and advances it; dequeue reads at front and advances it. Both take O(1) without shifting elements, A, with overflow handled separately from dynamic resizing.

# GATE 2016 CS1: Q51 (printed CS Q41)

**Question:** [Official archived paper page 16](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 256.0 : 256.0

**Derived answer:** 256

**Source access:** Open archive member CS/CS2016.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

Let F(n) be the maximum number of loop iterations with n queued values and no relevant stack entries. Until a minimum queued value is pushed, each value originally preceding that minimum is pushed at most once and popped at most once: popped items return behind the minimum. Thus this phase costs at most2n−1 iterations. Once the minimum is pushed it never pops, leaving at most n−1 values to process above it. Hence F(n)≤2n−1+F(n−1), giving F(n)≤n². A strictly descending initial queue attains equality at each phase, because all preceding values are pushed and popped and return in descending order behind the minimum. Therefore F(16)=256.

**Official answer:** C

**Derived answer:** C

**Source access:** Open archive member CS/CS2016.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

With the node pointer, doubly linked deletion is O(1). Maintaining sorted order can require O(N) search per insertion, find, or decrease-key repositioning. Thus Θ(N) deletions cost O(N), O(log N) insert/find calls cost O(N log N), and Θ(N) decreases cost O(N²) in the worst case. Total O(N²), C; the deletion count may leave Θ(N) elements, allowing this worst case.

**Derived answer:** 64

**Source access:** Open archive member CS/CS2016.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

Height6 with seven nodes means every node lies on one chain. The first inserted value must be the smallest or largest remaining key; otherwise both subtrees would be nonempty and the tree could not be a chain. Recursively choose either endpoint for each of the first six insertions, with the last forced. This gives 2^6=64 distinct insertion orders.
