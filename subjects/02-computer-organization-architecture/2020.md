**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

Daisy chaining imposes interrupt priority, and polling periodically examines device status, so I and III are true. A vectored interrupt supplies identification/vector information rather than requiring source polling. A single shared bus has one current master, so CPU and DMA controller cannot simultaneously master that bus. Thus C in the depicted conventional bus model.

# GATE 2020 CS: Q31 (printed CS Q21)

**Question:** [Official archived paper page 8](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=8); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 13.3 to 13.3 OR 13.5 to 13.5

**Derived answer:** 13.5 or13.3 under the two accepted timing conventions

## Solution

Each block holds256/8=32 words. A complete refill takes 20+31·5=175 ns. If a miss incurs the 3 ns cache lookup before refill, AMAT=3+0.06·175=13.5 ns. If the 175 ns miss time is treated as the total miss-service time, the weighted average is 0.94·3+0.06·175=13.32 ns, rounding to 13.3. The official key explicitly accepts both13.3 and 13.5; neither is silently discarded. Both calculations assume full-block service without critical-word early restart.

The cache has 65536/256=256 lines and 64 four-way sets. Offset uses8 bits and set index6 bits, so index=(address>>8)&63. The four addresses map to sets8, 40, 40, 8, respectively. Exactly A2 and A3 share a set among the listed positive claims, B; A1 and A4 actually also share a set, contrary to A.

**Official answer:** 2.15 to 2.18

**Derived answer:** 2.16

## Solution

The non-pipelined time per instruction is 5/(2.5GHz)=2 ns. The pipeline average CPI is 1+0.30*0.05*50+0.10*0.50*2=1.85. At2GHz its average time is 1.85*0.5=0.925 ns per instruction. Speedup=2/0.925=2.162162..., or2.16, within the official2.15–2.18 range. This is the long-program steady-state calculation; the fixed pipeline fill/drain cost is neglected because program length is not supplied.

# GATE 2020 CS: Q54 (printed CS Q44)

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 14 to 14

**Derived answer:** 14

## Solution

Each register field needs 6 bits. An I-type opcode leaves10 operand bits, so 8 I-type opcodes reserve8*2^10=8192 of the 65536 instruction words. An R-type opcode needs 12 operand bits, consuming4096 words. The remaining 57344 words allow57344/4096=14 R-type opcodes. Achievability: reserve two four-bit opcode prefixes for the eight six-bit I-opcodes and use the other14 four-bit prefixes for R-type instructions.
