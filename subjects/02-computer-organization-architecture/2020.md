**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Which statements are true? I Daisy chaining assigns interrupt priority. II For a vectored interrupt CPU polls to identify the source. III Polling periodically checks device status bits. IV During DMA the CPU and DMA controller can simultaneously be masters of the bus. Options: A I,II; B I,IV; C I,III; D III only.

## Solution

Worked explanation

In a daisy chain an interrupt acknowledge passes through devices in order; the first requesting device captures it, establishing priority. In vectored handling, vector information selects the service routine, avoiding the source-identification poll claimed in II. Polling explicitly means testing device status, establishing III. DMA can overlap CPU computation that does not require the shared bus, but that is different from two simultaneous masters driving one shared bus. The conventional bus arbitration model permits one current owner, making IV false.

Derivation and answer

Daisy chaining imposes interrupt priority, and polling periodically examines device status, so I and III are true. A vectored interrupt supplies identification/vector information rather than requiring source polling. A single shared bus has one current master, so CPU and DMA controller cannot simultaneously master that bus. Thus C in the depicted conventional bus model.

**Paraphrased problem context:** Execute R0←R1+R2 on a single-bus datapath. Figure equivalent: bus connects MAR, MDR, IR, PC and R0–R7; one ALU input comes directly from bus, the other from TEMP1 (loaded from bus); ALU output enters TEMP2, which can drive bus. MAR addresses memory; MDR exchanges memory data. PC increment is handled. Steps (r read,w write): 1 R2_r,TEMP1_r,ALU_add,TEMP2_w; 2 R1_r,TEMP1_w; 3 PC_r,MAR_w,MEM_r; 4 TEMP2_r,R0_w; 5 MDR_r,IR_w. Correct order? A 2,1,4,5,3; B 1,2,4,3,5; C 3,5,2,1,4; D 3,5,1,2,4.

## Solution

Worked explanation

Follow data dependencies rather than memorizing an instruction cycle. The instruction register cannot receive the requested instruction before the PC address has been sent to memory and the result has reached MDR, so 3 precedes 5. To add two register values on one bus, first save one operand in TEMP1: step 2 must precede step 1. The ALU result is latched into TEMP2 before R0 can receive it, so 1 precedes 4. Fetch followed by execution therefore gives 3→5→2→1→4. D violates the TEMP1 dependency; A,B attempt execution before the fetch sequence.

Derivation and answer

Fetch the instruction with PC→MAR and memory read(step3), then MDR→IR(step5). Load R1 into TEMP1(step2), add R2 through the bus with TEMP1 and store the result in TEMP2(step1), then TEMP2→R0(step4). Therefore3, 5, 2, 1, 4, C. The single-bus data path and temporary-register directions were visually checked.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 13.3 to 13.3 OR 13.5 to 13.5

**Derived answer:** 13.5 or13.3 under the two accepted timing conventions

**Paraphrased problem context:** A 1 MB direct-mapped cache has 256-byte blocks, access time 3 ns, hit rate 94%, and 64-bit words. On a miss, main memory delivers the first word in 20 ns and every subsequent word in 5 ns. Find average access time to one decimal place. Official scoring accepts 13.3 or 13.5 ns as separate values.

## Solution

Worked explanation

Convert the word size first: 64 bits is 8 bytes. A block therefore contains 32 words, and the first-word latency is paid once, followed by 31 further transfers, giving 20+31×5=175 ns. Miss probability is 1−0.94=0.06. If the 175 ns is an extra miss penalty after lookup, every reference pays 3 ns and 6% pay the extra penalty. If it is the entire miss-path time instead, only the hit branch uses the separate 3 ns figure in a weighted average. These conventions produce the two official answers already preserved below. The 1 MB capacity and direct mapping are not needed once the hit rate is given. No early-restart timing is specified, so use a full refill.

Derivation and answer

Each block holds256/8=32 words. A complete refill takes 20+31·5=175 ns. If a miss incurs the 3 ns cache lookup before refill, AMAT=3+0.06·175=13.5 ns. If the 175 ns miss time is treated as the total miss-service time, the weighted average is 0.94·3+0.06·175=13.32 ns, rounding to 13.3. The official key explicitly accepts both13.3 and 13.5; neither is silently discarded. Both calculations assume full-block service without critical-word early restart.

## Solution

Worked explanation

For a normal single-precision value, decode (−1)^s×(1+fraction/2^23)×2^(E−127). R1 has s=0,E=132,fraction=0x200000, so its significand is 1+1/4=1.25 and its value is 40. R2 has s=1,E=130,the same fraction, so it is −10. Divide the represented values, not the hexadecimal integers: 40/(−10)=−4. Normalize −4 as −1.0×2², yielding sign 1, exponent 129=10000001₂ and all-zero fraction. Packing those fields gives 0x80000000+0x40800000=0xC0800000. No rounding is needed because all values are exact powers-of-two fractions.

Derivation and answer

0x42200000 represents+1.25·2⁵=40. 0xC1200000 represents−1.25·2³=−10. Their quotient is−4=−1.0·2². Its sign bit is 1, biased exponent129, fraction0, yielding0xC0800000, B.

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** A 32-bit-word system has 16 MB byte-addressable memory and a 64 KB four-way set-associative cache with 256-byte blocks. Addresses: A1=0x42C8A4, A2=0x546888, A3=0x6A289C, A4=0x5E4880. Which is true? A A1,A4 map to different sets; B A2,A3 same set; C A3,A4 same set; D A1,A3 same set.

## Solution

Worked explanation

Compute organization before extracting bits. Total cache blocks=2^16/2^8=2^8; four blocks per set gives 2^6 sets. A 24-bit physical byte address therefore divides as tag 10 bits | set 6 bits | byte offset 8 bits. Shifting each address right by 8 discards its final byte; masking the next six bits gives 0x08,0x28,0x28,0x08, or 8,40,40,8. Same set does not require equal tags or equal byte offsets, and four-way associativity does not change this index extraction. Only B among the offered statements is true.

Derivation and answer

The cache has 65536/256=256 lines and 64 four-way sets. Offset uses8 bits and set index6 bits, so index=(address>>8)&63. The four addresses map to sets8, 40, 40, 8, respectively. Exactly A2 and A3 share a set among the listed positive claims, B; A1 and A4 actually also share a set, contrary to A.

**Official answer:** 2.15 to 2.18

**Derived answer:** 2.16

**Paraphrased problem context:** A nonpipelined 2.5 GHz processor takes 5 cycles/instruction. Its five-stage pipeline runs at 2 GHz. Program mix: 30% memory,60% ALU,10% branch. Of memory instructions,5% cause 50-cycle stalls. Of branches,50% cause 2-cycle stalls. ALU instructions cause none. Find steady-state speedup to two decimals.

## Solution

Worked explanation

Use time per instruction, since the two designs have different clocks. For 1000 representative instructions, 300 are memory, of which 15 stall for 750 cycles total; 100 are branches, of which 50 stall for 100 cycles total. Add the ideal 1000 pipeline cycles to obtain 1850, or CPI=1.85. Nonpipelined cycle time is 1/2.5 GHz=0.4 ns, so an instruction takes 2 ns. Pipeline cycle time is 0.5 ns, making average time 0.925 ns. Speedup is old time/new time=2/0.925=2.162162…, rounded 2.16. Counting 5% of all instructions as cache misses would overstate the penalty because that rate is conditional on memory instructions.

Derivation and answer

The non-pipelined time per instruction is 5/(2.5GHz)=2 ns. The pipeline average CPI is 1+0.30*0.05*50+0.10*0.50*2=1.85. At2GHz its average time is 1.85*0.5=0.925 ns per instruction. Speedup=2/0.925=2.162162..., or2.16, within the official2.15–2.18 range. This is the long-program steady-state calculation; the fixed pipeline fill/drain cost is neglected because program length is not supplied.

**Official answer:** 14 to 14

**Derived answer:** 14

**Paraphrased problem context:** A processor has 64 registers and 16-bit instructions. I-type has opcode, one register and a 4-bit immediate; R-type has opcode and two registers. Given 8 I-type opcodes, what is the maximum number of distinct R-type opcodes?

## Solution

Worked explanation

A register number occupies log2 64=6 bits. I-type operands occupy 6+4=10 bits, leaving a 6-bit opcode; R-type operands occupy 12 bits, leaving a 4-bit opcode. Their opcode spaces cannot be independently filled because every complete 16-bit word needs an unambiguous interpretation. Each chosen I opcode consumes 2^10 words, so eight consume 8192. R opcodes each need 2^12 distinct operand combinations; the 57344 words left permit 14. Constructively, use four-bit prefixes 0000 through 1101 for R instructions. Reserve 1110 and 1111, extending each by two bits to obtain the eight six-bit I opcodes. This proves attainability as well as the counting bound.

Derivation and answer

Each register field needs 6 bits. An I-type opcode leaves10 operand bits, so 8 I-type opcodes reserve8*2^10=8192 of the 65536 instruction words. An R-type opcode needs 12 operand bits, consuming4096 words. The remaining 57344 words allow57344/4096=14 R-type opcodes. Achievability: reserve two four-bit opcode prefixes for the eight six-bit I-opcodes and use the other14 four-bit prefixes for R-type instructions.
