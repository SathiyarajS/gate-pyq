**Official answer:** 4 to 4

**Derived answer:** 4

**Source access:** Open archive member CS/CS2014.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

The average cycles per instruction is 1+0.25·2=1.5. A nonpipelined instruction takes six balanced stage times, so steady-state speedup is 6/1.5=4. This ignores fill/drain effects; for a finite N-instruction run with exactly N/2 stall cycles, the usual timing is 6N/(1.5N+5), approaching4.

# GATE 2014 CS1: Q54 (printed CS Q44)

**Question:** [Official archived paper page 19](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A requires strict A>k and an initially empty cache

**Source access:** Open archive member CS/CS2014.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

An LRU hit requires fewer than A distinct intervening blocks mapping to the same set. The stated bound k suffices when A>k, but not at A=k. For example, let a direct-mapped cache have A=k=1 and let distinct x, y map to the same set. The sequence x, y, x, y has N=4, n=2 and one distinct intervening block on each reuse, yet all four accesses miss, giving1 rather than n/N=1/2. Thus the official cold-miss-only answer A needs a strict inequality (or a reuse-distance definition including the reused block) and an initially empty cache.

# GATE 2014 CS2: Q53 (printed CS Q43)

**Question:** [Official archived paper page 41](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

**Source access:** Open archive member CS/CS2014.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

A smaller cache block requires fewer bytes to refill, reducing the transfer component of a miss penalty under the usual fixed-latency, finite-bandwidth memory model. Thus D is the intended statement. It does not improve the program’s inherent spatial locality, and smaller blocks do not justify a shorter tag or guaranteed lower hit time. If critical-word-first timing or fixed-size physical bursts dominate, the measured penalty need not strictly decrease; the answer uses the textbook full-block refill model.

The single bus admits at most one new store per100 ns, so in a half-open1ms interval the limit is 10^6/100=10000 initiations. The question counts stores initiated, not necessarily completed within the interval.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 1.50 to 1.60

**Derived answer:** 1.54

**Source access:** Open archive member CS/CS2014.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

The old clock period is 2.2 ns; branch resolution at the end of stage3 causes two lost fetch slots, giving average CPI1+0.2·2=1.4. The new clock period is 1 ns; resolution at stage6 causes five lost fetch slots, giving CPI1+0.2·5=2. Thus steady-state P/Q=(2.2·1.4)/(1·2)=1.54. This neglects pipeline fill/drain and latch overhead, as in the intended throughput model.

## Solution

There are160 reads including instruction fetches and 40 writes. Applying hit ratio0.9 to both classes gives read mean0.9·1+0.1·5=1.4 ns and write mean0.9·2+0.1·10=2.8 ns. The weighted mean is(160·1.4+40·2.8)/200=1.68 ns. If the stated0.9 is only the aggregate ratio, it does not determine this answer: there are20 misses total, and w write misses give total time320+4w ns, mean1.6+0.02w. Values w=0..20 all respect the aggregate ratio but yield1.6..2 ns. Official1.68 assumes w=4 or the common per-class ratio.
