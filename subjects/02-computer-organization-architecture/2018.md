**Paraphrased problem context:** Which characterize conventional RISC design? I arithmetic only register-to-register; II fixed-length instructions; III hardwired control. Choices: A I,II; B II,III; C I,III; D all three.

## Solution

Method and intermediate reasoning:

A load/store design keeps arithmetic operands in registers and uses separate instructions for memory transfers. Regular instruction lengths simplify fetching and decoding, while simple instruction semantics support direct hardwired control instead of a large microprogram. These properties work together to simplify pipelining. The question asks about the conventional design model; modern instruction-set families can have compressed encodings or other extensions without making the textbook characterization invalid.

Derivation, answer and qualifications:

The conventional RISC design combines register-to-register arithmetic, fixed-length instruction encoding and hardwired control. All three listed characteristics apply, D. These are textbook design characteristics, not a claim that every modern RISC extension has identical instruction lengths.

**Paraphrased problem context:** After an interrupt during process L: P saves L status on control stack; Q finishes current instruction; R executes ISR; S restores L status; T loads ISR PC. Choose A QPTRS; B PTRSQ; C TRPQS; D QTPRS.

## Solution

Method and intermediate reasoning:

At an instruction boundary the processor has a consistent state to save. Save that state before replacing the program counter, otherwise the return address and other status could be lost. Loading the interrupt-vector target transfers control to the handler; restoring saved state is meaningful only after the handler finishes. The model describes an ordinary precise interrupt, not an exception that aborts and restarts the current instruction.

Derivation, answer and qualifications:

Complete the current instruction(Q), save the interrupted process state(P), load the ISR entry PC(T), run the ISR(R), and restore the saved state(S). The order is QPTRS, A.

**Paraphrased problem context:** A 1 GB, 32-bit-wide memory uses 256M×4-bit DRAMs. Each chip has 2^14 rows; refreshing a row takes 50 ns and all rows must refresh every 2 ms. Find the nearest-integer percentage available for reads/writes.

## Solution

Method and intermediate reasoning:

Eight 4-bit chips operate in parallel to provide the 32-bit word. Since corresponding rows refresh together, the memory loses 16384 row-refresh slots per period, not eight times that number. Convert all durations to one unit: 2 ms=2000000 ns, and refresh consumes 819200 ns. Available time is 1180800 ns per period. Divide available time by total time, rather than reporting the refresh fraction.

Derivation, answer and qualifications:

The row refresh time per period is 2^14·50 ns=819200 ns=0.8192ms. The remaining fraction of the 2ms period is 1−0.8192/2=0.5904, or 59.04%, rounded 59%. The eight parallel 4-bit chips refresh a row together to form the 32-bit memory; their refresh times are not added serially.

**Paraphrased problem context:** Physical addresses span 2^P bytes, words have 2^W bytes, cache capacity is 2^N bytes, blocks hold 2^M words, and associativity is K. Choose tag bits: A P−N−log₂K; B P−N+log₂K; C P−N−M−W−log₂K; D P−N−M−W+log₂K.

## Solution

Method and intermediate reasoning:

A byte address has P bits. First convert block capacity from words to bytes, obtaining 2^(M+W). Cache blocks total 2^(N−M−W); grouping K per set divides this by K. Address bits split into tag, set index and byte-within-block offset. Increasing associativity at fixed capacity reduces index bits and therefore increases tag bits, a useful sign check on the log₂K term. The result assumes integral power-of-two field sizes.

Derivation, answer and qualifications:

A block contains 2^(M+W) bytes. There are 2^(N−M−W)/K sets, so index bits=N−M−W−log2K, and block-offset bits=M+W. Subtract both from P address bits: tag=P−N+log2K, B, under the conventional power-of-two cache parameters.

**Paraphrased problem context:** A pipeline is IF,ID,OF,PO,WB. Every stage except PO takes one cycle. Among 100 instructions PO takes 3 cycles for 40, 2 for 35, and 1 for 25. No data/control hazards. Find total cycles under single-occupancy PO operation.

## Solution

Method and intermediate reasoning:

Start with the ideal five-stage baseline: 100+5−1=104 cycles if every PO takes one cycle. The 40 three-cycle operations add 40·2=80 stall cycles; the 35 two-cycle operations add 35·1=35. Total is 104+80+35=219. This agrees with adding three fill cycles, all PO occupancies, and one final writeback cycle. It would be wrong to charge every instruction five separate nonoverlapped stages; most stage work overlaps.

Derivation, answer and qualifications:

The single PO stage is occupied for 40*3+35*2+25*1=215 clocks. The first instruction needs 3 clocks to reach PO through IF, ID, OF, and the final instruction needs 1 WB clock afterward. With no data/control hazards, earlier stages can supply the next instruction whenever PO becomes free, so total=3+215+1=219. This uses the intended non-overlapped PO-stage model; a separately internally pipelined execution unit would need an initiation-interval specification.

**Paraphrased problem context:** A 16-bit instruction set has 16 integer and 64 floating registers. Four type-1 instructions use 3 integer operands; eight type-2 use 2 floating operands; fourteen type-3 use 1 integer+1 floating; N type-4 use 1 floating. Find maximal N.

## Solution

Method and intermediate reasoning:

An integer register needs 4 bits and a floating register 6 bits. Operand bits are therefore 12,12,10,6 for the four categories, leaving variable opcode widths 4,4,6,10. Counting complete instruction words avoids assigning incompatible fixed-length opcodes. Each opcode must reserve all combinations of its operands. After subtracting the first three categories from the 65536 available words, divide the remaining words by 64 per type-4 instruction. The prefix construction below verifies that this counting bound can actually be encoded.

Derivation, answer and qualifications:

There are 2^16 instruction encodings. A three-integer-register instruction uses 2^12 encodings, as does a two-floating-register instruction. Each mixed register instruction uses 2^10 encodings. The remaining space is 65536−4*4096−8*4096−14*1024=2048. Each type4 opcode needs 64 encodings, so N≤2048/64=32. This bound is achievable with expanding opcodes: allocate 12 four-bit prefixes to types 1/2; the remaining 4 prefixes yield 16 six-bit prefixes, 14 for type3, leaving 2 prefixes expandable to 32 ten-bit type4 opcodes.
