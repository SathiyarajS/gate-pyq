

# GATE 2026 CS1: Q14

**Topic:** Addressing-mode correspondence.

**Question:** Consult [the original master question, page 11](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=11) for the full wording and options. This entry supplies an original solution, not a complete transcription.

**Type / marks:** MCQ, 1 mark.

**Official and derived answer:** B

## Solution

Immediate addressing encodes a literal constant in the instruction, giving P to 4. Indirect addressing obtains an address through a pointer, giving Q to 2. Base-plus-index addressing selects an array element using a varying index, giving R to 1. A fixed displacement from a record base selects a record field, giving S to 3. The matching tuple is therefore (4,2,1,3), option B.

# GATE 2026 CS1: Q15

**Topic:** Load-store instruction sequence.

**Question:** Consult [the original master question, page 12](https://gate2026.iitg.ac.in/doc/download/2026/QPs/CS1.pdf#page=12) for the full wording and options. This entry supplies an original solution, not a complete transcription.

**Type / marks:** MCQ, 1 mark.

**Official and derived answer:** D

## Solution

A load-store architecture performs arithmetic on registers, with explicit instructions moving operands between memory and registers. Load X into R0 and Y into R1, compute ADD R2,R0,R1, then store R2 into memory location Z. This is option D. Option A uses memory operands directly in ADD; B still adds a memory operand and targets memory; C likewise tries to add memory operands before storing. Those three do not obey the stated architecture.

## Q36 — Computer Organization and Architecture: binary32 addition

Paper page 25; key page 1. MCQ, 2 marks. **Answer: C, hexadecimal 35E80000.**

1. Both operands are positive normal IEEE 754 binary32 numbers. The exponent field of 35C00000 is 107, so its unbiased exponent is −20. Its fraction field is 400000, giving significand 1.5. Thus X = 1.5 × 2^−20.
2. For 34A00000 the exponent field is 105, giving unbiased exponent −22; fraction 200000 gives significand 1.25. Thus Y = 1.25 × 2^−22 = 0.3125 × 2^−20.
3. Their sum is 1.8125 × 2^−20. Since 1 ≤ 1.8125 < 2, no exponent renormalization is required. The fraction is 0.8125 = 13/16, which has an exact terminating binary expansion.
4. The exponent bits remain 107, contributing 35800000. The stored fraction is (13/16) × 2^23 = 680000 in hexadecimal. Combining the fields yields 35E80000. No rounding error occurs here.

**Computational check:** Python struct unpacked both binary32 operands and repacked their sum, obtaining 0x35e80000. This complements the exact field-level derivation; it is not the sole justification.

## Q38 — Computer Organization and Architecture: cache address fields

Paper page 27; key page 2. MCQ, 2 marks. **Answer: A, N = M + L.**

1. Byte addresses contain 32 bits. A 128-byte block needs log2(128)=7 offset bits.
2. The cache contains 2^23 / 2^7 = 2^16 blocks. In a direct-mapped organization, there are 2^16 sets, requiring 16 index bits. Hence its tag length is M=32−16−7=9.
3. K=2^L ways reduce the set count to 2^(16−L). The set index therefore uses 16−L bits while the block offset remains 7 bits.
4. The set-associative tag length is N=32−(16−L)−7=9+L=M+L.

**Common error:** Associativity changes the number of sets, not the number of bytes per block. Offset bits do not grow with the number of ways.
