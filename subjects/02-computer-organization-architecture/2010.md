

# GATE 2010: Q17 (printed CS Q7)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 2. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** A 4-megabyte main memory is built from 1M×1-bit DRAM chips. Each chip has 1K rows with 1K cells in each row. One refresh operation takes 100 ns. How long does one complete refresh of all memory cells take?
Options: (A) 100 ns; (B) 100×2^10 ns; (C) 100×2^20 ns; (D) 3200×2^20 ns.

## Solution

A refresh operation refreshes one row in each chip in parallel. Each chip has 1K=2¹⁰ rows, requiring 2¹⁰ refresh operations to cover all its cells. At 100 ns each, the total is 100·2¹⁰ ns, B. The memory needs 32 chips for 4 MiB, but the standard parallel-bank refresh model does not multiply the refresh time by 32.

Teaching detail: The row count, rather than the total cell count, determines the number of refresh commands: all 1024 cells on the selected row are refreshed together. Memory capacity determines how many chips are needed, but chips sharing refresh control perform that command concurrently in the model used here. Multiplying by 2^20 would incorrectly refresh individual cells separately.

# GATE 2010: Q43 (printed CS Q33)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 8. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** A five-stage pipeline has IF, ID, OF, PO and WO stages. IF, ID, OF and WO each take one cycle. PO takes one cycle for ADD/SUB, three for MUL and six for DIV. Operand forwarding is used. How many cycles execute this instruction sequence?
I₀: MUL R₂,R₀,R₁   (R₂←R₀×R₁)
I₁: DIV R₅,R₃,R₄   (R₅←R₃/R₄)
I₂: ADD R₂,R₅,R₂   (R₂←R₅+R₂)
I₃: SUB R₅,R₂,R₆   (R₅←R₂−R₆)
Options: (A) 13; (B) 15; (C) 17; (D) 19.

## Solution

With the single shared PO stage, the first MUL occupies PO in cycles 4–6 after IF,ID,OF in cycles 1–3. DIV occupies PO in cycles 7–12; the dependent ADD then uses the forwarded DIV result in PO cycle 13, and SUB uses PO cycle 14. The last WO is cycle 15. Earlier stages stall as necessary while PO is occupied, but forwarding avoids waiting for an extra writeback before dependent execution. Total 15, B. This assumes the ordinary unpipelined multi-cycle PO unit implicit in this question, not separate independently pipelined arithmetic units.

Teaching detail: A compact timing schedule is MUL: PO 4–6, WO 7; DIV: PO 7–12, WO 13; ADD: PO 13, WO 14; SUB: PO 14, WO 15. PO is the bottleneck and its occupied cycles sum to 3+6+1+1=11. Three initial stages plus eleven PO cycles plus the final writeback give 3+11+1=15. Forwarding handles the DIV→ADD and ADD→SUB true dependencies.

# GATE 2010: Q58 (printed CS Q48)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 12. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** An L1 cache connects to L2, which connects to main memory. Both connecting data buses are four words wide. L1 blocks contain four words; L2 blocks contain sixteen words. Access times are 2 ns for L1, 20 ns for L2 and 200 ns for main memory. On an L1 miss and L2 hit, one block is transferred from L2 to L1. What is the transfer time?
Options: (A) 2 ns; (B) 20 ns; (C) 22 ns; (D) 88 ns.

## Solution

The L1 block is 4 words and the L2–L1 bus transfers 4 words, so one bus-width transfer suffices. Under the serial source-read plus destination-write model implicit in the offered transfer-time choices, reading L2 takes 20 ns and writing L1 takes 2 ns, giving 22 ns, C. This is the block movement time, not an extra sum including a previous failed lookup. Bus width alone does not specify pipelining, write overlap or timing semantics; the result relies on this conventional serialized model.

Teaching detail: Do not use the entire 16-word L2 block as the transfer size here: the destination L1 line needs only four words, exactly one bus width. Under the stated serialized interpretation, 20 ns pays for the source access and 2 ns for the destination write. The 88 ns distractor is four times 22 ns and incorrectly moves four L1-sized pieces.

# GATE 2010: Q59 (printed CS Q49)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 12. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** An L1 cache connects to L2, which connects to main memory. Both connecting data buses are four words wide. L1 blocks contain four words; L2 blocks contain sixteen words. Access times are 2 ns for L1, 20 ns for L2 and 200 ns for main memory. On misses in both caches, a block is first transferred from main memory to L2, then a block from L2 to L1. What is the total transfer time?
Options: (A) 222 ns; (B) 888 ns; (C) 902 ns; (D) 968 ns.

## Solution

The L2 block has 16 words and the memory–L2 bus is 4 words wide, so filling it requires four transfers. Under the same non-overlapped read/write model as CS48, each costs 200 ns to read memory plus 20 ns to write L2: 4(200+20)=880 ns. The question says first fill L2, then transfer one 4-word block from L2 into L1, costing 20+2=22 ns. Total 902 ns, option C. No burst/pipelining/critical-word-first mechanism is specified; other timing models would require extra assumptions and are not used.

Teaching detail: Keep the destination line size separate at each level: filling L2 moves sixteen words, hence four memory-bus transfers; filling L1 moves four words, hence one L2-bus transfer. The total is therefore 4×220+1×22, not four times the entire two-level path. The question explicitly orders the two fills, so their durations add in the model used.
