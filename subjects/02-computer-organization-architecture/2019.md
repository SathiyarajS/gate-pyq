**Question:** [Official archived paper page 4](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=4); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** A byte-addressed processor has 32-bit addresses and a fully associative 16 kB cache with 16-byte blocks. Find tag bits and index bits, in that order. Choices: A (24,0); B (28,4); C (24,4); D (28,0).

## Solution

Method: partition the address into tag, set index, and block offset.

1. Because memory is byte-addressed, the offset selects one of the 16 bytes in a block. It requires log2(16) = 4 bits.
2. A fully associative cache has only one set containing all cache lines. Any memory block can occupy any line, so the processor address supplies no set index: log2(1) = 0 bits.
3. The remaining address bits identify which memory block is stored: tag bits = 32 − 4 − 0 = 28.
4. The 16 kB capacity determines the number of available lines, not an address index in this organization. Interpreting kB as 1024 bytes gives 1024 lines, all compared associatively.

Result: D, 28 tag bits and 0 index bits. The four low-order bits are an offset, not an index.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** Sixteen address lines are A15 through A0. A five-input AND chip-select gate receives A15, A14, inverted A13, inverted A12, and A11. Which address range enables the chip? Choices: A C800–CFFF; B CA00–CAFF; C C800–C8FF; D DA00–DFFF, all hexadecimal.

## Solution

Method: turn the gate into fixed high-order bits and let every unused low-order address bit vary.

1. The active-high AND output is CS = A15 AND A14 AND NOT A13 AND NOT A12 AND A11. It is 1 only when A15…A11 = 11001.
2. Address lines A10…A0 do not enter the gate. Their 11 bits may take any values, giving 2^11 = 2048 consecutive addresses for the selected chip.
3. The lowest address sets those bits to zero: 1100 1000 0000 0000 in binary, or C800 in hexadecimal.
4. The highest address sets them all to one: 1100 1111 1111 1111, or CFFF. The number of addresses is CFFF − C800 + 1 = 0800 hexadecimal = 2048, agreeing with step 2.

Result: A, C800 through CFFF inclusive. The circles on A13 and A12 are inversions, so those original address lines must be zero, not one.

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 160 to 160

**Derived answer:** 160

**Paraphrased problem context:** A cache block contains 8 words of 4 bytes each. With a 60 MHz memory clock, serial miss service uses 1 cycle to accept the address, 3 cycles to fetch the block, then transmits 1 word per cycle. Find maximum bandwidth as a coefficient of 10^6 bytes/s.

## Solution

1. Compute useful bytes per completed block: 8 words×4 bytes/word=32 bytes. Clock frequency is 60×10^6 cycles per second.
2. The description gives successive stages, so their times add. Address acceptance takes 1 cycle, block fetching takes 3, and sending eight words at one per cycle takes 8. Total service time is 1+3+8=12 cycles per block.
3. The completed-block rate is (60×10^6)/12=5×10^6 blocks/s. Multiplying by 32 bytes/block gives 160×10^6 bytes/s.
4. Thus the requested numeric coefficient is 160. Equivalently, one block takes 12/(60×10^6)=200 ns, and 32 bytes/200 ns gives the same bandwidth.
5. Counting only the eight transfer cycles would incorrectly ignore the four-cycle overhead. Conversely, interpreting the three fetch cycles as three per word would contradict the stated fetch of all eight words. This calculation assumes the sequential per-block controller service described; overlapping different block transactions would require a separate pipelining model not specified here.
