

# GATE 2019 CS: Q11 (printed CS Q1)

**Question:** [Official archived paper page 4](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=4); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

## Solution

A16-byte block needs 4 offset bits. Full associativity uses no index bits, so a 32-bit address leaves28 tag bits. Thus28, 0, D.

# GATE 2019 CS: Q12 (printed CS Q2)

**Question:** [Official archived paper page 4](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=4); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

The chip-select AND gate fixes A15..A11 to 11001, with A13 and A12 inverted. The remaining 11 address bits vary freely, so the range is C800 through CFFF, A.

# GATE 2019 CS: Q55 (printed CS Q45)

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 160 to 160

**Derived answer:** 160

## Solution

A block contains8*4=32 bytes. The specified serial miss service takes 1 address cycle+3 fetch cycles+8 transmission cycles=12 cycles. At60MHz it therefore transfers32*60, 000, 000/12=160, 000, 000 bytes/second. The requested coefficient of 10^6 is 160. This follows the sequential per-block service described; overlapping multiple block transactions would be a different controller model.
