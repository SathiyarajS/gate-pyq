**Question:** [Official archived paper page 11](https://web.archive.org/web/20220204093545id_/https://gate.iitkgp.ac.in/documents/gatepapers/2011/cs_2011.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Source access:** Archived official IIT Kharagpur paper and IIT Madras key, booklet A. Physical PDF page numbers are used; code A is the matching key column. Final-revision designation is unverified.

## Solution

The non-pipelined combinational delay is 5+6+11+8=30 ns. The pipelined clock period is determined by the slowest stage plus its pipeline-register delay: 11+1=12 ns. In ideal steady state one instruction completes every 12 ns, so the conventional throughput speedup is 30/12=2.5, option B. If the non-pipelined implementation also counts a final 1 ns output register, the ratio is 31/12≈2.58, still the same approximate option. This is steady-state throughput, not the latency speedup of one instruction.

**Question:** [Official archived paper page 11](https://web.archive.org/web/20220204093545id_/https://gate.iitkgp.ac.in/documents/gatepapers/2011/cs_2011.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

**Source access:** Archived official IIT Kharagpur paper and IIT Madras key, booklet A. Physical PDF page numbers are used; code A is the matching key column. Final-revision designation is unverified.

## Solution

There are 8192/32=256 cache lines, requiring 8 index bits. A 32-byte block requires 5 byte-offset bits, leaving 32−8−5=19 address-tag bits. Add one valid bit and one modified (dirty) bit per line: 21 bits per line. The metadata memory is therefore 256×21=5376 bits, option D. Data storage itself is not included.
