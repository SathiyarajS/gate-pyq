

# GATE 2024 CS1: Q15

**Question:** [Official archived paper page 10](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=10); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

Programmed I/O occupies the CPU polling or waiting for device readiness, whereas interrupt-driven I/O lets it execute other work until service is needed. Thus the claimed better utilization is false in the standard comparison. Cycle stealing transfers one word per stolen bus cycle; burst DMA amortizes arbitration for higher bulk throughput; vectored interrupts supply a handler address rather than requiring software identification. Answer C.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;B;C

**Derived answer:** A;B;C

## Solution

Forwarding bypasses the register-file write/read round trip by taking an earlier instruction’s result from a pipeline stage to a later instruction’s needed input. MEM-output to EX-input is one such path. A load-use dependency in the usual five-stage design can still require a bubble, and structural/control hazards also remain, so forwarding does not remove every stall. Bypass multiplexers, wires, comparators, and control logic are additional hardware. Thus A, B, C.

# GATE 2024 CS1: Q53

**Question:** [Official archived paper page 33](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=33); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

## Solution

A write-through cache keeps main memory updated on writes, so an ordinary replacement after a read miss has no dirty victim requiring write-back: B. A write hit in a write-back cache can turn a clean block dirty: C. A is false because LRU can select a dirty block after a read miss and must write it back. D is false because write-through victims do not require unconditional write-back; on a write miss the policy may also be no-write-allocate. Answer B, C, assuming the usual completed-write model.

**Official answer:** 4096 to 4096

**Derived answer:** 4096

## Solution

A cylinder has one track per surface. Each track stores4096×1024=2²² bytes, so 32 surfaces give2²⁷ bytes per cylinder. Taking GB in the binary capacity convention used by the key, the disk has 512×2³⁰=2³⁹ bytes. Cylinders=2³⁹/2²⁷=4096. A decimal GB convention would give a different nonintegral result, so the binary convention is explicit.

## Solution

With k cores, serial work takes 10 ns, parallel work takes 90/k ns, and the k−1 additional cores cost10(k−1)ns. Total T(k)=90/k+10k. Its derivative is−90/k²+10, which vanishes at k=3; the second derivative180/k³ is positive. Thus the integer minimum is 3 cores, with 60 ns versus65 ns for2 and 62.5 ns for4. This uses additive per-extra-core overhead as intended.

**Official answer:** 29.50 to 30.50

**Derived answer:** 30.06

## Solution

At6000RPM one revolution takes 60/6000=0.01s=10ms. Mean rotational latency is 5ms; one of 500 sectors transfers in 10/500=0.02ms. Using a separate average seek and rotational wait for each randomly placed sector gives 3000×(5+5+0.02)ms=30060ms=30.06s. This is an average random-read estimate, not a guaranteed realized time; cache, scheduling and correlated sector positions are not modeled.
