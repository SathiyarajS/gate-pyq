

# GATE 2024 CS1: Q15

**Question:** [Official archived paper page 10](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=10); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Which statement is false? A Cycle-stealing DMA transfers one word between an I/O device and memory in a stolen cycle. B Burst DMA offers higher bulk-transfer throughput than cycle stealing. C Programmed I/O uses the CPU better than interrupt-driven I/O. D Vectored interrupts can start their service routine faster than non-vectored interrupts.

## Solution

Approach: Compare what the CPU must do while an I/O device is not ready, then check the other hardware statements.
1. In programmed I/O the CPU repeatedly polls device status and performs the transfer itself. Time spent waiting or polling is unavailable for useful work on other tasks.
2. With interrupt-driven I/O, the CPU can execute other work until the device signals that attention is required. In the standard comparison used here, this improves CPU utilization. Thus C reverses the expected relationship and is false.
3. Cycle stealing grants DMA a bus cycle for a word transfer, supporting A. Burst DMA keeps the bus for a block, reducing repeated arbitration overhead and supporting B for bulk traffic.
4. A vectored interrupt identifies the appropriate handler through a vector, whereas a non-vectored mechanism needs additional identification or dispatch. This supports D.
Answer: C. These are textbook comparisons under comparable conditions, not a claim that interrupt overhead is zero for every workload.

# GATE 2024 CS1: Q30

**Question:** [Official archived paper page 19](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=19); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;B;C

**Derived answer:** A;B;C

**Paraphrased problem context:** A processor has IF, ID, EX, MEM and WB pipeline stages. Which forwarding claims are correct? A An earlier instruction's result is passed from a source stage to a later instruction's destination stage. B MEM output can feed the next instruction's EX input. C Forwarding does not prevent every pipeline stall. D Forwarding needs no extra hardware.

## Solution

Approach: Forwarding supplies a computed value before the normal register-file writeback/read sequence has completed.
1. A later instruction may need a value that an earlier instruction has produced but has not yet written to the architectural register file. A bypass path sends that result directly to the consumer's appropriate stage. This is A.
2. A result available at the output of MEM can be routed to an EX input in a following cycle through pipeline registers and bypass selection. Thus B describes a valid forwarding path.
3. Availability still matters: in the usual five-stage pipeline, a load's value arrives too late for the immediately following instruction's EX stage without a load-use bubble. Control hazards and resource conflicts are not universally removed either. Therefore C is true.
4. Forwarding requires extra wires, multiplexers, register-number comparators and control logic to choose the correct source. D is false.
Answer: A, B and C. Forwarding reduces some data-hazard stalls; it does not eliminate timing constraints.

# GATE 2024 CS1: Q53

**Question:** [Official archived paper page 33](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=33); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

**Paraphrased problem context:** Two set-associative caches use LRU replacement. WBC is write-back; WTC is write-through. Which are true? A A WBC read miss never evicts a dirty block. B A WTC read miss never writes a victim block back to memory. C A WBC write hit can change a dirty bit. D A WTC write miss always writes its victim back before loading a block.

## Solution

Approach: Replacement policy selects the victim, whereas write policy determines whether the victim may contain newer data than main memory.
1. In a write-back cache, a write can modify the cached block without immediately updating memory. The dirty bit records this mismatch. On a write hit to a clean block, the bit can change from 0 to 1, proving C.
2. LRU selection does not guarantee a clean victim. A read miss can evict a dirty write-back block, which must then be written to memory. A's “never” is false.
3. Write-through propagates each write to memory, so a replaced cache block does not need an eviction-time dirty-block write-back in the standard completed-write model. Hence B is true.
4. D is false for the same reason. Moreover, a write-through cache may use no-write-allocate, in which case a write miss need not load a new block or select a cache victim at all.
Answer: B and C. Write-through memory traffic caused by the current write is not the same thing as writing back an evicted dirty block.

# GATE 2024 CS1: Q54

**Question:** [Official archived paper page 33](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=33); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4096 to 4096

**Derived answer:** 4096

**Paraphrased problem context:** A hard disk has capacity 512 GB, 32 storage surfaces, 4,096 sectors per track and 1,024 bytes per sector. How many cylinders does it contain? Use the binary capacity convention underlying the official answer.

## Solution

Approach: A cylinder is the collection of tracks at one radial position across all storage surfaces. Compute bytes per cylinder before dividing total capacity.
1. One track contains 4,096×1,024=2¹²×2¹⁰=2²² bytes.
2. A cylinder contains one track on each of 32=2⁵ surfaces, so its capacity is 2⁵×2²²=2²⁷ bytes. The stated surface count is already the number of recording surfaces; it must not be doubled again.
3. Under the question's intended binary convention, 512 GB=512×2³⁰=2³⁹ bytes.
4. Number of cylinders = total bytes / bytes per cylinder = 2³⁹/2²⁷=2¹²=4,096.
Answer: 4096. Strict decimal GB would mean 512×10⁹ bytes and would produce approximately 3814.697 cylinders, not the key's integer. The binary convention is therefore made explicit rather than silently treating the two unit definitions as identical.

# GATE 2024 CS1: Q55

**Question:** [Official archived paper page 33](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=33); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 3 to 3

**Derived answer:** 3

**Paraphrased problem context:** A program takes 100 ns on one 2 GHz core. Work accounting for 90% of that time parallelizes fully and is shared equally among cores. Every additional core adds 10 ns overhead. How many cores minimize total execution time?

## Solution

Approach: Write a total-time function containing serial work, divided parallel work, and overhead for cores beyond the first.
1. The serial part takes 10 ns regardless of core count. With k≥1 cores, the parallel part takes 90/k ns.
2. There are k−1 additional cores, so overhead is 10(k−1) ns. Thus T(k)=10+90/k+10(k−1)=90/k+10k ns.
3. Treating k temporarily as continuous, T'(k)=−90/k²+10. The stationary point is k²=9, so k=3. Since T''(k)=180/k³>0, this is the unique continuous minimum.
4. It is also a valid integer choice. Check its neighbors: T(2)=65 ns, T(3)=60 ns, T(4)=62.5 ns. The derivative is negative before 3 and positive afterward, excluding more distant improvements.
Answer: 3 cores. The 2 GHz rate is not needed because the baseline and overhead are already specified in time units. Ignoring overhead would incorrectly suggest that more cores always help.

# GATE 2024 CS1: Q56

**Question:** [Official archived paper page 33](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=33); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 3.00 to 3.00

**Derived answer:** 3.00

**Paraphrased problem context:** A program has 25% load/store instructions. Ideal CPI is 2; instruction-cache miss rate is 2%; data-cache miss rate is 8%; every miss costs 100 cycles. Find the speedup with perfect instruction and data caches, rounded to two decimals.

## Solution

Approach: Express every stall contribution per executed instruction so they can be added to the base CPI.
1. Every instruction requires an instruction fetch. Instruction-cache stalls therefore contribute 0.02 misses/instruction ×100 cycles/miss=2 cycles/instruction.
2. Only 25% of instructions access data memory. Data-cache stalls contribute 0.25 accesses/instruction ×0.08 misses/access ×100 cycles/miss=2 cycles/instruction.
3. With the stated additive, nonoverlapped miss-penalty model, actual CPI=ideal CPI+instruction stalls+data stalls=2+2+2=6.
4. Perfect caches remove both stall terms and restore CPI=2. With the same instruction count and clock rate, execution time is proportional to CPI, so speedup=old time/new time=6/2=3.
Answer: 3.00. Using 8% for every instruction would overcount data misses. The reciprocal 2/6 is the new-to-old time ratio, not the speedup factor.

A exponent 01111111, 23 fraction bits all 1; B exponent 11111110, fraction all 1; C exponent 11111111, fraction all 1; D exponent 01111111, fraction all 0.

## Solution

Approach: Classify special encodings before comparing the ordinary positive values.

1. Derivation. For a normal binary32 value the magnitude is(1+fraction)×2^(E−127). B has the largest finite exponent254 and an all-one fraction, giving(2−2⁻²³)×2¹²⁷, the largest finite positive binary32 value. A is just below2; D is 1. For B the biased exponent 254 becomes 127, and the fraction sum is 1−2^−23, giving significand 2−2^−23. A instead has actual exponent zero, and D has both exponent zero and fraction zero, so both are much smaller.

# GATE 2024 CS2: Q31

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** Instructions have destination first: I1 DIV R3,R1,R2; I2 SUB R5,R3,R4; I3 ADD R3,R5,R6; I4 MUL R7,R3,R8. Which are true? A I1→I2 RAW on R3; B I1→I3 WAR on R3; C I2→I3 RAW on R3; D I3→I4 WAW on R3.

## Solution

Approach: Write down which instruction produces a register and which consumes it; retain the stated register name.

1. Derivation. I1 writes R3 and I2 reads R3, a read-after-write dependency, so A is true. I1 and I3 both write R3, making their relation WAW rather than WAR. I2 reads R3 and I3 writes it, giving WAR on R3 (they also have RAW on R5). I3 writes R3 and I4 reads it, giving RAW rather than WAW. Only A.

2. Explanation and checks. On R3 the four operations are write, read, write, read. A later read after an earlier write is RAW, two writes give WAW, and a write after an earlier read gives WAR. This sequence directly classifies each proposed pair. Although I2→I3 does have a RAW dependency on R5, option C explicitly says R3 and is therefore false. A dependency is a program-order relationship; whether it produces an actual stall depends on the implementation.

## Solution

Approach: For each random sector add average seek, half a revolution, and one-sector transfer time.

The sector byte count cancels if transfer speed is computed as 500×512 bytes per revolution and divided into a 512-byte request. Because locations are random, the intended model charges seek and rotation for every sector rather than only once for a contiguous file. The derived 30.06 lies inside the preserved official acceptance range 29.50–30.50.

## Solution

Approach: Reserve enough binary codes for each independent fixed-width field, then count the remaining opcode patterns.

1. Derivation. Each of 16 registers requires4 bits, so the two register fields use8 bits. Eight addressing modes require3 bits and the scalar field uses16. The opcode therefore has 32−8−3−16=5 bits, supporting2⁵=32 unique opcodes for each mode under the separate fixed-field format.

2. Explanation and checks. A register identifier uses ceil(log2 16)=4 bits even though an operand value may occupy many more bits. The two fields therefore cost eight bits, not sixteen or thirty-two. The mode field needs ceil(log2 8)=3 bits. After allocating these and the scalar there are five opcode bits. The question asks per addressing mode, so the eight mode patterns are not multiplied into the number of distinct opcode-field encodings.

**Question:** [Official archived paper page 39](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=39); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 34 to 34

**Derived answer:** 34

**Paraphrased problem context:** A 32-bit ISA has 150 instructions, 75 each of R-type and I-type, and 50 registers. OPCODE includes a 1-bit type tag plus operation bits. R-type fields: OPCODE, UNUSED, DST, SRC1, SRC2. I-type: OPCODE, DST, SRC, immediate/address. Equal-sized register fields are used. If UNUSED, OPCODE and immediate/address sizes are X,Y,Z, find X+2Y+Z.

## Solution

Approach: Count the operation bits within each type, add the type bit, then subtract register fields from each format.

1. Derivation. There are75 operations per instruction type, requiring7 operation bits plus the 1-bit type tag, so Y=8. Each of 50 architectural registers requires6 bits. The R-type unused field has X=32−8−3×6=6 bits; the I-type immediate field has Z=32−8−2×6=12 bits. Hence X+2Y+Z=6+16+12=34.

2. Explanation and checks. Six bits encode only 64 operations, insufficient for 75, so seven operation bits are necessary. The one-bit type discriminator brings the full opcode width to eight. Similarly five register bits encode only 32 names, while six accommodate 50. The R-type equation is X+Y+18=32 and the I-type equation is Y+12+Z=32. Adding those equations directly gives X+2Y+Z=64−30=34, which independently checks the field-by-field calculation.
