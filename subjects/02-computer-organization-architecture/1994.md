

# GATE 1994: Q31 (printed A Q2.7)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=3), physical page 3. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** fill-in, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** −2^(n−1) ≤ N ≤ 2^(n−1)−1

**Essential problem context (paraphrased):** Give the representable integer range of an n-bit two’s-complement word, including the sign bit.

## Solution

The most significant bit has weight −2^(n−1); the remaining bits have positive weights 1,2,…,2^(n−2). The smallest value sets only the sign bit, giving −2^(n−1). The largest clears it and sets all remaining bits, whose sum is 2^(n−1)−1. Thus the range has one more negative value than positive value. Zero uses one of the 2^n codes, and there is no separate negative-zero representation.

# GATE 1994: Q35 (printed A Q3.1)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Official answer:** Not available; no official key located.

**Independently derived answer:** False

**Essential problem context (paraphrased):** True or false: multiplexing address/data lines in the 8085 reduces instruction execution time.

## Solution

The same AD0–AD7 pins carry low address bits during the address phase and data during later transfer phases. This saves package pins and wiring, not instruction time. An external latch controlled by ALE preserves the address while the pins are reused for data. Sharing lines can require additional timing constraints rather than making access intrinsically faster. Therefore the asserted speed benefit is false; the principal design tradeoff is interface cost and pin count.

**Official answer:** Not available; no official key located.

**Independently derived answer:** False in the conventional RISC/CISC distinction

**Essential problem context (paraphrased):** True or false: expanding-opcode instruction formats are commonly employed in RISC machines.

## Solution

An expanding opcode reuses bits otherwise needed for operands to distinguish more operations in formats with fewer operands. This increases encoding flexibility but complicates decoding and produces less uniform formats. Conventional RISC emphasizes regular, often fixed-length instructions and straightforward decoding, so expanding opcodes are associated more with complex instruction-format designs. The statement is a textbook architectural tendency, not a prohibition: real instruction sets may mix features, and “RISC” is not a formal theorem excluding every variable-format encoding.

# GATE 1994: Q56 (printed B Q10)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Use ADD/DAA for the low byte and ADC/DAA for the high byte; final CY is decimal overflow.

**Essential problem context (paraphrased):** Write 8085 assembly to add two unsigned 16-bit packed 8-4-2-1 BCD operands in register pairs BC and DE. Place the result in BC; the higher register contains the higher-order decimal digits.

## Solution

1. Each packed byte holds two decimal digits. First add C and E in A; DAA adjusts the binary sum into valid packed BCD and supplies the carry into the next two digits.

2. MOV C,A saves the low result without changing flags. MOV A,B also preserves the carry, allowing ADC D to add high bytes plus the low-byte decimal carry.

3. A second DAA adjusts the upper digits. MOV B,A preserves the final carry flag. BC now contains the lowest four decimal digits.

4. A sum above 9999 cannot fit in BC. The fifth digit is final CY (0 or 1); the question supplies no separate overflow destination. This limitation must not be concealed.

Code:
MOV A,C
ADD E
DAA
MOV C,A
MOV A,B
ADC D
DAA
MOV B,A

# GATE 1994: Q58 (printed B Q12(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** XOR R1,R2; XOR R2,R1; XOR R1,R2.

**Essential problem context (paraphrased):** A CPU has only R1,R2 and instruction XOR Ri,Rj, meaning Ri←Ri XOR Rj for i,j∈{1,2}. Give a sequence that exchanges R1 and R2.

## Solution

1. Execute XOR R1,R2; XOR R2,R1; XOR R1,R2, in that order.

2. Let the original contents be a,b. After the first instruction the pair is (a XOR b,b).

3. After the second it is (a XOR b,b XOR (a XOR b))=(a XOR b,a).

4. After the third it is ((a XOR b) XOR a,a)=(b,a), using associativity and x XOR x=0. No temporary register is needed.
