

# GATE 2025 CS1: Q11

**Question:** [Official archived paper page 10](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=10); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** A non-pipelined single processor receives an asynchronous device interrupt while running a program. Order these steps: (i) save the program counter, (ii) load the ISR start address into the program counter, (iii) finish the current instruction. A iii,i,ii; B i,iii,ii; C i,ii,iii; D iii,ii,i. Options C and D continue on source page 11.

## Solution

Approach: Preserve a consistent return point before redirecting instruction execution.
First finish the instruction already in progress: step iii. In the usual instruction-boundary interrupt model, this leaves the program’s architectural state consistent and determines the address at which it must resume. Interrupts are asynchronous arrivals, but service is begun at an instruction boundary.
Next save the program counter containing that resume address: step i. Finally load the ISR entry address into the program counter: step ii. Fetching now begins in the interrupt routine, and the saved address remains available for return.
The sequence is iii,i,ii, option A. B and C save before the current instruction has completed; D overwrites the return address with the ISR address before saving it. This ordering describes the stipulated simple processor, not an attempt to interrupt halfway through a partially completed instruction.

# GATE 2025 CS1: Q27

**Question:** [Official archived paper page 27](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=27); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;B;C

**Derived answer:** A;B;C

**Paraphrased problem context:** Two independent multiplexers feed an ALU. Mux_A selects either 32-bit register RA or a 32-bit immediate; Mux_B selects either 32-bit register RB or another 32-bit immediate. The ALU writes a 32-bit register RZ. Which are supported? A two register operands; B one register and one immediate; C two immediate operands; D only one-register/one-immediate operations.

## Solution

Approach: Enumerate independent multiplexer settings instead of assuming the instruction formats of a familiar processor.
Selecting RA at Mux_A and RB at Mux_B gives two register operands, so A is supported. Selecting RA and the B-side immediate, or the A-side immediate and RB, gives one register and one immediate; B is supported. Selecting the immediate input at both multiplexers gives two immediate operands, so C is supported as well.
All selected values are 32 bits and can be delivered simultaneously to the ALU, whose result goes to RZ. No data connection in the shown partial datapath forces a mux to choose a register merely because the other mux chose an immediate.
Thus select A,B,C. D is false because its word “only” excludes the other two combinations. This is a claim about the available datapath connections, not proof that a particular instruction-set encoding actually exposes every such combination.

# GATE 2025 CS1: Q36

**Question:** [Official archived paper page 36](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=36); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** A byte-addressable system has 1 MiB of main memory, 20-bit addresses, and a 16 KiB direct-mapped cache with 16-byte blocks. How many bits store the tag values for all lines, excluding other metadata? A 6×2^10; B 8×2^10; C 2^12; D 2^14. Here K=2^10 and M=2^20.

## Solution

Approach: Split an address into tag, cache-line index and byte offset; then multiply tag width by the number of lines.
A 16-byte block requires log₂16=4 offset bits. The cache contains 16 KiB/16 bytes=2^14/2^4=2^10 lines, so direct mapping requires 10 index bits to select a line.
From the 20 address bits, the remaining tag width is 20−10−4=6 bits. Every line needs its own stored tag to distinguish the main-memory blocks that map to that line. Therefore total tag storage is 2^10×6=6144 bits, option A.
This is a bit count, not a byte count. The 16 KiB cache size describes data capacity; valid bits, dirty bits and other control metadata are not part of the requested tag values. Ignoring the block offset or using the number of bytes instead of lines would produce the wrong tag width or multiplier.

# GATE 2025 CS1: Q37

**Question:** [Official archived paper page 37](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=37); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** A processor has 64 general-purpose registers, 50 instruction types, and fixed 32-bit instructions. For ADD R1,#25, meaning R1=R1+25, what is the maximum immediate field width in the conventional fixed-width opcode/register-field model? A 16; B 20; C 22; D 24 bits.

## Solution

Approach: Reserve the minimum bits needed for the opcode and the explicitly encoded register, then assign the remainder to the immediate.
There must be at least 50 opcode patterns. Five bits provide only 32 patterns, while six provide 64, so the opcode requires ceil(log₂50)=6 bits. Selecting among 64 registers requires log₂64=6 bits.
This two-address instruction uses R1 both as a source and as the destination; the same register is encoded once, not in two independent fields. Thus the immediate can occupy 32−6−6=20 bits, option B.
The calculation assumes a uniform opcode field and no additional mode or reserved fields, as intended by the question. A 16-bit immediate would leave unused capacity under those assumptions, while 22 or 24 bits would not leave enough room for both required fields. An instruction-set design with variable-length opcodes would need additional specification before such a maximum could be established.

# GATE 2025 CS1: Q53

**Question:** [Official archived paper page 53](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=53); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 11.83 to 11.87

**Derived answer:** 11.85

**Paraphrased problem context:** Memory is searched in order L1,L2,main memory. L1 has 95% hit rate and 10 ns access time. L2 has 85% hit rate conditional on an L1 miss; its 20 ns time already includes the L1 miss penalty. Main-memory access is 200 ns including both cache miss penalties. Find average access time in ns to two decimals.

## Solution

Approach: Partition accesses into mutually exclusive completion paths and weight the total time of each path.
An L1 hit has probability 0.95 and total time 10 ns. An L1 miss followed by an L2 hit has probability 0.05×0.85=0.0425 and total time 20 ns. Missing both caches has probability 0.05×0.15=0.0075 and total time 200 ns. These probabilities sum to 1.
The expected time is therefore 0.95×10+0.0425×20+0.0075×200=9.50+0.85+1.50=11.85 ns.
The word “including” in the diagram is essential: adding 10 ns again to the L2 or memory path would double-count time already included. Likewise the 85% L2 hit rate applies only to accesses reaching L2, not to all processor requests. The visually verified diagram supports 11.85, within the preserved official range 11.83–11.87.

# GATE 2025 CS2: Q28

**Question:** [Official archived paper page 22](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=22); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** Select the processor properties that belong to its Instruction Set Architecture (ISA).
Options: A. cache capacity; B. processor clock frequency; C. number of cache levels; D. total number of registers.

## Solution

An ISA is the programmer-visible contract implemented by a processor, including instruction meanings, operand formats, and architectural registers. Therefore the number of registers that machine instructions can name belongs to that contract, making D the intended selection.

Cache capacity and the number of cache levels are generally microarchitectural implementation choices. Two processors may execute the same machine code while using different cache hierarchies. Clock frequency likewise affects execution speed, but is not a definition of the instruction set. Thus A, B, and C are not ISA properties in this question.

There is a necessary terminology qualification: “total number of registers” must mean the architectural register set. Physical registers used for renaming, pipeline latches, and other hidden internal storage need not be specified by the ISA and can vary across implementations. Under the intended architectural interpretation, select D only.

# GATE 2025 CS2: Q32

**Question:** [Official archived paper page 25](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=25); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 13 to 13

**Derived answer:** 13

**Paraphrased problem context:** Ordinary radix-2 Booth multiplication is applied to signed 16-bit two's-complement operands M=1100 1101 1110 1101 and Q=1010 0100 1010 1010. How many additions and subtractions of the multiplicand occur in total? Count arithmetic operations, not shifts.

## Solution

In radix-2 Booth multiplication append q_(−1)=0 to the multiplier and inspect (q_i,q_(i−1)) for i=0,…,15. A pair 01 causes addition of M, 10 causes subtraction of M, and 00 or 11 causes neither. Each iteration still performs its arithmetic right shift, but shifts are not included in the question's count. The count depends on the multiplier's bit transitions, not on the value of M.

Read Q from its least significant end. The positions producing subtraction (10) are i=1,3,5,7,10,13,15, seven positions. The positions producing addition (01) are i=2,4,6,8,11,14, six positions. The remaining positions i=0,9,12 have equal adjacent bits and require no arithmetic update.

Thus there are 7+6=13 additions/subtractions during the 16 iterations. Do not append an extra seventeenth correction for the leading one: the fixed-width signed Booth algorithm already handles that sign bit through its arithmetic shifts. Answer: 13.

# GATE 2025 CS2: Q39

**Question:** [Official archived paper page 30](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=30); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** A byte-addressable system has a direct-mapped cache. Addresses contain 4 tag bits and 12 cache-index bits; each cache block holds one byte. Choose main-memory address capacity and cache data capacity, respectively.
Options: A. 64 KB,4 KB; B. 128 KB,16 KB; C. 64 KB,8 KB; D. 128 KB,6 KB. Use KB=1024 bytes. The original wording says no other information is stored per block.

## Solution

A one-byte block needs log2(1)=0 block-offset bits. Therefore each address has tag+index+offset=4+12+0=16 bits. With byte addressing it identifies 2^16 bytes, or 65536 bytes=64 KB of main memory.

The 12 index bits select one of 2^12=4096 cache lines. Each line holds one byte of data, so the cache data capacity is 4096 bytes=4 KB. This gives A.

Distinguish data capacity from total physical storage. The tag itself occupies 4 bits per line, so explicitly counting stored tags would add 4096·4 bits=2048 bytes=2 KB, making 6 KB before any other metadata. The offered correct option and standard cache-capacity convention use data bytes only. The original “no other information” wording does not turn the 4 tag bits into addressable data, and no option pairs the 64-KB address space with 6-KB physical storage. Answer: A under the stated data-capacity interpretation.

# GATE 2025 CS2: Q49

**Question:** [Official archived paper page 38](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=38); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A;B;C

**Derived answer:** A;B;C

**Paraphrased problem context:** IEEE 754 binary32 registers hold RX=0xC1100000, RY=0x40C00000, RZ=0x41400000, representing numbers X,Y,Z. Select true equations.
A. 4(X+Y)+Z=0. B. 2Y−Z=0. C. 4X+3Z=0. D. X+Y+Z=0.

## Solution

For a normal binary32 number, value=(−1)^s·(1+f/2^23)·2^(e−127), where s is the sign bit, e the 8-bit biased exponent, and f the 23-bit fraction integer.

RX has s=1, e=130, and f=0x100000=2^20. Its fractional contribution is 2^20/2^23=1/8, so X=−(1+1/8)·2^3=−9. RY has s=0,e=129,f=0x400000=2^22, giving Y=(1+1/2)·2^2=6. RZ has s=0,e=130 and the same fraction, giving Z=(1+1/2)·2^3=12.

Now evaluate the choices directly: A gives 4(−9+6)+12=−12+12=0; B gives 2·6−12=0; C gives 4·(−9)+3·12=−36+36=0. D gives −9+6+12=9, not zero. These small integer values and intermediate results are exactly representable, so floating-point rounding does not change the conclusions. Select A,B,C.

# GATE 2025 CS2: Q55

**Question:** [Official archived paper page 43](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=43); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 4.0 to 4.0

**Derived answer:** 4.0

**Paraphrased problem context:** A two-level cache has L1 access time 1 ns and hit rate 90%. Conditional on reaching L2, its hit rate is 80%; the L1-miss transfer/access penalty through L2 is 10 ns. An L2 miss adds 100 ns to transfer from main memory. Find average memory access time in ns, to one decimal place, using additive miss penalties.

## Solution

Always pay the 1-ns L1 lookup. With probability 1−0.9=0.1, an L1 miss adds 10 ns for the next level. Of those L1 misses, a fraction 1−0.8=0.2 also miss L2 and incur the additional 100 ns. Therefore
AMAT=1+0.1[10+0.2·100]=1+0.1·30=4.0 ns.

An equivalent path-probability calculation makes the nesting clear. L1 hits occur with probability 0.9 and cost 1 ns. L1 miss/L2 hit occurs with probability 0.1·0.8=0.08 and costs 1+10=11 ns. Misses in both levels occur with probability 0.1·0.2=0.02 and cost 1+10+100=111 ns. Their weighted sum is 0.9·1+0.08·11+0.02·111=4.0 ns.

The L2 hit rate is conditional on an L1 miss, not a separate 80% of all requests. Also, the stated miss penalties are additional times; treating them as inclusive complete-path times would describe a different model. Answer: 4.0.

# GATE 2025 CS2: Q56

**Question:** [Official archived paper page 43](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=43); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 260.20 to 261.20

**Derived answer:** 261.04

**Paraphrased problem context:** A five-stage pipeline has stage delays 180,250,150,170,250 ns. Each inter-stage latch adds 10 ns. With no stalls, how long does execution of 1000 instructions take, in microseconds to two decimal places?

## Solution

A synchronous pipeline clock must allow its slowest stage plus the latch overhead to complete. Thus T_clock=max(180,250,150,170,250)+10=260 ns. Adding all five stage delays would instead describe an unpipelined or differently timed design; faster stages must still wait for this common clock.

The first instruction completes after five cycles. Once the pipeline is full, one further instruction completes per cycle, so 999 additional instructions take 999 more cycles. Total cycles=k+n−1=5+1000−1=1004.

Execution time is 1004·260=261040 ns. Dividing by 1000 ns per microsecond gives 261.04 μs. The fill/drain accounting is already included in k+n−1; adding separate extra fill and drain terms would double-count. The value lies within the published acceptable range 260.20 to 261.20 μs. Answer: 261.04.

# GATE 2025 CS2: Q61

**Question:** [Official archived paper page 45](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=45); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 3.0 to 3.0

**Derived answer:** 3.0

**Paraphrased problem context:** An application takes 6.3 seconds to execute 6.4×10^8 instructions. Instruction classes are: branch CPI 2, count 2.25×10^8; load CPI 5, count 1.20×10^8; store CPI 4, count 1.65×10^8; arithmetic CPI 3, count 1.30×10^8. Find the clock-cycle duration in ns to one decimal place.

## Solution

Multiply each class count by its cycles per instruction before adding. Branches use 2·2.25×10^8=4.5×10^8 cycles; loads use 5·1.20×10^8=6.0×10^8; stores use 4·1.65×10^8=6.6×10^8; arithmetic uses 3·1.30×10^8=3.9×10^8. Total cycles are (4.5+6.0+6.6+3.9)×10^8=2.1×10^9.

CPU time equals total cycles times cycle duration, so T_cycle=6.3/(2.1×10^9)=3×10^(−9) seconds=3.0 ns. Equivalently, the instruction-count-weighted average CPI is 2.1×10^9/(6.4×10^8)=3.28125, leading to the same result. A simple arithmetic average of the four CPIs would be incorrect because the instruction counts differ. The corresponding clock frequency is approximately 333.33 MHz, a useful unit check. Answer: 3.0.
