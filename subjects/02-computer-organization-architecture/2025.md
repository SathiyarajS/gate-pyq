## Solution

Only then replace it with the ISR entry address. Otherwise the interrupted execution point would be lost or inconsistent. Thus (iii),(i),(ii), option A.

## Solution

The diagram has two independent input multiplexers. Mux_A selects RA or a 32-bit immediate, and Mux_B selects RB or a 32-bit immediate. Selecting both register inputs enables register–register arithmetic; selecting one immediate enables register–immediate arithmetic; selecting both immediate inputs enables immediate–immediate arithmetic. Thus A, B, C are supported by this partial datapath, and the exclusive claim D is false.

# GATE 2025 CS1: Q36

**Question:** [Official archived paper page 36](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=36); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

Each 16-byte block uses 4 offset bits. A 16-KB cache has 2¹⁴/2⁴=2¹⁰ lines, requiring 10 index bits. From a 20-bit address, 20−10−4=6 bits remain for each tag. Across 2¹⁰ lines the tag storage is 6×2¹⁰ bits, option A. Valid/dirty bits are not tag values and are not included.

# GATE 2025 CS1: Q37

**Question:** [Official archived paper page 37](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=37); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

## Solution

Under the usual fixed-width opcode-field model, 50 instruction types require ceil(log₂50)=6 opcode bits, and 64 register choices require log₂64=6 register bits. The two-address instruction uses R1 as both source and destination, so only one register field is needed. The remaining 32−6−6=20 bits can hold the immediate operand, option B. This relies on a uniform opcode field with no extra mode bits; a variable-length opcode design is not specified.
