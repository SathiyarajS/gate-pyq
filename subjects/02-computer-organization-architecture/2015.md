**Paraphrased problem context:** In a three-address instruction format, what may an address field specify? S1 memory operand; S2 processor register; S3 implied accumulator register. A either S1 or S2; B either S2 or S3; C only S2 and S3; D all S1,S2,S3.

## Solution

An instruction such as ADD destination,source1,source2 names its explicit operands. Depending on the instruction-set architecture, these fields can select memory locations or registers. An implied accumulator needs no address field because its identity is determined by the opcode or architecture. The issue is explicit versus implicit designation, not whether an accumulator physically exists.

Baseline derivation and retained qualifications: Three-address instruction operands can refer to registers or memory as defined by the architecture. An accumulator is implicit in an accumulator architecture, not required as one of these explicit operand addresses. Thus A.

## Solution

Compare time per instruction, not stage count alone. Initially an instruction costs four 0.4-ns cycles, or 1.6 ns. A full stall-free pipeline produces one result per 0.5-ns cycle. Throughput speedup is 1.6/0.5=3.2. Five stages affect latency and initial fill; they do not make the improvement automatically fivefold. This is the steady-state limit for a sufficiently long stream.

Baseline derivation and retained qualifications: Nonpipelined throughput is 2.5GHz/4=0.625 billion instructions/s. A stall-free full pipeline at 2GHz completes one instruction per cycle, giving2 billion/s. The steady-state speedup is 2/0.625=3.2. This ignores fill/drain overhead for a finite short instruction sequence, whose length is not supplied.

Pipeline stages IF, OF and WB take one cycle; PO takes 3 for MUL, 5 for DIV and 1 for ADD/SUB. PO output can forward to OF. Find total cycles under the stated single occupied PO-stage interpretation.

## Solution

With a single occupied PO stage and the stated forwarding, MUL uses IF1, OF2, PO3–5, WB6. DIV uses PO6–10, ADD uses PO11 and SUB uses PO12; SUB writes back in cycle 13. The dependent ADD/SUB operand fetches use the forwarded results at the end of the preceding producer PO cycle. Thus total 13 cycles. This is the conventional in-order, non-internally-pipelined PO-stage model; independent or internally pipelined functional units would require more scheduling details.

Teaching detail:
Count occupied execution cycles rather than adding all independent instruction latencies. MUL starts PO in cycle 3 and occupies cycles 3–5. DIV cannot use the same PO stage until cycle 6, then occupies 6–10. ADD depends on both results and uses PO in cycle 11 after forwarding; SUB follows in cycle 12. Its WB is cycle 13. The explicit resource model matters: a separately pipelined multiplier/divider would permit a different schedule, and a non-forwarding design would add dependency stalls.

**Paraphrased problem context:** A three-stage pipeline has a five-column reservation table. Stage S1 is used at time slots 1 and 5, S2 at slots 2 and 4, and S3 only at slot 3; all other cells are blank. Determine the minimum average initiation latency (MAL). Initiation times may vary, but no two active operations may use the same stage simultaneously.

## Solution

1. The forbidden separations come from differences between occupied columns in the same row, not from differences across different stages. Thus the initial forbidden-latency set is exactly {2,4}. To attain average 3, start operations at times 0,3,6,9,...; every pairwise separation is a positive multiple of 3 and therefore safe.

2. Repeated use in S1 forbids initiation separation4; S2 forbids2. Therefore allowed positive gaps include1, 3, 5. Constant gap3 is collision-free because no multiple of 3 is 2 or4, achieving average3. If any gap is 1, its next gap cannot1 or3 (the two-gap total would be2 or4) and must be at least5. Pair each such1 with its following≥5 gap; every pair averages≥3, while unpaired gaps are≥3. Thus no lower long-run average is possible.
