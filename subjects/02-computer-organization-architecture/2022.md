**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

DMA transfers a block directly between the device and memory after CPU setup, avoiding a CPU instruction sequence or interrupt per transferred word. For a large transfer it therefore provides the highest throughput among the offered programmed/interrupt-driven methods, A, under the ordinary comparable-hardware model.

# GATE 2022 CS: Q24

**Question:** [Official archived paper page 19](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=19); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A,B,D

**Derived answer:** A,B,D

## Solution

The question asks for false statements. A is false because write-through does not require dirty bits: writes already update memory. B is false because a write-back hit normally only changes the cache and marks the line dirty. C is true: evicting a write-through line needs no extra write-back. D is false because a write-back read miss can evict a dirty victim and consequently write memory. Thus A, B, D.

# GATE 2022 CS: Q33

**Question:** [Official archived paper page 23](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=23); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 0.85 to 0.85

**Derived answer:** 0.85

## Solution

Originally the average access time is 10+(1−0.8)100=30 ns. With the slower 15 ns cache it becomes 15+(1−h)100. Requiring this to be at most 30 gives h≥0.85, so the minimum hit ratio is 0.85. The 100 ns miss penalty is additional to the cache lookup, as in the standard AMAT formula.

# GATE 2022 CS: Q54

**Question:** [Official archived paper page 36](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=36); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A,B,D

**Derived answer:** A,B,D

## Solution

There are 2048/64=32 cache lines. A byte address maps to line (address>>6) mod 32. P and S both lie in the same block from 0xA240 through 0xA27F, mapping to line 9. Q and R map to line 10 but have different tags. Thus the first P loads the P/S block permanently, and every S access hits. Each Q access replaces R (or loads the initially empty line), and every R access replaces Q. At the end the cache contains the P/S block and the R block, so P still resides and C is false. Select A, B, D. Each two-byte word fits inside its block.

# GATE 2022 CS: Q61

**Question:** [Official archived paper page 39](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=39); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 1.42 to 1.45

**Derived answer:** 1.43

## Solution

Without prediction, CPI1=1+0.30*2=1.6. With 80 percent correct predictions, only 20 percent of branches still pay the two-cycle penalty, so CPI2=1+0.30*0.20*2=1.12. Both processors have the same frequency and execute the same program, giving speedup 1.6/1.12=10/7, or 1.43 to two decimal places. This uses the stated steady-state CPI model, without separately charging pipeline fill/drain.
