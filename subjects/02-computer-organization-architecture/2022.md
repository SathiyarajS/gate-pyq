**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** Which method gives the highest bulk hard-disk-to-main-memory throughput among A DMA; B interrupt-driven I/O; C polling; D programmed I/O?

## Solution

DMA transfers a block directly between the device and memory after CPU setup, avoiding a CPU instruction sequence or interrupt per transferred word. For a large transfer it therefore provides the highest throughput among the offered programmed/interrupt-driven methods, A, under the ordinary comparable-hardware model.

Teaching detail:
With programmed or polling transfer, the CPU repeatedly tests status and moves data. Interrupt-driven transfer avoids continuous polling but still involves servicing the device. DMA amortizes CPU setup over a block and lets its controller perform the memory transfers, which is the relevant advantage for bulk throughput.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A,B,D

**Derived answer:** A,B,D

**Paraphrased problem context:** WB and WT are set-associative LRU caches using write-back and write-through respectively. Select FALSE statements: A both need a dirty bit per block; B every WB write hit transfers data to main memory; C WT eviction causes no cache-to-memory transfer; D a WB read miss never evicts a dirty block.

## Solution

The question asks for false statements. A is false because write-through does not require dirty bits: writes already update memory. B is false because a write-back hit normally only changes the cache and marks the line dirty. C is true: evicting a write-through line needs no extra write-back. D is false because a write-back read miss can evict a dirty victim and consequently write memory. Thus A, B, D.

Teaching detail:
Dirty means the cached copy differs from memory. A write-back eviction of a clean victim needs no write; a dirty victim must be written before replacement. LRU determines which victim is chosen, not whether it is dirty, so a read operation can indirectly cause a write-back.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 0.85 to 0.85

**Derived answer:** 0.85

**Paraphrased problem context:** A cache initially has hit rate 0.8, lookup latency 10 ns and additional miss penalty 100 ns. An optimization increases lookup latency to 15 ns, leaving miss penalty unchanged. What minimum new hit rate prevents AMAT increasing? Round to two decimals.

## Solution

Originally the average access time is 10+(1−0.8)100=30 ns. With the slower 15 ns cache it becomes 15+(1−h)100. Requiring this to be at most 30 gives h≥0.85, so the minimum hit ratio is 0.85. The 100 ns miss penalty is additional to the cache lookup, as in the standard AMAT formula.

Teaching detail:
Solve 15+100−100h≤30: 100h≥85, hence h≥0.85. At exactly 0.85 the AMAT is 15+15=30 ns. A smaller rate would cause the extra cache latency to outweigh the miss-rate improvement.

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** IEEE-754 binary32 register patterns for A,B,C are C1400000,42100000,41400000 (hex). Which is false? A A+C=0; B C=A+B; C B=3C; D B−C>0.

## Solution

Decode the binary32 values: 0xC1400000 has sign1, exponent130 and significand1.5, giving −12. 0x42100000 has exponent132 and significand1.125, giving 36. 0x41400000 gives 12. Therefore C=A+B is false, since 12≠−12+36=24. The other offered relations hold, so B.

Teaching detail:
For normalized binary32, value=(−1)^sign ×(1+fraction/2^23)×2^(exponent−127). A has unbiased exponent 3 and fraction 0.5: −1.5×8=−12. B has exponent 5 and fraction 0.125: 1.125×32=36. C is +12. Thus A+C=0, B=3C, and B−C=24>0.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A,B,D

**Derived answer:** A,B,D

**Paraphrased problem context:** An initially empty 2 KB direct-mapped data cache has 64-byte blocks; physical space is 64 KB and words are 16 bits. Access P,Q,R,S in that order ten times, with first-byte addresses 0xA248,0xC28A,0xCA8A,0xA262. Select true statements: A every S hits; B P never evicted after loading; C only R,S remain at the end; D every R evicts Q.

## Solution

There are 2048/64=32 cache lines. A byte address maps to line (address>>6) mod 32. P and S both lie in the same block from 0xA240 through 0xA27F, mapping to line 9. Q and R map to line 10 but have different tags. Thus the first P loads the P/S block permanently, and every S access hits. Each Q access replaces R (or loads the initially empty line), and every R access replaces Q. At the end the cache contains the P/S block and the R block, so P still resides and C is false. Select A, B, D. Each two-byte word fits inside its block.

Teaching detail:
The 16-bit physical byte address splits into 5 tag bits, 5 line bits and 6 offset bits. P: line9,tag20,offset8; S: line9,tag20,offset34; Q: line10,tag24,offset10; R: line10,tag25,offset10. The first cycle is miss,miss,miss,hit; later cycles are hit,miss,miss,hit. Therefore there are 21 misses and 19 hits across 40 accesses.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 1.42 to 1.45

**Derived answer:** 1.43

**Paraphrased problem context:** X1 runs at 2 GHz, base CPI 1, with 30% branches and two stall cycles per branch. X2 has the same frequency and base CPI, but predicts 80% of branches correctly, eliminating stalls for those; mispredictions keep the same two-cycle penalty. No other hazards occur. Find speedup rounded to two decimals.

## Solution

Without prediction, CPI1=1+0.30*2=1.6. With 80 percent correct predictions, only 20 percent of branches still pay the two-cycle penalty, so CPI2=1+0.30*0.20*2=1.12. Both processors have the same frequency and execute the same program, giving speedup 1.6/1.12=10/7, or 1.43 to two decimal places. This uses the stated steady-state CPI model, without separately charging pipeline fill/drain.

Teaching detail:
Speedup is old execution time/new execution time, not new CPI/old CPI. For N instructions at frequency F, times are N·1.6/F and N·1.12/F, so N and F cancel. The branch predictor saves 0.30×0.80×2=0.48 cycles per instruction, reducing CPI from 1.60 to 1.12.
