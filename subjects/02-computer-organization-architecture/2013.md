**Paraphrased problem context:** A cache has v sets of k consecutive lines each, sets numbered from 0 in order. Memory block j maps to which line interval? A(j mod v)k through(j mod v)k+k−1; B(j mod v) through(j mod v)+k−1; C(j mod k) through(j mod k)+v−1; D(j mod k)v through(j mod k)v+v−1.

## Solution

Block j maps to set s=j mod v. Each earlier set occupies k consecutive lines, so this set starts at sk and ends at sk+k−1. Substituting s gives the interval in A.

Teaching detail:
First choose the set, not a particular way: s=j mod v. There are s earlier sets, each occupying k line positions, so the first line of set s is sk. The k allowed ways occupy offsets0 through k−1, hence last line sk+k−1. For example, v=4, k=2, j=6 gives s=2 and lines4, 5. This example also shows why omitting the factor k, as in B, gives the wrong physical positions.

**Paraphrased problem context:** Micro-operations are MBR←PC; MAR←X; PC←Y; Memory←MBR (write at MAR). Which operation can this implement? A instruction fetch; B operand fetch; C conditional branch; D interrupt-service initiation.

## Solution

MBR receives the current PC, MAR selects location X, PC is changed to Y, and the saved PC is written at X. This saves a return address and transfers control to another routine, consistent with interrupt-service initiation, D.

Teaching detail:
Track the values rather than just the register names. The old PC is copied into MBR before PC is overwritten, so it is preserved. MAR directs the final write to X, saving that old PC in memory. Loading Y into PC redirects execution. Together these actions save a return location and jump to a service routine, consistent with D. An instruction fetch would read memory into an instruction register/buffer rather than store the old PC to memory.

**Paraphrased problem context:** A disk has 16 surfaces, 16384 cylinders, 512 bytes/sector and the source says64 sectors per cylinder. A contiguous42797 KB file begins at<cylinder1200, surface9, sector40>. Find last cylinder: A1281, B1282, C1283, D1284. The answer model interprets64 sectors per surface-track and KB=1024 bytes.

## Solution

Using the intended geometry, each cylinder has 16×64=1024 sectors and each512-byte sector is half a KiB. The file occupies42797×2=85594 sectors. Its starting within-cylinder offset is 9×64+40=616. The last sector is therefore at cylinder1200+floor((616+85594−1)/1024)=1284, D. The source literally says each cylinder contains 64 sectors, but also supplies a surface coordinate and uses the geometry above in the key. The calculation needs 64 sectors per surface-track, rather than per entire cylinder, and KB=1024 bytes; these are explicit intended interpretations.

Teaching detail:
Under the intended track geometry, one cylinder contains 16×64=1024 sectors, hence512 KiB. Convert the file to sectors:42797 KiB×1024/512=85594. The starting surface/sector is offset9×64+40=616 within cylinder1200. Numbering the first file sector as offset0 makes its last sector offset85593, so the combined last offset is 86209. Divide by 1024:84 full cylinders and remainder193. Add84 to 1200 to obtain1284. Subtracting1 before the division prevents an off-by-one error for a file ending on a cylinder boundary.

**Paraphrased problem context:** Five pipeline stages FI, DI, FO, EI, WO take5, 7, 10, 8, 6 ns, with 1 ns buffer delay. Program I1… I12 has only branch I4, taken to I9. Without branch prediction, under end-of-EI resolution, time to complete is A132, B165, C176, D328 ns.

## Solution

The pipeline clock period is max(5, 7, 10, 8, 6)+1=11 ns. Because I4 branches to I9, the useful executed instructions are I1, I2, I3, I4, I9, I10, I11, I12: eight instructions. Using the standard model in which the branch is resolved at the end of EI, I4 occupies FI in cycle 4, DI in cycle 5, FO in cycle 6 and EI in cycle 7. Without prediction, target fetch starts in cycle 8. Then I9 finishes WO in cycle 12 and I12 finishes WO in cycle 15. Equivalently, eight useful instructions need 8+5−1=12 cycles without a control hazard, plus three branch-wait cycles. The total is 15×11=165 ns, option B. The answer relies on branch resolution in EI and target fetch in the following cycle; the prompt does not separately specify an earlier branch-resolution mechanism.

Teaching detail:
A common clock must accommodate the slowest stage plus its buffer:10+1=11 ns. Branch I4 enters EI in cycle 7, after FI4, DI5, FO6. Its target can enter FI in cycle 8, then DI9, FO10, EI11, WO12. The next target-path instructions finish in cycles 13, 14, 15. Thus the total is 165 ns. Counting all 12 source instructions would incorrectly include the skipped I5–I8. The branch resolution convention is stated because a different resolution stage would change the stall count.

**Paraphrased problem context:** Build16K×16 RAM from 1K×8 chips. How many2-to-4 decoders with enable are needed? A4, B5, C6, D7.

## Solution

Two 1K×8 chips operate in parallel to supply each 16-bit word, making one 1K×16 bank. Sixteen such banks give 16K×16, so there are 32 memory chips but only 16 bank-select signals. The low ten address bits select a word within a bank; the upper four bits select the bank. Construct the required 4-to-16 decoding with one 2-to-4 decoder on the upper two bank bits. Its four outputs enable four further 2-to-4 decoders, each decoding the lower two bank bits. The total is 1+4=5 decoders, option B. Four bottom-level decoders are needed to provide sixteen outputs and an additional level is needed to select their enables.

Teaching detail:
Separate width expansion from depth expansion. Pairing two8-bit chips gives16 data bits at one address; it does not double the number of addresses. Sixteen such pairs are needed for16Kdepth. A4-bit bank number chooses one pair, while10low address bits are broadcast to all chips. A top decoder selects one group of four pairs, and four enabled bottom decoders select within each group. This produces16mutually exclusive bank enables with five decoders; it is not one decoder per memory chip.

**Paraphrased problem context:** Using the preceding page size and 1MB16-way VIPT cache with 64-byte blocks, how many page colours prevent synonyms mapping to different sets? A2, B4, C8, D16.

## Solution

There are 2^20/(16×64)=2^10 cache sets. A 64-byte cache block uses six offset bits, so the ten set-index bits are virtual-address bits 6 through 15. From the preceding linked question, the page size is 8 KiB and the page offset consists of bits 0 through 12. Only seven set-index bits (6 through 12) lie inside the page offset and are automatically identical for synonyms. The remaining three bits (13 through 15) can differ between virtual aliases of the same physical page. Distinguishing 2^3=8 page colours, and requiring aliases of a physical page to use the same colour, makes all index bits agree. Thus eight colours are necessary and sufficient, option C. Equivalently, colours=(cache size)/(associativity×page size)=1 MiB/(16×8 KiB)=8.

Teaching detail:
Synonyms share a physical page but can have different virtual page numbers. A VIPT lookup uses virtual index bits before the physical tag is known; if any such bit is outside the page offset, aliases can select different sets. Here10 index bits follow6block-offset bits, ending at bit15. Only bits 0–12belong to the8KiBpage offset, leaving three potentially different index bits. Colouring controls exactly those three bits, requiring eight choices. More tag bits do not repair selection of the wrong set.
