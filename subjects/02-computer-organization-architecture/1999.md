**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Essential problem context (paraphrased):** System calls are usually invoked by software interrupt, polling, indirect jump, or privileged instruction.

## Solution

A user program must request a controlled transition to kernel code. A software trap or software interrupt supplies that entry point, saves the required return state and switches privilege as the architecture specifies. Thus A is the traditional description. An ordinary indirect jump does not itself authorize a privilege change, and polling is a waiting strategy rather than a syscall entry mechanism. Modern processors may use dedicated syscall instructions; the user-callable trap must not be confused with an instruction executable only after privilege has already been obtained.

**Essential problem context (paraphrased):** Find the eight Booth signed digits for decimal −57, most significant first; option B is 0,−1,0,0,+1,0,0,−1.

## Solution

The eight-bit two’s-complement representation of −57 is 11000111, obtained from 57=00111001 by inversion and adding one. Append b[−1]=0 and use signed digit d[i]=b[i−1]−b[i]. From low to high the digits are −1,0,0,+1,0,0,−1,0. Reversing them gives 0,−1,0,0,+1,0,0,−1, option B. The weighted check is −2^6+2^3−2^0=−64+8−1=−57. The negative sign in the question is essential.

**Independently derived answer:** B

**Essential problem context (paraphrased):** For multiplying two n-bit numbers using an array multiplier, is maximum output delay O(n²),O(n),O(log n),or O(1)?

## Solution

The array contains quadratically many partial-product cells, but delay measures the longest dependent path rather than the total number of cells. In a regular array multiplier, carry/sum information traverses only a linear number of cell stages along a path to the final output. With bounded gate delay per stage, the critical delay is O(n), B. A logarithmic tree multiplier is a different organization; counting all n² cells as if they operated serially incorrectly gives A.

**Independently derived answer:** B

**Essential problem context (paraphrased):** Main memory has 2cm blocks and cache has 2c blocks, with two blocks per set. Which set receives block k: k mod m,c,2c,or 2cm?

## Solution

The number of cache sets is capacity divided by associativity: (2c)/2=c. Consecutive main-memory blocks are distributed cyclically over these c sets, so the set index is k mod c. The remaining quotient supplies tag information, while either way within that indexed set may hold the block. Thus B. Both reproductions display products 2cm and 2c, not exponents; reading the latter as 2^c would change the set-count formula incorrectly.

**Essential problem context (paraphrased):** RAID configurations provide fault tolerance,high speed,high data density,or none. Select applicable goals.

## Solution

Mirroring or parity can preserve recoverability after a disk failure, providing fault tolerance. Striping distributes transfers across disks and can increase throughput, providing high speed. These are system-level properties, not an increase in the physical bit density of an individual disk, so C is not a RAID benefit. The applicable goals are A,B. Different RAID levels trade these goals differently: RAID0 emphasizes striping without redundancy, while mirrored/parity levels supply failure protection; the answer does not claim every level supplies both equally.

**Independently derived answer:** B

**Essential problem context (paraphrased):** Order hardwired control,horizontal microprogramming,vertical microprogramming from fastest to slowest.

## Solution

Hardwired control generates signals through dedicated logic without fetching a microinstruction for each control step. Horizontal microcode exposes many control fields directly, reducing decoding and allowing parallel control actions. Vertical microcode is more densely encoded and needs additional decoding, often with less control parallelism. Thus the traditional comparable-design order is hardwired, horizontal, vertical, option B. This is an architectural rule of thumb, not a universal measured ordering across unrelated implementations or clock technologies.

**Independently derived answer:** No unconditional impossibility; A,B,D under a restricted direct-code model

**Essential problem context (paraphrased):** With only immediate and direct addressing, which cannot be implemented: pointers,arrays,records,recursive procedures with locals?

## Solution

A direct instruction names a fixed address; it cannot in one ordinary memory operation follow a runtime pointer or index. Records with fixed field offsets can use fixed addresses, while pointers, variable array indices and runtime stack frames naturally need computed-address access. This motivates A,B,D only under a model excluding software emulation and code modification. Literally, however, a finite address space permits a dispatch chain: compare the desired address with each legal address and execute the matching direct load/store. Such an interpreter can implement all these features, albeit inefficiently; self-modifying code supplies another possible route if allowed. Therefore the given addressing-mode restriction alone does not prove impossibility, and no unsupported official choice is assigned.

# GATE 1999: Q71 (printed B Q13)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 15 clock cycles

**Essential problem context (paraphrased):** Five instructions pass in order through F, D, E, W. Their respective cycle requirements are I1=(1,2,1,1), I2=(1,2,2,1), I3=(2,1,3,2), I4=(1,3,2,1), I5=(1,2,1,2). Find the completion time.

## Solution

Assume one instruction can occupy each stage at a time, in-order processing and no unmentioned data hazards. A completed instruction may wait for the next stage. A feasible schedule, using inclusive cycle ranges, is:

Instruction   F     D      E      W
I1            1     2–3    4      5
I2            2     4–5    6–7    8
I3            4–5   6      8–10   11–12
I4            6     8–10   11–12  13
I5            8     11–12  13     14–15

Waiting is not additional useful stage work: I2 stays at F through cycle 3; I3 stays at D during cycle 7; I4 stays at F during cycle 7; I5 stays at F through cycle 10. Thus the schedule is also feasible with ordinary backpressure rather than unbounded interstage queues. For a lower bound, even with unrestricted waiting buffers the earliest completion recurrence is C(i,j)=max(C(i−1,j),C(i,j−1))+duration(i,j), with zero boundary values. Its rows are (1,3,4,5), (2,5,7,8), (4,6,10,12), (5,9,12,13), (6,11,13,15). No legal schedule can finish before cycle 15, and the displayed schedule attains it. Summing all stage times would incorrectly remove pipeline overlap.

# GATE 1999: Q78 (printed B Q17(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** R1=0, R3=2

**Essential problem context (paraphrased):** For the assembly below with initial (R1,R2,R3)=(5,0,0), find R1 and R3 on reaching Z:
X: CMP R1,0
   JZ Z
   MOV R2,R1
   SHR R1
   SHL R1
   CMP R2,R1
   JZ Y
   INC R3
Y: SHR R1
   JMP X
Z: ...
CMP sets comparison flags; JZ jumps on equality; MOV copies its second operand into its first; SHR/SHL shift by one bit.

## Solution

The SHR followed by SHL clears the least significant bit. Comparing the result against saved R2 detects whether that bit was 1. If so, increment R3. The SHR at Y then advances to the next bit. With nonnegative logical shifts the trace is:

Entry R1 | R2 after MOV | after SHR,SHL | R3 after test | R1 after Y
5 (101)  | 5            | 4 (100)       | 1             | 2
2 (010)  | 2            | 2 (010)       | 1             | 1
1 (001)  | 1            | 0 (000)       | 2             | 0

At the next X, R1=0 makes JZ Z branch before another iteration. Hence final R1=0 and R3=2. R2 happens to remain 1, though it is not requested. The two right shifts in the body do not skip two input bits because the intervening left shift restores the higher-bit positions.

# GATE 1999: Q79 (printed B Q17(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 3 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** R3=popcount(n), the number of 1 bits in n.

**Essential problem context (paraphrased):** For the same assembly with initial (R1,R2,R3)=(n,0,0), determine R3 on reaching Z:
X: CMP R1,0
   JZ Z
   MOV R2,R1
   SHR R1
   SHL R1
   CMP R2,R1
   JZ Y
   INC R3
Y: SHR R1
   JMP X
Z: ...
CMP sets comparison flags; JZ jumps on equality; MOV copies its second operand into its first; SHR/SHL shift by one bit.

## Solution

For nonnegative integer n (or an unsigned fixed-width register with logical SHR), write current R1=2k+b, where b∈{0,1}. SHR then SHL yields 2k, so CMP detects inequality exactly when b=1; R3 therefore increases by b. The SHR at Y sets R1=k. After t iterations, R1=floor(n/2^t) and R3 equals the number of ones in the t low-order bits removed from n. This invariant holds initially and is preserved by the decomposition 2k+b. Termination occurs when R1=0, after all significant bits have been examined, so R3 is the binary population count of n. For n=0 the initial branch exits immediately and R3=0. For negative signed inputs the outcome requires a specified word width and right-shift convention; arithmetic SHR is not covered by this nonnegative-integer proof.

# GATE 1999: Q80 (printed B Q18)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Two 1K×8 banks: 1000h–13FFh and 1400h–17FFh; decode A15…A11=00010 and select bank by A10.

**Essential problem context (paraphrased):** Design 2048 eight-bit locations at 1000h–17FFh for an 8085, using four 1K×4 chips. Each has active-low /CS, /RD, /WR; address A0–A9; data D0–D3. /CS=1 makes data high impedance. GFG explicitly says eight-bit locations; GateForum loses the 8 in the prose.

## Solution

A 1K×4 chip has 1024 locations of four bits. Put two chips in parallel to make each 1K×8 bank, then use two banks for 2K×8. Name them L0,H0 and L1,H1. Wire all four address inputs to CPU A0–A9. In each bank L’s chip D0–D3 connect to CPU D0–D3, and H’s chip D0–D3 connect to CPU D4–D7. Both chips in a bank share selection and read/write controls.

1000h = 0001 0000 0000 0000
17FFh = 0001 0111 1111 1111
Thus A15…A11=00010 is fixed; A10 selects one of two banks; A9…A0 address a byte within the bank. Let M=NOT(IO/M), true on memory cycles, and S=M·¬A15·¬A14·¬A13·A12·¬A11. Then
/CS0=NOT(S·¬A10), to L0 and H0
/CS1=NOT(S· A10), to L1 and H1.
Bank 0 responds to 1000h–13FFh and bank 1 to 1400h–17FFh, with no other addresses selected. Connect CPU /RD and /WR to each chip’s /RD and /WR; memory qualification in /CS suppresses I/O-cycle responses.

8085 AD0–AD7 ──┬── bidirectional data bus D0–D7 ── both banks
               └── ALE-controlled latch ── A0–A7 ── all chips
8085 A8,A9 ─────────────────────────────── A8,A9 ── all chips
A15…A10, IO/M ── decoder ── /CS0,/CS1
/RD,/WR ───────────────────────────────────────── all chips

The latch is essential because the 8085 multiplexes low address and data pins. The upper chip in each bank maps its local D0 to CPU D4, not CPU D0. Only one bank is enabled per address; deselected banks stay high impedance and cannot fight the data bus.
