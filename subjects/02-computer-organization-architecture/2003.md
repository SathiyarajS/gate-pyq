

# GATE 2003: Q10 (printed CS Q10)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** For a pipelined CPU with one ALU, consider I. Instruction j+1 uses instruction j’s result; II. A conditional jump executes; III. Instructions j and j+1 need the ALU simultaneously. Which can cause a hazard? A. I and II only; B. II and III only; C. III only; D. All three.

## Solution

1. A data hazard concerns operand availability, a control hazard concerns which instruction address to fetch, and a structural hazard concerns resource availability. These are separate reasons a pipeline may need a stall or other mitigation. A single ALU does not eliminate the data or control cases.

2. Using a preceding result can cause a data hazard; a conditional branch causes a control hazard; simultaneous demand for the single ALU causes a structural hazard. Therefore all three can cause hazards, D. The question asks possibility, not that every instance necessarily stalls.

# GATE 2003: Q43 (printed CS Q43)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** A 16-bit floating-point scheme has sign s at bit 15, six-bit exponent e at bits 14–9, and nine-bit mantissa integer m at bits 8–0. Its value is (−1)^s(1+m·2^(−9))2^(e−31) if e≠111111₂, and zero otherwise. What is the maximum difference between successive representable real numbers? A. 2^(−40); B. 2^(−9); C. 2^22; D. 2^31.

## Solution

1. Within an exponent binade, incrementing the nine-bit mantissa integer by one increments the value by 2^(e−40). Maximizing this requires the largest nonreserved exponent, 62. The positive/negative sign duplicates gaps by symmetry; crossing zero and crossing adjacent exponent ranges cannot exceed the largest within-binade gap.

2. There are six exponent bits and nine fractional mantissa bits. Exponent 63 is reserved for zero, so the largest usable exponent is e=62. For fixed e, adjacent significands differ by 2⁻⁹, giving spacing 2^(e−31−9). This is largest at e=62, namely 2²², option C. Crossing a binade boundary has the smaller binade’s spacing, and the gaps adjacent to zero are only 2⁻³¹, so neither produces a larger gap.

# GATE 2003: Q46 (printed CS Q46)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** An n-bit ripple-carry ALU has a full adder at each bit. At bit i its inputs are Ai, Bi XOR K, and carry Ci; the output is Si and the next carry. K is shared by all XOR gates and C0 is the least-significant carry input. For two's-complement operands, which operations can be performed by choosing only K and C0?
A. A+B and A−B, but not A+1
B. A+B and A+1, but not A−B
C. A+B, but neither A−B nor A+1
D. A+B, A−B and A+1

## Solution

1. A full-adder chain adds its two input words and the initial carry, so S=A+(B XOR K...K)+C0 modulo 2^n.
2. Enumerate the controls: (0,0) produces A+B; (0,1) produces A+B+1; (1,0) produces A+complement(B)=A−B−1; (1,1) produces A−B.
3. For arbitrary B none of these cancels B entirely. In particular the extra carry in (0,1) gives A+B+1, not A+1. Thus only addition and subtraction are generally available: A.

Baseline derivation and caveats (retained): The gates feeding the B inputs are XOR gates. For an n-bit word the circuit computes A+(B XOR K…K)+C₀ modulo 2ⁿ. Setting (K,C₀)=(0,0) gives A+B; setting (1,1) gives A+¬B+1=A−B. Neither setting can remove arbitrary B to give A+1 solely by changing those two control lines. Therefore A+B and A−B, but not general A+1, is option A.

# GATE 2003: Q48 (printed CS Q48)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** A, B and C are 8-bit registers in a hypothetical processor. The program is:
MOV B,#0       ; B=0
MOV C,#8       ; C=8
Z: CMP C,#0    ; compare C with zero
JZ X          ; jump if zero flag is set
SUB C,#1      ; C=C-1
RRC A,#1      ; rotate A right through carry once
JC Y          ; jump if carry is set
JMP Z
Y: ADD B,#1   ; B=B+1
JMP Z
X:
RRC transforms A=a7...a0 and carry=c into A=ca7...a1 and carry=a0. Use the instruction effects listed for this hypothetical machine.
If A initially equals A0, what is B after execution?
A. Number of 0 bits in A0
B. Number of 1 bits in A0
C. A0
D. 8

## Solution

1. The C test is before the decrement: C=8,7,...,1 each enters the body, while C=0 exits. There are exactly eight rotations.
2. Write the original bits as a7...a0. The successive carry outputs are a0,a1,...,a7. Any incoming carry sits at the top and cannot emerge until a ninth rotation.
3. Only JC Y reaches ADD B,#1. Thus B increases once for every outgoing 1 and never for an outgoing 0. Starting from zero it ends at a0+...+a7, the population count: B.

Baseline derivation and caveats (retained): The counter C starts at eight and the loop performs exactly eight one-bit right rotations through carry. The carry tested immediately after the kth rotation is the kth original low-to-high bit of A. Newly inserted carry bits cannot reach the outgoing low position during these eight iterations. B starts at zero and is incremented exactly when the outgoing bit is one, so B is the population count of the original A, option B.

# GATE 2003: Q49 (printed CS Q49)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A under the stated instruction effects

**Paraphrased problem context:** A, B and C are 8-bit registers in a hypothetical processor. The program is:
MOV B,#0       ; B=0
MOV C,#8       ; C=8
Z: CMP C,#0    ; compare C with zero
JZ X          ; jump if zero flag is set
SUB C,#1      ; C=C-1
RRC A,#1      ; rotate A right through carry once
JC Y          ; jump if carry is set
JMP Z
Y: ADD B,#1   ; B=B+1
JMP Z
X:
RRC transforms A=a7...a0 and carry=c into A=ca7...a1 and carry=a0. Use the instruction effects listed for this hypothetical machine.
Which instruction inserted at X ensures that A ends with its original value?
A. RRC A,#1
B. NOP (no operation)
C. LRC A,#1 (rotate A left through carry once)
D. ADD A,#1

## Solution

1. Include carry in the state: (c,a7,a6,...,a0) is a nine-position ring. One RRC moves this ring one position right.
2. The loop performs eight rotations, so its accumulated permutation is R^8. Since R^9 is the identity, another RRC restores all nine bits.
3. NOP leaves R^8 unchanged; one left rotation gives R^7, not identity; adding 1 is not a bit-position inverse. Hence A works under the given instruction effects. This explicitly relies on other listed instructions not modifying carry.

Baseline derivation and caveats (retained): Treat carry and A together as a nine-bit circular register and use the instruction effects stated for this hypothetical processor. Eight right rotations leave one right rotation short of a full nine-bit cycle. Inserting RRC A,#1 at X therefore restores A, irrespective of the initial carry value, giving A. This reasoning uses carry preservation by instructions whose listed effects do not change carry; importing different flag side effects from a real ISA would require a new analysis.

# GATE 2003: Q78 (printed CS Q78)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=11), physical page 11. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** None

**Paraphrased problem context:** A byte-addressable processor has 32-bit virtual and physical addresses and two-level page tables stored in main memory. Address bits are split 10 bits for first-level index, 10 for second-level index, and 12 for page offset. All page-table entries are 4 bytes. TLB hit rate is 96%, physical-cache hit rate 90%; TLB and cache access each take 1 ns, and main memory takes 10 ns. With no page faults, what is mean virtual-address access time, approximately to the nearest 0.5 ns?
A. 1.5 ns  B. 2 ns  C. 3 ns  D. 4 ns
The statement does not specify whether page-table reads use the cache/hit rate.

## Solution

1. A cache-backed physical access costs 1 ns on a hit and 1+10=11 ns on a miss. Its mean is H=0.9×1+0.1×11=2 ns.
2. Every virtual access pays the 1 ns TLB lookup and one final data access. A TLB miss occurs with probability 0.04 and additionally reads two page-table entries.
3. If those reads also use this cache and hit rate, the conditional costs are 3 ns on a TLB hit and 7 ns on a miss. E=0.96×3+0.04×7=3.16 ns, rounding to 3.0 ns (C).
4. If page-table reads bypass the cache, a miss instead costs 1+20+2=23 ns. E=0.96×3+0.04×23=3.8 ns, rounding to 4.0 ns (D).
5. Both interpretations place page tables in main memory; this phrase alone does not resolve caching. Consequently retain the baseline underdetermination instead of asserting an unconditional option.

Baseline derivation and caveats (retained): If every physical memory reference, including page-table reads, uses the stated cache with 90% hit probability, its mean service time is H=1+0.10×10=2 ns, charging the cache probe before a miss fetch. A lookup always costs 1 ns for the TLB and one data reference; a TLB miss, probability 0.04, adds two page-table references. Thus E=1+(1+2×0.04)H=3.16 ns, which rounds to 3.0 ns, C. If the two page-table references instead bypass the cache and each costs 10 ns, E=1+0.04×20+H=3.8 ns, rounding to 4.0 ns, D. The statement that page tables reside in main memory does not itself specify whether their reads are cached or share the data-cache hit rate. C is the usual all-physical-accesses-cached interpretation, but an unconditional answer is withheld.
