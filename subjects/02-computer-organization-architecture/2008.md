

# GATE 2008: Q32 (printed CS Q32)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 6. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

The actuator must accelerate from rest and decelerate to settle at the target track. These starting/stopping dynamics make short and long seeks have different effective travel speeds, so latency is not simply a constant times distance. Thus B, not request distribution or track capacity.

# GATE 2008: Q34 (printed CS Q34)

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B in the conventional privileged-return model

## Solution

RFE restores saved execution/control state and may change privilege, so the conventional architecture restricts its use to privileged code: II. It returns from a trap rather than being required to generate one, so I is false. A processor may define exceptions/faults during a return, for example invalid saved state, so III is not universally required. Therefore B under the conventional model. Architectures can instead permit restricted unprivileged returns that cannot escalate privilege, so the broad must wording is architecture-dependent.

# GATE 2008: Q35 (printed CS Q35)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 6. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A under full-capacity inclusion convention

## Solution

For every resident L1 block also to be represented in L2 while L1 can use its full capacity, L2 must be at least as large: IV. Write-back can be compatible with inclusion via appropriate dirty-state and invalidation handling, so I and II are not required. Equal associativity can satisfy inclusion; it need not be strictly greater, so III is false. Hence A under the standard capacity convention. A policy that deliberately underutilizes a larger L1 through back-invalidations could preserve resident-set inclusion with a smaller L2, so IV is not a purely set-theoretic necessity without the full-capacity convention.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Windows keep function locals and parameters in registers, reducing their data-memory accesses. Overlap passes arguments between caller and callee, and window rotation avoids many explicit register-save/restore operations. Omitting those load/store instructions also avoids fetching those instructions, reducing instruction-memory accesses. Thus all I,II,III are benefits, D, subject to spills when available windows are exhausted.

**Independently derived answer:** C in the conventional address-generation pipeline

## Solution

The data TLB is indexed/tagged by the virtual page number of the effective address. In the conventional pipeline that address is available after address calculation, so C is the intended stage ordering. Optimized implementations may speculate or overlap translation when upper address bits are known early; the answer is not a universal prohibition on such microarchitectural techniques.

# GATE 2008: Q71 (printed CS Q71)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 15. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

The 64-KiB cache with 16-byte blocks contains 4096 lines. Two ways give 2048 sets, requiring 11 index bits; the byte offset needs 4 bits. The 32-bit virtual address therefore leaves 32−11−4=17 tag bits per line. Total tag storage is 4096×17=69632 bits=68 Kibits, option D. Valid, dirty and replacement bits are not tags and are excluded.

# GATE 2008: Q73 (printed CS Q73)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 15. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C (assuming write allocation)

## Solution

Sequential row-major stores touch two adjacent 8-byte doubles in each 16-byte cache line. With the intended write-allocate policy and an initially empty cache, the first store misses and allocates the line, and the second store hits. The hit ratio is therefore 1/2=50%, option C. The array is page-aligned and thus line-aligned. No line is reused after the traversal moves beyond it, so capacity misses do not change this pairing. A no-write-allocate cache would leave every store a miss and yield 0% (A).

# GATE 2008: Q76 (printed CS Q76)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 16. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

In the ordinary non-annulling delayed-branch model, the instruction immediately following the branch in memory executes before control transfers, regardless of whether the branch is taken. That is the delay-slot instruction, option A. Instructions beyond the delay slot on the fall-through or target paths are not both guaranteed to execute. Some ISAs offer annulled slots, but those are outside the simple delayed-branch model used by this linked pair.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

I4 stores R1 through address R4 but changes neither register used by the branch condition. Moving it from immediately before the branch to the single delay slot preserves its unconditional execution and lets the branch still test the R1 computed by I3. I1 cannot move because I3 needs R2; I2 cannot move because I4 needs R4; I3 cannot move because I4 and the branch need R1. Thus I4, option D, is the legal choice in the stated dependency model.
