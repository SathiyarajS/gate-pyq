**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Base addressing forms an address as relocation base plus displacement, while PC-relative addressing uses a displacement from the moving instruction location. Both preserve relative positions when code is relocated, so ii and iii, C. Absolute embedded addresses require adjustment; indirection alone does not guarantee that stored pointer values relocate correctly.

## Solution

There are7 instruction words, so fetch/decode costs7×2=14 cycles. The first MOV loads a memory word, the second MOV uses register-indirect addressing to load one memory word, and the last MOV stores one memory word:3 transfers×3=9 cycles. ADD has register operands and costs1. No extra HALT execution cost is specified. Total14+9+1=24 cycles. Register-indirect addressing does not itself require another memory load because R1 already contains the address.

## Solution

Four blocks in a two-way cache means two sets. With the standard block-number modulo2 mapping,8,12,0 all map to the same set. Starting empty:8 miss gives[8];12 miss gives[8,12];0 miss evicts least-recent8, giving[12,0];12 hits and becomes MRU;8 misses and evicts0. Thus four misses. The unused other set cannot absorb these conflicting blocks. An initially empty cache and conventional set indexing are assumed.

## Solution

An eight-input status multiplexer needs Y=log2(8)=3 select bits. Of the 26 microinstruction bits, 13 encode operations, leaving X=26−13−3=10 next-address bits. An address space of ten bits contains 2^10=1024 control-memory words. Thus (X,Y,words)=(10,3,1024), A.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

The CPU spends 300+900=1200 cycles per block, or 1200/(600×10^6)=2 microseconds. At 10 MB/s a 20 KB block takes approximately 2 milliseconds, so CPU overhead is 2 microseconds / 2 milliseconds ×100%=0.1%, D. Consistent binary KB/MB units give about 0.1024%, still the stated approximation. This counts setup/completion CPU time, not the disk-transfer duration as busy CPU time.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

The common clock period is the slowest stage plus register delay: max(150,120,160,140)+5=165 ns. A four-stage pipeline needs 4 cycles for its first item and 999 more for the remaining items. Total time is (1000+4−1)×165=165495 ns=165.495 microseconds, rounded to 165.5 microseconds, C. This is the standard balanced-clock pipeline timing model.
