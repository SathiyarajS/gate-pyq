**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Which addressing modes support program relocation at runtime? (i) Absolute; (ii) Based; (iii) Relative; (iv) Indirect.
Options:
(A) i and iv
(B) i and ii
(C) ii and iii
(D) i,ii and iv

## Solution

1. Base addressing forms an address as relocation base plus displacement, while PC-relative addressing uses a displacement from the moving instruction location. Both preserve relative positions when code is relocated, so ii and iii, C.

2. Absolute embedded addresses require adjustment; indirection alone does not guarantee that stored pointer values relocate correctly.

3. Teaching check: If relocation shifts all code by Δ, a PC-relative target shifts with the PC while its displacement stays fixed. A base-addressed target shifts when the base register is updated. An arbitrary indirect pointer can still contain an obsolete absolute address, so indirection alone is not a relocation guarantee.

**Paraphrased problem context:** A CPU has user registers R1,R2,R3. Program in order (operation; instruction size in words): MOV R1,5000 (R1←Memory[5000];2); MOV R2,(R1) (R2←Memory[R1];1); ADD R2,R3 (R2←R2+R3;1); MOV 6000,R2 (Memory[6000]←R2;2); HALT (machine halts;1). Memory is byte-addressable with 32-bit words and the program starts at decimal 1000. If an interrupt occurs after HALT has executed, what decimal return address is saved on the stack?
Options:
(A) 1007
(B) 1020
(C) 1024
(D) 1028

## Solution

1. The five instructions occupy2+1+1+2+1=7 words. Each word is32 bits=4 bytes, so the program occupies28 bytes starting at1000.

2. Under the ordinary next-instruction-PC convention, after fetching/executing HALT the saved return address is1000+28=1028. HALT itself begins at1024;1007 would confuse word and byte addressing.

3. Teaching check: Instruction start addresses are 1000,1008,1012,1016,1024. HALT occupies one four-byte word, so the next sequential address is 1028. Saving 1024 would resume at HALT itself; saving 1007 wrongly treats byte-addressed memory as word-addressed.

**Paraphrased problem context:** A CPU has user registers R1,R2,R3. Program in order (operation; instruction size in words): MOV R1,5000 (R1←Memory[5000];2); MOV R2,(R1) (R2←Memory[R1];1); ADD R2,R3 (R2←R2+R3;1); MOV 6000,R2 (Memory[6000]←R2;2); HALT (machine halts;1). Each register/memory transfer costs 3 cycles, register ADD costs 1 cycle, and instruction fetch/decode costs 2 cycles per word. What is the total execution-cycle count?
Options:
(A) 29
(B) 24
(C) 23
(D) 20

## Solution

1. There are7 instruction words, so fetch/decode costs7×2=14 cycles. The first MOV loads a memory word, the second MOV uses register-indirect addressing to load one memory word, and the last MOV stores one memory word:3 transfers×3=9 cycles.

2. ADD has register operands and costs1. No extra HALT execution cost is specified.

3. Total14+9+1=24 cycles. Register-indirect addressing does not itself require another memory load because R1 already contains the address.

4. Teaching check: The instruction sizes sum to seven words, so fetch/decode alone costs fourteen cycles. Indirect MOV R2,(R1) uses R1’s value as an address; it does not first fetch that address from memory. This leaves exactly three data-memory transfers and one ADD.

**Paraphrased problem context:** A two-way set-associative cache contains four blocks total and uses LRU replacement. How many misses occur for block references 8,12,0,12,8? Assume an initially empty cache and conventional block-number modulo number-of-sets mapping.
Options:
(A) 2
(B) 3
(C) 4
(D) 5

## Solution

1. Four blocks in a two-way cache means two sets. With the standard block-number modulo2 mapping,8,12,0 all map to the same set.

2. Starting empty:8 miss gives[8];12 miss gives[8,12];0 miss evicts least-recent8, giving[12,0];12 hits and becomes MRU;8 misses and evicts0. Thus four misses.

3. The unused other set cannot absorb these conflicting blocks. An initially empty cache and conventional set indexing are assumed.

4. Teaching check: Only two ways are available in the even-numbered set despite four blocks existing overall. The access to 12 after inserting 0 is a hit and changes recency. That change determines which entry is evicted on the final 8 reference, although the miss count remains four.

**Paraphrased problem context:** A 26-bit microinstruction has a 13-bit micro-operation field, next-address field X and MUX-select field Y. A MUX selects one of eight status bits. Figure connectivity: X feeds the control address register; Y selects the status MUX; the selected status controls address-register load versus increment; that register addresses control memory. What are (X bits,Y bits,control-memory words)?
Options:
(A) 10,3,1024
(B) 8,5,256
(C) 5,8,2048
(D) 10,3,512

## Solution

1. An eight-input status multiplexer needs Y=log2(8)=3 select bits. Of the 26 microinstruction bits, 13 encode operations, leaving X=26−13−3=10 next-address bits.

2. An address space of ten bits contains 2^10=1024 control-memory words. Thus (X,Y,words)=(10,3,1024), A.

3. Teaching check: The select field encodes which of eight status lines is used, so it needs three bits rather than eight. The next-address width is what addresses control-memory words; the microinstruction width determines word size, not the number of words.

**Paraphrased problem context:** A disk continuously transfers at 10 Mbytes/s using DMA. A 600-MHz CPU uses 300 cycles to initiate and 900 cycles to complete each 20-Kbyte DMA block transfer. What percentage of CPU time is consumed by transfer overhead?
Options:
(A) 5.0%
(B) 1.0%
(C) 0.5%
(D) 0.1%

## Solution

1. The CPU spends 300+900=1200 cycles per block, or 1200/(600×10^6)=2 microseconds. At 10 MB/s a 20 KB block takes approximately 2 milliseconds, so CPU overhead is 2 microseconds / 2 milliseconds ×100%=0.1%, D.

2. Consistent binary KB/MB units give about 0.1024%, still the stated approximation. This counts setup/completion CPU time, not the disk-transfer duration as busy CPU time.

3. Teaching check: DMA frees the CPU during the bulk data movement. Charge only 1200 CPU cycles per transfer, not the full disk-transfer interval. Using consistent seconds and clock cycles gives a dimensionless ratio before multiplying by 100 to express a percentage.

**Independently derived answer:** C

**Paraphrased problem context:** A four-stage pipeline has stage delays 150,120,160,140 ns and interstage-register delay 5 ns. With a constant clock period, how long does it take to process 1000 items?
Options:
(A) 120.4 μs
(B) 160.5 μs
(C) 165.5 μs
(D) 590.0 μs

## Solution

1. The common clock period is the slowest stage plus register delay: max(150,120,160,140)+5=165 ns. A four-stage pipeline needs 4 cycles for its first item and 999 more for the remaining items.

2. Total time is (1000+4−1)×165=165495 ns=165.495 microseconds, rounded to 165.5 microseconds, C. This is the standard balanced-clock pipeline timing model.

3. Teaching check: Pipeline throughput is set by the slowest stage, not the sum of stage delays. The sum matters for an unpipelined path; the pipelined batch takes a fill of four cycles plus one cycle for each subsequent item. Include the register delay in every clock period.
