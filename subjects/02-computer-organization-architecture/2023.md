**Type / marks:** NAT, 1 mark(s).

**Official answer:** 2040 to 2040

**Derived answer:** 2040

**Paraphrased problem context:** A hazard-free 3-stage pipeline has stage delays 10,20,14 ns, no other delay, and fetches one instruction per cycle. Find total time in ns for 100 instructions, starting with an empty pipeline.

## Solution

The pipeline clock must accommodate the slowest stage, 20 ns. Three stages take3 cycles for the first instruction, followed by one cycle per additional instruction. Thus100 instructions require100+3−1=102 cycles and 102×20=2040 ns. There are no extra latch delays or hazard stalls by premise.

Teaching detail. A synchronous pipeline cannot clock each stage at its own independent duration: its common cycle length is bounded by the slowest stage. The first instruction leaves stage 3 after three 20 ns cycles. The remaining 99 instructions then finish one per cycle, so the elapsed time is (3+99)·20. Summing delays to get 44 ns per instruction would describe a different, unpipelined calculation. Multiplying only 100·20 overlooks the two extra fill/drain cycles in the finite batch.

**Official answer:** 10.2 to 10.2

**Derived answer:** 10.2

**Paraphrased problem context:** A keyboard produces one keystroke per second. Polling every 10 ms costs 100 μs per poll plus 200 μs per detected keystroke; its CPU-time fraction is T1. Interrupt handling and processing together cost 1 ms per keystroke; its fraction is T2. Find T1/T2 to one decimal place.

## Solution

Polling every 10 ms means 100 polls per second, consuming100×100μs=10000μs. Processing one keystroke adds200μs, giving T1=10200μs/second. Interrupt-based processing consumes1ms=1000μs per second, so T1/T2=10200/1000=10.2.

Teaching detail. Keep all quantities in the same unit before taking the ratio. Each second contains 1000/10=100 polling intervals, even though only one of those intervals typically detects a keystroke. Poll overhead is therefore paid 100 times, whereas keystroke processing is paid once. The fractions are T1=0.0102 and T2=0.001, and division gives 10.2. The interrupt approach's larger cost per event can still be much cheaper overall because it avoids 99 unproductive polling checks.

**Official answer:** B

**Paraphrased problem context:** Translate for(i=0;i<10;i++) a[i]=b[i]*8, with 32-bit ints and byte addressing. r1=0,r2=10 and r3,r4 point to a,b. L01 tests r1==r2 and exits; L02 loads from r4; L03 shifts left by U1; L04 stores at r3; L05,L06 add U2,U3 to r3,r4; L07 increments r1; L08 jumps to U4. Find U1,U2,U3,U4.

## Solution

Multiplication by 8 is a left shift by 3, so U1=3. A32-bit int occupies4 bytes in the stated byte-addressed memory, so both source and destination pointers advance4: U2=U3=4. Each iteration must revisit the termination test at L01, making U4=L01. Answer B, under the usual arithmetic range assumptions for this translation.

Teaching detail. The loop counter r1 counts elements, so its increment is one; the address registers count bytes, so their increments differ. Shifting by 3 multiplies a representable nonnegative binary value by 2³, whereas shifting by 8 would multiply by 256. A jump to L02 would skip the test on later iterations and make termination incorrect. Translating signed C shifts or overflow in full generality requires care, but the intended machine-code comparison is element addressing and multiplication by a power of two within the assumed range.

**Paraphrased problem context:** Four 1 KiB blocks form a 4 KiB byte-addressed memory. External IA4,IA3 select blocks X1,X2,X3,X4 through decoder outputs 00,01,10,11; the other ten address lines feed each block's internal address. Find the external decimal addresses where internal Addr=0 for X1 through X4.

## Solution

The internal address lines are all external lines except IA4 and IA3. Internal Addr=0 forces every one of those ten lines to 0. The four blocks are then selected by(IA4, IA3)=00, 01, 10, 11, whose external numeric contributions are0, 8, 16, 24. Thus C. These are the starts in the interleaved external address map, not contiguous1024-byte block boundaries. Decoder wiring was visually checked.

Teaching detail. The address bits used for selection do not feed the internal address port. Setting internal Addr=0 therefore fixes IA11..IA5 and IA2..IA0 to zero, while leaving IA4,IA3 free to encode the selected block. Their binary place values are 16 and 8. This is an interleaved address mapping: the internal address can change as lower external bits change and block selection can change at bit 3. Assuming the chip-select lines are the two most significant bits would incorrectly produce 0,1024,2048,3072.

**Paraphrased problem context:** Multiply binary32 values P=0xC1800000 and Q=0x3F5C2EF4. Which binary32 encoding results? A 0x404C2EF4; B 0x405C2EF4; C 0xC15C2EF4; D 0xC14C2EF4.

## Solution

P=0xC1800000 is−16=−2⁴. Q is a positive normal binary32 number with exponent126 and fraction0x5C2EF4. Multiplying by−2⁴ flips the sign and raises the biased exponent from 126 to 130, leaving the fraction unchanged. The result is 0xC15C2EF4, option C. Scaling remains within the normal range and is exact.

Teaching detail. A normal binary32 value is (−1)^s·(1+fraction/2²³)·2^(e−127). For P the sign is 1, biased exponent 131, and fraction zero, yielding −16. For Q the sign is 0 and biased exponent 126. Exact scaling by 16 adds four to that exponent, while the negative multiplier changes the sign bit to 1. Packing sign 1, exponent 130, and unchanged fraction 0x5C2EF4 yields the stated hexadecimal word. No significand multiplication or rounding is needed for this power-of-two scaling.

**Official answer:** 19 to 19

**Derived answer:** 19

**Paraphrased problem context:** An 8-way set-associative cache has 64 KiB data capacity and 32-bit byte addresses divided into tag, set index, and block offset. Find the tag width.

## Solution

For byte addressing, cache data capacity equals associativity times number of sets times bytes per block. Therefore the number of sets times block size is 65536/8=8192=2^13. The index and block-offset fields together occupy 13 bits regardless of the particular power-of-two block size. The tag has 32-13=19 bits. As usual, the stated capacity is data capacity, excluding tag and replacement metadata.

Teaching detail. Let block size be 2^b bytes and the number of sets be 2^s. Eight ways means each set stores eight blocks, so 2^16=2^3·2^s·2^b and s+b=13. These lower address bits choose a set and byte within a block; the remaining bits identify which memory block occupies the selected way. Therefore tag width is independent of the unspecified block size, provided the conventional power-of-two partition is used. Associativity bits do not appear as a separate address field selecting a way.
