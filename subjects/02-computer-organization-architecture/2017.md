**Derived answer:** C

**Paraphrased problem context:** A 32-bit IEEE-754 single-precision number has bits 00111110011011010000000000000000 (sign/exponent/fraction: 0 | 01111100 | 11011010000000000000000). Which listed decimal value is closest? A:1.45×10¹. B:1.45×10^-1. C:2.27×10^-1. D:2.27×10¹.

## Solution

1. For a normal single-precision number, value=(-1)^sign × (1.fraction)₂ × 2^(stored exponent-127). Here sign=0, exponent 01111100₂=124, and the exponent is therefore -3.

2. The significand is 1+2^-1+2^-2+2^-4+2^-5+2^-7=1.8515625. Multiplication by 2^-3 gives 0.2314453125.

3. Compare the offered approximations rather than requiring an exact match. Its distance from 0.227 is 0.0044453125, much less than its distance from 0.145; 14.5 and 22.7 are far away. Hence C. The hidden leading 1 and exponent bias are both essential.

**Derived answer:** A

**Source access:** Open archive member CS/CS2-2017.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** L1 and L2 cache access times are 1 and 8 cycles. The additional L2-to-memory miss penalty is 18 cycles. The L1 miss rate is twice the L2 miss rate. Given AMAT=2 cycles, find the rates (L1,L2). A:(0.111,0.056). B:(0.056,0.111). C:(0.0892,0.1784). D:(0.1784,0.0892).

## Solution

1. Let m be the local L2 miss rate, conditional on reaching L2. The L1 miss rate is 2m. Every access pays 1 cycle, an L1 miss adds 8, and an L2 miss on that path adds 18.

2. Therefore 2=1+2m(8+18m). Expanding gives 36m²+16m-1=0. The quadratic formula gives m=(-16±√400)/72, so its nonnegative root is 4/72=1/18; the other root is invalid as a probability.

3. Thus L2 misses about 0.05556 and L1 misses 1/9≈0.11111. In the requested L1,L2 order, the rounded pair is A. Treating the L2 rate as a global rate, or charging lower-level time on every hit, would give a different model.

**Question:** [Official archived paper page 18](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Derived answer:** 4.72

**Source access:** Open archive member CS/CS2-2017.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** I-cache read time/hit ratio:2 ns/0.8; D-cache:2 ns/0.9; shared L2:8 ns/0.9. Main-memory read time is 90 ns. Caches are direct mapped, use referred-word-first and write-back, and every dirty bit is 0. Of reads,60% fetch instructions and40% fetch operands. Find average read time in ns to two decimals.

## Solution

1. Compute the chance of reaching L2 by weighting the two L1 miss rates: 0.6(1-0.8)+0.4(1-0.9)=0.12+0.04=0.16. Every read first pays the 2 ns L1 lookup.

2. Conditional on an L1 miss, the L2 lookup adds 8 ns. Its local miss probability is 0.1, and such a miss adds 90 ns for memory. The expected additional time on an L1 miss is therefore 8+0.1·90=17 ns.

3. AMAT=2+0.16·17=4.72 ns. As a separate check, instruction reads average 2+0.2·17=5.4 ns and data reads 2+0.1·17=3.7 ns; 0.6·5.4+0.4·3.7=4.72. Clean blocks eliminate dirty write-back penalties, and referred-word-first permits the demanded read to finish without waiting for an unspecified whole-block transfer.

**Derived answer:** 18

**Paraphrased problem context:** A byte-addressable main memory contains 2^32 bytes, divided into 32-byte blocks. A direct-mapped cache has 512 lines. How many address bits form the tag field?

## Solution

1. There are 2^32 separately addressable bytes, so a memory address needs 32 bits. A 32-byte block needs log₂32=5 low-order offset bits to select a byte within it.

2. A direct-mapped cache with 512=2^9 lines uses 9 index bits to select the one cache line where a block may reside.

3. The remaining high-order bits distinguish the different memory blocks that map to that same line: tag=32-5-9=18 bits. Equivalently, memory has 2^27 blocks and each of 2^9 lines represents 2^18 possible blocks. Do not use 512 as the cache byte capacity; it is the number of lines.

**Paraphrased problem context:** C declaration: struct data { int marks[100]; char grade; int cnumber; }; struct data student; Register R1 holds the base address of student. How to access student.grade efficiently? A postincrement (R1)+; B predecrement −(R1); C register direct R1; D indexed X(R1), with signed 16-bit displacement X.

## Solution

1. A structure layout assigns each member a fixed byte offset from its base. The compiler determines grade’s offset after the marks array, accounting for the implementation’s layout rules.

2. R1 already contains the base. Computing effective address R1+X directly selects grade without traversing the array or modifying R1.

3. That is displacement/index addressing X(R1), D. Register direct accesses the register rather than the field; predecrement and postincrement unnecessarily change the base. No assumed int width is needed.

**Paraphrased problem context:** A two-level cache sees 1.4 memory accesses per instruction. L1 miss rate is 0.1; L2 has 7 misses per 1000 instructions. Find the L2 miss rate to two decimals.

## Solution

1. Choose a common basis of 1000 instructions. This gives 1000×1.4=1400 L1 accesses.

2. L1 misses on 0.1×1400=140 of these, and only those misses access L2. L2 therefore sees 140 accesses, not 1400 and not 1000.

3. Its local miss rate is L2 misses/L2 accesses=7/140=0.05. Dividing 7 by 1400 instead computes a global miss rate and answers a different question.

**Paraphrased problem context:** A RISC instruction is 4 bytes. Branch offsets are byte offsets relative to the NEXT instruction. Instructions are i:add R2,R3,R4; i+1:sub R5,R6,R7; i+2:cmp R1,R9,R10; i+3:beq R1,Offset. Branch target is i. Find signed decimal Offset.

## Solution

1. Let the byte address of instruction i be A. Then i+1,i+2,i+3 have addresses A+4,A+8,A+12.

2. The branch uses the next instruction as reference, which is i+4 at A+16, not the branch’s own address A+12.

3. Offset=target−reference=A−(A+16)=−16 bytes. The negative sign denotes a backward branch. Counting three instruction gaps from the branch itself would incorrectly give −12.

**Paraphrased problem context:** Five pipeline stages IF,ID,OF,EX,WB take 5,4,20,10,3 ns; interstage buffer overhead is 2 ns. NP uses these five stages. EP splits OF into OF1=12 ns,OF2=8 ns. Find EP speedup over NP for 20 independent hazard-free instructions, to two decimals.

## Solution

1. The clock period is the slowest stage plus buffer overhead. NP therefore has period max(5,4,20,10,3)+2=22 ns. Its five-stage pipeline needs 5+(20−1)=24 cycles, or 528 ns.

2. EP has stages 5,4,12,8,10,3 ns, so its period is 12+2=14 ns. Six stages need 6+19=25 cycles for the same twenty instructions, or 350 ns.

3. Speedup is old time/new time=528/350=1.508571..., rounding to 1.51. Using only the clock ratio 22/14 neglects the extra fill cycle.

**Paraphrased problem context:** A 256-block, 2-way set-associative cache uses LRU and starts empty. Repeat this block-reference sequence ten times: 0,128,256,128,0,128,256,128,1,129,257,129,1,129,257,129. Count conflict misses, excluding compulsory first-access misses.

## Solution

1. There are 256/2=128 sets. Block number modulo 128 puts {0,128,256} in set 0 and {1,129,257} in set 1; each set holds only two blocks.

2. For the first set-0 subsequence 0,128,256,128,0,128,256,128 the outcomes are compulsory,compulsory,compulsory,hit,conflict,hit,conflict,hit. LRU ends with 256 then 128 from least to most recent. Set 1 behaves identically.

3. Each later subsequence starts with those two survivors: accesses to its first,third,fifth,seventh entries miss, all now conflicts. Thus repetition 1 has four conflicts total, and each of nine later repetitions has eight. Total=4+9×8=76 conflicts, alongside six compulsory misses.

**Paraphrased problem context:** A cache has capacity N words, blocks of B words, and a 10-bit tag when directly mapped. With unchanged capacity and block size, redesign as 16-way set associative. Find tag width.

## Solution

1. Address bits are partitioned into tag, set index, and block offset. Keeping B fixed leaves offset width unchanged.

2. A direct-mapped cache has N/B sets. A 16-way cache of the same total capacity has N/(16B) sets, requiring log₂16=4 fewer index bits.

3. The address width has not changed, so those four bits move to the tag. New tag width=10+4=14 bits. Associativity changes the set count, not the number of offset bits.
