**Independently derived answer:** C

**Paraphrased problem context:** How many 32K×1 RAM chips are needed for 256K bytes of memory? A 8; B 32; C 64; D 128.

## Solution

Each 32K×1 chip stores 32K bits. The required 256K bytes equal 2048K bits. Therefore 2048K/32K=64 chips, C.

Teaching detail:
A 32K×1 chip stores 32K bits, not 32K bytes. The requested capacity is 256K·8 bits. Dividing gives(256·8)/32=64 chips. Equivalently, eight chips in parallel provide a byte-wide 32K bank, and eight banks provide 256K byte addresses. Confusing width in bits with bytes would undercount by a factor of eight.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** When does a CPU normally begin interrupt service? A immediately when raised; B after checking at the end of fetch; C after checking when the current instruction finishes; D at fixed time intervals.

## Solution

In the conventional instruction-cycle model, an enabled pending interrupt is checked after the current instruction completes, then control transfers to its service routine. This preserves an instruction boundary rather than interrupting immediately at an arbitrary internal step. Thus C.

Teaching detail:
The usual instruction-cycle model completes an instruction before recognizing a pending interrupt and saving a consistent next-instruction state. This gives C. An asynchronous request can arrive earlier, but arrival is not the same as immediate transfer of control. Fetch completion is too early in that simple model, and periodic checking is not the general interrupt mechanism. Architecture-specific restartable instructions and precise-exception implementations are finer details outside this convention.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B under continuous overlapped execution

**Paraphrased problem context:** Four pipeline stages S1–S4 require cycles per instruction: I1=(2, 1, 1, 1), I2=(1, 3, 2, 2), I3=(2, 1, 1, 3), I4=(1, 2, 2, 2). Execute two iterations of I1, I2, I3, I4. Find total cycles under overlapping buffered-stage execution, ignoring loop-control overhead: A 16; B 23; C 28; D 30.

## Solution

Ignoring loop-control overhead and allowing the eight instructions from two iterations to overlap, each stage starts after both its instruction’s previous stage and the previous instruction’s same stage finish. The four stage-completion times are(2, 3, 4, 5), (3, 6, 8, 10), (5, 7, 9, 13), (6, 9, 11, 15), (8, 10, 12, 16), (9, 13, 15, 18), (11, 14, 16, 21), (12, 16, 18, 23). Thus completion is at cycle 23, B. This recurrence uses buffered stage outputs; it does not charge an additional loop branch or force a pipeline drain between iterations. Such implementation choices are not explicitly specified by the prompt.

Teaching detail:
Construct a completion-time grid. A cell cannot start until the same instruction finishes its prior stage and the previous instruction releases this stage. Thus completion(i, j)=max(completion(i−1, j), completion(i, j−1))+duration(i, j). Applying it to the eight instruction rows yields final completion 23; the full row table is given above. Simply summing durations would ignore overlap, while assuming every stage takes one cycle ignores the supplied table. Pipeline draining or stage blocking without buffers changes the model, so those assumptions remain explicit.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** An initially empty four-way cache has 16 blocks and memory 256 blocks. Reference sequence:0, 255, 1, 4, 3, 8, 133, 159, 216, 129, 63, 8, 48, 32, 73, 92, 155. With LRU within each set, which block is absent at the end? A 3; B 8; C 129; D 216.

## Solution

There are 16/4=4 sets, selected by block number modulo 4. Simulating LRU gives oldest-to-newest final sets: set 0=[8, 48, 32, 92], set 1=[1, 133, 129, 73], set 2=[], set 3=[3, 159, 63, 155]. Thus 3, 8, 129 remain but 216 has been evicted, D. In set 0, insertion 32 removes 4 and insertion 92 removes 216 after 8 was refreshed.

Teaching detail:
There are 16/4=4 sets; choose set number by block modulo 4. Only blocks mapping to the same set compete for four ways. In set 0, references are 0, 4, 8, 216, 8, 48, 32, 92. The second 8 refreshes its recency; inserting 48 removes 0, 32 removes 4, and 92 removes 216. The final set is 8, 48, 32, 92. Other sets retain 3 and 129. Hence 216, option D, is the absent listed block.
