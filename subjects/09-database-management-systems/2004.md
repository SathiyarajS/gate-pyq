**Paraphrased problem context:** Relations R1(A,B,C) and R2(D,E) have keys A and D respectively. C is a foreign key in R1 referencing D in R2. Instances r1,r2 satisfy referential integrity. Which expression must be empty? Projection outputs in set differences are identified by their compatible single domains.
Options:
(A) π_D(r2) − π_C(r1)
(B) π_C(r1) − π_D(r2)
(C) π_D(r1 ⋈_(C≠D) r2)
(D) π_C(r1 ⋈_(C=D) r2)

## Solution

1. Referential integrity requires every C value in r1 to occur as a referenced D value in r2. Hence π_C(r1)⊆π_D(r2), and π_C(r1)−π_D(r2) is empty, B, under classical relational algebra without SQL nulls.

2. The reverse difference can contain unreferenced parent keys.

3. Teaching check: Think of C values as child references and D values as parent keys. A dangling reference would be a value in the child projection absent from the parent projection. Referential integrity forbids precisely that difference, while allowing parent rows with no children.

**Paraphrased problem context:** Student(rollno,name,address) has key rollno; Enroll(rollno,courseno,coursename) has composite key (rollno,courseno). They have 120 and 8 tuples respectively. What are the maximum and minimum sizes of Student ⋈ Enroll (natural join)? No foreign-key constraint is stated.
Options:
(A) 8,8
(B) 120,8
(C) 960,8
(D) 960,120

## Solution

1. In the GFG reproduction Student.rollno is the underlined key, while Enroll has the composite key(rollno,courseno). Each of the8 enrollment tuples can match at most one Student tuple, so the maximum join size is8.

2. With only the stated keys, all enrollment roll numbers may be absent from Student, giving minimum0; no listed pair is then correct. If the intended additional constraint is Enroll.rollno referencing Student.rollno, every enrollment matches exactly once and both maximum/minimum are8, A.

3. This foreign-key constraint is not stated and is not inferred from matching attribute names alone.

4. Teaching check: The maximum is attained when all eight enrollments use existing student roll numbers, possibly different courses for the same student. The minimum zero is attained by eight enrollments with roll numbers absent from Student. Primary-key uniqueness alone rules out duplicate student matches, not missing matches.

**Paraphrased problem context:** StudentPerformance(name,courseNo,rollNo,grade) has dependencies (name,courseNo)→grade; (rollNo,courseNo)→grade; name→rollNo; rollNo→name. What is its highest listed normal form?
Options:
(A) 2NF
(B) 3NF
(C) BCNF
(D) 4NF

## Solution

1. The candidate keys are{name,courseNo} and{rollNo,courseNo}. Thus name,rollNo,courseNo are prime attributes, and grade is non-prime.

2. Dependencies from either key to grade satisfy3NF. The non-key determinants name and rollNo determine only another prime attribute, so these dependencies also satisfy3NF.

3. But name→rollNo and rollNo→name violate BCNF because neither determinant determines courseNo. Highest listed normal form is3NF.

4. Teaching check: Compute closures: {name,courseNo}+ and {rollNo,courseNo}+ both contain all attributes, but name+ contains only name,rollNo. In 3NF a non-superkey determinant may determine a prime attribute; BCNF forbids that exception. This is exactly why the two normal forms differ here.

**Paraphrased problem context:** Student(name,sex,marks), key name, contains at least one boy and one girl. Let ρ_(n,x,m)(Student) rename the three attributes. Interpret π_name(σ_(sex=female)(Student)) − π_name(Student ⋈_(sex=female ∧ x=male ∧ marks≤m) ρ_(n,x,m)(Student)).
Options:
(A) Names of girls with the highest marks
(B) Names of girls with more marks than some boy
(C) Names of girls with marks not less than some boy
(D) Names of girls with more marks than every boy

## Solution

1. The left expression selects all female names. The right expression finds a female student paired with a male student whose marks m satisfy female marks≤m, and projects that female name.

2. Subtracting these removes every girl for whom at least one boy has marks greater than or equal to hers. Remaining girls therefore have marks greater than EVERY boy.

3. The primary-key name makes the projected subtraction unambiguous, and the stated existence of boys avoids a vacuous comparison.

4. Teaching check: The joined part is an existential counterexample set: it contains a girl if there exists a boy with marks at least hers. Subtracting all such counterexamples converts “there exists a violating boy” into “every boy has fewer marks.” Equality is removed because the join uses ≤.

**Paraphrased problem context:** The order of an internal B+ tree node is its maximum number of children. Child pointers use 6 bytes, search keys 14 bytes and each node occupies a 512-byte block. With no stated header overhead, what is the order?
Options:
(A) 24
(B) 25
(C) 26
(D) 27

## Solution

1. With order p, an internal node holds p child pointers and p−1 separator keys. The size is6p+14(p−1)=20p−14≤512, so p≤26.3 and the maximum integer is26.

2. At p=26 the node uses506 bytes; p=27 would need526 bytes. No unmentioned header overhead is assumed.

3. Teaching check: There is one fewer separator key than child pointers, so a p-child node needs p pointers and p−1 keys. Using p of each would incorrectly lower the capacity. Testing the two neighboring integers confirms maximality rather than relying only on rounded division.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203330/GATE2004.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Independently derived answer:** D

**Paraphrased problem context:** Employee(name,sex,salary,deptName) has key name. What department names does this SQL query return?
SELECT deptName FROM Employee
WHERE sex='M'
GROUP BY deptName
HAVING AVG(salary) > (SELECT AVG(salary) FROM Employee);
Options:
(A) Departments whose average salary exceeds the company average
(B) Departments whose male average salary exceeds the company-wide male average
(C) Departments whose male average salary exceeds the average of all employees in that department
(D) Departments whose male average salary exceeds the company average

## Solution

1. WHERE sex=M filters the outer rows to male employees before grouping by department. HAVING compares each such group’s average salary with the uncorrelated subquery SELECT AVG(salary) FROM Employee, which averages all employees company-wide.

2. Therefore it returns departments whose male employees’ average exceeds the overall company average. The inner query has no male filter and is not restricted to the same department.

3. Teaching check: Read SQL in stages: WHERE keeps only males; GROUP BY makes one male group per department; HAVING compares its average against a separately computed company-wide average. There is no correlation predicate linking the subquery to the department, and no sex filter inside it.
