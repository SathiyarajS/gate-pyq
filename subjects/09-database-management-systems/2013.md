# GATE 2013 CS: Q64 (printed CS Q54)

**Question:** [Official archived paper page 12](https://web.archive.org/web/20130418030400id_/http://www.gate.iitb.ac.in:80/gate2013/wp-content/uploads/2013/03/CS-A.pdf#page=12); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

## Solution

D never occurs on any right-hand side, so every key must contain D. The dependencies A→B, B→F, F→E and E→A form a reachability cycle among A, B, E, F. Starting from any one of those four attributes derives the other three, C and H through B→CFH, and G through F→EG. Consequently A+, B+, E+, F+ each equal {A, B, C, E, F, G, H}, missing only D. Thus AD, BD, DE and DF are candidate keys, and each is minimal. For completeness, any set containing none of A, B, E, F can include only C, D, G, H; its closure can at most add G via CH→G and can never reach that four-attribute cycle. Therefore every key includes at least one of A, B, E, F, and a minimal key includes exactly one together with D. There are precisely four candidate keys, option B.

**Question:** [Official archived paper page 12](https://web.archive.org/web/20130418030400id_/http://www.gate.iitb.ac.in:80/gate2013/wp-content/uploads/2013/03/CS-A.pdf#page=12); consult original wording, diagrams and choices.

**Official answer:** A

**Derived answer:** A

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

## Solution

Atomic fields give 1NF. The candidate keys are AD, BD, DE, DF, so the prime attributes are A, B, D, E, F and the non-prime attributes are C, G, H. From the given dependency A→BC we obtain A→C. Here A is a proper subset of the candidate key AD and C is non-prime, so C has a partial dependency on a candidate key. This violates 2NF. Therefore the relation is in 1NF but not 2NF, option A; no higher-normal-form analysis is needed.
