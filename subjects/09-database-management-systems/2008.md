**Independently derived answer:** C

**Paraphrased problem context:** Which tuple-calculus expressions equal ∀t∈r P(t)? I: ¬∃t∈r P(t). II: ∃t∉r P(t). III: ¬∃t∈r ¬P(t). IV: ∃t∉r ¬P(t).

(A) I only
(B) II only
(C) III only
(D) III and IV only

## Solution

1. A universal statement fails exactly when there is a counterexample. Here a counterexample is a tuple t in r for which P(t) is false.
2. Excluding every such counterexample gives ¬∃t∈r ¬P(t), which is III.
3. I instead says no tuple satisfies P; II and IV discuss tuples outside r. Therefore III only, C.

**Independently derived answer:** A

**Paraphrased problem context:** A clustering index is defined on fields of which type?

(A) Non-key and ordering
(B) Non-key and non-ordering
(C) Key and ordering
(D) Key and non-ordering

## Solution

1. An ordering field determines the physical ordering of the data file.
2. If that field is non-key, multiple records can share a value and form a contiguous cluster, indexed by a clustering-index entry.
3. This classical classification gives A. An ordering key instead gives a primary index; a non-ordering field gives a secondary index. Modern clustered-index terminology can be broader.

# GATE 2008: Q68 (printed CS Q68)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** R(P,Q,R1,R2,R3) and S(P,Q,S1,S2) each have key {P,Q}. Which relational-algebra queries are equivalent? ⋈ denotes natural join. I: πP(R⋈S). II: πP(R)⋈πP(S). III: πP(πP,Q(R)∩πP,Q(S)). IV: πP(πP,Q(R)−(πP,Q(R)−πP,Q(S))).

(A) I and II only
(B) I and III only
(C) I,II,III only
(D) I,III,IV only

## Solution

1. The natural join matches both common attributes P and Q. Consequently I returns P values of pairs (P,Q) appearing in both relations, exactly III.
2. Since A−(A−B)=A∩B, IV is also equivalent. II only matches P after discarding Q: R containing (p,q1) and S containing (p,q2), q1≠q2, makes II nonempty but I empty.
3. Thus only I, III and IV are equivalent, option D.

# GATE 2008: Q69 (printed CS Q69)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Book(Title,Author,Catalog_no,Publisher,Year,Price) and Collection(Title,Author,Catalog_no) have key {Author,Title}. Dependencies: Title Author→Catalog_no; Catalog_no→Title Author Publisher Year; Publisher Title Year→Price. Which statement is true?

(A) Both are in BCNF
(B) Both are in 3NF only
(C) Book is in 2NF and Collection is in 3NF
(D) Both are in 2NF only

## Solution

1. In Book, both {Title,Author} and {Catalog_no} are candidate keys. No given dependency makes a nonprime attribute depend on a proper subset of a candidate key, so Book is in 2NF.
2. Publisher,Title,Year→Price violates 3NF because its determinant is not a superkey and Price is nonprime. Collection has only Title, Author and Catalog_no; its nontrivial determinants are candidate keys, so it is BCNF and hence also 3NF.
3. Therefore C is true. The wording of C does not say Collection is only in 3NF.

# GATE 2008: Q70 (printed CS Q70)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 14. Consult original wording and choices.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** A file has 16384 records of 32 bytes each, with a 6-byte key. It is ordered on a non-key field and uses unspanned organization. Block size is 1024 bytes and block pointers occupy 10 bytes. A multilevel secondary index is built on the key. How many first- and second-level index blocks are needed?

(A) 8 and 0
(B) 128 and 6
(C) 256 and 4
(D) 512 and 5

## Solution

1. Because the file is not ordered by the indexed key, the first secondary-index level is dense, with one entry per record. An entry occupies 6+10=16 bytes, so a 1024-byte block holds 64 entries.
2. The first level therefore needs 16384/64=256 blocks. The second level indexes those ordered first-level blocks, requiring 256/64=4 blocks.
3. Option C. The 512 data blocks are not the first-level index-block count.

**Paraphrased problem context:** An ER diagram has strong entities M with attributes M1 (key), M2,M3, and P with attributes P1 (key),P2. Relationship R1 is many-to-one from M to P, with total participation of M. N is a weak entity with partial key N1 and attribute N2. Its identifying relationship R2 is many-to-one from N to owner P, with total participation of N. Neither relationship has attributes. What is the minimum number of tables in the standard relational mapping?

(A) 2
(B) 3
(C) 4
(D) 5

## Solution

1. Use three relations: P(P1,P2), M(M1,M2,M3,P1), and N(P1,N1,N2). R1 is many-to-one from M to P with total participation of M, so a P1 foreign key in M represents it without a separate relationship table.
2. N is weak, R2 is its identifying many-to-one relationship with P, and N1 is the partial key; include P1 in N, whose primary key is (P1,N1). Thus the standard ER-to-relational mapping needs three tables, option B.

# GATE 2008: Q83 (printed CS Q83)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 18. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** An ER diagram has strong entities M with attributes M1 (key), M2,M3, and P with attributes P1 (key),P2. Relationship R1 is many-to-one from M to P, with total participation of M. N is a weak entity with partial key N1 and attribute N2. Its identifying relationship R2 is many-to-one from N to owner P, with total participation of N. Neither relationship has attributes. In the minimum-table standard mapping, which is the attribute set of one resulting table?

(A) {M1,M2,M3,P1}
(B) {M1,P1,N1,N2}
(C) {M1,P1,N1}
(D) {M1,P1}

## Solution

1. The many-to-one R1 relationship associates each M with a unique P. Total participation means every M must have that owner/reference.
2. Store P’s key P1 as a foreign key beside M’s own attributes M1,M2,M3; a separate R1 table is unnecessary.
3. Thus M’s table has {M1,M2,M3,P1}, A. N is represented separately by owner key P1, partial key N1 and N2; there is no direct M-to-N relationship to justify the other sets.
