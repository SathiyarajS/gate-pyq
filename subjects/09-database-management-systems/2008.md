## Solution

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

The natural join matches both common attributes P and Q. Consequently I returns P values of pairs (P,Q) appearing in both relations, exactly III. Since A−(A−B)=A∩B, IV is also equivalent. II only matches P after discarding Q: R containing (p,q1) and S containing (p,q2), q1≠q2, makes II nonempty but I empty. Thus only I, III and IV are equivalent, option D.

# GATE 2008: Q69 (printed CS Q69)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

In Book, both {Title,Author} and {Catalog_no} are candidate keys. No given dependency makes a nonprime attribute depend on a proper subset of a candidate key, so Book is in 2NF. Publisher,Title,Year→Price violates 3NF because its determinant is not a superkey and Price is nonprime. Collection has only Title, Author and Catalog_no; its nontrivial determinants are candidate keys, so it is BCNF and hence also 3NF. Therefore C is true. The wording of C does not say Collection is only in 3NF.

# GATE 2008: Q70 (printed CS Q70)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Because the file is not ordered by the indexed key, the first secondary-index level is dense, with one entry per record. An entry occupies 6+10=16 bytes, so a 1024-byte block holds 64 entries. The first level therefore needs 16384/64=256 blocks. The second level indexes those ordered first-level blocks, requiring 256/64=4 blocks. Option C. The 512 data blocks are not the first-level index-block count.

# GATE 2008: Q82 (printed CS Q82)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 18. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Use three relations: P(P1,P2), M(M1,M2,M3,P1), and N(P1,N1,N2). R1 is many-to-one from M to P with total participation of M, so a P1 foreign key in M represents it without a separate relationship table. N is weak, R2 is its identifying many-to-one relationship with P, and N1 is the partial key; include P1 in N, whose primary key is (P1,N1). Thus the standard ER-to-relational mapping needs three tables, option B.
