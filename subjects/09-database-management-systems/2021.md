

# GATE 2021 CS1: Q23 (printed CS Q13)

**Question:** [Official archived paper page 18](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=18); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A in the basic repeated undo/redo model

**Paraphrased problem context:** A database crashes again while recovering from a previous crash. No checkpoints are taken during transactions or recovery. Select correct statements in the intended basic recovery model. A the same undo and redo lists are used on restarting recovery; B further recovery is impossible; C transactions already undone/redone will not be recovered again; D the database becomes inconsistent.

## Solution

Without a new checkpoint or changed transaction-completion history, restarting recovery analyzes the same log to identify the same committed and uncommitted transactions. Undo/redo actions are designed to be idempotent, so a second crash does not make recovery impossible or inherently inconsistent. Thus A in the intended basic log-recovery model. An implementation with compensation log records may track already completed recovery work more precisely; the answer is not a universal claim that every recovery algorithm literally repeats an unchanged physical work list.

Redo reapplies logged updates for transactions whose effects must survive; undo removes effects of incomplete transactions. Idempotence means redo(redo(state))=redo(state), with corresponding safe repeated undo semantics. A crash can leave only a prefix of recovery finished, so a correct recovery design cannot assume that restarting itself destroys consistency. No new checkpoint is available to certify that the earlier log prefix can be ignored. More elaborate logging of recovery work is precisely the qualification already retained above.

# GATE 2021 CS1: Q33 (printed CS Q23)

**Question:** [Official archived paper page 21](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=21); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 819 to 820 OR 205 to 205

**Derived answer:** 820 under uniform bag estimation; official also accepts205

**Paraphrased problem context:** A database relation r(A,B) is stated to contain 1200 tuples. A takes integer values 6 through 20 and B values 1 through 20; A and B are independently distributed. Estimate the output count of σ[(A>10) OR (B=18)](r). The source does not explicitly assume uniform distributions and its tuple count exceeds the distinct-pair domain size.

## Solution

Under uniform independent attribute estimates, P(A>10)=10/15 and P(B=18)=1/20. Inclusion-exclusion gives selection fraction10/15+1/20−(10/15)(1/20)=41/60. Multiplying by 1200 gives 820. The official key also accepts205, which is the number of distinct qualifying pairs in the full15×20 value grid: 200 pairs with A>10 plus5 additional pairs with B=18. Both official alternatives are preserved exactly. Premise issues: independence alone does not imply uniform marginals, and a mathematical set relation with only these two finite-domain attributes can have at most300 distinct tuples, not1200. The820 estimate therefore uses bag/count statistics and uniformity assumptions; 205 corresponds to the distinct-pair grid, not1200 distinct source tuples.

There are 15 A-values and 20 B-values. Ten A-values (11 through 20) pass A>10, while one B-value passes B=18. The overlap must be subtracted because OR counts a tuple satisfying both only once. Under the full-grid model there are 10×20+15×1−10×1=205 qualifying pairs out of 300, so the selectivity is 205/300=41/60. Applying that fraction to the stated 1200 rows yields 820. These are distinct interpretations, not two different arithmetic roundings of one count.

**Paraphrased problem context:** empAge(empNo,age) stores ages of 500 employees, with empNo a key. Evaluate π_empNo(empAge ⋈_[age>age1] ρ_[empNo1,age1](empAge)). A employee numbers with maximum age only; B those older than exactly one other employee; C all those whose age is not minimum; D all those with minimum age.

## Solution

The renamed second copy supplies another employee’s age. The theta join retains a first-copy employee whenever some other row has a strictly smaller age. Projecting empNo therefore returns exactly employees whose age is not the minimum. Minimum-age ties are all excluded. Thus C.

The join is existential after projection: an employee appears if there exists any employee of smaller age. An employee of minimum age has no such witness and is excluded, even if multiple employees tie for minimum. For ages 20,20,30,40 the output contains the 30- and 40-year-old employee numbers. The 40-year-old has several witnesses, but set projection removes duplicates; it is not restricted to 'exactly one' younger employee.

# GATE 2021 CS1: Q42 (printed CS Q32)

**Question:** [Official archived paper page 28](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=28); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Let ri(z),wi(z) denote reads/writes by transaction Ti. S1=r1(x),r1(y),r2(x),r2(y),w2(y),w1(x). S2=r1(x),r2(x),r2(y),w2(y),r1(y),w1(x). Which schedules are conflict-serializable? A S1 only; B S2 only; C both; D neither.

## Solution

In S1, r1(y) before w2(y) gives T1→T2, while r2(x) before w1(x) gives T2→T1, creating a cycle. In S2, w2(y) before r1(y) and r2(x) before w1(x) both give only T2→T1. Therefore S1 is not conflict-serializable while S2 is, equivalent to T2 thenT1. Answer B.

Only different transactions accessing the same item, with at least one write, create precedence edges. Reads of x by both transactions do not conflict. In S1, y imposes T1 before T2 whereas x imposes T2 before T1, making a directed cycle. Moving r1(y) after w2(y) in S2 reverses the y constraint; all constraints now agree. An acyclic precedence graph is the necessary and sufficient test for conflict serializability.

# GATE 2021 CS1: Q43 (printed CS Q33)

**Question:** [Official archived paper page 28](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=28); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** R(P,Q,S,T,X,Y,Z,W) has FDs PQ→X, P→YX, Q→Y, Y→ZW. D1 decomposes it into (P,Q,S,T),(P,T,X),(Q,Y),(Y,Z,W). D2 decomposes it into (P,Q,S),(T,X),(Q,Y),(Y,Z,W). Which is correct? A D1 lossless/D2 lossy; B D1 lossy/D2 lossless; C both lossless; D both lossy.

## Solution

For D1, join PQST with PTX on PT: P→X makes PT a key of PTX, so this step is lossless. Join QY using Q→Y, then YZW using Y→ZW; both steps are lossless. D2 separates TX from every other component, leaving no common attribute to reconnect it. A concrete legal relation can contain two rows with distinct P, Q, S, T, X, Y, Z, W values; all listed FDs hold, but joining its D2 projections pairs each TX row with either other-part row, creating spurious tuples. Thus D1 is lossless and D2 lossy, A.

For D1, add projections in the order PQST,PTX,QY,YZW. Their intersections with the accumulated schema are PT,Q,Y respectively, each determining all attributes of the new projection via P→X,Q→Y,Y→ZW. The binary lossless-join criterion applies at each step. For D2 use two original tuples (p1,q1,s1,t1,x1,y1,z1,w1) and (p2,q2,s2,t2,x2,y2,z2,w2) with every subscripted value distinct. All FDs hold, yet the join contains (p1,q1,s1,t2,x2,y1,z1,w1), which was not an original tuple.

**Paraphrased problem context:** Relational model statements: S1 a relation schema has at most one foreign key; S2 a foreign key in R cannot refer to tuples of R itself. A both; B only S1; C only S2; D neither.

## Solution

A relation can have several foreign keys, for example managerId and departmentId. It can also reference itself, as managerId referencing another employee in the same employee relation. Both proposed restrictions are false, D.

A concrete schema is Employee(id,managerId,deptId), where managerId references Employee(id) and deptId references Department(id). It simultaneously refutes both claims. A foreign key enforces referenced-key membership; it does not impose a one-foreign-key limit or require a different relation name.

## Solution

The secondary candidate-key index is dense, with one entry per student. Each entry needs 12+7=19 bytes. With no split entries, each4096-byte block holds floor(4096/19)=215 entries. Thus ceil(150000/215)=698 blocks.

ANum is not the ordering key of the data file, so a sparse primary index with one entry per data block is not applicable. Packing permits 215 complete 19-byte entries per block because 216 require 4104 bytes. There are 697 full blocks holding 149855 entries and 145 entries in a final block.

# GATE 2021 CS2: Q42 (printed CS Q32)

**Question:** [Official archived paper page 73](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=73); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Schedule R1(Y),R1(X),R2(Z),R1(Y),W1(X),R2(Z),W2(Y),R3(X),W3(Z). P: conflict-serializable. Q: if T3 commits before T1 finishes, schedule is recoverable. A both; B only P; C only Q; D neither.

## Solution

On Y, R1(Y) precedes W2(Y), giving T1→T2. On X, W1(X) precedes R3(X), giving T1→T3. On Z, R2(Z) precedes W3(Z), giving T2→T3. This acyclic graph has serial orderT1, T2, T3, so P is true. T3 reads X written by T1; committing T3 before T1 finishes violates recoverability. Hence Q is false and B holds. All transaction subscripts were visually checked.

Conflicts require the same data item, distinct transactions, and at least one write. Repeated reads of Z do not introduce a reverse edge. Serializability and recoverability are distinct: an acyclic precedence graph controls equivalent ordering of operations, whereas a reads-from dependency requires the writer to commit before its reader commits.

# GATE 2021 CS2: Q50 (printed CS Q40)

**Question:** [Official archived paper page 78](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=78); consult original wording, diagrams and choices.

**Official answer:** A; C; D

**Derived answer:** A; C; D

**Paraphrased problem context:** On U(P,Q,R,S,T), dependencies P→QR and RS→T hold. Which follow? A PS→T; B R→T; C P→R; D PS→Q.

## Solution

P→QR gives P→R and P→Q by decomposition. With PS, derive R and retain S, then RS→T gives PS→T; also PS→Q follows by augmentation and decomposition. Starting only from R yields closure{R}, so R→T is not implied. Therefore A, C, D.

Attribute closure of PS starts {P,S}, then adds Q,R using P→QR, then T using RS→T, giving all five attributes. Closure of P is {P,Q,R}, and closure of R is only {R}. The latter is a complete test of nonimplication: no listed dependency can fire from R alone, so S cannot be conjured merely because it appears beside R in RS→T.
