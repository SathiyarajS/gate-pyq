

# GATE 2021 CS1: Q23 (printed CS Q13)

**Question:** [Official archived paper page 18](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=18); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A in the basic repeated undo/redo model

## Solution

Without a new checkpoint or changed transaction-completion history, restarting recovery analyzes the same log to identify the same committed and uncommitted transactions. Undo/redo actions are designed to be idempotent, so a second crash does not make recovery impossible or inherently inconsistent. Thus A in the intended basic log-recovery model. An implementation with compensation log records may track already completed recovery work more precisely; the answer is not a universal claim that every recovery algorithm literally repeats an unchanged physical work list.

**Question:** [Official archived paper page 21](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=21); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 819 to 820 OR 205 to 205

**Derived answer:** 820 under uniform bag estimation; official also accepts205

## Solution

Under uniform independent attribute estimates, P(A>10)=10/15 and P(B=18)=1/20. Inclusion-exclusion gives selection fraction10/15+1/20−(10/15)(1/20)=41/60. Multiplying by 1200 gives 820. The official key also accepts205, which is the number of distinct qualifying pairs in the full15×20 value grid: 200 pairs with A>10 plus5 additional pairs with B=18. Both official alternatives are preserved exactly. Premise issues: independence alone does not imply uniform marginals, and a mathematical set relation with only these two finite-domain attributes can have at most300 distinct tuples, not1200. The820 estimate therefore uses bag/count statistics and uniformity assumptions; 205 corresponds to the distinct-pair grid, not1200 distinct source tuples.

# GATE 2021 CS1: Q43 (printed CS Q33)

**Question:** [Official archived paper page 28](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=28); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

For D1, join PQST with PTX on PT: P→X makes PT a key of PTX, so this step is lossless. Join QY using Q→Y, then YZW using Y→ZW; both steps are lossless. D2 separates TX from every other component, leaving no common attribute to reconnect it. A concrete legal relation can contain two rows with distinct P, Q, S, T, X, Y, Z, W values; all listed FDs hold, but joining its D2 projections pairs each TX row with either other-part row, creating spurious tuples. Thus D1 is lossless and D2 lossy, A.

**Derived answer:** A; C; D

## Solution

P→QR gives P→R and P→Q by decomposition. With PS, derive R and retain S, then RS→T gives PS→T; also PS→Q follows by augmentation and decomposition. Starting only from R yields closure{R}, so R→T is not implied. Therefore A, C, D.
