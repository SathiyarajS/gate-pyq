**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** Choose the ER diagram for: instructors teach courses; students register for courses; courses receive classrooms; instructors guide students. Rectangles denote entities and diamonds denote relationships. A diagram (i) uses a Student diamond and Registration rectangle. B diagram (ii) uses a Projects entity in place of Student. C diagram (iii) directly links Classroom to Course while its Allocation diamond is attached only to Course. D diagram (iv) has entities Instructor, Course, Student, Classroom and relationships Teaches(Instructor,Course), Registration(Student,Course), Allocation(Course,Classroom), Guides(Instructor,Student).

## Solution

Approach: Identify the objects first, then check the two endpoint entities of each relationship.
1. The four object categories are Instructor, Course, Student and Classroom. These must be entity rectangles. The verbs or associations become relationship diamonds: Teaches, Registration, Allocation and Guides.
2. Teaches must connect Instructor to Course; Registration must connect Student to Course; Allocation must connect Course to Classroom; Guides must connect Instructor to Student. Diagram (iv) satisfies all four requirements.
3. Diagram (i) interchanges the semantic roles of Student and Registration, using the wrong kinds of symbols. Diagram (ii) introduces Projects instead of the specified Student entity.
4. Diagram (iii) has a direct Classroom–Course edge and does not connect Classroom through Allocation; the named allocation relationship is therefore not properly represented.
Answer: D. The specification does not give cardinality constraints such as one-to-many, so there is no need to invent them when selecting the diagram.

# GATE 2024 CS1: Q22

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;C

**Derived answer:** A;C

**Paraphrased problem context:** Which claims about a relation R in first normal form are true? A R may have a multi-attribute key. B R cannot have a foreign key. C R cannot have a composite attribute. D R cannot have more than one candidate key.

## Solution

Approach: First normal form concerns the form of attribute values, not the number of columns in a key or the number of valid identifiers.
1. In the usual relational model, a 1NF relation stores one atomic value in each attribute position. An undivided composite attribute, such as an Address object containing separate Street and City components, must be represented using suitable atomic columns. Thus C is true in the intended terminology.
2. Several individually atomic columns can together uniquely identify a row. For example, (StudentID,CourseID) can be a key of an enrollment relation. This is a composite key, not a composite attribute, so A is true.
3. A foreign key simply constrains values to reference another relation. It is compatible with atomic values, so B is false.
4. Different columns or column sets may each identify rows uniquely. First normal form does not forbid multiple candidate keys, so D is false.
Answer: A and C.

# GATE 2024 CS1: Q35

**Question:** [Official archived paper page 21](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=21); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 2 to 2

**Derived answer:** 2

**Paraphrased problem context:** R(A,B) has rows (10,20),(20,30),(30,40),(30,50),(50,95). S(A,C) has rows (10,90),(30,45),(40,80). Join R and S on equal A values, then keep rows with B<C. How many tuples remain?

## Solution

Approach: First match rows using the join condition, then test the selection condition for each resulting pair.
1. At A=10, R's B=20 matches S's C=90. The equijoin row is (R.A,B,S.A,C)=(10,20,10,90), and 20<90 is true. Below, write the equal A columns once as shorthand (A,B,C).
2. At A=30, there are two R rows and one S row. They produce (30,40,45) and (30,50,45). The first passes 40<45; the second fails 50<45.
3. R's A=20 and A=50 rows find no matching S row. S's A=40 row finds no R partner. An ordinary inner equijoin does not retain these unmatched rows.
4. The join therefore creates three tuples, of which exactly two survive the B<C filter.
Answer: 2. Repeated A values in R must not be collapsed: each matching row contributes its own joined tuple before selection.

# GATE 2024 CS1: Q44

**Question:** [Official archived paper page 28](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=28); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C;D

**Derived answer:** B;C;D

**Paraphrased problem context:** Which functional-dependency implications are valid? A XY→ZW implies X→ZW. B XY→ZW implies XY→Z. C XY→Z and W→Y imply XW→Z. D X→Y and Y→Z imply X→Z. Concatenated letters denote attribute sets.

## Solution

Approach: Treat a functional dependency as a guarantee that equality on its left side forces equality on its right side. Use Armstrong-style inference or a concrete counterexample.
1. A is false: dropping a determinant attribute can lose information. Consider rows (X,Y,Z,W)=(0,0,0,0) and (0,1,1,1). Their XY values differ, so XY→ZW holds, but equal X values have different ZW values, violating X→ZW.
2. B is true by decomposition. If equal XY forces both Z and W to agree, it certainly forces Z alone to agree.
3. C is true. From equal XW, we have equal W, hence equal Y by W→Y. We now have equal XY, which forces equal Z by XY→Z. Equivalently, the closure of XW contains Y and then Z.
4. D is the transitivity rule: agreement on X gives agreement on Y, then on Z.
Answer: B, C and D. Decomposing the right-hand side is valid; arbitrarily decomposing the left-hand side is not.

# GATE 2024 CS1: Q46

**Question:** [Official archived paper page 29](https://gate2026.iitg.ac.in/doc/download/2024/CS124S5.pdf#page=29); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B;C;D

**Derived answer:** B;C;D

**Paraphrased problem context:** The schedule is r1(z); w1(z); r2(x); r3(y); w3(y); r2(y); w2(x); w2(y), where subscripts name transactions. Which serial schedules are conflict equivalent? A T1 T2 T3; B T1 T3 T2; C T3 T2 T1; D T3 T1 T2.

## Solution

Approach: Only operations from different transactions on the same data item, with at least one write, impose conflict-order constraints.
1. Transaction T1 touches only z. Neither T2 nor T3 uses z, so T1 has no conflicts with the others and may appear anywhere in a serial order.
2. Only T2 accesses x, so x creates no intertransaction constraint.
3. On y, T3's read and write precede T2's read and write. Conflicting pairs include w3(y) before r2(y), w3(y) before w2(y), and r3(y) before w2(y). Each demands the same precedence edge T3→T2.
4. A conflict-equivalent serial order must therefore put T3 before T2, with T1 free. The valid orders are T1 T3 T2, T3 T2 T1, and T3 T1 T2.
Answer: B, C and D. Option A reverses the y-conflict order. Merely knowing that the precedence graph is acyclic establishes serializability; enumerating its topological orders identifies the actual choices.

# GATE 2024 CS2: Q19

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** A DBMS has told the user a transaction succeeded. Its effect must survive a crash even if all changed data pages have not reached disk. Which ACID property is this? A durability; B atomicity; C consistency; D isolation.

## Solution

Approach: Identify which guarantee applies after successful commit.

1. Derivation. Durability guarantees that the effect of an acknowledged committed transaction survives a crash, typically through durable logging and recovery even if data pages have not yet been flushed. Atomicity is all-or-nothing execution, consistency concerns integrity constraints, and isolation concerns interference. Answer A.

2. Explanation and checks. Durability need not mean that every modified database page is already stored in its final disk location. A sufficiently durable commit record and log can permit recovery to redo committed changes after restart. Atomicity instead prevents partial effects of an unsuccessful transaction; isolation controls interactions among simultaneous transactions. Consistency concerns preservation of the database constraints when transactions execute correctly. The decisive words here are successful completion and persistence after a crash.

# GATE 2024 CS2: Q20

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** In an ER model, what participation in an identifying relationship is mandatory? A total participation of the weak entity set; B total participation of the owner entity set; C both sets must participate totally; D neither must.

## Solution

Approach: Distinguish the dependent entity from the entity that supplies its identity.

1. Derivation. A weak entity needs its identifying owner relationship to determine its identity; every weak entity therefore participates. An owner may exist with no dependent weak entity unless a separate application constraint requires one. Thus total participation is mandatory for the weak entity set only, option A.

2. Explanation and checks. For example, a dependent identified by an employee identifier together with a dependent-name discriminator cannot exist in this model without an employee owner. However an employee can have no dependents and still have its own identity. “Total participation” means every entity in that set appears in the relationship; it does not mean every possible owner–dependent pair is related. Thus mandatory dependence flows from weak entity to owner, not in both directions.

# GATE 2024 CS2: Q26

**Question:** [Official archived paper page 18](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=18); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;B

**Derived answer:** A;B

**Paraphrased problem context:** Which file organizations are I/O-efficient for scanning all records? A sorted file; B heap file; C unclustered tree index; D unclustered hash index.

## Solution

Approach: Optimize for reading the entire data set, not for retrieving a few qualifying records.

1. Derivation. A full scan of a sorted file or a heap file reads the data pages sequentially, usually once each. Scanning through an unclustered index can chase record pointers to many scattered data pages, causing repeated/random I/O. Thus the I/O-efficient file organizations for the full scan are A, B; a selective index lookup is a different workload.

2. Explanation and checks. For a data file occupying B pages, scanning the file in its physical order takes about B page reads whether the records have a sorted order or an arbitrary heap order. An unclustered index does not group the data records in index traversal order, so neighboring index entries may point to different pages and cause random accesses or rereads. The index also has its own pages to read. Selectivity can make an index attractive for lookup, but that is absent in a full scan.

# GATE 2024 CS2: Q27

**Question:** [Official archived paper page 19](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=19); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A;C;D

**Derived answer:** A;C;D

**Paraphrased problem context:** Which statements about two-phase locking are true? A it permits only serializable schedules; B every operation locks just before and releases immediately after; C after the first lock release a transaction can acquire no new lock; D deadlock can occur.

## Solution

Approach: Apply the no-new-locks-after-release rule and distinguish serializability from progress.

1. Derivation. Two-phase locking first acquires locks and then, after the first release, only releases locks. The no-new-locks shrinking-phase rule proves C. Ordering transactions by their lock points proves conflict serializability, hence A. It does not release every lock immediately after each operation, and deadlock is possible: T1 holds X and waits for Y while T2 holds Y and waits for X. Thus A, C, D.

2. Explanation and checks. The growing phase permits acquisition but no release; the shrinking phase permits release but no acquisition. The instant at which a transaction acquires its final lock is its lock point; ordering transactions by such points is consistent with every conflicting dependency, giving a serial order. Holding X while waiting for Y and holding Y while waiting for X obey the growing-phase rule, so 2PL can still deadlock. Releasing each lock immediately, as B claims, would prevent later acquisitions and is not the general protocol.

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Person(pid,city) has a unique pid per person. Using only selection, projection, cross product and rename, how many cross-product operations are minimally required to find cities with at least three residents? A 1; B 2; C 3; D 4.

## Solution

Approach: Introduce one independently chosen tuple for each person that must be witnessed.

1. Derivation. Rename three copies P1, P2, P3 of Person and take their product using two binary cross products. Select equal cities and pairwise distinct pids, then project the city. This identifies exactly cities with at least three residents. With only one cross product, selection/projection/rename can expose at most two independently chosen source tuples, which cannot witness a third distinct person. Thus the minimum is 2, option B, in the stated algebra without aggregation or other operators.

2. Explanation and checks. Write P1×P2×P3 as (P1×P2)×P3. Select P1.city=P2.city=P3.city and P1.pid≠P2.pid, P1.pid≠P3.pid, P2.pid≠P3.pid, then project P1.city. All three inequalities are necessary to prevent a two-person city from reusing one person. Rename, selection and projection do not introduce an additional independently chosen resident. This lower-bound argument assumes the stated relational algebra expression model, not a materialized intermediate relation supplied from outside the expression.

# GATE 2024 CS2: Q56

**Question:** [Official archived paper page 37](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=37); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 50 to 50

**Derived answer:** 50

**Paraphrased problem context:** On a schema of four attributes, call X→Y useful when X and Y are both nonempty and X∩Y=∅. How many different such dependencies are possible?

## Solution

Approach: Assign each attribute to the left side, right side, or neither, then exclude empty sides.

1. Derivation. For each of four attributes choose membership in X, membership in Y, or neither: 3⁴ assignments enforce disjointness. Exclude assignments with X empty (2⁴) and Y empty (2⁴), then restore the all-neither assignment counted twice. The number is 3⁴−2⁴−2⁴+1=81−16−16+1=50. This counts possible syntactic dependencies, not dependencies that necessarily hold on a particular instance.

2. Explanation and checks. An alternative count chooses the size k of X: sum from k=1 to 3 of C(4,k)(2^(4−k)−1). For k=1 there are 4×7=28 choices; k=2 gives 6×3=18; k=3 gives 4×1=4, totaling 50. X→Y and Y→X are different dependencies because direction matters. Multiattribute right sides are allowed by the definition; restricting Y to a single attribute would answer a different question.
