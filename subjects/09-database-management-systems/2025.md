

# GATE 2025 CS1: Q15

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

T1 writes Y before either T2 or T3 reads it. With no intervening write or commit, both later reads consume T1’s uncommitted value. Aborting T1 invalidates that value and forces cascading rollback of both readers, T2 and T3. The earlier reads of X do not change this dependency. Thus C.

The usual split allocates one extra leaf, one extra internal node, and a new root (five nodes become eight). ## Solution

**Official answer:** B;C

**Derived answer:** B;C

## Solution

name determines all attributes, hence is a key of team. Each nontrivial specified dependency has a superkey determinant, so team is BCNF (and therefore 3NF). The projections t1 and t2 also have name as a key and are BCNF. Their intersection is {name}, which determines both components, satisfying the binary lossless-join test. Thus B and C are true; A and D are false.
