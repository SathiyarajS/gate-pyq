**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

T1 writes Y before either T2 or T3 reads it. With no intervening write or commit, both later reads consume T1’s uncommitted value. Aborting T1 invalidates that value and forces cascading rollback of both readers, T2 and T3. The earlier reads of X do not change this dependency. Thus C.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** B;C

**Derived answer:** B;C

## Solution

Both transfers read the same old balance and overwrite A with 1000, losing one debit, while B receives both credits. This is not equivalent to a valid serial execution, so isolation fails. It also creates10000 of net funds instead of conserving the transfer total, violating consistency. Both individual transactions could have executed all of their read/write operations and committed, so atomicity need not have failed; no loss of a committed result after a failure is stated, so durability violation is not established. Select B, C.
