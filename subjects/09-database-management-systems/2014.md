The subquery finds a customer of E whose rating is not GOOD. SQL NULL is an important missing condition: rating<>GOOD evaluates UNKNOWN for a null rating and is filtered out. An employee whose only customer has NULL rating is therefore returned although that rating is not known GOOD. The source does not declare rating NOT NULL, so the official description requires this qualification.
