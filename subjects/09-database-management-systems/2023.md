

# GATE 2023 CS: Q16

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** What is a relation's degree or arity? A number of attributes; B number of tuples; C number of entries; D number of distinct attribute domains.

## Solution

The degree or arity of a relation is its number of attributes/columns. Its number of tuples is its cardinality, and multiple attributes may share a domain. Therefore A.

Teaching detail. For example, a Student relation with columns rollNum, name, gender, marks has degree 4 whether it contains zero rows or a million rows. Its cardinality changes when rows are inserted, but its arity changes only if the schema's attribute count changes. Two columns can share the same domain, such as two integer-valued attributes, so counting distinct domains can undercount attributes. “Entries” is not the precise schema-level definition sought here.

# GATE 2023 CS: Q61

**Question:** [Official archived paper page 64](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=64); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 2 to 2

**Derived answer:** 2

**Paraphrased problem context:** Student rows (rollNum,name,gender,marks) are (1,Naman,M,62),(2,Aliya,F,70),(3,Aliya,F,80),(4,James,M,82),(5,Swati,F,65); rollNum is primary key. How many rows does SELECT * FROM Student WHERE gender='F' AND marks>65 return?

## Solution

The condition requires both female gender and marks strictly greater than 65. Roll numbers 2 and 3 qualify, with marks 70 and 80. Swati has exactly 65 and is excluded; the other two rows are male. The two Aliya rows remain distinct because their roll numbers differ, and SELECT * does not deduplicate them. The result contains 2 rows.

Teaching detail. Evaluate the conjunction row by row: row 1 fails gender, row 2 passes both predicates, row 3 passes both, row 4 fails gender despite high marks, and row 5 fails the strict greater-than test. The primary key identifies records by rollNum, not by name, so equal names do not imply one record. SQL's ordinary SELECT is not SELECT DISTINCT; moreover even DISTINCT over all columns would keep the two qualifying rows because both roll numbers and marks differ. Only the number of qualifying rows is requested.

# GATE 2023 CS: Q62

**Question:** [Official archived paper page 65](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=65); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 6 to 6

**Derived answer:** 6

**Paraphrased problem context:** An ordered file has 25,000 unspanned records of 100 bytes, including a 15-byte primary key. Blocks hold 1024 bytes. A sparse primary index has one anchor key and 5-byte block pointer per data block, with unspanned entries. Binary search on b index blocks costs ceil(log2 b) accesses by stipulation. How many accesses identify the candidate data block, without reading that block?

## Solution

Each data block holds floor(1024/100)=10 unspanned records, so 25000 records occupy 2500 blocks. The sparse primary index has one anchor entry per data block. Each entry occupies 15+5=20 bytes, so an index block holds floor(1024/20)=51 entries and the index needs ceil(2500/51)=50 blocks. By the expressly given search-cost rule, identifying the data-block pointer costs ceil(log2 50)=6 block accesses. Reading that data block would add one more, but the question asks only to identify it.

Teaching detail. Unspanned storage requires rounding at each level before progressing. A block cannot store 10.24 records, so 24 bytes remain unused after its ten full records. Similarly an index block stores 51 complete 20-byte entries, leaving four bytes. There are 2500 data-block anchors, not 25,000 record-level entries, because the index is sparse. Since 49·51=2499, a fiftieth index block is necessary for the final anchor. With 32<50≤64, the stated ceiling-logarithm search rule yields six accesses, excluding the data fetch.
