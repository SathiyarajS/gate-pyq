**Essential problem context (paraphrased):** Which is true about SLR, LALR, canonical LR power? C says canonical LR is more powerful than LALR.

## Solution

Canonical LR(1) retains separate lookahead contexts. LALR merges LR states with identical LR(0) cores; this can introduce reduce/reduce conflicts that did not exist before merging. SLR uses the still coarser FOLLOW-set reduction rule. Therefore the recognizable grammar classes satisfy SLR⊆LALR⊆canonical LR, with proper inclusions in general, giving C. This compares conflict-free grammar handling, not table compactness or parsing speed.

**Independently derived answer:** C

**Essential problem context (paraphrased):** An array of pointers to activation records used to speed nonlocal variable access is called stack, heap, display, or activation tree?

## Solution

A display stores the current activation-record pointer for each lexical nesting level. A nonlocal variable’s declaration level and fixed offset then identify its address through one indexed display lookup plus the offset. This avoids following a chain of static links through multiple records. The structure is called a display, C. A stack stores records themselves, a heap supports general dynamic allocation, and an activation tree describes call relationships rather than this direct-access table.

# GATE 1998: Q62 (printed A Q6(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203837/GATE1998.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A valid six-alternative grammar is S→Ta|bdTa|b; T→cT|adT|ε. Global minimum among arbitrary CFGs is not certified.

**Essential problem context (paraphrased):** For S→Aa|b and A→Ac|Sd|ε, construct an equivalent grammar with no left recursion and the minimum number of productions. Count each alternative as a production.

## Solution

Substitute S→Aa|b into the occurrence S in A→Sd. Then A→Ac|Aad|bd|ε. Each recursive use appends either c or ad on the right; the base is either bd or ε. Thus L(A)=(ε∪{bd}){c,ad}*, and

L(S)={b} ∪ (ε∪{bd}){c,ad}*{a}.

Introduce T generating {c,ad}*. The following equivalent grammar has six individual alternatives:

S → Ta | bdTa | b
T → cT | adT | ε

Every recursive T production starts with a terminal, so it cannot be left recursive. S is not reachable from T, and although S→Ta starts with a nonterminal, its nullable prefix cannot lead back to S. This also rules out indirect left recursion. The first two S alternatives select the two possible prefixes before a word from {c,ad}* and its final a; the third supplies the isolated word b. Conversely, each original derivation has exactly one of these forms, proving language equivalence.

For comparison, the usual mechanical elimination gives S→Aa|b, A→bdT|T, T→cT|adT|ε, with seven alternatives. Inlining A into S removes its two rules and replaces one S alternative by two, saving one production. The six-rule grammar is therefore smaller than that routine result.

The printed requirement “minimum number” needs care. This construction establishes an upper bound of six. It is not a proof that no differently structured, arbitrary CFG can use fewer alternatives. Counting a line with several bars as one “rule” would also give a different metric. The requested global minimum is left uncertified rather than asserted without a lower-bound proof; the equivalent non-left-recursive grammar itself is fully established.

**Independently derived answer:** Nonempty table entries: Program/begin; X/d,X/s; Y/semi,Y/end.

**Essential problem context (paraphrased):** Construct the LL(1) table for Program→begin d semi X end; X→d semi X | sY; Y→semi sY | ε. Treat begin,d,semi,s,end as terminals.

## Solution

FIRST(Program)={begin}; FIRST(X)={d,s}; FIRST(Y)={semi,ε}. Program is the start symbol, so FOLLOW(Program)={$}. In Program's production, X is followed by end, hence FOLLOW(X)={end}. The occurrence Y at the end of X→sY gives FOLLOW(Y)={end}; its recursive production adds no new follower.

Fill a production in columns belonging to the FIRST set of its right side. For the ε production, use FOLLOW(Y). The complete non-error entries are:

Nonterminal | lookahead | production
Program     | begin     | Program→begin d semi X end
X           | d         | X→d semi X
X           | s         | X→sY
Y           | semi      | Y→semi sY
Y           | end       | Y→ε

Every other cell, including all cells under $, is an error for these nonterminals. The parsing stack accepts only when both its end marker and the input end marker match after Program is fully processed. There is no conflict: X's alternatives start with different terminals, and FIRST(semi sY)={semi} is disjoint from FOLLOW(Y)={end}. That establishes LL(1), rather than merely presenting a table without explaining why it works.

## Solution

Read the source raster rather than relying on extracted text: GateForum visibly supplies the dot terminal in S→L.L|L. It is faint in GFG and can disappear in OCR. This production parses the fractional example; replacing it by dotless S→LL would describe a different grammar.

Use L.val for the integer represented by its bit string and L.len for its number of bits. All attributes are synthesized:
S→L1 . L2: S.val=L1.val+L2.val/2^(L2.len)
S→L: S.val=L.val
L→L1 B: L.val=2*L1.val+B.val; L.len=L1.len+1
L→B: L.val=B.val; L.len=1
B→0: B.val=0
B→1: B.val=1

Appending a bit shifts the prior number left by one, hence multiplication by two. A fractional bit string of length k represents its integer value divided by 2^k.
