**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

A symbol table stores identifier entries and attributes such as type, scope, storage location and parameter information. An abstract syntax tree represents program structure, a parse table guides parsing, and a semantic stack supports intermediate parser actions. Therefore the data structure asked for is the symbol table, B.

# GATE 2010: Q24 (printed CS Q14)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 3. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Dynamically created data structures can have sizes and lifetimes unrelated to the last-in-first-out nesting of procedure activations, so their runtime storage requires heap-style allocation in the standard implementation model. Recursion and dynamic scope can be supported with activation stacks; global variables can use static storage. C is the intended distinction. A language implementation may realize the allocator through a preallocated arena, but that is still heap-style management rather than a counterexample to the storage-lifetime distinction.

# GATE 2010: Q47 (printed CS Q37)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 9. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Immediately after c=20, a,b,c are all live because a and b are needed for d=a+b while c is needed later. At least three registers are therefore necessary. Three suffice: put a,b,c in registers r1,r2,r3; overwrite r1 with d=a+b, then with e=c+d; overwrite r2 with f=c+e; overwrite r3 with b=c+e after c dies; overwrite r1 with e=b+f and then d=5+e. The final d+f uses r1 and r2. Thus 3, B, under the usual model allowing a destination to reuse a dead operand register.

# GATE 2010: Q48 (printed CS Q38)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 9. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

The productions S→aSa, S→bS and S→c begin with distinct terminals a,b,c and none derives epsilon. Their FIRST sets are disjoint, so one lookahead symbol uniquely selects the production and the grammar is LL(1). Every LL(1) grammar is LR(1), so it is both, C. The trailing a in aSa does not cause a predictive conflict because the initial a already selects that alternative.
