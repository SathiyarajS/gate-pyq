**Paraphrased problem context:** In a lexically scoped block language, main declares A1 and A2. A1 calls A2. A2 declares A21 and calls A21; A21 calls A1. Main calls A1, producing the live call stack main→A1(first)→A2→A21→A1(second). Which activation-record/access-link diagram is correct? Let M, X, Y, Z, W denote these five activations respectively. Arrows below are access (static) links, and FP denotes the frame pointer.
(A) X→M, Y→X, Z→Y, W→Z; FP=W.
(B) Y→M, Z→Y, W→Z; no access link is drawn for X; FP=W.
(C) Only M,X,Y,Z are drawn: X→M, Y→M, Z→Y; W is absent and FP=X.
(D) X→M, Y→M, Z→Y, W→M; FP=W.

## Solution

An access link points to the activation of the lexically enclosing procedure, not generally to the caller. Both A1 activations and A2 are declared directly in Main, so all three point to Main. A21 is declared in A2, so its access link points to that A2 activation. The frame pointer is at the latest (bottom) A1 activation. Option D depicts precisely these static links; caller links instead would form the dynamic call chain.

Worked check / additional reasoning: The second A1 was called by A21, but A1’s declaration remains inside main. Dynamic recursion changes which activation is current, not the lexical parent. Thus its static link skips both A21 and A2, while its dynamic caller link would point to A21.

**Paraphrased problem context:** Grammar: S→aAbB | bAaB | ε; A→S; B→S. S is the start symbol. The partial predictive table has columns a,b,$: S row=[E1,E2,S→ε]; A row=[A→S,A→S,error]; B row=[B→S,B→S,E3]. ε is empty and $ is the input-end marker.
Find FIRST and FOLLOW of A and B.
(A) FIRST(A)=FIRST(B)={a,b,ε}; FOLLOW(A)={a,b}; FOLLOW(B)={a,b,$}.
(B) FIRST(A)={a,b,$}; FIRST(B)={a,b,ε}; FOLLOW(A)={a,b}; FOLLOW(B)={$}.
(C) FIRST(A)=FIRST(B)={a,b,ε}; FOLLOW(A)={a,b}; FOLLOW(B)=∅.
(D) FIRST(A)=FIRST(B)={a,b}; FOLLOW(A)=FOLLOW(B)={a,b}.

## Solution

S can start with a or b or derive ε; A→S and B→S therefore give FIRST(A)=FIRST(B)={a, b,ε}. In S→aAbB and S→bAaB, A is immediately followed by b and a respectively, so FOLLOW(A)={a, b}. Since S is the start symbol, $ belongs to FOLLOW(S). A→S passes FOLLOW(A) into FOLLOW(S), giving FOLLOW(S)={a, b,$}. B occurs at the end of each nonempty S production, so it inherits FOLLOW(S), and FOLLOW(B)={a, b,$}. B→S adds no new symbols. These are option A.

Worked check / additional reasoning: Nullable propagation is essential: A and B derive ε through S even though neither has an explicit ε production. FOLLOW sets require a fixed point because A→S and B→S propagate symbols back to S, which then propagates them to trailing B.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Source access:** Open archive member CS/CS2012.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** Grammar: S→aAbB | bAaB | ε; A→S; B→S. S is the start symbol. The partial predictive table has columns a,b,$: S row=[E1,E2,S→ε]; A row=[A→S,A→S,error]; B row=[B→S,B→S,E3]. ε is empty and $ is the input-end marker.
Fill E1,E2,E3.
(A) E1={S→aAbB,A→S}; E2={S→bAaB,B→S}; E3={B→S}.
(B) E1={S→aAbB,S→ε}; E2={S→bAaB,S→ε}; E3={S→ε}.
(C) E1={S→aAbB,S→ε}; E2={S→bAaB,S→ε}; E3={B→S}.
(D) E1={A→S,S→ε}; E2={B→S,S→ε}; E3={B→S}.

## Solution

For M[S, a], FIRST(aAbB) supplies S→aAbB; because a belongs to FOLLOW(S), the nullable alternative also supplies S→ε. Similarly M[S, b] contains both S→bAaB and S→ε. At M[B,$], B→S is inserted because S is nullable and $ belongs to FOLLOW(B). Thus E1={S→aAbB, S→ε}, E2={S→bAaB, S→ε}, E3={B→S}, exactly C. The two multiple-production cells are FIRST/FOLLOW conflicts, proving this grammar is not LL(1). The source’s phrase “LL(1) parsing table” should be understood as the table-construction procedure, not as certification that the grammar admits deterministic LL(1) parsing.

Worked check / additional reasoning: Each parsing-table row can contain only productions whose left-hand side is that row’s nonterminal. This immediately eliminates options inserting A→S or B→S into S’s row, and eliminates S→ε as the B-row entry E3.
