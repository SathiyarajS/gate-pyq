

# GATE 2022 CS: Q13

**Question:** [Official archived paper page 12](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=12); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** Choose the true statement: A LALR(1) cannot introduce reduce/reduce conflicts absent from LR(1); B symbol tables are accessed only during lexical analysis; C data-flow analysis is necessary for run-time memory management; D LR(1) parsing suffices for deterministic context-free languages.

## Solution

Every deterministic context-free language has an LR(1) grammar, so LR(1) parsing is sufficient for these languages, D. LALR merging can introduce reduce-reduce conflicts even when canonical LR has none. Symbol-table information is used beyond lexical analysis, and data-flow analysis is not a necessary runtime step in program execution. The claim is about existence of a suitable LR(1) grammar, not that every grammar of the language is LR(1).

Teaching detail:
LALR merges canonical states with identical LR(0) cores but potentially different lookahead sets; combining these lookaheads can create a reduce/reduce choice. Symbol tables also serve declaration/type checking, code generation, and optimization. LR(1) sufficiency concerns a grammar for the language, not every arbitrary presentation of it.

# GATE 2022 CS: Q29

**Question:** [Official archived paper page 22](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=22); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 5 to 5

**Derived answer:** 5

**Paraphrased problem context:** Grammar: S′→S; S→S+R|R; R→R*P|P; P→(S)|id. Let I0={S′→S·, S→S·+R}. Count items in goto(closure(I0),+).

## Solution

Taking goto on + advances S→S·+R to S→S+·R. Closure then adds R→·R*P, R→·P, P→·(S), and P→·id. No dot precedes S in these items, so no further closure is needed. Total 5 items.

Teaching detail:
Closure only expands a nonterminal immediately after a dot. Initially the dots precede end-of-rule or terminal +, so closure(I0)=I0. After shifting +, R is exposed; recursively expanding R and P yields the five items listed. The left-recursive R production is added once, so closure terminates.

# GATE 2022 CS: Q65

**Question:** [Official archived paper page 41](https://gate2026.iitg.ac.in/doc/download/2022/cs_2022.pdf#page=41); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 80 to 80

**Derived answer:** 80

**Paraphrased problem context:** Translation grammar: S→S1#T gives S.val=S1.val*T.val; S→T copies T.val; T→T1%R gives T.val=T1.val/R.val; T→R copies R.val; R→id copies integer id.val. Evaluate root S.val for 20#10%5#8%2%2. The source lists an unused nonterminal P as well.

## Solution

The grammar gives % higher precedence than #, with both operators left-associative. Their semantic operations are division and multiplication, respectively, rather than C remainder. The three T values are 20, 10/5=2, and (8/2)/2=2. The left-associative S combination therefore gives (20*2)*2=80. The printed nonterminal list includes an unused P, but no production or calculation depends on it.

Teaching detail:
The parse groups as (20 # (10 % 5)) # ((8 % 2) % 2). The left recursion in T fixes the latter association, so its value is (8/2)/2=2 rather than 8/(2/2)=8. S’s translation multiplies the three T values: 20×2×2=80.
