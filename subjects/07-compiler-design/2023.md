

# GATE 2023 CS: Q11

**Question:** [Official archived paper page 8](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=8); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Assess compiler statements S1: front-end phases are target-hardware independent; S2: back-end phases are target-hardware specific; S3: back-end phases are specific to the source programming language. A S1 only; B S1,S2; C all; D S1,S3.

## Solution

The front end analyzes the source language and produces a target-independent representation, making S1 true. The back end maps that representation to the target instruction set and hardware, making S2 true. Source-language-specific analysis is normally a front-end responsibility rather than a back-end phase, so S3 is false. Thus B.

Teaching detail. Lexical analysis, parsing, and semantic/type analysis must understand source-language rules, but need not know the final processor's register set. Conversely, instruction selection, register allocation, and machine-code generation depend on the target. An intermediate representation is the interface separating these responsibilities. Particular compilers may mix optimizations across this boundary, but the question concerns the standard conceptual division; source-language semantics do not become a back-end-specific phase merely because the back end receives their translated representation.

# GATE 2023 CS: Q19

**Question:** [Official archived paper page 16](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=16); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Identifiers match letter(letter|digit)*, with letter in A–Z or a–z and digit in 0–9. Choose the equivalent ε-NFA: A permits skipping the initial letter and then loops on letters/digits; B after the initial letter branches into an all-letter loop or an all-digit loop; C after the initial letter reaches an accepting hub, from which either a letter or digit branch can be selected by ε-transitions and returned to repeatedly; D after the initial letter repeats letter-then-digit pairs. The source diagrams are linked for exact state layouts.

## Solution

A valid identifier begins with one letter and then permits any mixture of letters and digits, including an empty suffix. In C the first letter reaches an accepting state; each repeated epsilon-selected letter/digit branch returns there through the outer epsilon edge. A wrongly accepts epsilon and leading digits; B forces the suffix to be all letters or all digits; D only permits letter-digit pairs after the first letter. Thus C. All accepting states and epsilon directions were visually checked.

Teaching detail. Test a candidate recognizer against boundary cases: a single letter must be accepted, an initial digit must be rejected, and the empty word must be rejected. Then test mixing in the suffix, such as a1b2. The accepting hub of C allows stopping immediately after the first letter and returning after each one-symbol suffix choice. An ε-transition changes state without consuming input; it does not allow an initial digit unless it bypasses the required initial-letter transition. These tests reveal why merely having letter and digit edges somewhere is insufficient.

# GATE 2023 CS: Q37

**Question:** [Official archived paper page 37](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=37); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** The control-flow graph has B1: i=m−1;j=n;a=10; B2: i=i+1;j=j−1; B3: a=20; B4: i=a+1. Edges are entry→B1→B2, B2→B3, B2→B4, B3→B4, B4→B2, and B4→exit. Find the live-variable set at each block exit; no values are used after exit.

## Solution

Liveness means a current value can be read along some future path before redefinition. B4 computes i from a, then can return to B2, where i and j are read; a can also survive to another B4. Thus OUT(B4)={a, i, j}. Before B4 the old i is killed, so IN(B4)={a, j}, yielding OUT(B3)={a, j}. B2 can reach B4 directly or through B3, so OUT(B2)={a, j}; its updates read i, j, yielding IN(B2)={a, i, j}=OUT(B1). Therefore D. The B4→B2 back edge was visually checked.

Teaching detail. Use OUT(B)=the union of IN over successor blocks and IN(B)=USE(B) union (OUT(B)−DEF(B)). Here USE(B2)={i,j}, DEF(B2)={i,j}, USE(B3)=∅, DEF(B3)={a}, USE(B4)={a}, DEF(B4)={i}. The loop requires a fixed point rather than a single backward pass. Crucially j remains live through B4 because the next B2 reads it; old i is killed inside B4 but the newly assigned i is live afterward. Values m,n are used only in B1 and are not live at its exit.

# GATE 2023 CS: Q60

**Question:** [Official archived paper page 63](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=63); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 2.374 to 2.376

**Derived answer:** 2.375

**Paraphrased problem context:** Syntax-directed rules: N→I#F gives N.val=I.val+F.val; I→I1 B gives I.val=2I1.val+B.val and I→B copies B.val; F→B F1 gives F.val=(B.val+F1.val)/2 and F→B gives B.val/2; B→0 or 1 takes the bit value. Evaluate 10#011 to three decimals.

## Solution

The I rules interpret the left substring as a binary integer: I(10)=2*1+0=2. Evaluate the fractional suffix from right to left: F(1)=1/2, F(11)=(1+1/2)/2=3/4, and F(011)=(0+3/4)/2=3/8. Thus N.val=2+3/8=2.375, within the official interval 2.374 to 2.376.

Teaching detail. The separator # plays the role of a binary radix point in these semantic rules, not a multiplication or concatenation operator on numbers. The left-recursive integer production multiplies the accumulated prefix by two before appending the next bit. The right-recursive fractional production halves the sum of the current bit and the suffix fraction, placing successive bits at weights 1/2,1/4,1/8. Directly, 10#011 represents 2+0/2+1/4+1/8. This corroborates the synthesized-attribute evaluation and yields an exact terminating decimal.
