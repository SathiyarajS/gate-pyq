## Solution

An operator grammar forbids adjacent nonterminals on a right-hand side and, in the standard definition used here, empty productions. P→QR violates the first rule and P→ε the second. P→QsR and P→QtRr separate nonterminals by terminals. Thus i and iii, B.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Evaluate E2 first and save its value in a temporary memory location. Then evaluate E1, leaving the required first operand in the sole register, and subtract the saved E2. Evaluating E1 first would require saving it, evaluating/storing E2, then reloading E1 before subtraction. Thus E2-first, B, avoids an extra reload in the stated accumulator-style model, assuming both expressions require evaluation and their order is free of side-effect constraints.

# GATE 2004: Q45 (printed CS Q45)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203330/GATE2004.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C (GFG); no listed option (GateForum)

## Solution

The grammar groups & inside T, hence it has higher precedence than #. In the GFG image the T→T1 & F semantic rule is T.value=T1.value+F.value, while E→E1 # T multiplies. Therefore 2 # 3 & 5 # 6 & 4 evaluates as 2×(3+5)×(6+4)=160, option C. The GateForum image instead prints multiplication in BOTH semantic rules, which yields 2×3×5×6×4=720, absent from the options. This is a substantive reproduction variant; C applies only to the visibly printed GFG plus-sign rule, not to the alternate as printed.
