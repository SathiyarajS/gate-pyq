**Official answer:** B

**Derived answer:** B

**Source access:** Open archive member CS/CS2018.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** Choose the false claim: A CFGs can specify lexical and syntactic rules; B type checking precedes parsing; C high-level code can translate to different intermediate representations; D function arguments can be passed on the program stack.

## Solution

Method and intermediate reasoning:

Parsing identifies constructs such as expressions, declarations and function calls. Type checking applies rules to those constructs and their symbol-table information, so the conventional dependency is syntax before semantic type checking. A compiler may interleave actions during parsing, but that does not establish the blanket claim in B. Regular token languages are also context-free, which is why A is expressively valid even though practical lexers usually use regular expressions.

Derivation, answer and qualifications:

Parsing supplies the syntactic structure on which conventional type checking operates, so saying type checking is performed before parsing is false, B. CFGs can express regular lexical rules as well as syntax, multiple intermediate representations are possible, and stack argument passing is standard.

# GATE 2018 CS: Q47 (printed CS Q37)

**Question:** [Official archived paper page 15](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** D

**Derived answer:** D

**Source access:** Open archive member CS/CS2018.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** Tokens are T1=a?(b|c)*a, T2=b?(a|c)*b, T3=c?(b|a)*c, where ? is optional. Scan bbaacabc using longest-prefix matching. Choices A T1,T2,T3; B T1,T1,T3; C T2,T1,T3; D T3,T3.

## Solution

Method and intermediate reasoning:

At the first position T1 can consume bba: its final a ends the token before the next a. T2 can consume bb but cannot include both leading b symbols in its middle (a|c)*. T3 consumes bbaac; it cannot consume the entire input because its middle cannot contain the earlier c. Remove that five-character prefix and rescan abc, which T3 consumes completely. Longest match is decided afresh at each position, rather than choosing the earliest token pattern that can match anything.

Derivation, answer and qualifications:

On bbaacabc, the longest first token is bbaac, matching T3=(optional c)(a|b)*c. T1 matches only bba and T2 only bb at that position. The remaining abc also matches T3 in full, longer than the alternatives. Therefore the output is T3, T3, D.

# GATE 2018 CS: Q48 (printed CS Q38)

**Question:** [Official archived paper page 15](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Source access:** Open archive member CS/CS2018.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** For a#b$c$d#e#f, the supplied tree represents a#(((b$c)$d)#(e#f)). Choose A $ higher and left-associative, # right-associative; B # higher and left-associative, $ right-associative; C $ higher and left-associative, # left-associative; D # higher and right-associative, $ left-associative.

## Solution

Method and intermediate reasoning:

Read each internal node as an operation on its two child subtrees. The $ subtree first combines b,c and then combines that result with d, demonstrating left association. Treating this whole subtree as one operand gives a#(X#(e#f)), which nests # to the right. Because the dollar chain is grouped into an operand before surrounding hash operations, $ has higher precedence in the intended grammar. Do not infer precedence from the visual height of leaf letters.

Derivation, answer and qualifications:

The tree groups the expression as a#(((b$c)$d)#(e#f)). The two dollar operations group left, and their subtree is below the hash operations, showing higher precedence. The hash chain groups to the right. Thus A.
