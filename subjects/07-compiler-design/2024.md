## Solution

Shift-reduce parsing builds a parse from terminals upward by reducing handles. LR is a deterministic shift-reduce family, so both are bottom-up. Predictive parsing and LL(1) expand productions from the start symbol toward the input, so they are top-down. Answer A, D.

## Solution

Including the start marker yields FOLLOW(S)=FOLLOW(T)={c, f,$}, exactly as given.

# GATE 2024 CS2: Q29

**Question:** [Official archived paper page 20](https://gate2026.iitg.ac.in/doc/download/2024/CS224S6.pdf#page=20); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** B;D

**Derived answer:** B;D

## Solution

The question asks for false statements. A is the usual side-effect-free definition of an attribute grammar. L-attributed definitions admit a left-to-right depth-first evaluation, assigning inherited attributes on entry and synthesized ones on return, so B is false. Synthesized attributes can be computed at reductions, making C true. Arbitrary inherited dependencies in an L-attributed definition need not be available at the relevant point in an LR parse, so D’s universal claim about evaluation during bottom-up parsing is false. Thus B, D. Constructing a full parse tree and doing a separate attribute-evaluation traversal is distinct from the intended parsing-time claim.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

## Solution

FIRST(AaAb)={c, a}, while FIRST(BbBa)={d, b}. Thus the S-row c cell chooses S→AaAb and the d cell S→BbBa. A occurs before a and b in the first production, so FOLLOW(A)={a, b}; its epsilon production is entered for both lookaheads. Similarly FOLLOW(B)={b, a}, so B→epsilon goes in both a, b cells. Hence cells(1)–(4) are S→AaAb, S→BbBa, A→epsilon, B→epsilon, option A. The table columns and productions were visually checked.

## Solution

The initial closure contains S′→·S and S→·SS, plus the other four S-start items and A→·d#, B→·@. GOTO on S shifts the first two into S′→S· and S→S·S. The latter requires closure under S, adding all five S-start items: ·SS, ·Aa, ·bAc, ·Bc, ·bBa. Closure of their leading A/B adds A→·d# and B→·@. The total is 2+5+2=9 distinct LR(0) items; SLR FOLLOW sets do not change this item-set construction.
