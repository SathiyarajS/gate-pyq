# GATE 2007: Q52 (printed CS Q52)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 12. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

The grammar is S→iCtSS₁ | a, S₁→eS | ε, C→b. It is the dangling-else grammar. The string i b t i b t a e a has two parse trees: the e a can belong to the inner conditional (inner S₁→eS, outer S₁→ε) or the outer conditional (inner S₁→ε, outer S₁→eS). Therefore it is ambiguous and cannot be LL(1), giving C. Equivalently e belongs both to FIRST(eS) and FOLLOW(S₁), causing a prediction-table conflict with S₁→ε. Right recursion by itself is not an obstruction to LL(1), and these productions are context-free and not left recursive.

# GATE 2007: Q53 (printed CS Q53)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 13. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

P is false: the right-linear regular grammar S→aA | aB, A→b, B→c has two alternatives whose FIRST sets both contain a, so this particular grammar is not LL(1). Q is true: construct a grammar from a DFA by using one nonterminal per state, production Q→aR for each transition on a, and Q→ε for each accepting state. Determinism gives at most one alternative per terminal; epsilon is selected at end of input. This yields an LL(1), hence LR(1), grammar for the regular language (or use the standard inclusion of regular languages in deterministic context-free languages). Thus P false and Q true, option C.

# GATE 2007: Q54 (printed CS Q54)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 13. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

For expression-preserving code generation, three MOVs suffice: MOV a,R1; ADD b,R1; MOV c,R2; ADD d,R2; SUB e,R2; SUB R1,R2; MOV R2,t4. The specified source-minus-destination semantics gives R1=t1, R2=t2 then t3=e−t2 then t4=t1−t3. There are two loads to initialize the two independently computed subexpressions and one store, yielding the intended option B (3). This minimum presumes the usual task of generating code for the given expression structure. If algebraic reassociation is allowed, two MOVs suffice: MOV c,R1; ADD d,R1; SUB e,R1; SUB a,R1; ADD b,R1; MOV R1,t4. This computes t4=a−(e−(c+d))+b. Furthermore, if arbitrary arithmetic instructions may initialize a register, SUB R1,R1 makes zero; replacing the initial MOV c,R1 by SUB R1,R1; ADD c,R1 leaves only the final MOV. Hence the literal unrestricted minimum is not 3, and the scope assumption must be disclosed; B is an intended, conditional answer rather than an unconditional theorem.
