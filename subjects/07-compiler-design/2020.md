**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** Test I: symbol tables are accessed only in lexical and syntax analysis. II: supporting recursion necessarily requires heap allocation. III: declaration-before-use errors are detected during syntax analysis. Options: A I only; B I and III; C II only; D none.

## Solution

Worked explanation

A symbol table records information such as declarations, types and locations. Type checking needs that information in semantic analysis, and code generation may need offsets and storage locations, so “only” makes I false. Recursive calls need distinct activation records, but their last-in-first-out lifetimes are exactly what a runtime stack handles; a heap is not logically necessary. Finally, syntax checks whether token sequences fit grammatical productions, whereas whether a particular name has already been declared depends on the binding environment. That contextual condition belongs to semantic analysis in the conventional compiler-phase distinction used here.

Derivation and answer

Semantic analysis and code generation also consult symbol-table information, refuting I. Ordinary nested recursion can be supported with stack activation records and does not inherently need a heap, refuting II. Declaration-before-use is a contextual semantic condition, not ordinary context-free syntax checking, refuting III. Thus none, D.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 7 to 7

**Derived answer:** 7

**Paraphrased problem context:** Grammar: S→aSB | d; B→b. How many reductions does a bottom-up parser perform to accept aaadbbb?

## Solution

Worked explanation

An explicit reduction sequence is aaadbbb ⇒ aaaSbbb ⇒ aaaSBbb ⇒ aaSbb ⇒ aaSBb ⇒ aSb ⇒ aSB ⇒ S. The first step uses d→S; each pair thereafter uses b→B followed by aSB→S. Thus there are 1+3+3=7 reductions. The corresponding derivation tree has four S-production nodes and three B-production nodes. A bottom-up parser may also shift seven terminals and eventually perform an accept action; neither shifts nor accept are additional grammar reductions.

Derivation and answer

The derivation uses S→aSB three times, S→d once, and B→b three times. A bottom-up parse reverses these seven production applications, so it performs7 reductions, excluding the separate parser accept action.

# GATE 2020 CS: Q43 (printed CS Q33)

**Question:** [Official archived paper page 11](https://gate2026.iitg.ac.in/doc/download/2020/cs_2020.pdf#page=11); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Productions A→PQ and A→XY have inherited i and synthesized s attributes on each nonterminal. Rule 1: P.i=A.i+2; Q.i=P.i+A.i; A.s=P.s+Q.s. Rule 2: X.i=A.i+Y.s; Y.i=X.s+A.i. Which are L-attributed? A both; B only Rule 1; C only Rule 2; D neither.

## Solution

Worked explanation

An inherited attribute of a child in an L-attributed definition may depend on inherited attributes of the parent and attributes of siblings to its left. In A→PQ, P has no left sibling, and its inherited value depends only on A.i. Q can use P.i because P is left of Q. Synthesized A.s is evaluated after both children return. A valid evaluation order is A.i, P.i, process P to get P.s, Q.i, process Q to get Q.s, then A.s. In A→XY, X.i needs Y.s even though Y is on X’s right, violating the restriction. Y.i’s use of X.s would be allowed by itself; it does not rescue the first dependency.

Derivation and answer

Rule1 computes each inherited attribute from the parent’s inherited attribute and, for Q, a left sibling’s attribute; the parent synthesized attribute can then combine child results. This is L-attributed. Rule2 computes X.i using right sibling Y.s, violating the left-to-right dependency restriction. Only Rule1, B.
