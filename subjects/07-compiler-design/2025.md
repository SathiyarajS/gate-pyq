# GATE 2025 CS1: Q13

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

## Solution

A variable is live where its current value can be used along some future path before being overwritten. Variables with overlapping live ranges generally cannot share the same register. Register allocation/assignment uses this information, often via an interference graph; variables whose live ranges do not overlap can reuse a register. Thus B. Strength reduction and constant folding instead exploit cheaper equivalent operations and known constant values.

**Derived answer:** C

## Solution

Backpatching emits branches with temporarily unresolved target fields and retains lists of those branches. When the target location becomes known later in the same traversal, the fields are filled in. This supports Boolean short-circuit true/false lists and flow-of-control next/break-style targets without a second source pass. Both statements hold, so C.

# GATE 2025 CS2: Q40

**Question:** [Official archived paper page 30](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=30); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

FOLLOW(A)={a, c}. In the LR(0) state after reading d from the start, items include A→d· and S→d·c, so SLR reduces A→d on c and also shifts c, a conflict. After bd there is the analogous conflict on a. In LR(1), after initial d the completed A item has only lookahead a, while the S item shifts c; after bd the completed A item has only lookahead c, while S→bd·a shifts a. Thus the conflicts disappear with precise lookaheads. These two states have different LR(0) cores because their S items differ, so LALR merging does not combine them; no other state causes a conflict. Therefore the grammar is LALR(1) but not SLR(1), option C.

# GATE 2025 CS2: Q51

**Question:** [Official archived paper page 39](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=39); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** C;D

**Derived answer:** C;D

## Solution

Write i for the terminal phrase “if b then” and e for “else”. G1 derives i i a e a with the else attached either to the inner or outer if, so it is ambiguous. G2 is also ambiguous: i i c e i c e c can be parsed as an unmatched outer i followed by the matched statement [i c e (i c e c)], or as the matched outer statement [i (i c e (i c)) e c]. The latter inner unmatched i is allowed because the else branch in M→i M e S is S, not a fully matched M. These are distinct parse trees. Neither grammar is LL(1), since LL(1) grammars are unambiguous; directly, the alternatives also share FIRST token if. Select C, D.
