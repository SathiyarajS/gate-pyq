## Solution

Scope tracking is a normal symbol-table function, and a binary search tree is a possible implementation. D reflects the textbook organization in which lexical analysis creates initial identifier entries; exact construction and population timing can vary across compiler implementations, so it is not a universal implementation requirement.

# GATE 2025 CS1: Q13

**Question:** [Official archived paper page 13](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=13); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

## Solution

A variable is live where its current value can be used along some future path before being overwritten. Variables with overlapping live ranges generally cannot share the same register. Register allocation/assignment uses this information, often via an interference graph; variables whose live ranges do not overlap can reuse a register. Thus B. Strength reduction and constant folding instead exploit cheaper equivalent operations and known constant values.

# GATE 2025 CS1: Q46

**Question:** [Official archived paper page 46](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=46); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A;D

**Derived answer:** A;D

## Solution

A production A→ε makes ε a possible derived string, so ε belongs to FIRST(A). The end marker belongs to FOLLOW(S) for the start symbol because an accepted complete input follows S with end-of-input. ε is never a FOLLOW symbol, and the end marker is not automatically an element of FIRST(S). Select A and D.

Leaders are the first instruction1001, jump targets1002, 1003, 1013, and instructions following conditional jumps1010, 1012. The six blocks are1001; 1002; 1003–1009; 1010–1011; 1012; 1013–1017. The final branch has no following instruction in the supplied sequence, so no extra block is created. Answer 6.
