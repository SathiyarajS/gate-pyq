**Independently derived answer:** x¬ab+ya¬b in the Boolean switching model; no driven output for a=b without an additional convention

**Essential problem context (paraphrased):** The GFG figure connects x through controls ¬a, b and y through controls a, ¬b, joining at f. Upper a and lower b have inversion bubbles; Forum omits these bubbles. Find f.

## Solution

In the enlarged GFG figure, the upper a-controlled switch has an inversion bubble while its b switch does not. This path conducts when a=0, b=1, passing x. The lower path has the opposite control polarities, so it conducts when a=1, b=0 and passes y. Combining those path contributions gives f=x¬ab+ya¬b. The paths are never simultaneously enabled, so this GFG reading avoids conflicting input drivers. However, when a=b neither path conducts: a physical pass-transistor output is floating or retains charge unless a pull device or storage convention is specified. Thus treating disabled paths as Boolean zero is a switching-algebra convention. Forum loses the two bubbles and must not silently replace the clearer GFG controls.

**Independently derived answer:** c1=(a1b0) XOR (a0b1)

**Essential problem context (paraphrased):** A=a3a2a1a0 and B=b3b2b1b0 are unsigned four-bit numbers. Express product bit c1.

## Solution

The column of weight 1 contains only a0b0, so it produces c0 and no carry into the weight-2 column. That next column contains a1b0 and a0b1. Adding two bits gives their XOR as the low result bit and their AND as carry to weight 4. Hence c1 is the XOR of the two partial products. Higher input bits cannot contribute to this column because their positional weights are at least four. Ordinary OR would be wrong when both partial products are one.

**Independently derived answer:** A: lower power dissipation in the conventional static comparison

**Essential problem context (paraphrased):** Which listed advantage does CMOS have over nMOS: lower power, greater speed, smaller chip, fewer masks, none?

## Solution

A static CMOS gate ideally has no direct DC path from supply to ground in a stable logic state: one complementary network is off. Conventional nMOS load logic can draw steady current in one state. This explains the standard lower-static-power advantage. CMOS still consumes dynamic switching power and leakage, so zero real power is not asserted. Speed, area and fabrication-mask count depend on process and circuit design; the other listed claims are not universal advantages established merely by choosing CMOS. The comparison is historical logic-family behavior, not a ranking of every modern implementation.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B: easier avoidance of hazard-related errors

**Essential problem context (paraphrased):** Choose the advantage of synchronous over asynchronous sequential circuits: faster operation, easier hazard avoidance, less hardware, better noise immunity, none.

## Solution

A synchronous design samples state on designated clock events. If combinational signals settle and setup/hold constraints are met before those events, intermediate glitches need not become incorrect stored states. This makes hazard management more systematic than in an asynchronous network whose transitions can directly trigger further state changes. The clock does not eliminate glitches or metastability automatically. Nor does synchrony inherently guarantee greater speed, smaller hardware or electrical noise immunity. The advantage is controlled observation time, subject to correct timing design.

# GATE 1991: Q38 (printed B Q5(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 4 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 00→0; 01→previous Q; 10→previous Q; 11→1.

**Essential problem context (paraphrased):** Three two-input AND gates form aQ, ab and bQ; their outputs feed a three-input OR whose output Q is fed back to the first and third AND gates. Complete the output table for inputs ab=00,01,10,11, allowing for the prior stable output.

## Solution

Denote the previously stable feedback value by Q_old. Reading each gate gives Q_new = aQ_old + ab + bQ_old. This is the majority function of a, b and Q_old, not a memoryless two-input gate.

For a=b=0 all three products vanish, so the circuit resets to 0. For a=0,b=1 only bQ_old remains, so the old output is retained. For a=1,b=0 only aQ_old remains, also retaining the old value. For a=b=1 the middle product ab forces 1 irrespective of the old state. Thus the requested table, in row order 00,01,10,11, is 0,Q_old,Q_old,1.

A connection schematic is: AND(a,Q) ┐; AND(a,b) ├→ OR → Q; AND(b,Q) ┘, with Q returned to the indicated inputs. This is a two-input Muller C-element: equal inputs update the state, unequal inputs hold it. Without an initial condition the held value cannot be replaced by a numerical zero or one. The table describes settled behavior and does not assert that arbitrary simultaneous input changes are hazard-free.

**Official answer:** Not available; no official key located.

**Independently derived answer:** f = B′D′ + AC (two products, four literals).

**Essential problem context (paraphrased):** Find a minimum SOP for f(A,B,C,D)=Σm(0,2,8,10,15)+Σd(3,11,12,14), with A the most significant bit.

## Solution

Place the mandatory ones at 0,2,8,10,15 in the four-variable Karnaugh map, mark 3,11,12,14 as optional, and treat all other cells as zeros. The group {0,2,8,10} fixes B=0,D=0 while A,C vary, producing B′D′. The group {10,11,14,15} fixes A=1,C=1, producing AC; its cells 11 and 14 are permitted don’t-cares. The union covers every mandatory one and no mandatory zero.

For minimality, a single implicant containing both 0=0000 and 15=1111 would leave all four bits free and cover forbidden zeros. Therefore at least two product terms are necessary. No one-literal implicant is legal: each half of the truth table contains at least one mandatory zero. Hence each nonzero product needs at least two literals, and two products need at least four literals. Our expression meets both lower bounds.

Don’t-cares are permissions to choose values that simplify the implementation, not required ones. For example this solution sets 3 and 12 to zero, which is allowed. Check the seven mandatory-zero cells as well as the five mandatory-one cells; checking only the specified ones would not establish equivalence.

**Essential problem context (paraphrased):** Three JK flip-flops Q0,Q1,Q2 share a clock. J0=K0=1. Cascaded two-input ANDs compute C1=1·Q0, C2=C1·Q1, C3=C2·Q2; J1=K1=C1 and J2=K2=C2. C3 is an outgoing carry with no shown destination. Flip-flop and AND delays are each 10 ns; setup time is negligible. Find maximum counter clock frequency.

## Solution

This is a synchronous counter, since all three flip-flops receive the same clock. It is not a three-stage ripple-clock chain. After an active edge, Q0 may change after 10 ns. Its new value reaches C1 after one AND delay and C2 after a second AND delay. The latest JK input of a shown flip-flop therefore settles after 10+10+10=30 ns. With negligible setup time the next active edge must be no earlier, giving fmax=1/(30 ns)=33⅓ MHz.

The path from Q1 to C2 takes only 20 ns. Q2 does not drive another displayed flip-flop. The third AND produces C3 only after as much as 40 ns from the clock, but that carry output is not connected to a register input in the displayed three-bit circuit. Counting it in the counter’s internal feedback constraint would assume an additional stage or external timing requirement.

If the question intends the outgoing carry to settle before every next edge, or the drawing is an expandable counter whose next stage samples C3, use Tmin=40 ns and fmax=25 MHz instead. State that additional condition explicitly. Clock skew, hold-time constraints and wire delays are outside the supplied delay model.

**Official answer:** Not available; no official key located.

**Independently derived answer:** For L=1 load: D0=LA+L′S, D1=LB+L′Q0, D2=LC+L′Q1; serial output Q2.

**Essential problem context (paraphrased):** Using D flip-flops and gates, design a three-bit parallel-in/serial-out register shifting left to right. Inputs: CLK, parallel A,B,C; serial input S; LOAD/SHIFT control.

## Solution

Let Q0,Q1,Q2 be the stored bits from left to right. Define L=1 as LOAD and L=0 as SHIFT, consistent with the uncomplemented LOAD and complemented SHIFT label. Place a 2:1 multiplexer before each D flip-flop and connect all three clock pins to CLK.

Connection schematic:
A ─load─┐   B ─load─┐    C ─load─┐
S ─shift┴MUX→DFF Q0 ─shift┴MUX→DFF Q1 ─shift┴MUX→DFF Q2→OUT
Each MUX uses L as select; all DFFs use the same active clock edge.

The gate equations are D0=(L AND A) OR (NOT L AND S), D1=(L AND B) OR (NOT L AND Q0), D2=(L AND C) OR (NOT L AND Q1). Implement each mux with two AND gates and one OR gate, sharing an inverter for L.

On a load edge the state becomes (A,B,C). On successive shift edges it becomes (S1,A,B), then (S2,S1,A), then (S3,S2,S1). The bits shifted out, measured just before those edges, are C,B,A. All right-hand sides use the old state because the flip-flops update together; using the newly updated Q0 to compute Q1 would incorrectly move a bit through several stages in one clock. An asynchronous reset is optional, not required for loading.

# GATE 1991: Q42 (printed B Q6(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204230/GATE1991.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Use a modulo-1024 address counter and read-before-write phases: capture old RAM[p] as output, overwrite RAM[p] with input, then advance p.

**Essential problem context (paraphrased):** Design a 1024-bit serial-in/serial-out unidirectional shift register using a 1K×1 RAM with Din,Dout and READ/WRITE control, plus standard gates, registers and counters.

## Solution

A literal shift of all 1024 RAM cells on every bit would be wasteful. Instead, regard the RAM as a circular queue. Use a 10-bit binary counter p connected to RAM address A9..A0, an input holding flip-flop I, an output flip-flop O, and a two-phase controller.

Schematic:
serial IN→I→RAM Din; counter p[9:0]→RAM address; RAM Dout→O→serial OUT.
Controller→{I clock, RAM READ/WRITE, O clock, counter enable}.

For each external shift event: (1) latch the incoming bit in I and keep p stable; (2) select READ, wait for RAM access time, and clock Dout into O; (3) select WRITE and store I at the same p, meeting write pulse/setup/hold timing; (4) return to READ and increment p modulo 1024. The output must be captured before the write, since the RAM’s read-during-write behavior is not specified.

After initialization, address p holds the oldest of the 1024 retained bits. Reading emits that bit, overwriting appends the new bit, and incrementing makes the next-oldest location the head. Inductively, input bit s[k] is emitted on shift event k+1024, where an event’s output means the bit removed on that event. The first 1024 outputs depend on the RAM’s initial contents. To emulate a reset-to-zero shift register, clear every RAM location during a separate initialization sweep. The external shift period must accommodate both the read and write phases.
