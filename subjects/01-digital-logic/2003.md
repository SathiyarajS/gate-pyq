**Independently derived answer:** C

## Solution

A conventional array multiplier forms partial products in parallel and propagates carries/sums through a linear number of adder stages. With constant delay per gate/stage, its critical path is Θ(n), C. Its Θ(n²) hardware area does not imply quadratic propagation delay; a tree multiplier is a different architecture.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

Before a threshold is reached, it suffices to track d=(zeros seen)−(ones seen) in {−1,0,1}. Reaching +2 or −2 enters a separate absorbing state with output 10 or 01. Thus five states suffice. They are all distinguishable: the absorbing states have different outputs, and appropriate one-bit continuations separate each pair of the three pre-threshold states. Hence five states are necessary, option A.

# GATE 2003: Q45 (printed CS Q45)

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** (9,8); no listed option

## Solution

Use row variables xy and column variables zw in the printed Gray order 00,01,11,10. A valid minimum SOP is (¬w∧¬y)∨(w∧¬x∧¬z)∨(x∧¬w∧¬z), containing 2+3+3=8 literals. A valid minimum POS is (y∨¬x)∧(¬w∨¬z)∧(¬y∨¬z)∧(w∨x∨¬y), containing 2+2+2+3=9 literals. Each matches every specified 0 and 1; the X cells may be assigned as needed separately for the two minimizations. Exhaustive enumeration of all 3⁴ Boolean cubes, excluding any cube that covers a forbidden cell, and exact minimum-cost covering of the required cells confirms these lower bounds. Thus the requested ordered pair (POS,SOP) is (9,8), absent from (11,9),(9,13),(9,10),(11,11). Both visually inspected reproductions have the same map and options; an authentic original is needed to resolve the apparent defect.

# GATE 2003: Q47 (printed CS Q47)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Let A(t) rise once at t=1 ns. The first XOR output is A(t) XOR A(t−2), a pulse on [1,3). The second output XORs this pulse with its copy delayed by 4 ns. The copies occupy [1,3) and [5,7), so they do not overlap and the output changes at 1,3,5,7 ns. There are four transitions in the stated interval, option D.
