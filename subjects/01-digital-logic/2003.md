**Paraphrased problem context:** Interpret every bit string as an eight-bit two’s-complement integer. Which is divisible by 11111011? A. 11100111; B. 11100100; C. 11010111; D. 11011011.

## Solution

1. For an eight-bit word with most significant bit 1, subtract 256 from its unsigned value. The divisor is −5, so only signed multiples of 5 qualify. Dividing −25 by −5 gives the integer 5; the other listed values leave nonzero remainders.

2. The 8-bit two’s-complement divisor 11111011 is 251−256=−5. The listed values 11100111,11100100,11010111,11011011 are respectively−25,−28,−41,−37. Only−25 is divisible by−5, so A.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** An array multiplier multiplies two n-bit numbers. Every gate has unit delay. What is its total propagation delay? A. Θ(1); B. Θ(log n); C. Θ(n); D. Θ(n²).

## Solution

1. The relevant quantity is longest input-to-output path, not total gate count. Partial-product generation occurs in parallel, after which a regular array has a number of dependent addition levels proportional to operand width. Unit gate delay therefore makes the critical delay linear even though there are quadratically many partial-product cells.

2. A conventional array multiplier forms partial products in parallel and propagates carries/sums through a linear number of adder stages. With constant delay per gate/stage, its critical path is Θ(n), C. Its Θ(n²) hardware area does not imply quadratic propagation delay; a tree multiplier is a different architecture.

# GATE 2003: Q44 (printed CS Q44)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** A synchronous sequential circuit has one input and two output bits. Let zₖ,nₖ count zeros and ones in the first k input bits. Initially output is 00. When zₖ−nₖ first reaches 2, output becomes 10 forever. When nₖ−zₖ first reaches 2, output becomes 01 forever. What is the minimum number of states? A. 5; B. 6; C. 7; D. 8.

## Solution

1. Before absorption retain only d=zₖ−nₖ. On input 0 increment d and on input 1 decrement it. Values −1,0,+1 are nonabsorbing and still output 00; reaching +2 or −2 selects different permanent outputs. Distinguish 0 from +1 by suffix 0, 0 from −1 by suffix 1, and −1 from +1 by suffix 0, proving the three transient states cannot merge.

2. Before a threshold is reached, it suffices to track d=(zeros seen)−(ones seen) in {−1,0,1}. Reaching +2 or −2 enters a separate absorbing state with output 10 or 01. Thus five states suffice. They are all distinguishable: the absorbing states have different outputs, and appropriate one-bit continuations separate each pair of the three pre-threshold states. Hence five states are necessary, option A.

**Independently derived answer:** (9,8); no listed option

**Paraphrased problem context:** Literal count counts every variable occurrence, complemented or not; for example xy+xz has four literals. Find minimum literal counts for a product-of-sums and a sum-of-products, respectively, for this four-variable Karnaugh map. Rows xy and columns zw both use Gray order 00,01,11,10. Rows are: 00:(X,1,0,1); 01:(0,1,X,0); 11:(1,X,X,0); 10:(X,0,0,X), with X a don’t-care. A. (11,9); B. (9,13); C. (9,10); D. (11,11). An independently minimized pair may be absent from these reproduced options.

## Solution

1. For SOP, group 1 cells with optional X cells and never cover a specified 0; this yields ¬w¬y, w¬x¬z, x¬w¬z. For POS, group zeros with optional X cells, yielding factors (y∨¬x),(¬w∨¬z),(¬y∨¬z),(w∨x∨¬y). Count variable occurrences, not number of groups: SOP has 8 and POS has 9. Don’t-care choices may differ for the two minimizations. The exact-cover checker is needed to certify these are minima rather than just valid upper bounds.

2. Use row variables xy and column variables zw in the printed Gray order 00,01,11,10. A valid minimum SOP is (¬w∧¬y)∨(w∧¬x∧¬z)∨(x∧¬w∧¬z), containing 2+3+3=8 literals. A valid minimum POS is (y∨¬x)∧(¬w∨¬z)∧(¬y∨¬z)∧(w∨x∨¬y), containing 2+2+2+3=9 literals. Each matches every specified 0 and 1; the X cells may be assigned as needed separately for the two minimizations. Exhaustive enumeration of all 3⁴ Boolean cubes, excluding any cube that covers a forbidden cell, and exact minimum-cost covering of the required cells confirms these lower bounds. Thus the requested ordered pair (POS,SOP) is (9,8), absent from (11,9),(9,13),(9,10),(11,11). Both visually inspected reproductions have the same map and options; an authentic original is needed to resolve the apparent defect.

# GATE 2003: Q47 (printed CS Q47)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Two zero-delay XOR gates are cascaded. The first receives A directly and A through a non-inverting buffer delayed by 2 ns. Its output X feeds the second XOR directly and through a non-inverting buffer delayed by 4 ns. All wires/gates except those buffers have zero delay, and every signal is initially 0. A rises from 0 to 1 at t=1 ns and stays 1. How many transitions occur at the final output B from t=0 to 10 ns?
A. 1  B. 2  C. 3  D. 4

## Solution

1. Before 1 ns both first-XOR inputs are 0. At 1 ns its direct input rises, but its delayed input stays 0 until 3 ns. Therefore X is 1 exactly on [1,3).
2. The 4 ns delayed copy of X is 1 on [5,7). The second XOR is high when exactly one copy is high, so B is high on those two nonoverlapping intervals.
3. List the changes: 0→1 at 1 ns, 1→0 at 3 ns, 0→1 at 5 ns, and 1→0 at 7 ns. There are four, giving D.

Baseline derivation and caveats (retained): Let A(t) rise once at t=1 ns. The first XOR output is A(t) XOR A(t−2), a pulse on [1,3). The second output XORs this pulse with its copy delayed by 4 ns. The copies occupy [1,3) and [5,7), so they do not overlap and the output changes at 1,3,5,7 ns. There are four transitions in the stated interval, option D.
