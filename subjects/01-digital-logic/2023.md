

# GATE 2023 CS: Q21

**Question:** [Official archived paper page 19](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=19); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** A 2:1 multiplexer has its output Q fed to input 0 and external data D at input 1, controlled by S. Is it equivalent to A a D flip-flop; B a D latch; C a half-adder; D a demultiplexer?

## Solution

The feedback wire reaches mux input0 and the external data wire reaches input1. When S=0 the output feeds itself, holding the stored value; when S=1 the output follows the data continuously. This is a level-sensitive D latch, not an edge-triggered flip-flop. Answer B; feedback and selector wiring were visually checked.

Teaching detail. The mux equation is Qnext=(NOT S)Q+SD. At S=0 it reduces to Qnext=Q, providing storage through feedback. At S=1 it reduces to Qnext=D, so changes in D can propagate for the whole enabled level. An edge-triggered device would sample only at a clock transition, which this circuit does not implement. Calling the component a latch also assumes ordinary stable operation of the feedback circuit rather than treating its loop as a feed-forward combinational expression.

# GATE 2023 CS: Q32

**Question:** [Official archived paper page 30](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=30); consult original wording, diagrams and choices.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 110 to 110

**Derived answer:** 110

**Paraphrased problem context:** Convert the number (132)₄ to radix 5; enter its base-5 digits.

## Solution

132 base4 equals1×16+3×4+2=30 decimal. Dividing30 by 5 gives quotient6 remainder0, and 6 by 5 gives quotient1 remainder1. Thus30=1×25+1×5+0, or110 base5.

Teaching detail. The digits of a positional numeral are coefficients of powers of the base, starting at exponent zero from the right. Thus the conversion first obtains the underlying integer and then re-expresses it with powers of 5. The final check is 1·5²+1·5+0=30, equal to the original 1·4²+3·4+2. Do not enter 30 as the answer: that is the decimal intermediary, whereas the question requests the digit string in radix 5. All digits of 110 are valid in base 5.

# GATE 2023 CS: Q43

**Question:** [Official archived paper page 45](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=45); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** A synchronous circuit starts at (Q1,Q2,Q3)=(0,1,1). Its first T flip-flop input is NOT Q3, its middle D flip-flop input is Q1, and its third T flip-flop input is Q2; all share one clock. Which state is unreachable? A 001; B 100; C 101; D 111.

## Solution

All three flip-flops share the clock. The inspected wiring gives Q1_next=Q1 XOR NOT Q3, Q2_next=Q1, and Q3_next=Q3 XOR Q2. Starting at 011, simultaneous updates give000→100→010→101→111→110→011, a seven-state cycle. State001 never occurs, while the other offered states 100, 101, 111 do. Thus A. Each update uses old state values, not sequentially updated outputs.

Teaching detail. A D flip-flop copies its input at the active clock edge; a T flip-flop holds when T=0 and toggles when T=1, so its equation is Qnext=Q XOR T. Apply all three equations to the same old state. For initial 011, NOT Q3=0 keeps Q1 at 0, Q2 copies old Q1=0, and Q3 toggles because old Q2=1, giving 000. Continuing until the initial state repeats proves the whole reachable cycle is exhausted; a few sampled clock steps alone would not prove unreachability.

# GATE 2023 CS: Q44

**Question:** [Official archived paper page 46](https://gate2026.iitg.ac.in/doc/download/2023/cs_2023.pdf#page=46); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Two 4:1 muxes M1,M2 use select bits (S1,S0)=(A,C) and inputs X0..X3,X4..X7. A final mux selects M1 when B=0 and M2 when B=1. Set all Xi to constants to implement F=NOT A+(NOT A)(NOT C)+A(NOT B)C. Find the eight constants in order.

## Solution

The visually checked function is NOT A + (NOT A)(NOT C) + A(NOT B)C, which absorbs to NOT A + A(NOT B)C. Both four-input muxes use select bits(A, C), while the final mux selects M1 for B=0 and M2 for B=1. For B=0, evaluating at AC=00, 01, 10, 11 gives 1, 1, 0, 1; for B=1 it gives 1, 1, 0, 0. Therefore(X0,…, X7)=(1, 1, 0, 1, 1, 1, 0, 0), option C. Complement bars and selector ordering were visually verified.

Teaching detail. The mux address inside each 4:1 block is 2A+C. Thus each Xi is simply the desired output for one combination of A,C, with the block chosen by B. When A=0, the NOT A term forces output 1 irrespective of B,C, giving X0=X1=X4=X5=1. When A=1, the function reduces to (NOT B)C: it is zero for C=0 in both blocks, one only in the B=0,C=1 position. This independently obtains X2=X6=X7=0 and X3=1.
