**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Circuit: top gate is NAND of X and complemented Y; bottom gate is AND of Y and Z; output f is NAND of those two results. Which variable is redundant? A X; B Y; C Z; D none.

## Solution

The upper NAND output is ¬(X¬Y)=¬X+Y; the lower AND output is YZ. The final NAND is ¬[(¬X+Y)YZ]=¬(YZ), because Y(¬X+Y)=Y. Thus X is irrelevant and f depends only on Y, Z, A.

Teaching detail:
Let top output t=¬(X¬Y), bottom u=YZ, and f=¬(tu). If Y=0, u=0 and f=1 regardless of X, Z. If Y=1, the top output is 1 and f=¬Z. Together these cases give f=¬Y∨¬Z=¬(YZ), independent of X. This also follows algebraically because Y·¬Y=0 cancels the X-dependent product. Thus A.

**Independently derived answer:** A

**Paraphrased problem context:** Representable n-bit two’s-complement range? A −2^(n−1) through 2^(n−1)−1; B −(2^(n−1)−1) through 2^(n−1)−1; C −2^(n−1) through 2^(n−1); D −(2^(n−1)+1) through 2^(n−1)−1.

## Solution

The most significant bit has weight−2^(n−1) and the remaining bits sum from 0 to 2^(n−1)−1. Thus the represented range is−2^(n−1) through 2^(n−1)−1, A.

Teaching detail:
The most significant bit has weight−2^(n−1), while lower bits contribute from 0 through 2^(n−1)−1. Setting only the sign bit gives the minimum; setting all lower bits and clearing the sign bit gives the maximum. There are exactly 2^n values in the asymmetric interval, including zero once, so A.

## Solution

657 in octal is 6×64+5×8+7=431. Dividing into hexadecimal digits gives 1×256+10×16+15=1AF, A. Equivalently, octal bits 110101111 regroup as 0001 1010 1111.

# GATE 2005: Q62 (printed CS Q62)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A under pre-edge sampling convention

**Paraphrased problem context:** Positive-edge D flip-flop has D=A·X+Q′·X′ and output Y=Q. Before successive rising edges X=1, 1, 0, 1, 1; A takes A0, A1, A2, A3, A4. The source draws X changes exactly at some edges. Output over periods 1–5: A A0, A1, A1′, A3, A4; B A0, A1, A2′, A3, A4; C A1, A2, A2′, A3, A4; D A1, A2, A3, A4, A5. Explain the ideal sampling assumption.

## Solution

The combinational input is D=AX+Q′X′. Thus X=1 loads A and X=0 toggles the previous output. Sampling the values just BEFORE each rising edge, X is 1, 1, 0, 1, 1 and the available A values are A0, A1, A2, A3, A4. The outputs for periods 1–5 are therefore A0, A1, A1′, A3, A4, option A. Both drawings put X transitions exactly on rising edges; an actual device would require setup/hold timing to determine the result reliably. The answer uses the conventional idealized pre-edge interpretation rather than claiming that coincident physical transitions are well-defined.

Teaching detail:
Evaluate the next-state equation before each clock edge. With X=1 the second product vanishes, so D=A and the register loads that sample. With X=0 the first product vanishes, so D=¬Q and it toggles its previously stored value. The third edge therefore stores ¬A1 rather than an independent A2. This produces option A under pre-edge sampling. A real setup/hold violation at a coincident transition cannot be resolved solely from an ideal Boolean drawing.

# GATE 2005: Q63 (printed CS Q63)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** A binary transducer reads least-significant bit first. Initial Q0 loops on 0/output 0 and changes to Q1 on 1/output 1; Q1 loops on 0/output 1 and 1/output 0. Does it compute A ones complement; B twos complement; C increment; D decrement?

## Solution

Read from the least significant end: Q0 copies all initial zeros and copies the first 1, then Q1 complements every remaining bit. Keeping the least-significant 1 and all lower zeros while complementing higher bits is exactly fixed-width two’s-complement negation. The all-zero input remains zero. Thus B.

Teaching detail:
Subtracting a fixed-width binary word from zero leaves its trailing zeros unchanged, leaves the first 1 unchanged, and complements all higher bits. The state change happens at precisely that first 1. For example input word 010100 read from the right yields output 101100, its negation modulo 64. Zero never leaves Q0 and stays zero. A ones-complement machine would flip the trailing zeros too, so A is not the same operation.

# GATE 2005: Q64 (printed CS Q64)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203225/GATE2005.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Two positive-edge D flip-flops start at Q0Q1=00. Wiring gives D0=¬Q0 and D1=Q0 XOR ¬Q1. Which repeating cycle? A00→11→01→00; B00→11→00; C00→10→01→11→00; D00→11→01→10→00.

## Solution

Read the wires as Q0(next)=Q0′ and Q1(next)=Q0 XOR Q1′. Simultaneous updates from 00 give 11; from 11 give 01; from 01 give 10; and from 10 return to 00. Thus the cycle is 00→11→01→10→00, D. Both source diagrams agree.

Teaching detail:
Both registers sample old values simultaneously. At 00, D0=1 and D1=0 XOR 1=1, producing 11. At 11, D0=0 and D1=1 XOR 0=1, producing 01. At 01, D0=1 and D1=0 XOR 0=0, producing 10. At 10, D0=0 and D1=1 XOR 1=0, returning 00. Do not update Q0 first and reuse its new value in the Q1 equation; that would describe different asynchronous behavior.
