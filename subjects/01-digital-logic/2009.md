**Independently derived answer:** B

**Paraphrased problem context:** Convert octal 1217 to the equivalent choice: A hexadecimal 1217; B hexadecimal 028F; C decimal 2297; D hexadecimal 0B17.

## Solution

Octal 1217 expands to binary 001 010 001 111. Grouping in fours gives 0010 1000 1111, hexadecimal 28F, or 028F with a leading zero. Hence B. Its decimal value is 512+128+8+7=655.

Teaching detail:
Using place values, octal 1217 equals 1·8³+2·8²+1·8+7=512+128+8+7=655. Divide into hexadecimal place values:655=2·256+8·16+15, so it is 028F hexadecimal. The same conversion follows by octal digit triples 001010001111, regrouped into binary quartets 0010 1000 1111.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** Implement F=AB+C using only two-input NOR gates. Find the minimum gate count: A 2; B 3; C 4; D 5.

## Solution

Factor AB+C=(A+C)(B+C). Compute u=NOR(A, C), v=NOR(B, C), then NOR(u, v)=(A+C)(B+C), using three gates. Two do not suffice: with at most two gates, the final NOR receives only primary inputs and the output of one preceding NOR; exhaustive truth-table enumeration of all such input choices finds no realization. Thus 3, B. The accompanying check script verifies the lower bound without assuming complementary inputs are supplied.

Teaching detail:
Use the product-of-sums identity AB+C=(A+C)(B+C). Gate 1 gives ¬(A+C); gate 2 gives ¬(B+C); their NOR yields ¬[¬(A+C)+¬(B+C)]=(A+C)(B+C). Thus three gates suffice. With only two NOR gates, the last gate can take raw inputs and at most one derived NOR signal; checking these structural possibilities cannot produce this three-variable function. The accompanying exhaustive small-circuit checker supplies the lower-bound check, so three is minimal.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** A two-bit state AB starts 00. For input 0, states 00, 01, 10, 11 transition respectively to 00, 10, 01, 10 with outputs 1, 0, 0, 0. For input 1 they transition to 01, 00, 01, 00 with outputs 0, 1, 1, 1. Minimum input length that arrives in 01 while emitting 1? A 3; B 4; C 5; D 6.

## Solution

The only transition ending in state 01 with output 1 is from state 10 on input 1. From 00, reaching 10 requires at least two inputs:00 --1/0-->01 --0/0-->10. Appending 1 reaches 01 and emits 1. Thus input 101 achieves the target in 3 steps, and the predecessor argument rules out shorter inputs. Answer A.

Teaching detail:
Work backward from the desired transition: among rows ending in 01, output 1 occurs only from 10 on input 1. From initial 00, a single input reaches only 00 or 01, never 10, so at least two inputs are needed before the final 1. Input 1 reaches 01 with output 0, then 0 reaches 10 with output 0, then 1 reaches 01 with output 1. This witness 101 has length 3 and matches the lower bound.
