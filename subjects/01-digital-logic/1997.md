**Essential problem context (paraphrased):** Define x*y=¬x+y with Boolean OR+. Let z=x*y. Find z*x.

## Solution

Substitute z=¬x+y. Then z*x=¬z+x=¬(¬x+y)+x. De Morgan gives¬(¬x+y)=x¬y. Finally x¬y+x=x by absorption. Thus B. A truth-table check gives 0 for x=0 and 1 for x=1 regardless of y. The custom star is not ordinary multiplication, so the definition must be substituted before simplifying.

# GATE 1997: Q86 (printed B QGFG70(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=10), physical page 10. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** {A}, {B}, {C,D}, {E,F,G}, {H}.

**Essential problem context (paraphrased):** The Mealy state table gives (next state,output) for inputs 0 and 1:
A: 0→(B,1), 1→(H,1)
B: 0→(F,1), 1→(D,1)
C: 0→(D,0), 1→(E,1)
D: 0→(C,0), 1→(F,1)
E: 0→(D,1), 1→(C,1)
F: 0→(C,1), 1→(C,1)
G: 0→(C,1), 1→(D,1)
H: 0→(C,0), 1→(A,1).
No initial state is specified. Find the equivalence partition of its states.

## Solution

Two Mealy states are equivalent if every finite input string produces the same output string from either state. In particular they must first agree on their immediate output for each input. The output pairs are (1,1) for A,B,E,F,G and (0,1) for C,D,H. This gives the initial partition P0={ABEFG,CDH}.

Refine each block according to the blocks reached on inputs 0 and 1, while retaining the output test. In P0, A and B lead respectively to blocks (ABEFG,CDH); E,F,G lead to (CDH,CDH); and C,D,H lead to (CDH,ABEFG). Hence P1={AB,EFG,CDH}.

Now use P1 to distinguish formerly similar successor states. A reaches (AB,CDH), whereas B reaches (EFG,CDH), splitting A from B. C and D both reach (CDH,EFG), whereas H reaches (CDH,AB), splitting H from CD. The states E,F,G still both transition into CDH. Thus P2={A,B,CD,EFG,H}.

Check stability: C and D have equal outputs and both go into CD on 0 and EFG on 1. Each of E,F,G has output 1 on both inputs and goes into CD on both inputs. No further split is needed. The singleton blocks trivially satisfy stability, so P2 is the equivalence partition.

Refinement never separates equivalent states: a split witnesses a finite input on which outputs eventually differ. For example, A and B are distinguished by 000, producing 111 and 110 respectively; H and C are distinguished by 100, producing 111 and 110. Conversely, a stable equal-output partition guarantees equal output sequences by induction on input length. This proves both directions, rather than guessing equivalent states from one-step transitions alone.

**Independently derived answer:** Five quotient states A,B,CD,EFG,H with the transition/output table below.

**Essential problem context (paraphrased):** The Mealy state table gives (next state,output) for inputs 0 and 1:
A: 0→(B,1), 1→(H,1)
B: 0→(F,1), 1→(D,1)
C: 0→(D,0), 1→(E,1)
D: 0→(C,0), 1→(F,1)
E: 0→(D,1), 1→(C,1)
F: 0→(C,1), 1→(C,1)
G: 0→(C,1), 1→(D,1)
H: 0→(C,0), 1→(A,1).
No initial state is specified. Give the minimal equivalent state table, naming merged states by their members.

## Solution

The equivalence blocks are {A},{B},{C,D},{E,F,G},{H}. Replace every original destination by its block name, keeping the original output. The reduced table is:

Present state   input 0: next/output   input 1: next/output
A               B/1                    H/1
B               EFG/1                  CD/1
CD              CD/0                   EFG/1
EFG             CD/1                   CD/1
H               CD/0                   A/1

For example, C goes to D/0 and E/1, whereas D goes to C/0 and F/1. Once C,D are both named CD and E,F,G are all named EFG, those two rows become identical. Similarly, E,F,G all reduce to the row CD/1, CD/1. Therefore the choice of a representative inside a merged block does not affect the quotient table.

Why is this minimal rather than merely smaller? Output-based refinement begins with {ABEFG,CDH}, refines to {AB,EFG,CDH}, and then to the five displayed blocks, which are stable. Distinct resulting blocks have some finite distinguishing input, so no further merger preserves all output behavior. Five states are necessary to represent the behavior of all states in the given table.

No start state is printed, so the table does not justify inventing one or removing states as unreachable from it. This is minimization of the supplied machine's state behaviors. If a separate initial-state specification were supplied, one would additionally check reachability before reporting the size of a recognizer from that particular start. The table remains a Mealy table: outputs label transitions, not states, and a Moore-machine reinterpretation would be a different problem.

# GATE 1997: Q88 (printed B QGFG71(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=10), physical page 10. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 3 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** f=¬w¬x+yz.

**Essential problem context (paraphrased):** f=(¬w+y)(¬x+y)(w+¬x+z)(¬w+z)(¬x+z), where + is Boolean OR, juxtaposition is AND, and ¬ is complement. Express f in minimal sum-of-products form. The source requests only the answer; the derivation is included for learning.

## Solution

Group the two factors sharing ¬w and the two sharing ¬x. The Boolean identity (a+b)(a+c)=a+bc gives
(¬w+y)(¬w+z)=¬w+yz,
(¬x+y)(¬x+z)=¬x+yz.
Applying the same identity with the common term yz gives (¬w+yz)(¬x+yz)=¬w¬x+yz. The original function is therefore (¬w¬x+yz)(w+¬x+z).

The remaining factor is redundant. Whenever ¬w¬x=1, its term ¬x makes w+¬x+z true. Whenever yz=1, its term z makes that factor true. Thus multiplying by it changes neither product term and f=¬w¬x+yz.

To justify minimality, not just equivalence, consider the true input 0000 in variable order wxyz. Any implicant covering it must require w=0 and x=0: changing w alone gives 1000, which is false, and changing x alone gives 0100, which is false. Its largest covering cube is therefore ¬w¬x. At 1111, changing y alone or z alone makes f false, so an implicant covering that point must require y=z=1. Its largest covering cube is yz. A single product cannot cover both 0000 and 1111 without allowing false inputs, since they disagree on every variable. Hence at least two terms and at least four literals are needed. The expression above uses exactly two two-literal terms and is minimal.

As a separate finite check, its 1-minterms are 0,1,2,3,7,11,15. Evaluating all 16 assignments agrees with the visually read five-factor source formula. The complemented literals are essential: dropping a bar during OCR would change both the simplification and the following fault-count answer.

# GATE 1997: Q89 (printed B QGFG71(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203902/GATE1997.pdf#page=10), physical page 10. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** 7 of the 16 input combinations.

**Essential problem context (paraphrased):** f=(¬w+y)(¬x+y)(w+¬x+z)(¬w+z)(¬x+z), where + is Boolean OR, juxtaposition is AND, and ¬ is complement. If the output line is stuck at 0, for how many input combinations is the output incorrect?

## Solution

A stuck-at-zero output differs from the correct circuit exactly on inputs for which f should be 1. Inputs where f=0 still produce the correct visible output even though the circuit is faulty. First simplify the function to f=¬w¬x+yz using Boolean algebra.

Count the satisfying assignments by inclusion-exclusion. The term ¬w¬x fixes w=x=0 and leaves y,z free, giving four inputs. The term yz fixes y=z=1 and leaves w,x free, also giving four inputs. Their intersection fixes w=x=0,y=z=1, so that single input was counted twice. The number of distinct true inputs is 4+4−1=7.

In wxyz binary order, the erroneous inputs are 0000,0001,0010,0011,0111,1011,1111, corresponding to minterms 0,1,2,3,7,11,15. On each, the healthy output is 1 and the faulty output is 0. The other nine combinations have healthy output 0 and therefore do not expose this fault.

This count concerns one stuck-at fault on the final output line. It is not the count of faulty internal signals, nor a probability unless an input distribution is supplied. If all 16 inputs are equally likely, the observable error probability would be 7/16, but the requested answer is the integer 7.
