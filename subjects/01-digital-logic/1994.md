**Essential problem context (paraphrased):** The circuit forms t=NAND(A,B), u=NAND(t,C), v=NAND(C,D), then f=NAND(u,v). Find its Boolean expression.

Following the intermediate nets prevents accidentally treating the first NAND as AND or distributing a complement across a sum without changing the operator. **Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=3), physical page 3. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** fill-in, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** ceil(log₂N), for N≥2

**Essential problem context (paraphrased):** Fill in the minimum number of flip-flops required for a binary modulo-N counter.

## Solution

With k flip-flops, the state register has at most 2^k distinct binary states. A modulo-N counter must distinguish N positions before repeating, so 2^k≥N and k≥ceil(log₂N). This many bits are sufficient: use N of the available states and arrange the transition after N−1 to return to zero. Non-power-of-two counters leave unused codes, whose recovery behavior should be designed separately. The degenerate N=1 counter can be a constant output with no state bits in the abstract model.

# GATE 1994: Q37 (printed A Q3.3)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204113/GATE1994.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** true-false-with-reason, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** True for an LSB-first synchronous serial adder

**Essential problem context (paraphrased):** True or false: a finite-state machine can add two integers of arbitrary digit length. State the input/output convention.

## Solution

Feed the two numbers one bit pair at a time from least significant to most significant, padding the shorter with zeros. The machine needs only the carry bit c, hence two states. For input bits a,b it emits (a+b+c) mod 2 and changes state to floor((a+b+c)/2). After the final pair, emit the remaining carry. This works for any finite length with constant internal state. The convention matters: it is a transducer with paired LSB-first input, not a DFA expected to store both complete unbounded integers or emit an MSB-first sum before future carries are known.

## Solution

1. When A=0, C=B̅; hence C*0=C̅=B.

3. Equivalently two equivalence operations cancel the same A, leaving B.

**Official answer:** Not available; no official key located.

**Independently derived answer:** Even parity: bit 6 is wrong, corrected word 1100110. Odd parity: bit 1 is wrong, corrected word 1000111.

**Essential problem context (paraphrased):** A received seven-bit single-error-correcting Hamming word has positions 7,6,5,4,3,2,1 containing 1,0,0,0,1,1,0 respectively. Assuming at most one corrupted bit, determine correctness and, if needed, correct it.

## Solution

1. Parity checks cover positions {1,3,5,7}, {2,3,6,7}, {4,5,6,7}. Their received XORs are 0,1,1.

2. For even parity each expected XOR is zero. The failure vector (s4,s2,s1)=110₂=6 locates bit 6; flip its 0 to 1 to obtain 1100110 in position order 7 through 1. All three checks then equal zero.

3. For odd parity each expected XOR is one. The failure vector is 001₂=1, so flip bit 1 from 0 to 1 to obtain 1000111 in position order 7 through 1. All three checks then equal one.

4. Because the source does not specify the parity convention, one cannot select a unique corrected word without stating an assumption.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A=B=C=1.

**Essential problem context (paraphrased):** A first NAND gate takes A,B and drives line p; a second NAND takes p,C. Line p is stuck at 1. Determine an input test that detects the fault.

## Solution

1. Excite the fault by making the healthy p=0. Since p=NOT(A AND B), this requires A=B=1.

2. Propagate the discrepancy through the second NAND by setting its other input C=1. A controlling zero on C would mask p.

3. Healthy output is NOT(0·1)=1; faulty output is NOT(1·1)=0, so output comparison detects the fault.
