

# GATE 1996: Q46 (printed A Q2.21)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D: binary to radix 12

**Essential problem context (paraphrased):** The pictured four-bit adder receives b3…b0 and adds 0100 when b3b2=1, otherwise 0000; carry-in is zero. Its five output bits represent which conversion?

## Solution

The condition b3b2=1 holds exactly for input values 12 through 15. For inputs 0 through 11, adding zero leaves the low four-bit digit unchanged and the carry zero. For inputs 12 through 15, adding four produces 16 through 19, so the output is carry 1 with low digit 0 through 3. Interpreting these as radix-12 digits gives 10₁₂ through 13₁₂, equal to decimal 12 through 15. BCD would instead correct at decimal 10 and add six, so it does not match this wiring.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C: A⊕B⊕C for the GFG wiring

**Essential problem context (paraphrased):** A,B select mux inputs 0…3. In GFG the data inputs are C,¬C,¬C,C. Find f; the alternate loses the complement bars.

## Solution

When A=B, select 0 or 3, so f=C. When A≠B, select 1 or 2, so f=¬C. Thus f equals C toggled precisely when A⊕B=1, giving A⊕B⊕C. This evaluates all four selector cases and proves the parity expression. The GFG raster visibly places bars over the two middle C labels. GateForum prints all four inputs as C, which would give f=C instead and does not match the intended listed expression. Both source readings are disclosed rather than silently treating the damaged alternate as identical.

# GATE 1996: Q48 (printed A Q2.23)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B: 3

**Essential problem context (paraphrased):** For inputs 0,1, the next-state/output pairs are A:(D,0),(B,1); B:(A,0),(C,1); C:(A,0),(B,1); D:(A,1),(C,1). How many states remain?

## Solution

First group states by their immediate output pairs. A,B,C output (0,1), while D outputs (1,1), so D is separate. On input 0, A moves to D but B and C move to A, which belongs to the other initial group; therefore A must split from B,C. Now B and C both move to A on 0 and to the block {B,C} on 1, with identical outputs. They remain equivalent and no further split occurs. The stable partition is {A},{B,C},{D}, giving three states.

# GATE 1996: Q49 (printed A Q2.24)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** GFG C: (B+D)(¬B+¬D)

**Essential problem context (paraphrased):** The K-map has rows CD=00,01,11,10 and columns AB=00,01,11,10; its 1s occur exactly where B≠D. Find a product-of-sums expression.

## Solution

The displayed 1s occupy both B=1 columns when D=0 and both B=0 columns when D=1, independent of A and C. Hence the function is B XOR D. For a product-of-sums derivation, group the zeros with B=D=0 to obtain maxterm B+D, and group the zeros with B=D=1 to obtain maxterm ¬B+¬D. Their product is the required function. GFG option C prints this expression. The alternate changes complement marks in the choices and even labels the final column 20; its map still supports the same derived function, so the expression is more reliable than transferring a letter blindly.

# GATE 1996: Q57 (printed A Q5)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** MUX selects I0=NOT(A+B), I1=A+B, I2=A XOR B, I3=AB with selectors C1,C0.

**Essential problem context (paraphrased):** Inputs A,B and control bits C1,C0 specify F: 00→NOT(A OR B), 01→A OR B, 10→A XOR B, 11→A AND B. Implement using one 4:1 multiplexer, one two-input OR, one XOR, one AND, and one inverter. This is the complete GFG table; GateForum omits the last row.

## Solution

First compute P=A OR B using the single OR gate. Fan out P to the multiplexer input I1 and to the inverter; connect the inverter output NOT(P) to I0. Compute X=A XOR B with the XOR gate and connect it to I2. Compute G=A AND B with the AND gate and connect it to I3. Use C1 as the high-order select bit and C0 as the low-order select bit. The multiplexer output is F.

Text circuit: A,B→OR→P→I1; P→NOT→I0; A,B→XOR→I2; A,B→AND→I3; (C1,C0)→MUX select; MUX→F. A common wire may drive multiple inputs, so sharing the OR result does not require another gate.

The four select codes choose I0,I1,I2,I3 respectively, directly reproducing the complete table. Algebraically F=(NOT C1)(NOT C0)NOT(P)+(NOT C1)C0P+C1(NOT C0)X+C1C0G. These outer products describe the multiplexer and do not demand extra physical gates.

GFG p7 supplies all four rows and says 4-to-1. GateForum p11 labels the controls C1,C2 despite its prose naming C0,C1, omits the 11 row, and prints “4 to AB”. The implementation above follows the internally complete GFG version rather than inventing a missing GateForum requirement.

# GATE 1996: Q89 (printed B Q24(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=10), physical page 10. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** S0 self-loop; S1→S4→S2→S5→S6→S7→S3→S1.

**Essential problem context (paraphrased):** A synchronous circuit has three D flip-flops with common clock. Q1 feeds D2, Q2 feeds D3, and Q2 XOR Q3 feeds D1 through the feedback gate. State Si denotes the binary value i of Q1Q2Q3, so S0=000,...,S7=111. Draw its state-transition diagram.

## Solution

A D flip-flop takes its next output from its D input on the common active clock edge. All three updates use the old outputs simultaneously. Reading the circuit wires gives Q1(next)=Q2 XOR Q3, Q2(next)=Q1, and Q3(next)=Q2. In particular, do not feed the newly computed Q1 into Q2 during the same clock edge.

Evaluate the equations for every state:
S0: 000→000, hence S0→S0.
S1: 001→100, hence S1→S4.
S2: 010→101, hence S2→S5.
S3: 011→001, hence S3→S1.
S4: 100→010, hence S4→S2.
S5: 101→110, hence S5→S6.
S6: 110→111, hence S6→S7.
S7: 111→011, hence S7→S3.

To draw the diagram, put a self-loop on S0 and draw the separate seven-state directed cycle S1→S4→S2→S5→S6→S7→S3→S1. There is no external input, so each state has exactly one outgoing edge and there are no input labels to choose. The zero state is a fixed point because shifting zeros and XORing zeros still gives zeros. As a consistency check, the listed targets contain all eight states once; the transition function is invertible, since the old Q1 and Q2 are read from the new Q2 and Q3 and old Q3 is recovered by XORing new Q1 with new Q3.

# GATE 1996: Q90 (printed B Q24(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203937/GATE1996.pdf#page=10), physical page 10. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Only S0 is unreachable; the seven nonzero states form the cycle containing S4.

**Essential problem context (paraphrased):** A synchronous circuit has three D flip-flops with common clock. Q1 feeds D2, Q2 feeds D3, and Q2 XOR Q3 feeds D1 through the feedback gate. State Si denotes the binary value i of Q1Q2Q3, so S0=000,...,S7=111. Starting at S4, identify all unreachable states.

## Solution

The next-state equations are (Q1,Q2,Q3)→(Q2 XOR Q3,Q1,Q2). Begin with S4=100 and repeatedly apply them. The successive states are S4=100, S2=010, S5=101, S6=110, S7=111, S3=011, S1=001, and then S4=100 again.

Once a deterministic state repeats, its subsequent trajectory repeats too; there is no input capable of taking a different branch. Therefore the reachable set is exactly {S1,S2,S3,S4,S5,S6,S7}, including the initial state itself at time zero. The only member of the eight-state space not visited is S0=000. It is unreachable from S4, although it is a perfectly valid state and would remain at zero forever if chosen as an initial state.

One can verify the exclusion algebraically. If the next state were 000, then new Q2=old Q1=0 and new Q3=old Q2=0. New Q1=old Q2 XOR old Q3=0 then forces old Q3=0. Thus only 000 can transition to 000; no nonzero state can enter it. The enumerated seven-state cycle proves that no additional state is excluded. GFG labels this subpart separately as question 73, but it is part (b) of original question 24 and shares that question's circuit and five-mark group allocation.
