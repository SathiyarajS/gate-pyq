**Paraphrased problem context:** What is the smallest integer representable by an8-bit two’s-complement number? A−256, B−128, C−127, D0.

## Solution

An8-bit two’s-complement integer has range−2^7 through 2^7−1, hence minimum−128, B.

Teaching detail:
The leftmost bit has weight−128 and the remaining seven bits have positive weights64, 32, 16, 8, 4, 2, 1. To minimize the represented integer, set the negative-weight bit to 1 and all positive-weight bits to 0:10000000 represents−128. The opposite endpoint01111111 represents127. Unlike sign-magnitude, two’s complement has one more negative value than positive nonzero values, which explains why−127 is not the minimum.

**Paraphrased problem context:** A circuit has inputs D0, D1, D2, D3 and outputs X0, X1, V. For0000 it outputs don’t-care, don’t-care, 0; for1000 it outputs0, 0, 1; for x100 it outputs0, 1, 1; for xx10 it outputs1, 0, 1; for xxx1 it outputs1, 1, 1 (input order D0, D1, D2, D3). Identify A priority encoder; B decoder; C multiplexer; D demultiplexer.

## Solution

The table outputs the binary index of the highest asserted input, with D3 taking priority over D2, then D1 and D0. Its validity bit distinguishes no active input from input D0. Thus it is a priority encoder, A.

Teaching detail:
Read the table from highest priority downward. If D3=1, the other inputs are irrelevant and the code is 11. Otherwise D2=1 selects10; otherwise D1=1 selects01; otherwise D0=1 selects00. This is encoding the index of the highest asserted request. A decoder expands a binary code to selected outputs, the reverse direction. A multiplexer selects a data input using separate select lines, not this priority rule. The validity bit is needed because code00 otherwise cannot distinguish “D0 asserted” from “no input asserted.”

**Official answer:** D

**Derived answer:** D

**Source access:** Archived official IIT Bombay booklet A. Physical PDF page numbers are used; ORS code A is the matching key column. Booklets B/C/D permute the same questions, not separate sessions.

**Paraphrased problem context:** Which does not represent XNOR(x, y)? A xy+¬x¬y; B x XOR ¬y; C ¬x XOR y; D ¬x XOR ¬y.

## Solution

Complementing exactly one XOR input produces XNOR, while complementing both leaves XOR unchanged: x′⊕y′=x⊕y. Also xy+x′y′ is XNOR. Thus only D fails to represent XNOR.

Teaching detail:
XNOR is 1 exactly on equal inputs00 and 11. Complementing both XOR operands does not change whether they differ, so ¬x XOR ¬y has the same truth values as x XOR y:0, 1, 1, 0. It therefore disagrees with XNOR on every row. Complementing one input toggles equality versus inequality and produces XNOR. The sum xy+¬x¬y directly lists the two equal-input cases.
