**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Four-bit registers use two's complement. Which sum overflows? A 1011+1110; B 1100+1010; C 0011+0100; D 1001+1111.

## Solution

Four-bit two’s-complement integers range from −8 through 7. The sums in A, C, D are −7, 7,−8 and are representable. B computes −4+(−6)=−10, outside the range, so it overflows. Thus B.

Teaching detail:
Decode a bit pattern with leading 1 by subtracting 16 from its unsigned value. Thus A is −5−2=−7; B is −4−6=−10; C is 3+4=7; D is −7−1=−8. B wraps to 0110 (+6), revealing the sign reversal for a negative-plus-negative sum.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** A 16-bit control word contains mode M, an address for 1024-word memory S, and an address for 32-word register file R. Blocks P,Q select their addressed words; mode-controlled T selects one word to load display register X. Identify P,Q,T: A 10:1 mux,5:1 mux,2:1 mux; B 10:1024 decoder,5:32 decoder,2:1 encoder; C those two decoders and 2:1 mux; D 1:10 demux,1:5 demux,2:1 mux.

## Solution

Selecting one of 1024 memory words requires a 10-to-1024 decoder P. Selecting one of 32 registers requires a 5-to-32 decoder Q. Mode bit M selects between the two data words through a 2-to-1 multiplexer T. The fields use 1+10+5=16 bits, consistent with the code word. Thus C; wiring was visually checked.

Teaching detail:
A decoder expands a binary address into one selected word line; log2(1024)=10 and log2(32)=5 give its input widths. T routes one of two data-word inputs to one output and is therefore a multiplexer, not an encoder. The mode wire is one select bit, making the complete instruction width 1+10+5=16.
