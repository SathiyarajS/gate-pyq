**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Find the 16-bit two's-complement representation of decimal −28. Choices: A 1111 1111 0001 1100; B 0000 0000 1110 0100; C 1111 1111 1110 0100; D 1000 0000 1110 0100.

## Solution

Method: represent the positive magnitude at the specified width, complement every bit, and add one.

1. Positive 28 is 16 + 8 + 4, so its 16-bit binary representation is 0000 0000 0001 1100.
2. Complement all 16 bits: 1111 1111 1110 0011.
3. Add one: 1111 1111 1110 0100, which is hexadecimal FFE4.
4. Check by the modular interpretation: a negative integer −28 is encoded as 2^16 − 28 = 65508. FFE4 has unsigned value 65508 and signed value 65508 − 65536 = −28.

Result: C. Setting just the most significant bit would be sign-magnitude encoding, not two's complement; retaining the positive low byte after filling leading ones would also give the wrong number.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Let + mean Boolean OR, juxtaposition mean AND, prime mean NOT, and ⊕ mean XOR. Identify the invalid identity: A (x⊕y)⊕z = x⊕(y⊕z); B (x+y)⊕z = x⊕(y+z); C x⊕y = x+y when xy=0; D x⊕y = (xy+x′y′)′.

## Solution

Method: a universal identity is disproved by one assignment; valid alternatives can be checked from XOR's meaning.

1. For B, set x = 1, y = 1, z = 0. The left side is (1 OR 1) XOR 0 = 1 XOR 0 = 1. The right side is 1 XOR (1 OR 0) = 1 XOR 1 = 0. The two sides differ, so B is invalid.
2. A is XOR associativity. Both sides indicate whether an odd number of x, y, z are one, independent of grouping.
3. For C, xy = 0 excludes the only assignment, x = y = 1, on which OR and XOR differ. Therefore the conditional identity is valid.
4. In D, xy + x′y′ is true exactly when x and y agree: both one or both zero. Complementing that equality condition gives XOR, which is true exactly when they differ.

Result: B. XOR is associative with itself, but mixing it with OR does not preserve that associativity pattern.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** X and Y use n-bit sign-magnitude representations, and Z = X − Y must also use sign magnitude. Find the minimum width that avoids overflow for all operands. Choices: A n; B n−1; C n+1; D n+2 bits.

## Solution

Method: find the largest possible magnitude of a difference, then reserve a separate sign bit.

1. In an n-bit sign-magnitude number, one bit is the sign and n − 1 bits encode the magnitude. Thus each operand has absolute value at most M = 2^(n−1) − 1.
2. The largest positive difference occurs at X = M and Y = −M, giving Z = 2M = 2^n − 2. Reversing these operands produces the negative extreme of the same magnitude.
3. For n ≥ 2, n − 1 magnitude bits cannot hold 2^n − 2, but n magnitude bits can, since their maximum is 2^n − 1. Therefore n magnitude bits are necessary and sufficient.
4. Add the sign bit: the result needs n + 1 total bits. For example, with n = 4, inputs range from −7 to +7; their difference can be +14, requiring four magnitude bits plus a sign.

Result: C, n+1 bits. The degenerate n=1 format represents only signed zero and is outside the usual nontrivial-width interpretation.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** The on-sets of four-variable functions are f1={0,2,5,8,14}, f2={2,3,6,8,14,15}, f3={2,7,11,14}. A circuit ANDs f1 and f2, then XORs that output with f3. Find the output minterms: A {7,8,11}; B {2,7,8,11,14}; C {2,14}; D {0,2,3,5,6,7,8,11,14,15}.

## Solution

1. An on-set lists the input minterms on which a Boolean function equals 1. Working with these sets avoids expanding every minterm into a product of four literals.
2. The AND output is 1 only where both f1 and f2 are 1. Their intersection is H={2,8,14}; all other minterms make the AND output zero.
3. XOR is 1 precisely when its inputs differ. Therefore the final on-set is the symmetric difference of H and the on-set of f3, not their ordinary union.
4. Minterms 2 and 14 occur in both sets, so XOR makes them zero. Minterm 8 occurs only in H, while 7 and 11 occur only in f3, so these three survive.
5. The result is f=Σ(7,8,11), option A. Option B would correspond to OR at the second stage, illustrating why the XOR symbol matters.

# GATE 2019 CS: Q60 (printed CS Q50)

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 3 to 3

**Derived answer:** 3

**Paraphrased problem context:** For variable order a,b,c,d, implement f=Σ(0,2,5,7,8,10,13,15) using the fewest two-input NOR gates. All variables and their complements are already available. Find that gate count.

## Solution

1. Write minterm indices in binary abcd. The four indices 0,2,8,10 all have b=d=0; 5,7,13,15 all have b=d=1. In each group a and c take every combination. Hence f depends only on b,d and equals b XNOR d.
2. Build the two mismatch terms using NOR: u=NOR(b,¬d)=¬b·d and v=NOR(¬b,d)=b·¬d. Each is one gate because complemented inputs are available free.
3. Feed these to a third NOR: NOR(u,v)=¬(¬b·d+b·¬d)=b XNOR d=f. This proves three gates are sufficient.
4. For minimality, consider any circuit with at most two gates. If a raw input literal feeds the final NOR, setting that literal true forces the output to zero regardless of all other variables. The target XNOR has no such literal: for either setting of b or d it can still be 1, and it does not depend on a or c.
5. Without a raw literal at the final gate, both final inputs must be the output of the only earlier NOR. This merely inverts that NOR and gives the OR of its two input literals. No OR of literals realizes XNOR, whose 1-values are the two separated equal-bit cases.
6. Thus one or two gates cannot suffice, while the explicit circuit uses three. The minimum is 3. Complement availability is essential to this count; generating inversions separately would change the implementation cost.
