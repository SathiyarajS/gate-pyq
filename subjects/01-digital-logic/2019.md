# GATE 2019 CS: Q18 (printed CS Q8)

**Question:** [Official archived paper page 5](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=5); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

For n≥2, an n-bit sign-magnitude operand has magnitude at most2^(n−1)−1. Subtracting opposite signs can give magnitude2^n−2, requiring n magnitude bits and a sign bit, hence n+1 bits, C. The degenerate n=1 format represents only signed zero and is outside the usual nontrivial-width interpretation.

# GATE 2019 CS: Q60 (printed CS Q50)

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 3 to 3

**Derived answer:** 3

## Solution

With standard variable order a, b, c, d, the listed minterms have b=d, independent of a, c: f is b XNOR d. Let u=NOR(b, NOT d)=(NOT b)d and v=NOR(NOT b, d)=b(NOT d). Then NOR(u, v) is the desired XNOR, using3 gates and the available complemented inputs. Two gates cannot suffice: if the final NOR has a raw literal input, fixing that literal true forces output0, whereas XNOR has no such controlling input value. If both final inputs are the first gate output, the result is merely an OR of two literals. Neither can realize XNOR. Thus3 is minimal.
