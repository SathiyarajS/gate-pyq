**Paraphrased problem context:** What is the maximum number of different Boolean functions on n Boolean variables?
Options:
(A) n²
(B) 2^n
(C) 2^(2^n)
(D) 2^(n²)

## Solution

1. Approach. First count truth-table rows, not functions. A truth table has 2^n rows; choosing an output bit independently for every row determines one function.

2. Derivation and interpretation. There are 2^n input assignments. Each can independently be assigned output 0 or 1, giving 2^(2^n) distinct Boolean functions, C. This counts functions on n variables, including those independent of some variables.

**Paraphrased problem context:** How many 3-to-8 line decoders, each with an enable input, are needed to build a 6-to-64 line decoder without other logic gates?
Options:
(A) 7
(B) 8
(C) 9
(D) 10

## Solution

1. Approach. Split the six inputs into two groups of three. One decoder selects a bank, and each selected bank decodes the remaining three inputs.

2. Derivation and interpretation. One 3-to 8 decoder decodes the upper three bits into eight enable signals. Each enables one of eight further 3-to 8 decoders for the lower three bits. Total 1+8=9, C, assuming compatible enable/output polarities. Eight final decoders are required to provide 64 outputs, and another is needed to select their banks without extra gates.

**Paraphrased problem context:** Let f(w,x,y,z)=Σm(0,4,5,7,8,9,13,15), with minterm bits in w,x,y,z order. Which listed expressions are NOT equivalent to f? Prime denotes complement. The source expressions are:
P = x′y′z′ + w′xy′ + wy′z + xz
Q = w′y′z′ + wx′y′ + xz
R = w′y′z′ + wx′y′ + xyz + xy′z
S = x′y′z′ + wx′y′ + w′y
Options:
(A) P only
(B) Q and S
(C) R and S
(D) S only

## Solution

1. Approach. Read each complement mark carefully before testing equivalence. The source has Q=w′y′z′+wx′y′+xz. Expand product terms into minterms, or enumerate all sixteen inputs; a single extra or missing minterm disproves equivalence.

2. Derivation and interpretation. P, Q and R each produce minterms {0,4,5,7,8,9,13,15}, exactly the target set. For Q, w′y′z′ covers {0,4}, wx′y′ covers {8,9}, and xz covers {5,7,13,15}. For R, xyz+xy′z=xz, so R equals Q. S instead produces {0,2,3,6,7,8,9}: for instance input 0010 makes w′y true although minterm 2 is not in f. Thus only S is not equivalent, option D. The previous B answer resulted from dropping the prime on z in Q; the scanned original visibly contains that prime. This is a source-based independent correction, not an official-key match.

**Paraphrased problem context:** Define X*Y=XY+X′Y′ for Boolean variables, and let Z=X*Y. Consider P: X=Y*Z; Q: Y=X*Z; R: X*Y*Z=1. Which statements hold?
Options:
(A) Only P and Q
(B) Only Q and R
(C) Only P and R
(D) All P,Q,R

## Solution

1. Approach. The connective is equivalence/XNOR. Express it as 1⊕X⊕Y, then substitute the definition of Z; each variable appearing twice cancels under XOR.

2. Derivation and interpretation. The operation is XNOR, representable over modulo 2 arithmetic as X*Y=1⊕X⊕Y. With Z=1⊕X⊕Y, we get Y*Z=X and X*Z=Y. Moreover (X*Y)*Z=Z*Z=1; XNOR is associative here. Therefore all P,Q,R hold, D.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Only one multiplexer and one inverter may implement an arbitrary Boolean function of n variables. What is the minimum universal multiplexer size?
Options:
(A) 2^n-to-1
(B) 2^(n+1)-to-1
(C) 2^(n−1)-to-1
(D) 2^(n−2)-to-1

## Solution

1. Approach. Shannon expansion fixes selector variables and leaves a cofactor at each data input. If one variable remains, its only four Boolean functions are 0,1,x,x′, all available with constants, a wire and one inverter.

2. Derivation and interpretation. Use n−1 variables as selector bits of a 2^(n−1)-to 1 multiplexer. For each selector assignment the remaining one-variable function is 0,1,x or x′, so a single shared inverter suffices. A smaller selector set leaves at least two variables; some cofactors, such as two-variable parity, cannot be supplied by a constant, a wire or one inversion. Thus the universal size under direct-variable selector wiring is 2^(n−1):1, C.

**Paraphrased problem context:** For a 4-bit carry-lookahead adder, Pi=Ai⊕Bi, Gi=AiBi, Si=Pi⊕Ci and C_(i+1)=Gi+PiCi, where C0 is the input carry. All Pi and Gi are already available. With two-level AND–OR logic and unbounded gate fan-in, how many AND and OR gates are required for the carry generator used with outputs S3,S2,S1,S0,C4?
Options:
(A) 6 AND,3 OR
(B) 10 AND,4 OR
(C) 6 AND,4 OR
(D) 10 AND,5 OR

## Solution

1. Approach. Expand every carry directly in terms of P,G,C0, avoiding a ripple chain. C1 has one product needing AND; C2 has two; C3 three; C4 four. The standalone Gi terms need no AND gates.

2. Derivation and interpretation. Expand C1=G0+P0C0; C2=G1+P1G0+P1P0C0; similarly C3 and C4 have 3 and 4 nontrivial product terms. With unbounded fan-in and all P,G supplied, the four carry outputs require 1+2+3+4=10 AND gates and one OR gate each, totaling 4 OR gates. Thus B. XOR sum generation is outside this AND/OR carry-generator count.

**Paraphrased problem context:** A 4-bit up-counter has outputs A4,A3,A2,A1 from most to least significant. Control table: Clear=1 asynchronously clears to 0; Clear=0,Load=0,Count=0 holds; Clear=0 on a rising clock with Load=1 loads the parallel input; Clear=0 on a rising clock with Load=0,Count=1 counts up. The circuit fixes Count=1, Load=0 and parallel input=0011, and connects Clear=A3 AND A1. Starting at 0 and neglecting all gate/counter delays, which stable count cycle occurs?
Options:
(A) 0,3,4
(B) 0,3,4,5
(C) 0,1,2,3,4
(D) 0,1,2,3,4,5

## Solution

1. Approach. First determine whether the parallel input is enabled. It is not, since Load=0. Then find the first binary count making the asynchronous clear condition true; that state immediately disappears.

2. Derivation and interpretation. The clear input is the AND of outputs A 3 and A 1. With Load=0 the displayed 0011 input is ignored and the device counts upward from 0. The first count having A 3=A 1=1 is 0101=5, which immediately asserts asynchronous clear. With negligible delays this transient 5 is not a stable count state; the stable cycle is 0,1,2,3,4 and back to 0, C.
