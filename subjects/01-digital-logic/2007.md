# GATE 2007: Q34 (printed CS Q34)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 7. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Use n−1 variables as selector bits of a2^(n−1)-to1 multiplexer. For each selector assignment the remaining one-variable function is0,1,x or x′, so a single shared inverter suffices. A smaller selector set leaves at least two variables; some cofactors, such as two-variable parity, cannot be supplied by a constant, a wire or one inversion. Thus the universal size under direct-variable selector wiring is2^(n−1):1, C.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

The clear input is the AND of outputs A3 and A1. With Load=0 the displayed0011 input is ignored and the device counts upward from0. The first count having A3=A1=1 is0101=5, which immediately asserts asynchronous clear. With negligible delays this transient5 is not a stable count state; the stable cycle is0,1,2,3,4 and back to0, C.
