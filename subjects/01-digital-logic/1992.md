**Independently derived answer:** ¬B¬C+¬A¬C+ABC

**Essential problem context (paraphrased):** Rows are B=0, 1 and columns C=0, 1. The four entries are 1, 0, ¬A, A respectively. Give a sum of products.

## Solution

The B=0, C=0 cell is one for either A, giving ¬B¬C. At B=1, C=0 the output is ¬A, which joins the A=0 portion of the first cell to give ¬A¬C. The remaining one occurs at A=B=C=1 and is isolated, giving ABC. Thus the SOP is ¬B¬C+¬A¬C+ABC. Alternatively the direct unsimplified expansion ¬B¬C+¬AB¬C+ABC is equivalent. The letter entries in the map are functions of the third variable, not literal binary cells.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D: NAND

**Essential problem context (paraphrased):** Which operation is commutative but not associative: AND, OR, XOR, NAND?

## Solution

NAND(a, b)=¬(ab), unchanged when a and b are exchanged, so it is commutative. To refute associativity choose a=0, b=1, c=1. Then NAND(NAND(0, 1), 1)=NAND(1, 1)=0, whereas NAND(0, NAND(1, 1))=NAND(0, 0)=1. AND, OR and XOR are associative as well as commutative. A single counterexample suffices to disprove the NAND associativity identity for all triples.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B, C for combinational functions with constants available

**Essential problem context (paraphrased):** Which can realize arbitrary digital Boolean functions: XOR gates, multiplexers, half adders, OR gates? State constant-input assumptions.

## Solution

A multiplexer implements Shannon expansion f=¬s f0+s f1, so recursively selecting cofactors realizes any Boolean function with constant leaves. A half adder supplies XOR and AND; tying one XOR input to1 gives NOT, and AND plus NOT is functionally complete. XOR-only networks remain affine, while OR-only networks cannot implement negation. Thus B, C follow when constants, especially1, are available. Without a supplied1, mux and half-adder networks are zero-preserving and cannot realize every function. Also sequential circuits require state/feedback assumptions beyond combinational functional completeness; the source’s “all digital circuits” is broader than the standard intended claim.

# GATE 1992: Q39 (printed B Q4(a))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Overflow iff equal-sign operands produce the opposite-sign result; V = carry into sign bit XOR carry out.

**Essential problem context (paraphrased):** Explain when addition in fixed-width two’s-complement arithmetic overflows, and why carry out of the most significant bit is not sufficient.

## Solution

For a w-bit two’s-complement word the representable interval is −2^(w−1) through 2^(w−1)−1. Hardware retains the low w bits of the mathematical sum. Overflow means the mathematical signed sum lies outside this interval, not merely that an unsigned carry was discarded.

Let a,b be the operand sign bits and s the retained result sign bit. The overflow flag is V=(¬a∧¬b∧s)∨(a∧b∧¬s). Two nonnegative numbers overflow only by producing a sign bit of 1; two negative numbers overflow only by producing a sign bit of 0. Opposite-sign operands cannot overflow: their sum lies between the operands and hence within the representable interval.

Equivalently, if c_in is the carry into the sign-bit adder and c_out its outgoing carry, V=c_in XOR c_out. This follows by considering the sign-bit full-adder cases: for equal operand signs an incorrect result sign occurs precisely when these carries differ; for unequal signs they agree.

For four bits, 0111+0001=1000 represents 7+1 as −8: overflow occurs despite no outgoing carry. Conversely 1111+0001=0000 with carry 1 represents −1+1=0 correctly: carry occurs without overflow. Finally 1000+1111=0111 with carry 1 is −8+(−1), which really does overflow. These examples separate the unsigned carry flag from the signed overflow flag.

**Essential problem context (paraphrased):** Design a three-input priority encoder with A>B>C using 4:1 multiplexers. Output X1X0 identifies the highest-priority active input, and is 00 if none is active.

## Solution

The statement does not assign binary labels to A, B, C, so explicitly choose A→11, B→10 and C→01, reserving 00 for no request. Any distinct nonzero assignment is valid if stated and implemented consistently.

The compressed truth table is:
A B C | X1 X0
1 – – | 1  1
0 1 – | 1  0
0 0 1 | 0  1
0 0 0 | 0  0
A higher-priority 1 hides all lower-priority inputs. The resulting functions are X1=A∨B and X0=A∨(¬B∧C).

For both 4:1 multiplexers use select S1=A, S0=B, with D0,D1,D2,D3 selected by 00,01,10,11 respectively. Evaluate each function at these four selector values:
                    D0 D1 D2 D3
MUX for output X1:   0  1  1  1
MUX for output X0:   C  0  1  1

Wiring diagram:
A,B ──selects──>[4:1 MUX, data 0,1,1,1]──>X1
A,B ──selects──>[4:1 MUX, data C,0,1,1]──>X0
Tie 0 and 1 inputs to valid logic rails and enable both multiplexers. No inverter is needed in this realization. For example A=0,B=1,C=1 selects D1 and gives 10, correctly ignoring C. A=1 selects either D2 or D3 and always gives 11.

# GATE 1992: Q41 (printed B Q4(c))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005204205/GATE1992.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total None mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Use cyclic Gray sequence 000,001,011,010,110,111,101,100; D2=Q2Q0+Q1¬Q0, D1=Q1¬Q0+¬Q2Q0, D0=Q2Q1+¬Q2¬Q1.

**Essential problem context (paraphrased):** Design a 3-bit counter with D flip-flops such that at most one flip-flop changes between consecutive states.

## Solution

Use all eight states in the reflected Gray-code order, including a one-bit wraparound:
000 → 001 → 011 → 010 → 110 → 111 → 101 → 100 → 000.
A binary counter would fail at transitions such as 011→100, where three bits change. In this Gray cycle every adjacent pair, including 100→000, differs in exactly one bit.

For a D flip-flop, next Q equals current D at the active clock edge. Thus the state table directly gives the needed excitation table:
Q2Q1Q0 | D2D1D0
000 | 001
001 | 011
010 | 110
011 | 010
100 | 000
101 | 100
110 | 111
111 | 101

Grouping the 1s of each next-state column on a three-variable Karnaugh map gives:
D2=(Q2∧Q0)∨(Q1∧¬Q0)
D1=(Q1∧¬Q0)∨(¬Q2∧Q0)
D0=(Q2∧Q1)∨(¬Q2∧¬Q1).

Circuit specification:
Q2,Q1,Q0 ──> above AND/OR/NOT combinational network ──> D2,D1,D0
D2 ──>[DFF2]──>Q2; D1 ──>[DFF1]──>Q1; D0 ──>[DFF0]──>Q0
One common clock drives all three DFFs; clear inputs initialize Q2Q1Q0=000. Feedback connects each Q to the combinational network. All states belong to the cycle, so there are no unused lockout states. The guarantee concerns stable states at clock edges, assuming setup/hold and propagation constraints; glitches within combinational logic are not extra counter states.
