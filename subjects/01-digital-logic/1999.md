**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Essential problem context (paraphrased):** Which is not NOT x: x NAND x, x NOR x, x NAND 1, or x NOR 1?

## Solution

Compute each expression directly. x NAND x=¬(x·x)=¬x; x NOR x=¬(x+x)=¬x; x NAND 1=¬x. But x NOR 1=¬(x+1)=0 for both possible x values. At x=0 that differs from NOT x=1, so D is the non-inverter. Tying the inputs together and tying an input to a constant are different operations.

**Essential problem context (paraphrased):** The circuit has u=NAND(A,Y),v=NAND(B,u),Y=AND(C,v). Given steady Y=1, select ABC from 001,011,101,111.

## Solution

Substitute the required Y=1 into the first gate: u=¬A. The second gives v=¬(B·¬A)=¬B+A. For the output AND to be one, C=1 and v=1 are required. Thus either A=1 or B=0, with C=1. The allowed listed triples are 001,101,111, namely A,C,D; 011 gives v=0 and fails. This is a fixed-point calculation, not a claim about which state an arbitrary initial circuit will reach. # GATE 1999: Q34 (printed A Q2.9)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=4), physical page 4. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B,C if constants 0 and 1 are available

**Essential problem context (paraphrased):** Choose universal component sets: A XOR and NOT; B 2:1 multiplexers; C AND and XOR; D gates AB+C.

## Solution

A produces only affine Boolean functions, so it cannot express AND and is incomplete. For B, a mux with data inputs 1,0 implements NOT of its select; a mux with data 0,y and select x implements xy. NOT and AND are universal. For C, x XOR 1=¬x, again providing NOT plus AND. D is monotone, so compositions cannot implement inversion. Hence B,C under the usual available-constant convention. Without constant 1, B and C preserve zero and cannot produce NOT; the source does not explicitly state the constant-input convention, so this dependence is retained.

# GATE 1999: Q41 (printed A Q2.16)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Essential problem context (paraphrased):** Add two 16-bit numbers without an external carry-in. Choose the half/full-adder counts; B gives one half-adder and 15 full-adders.

## Solution

The least-significant position adds only two operand bits, so a half-adder produces its sum and carry. Each of the remaining fifteen positions must add two operand bits plus the carry from the preceding position, requiring a full-adder. The total is therefore one half-adder and fifteen full-adders, B. Using half-adders alone would not handle three inputs at higher positions without extra combination logic. If an external carry-in were required at the first position, sixteen full-adders would be the natural implementation instead.

# GATE 1999: Q42 (printed A Q2.17)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203805/GATE1999.pdf#page=5), physical page 5. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A,B

**Essential problem context (paraphrased):** Which schemes have two zeros: sign-magnitude,ones complement,twos complement,none?

## Solution

In sign-magnitude, magnitude bits all zero represent zero with either sign bit, producing +0 and −0. In ones complement, complementing the all-zero positive representation yields the all-one negative-zero pattern. In twos complement, negation complements then adds one, returning zero to the all-zero pattern after overflow is discarded; the all-one pattern represents −1 instead. Thus exactly A and B have two zero representations.
