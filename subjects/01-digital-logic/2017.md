**Paraphrased problem context:** A 16-bit unsigned integer is BCA9 in hexadecimal. Give its octal representation. A:571244. B:736251. C:571247. D:136251.

## Solution

1. Convert each hexadecimal digit into four binary bits: B=1011, C=1100, A=1010, 9=1001. The number is therefore 1011110010101001₂.

2. Octal groups binary bits in threes, starting at the least-significant end. Add two leading zeros only for grouping: 001 011 110 010 101 001.

3. These groups are 1,3,6,2,5,1, yielding 136251₈, option D. A decimal check is BCA9₁₆=48297, and 1·8⁵+3·8⁴+6·8³+2·8²+5·8+1=48297. Leading padding does not change the value.

**Official answer:** 8.0 to 8.0

**Derived answer:** 8

**Source access:** Open archive member CS/CS2-2017.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

**Paraphrased problem context:** The quadratic x²−13x+36=0 has its coefficients written in base b. Its roots in that same base are the single digits 5 and 6. Find b.

## Solution

1. Because 5 and 6 are single digits, their numerical values are 5 and 6, while the coefficient 13_b means b+3 and 36_b means 3b+6. The base must exceed 6 to admit all displayed digits.

2. For a monic quadratic, the sum of the roots equals the coefficient subtracted from x. Thus 5+6=b+3, which gives b=8.

3. Check the product condition as well: 5·6=30, and 36_8=3·8+6=30. Both coefficient relations agree, and digits 0 through 6 are legal in base 8. Hence the answer is 8, not a decimal interpretation of 13 and 36.

**Paraphrased problem context:** For Boolean variables w,x,y,z (juxtaposition=AND, +=OR, ¬=NOT), which equality is incorrect? A:wx+w(x+y)+x(x+y)=x+wy. B:¬[w¬x(y+¬z)]+¬w x=¬w+x+¬y z. C:[w¬x(y+x¬z)+¬w¬x]y=x¬y. D:(w+y)(wxy+wyz)=wxy+wyz.

## Solution

1. Check C by expanding its left side: w¬xyy+w¬xx¬zy+¬w¬xy. Since yy=y and ¬xx=0, this reduces to w¬xy+¬w¬xy=¬xy(w+¬w)=¬xy. The stated right side is x¬y, a different function.

2. A concrete counterexample is x=0,y=1, with any w,z. C then equates 1 with 0, so it is incorrect.

3. Verify the alternatives: A expands to wx+wx+wy+x+xy=x+wy by absorption. In B, De Morgan gives ¬w+x+¬y z for the complemented product; the extra ¬w x is absorbed. In D, every product inside the second factor already implies w+y, so multiplying by w+y changes nothing. C is uniquely false.

**Paraphrased problem context:** Given f(w,x,y,z)=Σm(0,1,2,3,7,8,10)+Σd(5,6,11,15), where d marks don't-cares, choose a minimum product-of-sums expression. A:(¬w+¬z)(¬x+z). B:(¬w+z)(x+z). C:(w+z)(¬x+z). D:(w+¬z)(¬x+z).

## Solution

1. For a POS minimization, group zeros rather than ones. Of the sixteen minterms, the required zeros are 4,9,12,13,14; entries 5,6,11,15 may be assigned as convenient.

2. The group {9,11,13,15} has w=1,z=1 throughout, so it contributes wz to the complement f′. The group {4,6,12,14} has x=1,z=0, contributing x¬z. Together these cover every required zero without covering any required one.

3. Thus f′=wz+x¬z. Complementing by De Morgan yields f=(¬w+¬z)(¬x+z), A. Both groups are needed: zero 9 is not covered by x¬z and zero 4 is not covered by wz. No single-literal zero group avoids all required ones, so the two two-literal clauses form a minimum POS.

**Paraphrased problem context:** A two-bit saturating up-counter has next states 00→01,01→10,10→11,11→11. It uses synchronous T flip-flops for bits Q1,Q0. Choose (T1,T0). A:(Q1Q0,¬Q1¬Q0). B:(¬Q1Q0,¬Q1+¬Q0). C:(Q1+Q0,¬Q1+¬Q0). D:(¬Q1Q0,Q1+Q0).

## Solution

1. A T flip-flop holds its state when T=0 and toggles when T=1. Thus its required input is T=Q XOR Qnext; compute it separately for each bit.

2. For current states 00,01,10,11, the high-bit toggle requirements are 0,1,0,0. Only state 01 toggles Q1, giving T1=¬Q1·Q0. The low-bit requirements are 1,1,1,0, since Q0 changes on every transition except the saturated 11→11.

3. Therefore T0=¬(Q1Q0)=¬Q1+¬Q0. This pair is B. In particular the final state must hold rather than wrap to 00, so both T inputs must be zero at 11.

**Paraphrased problem context:** An unsigned n-bit fixed-point number has f fractional bits and i=n−f integer bits. Find its range. A 2^(−f) to 2^i; B 2^(−f) to 2^i−2^(−f); C 0 to 2^i; D 0 to 2^i−2^(−f).

## Solution

1. Represent the stored bits first as an unsigned integer N. Its smallest code is 0 and largest is 2^n−1.

2. The fixed binary point gives value X=N/2^f, so the step size is 2^(−f). The upper endpoint is (2^n−1)2^(−f)=2^(n−f)−2^(−f).

3. Substitute i=n−f. The inclusive representable range is 0 through 2^i−2^(−f), D. The value 2^i itself would need an extra integer bit.

**Question:** [Official archived paper page 5](https://web.archive.org/web/20170712112248id_/http://www.gate.iitg.ac.in:80/2017questions/CS1.pdf#page=5); consult original wording, diagrams and choices.

**Source access:** Archived July2017 original official paper and key. Page numbers refer to the paper PDF; key is a separate two-page PDF.

**Paraphrased problem context:** Two 8-bit two’s-complement numbers A7...A0 and B7...B0 are added, producing S7...S0 and carry bits C7...C0. A0 and B0 are least significant. Which detects overflow? A C7=1; B all carries 1; C A7 B7 ¬S7 + ¬A7 ¬B7 S7=1; D A0 B0 ¬S0 + ¬A0 ¬B0 S0=1. Products mean AND and + means OR.

## Solution

1. In two’s complement the high bit is the sign. Opposite-sign addition cannot exceed both representable bounds, so overflow requires equal operand signs.

2. If both signs are 0, overflow means the result sign is 1: ¬A7∧¬B7∧S7. If both signs are 1, overflow means the result sign is 0: A7∧B7∧¬S7.

3. OR the two mutually exclusive cases to obtain C. For example, 127+1 produces negative 8-bit result without needing an unsigned carry-out; sign overflow and unsigned carry are different tests.

**Paraphrased problem context:** A four-variable K-map has columns ba=00,01,11,10 and rows dc=00,01,11,10, both in Gray order. Row entries respectively are [0,X,X,0], [1,0,0,X], [1,0,0,1], [0,X,X,0], where X means don’t care. All inputs a,b,c,d and their complements are available. Using only 2-input NOR gates, find the minimum number of gates.

## Solution

1. Use the stated column order ba, not ab. The three required ones are at (dc,ba)=(01,00),(11,00),(11,10).

2. Choose the don’t-care at (01,10) to be 1. With wraparound column adjacency, these four cells form a group: a stays 0 and c stays 1, while b and d vary. Thus f=¬a∧c.

3. De Morgan gives f=¬(a∨¬c). Since ¬c is supplied, feed a and ¬c to one NOR gate. A direct wire to any supplied literal fails some required cell, so zero gates cannot suffice. Minimum 1.

**Question:** [Official archived paper page 15](https://web.archive.org/web/20170712112248id_/http://www.gate.iitg.ac.in:80/2017questions/CS1.pdf#page=15); consult original wording, diagrams and choices.

**Source access:** Archived July2017 original official paper and key. Page numbers refer to the paper PDF; key is a separate two-page PDF.

**Paraphrased problem context:** Two flip-flops share a clock. T flip-flop output Q1 feeds the D input; D flip-flop output Q0 feeds the T input. Initial Q1Q0=11 before cycle 1. Select states after cycles 3 and 4: A (11,00); B (11,01); C (00,11); D (01,01).

## Solution

1. A T flip-flop toggles when T=1 and holds when T=0, so Q1(next)=Q1 XOR Q0. A D flip-flop copies its input, so Q0(next)=Q1.

2. Both right-hand sides use the old state at the same clock edge. Starting 11, edge 1 gives 01, edge 2 gives 10, and edge 3 gives 11.

3. Edge 4 repeats the first transition and gives 01. Therefore the requested pair is (11,01), B. Updating one flip-flop before computing the other would incorrectly mix old and new states.
