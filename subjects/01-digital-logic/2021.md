**Paraphrased problem context:** A number is 210 in base 3. What is its hexadecimal representation? A 15; B 21; C D2; D 528.

## Solution

The ternary numeral210 represents2·3²+1·3=21 decimal. Since21=1·16+5, its hexadecimal representation is 15, A.

The positional expansion is 2×9+1×3+0×1=21. Converting that decimal result to base 16 gives quotient 1 and remainder 5. Conversely hexadecimal 15 evaluates to 16+5=21, providing a reverse check. The visible digits 210 are not a decimal number to be converted directly.

# GATE 2021 CS1: Q38 (printed CS Q28)

**Question:** [Official archived paper page 25](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=25); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** A synchronous three-bit T-flip-flop counter has outputs P,Q,R and common clock. The circuit connects R to T_P, complemented P to T_Q, and complemented Q to T_R. Starting at PQR=000, what are its next three states? A 011,101,000; B 001,010,111; C 011,101,111; D 001,010,000.

## Solution

The inspected wiring gives T_P=R, T_Q=¬P, T_R=¬Q, with a shared clock. Since a T flip-flop updates by Q_next=Q XOR T, the simultaneous transition equations are P_next=P XOR R, Q_next=Q XOR ¬P, R_next=R XOR ¬Q. From000 they give011, then101, then000. Thus A. Every right-hand side uses the old state.

The transition trace is: old 000 gives T=(0,1,1), new 011; old 011 gives T=(1,1,0), new 101; old 101 gives T=(1,0,1), new 000. A T input of 0 holds its flip-flop and 1 toggles it. Since all receive the same clock, updating P first and then using the new P to compute Q would incorrectly simulate a sequential program instead of a synchronous circuit.

# GATE 2021 CS1: Q39 (printed CS Q29)

**Paraphrased problem context:** A 12-bit Hamming codeword is d8 d7 d6 d5 c8 d4 d3 d2 c4 d1 c2 c1, listed from left to right. Data d8...d1 are 1,1,0,x,0,1,0,1; check bits c8,c4,c2,c1 are y,0,1,0. Find x,y. A 0,0; B 0,1; C 1,0; D 1,1.

## Solution

Number codeword positions from the right. The c2 parity group at positions2, 3, 6, 7, 10, 11 already has four ones, establishing even parity. The c1 group at 1, 3, 5, 7, 9, 11 has 2+x ones, so x=0. The c8 group at 8, 9, 10, 11, 12 then has y+2 ones, so y=0. Thus A. This uses the parity convention inferred from the supplied known check group, not an unprovided arbitrary choice.

The positions from right to left are 1:c1=0,2:c2=1,3:d1=1,4:c4=0,5:d2=0,6:d3=1,7:d4=0,8:c8=y,9:d5=x,10:d6=0,11:d7=1,12:d8=1. Each parity check includes positions whose binary index has its corresponding bit set. After x=y=0, c4's group {4,5,6,7,12} also has two ones, verifying consistency with the parity convention inferred from c2.

# GATE 2021 CS1: Q52 (printed CS Q42)

**Question:** [Official archived paper page 35](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=35); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** B; C; D

**Derived answer:** B; C; D

**Paraphrased problem context:** Let F=(X+Y+Z)(¬X+Y)(¬Y+Z), where + is OR and adjacency AND. Select expressions equal to ¬F: A (¬X+¬Y+¬Z)(X+¬Y)(Y+¬Z); B X¬Y+¬Z; C (X+¬Z)(¬Y+¬Z); D X¬Y+Y¬Z+¬X¬Y¬Z.

## Solution

The visually verified expression is F=(X+Y+Z)(NOT X+Y)(NOT Y+Z). If Z=0, the product is (X+Y)(NOT X+Y)(NOT Y)=Y(NOT Y)=0. If Z=1, it is NOT X+Y. Thus F=Z(NOT X+Y) and its complement is NOT Z+X(NOT Y), option B. By (a+b)(c+b)=ac+b, C is the same expression. Direct De Morgan expansion gives X(NOT Y)+Y(NOT Z)+(NOT X)(NOT Y)(NOT Z), exactly D. Option A is false, for example at X=0, Y=1, Z=0: it evaluates to 0 while the complement of F is 1.

Algebraically, (X+Y)(¬X+Y)=Y, so setting Z=0 makes F=Y¬Y=0. Setting Z=1 leaves only ¬X+Y. Hence ¬F=¬Z+X¬Y. Expanding C gives X¬Y+X¬Z+¬Y¬Z+¬Z, which absorbs to B. De Morgan on the original three factors gives D directly. Checking A at (X,Y,Z)=(0,1,0) yields a zero second factor (X+¬Y), whereas F=0 and its complement must be 1; this single assignment rules A out.

**Paraphrased problem context:** Implement f(x,y,z)=Σm(0,1,3,4,5,6), with x the most significant minterm bit, using a 4:1 mux with selectors S1=y,S0=z. Candidate input tuples (I0,I1,I2,I3): A (1,1,x,¬x); B (x,1,¬x,1); C (1,1,¬x,x); D (¬x,1,x,1).

## Solution

With selectors y, z, the paired minterms for yz=00 and 01 both produce1 for either x. For yz=10 only x=1 is included, so input2 is x. For yz=11 only x=0 is included, so input3 is ¬x. Therefore the four mux inputs are1, 1, x,¬x, exactly A. Minterms and selector wiring were visually checked.

List truth values in selector groups: yz=00 selects minterms 0,4; yz=01 selects 1,5; yz=10 selects 2,6; yz=11 selects 3,7. Their outputs versus x are (1,1),(1,1),(0,1),(1,0). This is Shannon expansion with two selection variables. A gate equivalent is ¬y∨(x∧¬z)∨(¬x∧z), with redundant coverage allowed.

**Official answer:** 3 to 3

**Derived answer:** 3

**Paraphrased problem context:** Decimal digits x,y satisfy (0.1101)₂=(0.8xy5)₁₀. Find x+y.

## Solution

Binary0.1101 equals1/2+1/4+1/16=13/16=0.8125. Thus x=1, y=2 and x+y=3.

Weights to the right of the binary point are 2^−1,2^−2,2^−3,2^−4. Only the third bit is zero. Matching 0.8125 to 0.8xy5 identifies the digits individually before adding. The answer is an integer sum of digits, not the binary fraction's numerator.

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Two-state Mealy circuit replaces the first 1 of each maximal run of 1s by 0. Input 00100011000011100 produces 00000001000001100. Current state s starts at 0; current bit b; next state t; output y. A t=s+b,y=sb; B t=b,y=sb; C t=b,y=s¬b; D t=s+b,y=s¬b. Here + means OR.

## Solution

Use state s to remember the previous input bit, initialized0. The next state is therefore t=b. Output1 is permitted only when both the previous and current bits are1; the first 1 after 0 is suppressed. Thus y=s·b, giving B. The example and option overbars were visually checked.

State/input table (s,b)→(t,y) is 00→00,01→10,10→00,11→11. A D flip-flop with D=b stores the preceding input and an AND gate computes y=Q∧b. The reset state Q=0 ensures a leading 1 is suppressed. No lookahead into future input is needed.

# GATE 2021 CS2: Q62 (printed CS Q52)

**Question:** [Official archived paper page 86](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=86); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 6 to 6

**Derived answer:** 6

**Paraphrased problem context:** Boolean f(w,x,y,z) satisfies f(w,0,0,z)=1; f(1,x,1,z)=x+z; f(w,1,y,z)=wz+y. Find minimum number of literals in an SOP, noting incompletely specified inputs. + means Boolean OR.

## Solution

The supplied cofactors force on-set minterms0, 1, 6, 7, 8, 9, 11, 13, 14, 15 and off-set 4, 5, 10, 12. Minterms2, 3 are unspecified and may be used as dont-cares for minimization. One minimum SOP is (NOT x)(NOT y)+xy+wz, containing6 literals. No one-literal implicant avoids all forced zeros. Moreover on-set points0, 6, 13 cannot be covered pairwise by a single implicant: their covering cubes would include a forced zero. At least three terms, each with at least two literals, are required, proving the lower bound6. Treating unspecified cofactors as dont-cares is the minimization convention used here. The supplied equations do not uniquely specify f: for example assigning f(0, 0, 1, 0)=1 and f(0, 0, 1, 1)=0 requires a separate three-literal implicant for minterm2, while minterms1, 14, 13 force the three essential prime implicants (NOT x)(NOT y), xy, wz respectively. That completion needs 9 literals, not6. Thus the official6 is the minimum over permissible completions, not a forced value for every function satisfying the three equations.

Shannon cofactor constraints leave only minterms 2 and 3 free. The three two-literal cubes ¬x¬y,xy,wz cover the forced on-set and avoid zeros 4,5,10,12. A literal count counts occurrences, so three terms with two literals cost six, not three. The witness completion that needs nine literals must remain disclosed because minimization over don't-cares is an assumption, not a logical consequence that f is uniquely fixed.
