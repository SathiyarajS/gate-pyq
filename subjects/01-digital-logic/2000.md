**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Essential problem context (paraphrased):** Represent positive decimal 43 in the eight-bit two’s-complement options: 01010101,11010101,00101011,10101011.

## Solution

Step 1: Decompose 43=32+8+2+1, giving binary 101011.

Step 2: Since the number is positive, two’s complement uses its ordinary binary representation with leading zero sign extension: 00101011.

Thus C. The pattern 11010101 instead represents −43 in eight bits; complementing the positive value is not appropriate when the source asks for positive 43, as confirmed in the clearer alternate reproduction.

**Essential problem context (paraphrased):** Find a listed solution(x,y,z,w) to x+y+z=1,xy=0,xz+w=1,xy+z′w′=0. Choices0100,1101,1011,1000; + means OR.

## Solution

Step 1: xy=0 immediately rejects 1101. For 0100, xz+w=0, so it fails the third equation. The same third equation rejects 1000.

Step 2: For 1011, x+y+z=1,xy=0,xz+w=1, and xy+z′w′=0+0·0=0. It satisfies all four.

Thus C is the listed solution. The equations can have other solutions not listed, so this checks the requested candidate rather than asserting a unique solution over all sixteen assignments.

# GATE 2000: Q34 (printed A Q2.11)

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Essential problem context (paraphrased):** Map columns wz and rows xy are Gray-ordered 00,01,11,10. Rows are [0,X,0,0],[0,X,1,1],[1,1,1,1],[0,X,0,0]. Which does NOT implement it: A(w+x)y; Bxy+yw; C(w+x)(w′+y)(x′+y); D none?

## Solution

Step 1: The specified ones occur when y=1 and at least one of w,x is 1. Thus F=(w+x)y, and distribution gives xy+yw, proving A and B equivalent and consistent with all specified cells.

Step 2: Simplify C: (w′+y)(x′+y)=y+w′x′. Multiplying by(w+x) gives y(w+x)+(w+x)w′x′=y(w+x), because the last product is zero.

Therefore C is equivalent as well, so none of A–C fails: D. The complement bars on both w and x in C are essential and were checked in the clearer alternate figure.

**Independently derived answer:** A

**Essential problem context (paraphrased):** A JK master-slave flip-flop P has J=K=1; its output feeds a D master-slave flip-flop Q with the shared clock. Starting(P,Q)=(0,1), find the state after three cycles from choices(1,0),(1,1),(0,0),(0,1).

## Solution

Step 1: J=K=1 makes P toggle each cycle. Q captures the previous P through its D input; the master-slave arrangement prevents using the newly changed P as the same-cycle input.

Step 2: Apply(P_next,Q_next)=(¬P,P_old): (0,1)→(1,0)→(0,1)→(1,0).

After three cycles the state is(1,0), A. Sequentially updating Q from the new P would incorrectly erase the intended synchronous delay.

**Essential problem context (paraphrased):** Convert one valid BCD digit d∈{0,…,9} to d mod 6. Input bits I₄I₃I₂I₁ have weights 8,4,2,1; output bits R₃R₂R₁ have weights 4,2,1. Illegal BCD inputs need not be detected.

2. Table (decimal d: I₄I₃I₂I₁ → R₃R₂R₁): 0:0000→000; 1:0001→001; 2:0010→010; 3:0011→011; 4:0100→100; 5:0101→101; 6:0110→000; 7:0111→001; 8:1000→010; 9:1001→011.

3. Inputs 1010,1011,1100,1101,1110,1111 may all be assigned XXX (don’t-care), not mandatory zero. No fourth output bit is needed because the maximum remainder is 5; if a four-bit interface is desired, R₄=0 for valid inputs.

4. In particular parity is unchanged by subtracting six, so the least significant bit is simply R₁=I₁. This provides a useful check on every row.

# GATE 2000: Q62 (printed B Q9(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203732/GATE2000_compressed-1.pdf#page=7), physical page 7. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** R₁=I₁; R₂=(I₂∧¬I₃)∨I₄; R₃=I₃∧¬I₂.

**Essential problem context (paraphrased):** Convert one valid BCD digit d∈{0,…,9} to d mod 6. Input bits I₄I₃I₂I₁ have weights 8,4,2,1; output bits R₃R₂R₁ have weights 4,2,1. Illegal BCD inputs need not be detected. Available altogether: two two-input AND gates, one two-input OR gate, and two NOT gates (OR is explicit in GFG; omitted in GateForum).

Task: Specify one circuit for each output bit within the gate budget.

## Solution

1. R₃ must be one only for valid digits 4 and 5. Their I₃=1 and I₂=0, so R₃=I₃ AND NOT I₂. Illegal inputs are don’t-care, permitting this simple expression.

2. R₂ is one for 2,3,8,9. The term I₂ AND NOT I₃ covers 2,3; I₄ covers 8,9 among valid BCD digits. Therefore R₂=(I₂ AND NOT I₃) OR I₄.

3. Complete netlist: N₂=NOT(I₂); N₃=NOT(I₃); G₂=AND(I₂,N₃); G₃=AND(I₃,N₂); R₂=OR(G₂,I₄); R₃=G₃; R₁ is a wire from I₁. This explicitly identifies every gate input and output and uses exactly the allowed 2 NOT, 2 AND, 1 OR gates.

4. Checking d=6,7 gives I₃=I₂=1, so R₃=R₂=0 and only parity R₁ remains. Checking d=8,9 gives I₄=1 and I₃=I₂=0, so output is 010 or 011. These are the nontrivial modulo reductions.

5. R₃ is the weight-four bit, not R₄. If four output positions are drawn, tie R₄ to zero. The GateForum missing gate name is resolved by the explicitly printed OR in the GFG reproduction.
