**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203551/GATE2001.pdf#page=2), physical page 2. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Essential problem context (paraphrased):** Find a minimal SOP for the displayed four-variable map. Columns wx and rows yz both use Gray order 00,01,11,10. Rows are [0,X,0,X], [X,1,X,1], [0,X,1,0], [0,1,X,0], with X a don’t-care. Choices: A xy+y′z; B wx′y′+xy+xz; C w′x+y′z+xy; D xz+y.

## Solution

Step 1: Read columns wx and rows yz in Gray order 00,01,11,10. The entire row yz=01 can be grouped using its don’t-care cells, producing y′z. The block with x=1,y=1 across rows 11/10 and columns 01/11 produces xy.

Step 2: These two four-cell groups cover all specified ones without covering a specified zero. One term cannot cover both required regions: enlarging to a common cube would include forbidden zero cells.

Conclusion: xy+y′z is a minimal two-term expression, A. Don’t-care cells are chosen only to enlarge legal groups, not to change specified zeros.

# GATE 2001: Q33 (printed A Q2.8)

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A under the ideal synchronous timing model

**Essential problem context (paraphrased):** Two positive-edge D flip-flops start at Q0=Q1=0. Their inputs are D0=X and D1=X·¬Q0; output Y=Q1. Setup time is 20 ns, hold time zero, and clock period at least 40 ns. The figure shows X rising after the first clock rising edge and falling before the sixth. Select the output trace: A one-cycle pulse from the second to third edge; B high from first to third; C first to second; D later sustained high. Exact timing drawing remains linked.

## Solution

Step 1: At each positive clock edge, Q0_next=X and Y_next=X·¬Q0_old. Both flip-flops sample old pre-edge signals, so the second stage cannot use the newly updated Q0 in the same sampling event.

Step 2: Initially Q0=Y=0. X rises after the first shown rising clock edge. At the next rising edge X=1 while old Q0=0, so Q0 becomes 1 and Y becomes 1. At the following rising edge X remains 1 but old Q0=1, so Y becomes 0. Later edges keep Y low, including after X falls.

Thus Y has one clock-period pulse starting at the second rising edge, plot A. The displayed separation is interpreted as meeting the 20 ns setup requirement, with negligible unprovided gate/clock-to-Q delays; period alone would not guarantee timing for an arbitrarily placed X transition.

4. Having four ones alone would not prove self-duality: their distribution across complement pairs matters. Here all four pairs satisfy the required condition.

# GATE 2001: Q70 (printed B Q10(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203551/GATE2001.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** b4=(¬e4+e1)(¬e4+e2)(e4+¬e2+¬e1).

**Essential problem context (paraphrased):** Input bits e8,e4,e2,e1 encode decimal d as d+3 (valid codes 3…12); output b4 is the weight-4 BCD bit. Diagram has four excess-3 input lines and four BCD outputs b8,b4,b2,b1. GFG explicitly requests b4; GateForum omits the subscript in its prose.

Task: Give a minimal product-of-sums expression for b4.

## Solution

1. For decimal digits d=0…9, the weight-4 BCD bit is 1 exactly for d=4,5,6,7. Their excess-3 inputs are 7,8,9,10. Hence the on-set is {7,8,9,10}; the valid zero-set is {3,4,5,6,11,12}. Codes {0,1,2,13,14,15} are don’t-cares.

2. For a product-of-sums minimize groups of zeros, permitting invalid codes as don’t-cares. The group e4=1,e1=0 covers zero codes 4,6,12 and don’t-care 14, giving the clause ¬e4+e1.

3. The group e4=1,e2=0 covers 4,5,12 and don’t-care 13, giving ¬e4+e2. The pair 3,11 has e4=0,e2=1,e1=1 while e8 varies, giving e4+¬e2+¬e1.

4. Multiplying these clauses covers every required zero and no required one. The e8 input disappears because the chosen groups span both of its values.

5. To check minimality without claiming these groups are all essential, enumerate the maximal zero/don’t-care cubes (bit order e8,e4,e2,e1; dash means either value): -011, -1-0, -10-, 0--0, 0-0-, 00--, 1-11, 11--. Their covered required zeros are respectively {3,11}, {4,6,12}, {4,5,12}, {4,6}, {4,5}, {3}, {11}, {12}. This includes the legal alternative cube {0,1,2,3}; zero 3 is not restricted to pairing with 11.

6. Every clause must avoid all required one-codes. No single zero cube can cover any pair among required zeros 5,6,11: the smallest cube spanning each such pair contains code 7, a required one. At least three clauses are therefore necessary. The maximal cubes listed above have at most four cells, so every nonredundant clause has at least two literals. A cube covering zero 11 has at most two cells (the only choices are -011 and 1-11), so its clause needs at least three literals. Any POS consequently needs at least 3+2+2=7 literals; four or more clauses need at least eight. The displayed three-clause, seven-literal POS attains both lower bounds. Other minimum covers exist; its three chosen prime groups are not all essential.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203551/GATE2001.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** Four-state Mealy machine A,B,C,D with transitions A:0/0→B,1/1→A; B:0/0→C,1/1→A; C:0/1→C,1/0→D; D:0/1→C,1/0→A.

**Essential problem context (paraphrased):** Initially copy input bits. After two consecutive input zeros, complement following bits; after two consecutive input ones while complementing, return to copying. The triggering second bit still uses the old mode. Use J-K flip-flops.

Task: Give the state transition diagram (specified here by a complete labeled transition table).

## Solution

1. Define A as copy mode with no pending zero, B as copy mode after one zero, C as complement mode with no pending one, and D as complement mode after one one. Start at A. Edge labels are input/output.

2. In copy mode output equals input. Thus A on 0 emits 0 and moves to B; A on 1 emits 1 and stays A. B on 1 emits 1 and resets to A; B on 0 emits 0 and moves to C because the second zero has just occurred.

3. In complement mode output is inverted. Thus C on 0 emits 1 and stays C; C on 1 emits 0 and moves to D. D on 0 emits 1 and resets to C; D on 1 emits 0 and returns to A after the second one.

4. The transition-triggering symbol is processed using the old mode, matching the printed example: input 101100|01001011|0|11 gives output 101100|10110100|0|11.

5. These four states record exactly the information needed: the current mode and whether the first symbol of its switching pair has been seen. Runs of the nontriggering symbol reset the pending-pair state.

# GATE 2001: Q72 (printed B Q11(b))

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203551/GATE2001.pdf#page=8), physical page 8. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** descriptive, Unallocated leaf; group total 5 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** For mode flip-flop: J_M=P¬x, K_M=Px. Optionally J_P=Mx+¬M¬x and K_P=1.

**Essential problem context (paraphrased):** Initially copy input bits. After two consecutive input zeros, complement following bits; after two consecutive input ones while complementing, return to copying. The triggering second bit still uses the old mode. Use J-K flip-flops. Encode A=00, B=01, C=10, D=11 with mode bit M and pending-pair bit P. Input x; output y=x XOR M.

Task: Give minimized sum-of-products expressions for the J and K inputs of one state flip-flop.

## Solution

1. Use the four-state transition table from part (a), encoding copy states A,B with M=0 and complement states C,D with M=1. P=1 denotes B or D, where a triggering first bit is pending.

2. A J-K flip-flop obeys Q⁺=J¬Q+¬KQ. To change 0→1 requires J=1 (K don’t-care); 0→0 requires J=0; 1→0 requires K=1 (J don’t-care); and 1→1 requires K=0.

3. When M=0, the mode changes to 1 only in B (P=1) on x=0. Therefore J_M=P¬x. For M=1, J_M is irrelevant and these excitation don’t-cares allow the M literal to be omitted.

4. When M=1, the mode changes to 0 only in D (P=1) on x=1. Therefore K_M=Px, likewise independent of M after using its don’t-cares. Each is a single two-literal product and is already minimized SOP.

5. For a complete implementation, P=0 changes to 1 precisely when x=M (A on 0 or C on 1), giving J_P=Mx+¬M¬x. From either P=1 state the next P is always 0, so K_P=1. Reset both bits to 0 and use y=x XOR M.
