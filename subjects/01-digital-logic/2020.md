**Official answer:** 5 to 5

**Derived answer:** 5

**Paraphrased problem context:** A multiplexer selects exactly one of 32 registers to transfer to an accumulator. What is the minimum number of binary select lines?

## Solution

Worked explanation

With s binary selection inputs, a multiplexer can encode at most 2^s choices. Four lines provide only 16 choices, fewer than the 32 register inputs. Five lines provide 32, exactly enough. This counts control lines; the register word width determines the data-path width and is irrelevant to this count. The accumulator is the common destination, not a 33rd selectable source.

Derivation and answer

Selecting one of 32 registers requires32 distinct selector patterns. The minimum binary selector width is ceil(log₂32)=5.

**Type / marks:** NAT, 1 mark(s).

**Official answer:** 1034 to 1034

**Derived answer:** 1034

**Paraphrased problem context:** A decoder with m input lines and n output lines uniquely addresses a byte-addressable 1 KB RAM. Find the minimum m+n.

## Solution

Worked explanation

Byte addressability means each byte is a separately selected location. Under the binary memory-size convention, 1 KB=2^10 bytes, so there must be 1024 distinct outputs in the one-hot address decoder. Its m input bits must encode all 1024 choices, requiring m=10. Thus n=1024 and m+n=1034. Do not confuse the RAM’s 8-bit data width with the number of decoder outputs: those outputs select addresses, not individual data bits.

Derivation and answer

A byte-addressable1KB memory has 1024 distinct byte locations. A one-hot decoder needs 1024 output lines and log₂1024=10 address inputs. Thus m+n=10+1024=1034, using the conventional1KB=1024 bytes.

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Circuit equivalent: b enters NOT, its output and c enter AND, and that result and a enter OR to produce z. With minterm index 4a+2b+c, choose z. A Σm(0,1,3,7); B Σm(1,4,5,6,7); C Σm(2,4,5,6,7); D Σm(2,3,5).

## Solution

Worked explanation

Read the inversion bubble on b before constructing the product term. The AND output is b′c and the final OR adds a. Truth-table equivalent, in order abc=000,001,010,011,100,101,110,111: z=0,1,0,0,1,1,1,1. Index each assignment as binary abc with a most significant. The true rows are therefore 1,4,5,6,7. Option C incorrectly includes minterm 2, which has c=0, while A and D omit true rows with a=1. The displayed gate connections, rather than a guessed canonical expression, determine the result.

Derivation and answer

The circuit computes z=a∨(¬b∧c). For a=1 all four minterms4, 5, 6, 7 are on. For a=0 the only on assignment is b=0, c=1, minterm1. Thus Σm(1, 4, 5, 6, 7), B. Inverter and gate shapes were visually checked.
