**Paraphrased problem context:** In IEEE floating-point representation, what does hexadecimal 0x00000000 represent?

(A) Normalized value 2^(−127)
(B) Normalized value 2^(−126)
(C) Normalized value +0
(D) Special value +0

## Solution

1. Split binary32 into sign, exponent and fraction fields. Every field is zero here.
2. An all-zero exponent is reserved for zero/subnormal encodings, so the normalized-number formula with an implicit leading 1 does not apply.
3. The zero fraction makes the magnitude zero; sign bit 0 makes it +0. This is the special value in D.

# GATE 2008: Q5 (printed CS Q5)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 2. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Minimize the Karnaugh map. Columns ab are 00,01,11,10; rows cd are 00,01,11,10. Rows of cell values are [1,1,0,1], [X,0,0,0], [X,0,0,0], [1,1,0,X]. X is a don’t-care; blank source cells are zero. Prime denotes complement.

(A) b′d′+a′d′
(B) a′b′+b′d′+a′bd′
(C) b′d′+a′bd′
(D) a′b′+b′d′+a′d′

## Solution

1. Treat the map edges as adjacent. The four corners form a legal group by using the bottom-right don’t-care; b and d are zero throughout, giving b′d′.
2. Group the cells in the top and bottom rows of the left two columns. Here a=d=0, giving a′d′.
3. The union covers every specified 1 without any specified 0, so f=b′d′+a′d′, A. One implicant cannot cover both required ab=01 and ab=10 regions without including a forbidden ab=11 cell, so two terms are needed.

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 2. Consult original wording and choices.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** For radix r, which r satisfy √(121ᵣ)=11ᵣ?

(A) Decimal 10
(B) Decimal 11
(C) Decimal 10 and 11
(D) Any valid radix greater than 2

## Solution

1. Interpret the digits by place value: 121ᵣ=r²+2r+1=(r+1)², while 11ᵣ=r+1.
2. The positive square root is r+1 for every positive radix.
3. Digit 2 is valid only when the integer radix exceeds 2. Hence all valid r>2 satisfy the equation, D; there is nothing special about decimal 10 or 11.

**Paraphrased problem context:** An AND gate combines f₁ and f₂, and its output is ORed with f₃ to produce f. Given f₁=Σm(4,5,6,7,8), f₃=Σm(1,6,15), f=Σm(1,6,8,15), which offered f₂ works?

(A) Σm(4,6)
(B) Σm(4,8)
(C) Σm(6,8)
(D) Σm(4,6,8)

## Solution

1. The circuit computes f=(f1∧f2)∨f3. Minterm8 must be supplied through f1f2, while4,5,7 must not be introduced.
2. Of the options, only f2=Σm(6,8) meets these conditions, giving final set{1,6,8,15}, C. The internal function is not uniquely determined over all possible minterms: values outside f1’s support are irrelevant and minterm6 is already covered by f3.
3. C is the unique compatible supplied choice.

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 5. Consult original wording and choices.

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Simplify (P+Q′)(PQ′+PR)(P′R′+Q′), where + is Boolean OR and juxtaposition is AND.

(A) PQ′
(B) PR′
(C) PQ′+R
(D) PR′+Q

## Solution

1. Factor the middle term as P(Q′+R), so when P=0 the whole expression is 0.
2. For P=1, the first factor P+Q′ is 1; the middle is Q′+R; the last P′R′+Q′ is Q′.
3. Absorption gives (Q′+R)Q′=Q′. Combining both P cases yields PQ′, A. This checks the full function, not just a selected input.
