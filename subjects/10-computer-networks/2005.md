**Independently derived answer:** B

**Paraphrased problem context:** Packets in one session may take different routes under: A TCP only; B TCP and UDP; C UDP only; D neither.

## Solution

Both TCP segments and UDP datagrams are carried by IP, whose routing decisions can vary over time or across paths. TCP’s connection and ordering guarantees do not reserve one network route. Thus packets may take different paths for both, B.

Teaching detail:
TCP and UDP are transport protocols carried by IP. IP forwarding can change routes between packets, independent of whether the transport maintains a connection. TCP reconstructs ordering and retransmits as needed; those guarantees do not reserve a physical path. UDP likewise imposes no route consistency. Therefore both may traverse different paths, B.

**Independently derived answer:** D

**Paraphrased problem context:** ARP is used to find: A IP address from DNS; B default gateway IP; C IP corresponding to a MAC; D MAC corresponding to an IP.

## Solution

On an IPv4 local link, ARP resolves a known next-hop IPv4 address to the corresponding link-layer/MAC address, D. It does not perform DNS name resolution or discover the default gateway’s IP configuration.

Teaching detail:
To send a local-link Ethernet frame, the sender needs a destination MAC address. Given the next-hop IPv4 address, ARP requests who owns it and learns the corresponding MAC, D. Name-to-IP lookup is DNS; determining which gateway to use comes from routing/configuration; reverse resolution is a different function. For a remote destination, the resolved MAC normally belongs to its next-hop router.

**Independently derived answer:** B

**Paraphrased problem context:** Maximum selective-repeat/reject window with n-bit sequence numbers? A 2^n; B 2^(n−1); C 2^n−1; D 2^(n−2).

## Solution

With n sequence bits there are 2^n labels. To prevent a delayed old frame from being confused with a new frame after wraparound, equal sender/receiver windows must occupy at most half the label space. Hence W≤2^(n−1), B, under the standard selective-repeat model.

Teaching detail:
There are 2^n distinct labels. In selective repeat, receivers may accept out-of-order frames, so old and new receive windows must not overlap after sequence wrap. With equal window sizes W, the standard safety condition is 2W≤2^n, hence W≤2^(n−1). The half-space restriction distinguishes this protocol from the different Go-Back-N bound.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** Why use spanning tree among LAN bridges? A shortest paths; B avoid forwarding loops; C fault tolerance; D minimize collisions.

## Solution

A spanning tree leaves a connected forwarding topology without cycles. This prevents frames, especially flooded broadcasts/unknown unicasts, from circulating indefinitely and being duplicated. Thus B; spanning-tree forwarding does not promise pairwise shortest routes.

Teaching detail:
Flooded frames do not have an IP-style hop limit at the bridging layer. A forwarding cycle can therefore cause copies to circulate and multiply. The spanning-tree protocol disables redundant paths to leave a connected acyclic active topology, preventing that loop. It can reconfigure after faults, but the question’s direct purpose is B; pairwise routes need not be shortest.

## Solution

Starting with a /16 class-B network, borrow 6 bits to obtain 2^6=64 subnets. The /22 mask is 255.255.252.0, D. This uses all subnet numbers; the obsolete convention excluding all-zero/all-one subnets would require a different count and is not applied.

Teaching detail:
A class-B prefix starts with 16 network bits. Six additional subnet bits give 64 patterns, leaving 10 host bits. The resulting prefix length 22 has mask 11111111.11111111.11111100.00000000, or 255.255.252.0. This uses all 64 subnet numbers under the modern convention, rather than subtracting two obsolete reserved subnet patterns.

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** A24-byte message traverses a single packet-switched path with two intermediate nodes (three equal-rate store-and-forward links). Every packet has a 3-byte header. Optimum total packet size: A4; B6; C7; D9 bytes. Use equal payload segments and neglect packet-independent propagation.

## Solution

Let payload size be p bytes, so each packet has size p+3 and there are 24/p packets. Across three equal-rate store-and-forward links the serialization makespan, apart from constant propagation terms, is (24/p+2)(p+3)=30+2p+72/p byte-times. Its derivative is 2−72/p², giving p=6 bytes. This divides 24 exactly, and the total packet size is 6+3=9 bytes, option D. Packet size includes the header; six is only the payload.

Teaching detail:
For k packets of lengthp+3, a three-link pipeline needs k+2 packet transmission times: three for the first packet, one for each later packet. Substituting k=24/p gives 30+2p+72/p. Its derivative vanishes atp=6 and the second derivative 144/p³ is positive. Payload 6 divides 24, so no unequal final packet is needed. Adding its 3-byte header gives total 9, distinguishing the asked packet size from payload size.

**Paraphrased problem context:** A10 Mbps Ethernet has round-trip propagation 46.4 microseconds and 48-bit jam allowance. Intended minimum frame size in bits: A94; B416; C464; D512.

## Solution

The round-trip propagation delay corresponds to 10×10^6×46.4×10^−6=464 bit-times. Including the stated 48-bit jam allowance gives 464+48=512 bits, or 64 bytes, option D. This uses the question’s intended collision-slot budgeting convention; the jam is collision handling, not an extra field appended to every successful frame.

Teaching detail:
At 10 million bits/s, propagation 46.4 microseconds spans 464 bit times. Under the supplied collision-slot convention, add 48 bit times for jamming, giving 512 bits. Dividing by 8 gives 64 bytes, but the choices are in bits. The jam is not an ordinary payload/header field to append to every successful Ethernet frame; it belongs to the stated collision handling budget.
