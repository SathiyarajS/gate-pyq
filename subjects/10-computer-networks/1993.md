**Essential problem context (paraphrased):** An asynchronous serial line sends 8-bit characters at 2400 baud with two stop bits. Choose the character rate among 109,216,218,219,240.

## Solution

Each frame needs one start bit, eight data bits and two stop bits, totaling eleven bits. With one bit per symbol, 2400 baud is 2400 bits/s, so the sustained rate is 2400/11≈218.18 characters/s. At most 218 whole frames fit in a one-second interval starting on a frame boundary, giving C. Ignoring the start bit would incorrectly give 240. This assumes no parity bit and binary signaling; baud is generally symbols per second, so another modulation alphabet would require additional information.
