

# GATE 2025 CS1: Q16

**Question:** [Official archived paper page 16](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=16); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Match layers (a) network, (b) transport, (c) data link to functions (I) packet routing, (II) framing and error handling, (III) host-to-host communication. A a-I,b-II,c-III; B a-I,b-III,c-II; C a-II,b-I,c-III; D a-III,b-II,c-I.

## Solution

Approach: Identify the most specific layer functions before assigning the less precise phrase.
The network layer handles packet routing across networks, so a must match I. The data-link layer groups bits into frames for a link and handles link-level error detection or control, so c matches II. Those two matches already identify B among the choices.
The remaining b-III match is the question’s intended description of transport-layer end-to-end communication. More precisely, transport protocols provide process-to-process service using endpoint identifiers such as ports; “host-to-host” is broader wording than the usual precise definition.
A misassigns framing to transport; C assigns framing to network; D assigns routing to data link. Thus B is correct in the supplied matching scheme. Error handling can also exist at other layers, but “framing and error handling” together points to the data-link layer here.

# GATE 2025 CS1: Q22

**Question:** [Official archived paper page 22](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=22); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** B;D

**Derived answer:** B;D

**Paraphrased problem context:** Let P1,P2,P3 be the three successive packets of the ordinary TCP connection-establishment handshake. Select true claims: A P3 has SYN=1,ACK=1; B P2 has SYN=1,ACK=1; C P2 has SYN=0,ACK=1; D P1 has SYN=1.

## Solution

Approach: Separate the request to synchronize sequence numbers from the acknowledgment of the peer’s request.
P1 is the initiating SYN: it starts synchronization with SYN=1 and, in the ordinary initial handshake, ACK=0. Hence D is true.
P2 both acknowledges the first SYN and announces the responding endpoint’s own initial sequence number. Its flags are SYN=1 and ACK=1. This makes B true and C false.
P3 acknowledges the responder’s SYN. It is an ACK with SYN=0,ACK=1, so A is false. The correct selection is B and D.
The ACK flag indicates that the acknowledgment-number field is valid; it is not merely a generic statement that a packet arrived. This question is about the standard three-way establishment sequence, not simultaneous open or later connection teardown.

# GATE 2025 CS1: Q40

**Question:** [Official archived paper page 40](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=40); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** Destination 145.36.109.70 arrives at a router with entries 145.36.0.0/16→E1; 145.36.128.0/17→E2; 145.36.64.0/18→E3; 145.36.255.0/24→E4; default→E5. Which outgoing interface is selected? A E3; B E1; C E2; D E5.

## Solution

Approach: First find all matching network prefixes, then choose the most specific (longest) one.
The first two destination octets are 145.36, so the /16 E1 entry matches. The /17 E2 entry additionally requires the high bit of the third octet to be 1, meaning a third octet from 128 through 255. The destination’s third octet is 109, so that entry does not match.
The /18 E3 prefix fixes the first two bits of the third octet to 01, covering 64 through 127. Since 109 lies in that range, it matches. The /24 E4 entry requires third octet 255, so it does not match.
Among E1’s /16, E3’s /18 and the default, /18 is longest. Thus forward to E3, option A. Routing is not a first-listed-match decision, and a longer prefix is relevant only if it actually matches.

# GATE 2025 CS1: Q56

**Question:** [Official archived paper page 56](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=56); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 0.949 to 0.952

**Derived answer:** 0.951

**Paraphrased problem context:** A five-bit message is sent through a channel that independently flips each bit with probability 0.01. What is the probability of receiving the entire message error-free, rounded to three decimal places?

## Solution

Approach: An error-free message requires all five separate “not flipped” events to occur.
For each bit, P(no flip)=1−0.01=0.99. Since the bit-flip events are independent, their complements are independent as well, and the probability of all five correct bits is the product 0.99^5.
Calculating gives 0.9509900499, which rounds to 0.951 at three decimal places. This lies in the official accepted interval 0.949–0.952.
The expression 1−5×0.01=0.95 is only a first-order approximation: it treats the five error events as if they were disjoint, even though two or more bits may flip together. Alternatively, the number of errors is binomial with parameters 5 and 0.01, and its zero-error probability is C(5,0)(0.01)^0(0.99)^5, the same result.

# GATE 2025 CS1: Q57

**Question:** [Official archived paper page 57](https://gate2026.iitg.ac.in/doc/download/2025/CS12025.pdf#page=57); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 7 to 7

**Derived answer:** 7

**Paraphrased problem context:** A 15000-byte message travels Source→Router 1→Router 2→Destination. Router 1 has MTU 5000 bytes and Router 2 MTU 3000 bytes, each including its IPv4 header. How many fragments reach the destination? Use ordinary IPv4 fragmentation; no reassembly takes place at intermediate routers.

## Solution

Approach: Fragment at the first MTU, then split each existing fragment separately at the second MTU. Nonfinal IPv4 fragment payloads must be multiples of eight bytes.
Using a standard 20-byte header, Router 1 can carry at most floor((5000−20)/8)×8=4976 payload bytes in a nonfinal fragment. Treating 15000 as payload gives fragment payloads 4976,4976,4976,72, so four fragments leave Router 1.
At Router 2, the aligned maximum is floor((3000−20)/8)×8=2976. Each 4976-byte payload splits into 2976 and 2000 bytes, producing two fragments. The final 72-byte payload already fits and stays as one. Thus the destination receives 2+2+2+1=7 fragments.
It would be wrong to divide the original payload by Router 2’s MTU as though all first-stage fragments were reassembled; IPv4 routers do not coalesce them. If the original 15000 bytes includes its header, the first-stage remainder becomes 52 instead of 72, with the same total count. The count also remains seven for ordinary legal IPv4 header lengths. The two MTUs and route were visually verified.

# GATE 2025 CS2: Q16

**Question:** [Official archived paper page 14](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=14); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Assess two statements: (i) ARP maps an IP address to the corresponding hardware/link-layer address; (ii) a TCP segment from S to R cannot simultaneously contain S-to-R data and an acknowledgment for R-to-S traffic.
Options: A. both true; B. (i) true and (ii) false; C. (i) false and (ii) true; D. both false.

## Solution

For the IPv4 local-link setting, ARP resolves a next-hop IPv4 address to a link-layer address, such as an Ethernet MAC address. A host broadcasts an ARP request for the local next hop, and the reply supplies the hardware address used in the frame. This makes (i) true; ARP is not a mechanism for finding an arbitrary remote host's MAC through multiple routers.

TCP is full duplex. A segment has separate sequence-number and acknowledgment-number fields as well as a payload. The payload can carry bytes from S to R while the acknowledgment field, with ACK set, reports bytes already received by S from R. Combining them is called acknowledgment piggybacking and saves a separate ACK-only packet. Therefore (ii), which says they cannot be combined, is false. Answer: B.

# GATE 2025 CS2: Q17

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** Match routing methods with their usual shortest-path algorithm: (i) distance-vector routing; (ii) link-state routing. Algorithms are (a) Bellman–Ford and (b) Dijkstra.
Options: A. i→a, ii→b; B. i→a, ii→a; C. i→b, ii→a; D. i→b, ii→b.

## Solution

Distance-vector routing maintains estimates to destinations and exchanges these with neighbors. Router x updates its distance to y using
D_x(y)=min over neighbors v of [cost(x,v)+D_v(y)].
This is the Bellman–Ford recurrence, applied in a distributed fashion. Thus (i) matches (a).

A link-state router learns the network's connectivity and link costs through link-state advertisements. With this graph available locally, it computes a shortest-path tree rooted at itself, conventionally using Dijkstra's algorithm for nonnegative link costs. Thus (ii) matches (b). The important distinction is neighbor distance estimates versus an advertised topology map, not simply that both seek shortest routes. The two correct matches appear together only in A.

# GATE 2025 CS2: Q18

**Question:** [Official archived paper page 16](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=16); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** An IPv4 packet's Protocol field names the protocol carried immediately inside IPv4. Which listed protocol is not normally a possible direct value for this purpose?
Options: A. ICMP; B. IGMP; C. OSPF; D. RIP.

## Solution

The IPv4 Protocol field identifies the next encapsulated protocol, not every protocol that may appear farther inside the payload. ICMP, IGMP, and OSPF all run directly over IP and have assigned IPv4 protocol numbers 1, 2, and 89 respectively. Therefore A, B, and C are possible.

RIP messages are carried in UDP datagrams, conventionally using UDP port 520 for RIPv2. In such a packet the IP Protocol field is 17, identifying UDP. RIP is recognized by the transport-layer port and its message format rather than by a direct RIP value in this field. Thus D is the required exclusion. OSPF and RIP are both routing protocols, but they use different encapsulation, so their shared purpose does not imply the same packet layering.

# GATE 2025 CS2: Q23

**Question:** [Official archived paper page 20](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=20); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** D

**Derived answer:** D

**Paraphrased problem context:** Ethernet can carry at most 1500 bytes in its data field. IPv4 uses a 20-byte header with no options. A UDP datagram has 7488 bytes of application data. After IPv4 fragmentation, how many fragments are sent, and what is the total size of the last fragment including its IPv4 header?
Options: A. 5 and 1488 bytes; B. 6 and 88 bytes; C. 6 and 108 bytes; D. 6 and 116 bytes.

## Solution

UDP adds one 8-byte header to its 7488 data bytes. The payload of the original IPv4 datagram is therefore 7496 bytes. Each fragment must fit the 1500-byte Ethernet data field, and each has its own 20-byte IPv4 header. A full fragment can consequently carry 1500−20=1480 payload bytes.

Except for the last fragment, IPv4 fragment payload lengths must be multiples of 8 because fragment offsets are in 8-byte units. Here 1480=185·8, so the full payload size is usable. Divide the original payload: 7496=5·1480+96. There are five full fragments and one final fragment, hence six in total. The last has 96 payload bytes plus a 20-byte IPv4 header, or 116 bytes.

The UDP header is part of the original payload and appears only in the first fragment, not in every fragment. Omitting it would incorrectly give 88 bytes of last payload and 108 bytes including IP; 88 alone would additionally omit the final IP header. Answer: D.

# GATE 2025 CS2: Q36

**Question:** [Official archived paper page 27](https://gate2026.iitg.ac.in/doc/download/2025/CS22025.pdf#page=27); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** A

**Derived answer:** A

**Paraphrased problem context:** Stop-and-wait sends 3000-bit frames on a 2000-bit/s channel. One-way propagation delay is 100 ms. Ignore processing time and ACK transmission time. Which offered percentage best approximates channel utilization?
Options: A. 88.23; B. 93.75; C. 85.44; D. 66.67.

## Solution

Frame transmission takes T_tx=3000/2000=1.5 seconds. Once the last data bit leaves the sender it still needs 0.1 seconds to reach the receiver. The negligibly short ACK then needs another 0.1 seconds to propagate back. Therefore the interval from starting one frame until being allowed to start the next is T_cycle=1.5+0.1+0.1=1.7 seconds.

The sender uses the channel to transmit data for 1.5 seconds of each 1.7-second cycle, so utilization is U=1.5/1.7=15/17≈0.88235294, or 88.235294 percent. Equivalently U=1/(1+2a), where a=T_prop/T_tx.

A is the nearest listed choice. The displayed 88.23 is a truncated/approximate option; conventional rounding of the calculated percentage to two decimal places gives 88.24. Ignoring the return propagation would overestimate utilization, while treating the 100 ms as a round trip would change the supplied assumption. Answer: A.
