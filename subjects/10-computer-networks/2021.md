

# GATE 2021 CS1: Q18 (printed CS Q8)

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

In ordinary Ethernet ARP address resolution, a requester broadcasts because it does not yet know the target MAC address. The target learns the requester’s MAC from that request and unicasts the reply to it. Thus S1 is false and S2 true, C. This describes the normal request/reply exchange, not gratuitous ARP or implementation-specific unicast refresh traffic.

# GATE 2021 CS1: Q54 (printed CS Q44)

**Question:** [Official archived paper page 36](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=36); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A; B; C

**Derived answer:** A; B; C

## Solution

A passive client with no keepalive, no pending retransmission and no application timeout can wait indefinitely after a silent server crash, so A is possible. After reboot the server can bind and listen on the same port again, so B is possible. The old established connection state is gone; a segment from that old connection can elicit a reset, not an orderly FIN, giving C rather than D. This is the standard reachable-server TCP response model; actual delivery can still be affected by packet loss or filtering, and a listening socket does not restore the lost connection.

# GATE 2021 CS1: Q55 (printed CS Q45)

**Question:** [Official archived paper page 36](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=36); consult original wording, diagrams and choices.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** A; C

**Derived answer:** A; C

## Solution

The TCP segment is the 1400-byte IP payload. The original IP datagram is 1420 bytes and fits the first MTU. The second link allows 820-20=800 payload bytes per fragment, a multiple of eight. Fragment payloads are therefore 800 and 600 bytes, giving datagram sizes 820 and 620, so A holds. IP routers do not retransmit lost fragments, so B is false. Loss prevents reassembly of the original segment and TCP at P retransmits the unacknowledged data, corresponding to C in the ordinary unchanged-segmentation model. TCP may resegment retransmitted bytes in a more general implementation; it does not repair just the missing IP fragment. The TCP header is only in the first fragment, so the second alone does not reveal the destination port and D is false.

# GATE 2021 CS1: Q59 (printed CS Q49)

**Question:** [Official archived paper page 39](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=39); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 50 to 52

**Derived answer:** 51

## Solution

A data frame takes 2000/10^6=2 ms to serialize; an ACK takes 10/10^6=0.01 ms. The earliest ACK for the first frame returns after 2+100+0.01+100=202.01 ms. For an unsaturated sliding window of W frames, utilization is W*2/202.01. Requiring at least 0.5 gives W>=50.5025, so the smallest integer window is 51. The official accepted interval is 50 to 52 and is retained, but the explicit ACK serialization and minimum-integer calculation give 51.

## Solution

Q sends SYN+ACK using its own initial sequence Y and acknowledging X+1 because SYN consumes one sequence number. Thus SYN=1, SEQ=Y, ACK=1, ACKnumber=X+1, FIN=0, C; sequence arithmetic is modulo2³².

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

## Solution

Append three zeros to 11000, obtaining11000000. Divide over GF(2) by 1011. XOR at the leading positions gives 11000000 XOR10110000=01110000, then XOR01011000=00101000, then XOR00101100=00000100. The three-bit remainder is 100, so C. Appending100 makes the transmitted polynomial divisible by the generator.

## Solution

Bellman-Ford updates R-to-P with min(3+7, 2+6, 5+5)=8, reached through Y. For Q it uses min(3+4, 2+6, 5+8)=7, reached through X. Hence B, C, not A or D.

# GATE 2021 CS2: Q64 (printed CS Q54)

**Question:** [Official archived paper page 87](https://gate2026.iitg.ac.in/doc/download/2021/cs_2021.pdf#page=87); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 130 to 140

**Derived answer:** 135

## Solution

A frame occupies1000/10^6=0.001 seconds. For pure ALOHA the vulnerable period is twice that, 0.002 seconds. Given the stated Poisson attempt rate1000 per second, the chance of no competing attempt in that interval is exp(-1000*0.002)=e^-2. Successful throughput is 1000e^-2=135.335 frames/second, rounding to 135, within the official130–140 interval.
