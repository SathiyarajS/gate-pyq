**Essential problem context (paraphrased):** Does an RS232-style start bit synchronize each received byte, a whole byte sequence, provide parity, or synchronize only the last byte?

## Solution

Between asynchronous frames the line is idle. The start-bit transition tells the receiver that a new character frame has begun, allowing it to align sampling instants for that frame’s data bits. This resynchronization occurs for each byte, A. It is not a parity check and does not establish one permanent clock phase for an unlimited sequence. Strictly RS232 specifies electrical/interface aspects; the question refers to the familiar asynchronous framing used over that interface.
