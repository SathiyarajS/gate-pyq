

# GATE 2007: Q19 (printed CS Q19)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 4. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

Manchester uses two half-bit signal elements to encode each bit, with a transition in the middle. Under the conventional signal-element definition of baud, baud rate is twice bit rate, so the bit rate is half the baud rate, A. This is not a claim that every bit causes exactly two transitions.

# GATE 2007: Q67 (printed CS Q67)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 16. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

A class B network leaves 16 bits after its network prefix. Borrowing 6 subnet bits leaves 10 host bits, so usable ordinary unicast hosts per subnet are 2^10-2=1022. Under the historical convention excluding all-zero and all-one subnet numbers, the subnet count is 2^6-2=62, giving C. Modern subnetting permits those two subnet numbers and gives 64 subnets with 1022 hosts each; that pair is absent from the options. C is conditional on the obsolete convention, not a modern universal maximum.

## Solution

The generator x^3+1 is binary 1001. Append three zeroes to 11001001, obtaining 11001001000. Modulo-2 division by 1001 has remainder 011. Replace the trailing zeroes by this remainder to transmit 11001001011, option B. Dividing this codeword by 1001 gives zero remainder.

# GATE 2007: Q69 (printed CS Q69)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 17. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

Let transmission time T=K/R and one-way propagation time P=Lt. With negligible ACK serialization, full utilization needs an integer window W >= ceil(1+2P/T). For Go-Back-N with an m-bit sequence field, W <= 2^m-1, hence m >= ceil(log2(2+2LtR/K)); this is option A. The problem says only sliding window, not Go-Back-N, and does not state ACK timing: Selective Repeat instead needs sequence space at least 2W, while counting merely enough distinct labels without the Go-Back-N guard gives a different expression. Therefore A requires the standard Go-Back-N/negligible-ACK interpretation; the generic wording alone does not uniquely fix the answer.

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

SMTP provides application-layer mail transfer (1); BGP performs interdomain routing, conventionally classified here by its network-layer function (4); TCP is transport-layer (2); PPP is data-link-layer (3). Thus P-1,Q-4,R-2,S-3, option B. BGP actually exchanges control messages over TCP, so its implementation can also be described as an application-layer protocol; the offered matching uses routing function.
