**Paraphrased problem context:** In Ethernet using Manchester encoding, the bit rate is which of the following?
Options:
(A) Half the baud rate
(B) Twice the baud rate
(C) Equal to the baud rate
(D) None of these

## Solution

1. Approach. One data bit occupies two half-bit signal intervals. Under the convention in the question, count these intervals as signal elements when computing baud.

2. Derivation and interpretation. Manchester uses two half-bit signal elements to encode each bit, with a transition in the middle. Under the conventional signal-element definition of baud, baud rate is twice bit rate, so the bit rate is half the baud rate, A. This is not a claim that every bit causes exactly two transitions.

**Independently derived answer:** A

**Paraphrased problem context:** A slotted LAN has n stations. Each station independently attempts to transmit with probability p in a slot. What is the probability that exactly one station transmits?
Options:
(A) np(1−p)^(n−1)
(B) (1−p)^(n−1)
(C) p(1−p)^(n−1)
(D) 1−(1−p)^(n−1)

## Solution

1. Approach. Choose which station is the sole sender, then require it to transmit and every other station to remain silent. The n resulting events are mutually exclusive, so add their probabilities.

2. Derivation and interpretation. Assuming independent station attempts, a fixed station transmits alone with probability p(1-p)^(n-1). There are n disjoint choices for the sole transmitter, giving np(1-p)^(n-1), option A.

Options:
(A) 500 metres
(B) 200 metres
(C) 20 metres

## Solution

1. Approach. Convert bit rate to time per bit by taking the reciprocal. Express that time in microseconds before multiplying by the propagation speed to avoid a factor-of-a-million unit error.

2. Derivation and interpretation. At 10^7 bits/s, one bit takes 10^-7 s = 0.1 microsecond. During this time a signal travels 200 metres/microsecond times 0.1 microsecond = 20 metres. Answer C.

**Independently derived answer:** C

**Paraphrased problem context:** A class B address is divided into subnets using a 6-bit subnet number. What maximum numbers of subnets and hosts per subnet are intended?
Options:
(A) 62 subnets,262142 hosts
(B) 64 subnets,262142 hosts
(C) 62 subnets,1022 hosts
(D) 64 subnets,1024 hosts

## Solution

1. Approach. A class B prefix originally leaves 16 bits. Assigning six of those to subnet IDs leaves ten for hosts. Distinguish historical reserved subnet IDs from reserved host IDs and modern subnet conventions.

2. Derivation and interpretation. A class B network leaves 16 bits after its network prefix. Borrowing 6 subnet bits leaves 10 host bits, so usable ordinary unicast hosts per subnet are 2^10-2=1022. Under the historical convention excluding all-zero and all-one subnet numbers, the subnet count is 2^6-2=62, giving C. Modern subnetting permits those two subnet numbers and gives 64 subnets with 1022 hosts each; that pair is absent from the options. C is conditional on the obsolete convention, not a modern universal maximum.

**Paraphrased problem context:** Protect message 11001001 using CRC generator x³+1. Which bit string should be transmitted?
Options:
(A) 11001001000
(B) 11001001011
(C) 11001010
(D) 110010010011

## Solution

1. Approach. The generator degree is three, so append exactly three zero bits before polynomial division. Subtraction over GF(2) is XOR, with no borrowing. Replace the three zero placeholders by the remainder.

2. Derivation and interpretation. The generator x^3+1 is binary 1001. Append three zeroes to 11001001, obtaining 11001001000. Modulo-2 division by 1001 has remainder 011. Replace the trailing zeroes by this remainder to transmit 11001001011, option B. Dividing this codeword by 1001 gives zero remainder.

# GATE 2007: Q69 (printed CS Q69)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2007.pdf, physical page 17. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Stations M,N are L kilometres apart. Frames have K bits; propagation delay is t seconds per kilometre; channel capacity is R bits/s; processing delay is negligible. What minimum sequence-number bit width is intended for maximum utilization with the stated “sliding window” protocol? ACK timing and protocol variant are not explicitly specified.
Options:
(A) ceil(log₂((2LtR+2K)/K))
(B) ceil(log₂(2LtR/K))
(C) ceil(log₂((2LtR+K)/K))
(D) ceil(log₂((2LtR+K)/(2K)))

## Solution

1. Approach. A frame takes K/R seconds to serialize and an ACK takes a round trip of approximately 2Lt after the frame is sent. First find the necessary window in frames, then apply the Go-Back-N sequence-space constraint; do not confuse window size with number of labels.

2. Derivation and interpretation. Let transmission time T=K/R and one-way propagation time P=Lt. With negligible ACK serialization, full utilization needs an integer window W >= ceil(1+2P/T). For Go-Back-N with an m-bit sequence field, W <= 2^m-1, hence m >= ceil(log2(2+2LtR/K)); this is option A. The problem says only sliding window, not Go-Back-N, and does not state ACK timing: Selective Repeat instead needs sequence space at least 2W, while counting merely enough distinct labels without the Go-Back-N guard gives a different expression. Therefore A requires the standard Go-Back-N/negligible-ACK interpretation; the generic wording alone does not uniquely fix the answer.

**Paraphrased problem context:** Match P: SMTP, Q: BGP, R: TCP, S: PPP to 1: Application, 2: Transport, 3: Data link, 4: Network, 5: Physical layer.
Options:
(A) P-2,Q-1,R-3,S-5
(B) P-1,Q-4,R-2,S-3
(C) P-1,Q-4,R-2,S-5
(D) P-2,Q-4,R-1,S-3

## Solution

1. Approach. SMTP transfers mail, TCP provides end-to-end transport, and PPP frames data on a link. The offered matching classifies BGP by its routing function; its TCP-based transport is a separate layering nuance.

2. Derivation and interpretation. SMTP provides application-layer mail transfer (1); BGP performs interdomain routing, conventionally classified here by its network-layer function (4); TCP is transport-layer (2); PPP is data-link-layer (3). Thus P-1,Q-4,R-2,S-3, option B. BGP actually exchanges control messages over TCP, so its implementation can also be described as an application-layer protocol; the offered matching uses routing function.
