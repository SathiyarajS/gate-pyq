**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Two hosts use stop-and-wait on a point-to-point link. For the same frame size, which combination gives lowest utilization? A longer link/lower bit rate; B longer link/higher bit rate; C shorter link/lower bit rate; D shorter link/higher bit rate.

## Solution

Ignoring a negligible ACK, stop-and-wait utilization is T_tx/(T_tx+2T_prop)=1/(1+2T_prop R/L) for fixed frame size L. A longer link raises propagation time, and a higher transmission rate R shortens transmission time relative to the wait. Both decrease utilization, so the lowest is B.

Teaching detail. Let L be frame bits, R link bits/second, and d one-way propagation time. The sender spends L/R seconds transmitting, then approximately 2d waiting for propagation and acknowledgment before the next frame. Thus the useful busy fraction is (L/R)/(L/R+2d). Faster transmission can improve absolute throughput while lowering this fraction, because a short burst is followed by the same propagation wait. This distinction between utilization and raw link speed is the main trap in the options.

**Type / marks:** MSQ, 1 mark(s).

**Official answer:** A, C

**Derived answer:** A;C

**Paraphrased problem context:** Select the incorrect OSPF statements: A it uses Bellman–Ford; B it uses Dijkstra's least-cost paths; C it is an inter-domain protocol; D it supports hierarchical routing.

## Solution

OSPF is a link-state intra-domain routing protocol that applies Dijkstra’s shortest-path algorithm. It also supports hierarchical areas with a backbone. Bellman-Ford is associated with distance-vector protocols, and inter-domain routing is not OSPF’s role. The incorrect statements are A, C.

Teaching detail. OSPF routers distribute link-state information within an autonomous system, build a topology view, and compute shortest paths using Dijkstra. Areas provide hierarchy, normally tied together by a backbone area. Inter-domain routing means routing between autonomous systems and is associated with BGP rather than OSPF. Notice that the question asks for incorrect statements: selecting the two true statements B,D would reverse the answer even if the protocol facts were understood correctly.

**Official answer:** B, C, D

**Derived answer:** B;C;D

**Paraphrased problem context:** A TCP-like byte-stream protocol runs at 100 Mbps, RTT 150 ms, and maximum segment lifetime 2 minutes. Which sequence-number field lengths prevent reuse within a segment lifetime at full rate? A 30 bits; B 32; C 34; D 36.

## Solution

At100Mbps a byte-stream consumes100×10⁶/8=12.5×10⁶ sequence numbers per second. During the 120-second maximum segment lifetime it can send1.5×10⁹ bytes. The sequence space must exceed that count to avoid wraparound while old data can still exist. Since2³⁰≈1.074×10⁹ is too small and 2³¹≈2.147×10⁹ is sufficient, the listed32-, 34-, 36-bit fields work, but30 bits does not. Thus B, C, D. RTT affects window sizing, not this lifetime wraparound bound.

Teaching detail. Sequence numbers label bytes, not bits or whole packets, so the conversion from 100 megabits/second to bytes/second is essential. For b bits, wrap time is 2^b/(12.5×10^6) seconds; it must exceed 120 seconds in the intended model. A 30-bit space wraps in about 85.9 seconds, whereas 32 bits lasts about 343.6 seconds. The mathematical minimum is 31 bits, which is absent from the offered choices; that does not make 32 the sole valid answer, because larger listed fields also work.

**Type / marks:** MSQ, 2 mark(s).

**Official answer:** C, D

**Derived answer:** C, D

**Paraphrased problem context:** A browser and all DNS servers have empty caches. Resolving a hostname requires iterative queries through three DNS tiers, each costing RTT. Fetching its small HTML reveals ten small same-server objects; all transmission/rendering times are negligible and web-server RTT is identical. Which totals are correct? A 7 RTT for nonpersistent HTTP with five parallel connections; B 5 RTT for persistent pipelining; C 9 RTT for nonpersistent/five parallel; D 6 RTT for persistent/pipelining.

## Solution

The three uncached DNS tiers require three sequential round trips. Fetching the base HTML adds one TCP-handshake RTT and one request/response RTT. With non-persistent HTTP and five parallel connections, the ten objects take two batches, each needing two RTTs, so the total is 3+2+4=9 RTTs (C). With a persistent connection and pipelining, all ten object requests share one further RTT after parsing the HTML, giving 3+2+1=6 RTTs (D). This is the stipulated negligible-transmission, classic HTTP-over-TCP model; no extra TLS handshake is included.

Teaching detail. Write a dependency timeline: DNS root, DNS next tier, DNS authoritative lookup, TCP connection for HTML, then HTML request/response. This consumes five RTTs before the browser learns the object URLs. Parallel nonpersistent transfers then require two waves of five, each with a connection RTT and a response RTT. Persistent pipelining reuses the HTML connection and places all ten requests in flight together, requiring just one further RTT. The objects cannot be requested before their references are learned; disregarding that dependency undercounts the total.

**Official answer:** 3 to 3

**Derived answer:** 3

**Paraphrased problem context:** Routes are 200.150.0.0/16→1, 200.150.64.0/19→2, 200.150.68.0/24→3, 200.150.68.64/27→4, and default→0. Which interface receives destination 200.150.68.118 under longest-prefix matching?

## Solution

The destination matches 200.150.0.0/16 and 200.150.64.0/19, and it also matches 200.150.68.0/24. The /27 entry 200.150.68.64 covers last-octet values 64 through 95, so it does not match 118. The longest matching prefix is consequently the /24 entry, whose interface ID is 3.

Teaching detail. Check network matches rather than selecting the most specific row unconditionally. The /19 mask fixes the top three bits of the third octet and covers third-octet values 64 through 95, including 68. The /24 fixes the entire third octet to 68. The /27 additionally divides the last octet into groups of 32; its network 64 covers 64..95, whereas 118 lies in 96..127. The /27 is more specific but fails to match, leaving /24 as the longest matching row. The default is used only when no more specific route matches.
