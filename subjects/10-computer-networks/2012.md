**Paraphrased problem context:** The protocol data unit (PDU) for the application layer in the Internet stack is
        (A) Segment             (B) Datagram               (C) Message            (D) Frame

## Solution

The generic PDU at the application layer is a message. Segment is associated with TCP at transport, datagram with connectionless network/transport use, and frame with the data-link layer. Hence C.

**Paraphrased problem context:** Which of the following transport layer protocols is used to support electronic mail?
        (A) SMTP                (B) IP                   (C) TCP                  (D) UDP

## Solution

SMTP carries electronic mail at the application layer but normally relies on TCP for reliable transport. The question explicitly asks for the transport-layer protocol, so TCP, C, is correct. IP is network-layer and SMTP itself is not transport-layer.

Worked check / additional reasoning: The service needs ordered, reliable delivery rather than raw IP datagrams. TCP supplies these transport properties; SMTP supplies mail-transfer commands above it. Selecting SMTP would answer which mail application protocol is used, a different layer question.

**Paraphrased problem context:** In classful IPv4 addressing, how many Class C network numbers are allowed?
(A) 2^14 (B) 2^7 (C) 2^21 (D) 2^24.

## Solution

Class C addresses begin with the three fixed bits 110. The first 24 bits identify the classful network, leaving 24−3=21 variable network-number bits. Thus the class has 2^21 network numbers, C. The last eight bits identify hosts within each network; this is historical classful counting, not modern CIDR allocation.

Worked check / additional reasoning: There are 32 total address bits: three class-prefix bits, 21 variable network bits, and eight host bits. The question counts networks, not usable hosts, so subtracting network/broadcast host addresses from 2^8 is irrelevant.

**Paraphrased problem context:** An Internet Service Provider (ISP) has the following chunk of CIDR-based IP addresses available
        with it: 245.248.128.0/20. The ISP wants to give half of this chunk of addresses to Organization A,
        and a quarter to Organization B, while retaining the remaining with itself. Which of the following is
        a valid allocation of addresses to A and B?
        (A) 245.248.136.0/21 and 245.248.128.0/22
        (B) 245.248.128.0/21 and 245.248.128.0/22
        (C) 245.248.132.0/22 and 245.248.132.0/21
        (D) 245.248.136.0/24 and 245.248.132.0/21

## Solution

The /20 block spans third-octet values 128–143 and has 4096 addresses. A needs 2048 addresses, a /21 aligned on a multiple of 8, and B needs 1024 addresses, a /22 aligned on a multiple of 4. Option A assigns A the range 136–143 and B the range 128–131, disjoint and within the parent block, leaving 132–135. B overlaps its blocks; C has wrong sizes and an unaligned /21; D has wrong sizes. Hence A as subnet arithmetic. The supplied 245.x address lies in reserved 240.0.0.0/4 rather than ordinary public ISP unicast space, so the scenario is hypothetical.

Worked check / additional reasoning: Splitting a /20 in half adds one prefix bit, giving /21; splitting it into quarters adds two, giving /22. The allocation to A must have twice as many addresses as B, and both blocks must also satisfy their alignment boundaries.

**Paraphrased problem context:** A source S sends a 10^6-bit file to D through two store-and-forward routers R1,R2 and three links S→R1→R2→D. Every link is 100 km long, has bandwidth 1 Mbps, and signal speed 10^8 m/s. The file is split into 1000 packets of 1000 bits each. Find the elapsed transmission-plus-propagation delay for the whole file, without additional processing or queuing delay.
(A) 1005 ms (B) 1010 ms (C) 3000 ms (D) 3003 ms.

## Solution

A packet takes 1000/10⁶ s=1 ms to transmit on each link. Each link propagation delay is 100, 000/10⁸ s=1 ms. With store-and-forward routers and no extra processing/queueing delays, the first packet reaches D after 3×(1+1)=6 ms. Subsequent packets emerge from the equal-rate pipeline 1 ms apart, so the final packet arrives at 6+999=1005 ms, A. Equivalently, total elapsed completion time is (1000+3−1)×1+3×1 ms. Summing the service time separately over all packets is not the elapsed file-transfer time asked for.

Worked check / additional reasoning: For a single packet, store-and-forward requires all three serial transmissions plus all three propagations. For many packets, transmissions overlap on different links; only 999 additional packet times follow the first packet, rather than 999 complete end-to-end delays.

**Paraphrased problem context:** Consider an instance of TCP’s Additive Increase Multiplicative Decrease (AIMD) algorithm where
        the window size at the start of the slow start phase is 2 MSS and the threshold at the start of the first
        transmission is 8 MSS. Assume that a timeout occurs during the fifth transmission. Find the
        congestion window size at the end of the tenth transmission.
        (A) 8 MSS                 (B) 14 MSS                  (C) 7 MSS               (D) 12 MSS

## Solution

The official Code A key awards Marks to All; it does not supply a numerical answer or an official explanation. To expose the conventions needed, take transmissions as RTT-sized rounds: the initial windows are 2, 4, 8, 9, 10 MSS, so a timeout in round 5 sets a halved threshold of 5 MSS under the usual round model. If the post-timeout window resets to the stated slow-start value 2 and slow-start growth is capped at the threshold, rounds 6–10 end with windows 4, 5, 6, 7, 8 MSS (A). With a one-MSS timeout restart and the same threshold-capping convention, they end with 2, 4, 5, 6, 7 MSS (C). Literal doubling across the threshold gives still other round traces. ACK-level growth and whether the quoted window belongs to the beginning or end of a transmission also need a convention. These conditional examples explain why one should not present a uniquely established numerical result from this wording; they are not claimed as the exam authority’s reason for the award.

Worked check / additional reasoning: The timeout point matters because halving acts on the current window, not the original threshold. With the stated round trace the current window is 10 MSS, giving a threshold of 5, after which the restart convention determines which option can follow.
