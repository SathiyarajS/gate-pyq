**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203119/GATE2006.pdf#page=1), physical page 1. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** Why does IP put a Time-to-Live (TTL) field in the datagram header?
Options:
(A) Ensure delivery within that time
(B) Discard packets that reach the destination later than that time
(C) Prevent packets looping indefinitely
(D) Limit the time spent queued in intermediate routers

## Solution

1. Every forwarding router decreases TTL, and a datagram is discarded when it expires. This bounds forwarding through a routing loop rather than promising delivery within a deadline.

2. Therefore C, preventing indefinite looping.

3. Teaching check: A routing loop may keep forwarding a datagram without delivering it. Decrementing a finite counter at each router eventually destroys that datagram even if the routing error persists. TTL does not reserve network resources or provide an end-to-end latency guarantee.

# GATE 2006: Q44 (printed CS Q44)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203119/GATE2006.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** A sends 32-byte packets to B with a sliding-window protocol. Round-trip delay is 80 ms and bottleneck bandwidth is 128 kbps. Which window size is optimal under the conventional bandwidth-delay-product model?
Options:
(A) 20 packets
(B) 40 packets
(C) 160 packets
(D) 320 packets

## Solution

1. The bandwidth-delay product is 128000×0.080=10240 bits. A packet carries 32×8=256 bits, so 10240/256=40 packets fill the round-trip pipe (B).

2. This uses the problem's conventional bandwidth-delay-product interpretation of round-trip delay. If the given delay excludes serialization and ACK turnaround is measured from the last bit, a strict no-idle bound can require one additional packet; that convention is not represented in the options.

3. Teaching check: Convert bytes to bits and milliseconds to seconds consistently. The bandwidth-delay product measures the amount of data that must remain outstanding to keep the channel busy. Divide this bit count by packet size; do not use 32 directly as a bit count.

**Paraphrased problem context:** C1 has IP address 203.197.2.53 and mask 255.255.128.0. C2 has 203.197.75.201 and mask 255.255.192.0. What does each infer about the other’s network?
Options:
(A) Both consider the other local
(B) C2 considers C1 local, but C1 considers C2 remote
(C) C1 considers C2 local, but C2 considers C1 remote
(D) Both consider the other remote

## Solution

1. C1 uses /17, so both 203.197.2.53 and 203.197.75.201 map to 203.197.0.0. C2 uses /18, mapping itself to 203.197.64.0 and C1 to 203.197.0.0.

2. Therefore C1 treats C2 as local while C2 treats C1 as remote: C.

3. Teaching check: Each machine applies its own mask to both addresses. C1’s /17 groups third octets 0–127; C2’s /18 separates 0–63 from 64–127. Because the masks differ, being “on the same subnet” need not be a symmetric belief between these misconfigured hosts.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203119/GATE2006.pdf#page=6), physical page 6. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** A sends nine immediately available packets to B using go-back-N and window size 3. Every fifth transmission attempt by A is lost, counting retransmissions; acknowledgments are never lost. Under the standard full-window go-back-N interpretation, how many packet transmissions complete delivery?
Options:
(A) 12
(B) 14
(C) 16
(D) 18

## Solution

1. Number transmission attempts, including retransmissions. The transmitted packet labels are 1,2,3,4,5,6,7,5,6,7,8,9,7,8,9,9.

2. Attempts 5,10,15 are lost. After each loss the later in-window packets are discarded, and the sender retransmits from the missing packet.

3. All nine packets arrive in order after attempt 16 (C). This is the standard full-window, cumulative-ACK go-back-N model used by the question.

4. Teaching check: Lost attempts are numbered globally, not separately for each packet. After losing packet 5, later out-of-order packets are discarded by go-back-N even if physically received. Replaying packet labels while marking attempt numbers 5,10,15 avoids confusing packet identity with loss periodicity.

# GATE 2006: Q82 (printed CS Q82)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203119/GATE2006.pdf#page=13), physical page 13. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

**Paraphrased problem context:** Transparent bridges B1,…,B5 connect six LANs. The following connection list fully specifies the figure; Bk:p denotes port p of bridge k:
LAN H1,H2: B1:1, B5:2, B3:4.
LAN H3,H4: B1:2, B5:3, B3:3.
LAN H5,H6: B5:1, B3:1, B4:1, B2:2.
LAN H7,H8: B5:4, B3:2, B4:2, B2:1.
LAN H9,H10: B4:3.
LAN H11,H12: B2:3.
The bridge with lowest serial number is root. Every bridge selects a shortest path to the root; equal root-port choices prefer lower port index. For forwarding onto a LAN, bridges closer to the root win, then lower bridge serial number. Which listed order is a depth-first traversal of the resulting bridge spanning tree?
Options:
(A) B1,B5,B3,B4,B2
(B) B1,B3,B5,B2,B4
(C) B1,B5,B2,B3,B4
(D) B1,B3,B4,B5,B2

## Solution

1. B1 is the root (lowest serial number). B5 and B3 both connect directly to the two top LANs: B5 chooses root port 2 over 3, while B3 chooses root port 3 over 4.

2. On each middle LAN B3 wins the designated-bridge tie against B5 because 3<5. B4 chooses its root port 1 via the H5/H6 LAN; B2 chooses root port 1 via the H7/H8 LAN.

3. Thus the bridge tree has edges B1–B5, B1–B3, B3–B4, B3–B2. Among listed sequences only B1,B5,B3,B4,B2 is a depth-first traversal, A.

4. (Other child orders can give other valid DFS sequences, but the other listed sequences leave B3’s subtree prematurely.)

5. Teaching check: After choosing root ports, compare B3 and B5 on the middle LANs: both are one bridge-hop from B1, so B3’s smaller ID wins. B4 and B2 consequently attach under B3. A depth-first traversal must finish B3’s children before returning to visit sibling B5.

# GATE 2006: Q83 (printed CS Q83)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203119/GATE2006.pdf#page=13), physical page 13. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A, as complete topology-consistent forwarding table

**Paraphrased problem context:** Transparent bridges B1,…,B5 connect six LANs. The following connection list fully specifies the figure; Bk:p denotes port p of bridge k:
LAN H1,H2: B1:1, B5:2, B3:4.
LAN H3,H4: B1:2, B5:3, B3:3.
LAN H5,H6: B5:1, B3:1, B4:1, B2:2.
LAN H7,H8: B5:4, B3:2, B4:2, B2:1.
LAN H9,H10: B4:3.
LAN H11,H12: B2:3.
The bridge with lowest serial number is root. Every bridge selects a shortest path to the root; equal root-port choices prefer lower port index. For forwarding onto a LAN, bridges closer to the root win, then lower bridge serial number. For the resulting tree, after H1 sends a broadcast ping, which listed forwarding table describes B3? Tables list destination groups and outgoing port. D retains the reproduced H7 duplication.
Options:
(A) H1,H2,H3,H4→3; H5,H6,H9,H10→1; H7,H8,H11,H12→2
(B) H1,H2→4; H3,H4→3; H5,H6→1; H7,H8,H9,H10,H11,H12→2
(C) H3,H4→3; H5,H6,H9,H10→1; H1,H2→4; H7,H8,H11,H12→2
(D) H1,H2,H3,H4→3; H5,H7,H9,H10→1; H7,H8,H11,H12→4

## Solution

1. Using Q82’s spanning tree, B3 reaches both top LANs through root port 3: H1,H2,H3,H4→3. Its port 1 connects the H5/H6 LAN and B4 leading to H9/H10: H5,H6,H9,H10→1.

2. Port 2 connects the H7/H8 LAN and B2 leading to H11/H12: H7,H8,H11,H12→2. This is A; B3 port 4 is blocked.

3. A broadcast from H1 arrives at B3 on port 3.

4. Teaching check: Interpret the table as the forwarding directions implied by the converged spanning tree. A single broadcast frame teaches a learning bridge only the source’s direction, not every destination entry by itself. The full table in the options therefore describes the tree-based routes, rather than a complete table learned solely from that one frame.
