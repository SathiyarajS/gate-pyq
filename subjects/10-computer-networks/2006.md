**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Every forwarding router decreases TTL, and a datagram is discarded when it expires. This bounds forwarding through a routing loop rather than promising delivery within a deadline. Therefore C, preventing indefinite looping.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

The bandwidth-delay product is 128000×0.080=10240 bits. A packet carries 32×8=256 bits, so 10240/256=40 packets fill the round-trip pipe (B). This uses the problem's conventional bandwidth-delay-product interpretation of round-trip delay. If the given delay excludes serialization and ACK turnaround is measured from the last bit, a strict no-idle bound can require one additional packet; that convention is not represented in the options.

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

Number transmission attempts, including retransmissions. The transmitted packet labels are 1,2,3,4,5,6,7,5,6,7,8,9,7,8,9,9. Attempts 5,10,15 are lost. After each loss the later in-window packets are discarded, and the sender retransmits from the missing packet. All nine packets arrive in order after attempt 16 (C). This is the standard full-window, cumulative-ACK go-back-N model used by the question.

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203119/GATE2006.pdf#page=13), physical page 13. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

B1 is the root (lowest serial number). B5 and B3 both connect directly to the two top LANs: B5 chooses root port 2 over 3, while B3 chooses root port 3 over 4. On each middle LAN B3 wins the designated-bridge tie against B5 because 3<5. B4 chooses its root port 1 via the H5/H6 LAN; B2 chooses root port 1 via the H7/H8 LAN. Thus the bridge tree has edges B1–B5, B1–B3, B3–B4, B3–B2. Among listed sequences only B1,B5,B3,B4,B2 is a depth-first traversal, A. (Other child orders can give other valid DFS sequences, but the other listed sequences leave B3’s subtree prematurely.)
