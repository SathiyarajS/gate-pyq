

# GATE 2010: Q25 (printed CS Q15)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 4. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Routers decrement TTL as a datagram is forwarded and discard it when the limit is exhausted. A packet caught in a routing loop therefore cannot circulate indefinitely. This bounds packet lifetime rather than prioritizing traffic, directly reducing delay or optimizing throughput: D.

## Solution

Ping uses ICMP echo requests and replies handled by the network protocol stack, rather than a conventional application-layer client talking to an application server. Web browsing, ordinary email and server-based Internet chat use client-server application models. Thus D is the intended classification; request–reply alone does not make a utility an application-layer client-server service.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

The last octets are 113=01110001₂ and 91=01011011₂. A /24 mask gives the same network. A /25 mask (128) gives last-octet network 0 for both; a /26 mask (192) gives 64 for both. A /27 mask (224) gives 96 for 113 and 64 for 91, placing the hosts in different subnets. Therefore 255.255.255.224 must not be used, option D.

# GATE 2010: Q64 (printed CS Q54)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

With positive link weights, an edge is unusable by any shortest path exactly when another path between its endpoints is strictly shorter. Link R1–R2 has weight 6 but R1–R3–R2 costs 3+2=5, so it is unused. Link R4–R6 has weight 8 but R4–R5–R6 costs 1+4=5, so it is also unused. Every remaining edge is itself a shortest path between its endpoints: R1–R3=3, R2–R3=2, R2–R4=7, R3–R5=9 and R4–R5=1, R5–R6=4. In particular the alternative to R3–R5 through R2,R4 costs 2+7+1=10, greater than 9. Thus exactly two links will never be selected, C. This assumes stabilized shortest-path routing, with data available for any source/destination pair.

# GATE 2010: Q65 (printed CS Q55)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

Change precisely the two previously unused links R1–R2 and R4–R6 to weight 2. Now R5–R6 has direct weight 4 but R5–R4–R6 costs 1+2=3, so it becomes unused. All other links remain shortest between their endpoints: the changed links have weight 2; R1–R3=3 beats R1–R2–R3=4; R2–R3=2; R2–R4=7 beats R2–R3–R5–R4=12; R3–R5=9 beats R3–R2–R4–R5=10; and R4–R5=1. Hence one link remains unused, B. Recompute routes after the weight changes rather than retaining the previous unused set.
