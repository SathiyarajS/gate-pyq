

# GATE 2010: Q25 (printed CS Q15)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 4. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Which statement best explains why an IP datagram has a Time-to-Live (TTL) header field?
Options: (A) To prioritize packets; (B) To reduce delays; (C) To optimize throughput; (D) To prevent packet looping.

## Solution

Routers decrement TTL as a datagram is forwarded and discard it when the limit is exhausted. A packet caught in a routing loop therefore cannot circulate indefinitely. This bounds packet lifetime rather than prioritizing traffic, directly reducing delay or optimizing throughput: D.

Teaching detail: If routers A and B mistakenly route a destination through each other, the same packet can alternate indefinitely without a hop/lifetime bound. TTL makes each traversal consume part of a finite budget. It does not repair the routing error itself; it limits the damage by eventually dropping the circulating datagram.

# GATE 2010: Q26 (printed CS Q16)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 4. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Which is not a client–server application in the conventional networking classification?
Options: (A) Internet chat; (B) Web browsing; (C) E-mail; (D) Ping.

## Solution

Ping uses ICMP echo requests and replies handled by the network protocol stack, rather than a conventional application-layer client talking to an application server. Web browsing, ordinary email and server-based Internet chat use client-server application models. Thus D is the intended classification; request–reply alone does not make a utility an application-layer client-server service.

Teaching detail: The relevant distinction is the protocol layer and service model, not merely whether one machine sends and another responds. A web server, mail server or chat server implements an application service. Ping normally asks the remote IP/ICMP stack to generate an echo reply, without a separately running user-level application server.

# GATE 2010: Q57 (printed CS Q47)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 11. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Hosts A and B have IP addresses 10.105.1.113 and 10.105.1.91, with a common netmask N. Which mask must not be used if they are to belong to the same network?
Options: (A) 255.255.255.0; (B) 255.255.255.128; (C) 255.255.255.192; (D) 255.255.255.224.

## Solution

The last octets are 113=01110001₂ and 91=01011011₂. A /24 mask gives the same network. A /25 mask (128) gives last-octet network 0 for both; a /26 mask (192) gives 64 for both. A /27 mask (224) gives 96 for 113 and 64 for 91, placing the hosts in different subnets. Therefore 255.255.255.224 must not be used, option D.

Teaching detail: Network membership is determined by bitwise AND of address and mask. Since the first three octets agree, only the final octet matters. /26 partitions that octet into ranges 0–63,64–127,128–191,192–255, so both hosts are in 64–127. /27 splits it further into 64–95 and 96–127, separating 91 from 113.

# GATE 2010: Q64 (printed CS Q54)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

**Paraphrased problem context:** An undirected router network has exactly these links and weights: R1–R2:6, R1–R3:3, R2–R3:2, R2–R4:7, R3–R5:9, R4–R5:1, R4–R6:8, R5–R6:4. Routers use distance-vector routing, starting with neighbor entries equal to direct-link weights. After routing tables stabilize, how many links are never used to carry data?
Options: (A) 4; (B) 3; (C) 2; (D) 1.

## Solution

With positive link weights, an edge is unusable by any shortest path exactly when another path between its endpoints is strictly shorter. Link R1–R2 has weight 6 but R1–R3–R2 costs 3+2=5, so it is unused. Link R4–R6 has weight 8 but R4–R5–R6 costs 1+4=5, so it is also unused. Every remaining edge is itself a shortest path between its endpoints: R1–R3=3, R2–R3=2, R2–R4=7, R3–R5=9 and R4–R5=1, R5–R6=4. In particular the alternative to R3–R5 through R2,R4 costs 2+7+1=10, greater than 9. Thus exactly two links will never be selected, C. This assumes stabilized shortest-path routing, with data available for any source/destination pair.

Teaching detail: To prove that an edge is never needed, replace it in any purported shortest route by the cheaper endpoint-to-endpoint route; the result is a shorter walk and, with positive weights, can be reduced to a path. Conversely, an edge strictly shortest between its own endpoints is needed for that endpoint pair. This avoids enumerating every source–destination routing table.

# GATE 2010: Q65 (printed CS Q55)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2010.pdf, physical page 14. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

**Paraphrased problem context:** An undirected router network has exactly these links and weights: R1–R2:6, R1–R3:3, R2–R3:2, R2–R4:7, R3–R5:9, R4–R5:1, R4–R6:8, R5–R6:4. Routers use distance-vector routing, starting with neighbor entries equal to direct-link weights. First determine the links never used after stabilization. Change every such link’s weight to 2 and rerun distance-vector routing until stable. How many links are now unused?
Options: (A) 0; (B) 1; (C) 2; (D) 3.

## Solution

Change precisely the two previously unused links R1–R2 and R4–R6 to weight 2. Now R5–R6 has direct weight 4 but R5–R4–R6 costs 1+2=3, so it becomes unused. All other links remain shortest between their endpoints: the changed links have weight 2; R1–R3=3 beats R1–R2–R3=4; R2–R3=2; R2–R4=7 beats R2–R3–R5–R4=12; R3–R5=9 beats R3–R2–R4–R5=10; and R4–R5=1. Hence one link remains unused, B. Recompute routes after the weight changes rather than retaining the previous unused set.

Teaching detail: Changing edge weights requires recomputing shortest paths globally. The former R4–R6 bypass is now the cheap direct edge of weight two; together with R4–R5 of weight one it undercuts R5–R6. The changed R1–R2 edge does not undercut R1–R3, since 2+2=4>3. These comparisons explain why the unused set changes rather than merely shrinking.
