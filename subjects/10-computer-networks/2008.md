

# GATE 2008: Q14 (printed CS Q14)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 4. Consult original wording and choices.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

TCP presents a byte-stream service and segments that stream as needed. The application’s total data need not fit a single TCP/IP packet or Ethernet frame, so the conceptual service has no protocol-level maximum of the listed packet sizes. Thus any size, A, subject to implementation/API buffer limits rather than a stream-size restriction.

# GATE 2008: Q56 (printed CS Q56)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 11. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

The congestion window grows exponentially over successive round-trip times in slow start, option D. In the simplified textbook model each acknowledged segment increases the window by one MSS; a window of W segments produces about W acknowledgments in one RTT, so the window becomes approximately 2W. After k such rounds it is approximately 2^k times its initial value, until reaching a threshold or encountering loss. Growth is per ACK rather than continuous time; delayed ACKs and practical implementations affect the precise factor but not the intended exponential-versus-linear distinction.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** C

## Solution

255.255.248.0 has 8+8+5=21 leading one bits because 248=11111000₂. Thus 32−21=11 host bits remain. A subnet has 2^11=2048 addresses; reserving the all-zero host part for the subnet address and the all-one host part for broadcast leaves 2046 usable host addresses, option C. The original Class B label does not change the host count once the subnet mask is supplied.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** B

## Solution

At full output rate 10 Mbit/s, tokens are consumed at 10 Mbit/s while replenishment continues at 2 Mbit/s. The initially full 16-Mbit bucket therefore drains at a net rate of 8 Mbit/s. Its maximum full-rate burst lasts 16/(10−2)=2 seconds, option B. Equivalently 10t≤16+2t gives t≤2. Ignoring concurrent refill would incorrectly produce 1.6 seconds.

# GATE 2008: Q59 (printed CS Q59)

**Question:** [Official-source archive](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view), member CS/CS2008.pdf, physical page 11. Consult original wording and choices.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** A

## Solution

The client connect() can return successfully, option A. After socket(), bind() and listen(), the server kernel has a listening TCP endpoint and can complete the three-way handshake while the server process is descheduled. The resulting established connection waits in the listener’s accept queue; accept() subsequently removes an entry and returns a connected socket to the server process. Hence user-space accept() is not required for the client handshake to complete. The intended setting assumes an available backlog slot and normal network operation; incidental loss, queue exhaustion or unrelated errors can of course affect real calls.
