**Paraphrased problem context:** Match P UDP port, Q Ethernet MAC address, R IPv6 Next Header, S TCP sequence number to I 48, II 8, III 32, IV 16 bits. Options: A P-III,Q-IV,R-II,S-I; B P-II,Q-I,R-IV,S-III; C P-IV,Q-I,R-II,S-III; D P-IV,Q-I,R-III,S-II.

## Solution

Method and intermediate reasoning:

A UDP source or destination port is a 16-bit field, allowing 65536 numeric values. A conventional Ethernet address is six octets, hence 48 bits. IPv6 Next Header is a one-octet protocol identifier, not a pointer-sized field. TCP’s sequence space has 2^32 byte positions. These independent facts yield the complete matching; confusing byte lengths with bit lengths is the main arithmetic trap.

Derivation, answer and qualifications:

UDP port numbers have 16 bits; Ethernet MAC addresses 48; IPv6 Next Header8; TCP sequence numbers 32. Therefore P-IV, Q-I, R-II, S-III, C.

**Paraphrased problem context:** During textbook slow start consider: i cwnd increases by 2 MSS per ACK; ii doubles per ACK; iii increases by 1 MSS per RTT; iv approximately doubles per RTT. Choose A ii,iii; B i,iii; C iv only; D i,iv.

## Solution

Method and intermediate reasoning:

Suppose cwnd is w MSS at the start of a round, so approximately w full segments are sent. Each successful ACK adds roughly one MSS, and the w acknowledgments add w MSS in total. The next round therefore starts near 2w MSS. This is exponential growth by rounds, not by individual ACKs. A one-MSS increase per RTT describes the rough congestion-avoidance behavior instead of slow start.

Derivation, answer and qualifications:

In textbook slow start, each ACK increases cwnd by approximately one MSS. With one ACK per segment in a full window, one RTT supplies about cwnd/MSS ACKs, approximately doubling the window. Only iv is true, C. Delayed ACKs and implementation details qualify the approximate doubling.

**Paraphrased problem context:** A long-lived TCP connection sends at 10^9 bits/s and starts at sequence number 1234. Find the minimum time in seconds before that number can recur, rounded to an integer.

## Solution

Method and intermediate reasoning:

A TCP sequence number labels a byte, so a full modulo-2^32 cycle consumes 4294967296 bytes, or 34359738368 bits. Divide by the bit rate, maintaining consistent units. The initial value 1234 affects which label comes first, but not how many increments return to it. This is a sequence-space throughput calculation; it does not independently establish that reusing the number is safe from delayed old packets.

Derivation, answer and qualifications:

TCP sequence numbers count bytes modulo 2^32. At10^9 bits/s, consuming the full sequence space requires 2^32·8/10^9≈34.359738 seconds, rounded 34. The starting number 1234 only shifts the cycle and does not change its length.

**Paraphrased problem context:** An IPv4 packet is 4500 bytes including a 20-byte IP header and 40-byte TCP header. Router MTU is 600 bytes; each fragment has a 20-byte IP header and the first offset is zero. Find the third fragment’s stored offset.

## Solution

Method and intermediate reasoning:

Fragment offset is measured in eight-byte units from the original IP payload start, not from the original IP header. A full fragment may hold 580 payload bytes by MTU, but a nonfinal fragment must end on an eight-byte boundary, so round down to 576. The first occupies payload bytes 0–575, the second 576–1151, and the third starts at 1152. Their stored offsets are 0,72,144. The TCP header travels as part of the first payload, without a new TCP header in later fragments.

Derivation, answer and qualifications:

Each fragment has room for 600−20=580 payload bytes. Nonfinal payload lengths must be multiples of 8, so use 576 bytes per full fragment. The third fragment starts after 2*576=1152 bytes of original IP payload, giving stored offset 1152/8=144. The40-byte TCP header is part of the IP payload and is not repeated or subtracted from every fragment. Fragmentation is assumed permitted, as the question prescribes outgoing fragments.

**Paraphrased problem context:** Two nodes P,Q are d metres apart, propagation speed 10 m/time-unit. Nodes sense for 5 units then transmit next; on detecting another transmission they wait for it to end and sense again. Transmissions last 20 units without collision detection. P begins at t=0; Q begins sensing at t=0. Find largest collision-avoiding d, rounded to metres.

## Solution

Method and intermediate reasoning:

Q cannot sense P immediately at a distance: P’s leading signal arrives at t=d/10. To suppress Q’s pending transmission, that arrival must occur by the sensing decision at t=5 under the intended endpoint convention. At d=50 the signal reaches Q at the boundary and remains present for the next 20 units as P’s packet propagates past Q. A larger propagation delay leaves Q’s sensing interval apparently idle, so the protocol can launch an overlapping transmission. The limiting equation uses sensing time, not packet duration.

Derivation, answer and qualifications:

P’s signal reaches Q after propagation delay d/10 time units. To defer, Q must observe it during the five-unit sensing interval before Q starts transmission. Thus the intended boundary is d/10≤5, giving d≤50 metres. The answer 50 uses the convention that an arrival at the end of sensing is observed before the decision to transmit. If exact simultaneous-event ordering is not specified, 50 is the limiting distance; a strict-before model would use d<50, with the same rounded boundary. P transmits for 20 units, so its signal is still ongoing when first detected at this boundary.
