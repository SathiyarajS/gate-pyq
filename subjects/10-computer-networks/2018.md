**Derived answer:** 144

**Source access:** Open archive member CS/CS2018.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

Each fragment has room for600−20=580 payload bytes. Nonfinal payload lengths must be multiples of 8, so use576 bytes per full fragment. The third fragment starts after 2*576=1152 bytes of original IP payload, giving stored offset1152/8=144. The40-byte TCP header is part of the IP payload and is not repeated or subtracted from every fragment. Fragmentation is assumed permitted, as the question prescribes outgoing fragments.

# GATE 2018 CS: Q65 (printed CS Q55)

**Question:** [Official archived paper page 23](https://drive.google.com/file/d/1popAHO-cX69oQEx_tD0wZXL1tTrBljeO/view); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 50 to 50

**Derived answer:** 50

**Source access:** Open archive member CS/CS2018.pdf inside the linked official CS.zip. Page numbers refer to the extracted PDF, not the Drive preview.

## Solution

P’s signal reaches Q after propagation delay d/10 time units. To defer, Q must observe it during the five-unit sensing interval before Q starts transmission. Thus the intended boundary is d/10≤5, giving d≤50 metres. The answer 50 uses the convention that an arrival at the end of sensing is observed before the decision to transmit. If exact simultaneous-event ordering is not specified, 50 is the limiting distance; a strict-before model would use d<50, with the same rounded boundary. P transmits for20 units, so its signal is still ongoing when first detected at this boundary.
