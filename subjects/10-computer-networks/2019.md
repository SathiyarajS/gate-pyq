**Type / marks:** MCQ, 1 mark(s).

**Official answer:** B

**Derived answer:** B

**Paraphrased problem context:** Choose the protocol pair for sending and then retrieving email, in that order: A IMAP and POP3; B SMTP and POP3; C SMTP and MIME; D IMAP and SMTP.

## Solution

Method: assign each named standard its actual role, keeping the requested order.

1. SMTP, Simple Mail Transfer Protocol, handles mail submission and transfer between mail servers. It supplies the sending role.
2. POP3, Post Office Protocol version 3, lets a client retrieve messages from a mailbox server. It supplies the retrieval role, so SMTP followed by POP3 works.
3. IMAP also supports mailbox access and retrieval, but is not the sending protocol in A or D. MIME describes message content formats, encodings, and attachments; it is not a mailbox-retrieval protocol, so C fails in its second position.

Result: B, SMTP and POP3. This does not mean POP3 is the only way to read email; an SMTP/IMAP pair would also be valid if it were offered in the correct order.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** Machines M, N, P have IPv4 addresses 100.10.5.2, 100.10.5.5, 100.10.5.6 and all use mask 255.255.255.252. Are all in one subnet (A), only M/N together (B), only N/P together (C), or all in different subnets (D)?

## Solution

1. Two IPv4 interfaces are in the same subnet when bitwise AND of each address with the subnet mask yields the same network address. The first three octets are identical here, so only the last octet needs calculation.
2. The last mask octet 252 is binary 11111100. Thus the two low bits are host bits and each subnet spans four consecutive addresses, starting at multiples of four.
3. M has last octet 2=00000010; AND with 11111100 gives 0. Its network is 100.10.5.0/30, covering last octets 0 through 3.
4. N has 5=00000101 and P has 6=00000110. Masking either gives 4=00000100. Both belong to 100.10.5.4/30, covering 4 through 7.
5. Only N and P share a subnet, so C is correct. Comparing the first three octets alone would incorrectly assume a /24 mask; the supplied /30 mask is decisive.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** C

**Derived answer:** C

**Paraphrased problem context:** In an IP-over-Ethernet network, X needs the MAC address of Y in the same subnet. Choose between sending an ARP request to the gateway IP (A), gateway MAC (B), local broadcast MAC (C), or local broadcast IP (D).

## Solution

1. The task is address resolution: X knows Y's IP address but needs the link-layer destination address for an Ethernet frame on the local network.
2. ARP carries the target IP address in its request. Since X does not yet know Y's MAC address, it sends the Ethernet frame to FF:FF:FF:FF:FF:FF, the broadcast MAC address, so local hosts can inspect the request.
3. Y recognizes its own IP in the request and normally replies with its MAC address. X can then cache the mapping and send ordinary unicast Ethernet frames to Y.
4. Therefore C describes the needed technique. Neither gateway option is the ordinary same-subnet procedure: a router is used for off-subnet forwarding, not required to identify this local neighbor.
5. D confuses protocol layers. An ARP request is carried directly in an Ethernet frame; it is not an IP datagram sent to a broadcast IP destination. Its broadcast delivery is at the MAC layer.

**Question:** [Official archived paper page 15](https://gate2026.iitg.ac.in/doc/download/2019/cs_2019.pdf#page=15); consult original wording, diagrams and choices.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 3 to 3

**Derived answer:** 3

**Paraphrased problem context:** Connect 15 machines into one LAN using 8-port Ethernet switches with no separate uplink ports. What is the smallest number of switches required?

## Solution

1. Each machine connection consumes one switch port. Connecting switches to each other also consumes a port at each end because there are no extra uplink ports.
2. A connected arrangement of k switches requires at least k−1 inter-switch links. Using a tree achieves that minimum, consuming 2(k−1) ports in total.
3. The greatest possible number of machine ports is consequently 8k−2(k−1)=6k+2. For k=2 this is 14, insufficient for 15 machines; one switch is plainly insufficient as well.
4. For k=3 the bound becomes 20. A chain of three switches uses one port on each outer switch and two on the middle switch, leaving capacities 7,6,7 for machines.
5. Allocate five machines to each switch, for example. The outer switches then use six ports each and the middle uses seven, all within their eight-port limits. Thus three switches are feasible and two are impossible: minimum 3.
6. Simply dividing 15 by 8 and rounding up misses the ports consumed by the link between the two proposed switches. Extra cycles between switches only consume more ports and cannot improve the minimum.

**Type / marks:** NAT, 2 mark(s).

**Official answer:** 97 to 97

**Derived answer:** 97

**Paraphrased problem context:** For a two-prime RSA modulus n=3007, Euler's totient φ(n)=2880. Find the prime factor of n that exceeds 50.

## Solution

1. In the standard RSA construction n=pq for distinct primes p,q, and φ(n)=(p−1)(q−1). Expanding gives φ(n)=pq−p−q+1=n−(p+q)+1.
2. Rearrange to recover the prime sum: p+q=n+1−φ(n)=3007+1−2880=128. Their product is already known: pq=3007.
3. Numbers with this sum and product are roots of t²−128t+3007=0. Its discriminant is 128²−4×3007=16384−12028=4356=66².
4. The roots are (128+66)/2=97 and (128−66)/2=31. Both are prime, and their product 97×31=3007 verifies the factorization.
5. Also (97−1)(31−1)=96×30=2880, verifying the given totient. Only 97 is greater than 50, so the required answer is 97.
6. The useful method is recovering p+q from the totient; trial-dividing n is unnecessary. The formula used here relies on the stated RSA two-distinct-prime setting.
