**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Historical IPv4 includes loose/strict source-route options that allow a sender to influence/specify a route. Therefore the categorical assertion that only router tables can determine the route is false, D. Multiple addresses and differing packet routes are possible, while TTL limits forwarding hops. Source routing is commonly filtered or disabled operationally, which does not erase the protocol capability considered by this historical question.

## Solution

Transport supplies end-to-end process communication above network-layer host delivery, D. End-to-end connectivity here means communication service, not necessarily a connection-oriented handshake.

## Solution

Compare the bitwise AND of each address with the printed mask. Options A and C have unequal second octets, which are fully retained. Option B retains third octets 28 and 29 under AND 31, so they differ. For D, 129 AND 31=1 and 161 AND 31=1; both addresses therefore map to 128.8.1.0. The raw mask calculation gives D. The printed 31 octet is 00011111, so this is a noncontiguous mask and cannot be expressed as a standard CIDR prefix; it must not be silently changed to 224 or another contiguous-mask octet.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

The one-way propagation delay is 2000/(2×10^8)=10 microseconds. To detect the worst-case collision, transmission must continue for at least twice this delay, 20 microseconds. At 10^7 bits/s this requires 10^7×20×10^−6=200 bits=25 bytes. Since the offered sizes are 50,100,200 bytes and none-of-the-above, the theoretical minimum is D. This calculation uses the idealized LAN parameters; it does not import Ethernet's independently standardized minimum-frame overhead.

# GATE 2003: Q84 (printed CS Q84)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=12), physical page 12. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** None

## Solution

The physical data rate is 1000×8/(50 microseconds)=160 Mbit/s. The acknowledgment for the first packet can return after one packet transmission plus two propagation delays: 50+2×200=450 microseconds. A window of five permits 5×1000×8=40000 transmitted bits during that interval, hence the achievable steady-state rate is min(160 Mbit/s,40000/450 microseconds)=88.888… Mbit/s. None of the printed options equals this. Dividing 5000 bytes by 450 microseconds gives 11.111… million bytes/s, which numerically resembles option B but is not 11.11 million bits/s. The packet size is printed in bytes and every answer is printed in bps in both sources, so B cannot be accepted without changing a unit.
