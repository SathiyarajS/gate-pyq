**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=3), physical page 3. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Paraphrased problem context:** Which assertion about Internet Protocol is false? A. A computer can have several IP addresses; B. Packets from the same source to the same destination can take different routes; C. A packet is discarded if it cannot reach its destination within a bounded number of hops; D. A source cannot set an outgoing packet’s route, which is determined only by router routing tables.

## Solution

1. A and B are compatible with multiple interfaces and datagram routing. For C, IPv4 routers decrement TTL and discard expired packets. To refute D it suffices to cite the historical source-route options; their rarity or filtering in current networks does not make the categorical protocol statement true.

2. Historical IPv 4 includes loose/strict source-route options that allow a sender to influence/specify a route. Therefore the categorical assertion that only router tables can determine the route is false, D. Multiple addresses and differing packet routes are possible, while TTL limits forwarding hops. Source routing is commonly filtered or disabled operationally, which does not erase the protocol capability considered by this historical question.

# GATE 2003: Q28 (printed CS Q28)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=3), physical page 3. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 1 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** Which functionality must the transport protocol provide over and above network-layer service? A. Recovery from packet losses; B. Detection of duplicate packets; C. Correct-order packet delivery; D. End-to-end connectivity.

## Solution

1. Network delivery addresses hosts; transport adds end-to-end communication between application endpoints, usually identified by ports. TCP implements the first three enhancements, whereas UDP provides transport service without promising any of them. Hence they cannot be universal requirements of the layer.

2. Transport supplies end-to-end process communication above network-layer host delivery, D. Reliability, duplicate suppression and in-order delivery are features of some transport protocols, notably TCP, but are not required of all: UDP does not guarantee them. End-to-end connectivity here means communication service, not necessarily a connection-oriented handshake.

# GATE 2003: Q82 (printed CS Q82)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=12), physical page 12. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** A network uses the printed subnet mask 255.255.31.0. Which pair of addresses could belong to that network?
A. 172.57.88.62 and 172.56.87.233
B. 10.35.28.2 and 10.35.29.4
C. 191.203.31.87 and 191.234.31.88 [GFG; GateForum prints 191.03.31.87 as the first address.]
D. 128.8.129.43 and 128.8.161.55
The printed mask is noncontiguous; apply its literal bitwise AND, not an assumed CIDR repair.

## Solution

1. Membership under the printed mask requires address1 AND mask = address2 AND mask. Its first two 255 octets preserve both first octets, while the final zero octet discards the host's last octet.
2. A fails because 57≠56 in octet two; C fails because 203≠234. B's first two octets match, but 28 AND 31=28 and 29 AND 31=29, so it fails too.
3. For D, 129=10000001₂ and 161=10100001₂. AND with 31=00011111₂ gives 00000001₂ for both. Both network values are 128.8.1.0.
4. Thus the literal calculation selects D. Because 00011111 is not a contiguous prefix-mask octet, this is not a valid ordinary CIDR mask; that caveat must remain explicit.

Baseline derivation and caveats (retained): Compare the bitwise AND of each address with the printed mask. Options A and C have unequal second octets, which are fully retained. Option B retains third octets 28 and 29 under AND 31, so they differ. For D, 129 AND 31=1 and 161 AND 31=1; both addresses therefore map to 128.8.1.0. The raw mask calculation gives D. The printed 31 octet is 00011111, so this is a noncontiguous mask and cannot be expressed as a standard CIDR prefix; it must not be silently changed to 224 or another contiguous-mask octet.

# GATE 2003: Q83 (printed CS Q83)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=12), physical page 12. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** D

**Paraphrased problem context:** A broadcast LAN is 2 km long, has bandwidth 10^7 bits/s and uses CSMA/CD. Signals propagate along its wire at 2×10^8 m/s. What is the minimum packet size usable on the network?
A. 50 bytes  B. 100 bytes  C. 200 bytes  D. None of the above

## Solution

1. In the worst case a remote transmitter starts just before hearing the first transmitter. The collision indication must travel back, requiring nearly a full round-trip propagation time.
2. One-way propagation is 2000/(2×10^8)=10^−5 s=10 μs. Therefore a frame must last at least 20 μs for collision detection while transmission is still in progress.
3. At 10^7 bits/s the minimum length is 10^7×20×10^−6=200 bits. Divide by eight to convert to bytes: 25 bytes.
4. None of the listed numerical byte sizes equals that theoretical minimum, so D. The 200 in the computation is bits, not the 200-byte option C.

Baseline derivation and caveats (retained): The one-way propagation delay is 2000/(2×10^8)=10 microseconds. To detect the worst-case collision, transmission must continue for at least twice this delay, 20 microseconds. At 10^7 bits/s this requires 10^7×20×10^−6=200 bits=25 bytes. Since the offered sizes are 50,100,200 bytes and none-of-the-above, the theoretical minimum is D. This calculation uses the idealized LAN parameters; it does not import Ethernet's independently standardized minimum-frame overhead.

# GATE 2003: Q84 (printed CS Q84)

**Question:** [Third-party reproduction](https://media.geeksforgeeks.org/wp-content/cdn-uploads/20211005203452/GATE2003.pdf#page=12), physical page 12. Consult the reproduced wording and choices. Original official provenance and completeness have not been established.

**Type / marks:** MCQ, 2 mark(s).

**Official answer:** Not available; no official key located.

**Independently derived answer:** None

**Paraphrased problem context:** A sends data to B over a full-duplex link using a sliding-window protocol. Send and receive windows each hold five packets. Data packets are 1000 bytes and take 50 μs to transmit. ACKs travel only B→A and have negligible transmission time. One-way propagation is 200 μs. What is maximum achievable throughput?
A. 7.69×10^6 bps
B. 11.11×10^6 bps
C. 12.33×10^6 bps
D. 15.00×10^6 bps
Both reproductions print packet size in bytes and options in bits per second.

## Solution

1. The raw link rate is 1000×8/(50×10^−6)=160×10^6 bits/s.
2. Packet 1 finishes leaving A at 50 μs and reaches B at 250 μs. Its immediate ACK returns to A at 450 μs. Meanwhile A can send packets 1–5 during 0–250 μs and must wait before sending packet 6 at 450 μs.
3. The ACKs then space subsequent transmissions 50 μs apart, giving recurrent batches of five packets per 450 μs. Window-limited throughput=5×1000×8/(450×10^−6)=88.888... Mbit/s, below the raw rate.
4. No option matches. 5000/(450 μs)=11.111... million bytes/s, numerically close to B but with the wrong unit. Accepting B would silently discard the factor eight, so the baseline unanswered status is retained.

Baseline derivation and caveats (retained): The physical data rate is 1000×8/(50 microseconds)=160 Mbit/s. The acknowledgment for the first packet can return after one packet transmission plus two propagation delays: 50+2×200=450 microseconds. A window of five permits 5×1000×8=40000 transmitted bits during that interval, hence the achievable steady-state rate is min(160 Mbit/s,40000/450 microseconds)=88.888… Mbit/s. None of the printed options equals this. Dividing 5000 bytes by 450 microseconds gives 11.111… million bytes/s, which numerically resembles option B but is not 11.11 million bits/s. The packet size is printed in bytes and every answer is printed in bps in both sources, so B cannot be accepted without changing a unit.
