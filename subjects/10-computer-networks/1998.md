

# GATE 1998: Q16 (printed A Q1.16)

**Essential problem context (paraphrased):** Send 300 characters/s using 8 data bits, one parity bit, two stop bits. Choose 2400, 19200, 4800, 1200 baud.

## Solution

Asynchronous framing also uses one start bit. Each character therefore occupies 1+8+1+2=12 binary symbols, requiring 300·12=3600 symbols/s. With one bit per symbol, that is 3600 baud. Of the listed choices, 2400 and 1200 are too slow;4800 is the smallest sufficient choice, C. The literal minimum is not listed. If no start bit were intended, the arithmetic would instead give 3300; it still would not equal 4800. The choice is therefore a standard/listed-rate selection, not an exact unconstrained minimum.
