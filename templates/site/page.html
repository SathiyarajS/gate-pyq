{{ 'An honest preview' if preview else 'Scope and sources' }}

This archive covers CS papers from 1991–2026. The 1990 paper and separate IT papers from 2004–2008 are out of scope. Engineering mathematics and other excluded subjects remain visible in the thirteenth collection.

Questions without accepted independent transcription review retain paraphrase text and reviewed crops where enabled. Refer to source papers for exact wording, complete option sets, diagrams and shared data. Some historical sources are third-party reproductions with unverified fidelity. Archive links may open an archive rather than an individual PDF; the named member and physical page identify the source.

Keys, derivations and uncertainty

Official answers are displayed exactly as recorded. “None located” means no official key has been found. Independently derived answers are not official matches. Conditional reasoning and unresolved discrepancies remain visible with the solution. Practice checking uses only an unambiguous recorded official key; otherwise use self-check.

Repeated questions

When GATE asked a question again, each copy links to the others: “same question” when it was asked again as it was, and “different numbers” when the setup and question match but the given values changed. Questions that only share a topic or method are not linked. The matches were found by comparing this site’s question summaries and then checked by reading both questions; they are not exhaustive. Each subject keeps its original All questions view. Known repeats folded shows a representative with expandable alternatives; it does not claim that the remaining questions are unique. These legacy matches have not been newly source-audited by this feature. Problem patterns is separate: it groups source-reviewed questions that use the same reasoning method, while retaining differing constraints, requested metrics and all variants. Each view reports coverage and keeps ungrouped questions visible. Automated normalized-text, mathematical and reasoning-signature matches are discovery candidates only, never automatic grouping decisions.

Offline use

The Offline page saves chosen subjects or papers in this browser’s storage. Nothing is uploaded, and removing them there frees the space.

Your local practice data

Attempts, bookmarks and theme preferences are stored only in this browser when storage is available. No login or analytics is used. Blocking storage does not prevent reading.

Report a correction

Use the report link on a question to prepare a GitHub issue. Review its contents before submitting.
