**Official answer:** Not available; no official key located.

**Independently derived answer:** D

## Solution

Functional programming matches side-effect-free declarative expression evaluation (P→3). Logic programming matches declarative clauses and theorem proving (Q→4). In this classification object-oriented programming matches imperative programming with abstract data types (R→2), while imperative programming matches command-based procedural computation (S→1). Thus P-3,Q-4,R-2,S-1 is D. These are textbook paradigm characterizations, not claims that every language implementing a paradigm has only those features.
